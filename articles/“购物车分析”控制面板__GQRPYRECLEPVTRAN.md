# “购物车分析”控制面板

**注意： **此功能仅面向在亚马逊品牌注册中分配了[品牌代表](https://sellercentral.amazon.com/help/hub/reference/GJ84K745AL3R5N3Q)角色的卖家。要获得该角色，您必须直接为相关品牌工作，并负责在亚马逊商城销售该品牌。如果您无法使用此功能，说明您尚未被确定为符合亚马逊 Brand Registry 中定义的这些标准的卖家。如果您认为自己符合这些标准，请联系销售伙伴支持。

亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。

如果有错误消息提示“您没有权限访问此页面”，请向主账户管理员提出请求，在“全球用户权限”页面授予您访问**亚马逊品牌分析**的权限。

[购物车分析控制面板](https://sellercentral.amazon.com/brand-analytics/dashboard/market-basket-analysis)可向品牌代表显示亚马逊买家（总体上）在购买品牌代表商品的同时购买频率最高的商品。这可让品牌代表快速识别捆绑销售和交叉销售的机会。

## 常见问题

#### “购物车分析”控制面板中包含哪些信息？

购物车分析报告显示了与品牌代表商品同时购买的频率最高的前 3 种商品。它还显示了在用户选择的报告时间范围内，前 3 种商品中每种商品与品牌代表商品同时购买的频率。

#### 报告中显示哪些商品？

此报告可显示与品牌代表在 Brand Registry 中成功注册的品牌相关的所有商品。如果商品与该品牌代表无关，那么只有在这种商品是与该品牌某一商品同时购买的前 3 种商品之一时，才会显示在此报告中。

#### 此报告是否允许搜索特定商品？

允许，品牌代表可以使用报告顶部的 ASIN 搜索框来搜索特定商品或一组商品。ASIN 搜索框支持一次搜索最多 100 个 ASIN，每个 ASIN 可通过空格或逗号分隔。

#### “显示”下拉菜单如何运作？

【显示】下拉菜单允许用户筛选报告中显示的一组商品。默认情况下，【显示】下拉菜单将显示**所有商品**，其中会显示前 3 种商品的所有品牌组合，而不考虑相关的品牌代表。如果用户只想在前 3 种商品中查看自己的品牌商品，他们可以在【显示】下拉菜单中选择**仅限同一品牌组合**。如果用户只想在前 3 种商品中查看来自其他品牌的商品，他们可以在【显示】下拉菜单中选择**排除同一品牌组合**。这些视图可使其更轻松地识别捆绑销售机会，并确定直接竞争的商品。

#### “购物车分析”控制面板中的数据可追溯多久？

报告保留了 3 年的数据。

#### “-”是什么意思？

“-”是一项指标值，表示没有相关数据。如果未捕获所选时间段内的数据，则会出现此错误。
