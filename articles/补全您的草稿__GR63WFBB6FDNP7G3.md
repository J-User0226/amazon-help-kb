# 补全您的草稿

“补全您的草稿”页面是一个用于管理您的所有商品信息草稿的中央控制面板。您可以通过两种方式创建商品信息草稿：
- 【使用 Web URL】： 在您使用 【Web URL】 选项创建商品信息时，亚马逊会自动创建商品信息草稿。在您提交此 URL 后，亚马逊将获取相关商品信息、预填写商品信息表格并创建商品信息草稿供您审核。
- 【由您保存】： 您可以使用【另存为草稿】选项保存商品信息表格的进度来创建商品信息草稿。此选项可用于保存商品信息数据，并在您稍后方便时完成。

## 商品信息草稿状态
以下是您创建的商品信息草稿的不同状态：
- 【进行中】： 在您提交 URL 或手动创建商品信息草稿后，它将进入【进行中】状态。商品信息草稿最长可能需要 15 分钟才能得到处理并可供审核。
- 【URL 导入失败】： 如果亚马逊无法从您提交的 URL 中获取信息，或者此 URL 无效，您的商品信息草稿将处于失败状态，并显示为 【URL 导入失败】。
- 【检查并提交】： 您创建的所有商品信息草稿将自动进入此状态。在您使用 URL 创建商品信息后，此状态表示此商品信息草稿已准备好供您审核。您可以审核此商品信息，然后点击【另存为草稿】以稍后完成它，或者点击【提交】发布此商品信息。

## 查看并提交草稿
要一次查看并提交一个草稿，请按照以下步骤操作：
1. 针对要查看或提交的草稿，点击【检查并提交】。
2. 它将在新标签页中打开一个交互式页面。在“商品识别”“描述”“商品详情”“报价”和“安全与合规”选项卡中输入必填信息。
3. 点击【另存为草稿】保存您所做的更新，或者在提供的选项卡中输入所需信息后，点击【提交】，以完成商品发布流程。

要批量查看和提交草稿，请按照以下步骤操作：
1. 使用单个商品信息草稿左侧的复选框，选择您要查看或提交的草稿。点击【选择组操作】，然后选择【通过在线电子表格编辑】。
2. 它将在新标签页中打开一个交互式电子表格网页。在左上角，您可以查看所有已打开的草稿的状态。其中包括 SKU 总数、需要进一步操作的草稿数量，以及准备就绪可以提交的草稿数量。
3. 您可以通过以下方式在电子表格中添加或更新信息：
  1. 手动编辑单个单元格的内容
  2. 从其他 Excel 文件中复制值，并将其粘贴到这个交互式电子表格中
  3. 使用“填充柄”功能在多个行或列中复制值。当您将鼠标悬停在单元格的右下角时，系统会显示一个“+”号，这个就是填充柄

4. 电子表格在“状态”列中显示每个 SKU 的更新状态。如果 SKU 存在问题，【状态】列将显示存在问题的属性的数量。如果 SKU 没有问题，状态列将显示【就绪】。
5. 您可以使用右上角的【属性】筛选条件查看必填属性或所有属性。
6. 您可以使用右上角的【查看问题】筛选条件，仅查看包含问题的 SKU 和属性。
7. 您可以使用右上角的【撤销/重做】按钮，或使用键盘快捷键，撤消或重做所做的任何更改。
8. 完成更新后，点击【另存为草稿】以保存更改，或点击【提交】以发布准备就绪可以提交的所有 SKU。

## 删除草稿
- 如果您不再需要商品信息草稿，您可以点击此控制面板上【查看并提交】旁边的垃圾桶图标将其删除。点击此图标后，系统将提示您确认删除。点击【删除】，完全移除您的商品信息。
- 如果您想删除多个商品信息草稿，请选择某个商品信息草稿左侧的复选框，滚动至页面底部，点击【选择组操作】，然后选择【删除草稿】。
- **注意： **此操作无法撤销。删除商品信息草稿后，您的所有商品信息将被完全擦除，且无法恢复。
