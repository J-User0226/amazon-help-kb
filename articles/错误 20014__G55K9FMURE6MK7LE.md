# 错误 20014

## 导致错误 20014 的原因

出现此错误的原因如下：

- 您正在尝试上传的图片 URL 无效或已损坏。

- 上传的 URL 包含“https”而非“http”。

格式正确的图片 URL 示例如下：**http://www.domain.com/directory/image-file.jpg**

## 错误消息

您提交的媒体文件无效或已损坏。请使用 HTTP 协议（而非 HTTPS、FTP 或“file”），并确保您使用的是直接媒体链接，而不是网站链接。请确认 URL 输入正确并在任何 Web 浏览器中打开。

## 解决错误 20014

要解决此错误，请按照以下步骤操作：

- 查看您的上传数据处理汇总报告，找到突出显示的错误属性。确保图片 URL 指向有效的图片，并且该图片符合我们的[商品图片要求](https://sellercentral.amazon.com/gp/help/external/G1881)。

- 删除当前的 URL，然后使用更新的 URL 重试。

- 验证您的图片 URL 是否能够正确打开。在您的账户中重新提交文件。

**注意： **您可以使用“http”，但不能使用“https”、“ftp”或“file”协议。避免使用空格和非字母数字字符，例如 $、?、@ 和 &。
