# 亚马逊 SEND - 越南至美国

亚马逊 SEND 计划允许您利用亚马逊 SEND 承运人将您的亚马逊物流库存从越南发往美国的亚马逊运营中心。您可以利用该计划以经济高效的方式将 FBA 货件和 AWD 货件运送到全球各地。亚马逊 SEND 支持空运和海运服务。亚马逊 SEND 承运人取走您的货件后，将处理货件从清关到送达亚马逊运营中心和 AWD 库房的端到端运输事务。通过亚马逊 SEND，您可以让其承运人上门取件，也可以将货件投件至承运人网点。

## 通过亚马逊 SEND 运送您的货件

按照以下步骤，通过亚马逊 SEND 预约亚马逊物流货件：

- 要创建亚马逊物流货件，请在卖家平台的【库存】下拉菜单中选择【货件】，然后导航至【货件】下拉菜单，选择 【Send to Amazon】。

- 【我想使用亚马逊或亚马逊 SEND 运输货件】复选框已自动选中

- 在第 1 步中，选择您计划运往亚马逊物流运营中心的 ASIN 及其数量。选择库存和数量后，输入包装详情。有关包装配置的更多信息，请参阅[发送至亚马逊： 选择要发送的库存](https://sellercentral.amazon.com/gp/help/external/G8SXKYFWPG6DAW6T)。

- 如果 ASIN 是单一 SKU 包装箱（如大包装），并且您已创建相应的【装箱模板】，则请选择该模板。否则，请创建一个新的装箱模板，然后选择【准备运送】。对于运往亚马逊物流运营中心的所有 ASIN 按照此流程操作，然后选择【确认并继续】。

- 如果使用混合 SKU 包装箱，请选择【混装商品】，然后点击【准备包装】。对于运往亚马逊物流运营中心的所有 ASIN 按照此流程操作，然后选择【包装混装商品】。此时将前往**第 1b 步**，您需要在此步骤中提供包装箱详情，选择【确认并继续】。

- 选择配送方式，可选择【亚马逊运营中心】或 【AWD（亚马逊智能卫星仓）】。

**注意： **对于亚马逊智能卫星仓，亚马逊 SEND 仅支持海运。

- 选择【亚马逊 SEND】。

- 选择配送模式： 【空运或海运】。

- 如何选择入库配置选项： 根据您的需求选择亚马逊物流库存入库配置选项，以优化您的总物流费用。对于高级配置选项，卖家可以选择入库区域，例如东部、西部或中部。

**注意： **此处预计的入库配置服务费不包括承运人运费。承运人运费可能会因您选择的库存入库配置选项（如货件拆分数量和地区，如适用）而有所不同。有关更多信息，请参阅[亚马逊物流入库配置服务费](https://sellercentral.amazon.com/gp/help/external/GC3Q44PBK8BXQW3Z)。

- 为货件选择所需的发货日期和取件或投件选项。如果您打算投件，请在下面的“亚马逊 SEND 承运人要求”部分找到投件详情。

- 选择所需的亚马逊 SEND 承运人，然后点击【继续前往运输方】

- 点击【获取运费】，根据包装箱尺寸和重量生成承运人运费的预估值。此费用不包括美国海关收取的关税和其他附加费用。

- 确认运输方后，输入适用于您货件的清关信息。

- **发货人类型**: 请指明您是个人发货人还是公司。承运人将根据所选内容处理货件

- **税号或增值税登记号**： 输入出口实体的税号或增值税登记号。

- **发货人名称**： 使用英语输入出口发货人/公司名称。

- **发货人信息**： 添加或选择出口实体的公司地址。

- **起运地联系详情**： 输入起运地人员的详细联系信息，以方便亚马逊 SEND 承运人协调取件事宜。

- **商品说明**： 对库存的完整描述以及预期用途说明。例如：非临床用体温计、洗发水、保湿洁面乳。描述应准确无误，以免清关期间出现问题。

- 通过选中复选框来点击【接受费用】，即表示您接受费用并同意计划条款和条件（以及链接中包含的亚马逊 SEND 承运人条款和条件）。货件送达后，系统将从您的卖家平台付款账户中扣除相应金额。

**注意： **最终费用将根据亚马逊 SEND 承运人审计过程中核实的实际重量和尺寸以及配送期间产生的适用关税和附加费计算得出。有关更多信息，请参阅[亚马逊 SEND - 卖家条款和条件](https://sellercentral.amazon.com/gp/help/external/G27F6UHDSSHW6WXF)。

- 接受费用后，请下载亚马逊物流标签和承运人标签（如适用），并将标签粘贴到箱子上。

- 确认发货后，请在“Send to Amazon”工作流程中下载并上传所需文件。

**注意： **如果该货件为您通过亚马逊 SEND 运送的首个 UPS 货件，您可能无法看到文件上传选项。承运人取件时，您需要向其提供纸质文件副本。对于后续货件，则可以在卖家平台中上传文件。

- 交接时，货件应附有必要的亚马逊物流标签、空运单或承运人标签（如适用）。

**注意： **亚马逊 SEND 承运人可能还会要求您提供其他文件，具体取决于您要运送的商品分类。

## 通过亚马逊 SEND 运送您的 AWD 货件

要创建亚马逊物流 AWD 货件，请从卖家平台的【库存】下拉菜单中选择【货件】，然后导航至【货件】下拉菜单，选择 【Send to Amazon】。选择【创建 AWD 货件】，然后继续执行下面提到的货件创建步骤，或者前往库存（在下拉菜单下）并选择仓储和分拨服务 ( AWD )。点击【发送】至 AWD 以创建货件。

或者，您也可以开始创建货件，前往[亚马逊智能卫星仓 (AWD)](https://www.sellercentral.amazon.dev/asdn/about#learn-service)，导航至【管理服务】，然后点击【创建货件】。您将转至“发送至亚马逊智能卫星仓”工作流程。有关更多信息，请前往[将货件运送至亚马逊智能卫星仓 (AWD)： 确认发货](https://sellercentral.amazon.com/gp/help/external/GQ6ZR5KNWKRBPT4M)。

## 亚马逊 SEND 付款和卖家费用

使用亚马逊 SEND 计划的卖家需要在货件送达后支付运费。运费将从卖家的提现账户中扣除。

请按照以下步骤查找您的亚马逊 SEND 承运人和海关费用详情：

- 要查看费用，请前往您的销售账户，选择【付款】下拉菜单，然后选择【交易一览】选项卡。

- 使用亚马逊物流或 AWD 货件编号查找您的交易。

## 亚马逊 SEND 商品运输资格

对于国际货件，不能通过亚马逊 SEND 计划运输危险品。

## 联系销售伙伴支持

如有任何疑问，请前往【帮助】下拉菜单，然后选择【获取帮助和资源】或使用卖家助手。选择 【AWD、运输和物流】选项，然后选择【亚马逊 SEND】。这将直接将您转到亚马逊 SEND 的支持服务。
