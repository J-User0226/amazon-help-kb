# 错误 100471

## 错误消息

${attribute_name} 包含以下禁止使用的词语/字符，这些词语/字符会导致可读性问题：${invalid_phrases}。请从 ${attribute_name} 中移除此类词语/字符。

## 导致错误 100471 的原因

出现此错误的原因如下：

- 商品名称、描述或其他内容属性包含影响可读性的特殊字符，例如 ™、©、®、†、§。

- 内容包含过度使用标点符号或符号，例如多个叹号、问号或井号。例如 !!!、???、###、♥♥♥。

- 文本包含不应显示给最终用户的 HTML 标记或格式代码，例如：<br>。

## 解决错误 100471

要解决此错误，请按照以下步骤操作：

- 查看并移除对商品信息不重要的特殊字符。

**注意： **有关更多信息，请参阅[商品名称要求](https://sellercentral.amazon.com/help/hub/reference/GYTR6SYGFA5E3EQC)和指南以及[商品要点要求](https://sellercentral.amazon.com/help/hub/reference/GX5L8BF8GLMML6CX)。

- 仅使用标准的 ASCII 字符，并将任何装饰性标点符号替换为正确的标点符号。从内容字段中移除任何 HTML 或标记语言。
