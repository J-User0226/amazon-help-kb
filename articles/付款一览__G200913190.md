# 付款一览

## 结算一览
此页面汇总了您的付款信息，其中会显示所有账户类型的当前总余额、可用资金以及近期付款情况。此外，您还可以通过一张图表查看账户余额明细，其显示内容如下：

- **期初余额**：从上一结算周期结转的金额，包括账户级别预留金和失败的付款（如有）。
- **销售额**：通过您的订单产生的金额，包括：
  - **商品费用**：您的商品价格乘以商品售出数量。
  - **配送费**：向买家收取的订单配送费用。
  - **税费**：买家支付的销售税和管理费总额，支付给您之后由您向相应的税务机关代缴。
  - **促销返点**：针对任何促销返点收取的费用。
  - **其他**：包括但不限于亚马逊物流库存赔偿和礼品包装款项。

- **退款**：
  - **支出退款**：亚马逊收取的费用和促销返点金额。
  - **销售额退款**：买家订单付款（例如商品销售额、运费、礼品包装费、补偿和税费）的金额。

- **支出**：向您的账户收取的费用，包括：
  - **亚马逊所收费用**：包括但不限于销售佣金、月度专业销售计划费用（如适用）、亚马逊物流配送费用、运费和礼品包装费用。
  - **亚马逊物流费用**：包括但不限于运营中心库存仓储费、移除订单费、赔偿和余额盘点等非订单费用。
  - **广告费用**：广告产生的费用。
  - **其他**：杂项费用，可能包括优惠券兑换费用和亚马逊卖家贷款计划还款额。

- **账户级别预留金**：亚马逊为确保您的账户中有足够的资金来处理任何索赔或信用卡拒付问题而预留的金额。有关更多信息，请参阅[什么是账户级别预留金？](https://sellercentral.amazon.com/gp/help/external/G200136810)。

如需进一步深入分析，您可以导航至以下页面：

- **交易一览**：显示与买家订单、退款和亚马逊发起的费用或赊欠款项相关的账户交易。有关更多信息，请参阅[查看交易](https://sellercentral.amazon.com/gp/help/external/G200913230)。
- **延迟交易**：显示将在未来某个日期向您付款的交易。大部分交易都会延迟一段时间才会支付。有关更多信息，请参阅[什么是延迟交易？](https://sellercentral.amazon.com/gp/help/external/GLRNLZDAKHDBBVBY)。
- **付款**：显示每个结算周期内向您的账户支付的金额以及您的资金状态。此页面还提供有**结算报告**。这些报告提供了有关结算周期内所有财务交易的信息，包括买家订单、退款和亚马逊发起的费用或赊欠款项。 有关更多信息，请参阅[付款追踪工具](https://sellercentral.amazon.com/gp/help/external/GFLRKM5TG3LHNCV8)。
- **日期范围报告**：为指定日期范围内的所有交易生成逐笔交易报告和汇总报告。有关更多信息，请参阅[日期范围报告](https://sellercentral.amazon.com/gp/help/external/G200989190)。
