# 口呼吸贴

如果您要在亚马逊商城发布商品，则必须遵守与这些商品和商品信息相关的所有适用法律、法规、标准以及亚马逊政策。

## 本政策适用的口呼吸贴

口呼吸贴是设计用于贴在口部（通常会覆盖上下唇）以防止在睡眠期间张嘴的任何胶带或胶条（无论是否带孔）。此类商品通常销售用于解决与睡眠相关的问题和障碍，或者在睡眠期间调节鼻腔呼吸。

## 设计和特征

| 设计类型 | 主要特征 |
| --- | --- |
| X 形或交叉方式 | 两个相交的胶条 在口部形成“X”或交叉符号 胶条末端的边可能为弧形或带角 |
| H 形和 I 形 | H 形： 两端垂直延长、中间水平的胶条 I 形： 顶部或底部水平延长、中间垂直的胶条 |
| 长方形或正方形 | 可覆盖口部的单块水平胶条 可能在中间有呼吸口、圆角或四边有弧度 |
| 蝴蝶形或嘴部轮廓 | 采用自然嘴唇形状的弯曲边缘 侧面的延长部分像翅膀 可能在中间有窄的呼吸口，或者带有装饰性的曲线 |
| 椭圆形或拉长的椭圆形 | 覆盖口部的椭圆形状 两端为对称的弧形 可能在中间有排气口或排气孔 |
| 其他设计 | 以上形状的组合 标准几何形状的改版 在保持基本的口部覆盖功能时带有装饰元素 自定义开口或排气方式 |
