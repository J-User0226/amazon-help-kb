# 商品分类提醒

亚马逊会对商品信息进行审核，以确保网站上的分类准确无误。此外，如果某商品信息未正确分类，我们会向您发送提醒。这些提醒旨在帮助您改进商品分类，提高商品曝光度。

如果商品信息缺少商品类型关键词或推荐分类节点属性，或者此商品信息分配到的分类过于宽泛，则会出现这种情况。例如，如果要发布一款数码单反相机，商品类型关键词必须为“dslr-camera-systems”，而不是“digital-cameras”，因为数码相机可能包含数码单反相机、拍立得相机和傻瓜相机。

要为您的商品确定正确的分类，请前往[商品分类工具](https://sellercentral.amazon.com/listing/download)。 **注意： **商品名称、要点和商品描述是用于商品分类的三个关键属性。确保这些属性中的信息质量高，这对于优化分类至关重要。修改分类后，搜索框分类将发生变化。此更改将在 24 至 72 小时内反映出来。

如果商品未发布在特定分类、商品类型关键词或推荐分类节点下，则会对这些商品的销量产生负面影响，因为买家很难通过搜索或浏览找到它们。

有关更多信息，请参阅[创建库存文件模板并对商品进行分类](https://sellercentral.amazon.com/gp/help/external/G200956770)。

## 修复您的商品信息
使用以下功能，发现并修复未正确分类的商品信息：

- 【卖家平台中的“管理库存”】
  1. 点击卖家平台中【库存】选项卡下方的【管理所有库存】。
  2. 点击受影响商品信息最后一列的【编辑】，点击【商品详情】选项卡，然后点击【商品类型关键词】或【推荐分类节点】字段对应的【编辑】。
  3. 选择正确的分类/浏览路径并保存。

- 【卖家平台中可下载的报告】
  1. 点击卖家平台中【库存】选项卡下方的【库存报告】。
  2. 选择“商品信息质量和禁止显示的商品信息报告”（新增）。通过[商品分类工具](https://sellercentral.amazon.com/listing/download)确定商品信息的最佳分类位置。
  3. 使用商品分类工具中的值更新库存文件或 XML 中的“商品类型关键词”或“推荐分类节点”单元格。
