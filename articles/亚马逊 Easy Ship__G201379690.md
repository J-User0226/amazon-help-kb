# 亚马逊 Easy Ship

亚马逊 Easy Ship 通过一站式捆绑解决方案，简化了卖家端到端的订单管理，其中包括快速准确的配送、与承运人的便捷协调安排以及亚马逊管理的客户服务，所有服务均以可预测的费率提供。

亚马逊 Easy Ship 是一项通过我们的物流服务商网络协助您配送订单的计划，可对您的业务和买家产生积极影响。当您使用亚马逊 Easy Ship 服务时，您只需负责商品的销售、包装以及货件标签的打印和粘贴工作，我们会负责将商品配送给买家，并确保配送全程可追踪、速度更快，同时为您在亚马逊店铺中的商品带来更高的曝光度等优势。

**计划优势**

亚马逊 Easy Ship 提供以下优势：

- 亚马逊负责配送，并向买家提供更准确的配送承诺。

- 更好地管控您的账户状况和绩效，获得买家正面评价的几率更高。

- 您无需协商承运人费率、管理配送流程、计算送达日期或上传追踪信息。亚马逊 Easy Ship 为卖家简化了订单配送流程。

- 自动更新订单的追踪信息。

- 使用亚马逊 Easy Ship 价目表，享受可预测且具有竞争力的配送费用，使您能够制定更准确的运营计划。

- 亚马逊自动接受和处理所有退货，并且免费打印预付费退货标签。作为亚马逊 Easy Ship 服务的一部分，我们会代您为买家提供预付费退货货件标签。有关更多信息，请参阅[卖家自配送订单的预付费退货](https://sellercentral.amazon.com/help/hub/reference/G202072200)。

- [Customer Service by Amazon (CSBA)](https://sellercentral.amazon.com/help/hub/reference/G65T4N3XGC3MJB38) 是亚马逊 Easy Ship 包含的一项功能，无需额外付费。亚马逊负责处理所有售后联系事宜，以便您专注于自己的业务策略。

**卖家和商品资格**

要获得亚马逊 Easy Ship 的资格，您必须满足以下要求：

- 注册成为 Amazon.com（美国商城）的卖家。

- 拥有该计划覆盖范围内的取件或投件地址。

亚马逊 Easy Ship 覆盖以下州：

- 美国本土所有州，不包括阿拉斯加和夏威夷。

商品限制

- 最大长度、宽度或高度： 30 英寸

- 最大重量： 50 磅

- 商品不能被归类为危险品。有关更多信息，请参阅[危险品政策](https://sellercentral.amazon.com/help/hub/reference/GN4SW35Y4KXHX8BT)。

**整合： 亚马逊 Easy Ship 的外部配送 API**

如果您使用集成商或企业资源规划 (ERP) 系统，则无需使用卖家平台，即可直接在该工具中处理订单。亚马逊 Easy Ship 订单配送由外部配送 API（属于 SP-API 套件）提供支持，并通过标准化订单处理流程完成：

- 确认订单

- 创建包裹

- 获取交接（取件或投件）时段

- 生成标签

有关更多信息，请参阅 [SmartConnect API： 外部配送货件 API](https://developer-docs.amazon.com/sp-api/docs/external-fulfillment-shipping)。

**费用**

亚马逊对通过亚马逊 Easy Ship 配送的所有订单按件收取费用。费用因商品价格、重量范围以及货件的起运州而异。

与美国其他配送承运人的费率相比，我们的费用具有竞争力。有关更多信息，请参阅[亚马逊 Easy Ship 费用](https://sellercentral.amazon.com/help/hub/reference/G201439100)。

## 常见问题

#### 1. 如何注册亚马逊 Easy Ship 计划？

请参阅[注册亚马逊 Easy Ship](https://sellercentral.amazon.com/help/hub/reference/G201382100)，然后按照步骤操作。

#### 2. 如何确认我已加入亚马逊 Easy Ship？

完成最后一步注册后，您将自动加入亚马逊 Easy Ship。确认方式：转至**设置** > **配送设置**。如果您能看到 **亚马逊 Easy Ship** 选项卡，则表示您已注册。

#### 3.我需要将商品注册进该计划吗？

不需要。注册完成后，所有符合条件的商品都将通过亚马逊 Easy Ship 配送。

#### 4. 注册后收到了第一个订单，该如何操作？

前往[如何处理亚马逊 Easy Ship 订单](https://sellercentral.amazon.com/help/hub/reference/G201383340)，然后按照步骤操作。

#### 5. 我可以同时注册并参与亚马逊 Easy Ship 和亚马逊物流吗？

可以。注册其中一个配送计划并不会妨碍您注册另外一个计划。

#### 6. 费用是按商品收取还是按订单收取？

亚马逊 Easy Ship 的费用按每件已配送的商品收取。

#### 7. 如何知道我的包裹是需要上门取件，还是需要自行投件至承运人投件中心？

如果您是投件卖家，则您的所有订单均将在[管理订单](https://sellercentral.amazon.com/orders-v3/mfn/shipped/easyship/handover-ready?page=1)页面的**已发送**选项卡中显示为**等待投件**状态。

#### 8.投件站在哪里？

在投递订单包裹之前，请先转至[亚马逊 Easy Ship 投件交接方式](https://sellercentral.amazon.com/help/hub/reference/GP59NXPDDD8484UV)。

#### 9. 与亚马逊 Easy Ship 相关的绩效政策有哪些？

您能否继续使用亚马逊 Easy Ship，取决于您的卖家账户是否遵守在亚马逊商城销售所需的绩效目标和政策。这些政策与所有卖家自配送订单的政策一致。

要查看您的整体账户状况，请前往[账户状况评级](https://sellercentral.amazon.com/help/hub/reference/GR786P4BPEVKTBAG)。

有关账户状况页面上客户服务和配送绩效要求的更多信息，请转至[订单绩效计划政策](https://sellercentral.amazon.com/help/hub/reference/GGJVNFDXQT8C3RA8)。
