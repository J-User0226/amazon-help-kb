# 多渠道分拨费用

多渠道分拨订单会产生亚马逊智能卫星仓仓储费和处理费，因为储存在亚马逊智能卫星仓的库存可用于向我们的配送网络或您的其他销售渠道（亚马逊以外）补货。对于非亚马逊补货订单，亚马逊将会收取多渠道分拨运输费。

自 2026 年 1 月 15 日起，我们将调整多渠道分拨运输费用。要查看仓储费和处理费，请参阅[亚马逊智能卫星仓费用](https://sellercentral.amazon.com/gp/help/external/GAYG62Q3MPE6STFS)。

亚马逊会基于距离，根据发货重量和您选择的运送方式来确定多渠道分拨出库运输费。

在创建补货订单时，您可以选择托拍装载和箱子装载（通常称为小包裹快递），将货件运送至您的亚马逊站外分拨渠道。对于托拍装载选项，多个箱子将被装载至一个托拍中进行运送；而对于小包裹快递，将会直接运送箱子。

## 确定发货重量

发货重量（小数点后保留一位）取决于箱子或托拍的实际重量或体积重量中的较大值。每个箱子（小包裹快递）的体积重量等于长 x 宽 x 高（单位：英寸）除以 139。对于托拍，其体积重量等于长 x 宽 x 高（单位：英寸）除以 250。

## 发货重量示例

**箱子装载（实际重量大于体积重量）**

尺寸： 6.3 x 6.2 x 4.8 英寸

箱子重量： 13 磅

体积重量： 1.3 磅

发货重量 = 13 磅

**托拍装载（实际重量小于体积重量）**

尺寸： 48 x 40 x 42 英寸

托拍重量： 250 磅

体积重量： 322.6 磅

发货重量 = 322.6 磅
