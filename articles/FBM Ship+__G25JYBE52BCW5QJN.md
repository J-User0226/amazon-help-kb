# FBM Ship+

## 什么是 FBM Ship+？

FBM Ship+ 是适用于自配送订单卖家的一种配送解决方案，旨在通过向买家显示准确且较早的送达日期，从而提高您的销售额，同时通过较大运费折扣，让配送服务实现提速降费。此外，您的准时送达率将免受延迟送达*的影响；对于与配送相关的亚马逊商城交易保障索赔，您可获得退款。

**注意： **FBM Ship+ 目前适用于从中国发往英国、 德国、 意大利、 西班牙、 法国、 日本和澳大利亚的货件。该计划目前作为试点面向选定的中国至美国卖家，以及美国、英国和德国的选定国内卖家提供。我们会随着时间的推移向更多商城推出 FBM Ship+。

（*****我们设计了这款工具来设置准确的送达日期，减少延迟送达，并达到或超过最低的准时送达率要求；由于亚马逊代表您完成这些计算且计算结果会影响准时送达率，因此如果您的商品已注册加入 FBM Ship+，并且您使用亚马逊购买配送服务购买了带有“准时送达率保护”标记的货件标签，则按时发货的商品的准时送达率将会免受延迟送达的影响。）

## 开始使用

前往 [FBM Ship+](https://sellercentral.amazon.com/fbm/ship+) 页面，或导航至“配送设置”页面，然后向下滚动至【配送计划】部分。找到 FBM Ship+ 计划，然后点击【开始】。

要注册，请前往 [FBM Ship+](https://sellercentral.amazon.com/fbm/ship+) 页面，然后点击【注册 FBM Ship+】。系统将跳转至[注册 FBM Ship+](https://sellercentral.amazon.com/fbm/ship+) 页面。

点击注册后，系统将默认自动选择您的所有配送模板进行注册，但您可以删除任何不想注册的配送模板。您可以随时在[编辑模板选择](https://sellercentral.amazon.com/fbm/ship+)页面上选择要加入 FBM Ship+ 或要从该计划移除的模板。完成选择后，点击【保存】。

## FBM Ship+ 如何运作？

- **设置准确且较早的送达日期：** 在您注册 FBM Ship+ 后，亚马逊会将最长备货时间设为两个工作日，并根据与 FBM Ship+ 合作的加急配送服务同步设定较早的送达日期。对于您以往在收到订单当日便发货的 SKU，我们会将您在截止时间（可编辑）之前收到的所有订单的备货时间设置为当日。对于您以往备货时间长于当日的任何 SKU，我们会将其最长备货时间设置为 2 个工作日。

**注意： **您的 FBM Ship+ SKU 不会受到新推出的备货时间要求的影响。在[此处](https://sellercentral.amazon.com/help/hub/reference/G200955560)了解更多信息。

- **通过亚马逊购买配送服务购买货件标签：** 您可以通过亚马逊购买配送服务购买 FBM Ship+ 折扣货件标签，具体购买方式由您选择，如卖家平台的“管理订单”页面、我们的配送 API 或多渠道集成商和 ERP 合作伙伴。在亚马逊购买配送服务中，您将能够看到合作承运人提供的折扣运费，。有关更多信息，请参阅[如何通过亚马逊购买配送服务购买 FBM Ship+ 货件标签](https://sellercentral.amazon.com/help/hub/reference/GEDHSSQX2YBZ97RP)。

- **准时发货并享受 Ship+ 优惠：** 在预计发货日期当日或之前将包裹交给合作承运人，并享受 FBM Ship+ 权益。

## 常见问题

#### 如何在 FBM Ship+ 中添加或移除配送模板？

在 [FBM Ship+ 注册页面](https://sellercentral.amazon.com/fbm/ship+)，您可以找到所有预先选定的符合要求的配送模板列表。这些模板可以加入 FBM Ship+。点击【编辑选择】，可以从此列表中选择模板。

您还可以在注册后修改或移除所选模板。从 [FBM Ship+](https://sellercentral.amazon.com/fbm/ship+) 落地页，导航至【编辑 FBM Ship+ 首选项】。在[编辑模板选择](https://sellercentral.amazon.com/fbm/ship+)页面，您可以更新要加入 FBM Ship+ 或要从中移除的模板。请务必点击【保存】以确认您的更改。

#### 如何在“管理订单”页面上识别 FBM Ship+ 订单？

前往[管理订单](https://sellercentral.amazon.com/orders-v3/ref=xx_myo_dnav_xx?page=1)页面，在【订单详情】列下找到相关特定订单。在【用于计算配送承诺的配送服务】部分，查找 【FBM Ship+】 标记以识别 FBM Ship+ 订单。

您也可以点击【订单内容】下的【购买配送】，如果是 FBM Ship+ 订单，则会显示 【FBM Ship+】 标记。

此外，您可以从卖家平台的【订单报告】选项卡或者通过报告 API 来下载【卖家自配送订单】报告，启用“亚马逊计划”列，然后按 【FBM Ship+】 筛选。

#### 如何访问和使用亚马逊购买配送服务来购买 FBM Ship+ 标签？

您可以通过三种方式访问亚马逊购买配送服务：

- **在卖家平台上**： 在[管理订单](https://sellercentral.amazon.com/orders-v3/ref=xx_myo_dnav_xx?page=1)页面上，您可以从列表视图或订单详情页面购买“购买配送服务”标签。在您的卖家账户中，前往【订单】，选择【管理订单】，然后针对要发货的 FBM Ship+ 订单，点击【购买配送】。您还可以前往【管理订单】页面，在【订单详情】列下找到特定订单。在【用于计算配送承诺的配送服务】部分，查找 FBM Ship+ 标记以识别 FBM Ship+ 订单。然后，点击【订单内容】下的【购买配送】，通过亚马逊购买配送服务从 FBM Ship+ 合作承运人（例如，对于从中国发货的卖家，可以选择云途物流）处购买货件标签。符合 FBM Ship+ 要求的标签将显示 FBM Ship+ 标记[请点击此处了解更多信息](https://sellercentral.amazon.com/gp/help/external/GEDHSSQX2YBZ97RP)。

- **使用合作多渠道集成商 (MCI) 或 ERP**： 将您的亚马逊店铺与我们的某个首选合作多渠道集成商或 ERP 关联。关联后，系统将自动为您的订单启用亚马逊购买配送服务。接下来，前往 ERP 中的【管理订单】部分，找到带有 FBM Ship+ 标记的订单。要享受 FBM Ship+ 的权益，请通过亚马逊购买配送服务购买 FBM Ship+ 合作承运人的配送服务标签，例如，对于从中国发货的卖家，可以选择云途物流。首选合作 ERP 可能会在自己的用户界面上，通过显示 FBM Ship+ 横幅来注明这些配送服务。

- **使用您连接到我们的 API 的自有软件：** 如果您使用自有软件，则 FBM Ship+ 需要使用通知 API（选用，但建议使用）、订单 API 和购买配送服务 API。使用通知 API (ORDER_CHANGE)，您可以订阅通知，系统会在订单状态发生变化（例如订单更改或取消）时通知您。使用订单 API 可确定符合 FBM Ship+ 要求的订单。要使用购买配送服务 API 享受 FBM Ship+ 的优惠，请购买 FBM Ship+ 合作承运人的配送服务标签，例如，对于从中国发货的卖家，可以选择云途物流。对于 FBM Ship+ 推荐的配送方式，购买配送服务 API 同样会传递 【FBM_SHIP_PLUS】 标记。 要了解更多信息，请参阅[如何通过亚马逊购买配送服务购买 FBM Ship+ 货件标签](https://sellercentral.amazon.com/gp/help/external/GEDHSSQX2YBZ97RP)。

#### 我可以在亚马逊购买配送服务之外为我的 FBM Ship+ 订单确认发货吗？

您无法使用确认发货 API、上传数据上传或通过卖家平台中的“管理订单”页面为 FBM Ship+ 订单批量确认发货。

**注意： **如果您因技术问题无法通过亚马逊购买配送服务为 FBM Ship+ 订单购买货件标签，您仍可以通过卖家平台的“管理订单”页面[为每个 FBM Ship+ 订单分别确认发货](https://sellercentral.amazon.com/gp/help/help.html?itemID=/gp/help/hub/reference/G200197960)。

对于从中国发货的 FBM Ship+ 订单，要享受 FBM Ship+ 折扣率并获得账户保护权益，您必须通过亚马逊购买配送服务从列出的 Ship+ 支持的承运人（目前为“云途物流”）处购买货件标签，该承运人将自动为您确认发货。我们建议您通过亚马逊购买配送服务使用 FBM Ship+ 云途物流专线（一般货件或电池货件）配送方式，确保较高的准时送达率。

您可以通过以下方式通过[亚马逊购买配送服务](https://sellercentral.amazon.com/gp/help/help.html?itemID=/gp/help/hub/reference/GEDHSSQX2YBZ97RP)购买货件标签：

- 在卖家平台中，点击订单旁边的“购买配送”，即可跳转至“管理订单”页面。

- 与亚马逊购买配送服务集成的[多渠道集成商/企业资源规划系统 (ERP) 合作伙伴](https://sellercentral.amazon.com/gp/help/help.html?itemID=/gp/help/hub/reference/G201950090)

- 将您的软件连接到我们的[卖家合作伙伴 API](https://developer-docs.shipping.amazon.com/apis/docs/tutorial-integrate-fbm-ship-with-erps-and-multi-channel-integrators)

#### 在哪里可以查看我的订单适用的 FBM Ship+ 备货时间和运输时间？

有关针对 SKU 的备货时间，请在卖家平台上前往【库存】，然后导航至[管理卖家自配送商品](https://www.sellercentral.amazon.dev/seller-fulfilled-product/analytics/ref=xx_msfp_dnav_xx)，然后选择【针对商品的配送首选项】。

有关订单级别的备货时间和运输时间，请在卖家平台上前往【订单】，选择[订单报告](https://sellercentral.amazon.com/order-reports-and-feeds/reports/ref=xx_orderrpt_dnav_xx)，然后请求并下载 【FBM 订单报告】。您还可以通过订单报告 API 访问此数据。

**注意： **【商品级配送首选项】页面上的 SKU 级别备货时间反映了卖家配置的设置或自动备货时间。但是，【订单报告】会显示预计发货日期，此日期会考虑假日季、计划要求 (PSO/Ship+)、订单截止时间和订单处理容量，因此两者可能不一致。

#### 我能否对优先配送订单、卖家自配送 Prime 订单、加急订单或免费经济型订单使用 FBM Ship+？

FBM Ship+ 仅适用于通过标准配送方式配送的商品。通过其他配送选项（如免费经济型配送、标准 Prime 配送或优先配送）配送的商品目前不符合 FBM Ship+ 的要求。
