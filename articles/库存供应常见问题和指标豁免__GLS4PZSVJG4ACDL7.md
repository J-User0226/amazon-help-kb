# 库存供应常见问题和指标豁免

**常见问题：**

1. 如何确定首先操作哪些 SKU？ 亚马逊是针对所有 SKU 还是仅针对价值最高的 SKU 提供建议？
2. 您必须根据最佳判断来确定要首先操作哪些 SKU。我们建议您在做出这一决定时考虑几个因素，包括首先解决在 ASB 计划通信中确定的品牌，然后优先操作销量最高的 SKU。在上述假设中，SKU UBC10212155 的销量最高，因此您可以考虑优先对其执行操作。

3. 如何查看 SKU 的历史供货天数指标？
4. 要查看您的历史供货天数，请参阅[亚马逊物流库存](https://www.sellercentral.amazon.dev/inventoryplanning/manageinventoryhealth)，定期监控您的历史供货天数，并根据需要采取建议的操作。

5. 在计算库存供应时是否考虑卖家自配送库存？
6. 不会。库存供应指标仅会考虑储存在亚马逊物流网络中的亚马逊物流库存。

【指标豁免：】 **注意： **我们在计算您的绩效时会排除满足以下任何豁免条件的 ASIN。

1. [非标准尺寸商品](https://sellercentral.amazon.com/gp/help/external/GG5KW835AHDJCH8W)
2. 通过亚马逊仓储和分拨服务自动补货的商品。
3. 在过去 7 天内售出商品少于 20 件的商品。
4. [亚马逊物流评级重售计划商品](https://sellercentral.amazon.com/gp/help/external/GUA6RV6UA4DR2MFK)： 买家退回（亚马逊物流卖家的）商品，经确定符合转售要求的商品需要经过评级流程，如果通过，我们将为其重新分配新的 MSKU 和 FNSKU。
5. [翻新商品](https://sellercentral.amazon.com/gp/help/external/G201648580)
6. [易融商品](https://sellercentral.amazon.com/gp/help/external/G202125070)
