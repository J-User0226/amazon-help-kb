# 授权服务提供商访问您的账户

授权服务提供商访问您的卖家平台账户，以便他们可以代您管理相关服务。

## 什么是服务提供商？

服务提供商是指您授权其访问您的卖家平台账户的所有外部第三方，包括代理机构、顾问、外部承包商，或者在亚马逊的[解决方案提供商门户 (SPP)](https://solutionproviderportal.amazon.com/home) 中注册并提供服务以帮助您管理亚马逊业务（例如广告管理、账户优化或配送支持）的任何其他企业。

## 服务提供商访问权限与员工访问权限

如果您想授予他人访问您账户的权限，正确的方式取决于其是您组织的外部人员还是内部人员。

| | 服务提供商访问权限 | 员工访问权限 |
| --- | --- | --- |
| 谁 | 您组织外部的任何人（代理机构、承包商、顾问、第三方服务企业） | 您自己的员工或团队成员（您组织内部的任何人） |
| 如何 | 通过链接或服务提供商网络 (SPN) 获得授权；访问权限仅限于预先批准的角色 | 直接在管理员工中添加；您分配具体角色 |
| 时长 | 365 天（到期前需重新授权） | 无到期日（访问权限持续有效，直到您将其移除） |
| 何处管理 | 管理服务 | 管理员工 |

本页面介绍的是服务提供商访问权限。如要添加员工或内部团队成员，请前往[设置和编辑用户权限](https://sellercentral.amazon.com/help/set-edit-user-permissions)。

## 授权如何运作

当您授权服务提供商，即表示您授予其在 365 天内访问您的卖家平台账户中特定角色的权限。您可以控制他们能够访问哪些角色，并可按国家/地区限制其访问权限。

## 何时授权服务提供商

您需要在以下情况下授权服务提供商：

- 您首次授予服务提供商访问您账户的权限。

- 服务提供商此前的授权已到期（365 天后）。

- 您此前移除了服务提供商的访问权限，现在想要恢复。

**注意： **如果服务提供商的访问权限仍然有效且即将到期，您可以改为重新授权。了解更多信息，请参阅[对服务提供商的账户访问权限进行重新授权](https://sellercentral.amazon.com/help/hub/reference/G3782ZCL2U67NSTB)。

## 授权之前

在授权服务提供商之前，您必须满足以下条件：

- 您必须拥有有效的卖家平台账户。

- 您必须是账户所有者或账户管理员。

- 服务提供商必须已在解决方案提供商门户中完成注册。

- 服务提供商必须已完成角色选择并拥有已批准的角色。

## 如何授权服务提供商

您可以通过以下任一入口开始授权流程：

- **授权链接：** 服务提供商会向您提供一个唯一的授权链接。前往该链接开始操作。

- **服务提供商网络：** 前往该服务提供商在服务提供商网络中的商品信息页面，然后选择【立即授权】。

无论您通过哪一方式开始，请按照以下步骤完成授权：

- 通过上述任一入口前往授权页面。

- 根据服务提供商的服务分类，查看其已获得批准的角色。

- （可选）在确认之前调整个别角色或限制相应访问权限。

- （可选）使用【国家/地区筛选条件】按地理位置限定访问权限范围。

- 选择【授权服务提供商】，授予服务提供商 365 天的访问权限。

**注意： **如果服务提供商已在服务提供商网络中列出，系统会在您确认后创建一个服务请求。服务提供商必须接受该请求才能激活授权。

## 授权后

在您授权服务提供商后：

- 服务提供商可在 365 天内访问您确认的角色。

- 您可以随时在[管理服务](https://sellercentral.amazon.com/apps/authorize/global/manage)页面查看或移除其访问权限。

- 在 365 天的期限结束前，您可以重新授权其访问权限以避免服务中断。了解更多信息，请参阅[对服务提供商的账户访问权限进行重新授权](https://sellercentral.amazon.com/help/hub/reference/G3782ZCL2U67NSTB)。
