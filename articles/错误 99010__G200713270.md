# 错误 99010

## 错误 99010

这一组的一个或多个必填列缺少值。

如果其中一个条件性必填列的值缺少或相互冲突，则会出现此错误。例如，如果您要为促销添加折扣价格，则促销开始日期、结束日期和促销价格便成为必填项。如果缺少这其中的任何一个属性，便会出现此错误。错误消息内容如下：

该组的一个或多个必填列缺少值：[Sale Price = null]，[Sale Start Date = "2021-05-26"]，[Sale End Date = "2022-05-26"]。

**注意： **促销开始日期应早于促销结束日期。

| --- | --- | --- | --- |
| 99010 | 该组的一个或多个必填列缺少值：[Sale Price = "A_GEN_SUPERREDUCED"]，[Sale Start Date = null]，[Sale End Date = null]。 | Sale Price (FN)、Sale Start Date (FO)、Sale End Date (FP) | 336 |
| | | 错误总数 | 336 |

*错误报告中的示例错误表。*

要解决此问题，请确保条件性必填组的所有属性都填写了有效值。要避免此错误，请在上传特定分类库存模板文件之前检查 Data Definition 和 Valid Values 选项卡。

条件性必填字段的一些示例包括：

- 如果已填写 Sale Price 属性，则要填写 Sale_start_date 和 Sale_end_date。

- 如果填写了 Sale Price 以及 Sale_start_date 和 Sale_end_date，但您的日期格式不正确（即未采用 YYYY-MM-DD 或 DD-MM-YYYY 的格式），那么您将收到错误消息。

- 如果填写了 Product_id，那么请确保同时填写了 Product_id_type。

- 如果填写了 Parentage，那么请务必填写 Variation Theme。
