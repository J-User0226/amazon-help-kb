# 准时送达率缺陷报告

准时送达率缺陷报告会列出在送达日期（无承诺延期）之后送达的订单。您可以在[账户状况控制面板](https://sellercentral.amazon.com/performance/dashboard?ref=ah_em%20_op)上查看准时送达率（无承诺延期）指标。

## 如何查看准时送达率指标和报告

要在卖家平台上查看您的准时送达率指标和报告，请按照以下步骤操作：

- 前往【绩效】菜单，然后选择[账户状况](https://sellercentral.amazon.com/performance/dashboard)。

- 找到“配送绩效”部分，然后选择【准时送达率】。

- 您可以在“配送绩效”页面查看[准时送达率指标](https://sellercentral.amazon.com/performance/detail/shipping?t=otd&ref=sp_st_dash_csp_otd)。只有包含在当前准时送达率缺陷报告中的订单才会计入准时送达率指标。如果报告中不含任何订单，则表示这些订单中的商品已准时送达，或使用了亚马逊的免费配送工具进行配送。

- 要下载准时送达率缺陷报告，请点击【查看详情】，然后点击【下载报告】。

## **如何阅读准时送达率缺陷报告**

在分析准时送达率缺陷报告时，请密切关注以下字段：

- 订单编号

- 商品数量

- 承诺送达日期（有承诺延期）

- 实际送达日期

如果您关注这些要素，就能更高效地查看报告，从而更好地评估您的绩效和交付承诺。

以下部分提供了报告内各列的标题和详细描述：

【订单编号】

订单编号是分配给特定买家订单或交易的唯一标识。在缺陷报告中，您可能会看到同一订单编号出现多次。这种重复情况是因为订单可能包含多个 SKU。

【SKU 和商品数量】

商品数量字段显示了计算准时送达率时考虑的指定 SKU 的商品数量。此指标会直接影响您的绩效评估。

【订单日期】

此字段显示买家下单的确切时间。这是计算配送时间段和评估准时绩效的关键参考点。订单时间在主显示位中显示为格林尼治标准时间 (GMT)，在辅显示位的括号中显示为太平洋时间（PDT 或 PST）。

【承诺发货日期】

此字段表示订单发货的截止日期。它将在订单详情页面上醒目地显示为“发货日期”，并且是配送运营的关键绩效指标。订单时间在主显示位中显示为格林尼治标准时间 (GMT)，在辅显示位的括号中显示为太平洋时间（PDT 或 PST）。遵循此截止日期对于确保客户满意度并维持较高的卖家绩效指标至关重要。请将此日期作为库存管理、劳动力分配和配送安排的核心参考点。

【发货确认日期】

此时间戳代表了必须在卖家平台或通过 API 确认订单发货的精确时间，以便满足您的内部处理要求并保持最佳运营效率。此日期和时间是配送流程的重要检查点，标志着从内部处理到外部配送的转变。

【承运人首次扫描日期】

此时间戳表示承运人的追踪系统首次注册包裹的时间，标志着包裹开始通过物流网络进行运输。此日期通常会触发系统首次自动向买家更新配送信息，帮助买家确定对交付时间的预期。

【承诺送达日期（无承诺延期）】

此字段表示根据您配置的处理时间和运输时间设置，加上任何其他非运营天数，计算得出的送达日期。如果添加了任何承诺延期，买家可能会看到更晚的送达日期。它作为评估配送绩效和客户满意度的重要基准。该日期与订单详情页面上显示的“送达日期”一致，除非已应用承诺延期，该日期会影响买家的预期。

【承诺送达日期（有承诺延期）】

此日期反映了对初始配送承诺的实时修改，以反映不可预见的情况，例如恶劣的天气状况或物流网络限制。承诺延期允许在不损害买家信任的情况下进行必要的调整。它可让您深入了解买家对配送的预期。

【实际送达日期】

此时间戳代表承运人首次尝试将包裹交付给买家的日期。这是评估配送效率和客户满意度的一项关键绩效指标。实际送达日期基于承运人首次尝试妥投的官方记录，以便获取准确且一致的报告。此日期通常会触发系统向买家发送最终送达通知。

【在承诺送达日期（无承诺延期）之后送达】

此字段确认包裹在初始送达日期之后送达，且无承诺延期。

【在承诺送达日期（有承诺延期）之后送达】

此字段显示包裹是在向买家承诺的包裹送达日期之后送达的。应优先审核这些订单，因为它们会对您的卖家指标和买家信任产生严重的负面影响。

【承运人名称】

此字段用于标识在最后阶段负责向买家配送包裹的物流提供商或运输公司。它可帮助确定配送问题的模式，并追踪不同承运人的绩效。

【配送方式】

此字段显示了为将订单从您的所在地运输至买家而选择的特定配送服务或配送选项。配送方式通常根据速度、成本和包裹特征等因素进行选择，并会影响配送时间、买家期望和整体订单盈利能力

【追踪编码】

此字段显示承运人为每个包裹分配的唯一字母数字编码，可实时追踪包裹从发件人到收件人的运输过程。

有关追踪编码重要性的更多信息，请参阅[有效追踪率 (VTR)](https://sellercentral.amazon.com/gp/help/external/G201817070)。

【发货国家/地区】

此字段显示商品的发货国家/地区，代表包裹配送至买家这个过程的起点。发货国家/地区对于了解配送时间表和配送网络延迟至关重要。

## 缺陷报告常见问题

## 为什么同一订单会在报告中显示多次？

如果某个订单包含多个不同的 SKU，则这个订单就会显示多次。每个 SKU 均单独列出，以提供延迟交付商品的详细信息。此格式可让您更准确地评估准时送达率，因为影响此指标的是单个商品，而不仅仅是订单。

## 为什么不符合要求的已发货商品数量与报告中的订单数量不匹配？

如果某些订单包含同一 SKU 的多件商品，就会出现这种情况。商品总数量，而非订单数量，是影响准时送达率的主要因素。例如，一个订单可能包含某个特定 SKU 的三件商品，如果该订单延迟送达，则这些商品将计为 3 件不符合要的商品。

## 如果缺陷报告中显示为延迟送达的订单实际已按时送达，我该怎么做？

请按照以下步骤操作：

- 确认您查看报告时，时区设置正确。

- 检查是否应用了任何承诺延期，并且交付时间是否仍超出了此延长后的时间范围。

- 如果您仍然认为订单被错误标记为延迟，请收集所有相关配送证据。

- 请联系[销售伙伴支持](https://sellercentral.amazon.com/help/center?redirectSource=Hill)寻求帮助。向他们提供订单详情和订单已准时送达的证明。

**注意： **亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。

## 报告如何处理包含多个 SKU，其中一部分商品准时送达的订单？

该报告会分别处理订单中的每个 SKU。如果多 SKU 订单中某些 SKU 准时送达，而其他 SKU 延迟送达，那么只有延迟送达的 SKU 才会计入准时送达率计算。
