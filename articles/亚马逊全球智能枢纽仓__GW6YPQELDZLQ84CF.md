# 亚马逊全球智能枢纽仓

亚马逊全球智能枢纽仓计划提供制造地低成本仓储、整合的亚马逊全球物流跨境运费，以及面向满足 Prime 要求的运营中心的补货服务。

要使用亚马逊全球智能枢纽仓计划，您必须加入亚马逊全球物流计划以便进行跨境运输。完成注册后，您可以前往[亚马逊智能卫星仓](https://sellercentral.amazon.com/asdn/about/ref=xx_asdn_dnav_xx)并创建货件。

此服务受[亚马逊智能卫星仓政策](https://sellercentral.amazon.com/help/hub/reference/external/GHV89YC29VWN6SBM)和[亚马逊全球物流货运条款](https://sellercentral.amazon.com/help/hub/reference/G5N72FX7B37YJ3AT)的约束。

观看以下视频，详细了解 GWD。

## 开始使用
要开始使用亚马逊全球智能枢纽仓，请按照以下步骤操作：

1. 对于[美国](https://sellercentral.amazon.com/gssportal/index.html)目的地，如果您之前未使用亚马逊全球物流服务，请加入亚马逊全球物流计划。
2. 点击【设置资料】，选择您的[付款方式](https://sellercentral.amazon.com/gp/help/external/GZJ4B4HXDUEWP4PC)并设置[备案进口商](https://sellercentral.amazon.com/gp/help/external/GASFW4BD897LNTNN)。有关更多详情，请参阅[亚马逊全球物流](https://sellercentral.amazon.com/help/hub/reference/G202187670)。
3. 在卖家平台中，前往[亚马逊智能卫星仓计划页面](https://sellercentral.amazon.com/asdn/about)。或者，您可以前往【库存】下拉菜单，然后选择【亚马逊智能卫星仓 (AWD)】。
4. 在此页面上，点击【创建货件】。

## 向用户授予访问权限
只有有权使用该计划的用户才能看到“仓储和分拨服务”工具。如果您没有所需的权限，那么您账户的主账户持有人可以通过[用户权限](https://sellercentral.amazon.com/gp/account-manager/home.html/)页面向您授予权限。如果您已经为 AWD 设置了权限，则无需为我们的亚马逊全球智能枢纽仓计划设置额外权限。

主账户用户可以通过以下步骤授予访问权限：

1. 选择[用户权限](https://sellercentral.amazon.com/account/permissions)。
2. 添加新用户或选择现有用户。
3. 在【库存】下，前往【亚马逊智能卫星仓 - 次级用户权限】，然后选择以下权限级别之一：
  - 【无】： 这类用户无权访问库存信息。
  - 【仅查看】： 这类用户仅可查看库存信息。
  - 【查看和编辑】： 这类用户可以对库存进行操作。

4. 如果您还想授予“亚马逊仓储和分拨库存”页面的访问权限，请为【全球亚马逊物流库存】行选择相关选项。
5. 要授予使用亚马逊仓储和分拨库存分类账报告的权限，请在【报告】部分下授予使用【全球亚马逊物流库存】的权限。
6. 点击【保存更改】。
