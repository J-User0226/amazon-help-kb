# SKU 成本

SKU 成本卡显示了您的 SKU 随时间产生的成本。对于每种费用类型，您可以查看您的费用情况以及任何其他信息。

**注意： **目前，费用卡并未包含所有费用。但这些费用代表了普通卖家需支付的最常见费用。如需查看其他费用和功能，请留言告知我们。

**注意： ** SKU 成本报告以报告格式提供了与 SKU 成本中相同的汇总历史数据。可按照 [SKU 成本报告](https://sellercentral.amazon.com/sereport)中的步骤访问此数据，也可以转至 [SKU 成本报告帮助](https://sellercentral.amazon.com/gp/help/external/GZ8Y22NL2FSRY8M5)页面了解更多信息。

关键定义：

| 字段名 | 定义 |
| --- | --- |
| 亚马逊收取的总费用 | 在所选时间范围内，每种费用类型收取的费用总和。 |
| 亚马逊物流配送费用 | 亚马逊物流配送费用按件收取。费率取决于商品分类、尺寸分段和发货重量。 |
| 月度仓储费 | 月度仓储费取决于您的库存在亚马逊运营中心的平均每日占用体积1。 费用取决于商品分类、尺寸分段和一年中的仓储时间段。该费用每月收取。 |
| 低库存水平费用 | 低库存水平费用按件收取。该费用取决于历史供货天数。历史供货天数等于日均可售现货库存商品数量与日均发货商品数量之比。有关价目表以及此费用的相关信息，请参阅低库存水平费用。 |
| 销售佣金 | 销售佣金按售出商品件数收取。具体金额取决于商品分类。该费用根据总销售价格计算，总销售价格等于买家支付的总金额，其中包括商品价格以及任何配送费用或礼品包装费。 |
| 长期仓储费 | 对于在运营中心超期存放的库存，除了月度仓储费外，亚马逊还将收取月度长期仓储费作为附加费。亚马逊会在每月 15 日使用库存快照评估长期仓储费。有关更多信息，请参阅长期仓储费。 |
| 亚马逊物流入库配置服务费 | 对标准尺寸和大号大件商品收取的亚马逊物流入库配置服务费体现了向距离买家较近的运营中心分拨库存的成本。有关更多信息，请参阅亚马逊物流入库配置服务费。 |
| 商品推广费用 | 亚马逊商品推广是一种按点击付费的广告解决方案，通过使用可在亚马逊网站各个醒目位置展示的广告，对您的商品进行推广。 |
| 入库运输费用 | 使用亚马逊合作承运人将库存发往运营中心时，该费用将作为“入库运输费用”计入您的账户。计费重量用于估算运费。计费重量为体积重量或货件重量（以较大值为准）。体积重量是根据商品的当前尺寸估算得出的。 |
| 按件收取的销售费用 | 订阅个人销售计划的卖家需要为在亚马逊商城售出的每件商品额外支付一笔费用，同时还需支付任何其他适用费用。 |
| 交易手续费 | 以下分类中每件售出的商品均需支付交易手续费： 图书、DVD、音乐、软件和电脑/视频游戏、视频游戏机以及视频游戏配件。 |
| 移除费用 | 移除费用是从亚马逊运营中心移除商品时，按件收取的费用。 |
| 弃置费用 | 弃置费用是在您请求我们从亚马逊运营中心弃置商品时，按件收取的费用。 |
| 退款管理费用 | 如果您为已收到付款的买家订单退款，亚马逊会将您为订单商品支付的销售佣金减去适用的退款管理费用后的金额退还给您。 |
| 亚马逊物流预处理服务费 | 如果您使用亚马逊物流预处理服务，亚马逊将对符合要求的商品进行预处理，并按件收取费用。亚马逊将对其提供了贴标、聚乙烯塑料袋包装、气泡膜包装、不透明聚乙烯塑料袋包装或封装服务的商品收取此费用。 |

1如果多个 MSKU 与同一 FNSKU 相关联，则为所有 MSKU 显示的仓储费值均相同。

**注意： **2024 年 5 月 1 日之前，SKU 成本、SKU 成本报告及其净收入计算不包括亚马逊物流入库配置服务费用。

**注意： **某些司法辖区可能会要求亚马逊对上述费用收取税费。我们将使用您在卖家账户中提供的信息来确定某项费用是否应纳税，以及应收取的相应增值税、商品及服务税、销售税或其他税费税额。税务规则和法规因特定司法辖区而异。可在卖家平台帮助中心搜索增值税、商品及服务税、销售税或您所在国家/地区名称，了解更多信息。含税费用将与计算好的税费一并显示在亚马逊费用卡上。要了解哪些费用含税，请参阅您所在地区的[亚马逊服务商业解决方案协议](https://sellercentral.amazon.com/gp/help/external/1791)。
