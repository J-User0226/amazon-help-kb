# 错误 18477

## 错误消息
无法为指定 SKU (${targetSku}) 存储您提供的信息。多个商品共享同一 SKU 编码。要解决此错误，请执行以下操作：(i) 验证您是否提交了相同的商品。如果是，您必须删除其中一个提供的信息并重新提交（或）(ii) 如果其中一个提供的信息针对的是其他商品，请将 GTIN 更改为正确的值或创建唯一的 SKU，然后重新提交。

## 导致错误 18477 的原因
出现此错误的原因如下：
- 使用同一 SKU（库存单位）编码创建或提交多个商品信息，导致目录系统发生冲突，因为每个 SKU 在卖家账户中必须是唯一的。（例如，红色 T 恤衫和蓝色 T 恤衫都使用 SKU“TSHIRT-001”，而不是“TSHIRT-RED-001”和“TSHIRT-BLUE-001”等唯一标识）。
- 如果通过批量上传文件、单独创建商品信息或 API 集成等不同方法意外上传或创建了同一商品多次，从而导致生成了多个目录信息，则会出现重复的商品提交。
- SKU 编码被重复用于不同商品，且未正确删除或修改原始商品信息，导致系统在尝试将同一唯一标识关联至两个不同商品（GTIN、商品名称或商品属性不同）时检测到冲突。
- 批量上传文件或库存上传数据包含重复的 SKU 条目，其中同一 SKU 在一次提交或多次提交中出现多次。
- 与共享 SKU 的其中一个商品相关联的 GTIN（全球贸易项目代码）不正确或不匹配，导致系统检测到同一 SKU 被用于具有不同条形码编码的商品。

## 解决错误 18477
要解决此错误，请按照以下步骤操作：
1. 识别使用冲突 SKU 的所有商品信息，方法如下：导航至卖家平台中的“管理库存”，使用搜索功能查找 ${targetSku}，然后查看搜索结果中的所有商品信息，确定它们代表的是同一商品还是不同的商品。
2. 如果您多次提交了同一商品，请删除重复的信息，方法是从“库存”中选择“重复的商品信息”，点击下拉菜单中的“删除”按钮，确认删除，然后仅重新提交具有正确的 SKU 的一个商品版本，以消除冲突，并确保系统成功存储您提供的信息。
3. 验证并更正共享 SKU 的所有商品的 GTIN 值，方法是检查每个商品是否具有与所售实际商品匹配的准确条形码编号，将任何错误的 GTIN 更新为正确的值，并确保为具有不同 GTIN 的商品分配不同的 SKU 编码。
4. 在进行必要的更改（删除重复项、创建唯一的 SKU 或修复 GTIN 不匹配项）后重新提交更正后的商品信息，然后等待系统处理您更新的信息。
