# 一般商品限制

如果您要在亚马逊商城发布商品，则必须遵守与这些商品和商品信息相关的所有适用法律、法规、标准以及我们的政策。

| 分类 | 限制 |
| --- | --- |
| 儿童服装 | 禁止销售尺码为 2T 至 12（或同等尺寸）的带抽绳的儿童上身服装。尺码为 2T 到 16（或同等尺寸）的儿童下身服装在将服装完全展开时，其抽绳长度不能超过 3 英寸。此外，儿童下身服装的抽绳末端不能有绳扣、绳结或其他配件。尺码为 2T 至 16（或同等尺寸）的上身外衣，如果腰部或底边的抽绳是一整根绳子，则必须采用止缝工艺进行处理（即将抽绳缝死固定，防止抽绳被抽出）。有关更多信息，请参阅此处。 |
| 声明 | 商品信息中的声明必须准确无误，并且您必须能够证明其真实。如果声明中遗漏了相关信息，或者隐含不真实的内容，则会产生误导性。您在做出声明时必须提供证据，尤其当声明涉及健康、安全或性能时。您还可能需要提供证据，证明您的商品与商品详情页面上描述的技术规格和商品成分相符。如有要求，您必须向亚马逊提供相关文件，以证实您在商品信息中包含的任何声明。这类文件应包含科学证据，例如由相关领域专业人士进行的检测或其他研究的结果。如果您无法证实商品详情页面、商品图片或商品包装中的声明，我们可能会移除您的商品。需要支持证据的一些声明示例包括但不限于以下商品效果声明： 抗微生物 抗菌 可降低脑震荡的风险 由某种特定材料制成，如羊绒、竹子或皮革 包含特定的填充材料，如鹅绒或鸭绒 符合特定的纯度标准，例如声明商品 100% 全天然或含有有机成分 符合特定的质量标准，例如床单和亚麻制品上标注的纱支密度 符合特定的技术规格，例如标注的固态硬盘存储容量 商品营销受美国联邦贸易委员会监管。 |
| 环境营销 | 环境声明必须遵循美国联邦贸易委员会的营销指南。其中包括《美国联邦贸易委员会绿色指南》，该指南说明了如何避免会误导或欺骗消费者的声明。美国联邦贸易委员会认为，“环保”、“生态友好”和“绿色”等字眼可能存在问题。有关更多信息，请参阅： 环境营销指南帮助页面 美国联邦贸易委员会绿色指南 美国联邦贸易委员会环境声明： 绿色指南摘要 |
| 担保 | 商品信息必须遵循宣传保证和担保的广告指南。如果您在亚马逊商城使用“保证满意”或“保证退款”之类的措辞，则必须做到针对任何原因的退款均提供全额退款。请参阅美国联邦贸易委员会的《联邦担保法》商业人士指南、消费品担保以及互联网广告和营销： 规制手册。 |
| 珠宝首饰 | 珠宝首饰商品（包括镜框、钢笔和餐具等商品）的商品信息必须遵循美国联邦贸易委员会针对珠宝首饰、贵金属和白镴制品等行业的指南。该指南规定了如何使用“珍珠”、“铂金”、“无腐蚀性”和“无瑕”等术语。我们可能会检查在亚马逊商城销售的高级珠宝首饰的品质。高级珠宝首饰包括含黄金、白银、铂金或钯金、钻石、珍珠或宝石的商品。您必须确保您的高级珠宝首饰的商品详情页面包含关于商品质量的准确、完整的详细信息。作为“白银”或“纯银”商品发布的商品实际含银量必须至少为 92.5%。黄金和铂金含量必须与详情页面上说明的品质及商品上的压印标识相符。仿制珠宝必须具有相应标识。您必须公开所有经过处理的钻石或宝石的全部处理工艺。高级珠宝首饰的详情页面必须遵循针对首饰、贵金属和白镴制品等行业的指南和亚马逊的珠宝首饰质量保证标准。如果我们发现您为高级珠宝首饰商品提供了不准确或不完整的信息，我们可能会暂停您的发布权限，并暂停或撤销您的销售权限。请参阅美国联邦贸易委员会的珠宝首饰指南和信息页面及互联网广告和营销： 规制手册。 另请参阅受限商品： 珠宝首饰和贵重宝石。 |
| 激光商品 | 在亚马逊商城发布激光商品时，您必须在详情页面中标明激光危险等级和人体可接受的输出功率（单位：毫瓦特）。不能发布超过 Class IIIA 排放限制的激光商品，或超过 Class I 排放限制的儿童玩具激光商品。激光危险等级必须按照 21 CFR 1040.10 或国际电工委员会 60825-1 标准由独立的实验室确定。请参阅美国食品药品监督管理局关于激光商品和仪器以及最大程度降低儿童玩具激光商品的风险的指导。 |
| 美国制造 | 您描述或标记为“美国制造”的所有商品必须完全或大部分是在美国制造的。有关更多信息，请参阅美国联邦贸易委员会的美国本土制造执行政策声明和互联网广告和营销： 规制手册。有关显示原产国/原产地的指导，请参阅需要声明和公开的商品信息限制中的“动物毛皮”、“纺织品说明”和“毛制品说明”部分。 |
| 强力磁力商品和磁力商品套装 | 禁止销售通常用于娱乐目的（例如拼图游戏、雕塑建筑、头脑训练或减压等）的单个新奇磁力商品和新奇磁力商品套装。我们明确禁止销售以下磁力商品套装品牌： Buckyballs Buck balls Buckybars Bucky Bigs Buckycubes CyberCube Dynocube Hurry Harris balls Magnicube（也称为“Mag Cube”） Neocubes Neocubix Nanodots Neo spheres Puzzle Spheres（仅为磁力商品或有磁力时） Zen 磁力商品套装 |
| 医疗器械声明 | 您针对医疗器械所作的声明不能超出美国食品药品监督管理局批准的适用症范围。过度声明示例包括：将核准仅限成人使用的器械用于儿童、宣传可将器械用于适用症中未指定的身体部位，以及销售未开具处方的处方类器械。请参阅美国食品药品监督管理局医疗器械页面和受限商品： 医疗器械和配件。 |
| 医疗器械、食品、药品和化妆品 | 如果您要发布任何受《美国联邦食品、药品和化妆品法》管制的商品，则必须向我们提供以下连续性担保。“所有食品、药品、医疗器械和化妆品，截至发货之日，均保证不属于《美国联邦食品、药品和化妆品法》定义的掺假或贴错商标的商品。也保证不属于依据《美国联邦食品、药品和化妆品法》第 404、505 或 512 条规定无法在州际贸易中交易的商品。以上担保适用于之前以及以后由您本人发出或者由其他方代表您发出的所有货件。” |
| 美国本土商品 | 如果您使用了“美国原住民”、“印第安”或任何印第安部落名称等措辞，会错误地暗示该商品是“印第安商品”，或者是由部落成员或印第安艺术家制作的商品，则不能使用这些措辞。请参阅 1935 年颁布的《印第安艺术和手工艺品法》、1990 年颁布的《印第安艺术和手工艺品法》以及美国内政部印第安艺术品和工艺品委员会提供的指导。 |
| 农药以及抗微生物、抗真菌、抗细菌或杀虫商品声明 | 对于农药或者您声称具有抗微生物、抗真菌、抗细菌或其他杀虫效果的任何商品，您必须保证这些商品符合美国《联邦杀虫剂、杀真菌剂和灭鼠剂法》的要求。此保证可声明您是美国居民或者您的企业为美国居民的企业，并确认您在亚马逊商城销售的受《联邦杀虫剂、杀真菌剂和灭鼠剂法》监管的商品符合该法律的要求。此外，此类商品还必须遵守所有州级农药法律，这些法律可能包含其他注册要求、贴标要求和成分限制等。请参阅美国国家环境保护局的《联邦杀虫剂、杀真菌剂和灭鼠剂法》概述、《加利福尼亚州的农药法规》以及国家农药信息中心的相关规定。 |
| 无线电射频装置 | 对于会对其他装置产生无线电射频干扰的装置，其商品信息必须遵守美国联邦通信委员会对于此类装置的规定。您可能需要从美国联邦通信委员会获得编码或其他授权。请参阅美国联邦通信委员会工程技术办公室的设备审批页面。 |
| 冰箱用净水器替换滤芯 | 您必须确保冰箱用净水器替换滤芯获得 NSF/ANSI-42 标准或更高标准（例如材料安全和结构完整性方面的 NSF/ANSI-53 或 NSF/ANSI-401 标准）认证，且必须至少获得 NSF/ANSI-42 减排标准或系统性能认证。这些认证必须由美国国家标准协会认可的独立实验室（如 NSF、WQA 和 IAMPO）提供。减排声明必须准确显示在商品详情页面上。请参阅 NSF 关于住宅饮用水处理标准的指导。 |
| 仿真艺术品、硬币和邮票 | 有关发布仿真艺术品、硬币和邮票的信息，请参阅以下受限商品帮助页面： 艺术品 货币、硬币、现金等价物和礼品卡 盖戳器和邮票 |
| 推荐、代言、反馈和评论 | 推荐或代言必须遵循关于在广告中使用代言与推荐的指导原则。您必须公布您与代言人之间的任何重大利益关系。您不能向任何人付款购买评论，或者为删除商品评论或反馈提供礼品或退款。另请参阅： 美国联邦贸易委员会的互联网广告和营销： 规制手册 禁止的卖家活动和行为 |
| 窗帘 | 窗帘类商品的商品信息必须遵循窗帘制造商协会采用的非强制性安全标准。其中包括外露拉绳式窗帘类商品的非强制性安全标准 (ANSI/WCMA A.100.1)。 |
