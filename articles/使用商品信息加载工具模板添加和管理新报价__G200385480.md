# 使用商品信息加载工具模板添加和管理新报价

商品信息加载工具可让您向亚马逊目录中的已有商品添加报价。您提供商品编码和您的报价信息，无需提供商品详情。单个商品信息加载工具文件可同时发布或修改多个商品分类中的报价。每个文件最多可上传 20,000 个 SKU。

商品信息加载工具可用于：

- 在单个文件中向数千个已有商品添加报价

- 修改现有报价（价格、数量、状况、配送）

- 删除报价或将无货商品的库存设为零

**注意： **要创建亚马逊目录中尚未收录的新商品，请改用商品电子表格。

## 生成您的商品信息加载工具模板

您可以下载空白模板，或下载包含您所搜索商品的预填充模板。

要生成模板，请按照以下步骤操作：

- 前往[添加商品](https://sellercentral.amazon.com/product-search/bulk)，然后选择【电子表格】选项卡。

- 点击【下载空白模板】，然后在【发布亚马逊目录中已有的商品】下方，点击【获取商品信息加载工具】。

- 选择模板语言。

- （可选）输入 UPC、EAN、ISBN 或 ASIN 来搜索商品。输入多个编码，以逗号、空格或换行符分隔。您一次最多可以输入 500 个编码。

- 点击【生成电子表格】。

- 如果您搜索了商品，模板将预填充这些 SKU，并指示是否可以添加报价。

- 如果您未搜索，将生成空白模板。

您可以在【历史生成模板】部分找到您的模板。

要填写模板，请按照以下步骤操作：

- 打开下载的模板文件。

- 对于要发布的每个商品，填写以下必填列： SKU、价格、数量、状况和配送渠道。

- 如果使用的是空白模板，请提供商品编码（UPC、EAN、ISBN 或 ASIN）。

- 为每行设置【商品信息操作】。

如果您不想为预填充的商品添加报价，请删除该行或将其商品信息操作更改为【已忽略】。

## 主要字段和最佳实践

**SKU**

- 每个报价必须具有唯一的 SKU

- 如果您为现有 SKU 上传数据，新值将替换以前的值

**价格**

- 确保价格字段为数字格式，尤其是在使用逗号作为小数分隔符时

- 要删除 SKU 上的报价，请使用下拉菜单将【您的价格】设置为【删除报价】

- 要删除卖家允许的最低价格，请使用下拉菜单将其设置为【删除卖家允许的最低价格】

- 要删除卖家允许的最高价格，请使用下拉菜单将其设置为【删除卖家允许的最高价格】

**商品信息操作值**

商品信息加载工具支持以下商品信息操作值：

| 值 | 操作 |
| --- | --- |
| 创建或编辑 | 添加新报价或编辑现有报价。如果该列留空，则此为默认选项。 |
| 添加商品 | 创建报价。此项仅出现在预填充模板中。 |
| 删除 | 从您的目录中移除报价。 |
| 已忽略 | 跳过该行；不执行任何操作。仅当无法将报价添加到 ASIN 时，此项才会出现在预填充模板中。 |

**商品编码**

请务必提供有效的商品标识符（UPC、EAN、ISBN 或 ASIN），以便亚马逊能够将您的报价匹配到正确的商品页面。如果找到多个匹配项，商品信息加载工具将帮助您解决匹配问题。

## 更新现有报价

您无需在每次要进行更改时都重新上传整个文件。您可以上传仅包含要更新的 SKU 的文件。

**增量更新的工作原理**

- 您为某个 SKU 提交的数据将保留在目录中，直到您为同一 SKU 上传新数据。

- 当您为现有 SKU 上传新数据时，新值将替换以前的值。

- 上传文件中未包含的 SKU 不会受到影响。

要更新现有报价，请按照以下步骤操作：

- 前往[添加商品](https://sellercentral.amazon.com/product-search/bulk)，然后选择【电子表格】选项卡。

- 点击【下载空白模板】，然后在【发布亚马逊目录中已有的商品】下方，点击【获取商品信息加载工具】。

- 生成预填充或空白模板。

- 输入 SKU，并将商品信息操作设置为【创建】或【编辑】。

- 仅提供您要更改的报价属性。

- 上传文件。

## 删除商品

删除商品信息，请遵循以下步骤：

- 前往[添加商品](https://sellercentral.amazon.com/product-search/bulk)，然后选择【电子表格】选项卡。

- 点击【下载空白模板】，然后在【发布亚马逊目录中已有的商品】下方，点击【获取商品信息加载工具】。

- 生成空白模板或使用现有模板。

- 输入 SKU，并将商品信息操作设置为【删除】。

- 上传文件。

**重要： **删除 SKU 会移除您对该商品的报价。如果您只是需要暂时将商品设为无货，请改为将数量设置为零。
