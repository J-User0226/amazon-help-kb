# 使用不同类型的业务报告

## 业务报告类型

**Individual sellers：** 此功能仅适用于参与专业销售计划的卖家。有关更多信息，请参阅[销售计划对比](https://sellercentral.amazon.com/gp/help/external/64491)。

有多种不同类型的业务报告，您可以从卖家平台的[业务报告](https://sellercentral.amazon.com/gp/site-metrics/report.html)部分访问这些报告。

## 业务报告（按日期、按 ASIN 和其他）

在左侧的导航栏中，有一系列【按日期】、【按 ASIN】 和【其他】整理的报告。

您可以使用【调位】按钮将业务报告从【按日期】切换为【按 ASIN】。此功能仅适用于**按日期**排列的业务报告，不适用于【按 ASIN】 排列的业务报告。点击同一按钮（此时标签为【返回日期报告】），返回【按日期】排列业务报告。

这些报告的数据通常可以保留最多两年。

您可以点击【下载】，下载逗号分隔的 (CSV) 报告。选中您要下载的行旁边的复选框。如果没有选中行，则会下载所有行。

如果您已创建自定义报告，则可以通过为页面添加书签或者复制 URL 并将其保存在稍后可以检索的地方来保存设置。报告的参数会保留在 URL 中。

## 按日期： 销售和流量

最常用的报告之一是【按日期： 销售和流量】。下表显示了此报告中不同列的计算方式：

| 字段名 | 计算方式 |
| --- | --- |
| 已订购商品销售额 | 总和（商品价格 * 已订购商品数量） |
| 已订购商品数量 | 总和（“订购的商品数量”） |
| 订单商品总数 | 总和（“订单商品数”） |
| 每种订单商品的平均销售额 | 订购的商品销售额/订单商品总数 |
| 每种订单商品的平均数量 | 已订购商品数量/订单商品总数 |
| 平均销售价格 | 订购的商品销售额/订购的商品数量 |
| 会话数* | 总和（“不同会话数”） |
| 订单商品会话率 | 订单商品总数/会话数 |
| 平均商品数量 | 总和（“商品数”）/总和 (1) 注意： 仅适用于商品数 > 0 时。总和 (1)，指的是“具体时间段内的天数” |
| 已发货商品销售额 | 具体时间段内已确认发货的商品销售额总和（“商品价格”*“订购的商品数量”） |
| 已发货订单商品数 | 具体时间段内已确认发货的总和（“订单商品数”） |

*一次会话对应的是买家对亚马逊页面进行的一次访问。在访问过程中，即使买家多次浏览多个页面（24 小时内），也只会记为一次会话。页面浏览量指的是买家访问该页面的实际次数。在一次会话中，买家可以多次浏览页面。因此，报告中显示的会话数可能会低于页面浏览量。
