# 利润分析

如需了解如何使用“利润分析”（Profit Analytics）工具的概况，请收听这期“卖家平台”（Seller Central）播客节目。

利润分析是一种报告工具，可用于分析亚马逊目录中商品的费用、成本和盈利能力。

它整合了销售、退货、费用、广告和您提供的成本数据，以帮助您分析 SKU、ASIN 和父 ASIN 级别的盈利能力。利润分析可提供最多 50 万个在售商品的历史数据和未来预计数据。利润分析中的数据通常会是 1~2 天前的数据，但在极少数情况下，由于拆分某些费用需依赖上游数据，部分费用数据可能会延迟最多 7 天。[付款](https://sellercentral.amazon.com/payments/dashboard/index.html)是费用交易和提现数据的权威来源。税务发票是税务信息的权威来源。

**注意： **宣布费用变更后，可能预留一段时间让您提前了解即将实施变更的新费率。您可在此视图中预览目录中各款商品收取的新费率及其与历史费率的对比。

**利润分析： 用户指南**

在[利润分析](https://sellercentral.amazon.com/economics)选择您的首选数据视图类型：

- 总计提供指定数据类型的合计值。

- 商品成本提供总计、单件商品和商品数量等值，这些信息非常适合用来做细致分析。

利润分析会自动包含所有销售费用、销售佣金、配送费用和仓储费。您也可以选择显示其他叠加指标（如税务信息和促销数据），以加强分析。

**注意： **默认情况下，指标数据为含税数据。选择税费时，单件商品金额和总金额均为不含税数据，税额会单独显示。

请选择预先设定的时间段选项，以便以最低延迟查看您的历史和未来预估数据。对于自定义时间段或超过 50 万个商品的目录，请使用 SKU 成本和可配置成本预览下载报告。

点击一览的任意指标模块（如仓储成本），可在下方表格中查看其组成部分的明细。对于自定义视图，请点击设置图标，选择您要在表格中显示的具体字段。

要查找特定商品的数据，请使用搜索功能。输入商品的 SKU、ASIN 或名称，以显示该特定商品的选定指标。

使用“排序方式”功能按从高到低或从低到高排列数据。点击任意指标列进行排序，或使用“排序方式”选项来确定使用哪些指标来决定所选列的排序顺序。

要修改表格视图，请点击表格上方的设置图标，选择您想要显示的指标。

**利润分析中包含的指标**

销售组：

- 总销售额（收入）

- 售出的商品总数

- 净销售额（收入）

- 退款商品数量

- 退货率

- 净已售商品数量

- 净收入

配送成本：

- 亚马逊物流配送费用

- 低库存水平费用

- 基础亚马逊物流配送费用

- 欧洲整合服务计划大件费用（仅适用于欧盟地区）

- 卖家自配送邮费

- 卖家自配送商品的配送成本（卖家提供）

入库成本：

- 配送运输费用

- 亚马逊物流国际货运运费

- 亚马逊物流国际货运关税和税费

- 亚马逊物流入库配置服务费

- 亚马逊物流预处理服务费

- 运输成本（卖家提供）

- 包装成本（卖家提供）

- 汽运零担成本（卖家提供）

销售费用：

- 销售佣金

- 按件收取的销售费用

- 交易手续费

- 销售佣金退款

- DSTR 费用

仓储成本：

- 月度仓储费

- 仓储利用率附加费

- 超龄库存附加费

- 亚马逊仓储和分拨服务入库处理费

- 亚马逊仓储和分拨服务出库处理费

- 亚马逊仓储和分拨服务月度仓储费

- 亚马逊仓储和分拨服务运输费

- 仓储成本（卖家提供）

退货与价值回收操作：

- 退货商品数量

- 退货率

- 退款管理费用

- 退款处理费

- 移除费用

- 弃置费用

- 批量清货费用

广告成本销售比：

- 商品推广费用总计

- 每日促销费用

- 基于促销绩效的费用

- 优惠券参与费

- 优惠券费用

- 基于优惠券绩效的费用

- 亚马逊以外的广告支出（卖家提供 - Meta）

- 亚马逊以外的广告支出（卖家提供 - Tiktok）

- 亚马逊以外的广告支出（卖家提供 - Google）

- 亚马逊以外的广告支出（卖家提供 - 其他）

利润分析中不包含的费用：

- 服务订阅费

- 销售账户服务费

- 计划外服务费用

- 租赁图书服务费

- 大批量上架费用

- Prime Wardrobe

- 未明确列入指标包含范围的其他不常见费用

**提供其他财务数据**

利润分析可以整合您提供的额外数据，从而更准确地估算净利润，包括销售数据、成本数据和交期。要了解有关财务数据的更多信息，请前往[其他财务数据](https://sellercentral.amazon.com/seller-inputs)。

**预计净收入**

利润分析中预计净收入和显示的商品销售总额百分比只是预估值，基于您提供的数据得出，如入库运费和所售商品成本。如果您选择提供其他财务数据，则利润分析中提供的预计净收入可能与亚马逊提供的其他报告中显示的净收入不同，原因是后者不包含这些成本数据。预计净收入是在商品级别计算的，并汇总到您的目录一览中。这些预估值不包含未纳入“利润分析”的费用和成本（请参阅上方内容）。
