# 错误 13002

“可售”值无效。有关更多详情，请参阅 http://sellercentral.amazon.com/gp/help/external/24801

如果您在库存输入数据中提供一个无效的“可售”值，则会发生此错误。有效的“可售”值为：

- true
- false

要解决此错误，请使用有效的“可售”值之一发布修改后的库存输入数据。
