# 赔偿报告定义

卖家可以查看赔偿报告中各种赔偿类型的定义。

| 赔偿类型 | 定义 |
| --- | --- |
| 买家退货 | 买家退货是指买家已退回运营中心并退回至您的库存的商品。如果商品在退货流程中残损或丢失，并且过错方是亚马逊，我们将针对这些买家退货进行赔偿。 |
| 客户服务问题 | 这些赔偿是破例发放的。 |
| 例外残损 | 这些赔偿是破例发放的。 |
| 在库期间残损 | 在亚马逊运营中心残损或弃置的商品。 |
| 费用更正 | 针对错误收取的费用发放的赔偿。 |
| 入库期间丢失 | 入库期间误放的商品。 |
| 在库期间丢失 | 在亚马逊运营中心误放的商品。 |
| 赔偿撤销 | 由于赔偿发放错误，或者我们退还了商品，因此赔偿已追回。 |
