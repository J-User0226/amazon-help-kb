# 注册亚马逊 Easy Ship

## 注册流程

如果您注册为卖家，并且参与了专业销售计划，我们邀请您使用亚马逊 Easy Ship 计划，将商品配送给买家。

**注意： **主账户持有人是您曾在亚马逊商城注册的持有人。只有主账户持有人才有权注册亚马逊 Easy Ship 服务以及更改其设置。

请按照以下步骤进行注册：

- 使用您的主账户持有人凭证登录卖家平台。

- 在卖家平台中，点击【设置】，然后前往[配送设置](https://sellercentral.amazon.com/sbr/ref=xx_shipset_dnav_xx#settings)。

- 向下滚动至【一般配送设置】选项卡底部的选择加入通知，然后选择【选择加入】。

- 输入您的邮政编码验证您的资格。如果您的取件地址在亚马逊 Easy Ship 覆盖范围内，系统将自动带您访问注册流程的其余部分。

- 按照以下步骤输入您的取件地址： 

- 邮政编码（最多 5 位数）： XXXXX

- 联系人姓名：全名

- 地址 1：街道，门牌号（您可以在数字和门牌号之间用逗号分隔）

- 地址 2：街区或楼号。此字段为可选字段。

- 城市：城市名称

- 当您添加邮政编码时，已默认添加州和国家/地区

- 电话号码和分机：添加联系人名称的电话号码，以防出现任何问题。

- 输入您的包裹详情，包括尺寸和类型，然后提供以下信息：

- 是否可将包裹置于托拍上

- 您的库房或设施允许的最大车辆尺寸

- 点击**验证**和**保存**，完成注册流程。**点击“验证”和“保存”，即表示您声明已阅读并同意[亚马逊 Easy Ship 条款和条件](https://sellercentral.amazon.com/help/hub/reference/G201439100)，您的注册日期也将显示在[亚马逊 Easy Ship 设置](https://sellercentral.amazon.com/sbr)页面中。**

**注意： **目前，我们仅支持每个账户设置一个取件地址。为了获得更好的取件体验，请尝试提供尽可能详细的地址信息。

如果您的取件地址不在该计划涵盖范围内，系统将不会保存该地址，您将看到一条错误消息。在这种情况下，请稍后重试，因为我们会不断增加覆盖分区。

## 完成注册后的步骤

**将亚马逊 Easy Ship 设为默认配送方式**

注册亚马逊 Easy Ship 后，请按以下步骤操作：

- 转至卖家平台，然后依次转至**设置** > **[配送设置](https://sellercentral.amazon.com/sbr)**。在配送计划下查看状态，确认您已注册亚马逊 Easy Ship。

- 除非您选择使用亚马逊 Easy Ship，否则您的所有卖家自配送订单都将默认设置为自配送方式。要将默认配送方式从自配送更改为亚马逊 Easy Ship，请按以下步骤操作：

- 在卖家平台中，依次转至**设置** > **[配送设置](https://sellercentral.amazon.com/sbr)**。

- 转至**一般配送设置**，然后转至**配送首选项**。

- 点击**更改**。

- 选择亚马逊 Easy Ship 后，除危险品及重型大件商品外，您的所有商品都将自动加入该计划。

- 亚马逊的物流服务提供商 (LSP) 将从您的注册地址取件，并将包裹配送给买家。您必须在安排截止日期和时间之前，在卖家平台中完成包裹准备和订单安排。

**注意： **请勿通过自配送或第三方承运人配送符合条件的亚马逊 Easy Ship 订单。

**为特定商品选择亚马逊 Easy Ship**

注册亚马逊 Easy Ship 后，请按以下步骤操作：

- 默认情况下，卖家平台库存中所有符合条件的自配送商品仍将保持自配送状态。您可以随时将特定 SKU 加入亚马逊 Easy Ship，并可分别管理每个 SKU 的加入状态。要管理您的 Easy Ship 注册，请按以下步骤操作：

- 在卖家平台中，依次转至**设置** > **[配送设置](https://sellercentral.amazon.com/sbr)**。

- 转至**一般配送设置**，然后转至**配送首选项**。

- 要使商品在 Easy Ship 中处于启用状态，您可以更改默认配送方式（见上文），或单独将特定商品加入该计划。要单独选择特定商品加入，请按以下步骤操作：

- 在卖家平台中，转至**设置**，然后转至**配送设置**。

- 转至**一般配送设置**，然后转至**配送首选项**。

- 点击**编辑**。

- 转至**商品级配送首选项**，然后按 SKU 更改**配送方式**设置。将“配送方式”选项选为 

［
Easy Ship
］
的任何 SKU 均将在该计划中激活。

## 亚马逊 Easy Ship 配置

要编辑您的首选项，您可以通过 [Easy Ship 设置](https://sellercentral.amazon.com/easyship/panjeekaran/accountSettings)访问配置。在此页面上，您可以：

- 通过编辑当前地址修改您的取件地址。

- 选择**添加新包裹**选项，配置包裹的尺寸。添加包裹名称及其尺寸，以供参考。

- 选择**每张纸一个货件标签**或**每张纸多个货件标签**，以选择打印首选项。

您应全权负责确保信息准确无误，并与在亚马逊 Easy Ship 计划中注册的信息一致。

有关更多信息，请联系[销售伙伴支持](https://sellercentral.amazon.com/help/center)。
