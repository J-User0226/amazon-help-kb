# 错误 90199

## 错误消息

“${attribute_name}”的值不应包含 HTML 标记。

## 导致错误 90199 的原因

出现此错误的可能原因如下：

- 商品描述或属性中含有 HTML 格式代码，例如 <p>、<br> 或 <strong>。

- 从网站或富文本编辑器中复制并粘贴的内容包含 HTML 标记。

- 商品信息字段中包含格式标记。

## 解决错误 90199

- 删除指定属性中的所有 HTML 标记（例如 <p>、<br> 或 <strong>）。

- 所有商品属性（包括商品名称、描述和要点）均使用纯文本格式。

- 更新完属性值并确保其不含 html 标记后，重新提交上传数据文件。
