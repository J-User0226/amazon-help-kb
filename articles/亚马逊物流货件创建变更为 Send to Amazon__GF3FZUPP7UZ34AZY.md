# 亚马逊物流货件创建变更为 Send to Amazon

2022 年 10 月 17 日，Send to Amazon 将取代我们所有商城中的“发/补货”工作流程。所有新的亚马逊物流货件必须在 [Send to Amazon](https://sellercentral.amazon.com/fba/sendtoamazon) 中创建，或者通过[亚马逊商城网络服务应用 API](https://sellercentral.amazon.com/gp/help/external/G200389230) 或[销售伙伴 API](https://developer.amazonservices.com/gp/mws/docs.html) 创建。

自 2022 年 11 月 30 日起，您将无法再查看、编辑或完成通过“发/补货”工作流程创建的任何货件。

**注意： **可使用 Send to Amazon 处理从中国发货的亚马逊跨境物流服务货件。

使用 Send to Amazon，您可以创建可重复使用的原厂包装模板，为单一 SKU 包装箱中的货件保存箱内物品信息、预处理和贴标信详情。此外，您可以将单一 SKU 包装箱和混合 SKU 包装箱添加到同一工作流程。有关这些功能的更多信息，请参阅[使用 Send to Amazon 创建货件](https://sellercentral.amazon.com/gp/help/external/G6925SDD66GDLXJW)。

## 通过应用程序接口创建货件

2023 年 2 月 28 日是您可以通过[亚马逊商城网络服务 API](https://sellercentral.amazon.com/gp/help/external/G200389230)或[销售伙伴 API](https://developer.amazonservices.com/gp/mws/docs.html)使用“发/补货”查看和编辑亚马逊物流货件的最后期限。自 2023 年 3 月 1 日起，Send to Amazon 工作流程将取代由 API 创建的货件的“发/补货”库存。

您可以使用 Send to Amazon 功能查看和编辑通过亚马逊商城网络服务 API 或销售伙伴 API 创建的货件。当您从“货件处理进度”访问 API 创建的货件处于【待处理】状态时，系统会自动转至 Send to Amazon 工作流程。

自 3 月 1 日起，您将有三个选项来创建和编辑您的货件：

- **100% 通过卖家平台的 Send to Amazon 工作流程管理货件：** 通过使用 Send to Amazon 工作流程创建、编辑您的货件并完成货件发送工作。

- **100% 通过 API 管理货件：** 通过亚马逊商城网络服务 API 或销售伙伴 API 创建、编辑您的货件并完成货件发送工作。

- **同时使用 Send to Amazon 和 API 管理货件：** 使用 API 创建您的货件，然后前往卖家平台中的“货件处理进度”以管理 API 创建的货件。系统将自动转至 Send to Amazon 以编辑您的货件并完成货件发送工作。在 3 月 1 日时，您将无法选择旧的工作流程。

在 Send to Amazon 中查看或编辑 API 创建的货件后，您将无法使用 API 继续编辑该货件。此外，无法使用 API 编辑您在 Send to Amazon 工作流程中创建的货件。

一些亚马逊批准的第三方应用已经进行了改进，从而可以更好地使用 Send to Amazon 功能。您可以在[销售伙伴应用商店](https://sellercentral.amazon.com/selling-partner-appstore)中查看亚马逊批准的第三方应用程序的完整列表。
