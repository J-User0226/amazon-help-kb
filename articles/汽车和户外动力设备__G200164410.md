# 汽车和户外动力设备

如果您要在亚马逊商城发布商品，则必须遵守与这些商品和商品信息相关的所有适用法律、法规、标准以及亚马逊政策。

## 我们的汽车和户外动力设备商品政策

亚马逊禁止销售需要登记的机动车。但是，您通常可以销售符合美国《联邦机动车辆安全标准》和《清洁空气法》等适用法律要求的汽车零部件以及其他汽车和户外动力设备用品。

**准售商品示例**

- 汽车电池

- 符合以下合规检查清单的新轮胎：

- 轮胎必须符合美国[联邦机动车辆安全标准](https://www.nhtsa.gov/laws-regulations/fmvss)

- 轮胎状况必须为全新、未使用且未破损，在销售前未移除原始制造商标签或贴标

- 轮胎未曾安装在任何轮毂上，即未曾安装在任何轮辋或轮圈（胎圈接触的轮胎或内外胎总成的金属支架）上

- 轮胎必须具有未经更改的有效美国运输部轮胎识别号

- 根据轮胎识别号中列出的制造日期，轮胎的销售日期必须在其制造日期之后三年内

- 轮胎的原始制造商保修期（如有）不足两年时不能出售

- 要符合[轮胎注册要求](https://www.govinfo.gov/content/pkg/CFR-2011-title49-vol7/xml/CFR-2011-title49-vol7-sec574-8.xml)，应做到以下两点： 

- 向所有轮胎制造商提供买家的姓名和他们所购各轮胎的轮胎识别号；或者向每个购买轮胎的买家提供纸质轮胎注册表，上面注明出售给该买家的所有轮胎的轮胎识别号、您的姓名和街道地址、电子邮件地址或网站

- 根据需要提供帮助，确保亚马逊遵守轮胎识别和记录义务

- 提供的部件在单独使用以及与其他部件结合使用时可保留全排放控制设备的全部功能，包括车载诊断系统

- 经美国国家环境保护局认证的便携式燃料容器

- 车辆配件，例如地垫和雨刮器片

**禁售商品示例**

- 禁售的排放控制系统失效设备：

- 可能干扰发动机排放控制系统正常运行的商品，包括但不限于以下类型的商品、零件或套件： 

- 对已通过美国《清洁空气法》认证的车辆的排放产生不利影响的商品

- 移除、消除、删除或改造任何排放控制系统功效的商品。以下是一些准售但不允许改造的排放控制系统示例：

- 柴油微粒过滤器系统

- 选择性还原催化剂系统

- 废气再循环系统、阀门或冷却器

- 催化转换器

- 柴油氧化催化剂系统

- 氮氧化物吸附催化剂系统

- 改变车辆、摩托车或发动机的车载诊断系统的全部操作和功能的商品，包括移除、改变或取代故障指示灯的任何部件

- 拆除套件、管道、五金、垫片、垫圈或插头

- 拆除调谐器（也称为编程器）和拆除调校（也称为程序和校准）

- 性能调谐器（也称为编程器）和性能调校（也称为程序和校准），除非调谐器或调校已获得加利福尼亚州空气资源委员会行政命令 (CARB EO)

- 废气再循环系统阻塞板

- 废气再循环系统冷却器拆除套件

- 不包括已通过美国《清洁空气法》认证的车辆的排放控制部件的排气硬件和套件，包括涡轮后置和下置排气管

- 节气门拆除套件

- 氧气传感器模拟器

- 氧气传感器插头、垫圈适配器和扩展器

- 曲轴箱通风改线插头和套件

- 适用于公路车辆（如汽车、卡车或摩托车）但在公共道路上使用属于非法的排放相关商品（例如，仅允许越野、赛车或竞技使用的商品）

- 需要登记的机动车，除非由符合计划要求的卖家发布在 Amazon Autos 店铺中。

- 二手轮胎

- 二手轮毂

- 二手轮毂配件，包括但不限于车轮螺母、螺栓和垫圈

- 汽车安全气囊、安全气囊盖、安全气囊充气机以及安全气囊组件

- 汽车安全带和安全带组件

- 与官方应急响应车辆用灯相似的警示灯。此类车辆包括（但不限于）警车、县治安官车、州巡警车、救护车、首批响应车、紧急医疗服务车和道路救援车

- 高强度放电转换套件

- 发光二极管头灯转换套件

- 用于妨碍、规避或以其他方式干扰执法、车辆或道路安全功能或其他法律要求的商品，例如： 

- 用于遮挡车牌使其无法被读取或识别的车牌防拍喷剂或车牌盖板

- 可定制州车牌、仿制可定制州车牌，或可能被合理误认为官方车牌的其他车牌

- 交通信号组件（包括设计用于交通信号的任何部件或配件）

- 用于故意妨碍、屏蔽或干扰获得许可或授权的无线电通信的商品，例如：GPS 屏蔽器

- 用于更改里程表的商品

- 用于规避驾驶辅助系统或其他汽车安全功能的商品，包括配重环、自动驾驶警告减少装置、安全带报警消音器，以及用于规避车辆音频或视频系统停车制动要求的商品

- 不符合适用的美国《联邦机动车辆安全标准》的商品，例如不符合该标准第 218 条规定的摩托车头盔，以及不符合该标准第 108 条规定的公路用替换灯。

- 乙二醇含量超过 10% 且不含苦味剂的发动机冷却剂或防冻剂

- 未经美国国家环境保护局认证的便携式燃料容器

- 驾驶证和政府颁发的其他身份证明

- 临时车牌或标识

- 残疾人停车标牌、标签或车牌

- 车辆识别号标牌

- 汽车座椅加热垫（一种缓冲垫，内含一个通过连接汽车直流插座、USB 接口、内置电池或外接移动电源来供电的加热元件）

- 汽车贴纸或自粘标签，用于证明符合美国运输部 (DOT) 或州政府监管机构的检验要求，包括：

- 美国运输部 (DOT) 合规标签

- 商业车辆总重量标签

- 车辆登记标签

- 车辆识别号 (VIN) 标牌、替换件或保护盖

- 高乘载车辆/高乘载收费 (HOV/HOT) 车道许可证

- 检查贴纸或标签

**可能受司法管辖区销售限制的商品示例**

您还必须遵守适用于商品销售地司法管辖区和发货地司法管辖区的州和地方法律。可能需要遵守其他州或地方法规的商品示例，包括但不限于：

- 未经制造商认证，不符合限制此类商品中铜、特定重金属和石棉含量的州级法律法规的机动车制动垫

- 含铅的车轮重量

- 加利福尼亚州：不符合加利福尼亚州空气资源委员会要求的发动机、售后零件、高性能零件、附加件以及汽油罐

- 受司法管辖区政策约束的零售铅酸电池

- 科罗拉多州、缅因州和纽约州：不符合加利福尼亚州空气资源委员会要求的售后催化剂转换器。
