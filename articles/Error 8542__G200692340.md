# Error 8542

## What Causes Error 8542?

此错误通常称为“多个匹配错误”，当您的商品编码（UPC、EAN、JAN、ISBN 等）目前与两个或更多 ASIN 相关联，而您在库存模板中提供的其他属性（商品名称、品牌、颜色和尺寸等）与其中任何一个 ASIN 都不匹配时，就会出现此错误。

## Error Message:

提供的 SKU [SKU] 与亚马逊目录不一致。为此 SKU 提供的标准商品编码值与 ASIN [ASIN] 相对应，但部分信息与亚马逊目录中的信息不一致。以下是不一致的属性值： 商品包装数量（卖家：[Merchant Value]/亚马逊：[Amazon Value]）或部件编号（卖家：[Merchant Value]/亚马逊：[Amazon Value]）。如果您的商品与此 ASIN 相对应，请修改这些属性，以便与亚马逊目录值保持一致。如果您的商品与此 ASIN 不同，请检查您的标准商品编码值是否正确。

## How to Solve and Prevent Error 8542:

- 检查您提供的商品编码，确保其正确无误。如果有误，请在文件中输入正确的商品编码并重新提交。

- 如果您已提供正确的商品编码，请执行以下步骤： 

- 更新文件中的属性（错误报告中已列出这些属性），以便与目录中的属性相匹配，然后重新提交文件；或者

- 使用错误报告中提供的 ASIN 替换【商品编码】和【商品编码类型】列下的条目，然后重新提交您的文件。

如果此商品在亚马逊目录中的信息看起来不正确，请联系销售伙伴支持。

**注意： **亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。

**注意： **造成此错误通常是因为制造商重复使用了 UPC 或 EAN。例如，在服装分类中，条形码有时会在三年后重复使用。请确保您的商品与正确的 ASIN 相匹配。
