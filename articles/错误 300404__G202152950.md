# 错误 300404

## 错误消息

错误消息： “我们无法通过 URL !{imageUrl} 访问该媒体。我们收到了 404 HTTP 状态代码。在提供的地址无法找到该媒体。请确保该 URL 正确且该媒体可公开访问。”

## 导致错误 300404 的原因

当无法找到请求的资源，但可能会在日后提供时，就会出现此错误。

我们的系统多次尝试从指定的 URL 检索该媒体，但在某些情况下，所有尝试均失败。

## 解决错误 300404

您必须删除当前或可用的 URL，重新上传同一 URL，并确认上传的 URL 是否可在任何浏览器中打开。

## 避免错误 300404

要避免此错误，请按照以下步骤操作：

- 确保媒体服务器采用 HTTP 协议并返回正确的响应代码。

- 确保媒体 URL 中没有拼写错误。

- 确保所请求的文件未被重命名。

- 确保未将所请求的文件移动到其他位置或删除。

- 确保所请求的文件未因维护、升级或其他未知原因而暂时不可用。

- 确保所请求的文件确实存在。
