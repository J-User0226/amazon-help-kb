# 下载付款报告

付款报告详细列出了您在指定结算周期内的交易细目，可帮助您了解您的账户活动。

[付款报告](https://sellercentral.amazon.com/payments/reports/statement/details)中“结算一览”的顶部会显示您的结算日期和预计能够收到的付款金额。我们会自动更新这一信息。

如果您的卖家账户要进行结算，那么该卖家账户必须在结算周期内具有相关活动且账户余额为正数或零。销售佣金和退款可能会影响您的余额。当您的账户完成结算后，【所有结算】页面上会发布关于该结算周期的报告，而且您可下载此信息。

结算报告可能包含分配给您用于资金转账的[联邦自动清算中心系统追踪编码](https://sellercentral.amazon.com/gp/help/external/201717580)。自亚马逊发起转账之日起 5 个工作日后，您的银行可以使用此追踪编码来查看存款状态。

## 下载报告

要下载结算报告，请执行以下操作：

- 旧版卖家平台： 前往付款报告中的【所有结算】页面。新版卖家平台： 前往[财务报告](https://sellercentral.amazon.com/manage/finance/reports?view=reconcile-earnings)。

- 使用【选择日期范围】筛选条件，将结果限定到您选择的时间段（如果需要）。

- 点击“操作”列中与所需结算周期相对应的【下载】按钮。

- 【下载 XML】： 您可以使用 Microsoft Excel 等程序打开 XML 文件。

- 【下载模板文件】： 制表符分隔的文本文件。

- 【下载模板文件 V2】： 亚马逊物流卖家可以将此文件与结算汇总模板相结合使用来创建数据透视表，此表可以按订单显示简化的详情。了解关于[结算汇总报告](https://sellercentral.amazon.com/gp/help/external/200141680)的更多信息。

- 将文件保存到您的电脑中，然后使用电子表格或数据库程序将其打开。

要了解如何获取自定义日期范围内的报告，请参阅[日期范围报告](https://sellercentral.amazon.com/gp/help/external/200989190)。
