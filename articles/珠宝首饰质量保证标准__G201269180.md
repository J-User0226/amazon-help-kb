# 珠宝首饰质量保证标准

要在亚马逊上销售珠宝首饰类商品，卖家必须确保他们的商品达到亚马逊质量保证标准，这有助于卖家向珠宝首饰买家提供非凡的价值。此外，珠宝首饰类商品以及相关商品信息必须遵守所有适用法律、法规和标准以及本页中列出的标准。

本页面概述了珠宝首饰质量保证标准，该标准可帮助卖家清晰准确地描述其商品的各个方面，包括商品名称、商品功能、规格和描述。卖家必须确保其商品符合或超过他们在亚马逊上发布的商品描述。本页还介绍了亚马逊的审查流程。

我们可能会出于任何原因随时暂停或终止卖家的高级珠宝首饰或珠宝首饰发布权限，并会事先通知卖家。卖家可以出于任何原因随时停止发布高级珠宝首饰或珠宝首饰商品。

## 1. 商品信息和规范

卖家必须遵守美国和加拿大适用的金属质量标识和压印要求，且必须在其商品信息中提供准确的金属含量信息。以下部分就金属含量要求提供了额外的详细信息。

## 1.1 黄金

- 卖家必须遵守以下有关黄金纯度容差范围的规定。对于普通的黄金物品，冲压印记纯度的容差是 +/- 0.003。对于以焊接方式制作的商品（例如手链），总容差是 0.007。

- 将商品作为金制品发布时，必须明确标注黄金纯度（例如 10K、14K、24K）。

## 1.2 银

- 所有纯银商品的鉴定含银量必须达到 92.5%。对于普通的纯银商品（非焊接品），容差是 +/- 0.002。对于焊接品，容差是 +/- 0.006。

- 所有铸银商品的鉴定含银量必须达到 90.0%。对于普通的纯银商品（非焊接品），容差是 +/- 0.002。对于焊接品，容差是 +/- 0.006。

- 将商品作为银制品发布时，必须明确标注银纯度（例如 500、750、850、925）。

- 银饰上的某些物件无需进行鉴定：针杆、安全扣针等。接受镍制针杆。

## 1.3 铂金

- 标有“PLAT”或“PLATINUM”且显示为纯铂金的商品必须进行 950/1000 的含量鉴定。

- 如果铂金含量低于 950/1000，必须在质量标志中公开铂金含量，如“900 PLAT”。

- 如果铂金含量低于 850/1000，必须在质量标志中公开铂金含量，如“500 PLAT”，并且后面必须紧跟合金中使用的含量和元素，如“415 CO”。

- 作为别扣一部分的手链和项链搭扣无需进行铂金含量鉴定。

## 1.4 冲压印记

所有金属冲压印记必须准确、完整，且附带商标或制造商的名称。

- 贵金属

| 金属 | 普通冲压印记 |
| --- | --- |
| 黄金 | 6k、9k、10k、14k、18k、22k、24k |
| 银 | 纯银、925、999、500 |
| 铂金 | Plat、950Plat、PT950 |

- 电镀贵重金属/镀金银饰：

**注意： **美国和加拿大规定了商品成为镀金产品需达到的最低镀金层厚度（随使用的电镀方法而异）和贵重金属的纯度。如果商品具有贵重金属基底，冲压印记应反映贵重金属基底。

| 金属 | 冲压印记 |
| --- | --- |
| 镀金纯银 | 0.925 |
| 镀铑黄金 | 14K |

**注意： **如果您不太确定镀金银饰是什么，FTC 法规的定义如下：如果行业商品包含镀有纯银的基底或在重要表面镀有黄金或镀有含量不低于 10k 的金合金，且全方位电镀厚度等于 2.5 微米（约等于100/1,000,000 英寸）纯金，则商品可被描述或标注为银镀金。

- 有镀层的基底金属/镀金金属

**注意： **镀有贵金属的基底金属无需压印印记。

| 金属 | 冲压印记 |
| --- | --- |
| 镀金黄铜 | 无 |
| 镀银基底 | 无 |

**重要： **对于采用高级金属和基底金属的多金属构件，商品描述必须准确地注明商品的哪一部分具有哪种金属。

## 1.5 金属重量

为您商品提供误差不超过 5% 的最小金属重量。您商品的最小金属重量应该包括珠宝首饰商品的所有部件，如耳饰背扣、耳针、吊坠和链条。不同的指环大小可能有不同的金属重量。

## 1.6 金属镀层和含多种金属的商品

- 除非金属镀层的纯度为 24K 金、925 银或 950PT，否则必须公开金属镀层的纯度。

- 如果镀有铑，则必须公开这一信息。

- 必须按其相对重量的顺序列出贵金属（例如，“铂银戒指”表示铂金的含量多于银）。但是，如果使用了镀层或限定词，也可以按反序列出贵金属（例如，允许使用“镀铂金的银戒指）。

## 1.7 低过敏性标准

请勿将珠宝首饰商品描述为“低过敏性”，除非它满足以下要求：

- 不含镍、钴和其他致敏物质。

- 纯金属（如铂金、医用钢、纯银，或不低于 18K 的黄金）。

- 您有充分且可靠的科学证据，表明商品材质在导致过敏反应的可能性上与纯金属无异。不得将包含钨、不锈钢和镍镀纯银等的珠宝首饰描述为低过敏性。

## 1.8 变体关系

所有父 ASIN 和子 ASIN 的关系必须符合[变体关系概览](https://sellercentral.amazon.com/gp/help/external/G8831)帮助页面中列出的亚马逊变体关系指南。具体而言，父 ASIN 信息（包括商品名称）必须代表核心商品并准确描述与之有父子关系的所有子 ASIN。

## 1.9 儿童珠宝首饰

所有儿童珠宝首饰必须遵守所有联邦法律和法规，包括[《消费品安全改进法案》(CPSIA)](http://www.cpsc.gov/en/regulations-laws--standards/statutes/the-consumer-product-safety-improvement-act/)、[《加拿大消费品安全法案》](http://laws-lois.justice.gc.ca/eng/acts/C-1.68/)、[《儿童珠宝首饰法规》](http://laws-lois.justice.gc.ca/eng/regulations/SOR-2016-168/index.html)、[《表面涂层材料法规》](http://laws-lois.justice.gc.ca/eng/regulations/SOR-2016-193/page-1.html)，以及最严格的美国国家法律和加拿大省级法规。

## 2. 设计要求

## 2.1 总则

- 使用一个 ASIN 提供的所有商品必须在设计、构造、颜色、表面处理方面保持一致，宝石必须达到宝石指南中规定的标准（参见“珍珠和彩色宝石标准”）。

- 戒圈厚度必须足以支撑适度的手施压力。建议的最小厚度为 0.8 毫米，侧面厚度为 1.4 毫米，但必须与首饰的风格协调。

- 所有珠宝首饰必须具有精致的外观，包括功能部件（搭扣、耳扣等）。商品不应缺失任何可拆下的部件（如耳扣），并应完全能够轻松使用。

## 2.2 测量

- 戒指大小的容差范围是不得比详情页面上规定的尺码高出 1/4 且不得比其小 1/8。如果戒环较窄，可在前缘处测量大小；如果戒指较宽，可在戒圈中心处测量大小。

- 项链和手链长度的容差范围即装箱单/发票上标注的 + ¼ 英寸，以扣接后的可用长度为准，测量时容差为零。这是因为线上买家期望链子长度不低于他们所订购的长度。宽度必须与装箱单/发票上的毫米测量值匹配一致。手镯从内缘处进行测量，容差范围同样是 + ¼ 英寸，测量时容差为零。为了确保测量准确度，我们建议您使用弹性塑料尺，例如 Franklin Planner 记事本和 Filofax Organizer 活页笔记本所附带的软尺。

## 2.3铸造件和结构

- 从 12 英寸的“半臂”距离处观察，任何数量或位置的肉眼可见孔隙或孔洞都属于严重缺陷。

- 铸造件不得存在气泡产生的闪光现象或多余金属。

- 所有焊接珠宝首饰必须采用相似纯度，且不得有变色。不得有开缝、开裂、未填充的区域、断裂或过多焊料。

- 焊料不得焊死任何可以移动的配件（例如链索）。

- 从顶部或侧面观察时，环形头必须是平直的。

- 艺术加工必须对称、光洁。

## 2.4 磨光和抛光

- 如果订购的商品为磨光产品，则金属表面应高度磨光，且没有肉眼可见的刮痕或刀痕。设计细节必须光洁、独特。

- 如果订购了特殊抛光处理，如锻光、磨毛、哑光等，则必须均匀进行抛光处理，且如果与其他抛光处理结合进行，不得与周围非指定区域重叠。

- 所有商品必须光洁、干燥，不含指纹、油渍或残余的抛光铁丹。

- 不允许磨光轮/布的线头残留于爪托下。

- 电镀表面（如 18k 镀铑白金）的颜色应保持均匀一致，不得存在剥落、断裂或锈污迹象。

## 2.5 宝石镶嵌

- 任何种类的粗糙宝石均被视为缺陷。用镶嵌测试机测试宝石的牢固度，并使用镊子测试镶嵌的稳固性。

- 宝石必须放平，且高度按设计保持一致。

- 爪托必须在形状、长度和位置方面保持一致。爪托和宝石之间不应存在间隙。

- 金属托必须光滑整洁，厚度均匀，且与它们固定的宝石大小相协调，金属托和宝石之间不得存在间隙。

- 在夹镶中，宝石面必须位于同一平面中，或按设计沿一定曲线。槽缝壁应保持平整、光滑，且依照宝石腰棱均匀开槽。宝石应连腰逐一嵌入。

- 上钻时不应露出底面。有些设计可能要求露出底面，但是不应在佩戴或取下饰品时感受到底面。

- 珍珠类首饰（如耳饰、戒指、手镯、搭扣等）必须为每颗珍珠设计一个托座和针（或至少有一个针，具体视设计/布局而定），并将半打孔珍珠用环氧树脂胶粘到托座和针上。

- 可对珍珠、镶嵌和一些不透明的圆宝石（如缟玛瑙、翡翠等）使用环氧树脂胶或胶水，但不得在亚宝石或宝石中使用。

## 2.6 首饰用具

- 具有可移动部件的首饰用具必须完全实用，使用期间不会存在明显勒紧感，且持久耐用，能经受反复使用的考验。

- 首饰用具的大小和重量必须与首饰协调。

- 吊坠托必须足够大，允使吊坠能在链条上自由摆动。如果链条不随附吊坠一同出售，则吊坠托必须足够大，能容纳买家常用的各种链条。

- 耳针必须足够坚固，能够承受正常使用的考验，且耳针末端必须圆润光滑。耳钩和耳扣应使用顺手，牢固扣合。耳针应具有大约 9.5 毫米或 3/8 英寸的可用长度，且其厚度大约为 70 毫米（+/- .04 毫米），视其设计/类型而定。

- 具有桶形或盒状钩扣的手链必须至少达到 8 级安全标准。

## 3. 珍珠和彩色宝石标准

## 3.1 总则

- 无论金属类型为何，使用的任何宝石都必须达到本部分列出的标准。

- 按照亚马逊的要求，所有珠宝首饰类商品均须符合 GIA 制定的国际评级标准。这适用于所有商品名称、商品描述和商品规格。

- 宝石的色彩范围不得超出两种饱和度色调。

- 如果应用了新宝石、有机材质或处理工艺，卖家须提供一份 GIA 鉴定报告以证明其真实性。

- 仅接受稳定永久的处理和优化。必须以全面、充分的方式公开所有处理和优化，并且可能需要对处理稳定度进行单独检验。不接受玻璃填注或其他非永久性处理或优化。增强型彩色宝石的商品信息必须包含宝石制作、宝石处理和宝石护理方法。

- 必须在商品详情页面上充分、全面地公开珍珠制作方法（即天然、培植还是仿制/合成）。可能需要对制作方法进行单独检验。天然珍珠的生成不能有任何人为的促成因素。培植珍珠的培植方法是人为地在贝壳或软体动物体内植入一粒残骸，使其不断覆上珍珠母。仿制或合成珍珠是在外观上仿制珍珠或培植珍珠的人工制成品。

- 仅可在能够证实的情况下才能声明宝石的原产地（例如锡兰蓝宝石）；即便如此，也仅可在此地理位置是宝石的开采地区时才可使用其名称。亚马逊可能要求提供经卖家署名的宝石原产地声明，以验证产地。而且，如果注明了未经处理，亚马逊可能会要求卖家签署一份文件来证实未经处理，而且亚马逊可能会要求为样品提供一份 GIA 实验室报告作为证据。

- 使用肉眼观察标准对宝石进行评估。小型放大镜仅用于缺陷澄清目的。

- 宝石不得存在划痕、抛光纹、碎屑、裂痕和磨痕。不得有任何明显的缺陷。

- 宝石必须保持对称且妥善切割。刻面和深度必须与材料的直径、形状和类型协调，且必须在整个配送期间保持一致。宝石的腰棱必须已经过磨光。

- 确保将制作方法（例如，实验室制造、仿制、合成或人造）标注于所有非天然宝石、诞生石、珍珠和钻石的名称之前。

- 为所有宝石商品提供准确的最小重量、切工、净度和若干宝石属性。

- 确保所有珍珠属性（包括珍珠尺寸、形状、铸流长度、颜色等）的准确性。

## 4. 钻石标准

钻石必须达到以下特定的钻石标准：

- 如果商品所含宝石来自与民事冲突、犯罪活动或恐怖活动相关的来源，则亚马逊禁止卖家销售此类商品。在亚马逊上销售即表示您声明并保证您不会蓄意购买或销售与此类活动存在关联的任何宝石。

- 按照亚马逊的要求，珠宝首饰类的所有商品均须符合 GIA 制定的国际评级标准。这适用于所有商品名称、商品描述和商品规格。

- 激光钻孔、裂隙填充、透明度强化或其他任何处理都不可接受。增强型彩色宝石的商品信息必须包含宝石制作、宝石处理和宝石护理方法。

- 钻石颜色将通过与 GIA 比色石的直接对比来确定。

- 钻石重量将通过直接称重或重量估算公式进行验证。采用小数表示钻石重量时，应精确到小数点后两位。例如，0.47 克拉表示重量至少为 0.465 克拉。采用分数表示钻石重量时，克拉重量容差范围如下所示： 

| 克拉重量 | 向上舍入所需的最小实际克拉重量 |
| --- | --- |
| 1/10 | 0.09 |
| 1/5 | 0.18 |
| 1/4 | 0.23 |
| 1/3 | 0.30 |
| 3/8 | 0.37 |
| 1/2 | 0.46 |
| 5/8 | 0.59 |
| 3/4 | 0.71 |
| 1 | 0.96 |
| 1 ¼ | 1.22 |
| 1 ½ | 1.45 |
| 1 ¾ | 1.70 |
| 2 | 1.95 |
| 2 ½ | 2.45 |
| 3 | 2.95 |

- 所有钻石必须至少具有 17 个磨光对称刻面，且卖家发布的商品中不得包含描述为钻石但未达到此标准的宝石。

亚马逊不接受以下类型的钻石：

- 具有极厚或极薄腰棱的钻石。

- 大底面的钻石。

- 含有开腔式内含物的钻石。

- 影响腰棱轮廓或经过评估存在镶嵌风险的天然宝石。

- 内含物的尺寸、性质和位置导致钻石结构不够合理，以致钻石不适合安装或佩戴的钻石。

- 10 倍放大下可轻易看到划痕、碎屑、烧灼面或磨光痕的钻石。

- 有重大对称缺陷的钻石。

## 5. 钻石等级报告或真品证书

亚马逊要求卖家为以下商品所含的任何纯度和颜色（黑色钻石除外）的天然或实验室制造的钻石提供钻石等级报告（或真品证书）：

- 钻石耳钉：如果耳钉中心宝石的标注总重量大于 1.0 克拉，亚马逊会要求卖家提供等级报告。

- 耳环或吊坠：如果中心宝石的标注重量为 ¾ 克拉或更大，亚马逊会要求卖家提供等级报告。如果侧石的标注重量为 ½ 克拉或更大，则还需附有证书且必须包含在中心宝石的证书中。

我们仅接受以下四个认证机构之一提供的真品证书或钻石等级报告：GIA、IGI、AGS 和 GCAL。

- 所有等级报告必须表明，钻石的克拉重量、纯度、颜色和切割达到或超出了您的商品在亚马逊网站上的声明。

- 必须在等级报告上完整、充分地公开所有提升处理。

- 等级报告上必须明确说明制作方法。

## 6. 独立的实验室检测

亚马逊可能会不定期请求提供、购买在珠宝首饰分类中销售的商品或对其追根溯源，以进行质量保证检测。亚马逊可能会将这些商品提交到获得认可的独立珠宝首饰检测实验室，以进行彻底的质量检测。亚马逊也可能会要求珠宝首饰供应商与某些指定的实验室合作进行质量检测。在请求提供或购买时，实验室会测试商品是否符合亚马逊商品描述，以及是否符合“亚马逊珠宝首饰质量保证标准”。亚马逊可能会向适用卖家退还因这些目的购买的任何商品。

如果珠宝首饰未通过质量测试，亚马逊将联系卖家。根据未通过测试的商品数量及其问题的严重程度和类型，亚马逊将采取进一步的行动，包括（但不限于）与卖家共同制订补救计划以解决问题的根本原因、退还从卖家处购买的部分或全部库存（由卖家承担费用）、暂停或终止卖家在珠宝首饰分类或在亚马逊上销售商品的权限。
