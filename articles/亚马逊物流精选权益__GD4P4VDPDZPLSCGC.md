# 亚马逊物流精选权益

## 权益
FBA Select 可减少您的供应链成本，并将库存放在离买家更近的位置，从而提升配送速度。该计划提供合并的入库计划、免除已注册 ASIN 费用以及在旺季提供提前预留的容量和接收预约等权益。

这些权益仅适用于已注册 ASIN。

要了解有关亚马逊物流精选计划的更多信息，请参阅[亚马逊物流精选计划概览](https://sellercentral.amazon.com/help/hub/reference/G3G48PC5AVRABQNV)。

## 配送速度和销售转化率权益
1. 【更快的配送速度承诺】： 通过协作式计划，亚马逊将您的库存安排在那些对您 ASIN 需求集中的地区，使其距离买家更近。此战略布局可让次日达和当日达配送承诺覆盖更大规模的客户群体，该计划旨在让您最畅销的 ASIN 实现业界领先的配送速度。
2. 【提高商品曝光率】： 显示次日达或当日达配送承诺的商品更有可能提高被买家发现的几率，并提高您成为推荐报价的机会。更快的配送标记可提高点击率和购买可能性。

## 成本降低权益
1. 【无入库配置服务费 (IPSF)】： FBA Select 货件将自动创建，无需支付入库配置服务费，因为我们正在就货件体积、频率和地点与您合作。这将在注册时立即应用。
2. 【运输成本降低】： 每周发往 2~3 个区域的整合货件可实现整车运输和整箱装载配送，从而降低发往 FBA 的入库货件的每件商品的运输成本。

## 容量和计划权益
1. 【提前预留亚马逊物流仓储容量】： 亚马逊会为您的 FBA Select 货件预留仓储空间，确保即使在 Prime 会员日或第 4 季度假日季等高需求时段，卖家也能获得仓储空间。我们将调整您的 FBA 容量限制，以确保您可以根据 FBA Select 入库计划将所需数量送入库房。这意味着您的容量限制将反映您的预测、供应链配置（备货时间或卡车容量），并在最重要的时段保持稳定供应。
2. 【减少接收节点】： 您的 FBA Select 货件将被合并，并仅发送至您可在配置设置页面上找到的预定节点。FBA Select 计划在美国 5 个地区使用约 15 个指定的亚马逊接收节点。FBA Select 计划会将您的货件合并发往少量预定目的地，而非将货件拆分发往多个目的地。未来 13 周内，您账户中的这些目的地将保持不变。目的地更少，意味着物流协调工作更简单，运输成本更低，团队的管理开支也更少。
3. 【在配送时段内预留可用预约名额】： 亚马逊会为您的 FBA Select 货件预留入库容量，确保能够在您的送达时段内提供预约服务，即使在 Prime 会员日和假日季等高峰期也不例外。您的承运人在约定的时段内通过卖家平台预约。

【OOO 卖家注意事项】： 国际货件的送达时段可延长 1 周，以应对海运时效的不确定性和海关清关情况。

## 关键注意事项
- 目的地地区不同，海运备货时间也大不相同
- 清关可能会增加不可预测的延迟
- 您的客户成功经理将在 90 天的试用期内与您合作，以了解您的常用运输时间并相应调整预期时间

## 在试用期内
我们将追踪您的货件模式，并与您合作，为您的供应链确定正确的备货时间配置。通过此试用期，我们可以针对您的国际配送业务优化计划设置。
