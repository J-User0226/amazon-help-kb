# 业务规划工具概述

[业务规划工具](https://www.sellercentral.amazon.com/business-planner)旨在帮助您制定有效的行动计划，推动销售额增长和节约成本。无论您是新手卖家，还是成熟品牌，我们的业务规划工具都能为您量身定制目标和建议，助您走向成功。

**注意： ** 业务规划工具目前是早期版本，我们正在根据用户反馈积极扩展其功能。在此阶段，您只能接受建议的目标，我们正在评估和改进体验，添加新的目标类型和目标创建的灵活设置，从而更好地满足您的业务需求。

**目标类型**

业务规划工具的核心是设定目标，制定行动计划。您可以跨时间段创建目标，专注特定领域，例如通过广告提高销售额或降低成本等。您可以调整时间范围、目标指标以及任何相关限制，我们的业务规划工具将为您提供量身定制的建议，帮助您实现目标。

**可用目标**

| 目标 | 描述 |
| --- | --- |
| 通过营销提高销售额 | 为了提高亚马逊商城的销售额，请通过各种计划优化广告，例如商品推广、品牌推广、展示型推广广告，Z 划算和秒杀活动。关键步骤包括调整预算、调整定向、测试创意、利用不同的格式和确定热门特惠。这些策略可提高买家数量、增加品牌曝光度，并提升整体销售额。 |
| 通过提高商品推广广告展示次数来提高流量 | 此目标是通过提高您的商品推广广告展示次数来提高流量。针对此目标的建议可能包括：调整各个 ASIN 的关键词、竞价和预算，启动新的广告活动，以及改进现有广告活动。 |
| 通过优化库存降低成本 | 此目标旨在通过优化您的库存管理实践来降低业务成本，尤其注重提高您的库存绩效指标分数。针对此目标的建议可能包括：调整订单数量、优化库存水平、识别和处理周转缓慢库存或冗余库存，以及实施策略来提高库存绩效指标分数。有效的库存优化可帮助您降低仓储费、降低缺货风险、提高整体盈利能力。 |
| 通过推荐报价提高销售额 | 此目标在于通过提高您在亚马逊商品详情页面赢得推荐报价展示位的可能性，来推动销售额增长。针对此目标的建议可能包括：定价策略、库存管理策略，以及优化您的商品信息，以增加赢得推荐报价的几率。提高赢得推荐报价的几率可以提高您的商品在亚马逊商城的曝光率、转化率和整体销售额。 |

**系统如何为您推荐目标？**

系统根据类似群体的绩效为您推荐目标，这些群体是一群具有相似特征（例如企业规模、商品分类或销售额）的卖家。通过分析这些群体的绩效，我们可以推荐既具有一些挑战又切实可行的目标，帮助您在类似企业取得成功的领域取得进步。

**反馈和合作**

我们非常重视您的意见！ 您可以在系统界面左上角业务规划工具旁边找到提供反馈之处，或使用“赞/踩”功能就我们推荐的目标提供反馈。如果您有其他建议或需要进一步的帮助，请通过卖家支持或论坛联系我们。

**开始规划**

准备好将您的业务提升到新的高度？ 立即使用我们的业务规划工具，开始规划您的行动。自定义您的目标，查看我们的建议，并解锁您的发展潜力。
