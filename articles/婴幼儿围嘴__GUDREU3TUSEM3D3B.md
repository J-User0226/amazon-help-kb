# 婴幼儿围嘴

如果您要在亚马逊商城发布商品，则必须遵守与这些商品和商品信息发布相关的所有适用法律、法规、标准以及我们的政策。

## 本政策适用的婴幼儿围嘴

婴幼儿围嘴是一种系在婴幼儿脖子上的衣物，有助于保护其皮肤和衣服免遭过多唾液、外溢食物和饮料弄脏。围嘴通常由防水布、塑料、橡胶或硅胶制成，也有不同的款式，包括头巾、围巾、罩衣、围裙和工作服。罩衣、围裙和工作服的袖子通常具有带底边或凹槽的袖子，有些还被设计成可以覆盖或围住高脚椅的座位，以便收集食物残渣。

## 我们关于婴幼儿围嘴的政策

亚马逊要求所有婴幼儿围嘴均经过检测并符合下列法规、标准和要求：

| 商品 | 法规、标准和要求 |
| --- | --- |
| 婴幼儿围嘴 | 以下所有法规： 《消费品安全改进法》（铅、邻苯二甲酸盐） 消费品安全法第 14(a)(5) 节（追踪标签） 《美国联邦法规》第 16 卷第 1501 部分（小零件检测）（如适用） |
| 以下任意一项（如适用）： 《美国联邦法规》第 16 卷第 1610 部分（如适用）（服装纺织品的易燃性）；或 《美国联邦法规》第 16 卷第 1611 部分（如适用）（乙烯薄膜的易燃性） | |

**注意： **您向亚马逊提供的所有文件、检测报告或证书必须真实且采用原始格式（即未经修改）。
