# TikTok Shop 订单的多渠道配送促销

## 促销详情

借助多渠道配送 (MCF) 拓展您的业务。通过多渠道配送 TikTok Shop 促销，对于归属于 TikTok Shop 且通过多渠道配送处理的订单，您可以享受多渠道配送出库配送费用的优惠。自 2026 年 7 月 16 日起，在符合以下资格条件并完成以下步骤的前提下，此 12 个月促销适用于美国的 TikTok Shop 订单。有关这些条款和条件的更多信息，请参阅[多渠道配送 TikTok Shop 促销条款和条件](https://sellercentral.amazon.com/help/hub/reference/GCDSVEG8J82SGDRG)帮助页面。

符合要求的卖家可享受 TikTok Shop 订单多渠道配送出库配送费用 35% 的折扣。无需注册，费率会自动适用于在提交时被识别为 TikTok Shop 的任何订单。

## 如何获取资格

要享受此促销，您的 TikTok Shop 订单必须通过受支持的集成提交至多渠道配送，且该集成必须在提交订单时标识 TikTok Shop 渠道。以下是支持的方式：

- 您通过多渠道配送来配送 TikTok 商店订单所使用的受支持第三方集成方式 (ISV)。有关受支持集成方式的列表，请参阅 [TikTok 商店促销](https://supplychain.amazon.com/blog/tiktok-shop-promotion)。

- 与多渠道配送的销售伙伴 API (SP-API) 直接集成，前提是该合作伙伴的集成已获得亚马逊批准。

- 适用于 Shopify 的[亚马逊多渠道配送和 Buy with Prime](https://apps.shopify.com/buy-with-prime) 应用。

- 卖家平台中的多渠道销售工具。在多渠道设置中关联您的 TikTok 商店渠道。您的 TikTok 商店订单会同步到“【管理订单】”页面，您可以通过多渠道配送来配送这些订单，并自动享受促销。您在卖家平台手动创建的订单不符合条件，因为手动输入的订单无法确认为 TikTok 商店订单。

如果您通过受支持的集成方式来配送 TikTok 商店订单，或者通过卖家平台的多渠道设置关联您的渠道来配送这些订单，则可自动享受促销。要查找并关联受支持的集成方式，请前往[多渠道配送集成](https://sellercentral.amazon.com/mcf/integration-selection-tool)页面。

## 关于促销的常见问题

#### 我需要注册参与 TikTok Shop 促销吗？

不。无需注册，也没有“注册”按钮。只要您的 TikTok Shop 订单通过可标识 TikTok Shop 渠道的受支持集成提交至多渠道配送，35% 的折扣就会自动适用。

#### 折扣是多少？ 如何将折扣应用于我的订单？

在发货时生效的多渠道配送出库配送费用可享受 35% 的折扣。根据上述集成说明，折扣将自动适用于归属于 TikTok Shop 的订单，无论是标准配送速度还是加急配送速度。

#### 我可以在哪里查看收到的促销？

- 前往[多渠道配送控制面板](https://www.sellercentral.amazon.com/custom-analytics/dashboard/multi-channel-fulfillment-dashboard)。

- 导航至【报告】 > 【分析】 > 【亚马逊精选的控制面板】 > 【查看全部】 > 【多渠道配送】。您可以在控制面板上查看您收到的总优惠金额。

- 向下滚动以查看 TikTok Shop 折扣优惠表，其中按订单和货件粒度详细显示您收到的优惠金额，以及在 TikTok Shop 优惠下享受折扣的商品数量。请注意，数据可能会延迟 24~48 小时。

#### 为什么我的 TikTok Shop 订单未享受促销？

最常见的原因包括如下：

- 订单是在卖家平台中手动创建的（手动订单不符合要求）。

- 提交订单时，您使用的集成未标识 TikTok Shop 渠道。

请确认您的 TikTok Shop 订单通过受支持的集成提交。如果您使用第三方集成，请向您的服务提供商确认，对方是否会在您的订单中传递 TikTok Shop 渠道信息。如果订单已正确提交，但仍未获得折扣，请联系[销售伙伴支持](https://sellercentral.amazon.com/help/center)。

#### 我在卖家平台中手动创建的订单是否能够享受促销？

不能。手动创建的订单不符合要求，因为无法确认手动订单是否来自 TikTok Shop。要享受折扣，请通过受支持的集成方式来配送 TikTok 商店订单，或者通过卖家平台的多渠道设置关联您的 TikTok 商店渠道来配送这些订单。

#### 我的 TikTok Shop 订单可以获得亚马逊物流抵免额度吗？

不可以。TikTok Shop 折扣仅限配送费用折扣，不包括亚马逊物流抵免额度。

#### TikTok Shop 促销如何与优选定价计划结合使用？

如果您还参加多渠道配送 2026 年优选定价计划，以下说明这两项计划如何共同适用：

- 对于被标识为 TikTok 商店订单的订单，可享受 TikTok 商店促销，而非为此订单提供的适用优选定价折扣。

- 对于未被标识为 TikTok 商店订单的订单，仍将适用相应优选定价折扣。

- 为处理 TikTok Shop 订单而发出的多渠道配送商品数量计入用于确定您优选定价折扣的商品数量阈值计算，但不会从您优选定价的商品数量上限或亚马逊物流抵免额度上限中扣减，且 TikTok Shop 订单不会获得亚马逊物流抵免额度。

#### TikTok Shop 订单还享受哪些其他权益？

对于预计送达时间超过三个工作日的 TikTok Shop 渠道订单，我们将加快配送速度（承运人派送），以满足两个工作日派送政策。这适用于符合以下条件的订单：商品不是重型大件商品，配送目的地位于美国本土 48 个州，且没有承运人限制。我们还会在[卖家平台](https://www.sellercentral.amazon.com/custom-analytics/dashboard/multi-channel-fulfillment-dashboard)和[亚马逊供应链服务控制台的](https://scp.supplychain.amazon.com/custom-analytics/dashboard/multi-channel-fulfillment-dashboard)定制分析控制面板中为 TikTok 商店订单提供一个绩效控制面板。

#### TikTok Shop 货件或订单获得此促销是否有数量限制？

没有。根据集成说明归属于 TikTok Shop 的所有符合要求的订单都将获得此促销。

#### 此促销何时到期？

预计此促销将持续 12 个月。亚马逊保留随时修改、暂停或终止此促销任何部分（包括每个卖家的资格和参与状态）的权利，恕不另行通知，且此促销仅适用于配送至美国境内地址的商品。

要了解有关优选定价的更多信息，请参阅[多渠道配送 2026 年优选定价计划](https://sellercentral.amazon.com/help/hub/reference/G53QRBEHXR2G5CCT)帮助页面。
