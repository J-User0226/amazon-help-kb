# 照明类重要商品特征

详情页面上的重要商品特性要点有助于买家了解商品的详细情况，影响到他的购买决策。





- 突出展示您希望买家考虑的五个关键特点，比如尺寸、适龄性、商品的理想条件、技能水平、成分含量、原产地等。




- 保持一致的顺序。 如果您的第一个商品要点是原产地，那么请为所有的商品保持相同的顺序




- 重申商品名称和说明中的重要信息




- 请在每条要点开头使用大写




- 写短句，末尾不加标点




- 请勿包含促销和价格信息




- 请勿包含配送或公司信息。  亚马逊的政策禁止包含卖家、公司或配送信息




- 特性要点有助于买家评估商品，任何与商品无关的信息都会干扰买家的购买决策。









| 内容 | 示例：特性要点 |
| --- | --- |
| 材料/表面处理 | 拉丝镍，镀铬 黑色漆面 |
| 安规认证 | UL 湿润环境列名 能源之星合规 |
| 灯泡规格 | 使用 2 x 40W 枝形烛台底座灯泡 使用 60W 白炽灯泡（未含） 内含 26W 灯，寿命 10,000 小时 |
| 安装 | 半嵌入式安装 |
| 原产地 | 中国制造，美国制造 |
| 度量衡 | 实际尺寸：长：13 英寸；宽：13 英寸；高：3-1/8 英寸 |
| 质保信息 | 凭购买凭证享受 1 年制造商保修 |
| 其他 | 须装配，注意警示 |





买家使用这部分获取商品快照。他们可能使用这部分确定购买决定，或它足够有吸引力他们以便他们会阅读完整的商品描述。





## 改善可读性的小窍门





**建议：**





- 将所有数字写成阿拉伯数字




- 用分号将一个特性要点中的短语隔开




- 拼写出测量单位，例如 quart、inch、feet 等





**不建议：**





- 使用破折号、符号、句号或感叹标点




- 表达含糊。须尽可能具体说明商品特性和属性




- 输入公司具体信息。该板块只对应商品特性
