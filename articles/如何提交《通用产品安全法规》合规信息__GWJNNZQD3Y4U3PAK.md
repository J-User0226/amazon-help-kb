# 如何提交《通用产品安全法规》合规信息

**此帮助页面仅适用于有资格在欧盟亚马逊 Haul 上发布商品的卖家使用。**

要遵守适用于大多数非食品消费类商品的[《通用产品安全法规》(GPSR)](https://sellercentral.amazon.com/gp/help/external/GKAYGH3A6AK84BEX) 政策，您需要：
- 在欧盟拥有针对这些相关商品的负责人
- 商品标签上标有负责人的联系信息
- 商品标签上标有制造商的联系信息以及任何警告和安全信息

此外，您还必须在卖家平台上提交商品标签上显示的信息。

## 如何向亚马逊提交您的信息
您必须在“账户状况”页面上提交所需信息。制造商和负责人信息可以批量提交，但对于各 ASIN 需要单独提交警告和安全图片和文件。请注意，只要欧盟设有负责人，您的制造商可以分布在任何国家/地区。

要添加新信息，请按照以下步骤操作：
1. 前往“账户状况”页面上的[商品政策合规性](https://sellercentral.amazon.com/performance/account/health/product-policies?t=regulatory-compliance)。
2. 前往【打开】选项卡。
3. 在【受影响的项目】列中，您将看到需要提供信息的商品名称、ASIN 和 SKU 组合。然后，在【原因】列中，您将看到所需信息的类型，即“通用产品安全法规 - 制造商联系详情”“通用产品安全法规 - 负责人联系详情”或“通用产品安全法规 - 警告和安全信息”。您可以点击【添加其他筛选条件】，然后选择【亚马逊 Haul 店铺商品信息】。
4. 在【后续步骤】列中，点击【提交】。
5. 按照小部件中的步骤进行操作，为表格中的每一行输入信息（可能有多页）。
  - 如果表格行对应的是某个品牌，您可以选择之前提供的制造商和负责人信息，也可以添加新信息。然后，您必须选择要提交的信息，并点击【保存】。
  - 对于警告和安全信息，您可以选择以 PDF 格式上传商品文件，通过图片管理器上传最多六张图片，或者提交一份安全证明（该选项仅适用于特定商品）。在语言下拉菜单中，选择文件或图片的主语言，该语言需要采用销售国家/地区的官方语言。选择选项后，点击【保存】。

**注意： **如果您的负责人位于北爱尔兰，就必须在国家/地区字段选择**英国**，并在其中一个地址字段中添加以下郡之一： 安特里姆、阿马、德里/伦敦德里、唐郡、弗马纳或蒂龙。

**验证**

您的信息可能最多需要 7 天才能得到验证。一旦您提交的信息在小部件中被标记为【有效】，只要已发布的商品没有其他问题，“账户状况”中“商品政策合规性”页面中对应的表格行信息就会移至【已存档】选项卡。如果在提交的内容被标记为有效后的 48 小时内，该表格行信息未移至【已存档】选项卡，请按照[解决亚马逊 Haul 商品非在售](https://sellercentral.amazon.com/gp/help/external/GXAUGKFRDR7FMLM5)页面中的步骤解决尚未解决的问题。

如果制造商和负责人提交的信息在小部件中被标记为【无效】，请按照【后续步骤】列中的步骤更正错误。

如果文件被拒绝，请执行以下步骤：
1. 前往【绩效】选项卡，然后选择【账户状况】。
2. 在【政策合规性】下，点击【监管合规性】，以查看您的所有有效的请求和拒绝原因。
3. 点击【添加其他筛选条件】，然后选择【亚马逊 Haul】。
4. 如果您想搜索特定商品，请在搜索栏中输入 ASIN 或 SKU。
5. 找到您想要查看的被拒绝的文件。
6. 点击【提交】以查看特定商品的拒绝情况。
7. 在打开的弹出窗口中，点击以同一文件类型【上传文件】，以上传新文件。
8. 点击【提交】，发送您提交的内容以供审核。

**注意： **要对被拒绝的文件提出申诉，请与您的亚马逊 Haul 合规性账户经理 (AM) 联系。如果您不确定您的亚马逊 Haul 合规性账户经理是谁，请发送邮件至 [Haul-Compliance-Queries@amazon.com](mailto:Haul-Compliance-Queries@amazon.com)。

要查看图片上传的状态，您还可以前往图片管理器中的“提交”状态或“图片管理器”选项卡。除了标准拒绝原因，如果为遵守《通用产品安全法规》而在商品安全 (PS) 变体下上传的图片使用了错误的语言，或者无法阅读，我们可能会将其删除。要了解有关图片拒绝原因的更多信息，请参阅[图片问题](https://sellercentral.amazon.com/gp/help/external/GT8RSE9S9NK4LP6Z)。要替换图片，请按照[上传图片](https://sellercentral.amazon.com/gp/help/external/GUGPCYWV2P8KVFUT)中的说明操作（您必须使用 PS01~PS06 变体）。

**如何编辑已有的制造商或负责人信息（不包括电子邮件地址）**

1. 前往【已存档】选项卡。
2. 在【受影响的项目】列中，您将看到需要提供信息的商品名称、ASIN 和 SKU 组合。然后，在【原因】列中，您将看到所需信息的类型，即“通用产品安全法规 - 制造商联系详情”“通用产品安全法规 - 负责人联系详情”或“通用产品安全法规 - 警告和安全信息”。
3. 在【后续步骤】列中，对于制造商联系详情和负责人的联系详情，请点击【查看或更新】。
4. 您上次提交的信息将在小部件中突出显示。如果您想要编辑提交的信息，请点击【编辑】。如果您想要编辑其他提交信息，请找到包含相关提交内容的方框，然后点击【编辑】。
5. 根据需要进行编辑。
6. 选择您想要使用的提交信息，然后点击【保存】。如果您已上传制造商和负责人信息，那么只需要几分钟，就可以在小部件中看到验证状态。
7. 如果提交的信息被标记为【有效】，则“账户状况”中“商品政策合规性”页面上对应的表格行信息将保留在【已存档】选项卡中。
8. 如果提交的信息在小部件中被标记为【无效】，它将移至【未解决】选项卡，您需要编辑提交的信息以更正错误。

**注意： **目前无法更新制造商的电子邮件地址。如果需要更改电子邮件地址，请与您的亚马逊 Haul 合规性账户经理 (AM) 联系。如果您不确定您的亚马逊 Haul 合规性账户经理是谁，请发送邮件至 [Haul-Compliance-Queries@amazon.com](mailto:Haul-Compliance-Queries@amazon.com)。
