# 销量卡

【销量】卡显示了您业务（包括亚马逊物流和卖家自配送）的最新销量统计数据和销量对比情况，您可以按日期、销售额和销售的商品数量筛选结果。

关键定义：

| 字段名 | 定义 |
| --- | --- |
| 已订购商品数量 | 在指定时间范围内订购的商品总数量 |
| 每个订单的平均商品数量 | 商品数量除以包含此商品的订单总数 |
| 平均销售价格 | 您的销售额除以售出的商品数量 |
| 销售额 | 商品价格乘以订购的商品数量 注意： 销售额不包括已订购的礼品包装费总额或已订购的运费总额。 |
| 销量排行 | 您的销量相对于此 ASIN 的总销量的排名，其中近期销量所占的比重更大。 |
