# 错误 95105

## 错误消息

“状况说明”字段中的值 ${attribute_value} 无效。状况说明中不能包含电子邮件地址或网站信息。请从此字段中移除无效值，然后重新提交商品信息。

## 导致错误 95105 的原因

出现此错误的原因如下：

- 状况说明中包含电子邮件地址、电话号码或社交媒体入口等外部联系信息。

- 状况说明描述中显示有网站 URL、商城链接或外部平台引用。

- “状况说明”字段包含外部联系方式或促销链接，而不是描述商品状况。

## 解决错误 95105

要解决此错误，请按照以下步骤操作：

- 从“状况说明”字段中移除所有电子邮件地址，并将其替换为商品物理状况的描述。

- 从“状况说明”字段中删除任何网站 URL、域名或 Web 链接。

- 检查整个“状况说明”文本，确保没有包含联系信息或外部引用，包括社交媒体入口或电话号码。

- 对“状况说明”字段进行必要更正后，重新提交此商品信息
