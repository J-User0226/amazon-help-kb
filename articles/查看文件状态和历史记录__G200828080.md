# 查看文件状态和历史记录

## 创建退货属性调整文件

下载 [SKU 调整模板](https://images-na.ssl-images-amazon.com/images/G/01/rainier/help/ff/Flat.File.ReturnRequestAuthorization.xlsx)，并使用此模板创建您的退货属性调整文件。

退货属性调整文件包含一个 SKU 列表及其相关的操作。此文件包含两个用于定义标题的行，以及多个包含实际记录的行。每个记录均应包含一个 SKU 以及应对该 SKU 执行的一项操作，两个字段之间用一个制表符进行分隔。SKU 不应包含任何特殊控制字符，如换行符。

SKU 最多不得超过 40 个字符。退货属性调整文件最多可以包含 50,000 个 SKU。要了解有关如何创建此文件的更多详情，请参阅上述模板文件中的说明和示例数据。

## 上传退货属性调整文件

点击[退货设置](https://sellercentral.amazon.com/gp/returns/settings)页面上的[退货属性调整](https://sellercentral.amazon.com/returns/attribute-overrides)链接，您可以在此处上传已完成的退货属性调整文件。

在您上传此文件后，亚马逊会生成一个处理报告，其中将显示每个 SKU 调整的状态。

处理报告是以制表符分隔的文本文件，您可以使用 Microsoft Excel 或记事本等程序打开并阅读此类文件。电子表格中包含数据的每一行均称为记录。在处理报告顶部，您会看到已成功处理和未成功处理的记录的一览。

例如：

Feed Processing Summary: 
Number of records processed: 1045
Number of records successful: 1030

如果单条记录存在错误，您会看到每个错误的以下信息：

| 元素 | 描述 |
| --- | --- |
| 原始记录编号 | 您上传的原始文件中发生了错误的位置的行号。行 0 是指一般性的文件错误或标题错误，因此行 1 实际是指文件中的第 3 行，即具有实际数据的第 1 行。 |
| 错误代码 | 亚马逊用来识别错误消息的编号。即检查【错误代码说明】时使用的编号。 |
| 错误类型 | 两个值之一：错误或严重错误。错误指仅影响指定记录的无效数据。严重错误指影响整个文件的无效数据。严重错误会导致整个文件无法处理。 |
| 错误消息 | 简要的错误说明。错误消息可能会建议纠正措施。 |

查看处理报告中的错误消息后，您可采取任何纠正措施修改您的退货属性调整文件。有关纠正所收到错误的更多帮助，请参阅下面的【错误代码说明】部分。

## 错误代码说明

| 代码 | 严重程度 | 描述 |
| --- | --- | --- |
| 41001 | 严重错误 | 文件太大。允许的最大文件大小是 60MB。 |
| 41002 | 严重错误 | 文件具有太多记录。允许的最大记录数是 50,000。 |
| 41003 | 严重错误 | 文件为空或文件中的所有记录无效。 |
| 41004 | 错误 | 此行中没有 SKU。 |
| 41006 | 错误 | 此行中的 SKU 太长。最大长度为 40 个字符。 |
| 41007 | 严重错误 | 您已经超出上传配额，因此文件将不被处理。您可在 24 小时内上传 20 个文件。 |
| 41008 | 严重错误 | 此文件的标题无效。这可能是由标题缺失或标题中定义的列错误所致。 |
| 41009 | 错误 | 此行包含错误的字段数。所有行均须包含 2 个字段。 |
| 41010 | 错误 | 此行中的操作无效。必须是【自动】、【手动】或【删除】。 |

**注意： **退货属性调整上传历史记录仅包含过去 90 天内提交的调整文件。

请参阅[设置您的退货首选项](https://sellercentral.amazon.com/gp/help/external/200828040)，了解更多信息。
