# 错误代码说明

当您提交的商品不符合[商品详情页面规则](https://sellercentral.amazon.com/gp/help/external/G200390640)时，会出现错误。 这些错误消息是一种有力保障，可以避免您的商品中的错误信息显示在网站上。

错误可能由多种原因导致，例如：
- 使用了错误的模板
- 未在模板中添加必填或要求的属性
- 添加的属性错误：
  - 与有效属性值不匹配
  - 与其他属性或相关属性冲突
  - 超出字符数限制

例如，如果您提交的商品描述超过 1000 个字符，则会导致[处理报告](https://sellercentral.amazon.com/gp/help/external/G200194300)出错，并且您的商品也不会包含在目录中。

我们建议您在每次上传后查看[处理报告](https://sellercentral.amazon.com/gp/help/external/201576740)。如果您正在提交库存文件，此报告将显示在[检查上传状态](https://sellercentral.amazon.com/product-search/bulk/status)中。

要查看错误消息、其定义和建议解决方案，请从导航窗格上的列表中选择一个错误。
