# 查看我的库存结果

每次您上传文本文件时，亚马逊都会创建和发布一份处理报告。此处理报告用于确认您的上传数据是否成功，以及处理过程中是否遇到任何具体错误。

在您上传文件后，系统会显示一个状态框，用于确认我们已收到您的文件。

在此页面的【文件上传状态】部分，将显示您最近上传的日期、时间、批次编号、状态和结果。 此外，还会提供一列链接，可用于根据结果采取相应操作。如果您的上传数据未处理完毕，【状态/结果】列将会显示以下信息：
状态： 进行中 本次上传已处理的记录数： 0 已激活的记录数： 0 有错误的记录数： 0

您可以使用【刷新】查看最新结果。

文件处理完毕后，【状态/结果】列将显示已更新的信息，以及可执行的【操作】。

如果任何商品因出现错误而未被激活，请点击【查看处理报告】链接，下载相关的处理报告。请使用此报告来诊断和纠正上传文件中的错误。 在准备好上传编辑过的文件后，点击【返回上传页面】链接，重新上传文件。有关更多信息，请参阅[查看处理报告](https://sellercentral.amazon.com/gp/help/external/200194300)。

## 访问您的上传结果
从【上传商品和库存】页面的【查看文件状态和历史记录】部分，您可以访问文件的上传状态报告。可查看最近 10 次上传的状态。
