# 其他库存报告格式

虽然管理库存所需的信息也可以通过标准报告和【管理库存】部分获得，但向后兼容至您管理业务所用系统可能需要下述报告。

这些报告采用制表符分隔文本文件的格式。您可以在任何电子表格或数据库程序（例如 Microsoft Access 或 Microsoft Excel）中打开这些报告。然后，您可以在电子表格中修改商品数据和文件列，并使用库存加载工具随时上传。有关更多信息，请参阅[使用报告更新库存](https://sellercentral.amazon.com/gp/help/external/200388940)。

**注意： **如果您销售图书类商品，那么以下文件中的 【product-id】 字段将包含 ISBN。如果您在 Microsoft Excel 中打开报告，Excel 会去除 【product-id】 列中 ISBN 的前导零。要避免这种情况，可以使用导入向导，以文本格式强制导入 【product-id】 列。有关更多信息，请参阅 Microsoft Excel 帮助。

## 卖家自配送可售商品报告

卖家自配送可售商品报告中包含生成报告时当前可售商品的相关详细信息。该报告与在售商品报告类似。一个重要的区别在于，卖家自配送可售商品报告不显示数量为零 (0) 的商品。如果需要查看缺货库存商品的 SKU，请使用完整的[在售商品报告](https://sellercentral.amazon.com/gp/help/external/200385890)。

如果您注册了亚马逊物流计划，请注意，该报告不显示配送渠道。

## 卖家自配送可售商品报告（精简版）和卖家自配送可售商品报告（极简版）

这些卖家自配送可售商品报告的精简版本有助于确保您在网站上的可售库存的商品价格和数量与自己的记录保持一致。因为这些报告没有完整报告那么详细，所以生成速度更快，方便您更快地更新价格和数量。

两种报告包含的字段分别如下：

#### 卖家自配送可售商品报告（精简版）

- seller-sku

- quantity

- price

- product ID

#### 卖家自配送可售商品报告（极简版）

- seller-sku

- quantity

## 已取消商品报告

已取消商品报告中包含亚马逊在过去 30 天内取消的所有商品。该报告不包含已售出、卖家取消、通过库存加载工具或其他库存文件清除的商品。

## 已售商品报告

已售商品报告中包含通过亚马逊网站售出的所有商品，包括卖家自配送订单和未使用亚马逊物流的订单。您可以请求生成过去 7 天、15 天、30 天或 60 天内售出商品的报告。
