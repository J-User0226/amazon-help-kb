# 针对巴西卖家的商品发布要求

为确保买家获得良好的体验，亚马逊对发布商品具有特定的要求。商品名称、描述、图片和其他属性必须符合这些要求。如果存在任何不符情况，商品可能会被移除。要了解有关商品发布规则的更多信息，请访问以下帮助页面或搜索“帮助”菜单。

- [商品名称要求](https://sellercentral.amazon.com/gp/help/external/YTR6SYGFA5E3EQC)

- [商品图片要求](https://sellercentral.amazon.com/gp/help/external/1881)

- [禁止显示的商品](https://sellercentral.amazon.com/gp/help/external/200898440)

## 目录翻译

除上述要求外，**Amazon.com.br 商城发布的所有商品都必须使用葡萄牙语**。使用其他语言发布的商品将被移除，且发布该商品的卖家的账户也可能被临时暂停。为了帮助其他国家/地区的卖家使用葡萄牙语发布商品，亚马逊提供了一款与 BIL（建立国际商品信息）关联的翻译工具。

该工具可为卖家提供帮助，但您仍需负责查看所有翻译内容，并确保翻译内容准确无误，完美反映您的商品特征，并遵守巴西法律。亚马逊不对任何翻译文本负责。

要访问该工具，请执行以下步骤：

- 在卖家平台中，转至【库存】，然后点击【全球开店】。

- 点击【建立国际商品信息】。

- 点击页面右下角的【开始】。

- 选择 Amazon.com 作为来源商城。

- 勾选 Amazon.com.br 作为目标商城。

- 点击【保存并继续】。

- 选择您想要在 Amazon.com.br 商城发布的商品类型：**卖家自配送**商品以及**新品或二手**商品。您也可以选择特定商品，列出您想在 Amazon.com.br 商城销售的商品的 SKU。

- 点击【保存并继续】。

- 定义目标商城的定价规则。您可以选择使用与原始商品相同的价格（转换为巴西*雷亚尔*），也可以在原始商品价格的基础上添加一个固定百分比。

- 点击【保存并继续】。

- 检查您的设置。

- 点击【保存并继续】。

- 请仔细阅读屏幕上的警告，如果您同意，请点击【同意并创建商品】。商品经处理后，将于 4 小时内在目标商城上线。

重要信息：

- 用于 Amazon.com.br 目标商城的翻译工具仅适用于 Amazon.com 来源商城的商品。无法使用“建立国际商品信息”翻译在其他国家/地区发布的商品信息。

- “建立国际商品信息”不会同步 Amazon.com 商城的亚马逊物流商品。

- 带有状况说明（表明二手商品状况的商品属性）的二手商品不会进行同步，也不会进行翻译。

- 来源商城 (Amazon.com) 中无在售信息的商品不会进行同步或翻译。

- 限制向巴西卖家供货的商品不会进行同步或翻译。

- Amazon.com.br 中的 ASIN 编码将与 Amazon.com 保持一致。

- 如果 Amazon.com.br 商城使用的 SKU 与 Amazon.com 商城发布的 ASIN 相同，库存将自动同步。这意味着，如果商品数量在 Amazon.com 商城发生变化，系统将改写 Amazon.com.br 商城的商品信息，反之亦然。

- 如果卖家希望分别管理 Amazon.com.br 和 Amazon.com 库存，则必须使用不同的 SKU。

- 对于 Amazon.com 商城的亚马逊物流（亚马逊配送）商品，请在 Amazon.com.br 商城使用“不同”的 SKU 编号。使用相同的 SKU 会将所有账户的配送方式更改为“卖家自配送”。对于通过“建立国际商品信息”同步的所有商品，如果 Amazon.com 商城的 ASIN 图片更新，则会反映到 Amazon.com.br 商城中，反之亦然。

要详细了解如何创建和同步国际商品信息，请访问：

- [建立国际商品信息](https://sellercentral.amazon.com/gp/help/external/G202121570)

- [使用“建立国际商品信息”创建关联](https://sellercentral.amazon.com/gp/help/external/G202121580)

- [选择您的来源商城和目标商城](https://sellercentral.amazon.com/gp/help/external/G202121600)

翻译商品信息的另一种方式是雇用服务提供商。在【应用和服务】 > > 【浏览服务】中，搜索服务类型，然后选择【翻译】。

## 发布商品的其他方式

**API**： 如果您已使用“建立国际商品信息”翻译目录，请移除“建立国际商品信息”同步并删除在 Amazon.com.br 商城列出的所有 ASIN。如果您已在 Amazon.com 商城使用 API，则可以在 Amazon.com.br 商城使用同一密钥。

**批量上传**： 如果您已使用“建立国际商品信息”翻译目录，请移除“建立国际商品信息”同步并删除在 Amazon.com.br 商城列出的所有 ASIN。要在 Amazon.com.br 中使用不同的 SKU，此方式为最佳方式。请记住，如果您使用不同的 SKU，Amazon.com.br 库存将不会与 Amazon.com 同步。按照[库存文件模板](https://sellercentral.amazon.com/gp/help/external/G1641)帮助页面上的步骤批量上传。

**1:1**： 如果您已使用“建立国际商品信息”翻译目录，请移除“建立国际商品信息”同步并删除在 Amazon.com 商城列出的所有 ASIN。您可以逐个添加 ASIN。转至【库存】 > > 【添加商品】，然后按照屏幕上的说明操作。
