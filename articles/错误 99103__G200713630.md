# 错误 99103

如果提供的 SKU 已经不再与 ASIN 匹配，须为商品编码提供一个值。



（错误）您的输入文件中商品编码的必填值缺失。如果提供的 SKU 与 ASIN 不匹配，须提供商品编码。提供商品编码并重新提交输入数据。
