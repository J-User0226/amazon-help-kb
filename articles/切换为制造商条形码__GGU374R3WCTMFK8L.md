# 切换为制造商条形码

重要须知： 自 2026 年 3 月 31 日起，条形码要求将发生变更。品牌所有者可以继续使用不带标签的[制造商条形码](https://sellercentral.amazon.com/gp/help/external/G200141480)。现在，即使转销商具有制造商条形码，也需要对商品使用[亚马逊条形码](https://sellercentral.amazon.com/gp/help/external/G200141490)。有关此变更的详细信息，请参阅[亚马逊物流条形码选择和贴标常见问题](https://sellercentral.amazon.com/gp/help/external/GEFKUGES6NSE7CBP)。

了解如何从亚马逊条形码切换为制造商条形码，从而让您仅使用制造商条形码就可以将库存运送至运营中心。

了解更改首选项的一般要求、如何检查您的商品是否符合虚拟追踪的要求以及在将首选项更改为制造商条形码后应注意哪些事项。

## 切换为制造商条形码之前

制造商条形码资格随商品变化。而且，我们会定期更新以保持为买家和卖家提供最佳服务。 将首选项更改为制造商条形码之前，请参阅针对亚马逊物流的[使用制造商条形码](https://sellercentral.amazon.com/gp/help/external/G200141480)，查看您的商品是否符合资格要求。

对于在运营中心已有库存且使用亚马逊条形码进行追踪的亚马逊物流商品，您有两个选项：

- **创建新商品信息：** 您必须使用新的 SKU 创建新商品信息，以便使用制造商条形码。

或

- **切换现有商品信息的条形码首选项：** 必须先售出库存，或者先通过提交移除订单移除库存，然后这个商品信息才能切换为使用制造商条形码。

不能为已创建的货件或已储存在亚马逊运营中心的库存更改条形码首选项。更改仅适用于未来的货件。

## 切换为制造商条形码

确认商品资格以及切换为使用制造商条形码进行追踪有三个选项：

- 批量更改商品信息

- 使用 【Send to Amazon】 工作流程

- 创建新的 SKU

#### 批量更改商品信息

您可以生成一个 Excel 文件，其中包含现有库存的资格详情，以及有关如何更新和上传文件以转换符合要求的商品的说明，然后查看和批量更改商品。

要批量转换商品信息，请按照以下步骤操作：

- 前往[制造商条形码： 转换符合要求的商品](https://sellercentral.amazon.com/c2c/feeds)，然后点击第 1 步下的【生成下载文件】。

- 文件生成后，点击【下载文件】。

- 打开文件后，请阅读帮助说明并导航至标有制造商条形码的工作表。对于要转换的商品，请在 【SKU： 制造商条形码】列中输入新的 SKU，并在【启用制造商条形码追踪】列中输入“是”。

- 完成更改后，请按照第 2 步上传文件。

**注意： **并非所有符合制造商条形码要求的 SKU 都可以直接转换。某些 SKU 可能需要作为新的 SKU 重新发布。如果配送网络中存在与现有 SKU 相关的未完成的货件或库存，或者由于其他系统性限制，则可能会出现这种情况。

#### Send to Amazon 工作流程

您可以针对单个符合要求的商品使用制造商条形码。

要使用 Send to Amazon 工作流程转换单个商品，请按照以下步骤操作：

- 从【库存】下拉菜单中，选择【管理所有库存】。

- 从 ASIN 右侧的【编辑商品信息】下拉菜单中，选择【发/补货】。

- 在 Send to Amazon 工作流程的第 1 步中，符合要求的 SKU 将在【信息/操作】下方显示建议【使用制造商条形码保存】的链接。

- 点击【使用制造商条形码保存】链接，然后按照说明切换您的商品信息上的条形码首选项。

**注意： ** 如果商品信息中未提供**使用制造商条形码保存**，则相关商品可能不符合使用制造商条形码的要求。

#### 创建新的 SKU

您可以通过创建新的 SKU 逐个更改单个商品的条形码首选项。因为现有 SKU 已与亚马逊物流网络中的库存关联，所以必须使用新的 SKU。

要为现有商品创建新的 SKU，请按照以下步骤操作：

- 从【库存】下拉菜单中，选择【管理所有库存】。

- 从 ASIN 右侧的【编辑】下拉菜单中，选择【添加其他状况】。

- 在商品创建页面上，输入新的【卖家 SKU】，填写其余的必填字段，然后点击【保存并完成】。

- 在【发布为亚马逊物流商品】页面上，前往【选择条形码类型】页面，从下拉菜单中选择【制造商条形码】，然后点击【确认】并【发布为亚马逊物流商品】。

**注意： **如果商品信息中未提供【使用制造商条形码保存】，则相关商品可能不符合使用制造商条形码的要求。

## 切换为制造商条形码之后

切换为使用制造商条形码后创建新商品时，之前卖家 SKU 的信息通常不会适用。下表总结了针对新 SKU 的变更和建议步骤。

| 受影响的区域 | 变更 | 建议操作 |
| --- | --- | --- |
| 库存建议 | 新 SKU 将具有自己的库存建议。 | 为避免混淆，请考虑关闭旧 SKU 商品并提交移除订单，申请将商品退还给您。 |
| 定价建议 | 定价建议不适用于新 SKU。这是因为当商品在最近 60 天内但非最近 7 天内售出时，某些提示才会显示。 | 我们建议您对新 SKU 使用过去的定价建议。 |
| 广告建议 | 仅当有一定数量的买家查看新 SKU 后，系统才会对其显示广告建议。 | 如果您收到旧 SKU 的通知，并想参加可用的促销，则可将促销应用于新 SKU。 |
| 企业商品价格和数量折扣 | 如果您是亚马逊企业购卖家，将收到相关建议。这些建议可能不会立即适用于新 SKU。 | 考虑将历史建议应用于新 SKU。 |
| 库存规划 | 您的新旧 SKU 将在管理冗余库存、亚马逊物流库龄和修复无在售信息的亚马逊库存下分别拥有一个单独条目。 | 请务必管理正确的库存条目。 |
| 定向广告 | 定向广告（如商品推广）不会自动应用于新 SKU。 | 为新 SKU 发布新的定向广告活动，或将新 SKU 添加至现有广告活动。 |
| 其他广告 | 特惠、优惠券、Prime 专享折扣和促销不会自动应用于新 SKU。 | 为新 SKU 发布新的广告选项。 |
| 订购省 | 订购省订阅服务不会自动应用于新 SKU。 | 在管理“订购省”商品中为您的新 SKU 创建转移订阅请求。 |
| 虚拟捆绑商品 | 现有的虚拟捆绑商品不会自动与新 SKU 合并。 | 创建包含新 SKU 的新虚拟捆绑商品。 |
| 计划中的 ASIN | 转换后的 ASIN 可能不再符合卖家自配送 Prime 的要求。 | 查看资格要求并根据情况注册商品。 |
| 全球开店 | 系统将仅为您的主商城创建新 SKU。 | 如需全球销售，则必须完成相同的流程来更改每个目标商城的设置。条形码资格可能随商城变化。 |
