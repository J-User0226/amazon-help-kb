# 错误 14016

## 错误消息
${price_type} 和 ${currency} 的商品价格表无效。要进行修复，请查看商品价格表格式要求，更正所有无效值，然后重新提交。

## 导致错误 14016 的原因
由于以下原因导致出现此错误：
- 商品价格表数据格式错误或包含语法错误。
- 商品价格表中的日期和时间值未采用要求的格式。
- 输入的货币值格式不正确。

## 解决错误 14016
1. 查看上传数据处理汇总报告，了解商品价格类型和货币。
2. 验证商品价格表中的所有日期和时间是否格式正确 (YYYY-MM-DD HH:MM:SS) 且时区无误。
3. 使用适当的小数格式（无需货币符号），检查指定货币的所有商品价格值是否输入正确。
4. 更新值后，请重新提交上传数据模板文件。
