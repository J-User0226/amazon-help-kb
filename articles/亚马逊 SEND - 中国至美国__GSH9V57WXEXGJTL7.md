# 亚马逊 SEND - 中国至美国

亚马逊 SEND 计划允许您利用亚马逊 SEND 承运人将您的亚马逊物流库存从中国发往美国的亚马逊运营中心。您可以利用该计划以经济高效的方式将亚马逊物流货件和亚马逊仓储和分拨服务货件运送到全球各地。亚马逊 SEND 支持空运和海运服务。亚马逊 SEND 承运人取走您的货件后，将处理货件从清关到送达亚马逊运营中心和亚马逊仓储和分拨服务库房的端到端运输事务。通过亚马逊 SEND，您可以让承运人上门取件，也可以将货件投递至承运人网点。

## 通过亚马逊 SEND 发送您的货件

按照以下步骤，通过亚马逊 SEND 预约亚马逊物流货件：

- 要创建亚马逊物流货件，请在卖家平台的【库存】下拉菜单中选择【货件】，然后导航至【货件】下拉菜单，选择 【Send to Amazon】。

- 取消选择【我要使用亚马逊跨境物流服务进行运送】。

- 在第 1 步中，选择您计划运往亚马逊物流的 ASIN 和数量。选择库存和数量后，输入包装详情。有关包装配置的更多信息，请参阅 [Send to Amazon： 选择要发送的库存](https://sellercentral.amazon.com/gp/help/external/G8SXKYFWPG6DAW6T)中的步骤创建入库计划。

- 如果 ASIN 是单一 SKU 包装箱（例如大包装），则选择相应的【装箱模板】（如果您已创建了模板）。否则，请创建一个新的装箱模板，然后选择【准备发送】。对您计划发往亚马逊物流的所有 ASIN 按照此流程操作，然后选择【确认并继续】。

- 如果是混合 SKU 包装箱，请选择【混装商品】，然后点击【准备包装】。对于您发送至亚马逊物流的所有 ASIN，请按照此流程操作。然后，选择【包装混装商品】。此时将前往第 1b 步，您需要在此步骤中提供包装箱详情。提供包装箱详情后，选择【确认并继续】。

- 对于运输方式，选择【亚马逊运营中心】或【亚马逊仓储和分拨服务】。

**注意： **对于亚马逊仓储和分拨服务，亚马逊 SEND 仅支持海运。

- 选择【亚马逊 SEND】。

- 入库配置选项的选择： 根据您的需求选择亚马逊物流库存入库配置选项，以优化您的总物流费用。对于高级配置选项，卖家可以选择入库区域，例如东部、西部或中部。

- 选择配送模式： 【航空快递或海运 - 拼箱货件】。

**注意： **此处预计的入库配置服务费不包括承运人运费。承运人运费可能会因您选择的库存入库配置选项（如货件拆分数量和地区，如适用）而有所不同。有关更多信息，请参阅[亚马逊物流入库配置服务费](https://sellercentral.amazon.com/gp/help/external/GC3Q44PBK8BXQW3Z)。

- 为货件选择所需的发货日期和取件或投件选项。如果您打算投件，请在下面的“亚马逊 SEND 承运人要求”部分找到投件详情。

- 选择需要的配送日期和配送服务选项（取件或投件），并确认配送集装箱内是否有锂电池（是或否），然后点击【获取运费】。

- 选择所需的亚马逊 SEND 承运人，然后点击【预约】。

- 点击【获取运费】，根据包装箱尺寸和重量生成预计承运人运费。此费用不包括美国海关收取的关税和其他附加费用。

- 确认配送方后，输入适用于您货件的清关信息，然后点击【确认】。

- **公司名称（中文）**： 请使用您公司的中文名称

- **公司名称（英文）**： 输入您的法律文件中提及的公司名称

- **公司信息**： 办公地址在货件标签上印为“发货人地址”

- **起运地联系详情**： 在货件起运国家/地区指定一名取件联系人

- **商品描述**： 包含该商品的名称，材质和用途。例如，男士针织毛衣，100% 纯棉，个人使用。如果描述模棱两可、不准确或不完整，则货件可能会被海关扣缴或拒绝入境，导致货件接收延迟，并可能面临处罚。

- 通过选中复选框来点击【接受费用并确认配送】，即表示您接受费用并同意计划条款和条件，（以及链接中包含的亚马逊 SEND 承运人条款和条件）。货件送达后，将从您的卖家平台提现账户中扣除相应金额。

**注意： **最终费用将根据亚马逊 SEND 承运人审计过程核实的实际重量和尺寸以及配送期间产生的适用关税和附加费计算得出。有关更多信息，请参阅[亚马逊 SEND - 卖家条款和条件](https://sellercentral.amazon.com/gp/help/external/G27F6UHDSSHW6WXF)。

接受费用后，请下载亚马逊物流标签和承运人标签（如适用），并将标签粘贴到箱子上。

- 确认发货后，请在“SEND to Amazon”工作流程中下载并上传所需文件。

- 交接时，货件应附有必要的亚马逊物流标签、空运单或承运人标签（如适用）。

**注意： **亚马逊 SEND 承运人可能会要求您提供此处所列文件之外的其他文件，具体取决于您要配送的商品分类。

## 通过卖家平台在线预约亚马逊仓储和分拨服务货件

要开始创建货件，请前往[亚马逊仓储和分拨服务 (AWD)](https://sellercentral.amazon.com/ellercentral.amazon.dev/asdn/about#learn-service)，导航至【管理服务】，然后点击【创建货件】。您将进入**发送至亚马逊仓储和分拨服务**工作流程。有关更多信息，请参阅[将货件运送至亚马逊仓储和分拨服务中心 (AWD)： 确认发货](https://sellercentral.amazon.com/gp/help/external/GQ6ZR5KNWKRBPT4M)

## 亚马逊 SEND 付款和卖家费用

使用亚马逊 SEND 计划的卖家需要在货件送达后支付运费。运费将从卖家的提现账户中扣除。

请按照以下步骤查找您的亚马逊 SEND 承运人和海关费用详情：

- 要查看费用，请前往您的销售账户，选择【付款】下拉菜单，然后选择【交易一览】选项卡。

- 使用亚马逊物流或 AWD 货件编号查找您的交易。

## 亚马逊 SEND 商品运输资格

危险品不可以使用 SEND 计划进行全球运送。为确保安全运输，危险品必须遵守所有适用法规，并需遵守其他条款。有关更多信息，请参阅[亚马逊物流危险品计划](https://sellercentral.amazon.com/gp/help/external/GZLZBQ7W6QZRKWWK)

## 联系销售伙伴支持

如有任何疑问，请前往【帮助】下拉菜单，然后选择【获取帮助和资源】或使用卖家助手。选择 【AWD、运输和物流】选项，然后选择【亚马逊 SEND】。这将直接将您转到亚马逊 SEND 的支持服务。
