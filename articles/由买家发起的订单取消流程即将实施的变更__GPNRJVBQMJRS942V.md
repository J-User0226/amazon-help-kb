# 由买家发起的订单取消流程即将实施的变更

【自 2022 年 5 月 23 日起，我们将更改卖家对由买家取消的卖家自配送订单的管理方式。】

## 卖家平台 -“管理订单”页面变更

【取消流程：】

要请求正式取消订单，买家必须前往【我的账户】，点击【我的订单】，然后选择【请求取消】。

- 如果买家在下单 30 分钟后请求取消，您将收到电子邮件通知，并可以在【管理订单】页面查看取消请求，该页面位于订单信息正上方，并带有一条显示【“买家已请求取消此订单。取消此订单不会影响您的取消率指标”。】的横幅。

- 取消订单时，请选择【买家取消】作为取消原因，这样此订单就不会计入您的取消率指标。

- 在您取消订单之后，您和买家将分别收到一封确认电子邮件，告知双方订单已取消。

**注意： **如果订单取消并非由买家发起，但选择了【买家取消】作为取消原因，这将对您的取消率指标产生不利影响。

要应买家请求取消订单，请按照以下步骤操作：

- 登录您的卖家平台账户。前往【订单】，点击[管理订单](https://sellercentral.amazon.com/orders-v3/mfn/unshipped?)。

- 要查看由买家发起取消的订单，请注意横幅处即可（由买家发起取消的订单将在横幅上显示【“买家已请求取消此订单。取消此订单不会影响您的取消率指标”】）。

- 点击【操作】列下的【取消订单】。

**注意： **只有【未发货】订单才有对应的【取消订单】选项。

- 在【订单详情】页面上，选择【买家取消】作为取消原因。

- 点击【提交】。

**注意： **在您取消订单之后，您和买家将分别收到一封确认电子邮件，告知双方订单已取消。

以下图片展示了第 2 步和第 3 步的示例。在【管理订单】页面上，选择您想要取消的订单，然后点击【取消订单】。

![](https://m.media-amazon.com/images/G/15/rainer/help/Image1.png)

第 4 步示例。从下拉菜单中选择【买家取消】作为取消原因。

![](https://m.media-amazon.com/images/G/15/rainer/help/Image2.png)

**注意： **如果您因库存不足而无法配送订单并且需要取消订单，请选择【无库存】作为原因。请不要联系买家并要求对方提交取消申请。

## 买家发起的非正式取消流程会影响您的取消率指标

如果买家未遵循正式取消流程，仅通过买家与卖家消息服务请求取消订单，这将视为买家取消订单的非正式渠道。因此，如果您通过买家与卖家消息服务响应买家的请求取消了订单，那么这一非正式取消方式将影响您的取消率指标。

为避免您在取消订单时影响到取消率指标，您可以回复买家的消息并请买家按照上述正式流程提交订单取消请求。

请在回复中使用以下说明： “您可以在您的亚马逊账户中找到相关订单。请前往【我的账户】，点击【我的订单】，然后选择【请求取消】。”

## 订单报告变更

对于使用订单报告来处理订单的卖家，其订单报告中提供了一个名为 【is-buyer-requested-cancelation】 的可选附加字段。如果买家请求取消订单，则 【is-buyer-requested-cancelation】 列的值为 【TRUE】，反之则为 【FALSE】。

请参阅下方的图片。

![](https://m.media-amazon.com/images/G/15/rainer/help/Image3.png)

您可以通过访问[添加或移除订单报告列](https://sellercentral.amazon.com/order-reports-and-feeds/column-picker?source=/order-reports-and-feeds/reports/ref=xx_orderrpt_dnav_xx)，打开【买家请求取消】字段的切换选项，在订单报告中查看有买家发起取消请求的所有订单。

请参阅下方的图片。

## API 变更（销售伙伴 - API）

【订单 API】

为了向卖家突出显示买家的订单取消请求，亚马逊将更新【订单 API】 部分。

【销售伙伴 - API】

与订单 API 类似，对于 SP-API，当买家发起订单取消请求时：

1. 如果订单由买家请求取消，在响应时，【ordersV0GettOrderItemsList】 操作将为每个 【OrderItem】 添加一个 【isBuyerRequestedCancel】 标记和 【buyerCancelReason】 字符串。

2. 如果订单由买家请求取消，【isBuyerRequestedCancel】 标记将被设置为 【True】。

3. 【buyerCancelReason】 将显示买家指定的取消原因。

## 常见问题

#### 1. 为什么实施这些变更？

我们收到了来自卖家的反馈，他们表示希望在买家发起订单取消请求时得到通知，这样就不会错过这些请求，从而减少退货和退款。

#### 2. 取消率指标如何计算？ 是否有任何变化？

取消率政策或取消率指标的计算方式没有任何变化。有关更多信息，请参阅[取消率](https://sellercentral.amazon.com/help/hub/reference/G200285210)。

#### 3. 如果买家通过正式取消流程请求取消，我收到通知的方式是否会发生变化？

是的。您将通过以下方式收到买家发起的正式取消请求通知：

- 电子邮件

- 卖家平台中的【管理订单】页面

- 订单报告

- 订单 API 响应 (SP-API)

#### 4. 我是否需要下载订单报告才能查看买家发起的取消订单？

不会。如果您不使用订单报告，您将通过电子邮件、卖家平台的【“管理订单”】页面和 API 收到买家发起的取消通知。下载订单报告的优势在于，您能够在一份报告中查看所有由买家发起的取消订单。您需要切换切换选项，以启用【买家请求取消】字段。

#### 5. 我是否会继续通过买家与卖家消息服务收到买家的订单取消请求？

如果买家仅通过买家与卖家消息服务请求取消订单，这将被视为非正式请求。如果您取消订单，您的取消率指标将受到影响。

#### 6. 如果我在买家与卖家消息服务中收到取消请求，该怎么办？

买家与卖家消息服务被视为买家请求取消订单的非正式渠道。为避免您在取消订单时影响到取消率指标，您可以回复买家的消息并请其按照正式流程提交订单取消请求。

请在回复中使用以下说明： “您可以在您的亚马逊账户中找到相关订单。请前往【我的账户】，点击【我的订单】，然后选择【请求取消】。”

#### 7. 实施此变更后，我能否使用买家与卖家消息服务向买家发送消息？

可以，您可以像现在一样继续[使用买家与卖家消息服务和买家沟通](https://sellercentral.amazon.com/help/hub/reference/200389080)。

有关取消的消息属于[重要消息](https://sellercentral.amazon.com/gp/help/external/GRZ5Y5YEN9J84NAC)，即使买家已选择不接收非重要消息，也会发送给买家。

#### 8. 如果我选择不接受买家的订单取消请求，会怎么样？

目前，如果买家发起订单取消请求，而您选择继续配送订单，那么将不会对您的取消率指标产生负面影响。

#### 9. 此更新是否会改变对我的取消率指标产生负面影响的取消类型？

不会。此更新不会改变可能会对您的取消率指标产生负面影响的取消类型。

| 取消发起方 | 取消场景 | 是否会对取消率产生负面影响 |
| --- | --- | --- |
| 买家 | 1. 我正在取消订单，原因是买家提交了正式取消请求 | 否 |
| 2. 我正在取消订单，原因是买家要求我仅通过“买家与卖家消息服务”（非正式取消流程）取消订单 | 是 | |
| 卖家 | 1. 我正在取消订单，原因是我的商品缺货 | 是 |
| 2. 我正在取消订单，原因是地址无法送达 | 是 | |
| 3. 我正在取消订单，原因是买家没有回应 | 是 | |
| 亚马逊 | 1. 订单被亚马逊自动取消，因为卖家未在发货后的 7 天内确认发货 | 是 |
| 2. 订单被亚马逊自动取消，原因是我们检测到买家存在欺诈行为 | 否 | |
| 3. 付款验证失败，订单被亚马逊取消 | 否 | |
