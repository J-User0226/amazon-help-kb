# 销售佣金

对于所有商品，亚马逊将扣除基于总销售价格和适用百分比计算得出的销售佣金，其中不包含通过亚马逊税务计算服务计算得出的任何税费。总销售价格是买家支付的总金额，包括商品价格以及所有运费或礼品包装费。销售佣金因分类而异，如下所列。

## 费用详情
**收费时间** 买家订单发货时
**费用构成** 按每件售出商品收费，为总销售价格的百分比。根据商品分类和总销售价格来确定费率。

## 用于计算费用的值
**商品价格** 商品的销售价格
**运费** 自行配送此商品，您收取的运费金额
**礼品包装费** 针对礼品包装服务收取的金额
**商品分类** 商品销售所属分类
有关更多信息，请转至[分类概览](https://sellercentral.amazon.com/gp/help/external/200332540)和[需要批准的分类和商品](https://sellercentral.amazon.com/gp/help/external/200333160)。

## 销售佣金分类指南
有关每个分类中可搜索的详细商品列表，请参阅我们的[费用分类指南](https://sellercentral.amazon.com/gc/fee-category-guidelines)。此列表可帮助您快速确定与特定商品相关的费用分类。要了解更多信息，请参阅[了解费用分类](https://sellercentral.amazon.com/gp/help/external/GNJSJ7GP26PD5XWJ)。

要查找某个商品的费用分类，请前往[管理库存](https://sellercentral.amazon.com/inventory)并执行以下操作：
- 在【搜索】框中输入商品的 SKU 或 ASIN。
- 点击【每件售出商品的预计费用】列中的值。
- 点击【销售佣金】值旁边的信息图标，查看商品的费用分类。

## 费用示例
销售佣金的计算公式如下：

销售佣金 = [（商品价格 + 运费 + 礼品包装费） × 分类销售佣金费率] 或 [适用的最低销售佣金]，以较大值为准。

**示例 1： 玩具商品的销售佣金计算**

当前费率： 总销售价格的 15% 或 $0.30（适用的每件商品最低销售佣金）

商品价格 = $25.00

运费 = $4.50

礼品包装费 = $3.50

总销售价格 = 商品价格 + 运费 + 礼品包装费 = $33.00

销售佣金 =（15% 乘以 $33.00）或 $0.30，以较高者为准 = $4.95

**示例 2： 价值不等的钟表的销售佣金计算**

当前费率： 对总销售价格中 $1,500.00 以内的部分，收取 16% 的销售佣金；和对总销售价格中高于 $1,500.00 的部分，收取 3% 的销售佣金
