# 通行密码验证

## 概述

通行密钥让您可以通过指纹、面部扫描或 PIN 码快速、安全地登录您的亚马逊账户，就像您解锁手机或平板电脑一样。无需记住密码，无需完成电子邮件验证。

我们建议您使用通行密钥，而不是两步验证和一次性验证码登录，因为通行密钥能够防范网络钓鱼攻击，且快速易用。与密码不同，通行密钥不会像密码那样被猜中或被盗，从而保障您的账户和个人信息安全。通行密钥可在大多数设备和平台上使用，因此无论您在哪里工作，都可以登录您的亚马逊账户。

【通行密码验证的扩展和强制使用】

所有销售伙伴和买家均可使用通行密钥。虽然目前尚未要求所有用户都必须设置通行密钥，但我们仍建议您立即设置，以便在零售网站、卖家平台和供应商平台上获得更快、更安全的登录体验。今天设置通行密钥意味着当通行密钥成为强制要求时，您的账户将已处于安全就绪状态。届时，您在登录时会收到提示，要求设置通行密钥或使用现有通行密钥，然后才能继续操作。如果您尚未设置通行密钥，我们会引导您完成设置。您只需前往“登录和安全设置”页面，然后选择“设置通行密钥”。

## 实施通行密码验证

**如何为账户启用通行密码**

如果您已经是卖家平台的用户且尚未启用通行密钥验证，可以在下次登录卖家平台时，通过点击“启用通行密钥”按钮并按照屏幕上的说明来激活通行密钥。

您还可以访问零售网站上的“登录和安全设置”页面。在该页面上，您将执行相同的操作。您也可以在“关于通行密钥”中找到有关启用通行密钥验证的分步指南。

**如何确认是否启用了通行密码验证或进行更改**

启用通行密钥验证后，当您像往常一样登录卖家平台时，系统会提示您使用现有通行密钥（指纹、PIN 码、二维码、面容 ID 等）继续操作，而无需输入密码。这将确认您的通行密码已启用。您还可以导航至“我的账户”>“登录和安全”>“通行密钥”，查看和编辑您注册的通行密钥，然后按照屏幕上的说明更改并保存您的通行密钥设置。

【禁用通行密码验证】

您可以随时通过“登录和安全”或“高级安全设置”页面关闭或移除通行密钥验证。请注意，即使您禁用了通行密钥，登录时仍可能会看到需要使用通行密钥的提示 — 并且随着我们在 2026 年对部分安全敏感功能强制要求使用通行密钥，您的账户届时也可能要求使用通行密钥。

如果通行密钥成为强制要求，而您尚未完成设置，系统会先引导您完成设置流程，然后您才能登录。我们强烈建议您让通行密钥保持启用状态，以免被锁定在账户之外。

## 针对具有多个用户的账户实施通行密码验证

【共享账户指南】

如果您尚未执行此操作，亚马逊建议您通过卖家平台中的[用户权限](https://sellercentral.amazon.com/gp/account-manager/home.html/ref=xx_userperms_dnav_help)，使用不同的电子邮件地址为访问您账户的每个用户分别创建单独的登录信息。这是一项安全最佳实践，可确保所有需要访问该账户的用户都能访问，同时您也能在此过程中提升每个人的登录体验。

**账户启用通行密钥时，您为何应设置次级用户账户**

通行密钥与您的账户绑定，并可通过 iCloud Keychain、Google Password Manager 或 1Password 等通行密钥提供商在您的各台设备之间同步。这让通行密钥能够防范网络钓鱼 — 与密码不同，恶意行为者无法拦截或窃取您的通行密钥。

然而，通行密钥是个人专属的。无法访问您的通行密钥提供商的任何人都无法登录您的账户或在您的账户上创建通行密钥。对于共享账户，这意味着其他用户如果没有自己的次级账户，就会被锁定在外。

设置次级账户可以轻松解决这个问题。每位用户都有自己的登录信息并可以注册自己唯一的通行密钥，因此每个人都可以独立访问共享账户 — 而不会共享凭据或损害安全性。这是一次性设置，可为每位用户提供更快、防网络钓鱼的登录方式，并保护您的共享账户安全。

【如何设置次级用户账户】

作为主用户，您可以通过“用户权限”页面邀请其他用户，并准确控制他们可以访问的内容，例如管理库存或处理发货确认。我们建议仅为每位用户授予其角色所需的权限，并定期审核这些权限。

要添加次级用户，请执行以下操作：

- 前往“设置”，然后点击“用户权限”。

- 选择您要添加新用户的账户。

- 输入新用户的联系信息，然后点击“发送邀请”。次级用户需要一个全新的电子邮件地址，且该地址此前未用于任何亚马逊账户。

- 对要添加的所有新用户重复此操作。

- 让新用户按照电子邮件中的说明进行操作。

注册后，每位用户都可以登录并设置自己的通行密钥 — 这样账户中的每个人都能拥有自己的防网络钓鱼登录方式，并确保共享账户安全。

【通行密码验证对买家账户的影响】

您的通行密钥与您用于访问亚马逊的登录信息相关联。如果您对零售账户以及卖家账户或供应商账户使用相同的登录信息，您的通行密钥将同时适用于这两者 — 您将使用它登录亚马逊零售网站、卖家平台和供应商平台。

如果您不想在零售账户中使用通行密钥验证，您可以创建一个单独的亚马逊账户用于购物。不过，我们建议您在每个账户上都设置通行密钥 — 这是保护所有账户免遭未经授权访问的最有效方式。

【Windows 安全性和亚马逊通行密钥】

当您在 Windows 电脑上登录亚马逊账户时，可能会看到一条 Windows 安全性通知，要求您使用通行密钥或 PIN 码登录。此通知来自 Windows，而非亚马逊，对话框左上角的“Windows 安全性”标签已表明这一点。

此通知不会妨碍您访问自己的亚马逊账户。如果您不想创建 Windows 通行密钥，只需关闭此通知，然后继续使用密码或亚马逊专用通行密钥登录。如果您确实想在 Windows 设备上创建通行密钥，请选择【继续】，然后设置 PIN 码或二维码。此通行密钥将保存到您的设备并关联到您的亚马逊账户，这样您今后就可以使用它。有关 Windows 安全性如何与亚马逊通行密钥集成，以及如何创建通行密钥和次级用户的操作演示，请访问亚马逊的专用通行密钥 YouTube 频道。

要停止显示这些通知，请前往您电脑上的【设置】，选择【账户】，然后选择【登录选项】。在【其他设置】下，禁用【仅允许使用 Windows Hello 登录】。这将防止通知将来再次出现。

## 使用通行密码访问您的账户

**如何在多台设备上使用您的通行密钥**

您的通行密钥可在与您账户绑定的多台设备上启用，方便您在出行时使用，也可在设备丢失、被盗或更换时提供备选方案。有关更多信息，请参阅[在多台设备上使用通行密钥](https://www.amazon.com/gp/help/customer/display.html?ref_=hp_left_v4_sib&nodeId=TsfzMlkp9pNh0GzriE)。

只需通过与您的账户绑定的任何其他设备登录卖家平台 – 您的通行密钥将在这些设备上启用，并且应该允许访问。

【如果您丢失了已绑定通行密钥的设备】

如果您的设备丢失或被盗，我们建议您立即联系运营商，请他们停止或暂停您的服务，直到您弄清楚情况。

我们建议您在启用通行密钥验证时，将多台设备绑定到您账户的密码管理器。这样，即使您无法访问其中一台设备，您仍可继续访问，因为通行密钥已与您的密码管理器绑定，并会在您的所有设备上同步。

但是，如果您没有备用设备且无法更改设置，我们建议您联系客户支持或销售伙伴支持，并提供可验证您身份的文件。审核并批准后，通行密码验证将被禁用，这样您便可以在新设备上登录。下次登录时，系统会要求您再次设置通行密钥验证。这次请使用您可访问的设备，以便重新获得通行密钥的优势。

**注意： **销售伙伴支持无法调整此验证流程。

- 要从没有保存通行密码的设备登录您的亚马逊账户，请执行以下操作：

- 按照屏幕上的说明从其他设备使用通行密码。

- 确保已启用蓝牙。

- 使用已保存通行密码的手机或平板电脑的摄像头扫描二维码。

- 按照屏幕上的说明确认您想要使用通行密码登录。

【错误消息或锁定通知】

如果在使用通行密钥验证时出现错误消息或登录失败，通常是由于浏览器设置存在问题，可通过清除缓存和 Cookie 来解决此问题。 请确保您的设备或浏览器已更新到最新版本。

如果不起作用，我们建议您尝试使用绑定至您的账户的其他设备，或联系亚马逊销售伙伴支持寻求帮助。

如果您的账户被锁定，请联系亚马逊销售伙伴支持，寻求帮助以重新获取访问权限。
