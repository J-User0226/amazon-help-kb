# QZ Tray

## 什么是 QZ Tray？

QZ Tray 是一个支持一键打印的第三方解决方案。QZ Tray 一键打印现已与亚马逊“购买配送服务”集成。除了可以一键打印外，此解决方案还解决了使用 Print Connect 遇到的一些问题，如对不同格式的打印支持问题和当前状态打印问题。要了解使用“购买配送服务”的优势，请参阅[使用“购买配送服务”](https://sellercentral.amazon.com/gp/help/external/200202220)。

QZ Tray 可以帮助您：

- 一键打印通过“购买配送服务”购买的货件标签

- 支持不同格式的货件标签，专门打印 PDF、ZPL 或 PNG 文件

- 选择您的首选打印机并为每种格式分配不同的打印机

## 为什么需要使用 QZ Tray？

当前的状态打印解决方案 (Print Connect) 不支持多种格式。因此，需要执行额外的步骤才能将标签格式转换为可打印的版本。此外，打印是一个多步过程，如果一个步骤或所有步骤失败，将会出现问题。为了让卖家顺畅无忧地完成打印流程，我们将 QZ Tray 确定为改善卖家体验的最佳解决方案。

## 我是否需要卸载 Print Connect 才能使用 QZ Tray？

如果您目前在使用 Print Connect，那么无需卸载 Print Connect，即可直接安装和使用 QZ Tray。但是，所有新卖家将默认只使用 QZ Tray。亚马逊计划最终弃用 Print Connect。弃用时间表尚未确定。

## QZ Tray 支持

QZ Tray 是一个第三方解决方案，已经与亚马逊“购买配送服务”集成。这意味着 QZ Tray 的一些方面不是由亚马逊直接创建和维护的。但是，对于我们应用的所有工具，我们都将竭尽全力让卖家获得最佳体验，因此，如果您在使用 QZ Tray 时遇到任何问题，请先参阅此帮助页面上的故障排除和指导部分。如果您的问题仍然存在，请提交一个[销售伙伴支持 TT](https://sellercentral.amazon.com/help/hub/support)。

**注意： ** 由于我们需要与 QZ Tray 团队合作解决问题，所以某些问题可能需要更长时间才能解决。

如有任何与标签打印和“购买配送服务”功能相关的其他问题，请联系亚马逊销售伙伴支持。有关更多信息，请阅读故障排除部分或参阅[使用“购买配送服务”](https://sellercentral.amazon.com/gp/help/external/200202220)。

为确保我们的支持团队可以高效地为您提供帮助，我们建议您在联系销售伙伴支持之前收集以下信息：

- 有关订单编号、时间戳、时区、商城和订单卖家编号的信息

- 您看到的错误消息（如果有）

- 问题的屏幕截图（如果有）

## 系统要求

QZ Tray 可在 Mac OS、Windows 和 Linux 操作系统上使用。参见下方列表，了解支持的操作系统和互联网浏览器版本。有关更多信息，请参阅 [QZ Tray 网站](https://qz.io/wiki/faq)

**支持的操作系统：**

| 操作系统 | 最低版本 |
| --- | --- |
| Mac OS X | OS X 10.7 Lion 或更高版本 |
| Microsoft Windows | Windows XP 或更高版本 |
| Linux | Ubuntu 12.04 Precise 或更高版本 |

**支持的浏览器：**

| Web 浏览器 | 最低版本 |
| --- | --- |
| Safari | Safari 6.0.3 或更高版本 |
| Firefox | Firefox 31 或更高版本 |
| Chrome | Chrome 31 或更高版本 |
| Internet Explorer | IE 10 或更高版本 |
| Microsoft Edge | 20.x 或更高版本 |

## 在 Windows 操作系统上安装

如果您是上述支持版本的 Windows 操作系统用户，请按照以下步骤安装 QZ Tray 一键打印解决方案。

- 在卖家平台上，前往“管理订单”页面

- 点击“购买配送服务”，前往“购买配送服务”页面

- 在“购买配送服务”页面上，滚动到可以看到 QZ Tray 徽标的页面底部，点击【下载】

- 系统将提示您【重定向至 QZ Tray 外部网站】，点击【确认】

- 在 QZ Tray 网站上，点击 QZ Tray 下载图标开始下载

- 此时将出现一个弹出屏幕，点击【保存文件】

- 前往下载文件夹并【打开】下载的应用程序。弹出屏幕可能会询问“您要允许此应用对您的设备进行更改吗？”，点击【是】

- 此时会显示 QZ Tray 安装指南，点击 【Next】（下一步）

- 【选择】要安装 QZ Tray 的文件夹，然后点击 【Install】（安装）

- 完成安装后，点击 【Close】（关闭）

## 在 Mac OS 上安装

如果您是“系统要求”下所列支持版本的 Mac OS 用户，请按照以下步骤安装 QZ Tray 一键打印解决方案。

- 在卖家平台上，前往“管理订单”页面

- 点击“购买配送服务”，前往“购买配送服务”页面

- 在“购买配送服务”页面上，滚动到可以看到 QZ Tray 徽标的页面底部，点击【下载】

- 系统将提示您【重定向至 QZ Tray 外部网站】，点击【确认】

- 在 QZ Tray 网站上，点击 QZ Tray 下载图标开始下载

- 此时将出现一个弹出屏幕，点击【保存文件】

- 【点击】下载的文件并按照安装说明操作

- 完成安装后，点击 【Close】（关闭）

## 打印机设置

按照上文说明成功安装 QZ Tray 一键打印解决方案后，您必须将打印机连接到 QZ Tray 软件。以下是打印机设置步骤。

- 安装 QZ Tray 后，返回到“购买配送服务”页面。您会注意到，【一键式打印机】选项已启用，但默认设置为“无”，表示您尚未选择打印机

**注意： **如果您没有看到“一键式打印机”下拉菜单，请刷新网页，它应该就会显示。

- 点击【一键式打印机】下拉菜单，从连接的打印机中进行选择

- 当 QZ Tray 仍在尝试连接时，将在下拉菜单中显示【正在搜索打印机】

- 要配置打印机首选项（例如用于所有标签打印的默认打印机），请按照以下步骤操作：

- 前往“购买配送服务”页面底部的【打印机首选项】

- 此时会出现一个弹出窗口，其中包含每种标签格式的打印机首选项，每种标签格式的默认设置为“无”

- 从每种类型的标签格式下拉菜单中出现的所有已连接打印机中选择首选打印机

- 现在，您将在【一键式打印机】下拉菜单中看到您选择的首选项

## 标签打印方向

不同承运人的标签方向可能有所不同。在某些情况下，“购买配送服务”不会显示承运人标签方向。您可以从预定义的标签方向中进行选择，但您无法使用“购买配送服务”上的 QZ Tray 自定义此类标签的方向。要更改标签的打印方向，请执行以下操作：

- 在“购买配送服务”页面上，【选择】您将使用的承运人

- 点击【标签打印方向】，从预先确定的选项中选择不同的布局

- 如果您想进一步自定义标签打印方向，请在【一键式打印机】下拉菜单中选择【无】，然后点击“购买配送服务”。标签打开后，不使用 QZ Tray，也可以配置打印方向。

## QZ Tray： 故障排除

请注意，对于已安装 Print Connect 的所有现有卖家，Print Connect 仍将是默认选项。也就是说，如果出现任何 QZ Tray 问题，系统将默认使用 Print Connect（如果已安装）或进行普通打印（如果未安装 Print Connect），以便卖家能够继续使用标签打印功能。

【验证设置】

如果您在使用 QZ Tray 时遇到问题，请验证以下选项以确保应用程序设置正确。

【验证安装】

- 检查“购买配送服务”页面上的【一键式打印机】选项是否显示“您未安装一键打印”

- 如果 QZ Tray 应用程序已安装但未运行，请查找已下载的 QZ Tray 文件夹并打开文件

- 按照上述 QZ Tray 安装步骤进行安装

【验证首选打印机选择】

- 前往卖家平台中的“购买配送服务”页面

- 点击【一键式打印机】选项以检查连接的打印机

- 如果显示【正在搜索打印机】，说明 QZ Tray 仍在尝试连接

- 如果 QZ Tray 连接耗时很长，请联系[亚马逊销售伙伴支持](https://sellercentral.amazon.com/help/hub/support)

- 点击页面底部的【打印机首选项】选项，验证现有的首选打印机或保存任何新更改

【创建销售伙伴支持 TT】

如果您仍有问题，请创建一个[销售伙伴支持 TT](https://sellercentral.amazon.com/help/hub/support)。为确保我们的支持团队可以高效地为您提供帮助，我们建议您在联系销售伙伴支持之前收集以下信息：

- 有关订单编号、时间戳、时区、商城和订单卖家编号的信息

- 您设备的操作系统 (OS)（如 Windows 和 Mac），您使用的浏览器（如 Google Chrome、Mozilla Firefox、Safari），用于打印标签的打印机的型号和品牌，以及所选的标签格式

- 您看到的错误消息（如果有）

- 问题的屏幕截图（如果有）

【卸载 QZ Tray】

您可以按照您操作系统的卸载流程卸载 QZ Tray。卸载 QZ Tray 后，您可以使用亚马逊提供的另一个打印服务工具 Print Connect（如果已安装）。否则，您可以继续使用标准打印选项，点击“购买配送服务”页面上的“购买配送服务”按钮即可完成此操作。

适用于 Windows 操作系统：

- 点击 【Windows】 按钮。

- 前往【控制面板】。

- 前往【程序和功能】。

- 前往 【QZ Tray】。

- 选择【卸载】。

适用于 Mac OS：

- 点击程序坞中的【访达图标】

- 点击【访达边栏】中的【应用程序】。

- 如果 QZ Tray 应用位于一个文件夹中，请打开该应用的文件夹来查看是否有一个【卸载程序】
