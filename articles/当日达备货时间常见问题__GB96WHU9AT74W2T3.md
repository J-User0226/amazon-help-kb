# 当日达备货时间常见问题

#### 1.当日备货和当日达之间有什么区别？

当日达备货时间仅适用于国内标准配送和加急配送选项。仅在启用了“当日达备货时间”时，订单才需要在当日完成分拣、包装、发货和确认发货（取决于订单截止时间）。

而隔日达是一种优先配送选项，仅向达到较高配送标准的卖家提供。。亚马逊要求使用此选项的订单在当日完成取件、包装和配送。要了解有关优先配送选项和隔日达的更多信息，请参阅[优先配送](https://sellercentral.amazon.com/gp/help/external/201503640)。

#### 2.更新当日达备货时间的选项有哪些？

更新当日达备货时间的选项如下所示：

- 按 SKU 设置的备货时间

- 默认备货时间

**注意： **如果您启用了自动备货时间，则无法编辑默认备货时间。

**用于更新卖家平台上设置的特定于 SKU 的 0 天（当日达）备货时间的选项**

- 依次点击[库存](https://sellercentral.amazon.com/gp/help/help.html?itemID=/myinventory/inventory) > [管理所有库存](https://sellercentral.amazon.com/gp/help/help.html?itemID=/myinventory/inventory)。找到 SKU，然后点击【编辑】 > 【报价】 > 【备货时间设为 0】。有关更多信息，请参阅[管理库存](https://sellercentral.amazon.com/inventory/ref=xx_invmgr_dnav_xx?tbla_myitable=sort:%7b%22sortOrder%22:%22DESCENDING%22,%22sortedColumnId%22:%22date%22%7d;search:;pagination:1;)。

- 点击[此处](https://developer-docs.amazon.com/sp-api/docs/feed-type-values#listings-feeds)，通过开发人员文档中的 API 上传上传数据文件。

- 通过【批量上传商品】上传上传数据文件。

**0 天备货时间默认备货时间页面**

- 在卖家平台中，前往【设置】 > 【配送设置】 > 【一般配送设置】。

- 向下滚动至【备货时间】，然后点击【编辑】。

- 选择【当日达（0 天）】，然后点击【保存】。

**注意： **24 小时内，默认备货时间只能更改一次。更改最长可能需要 24 小时才会生效。

**通过上传数据文件更新特定于 SKU 的 0 天（当日达）备货时间的步骤**

- **使用库存加载工具：**

- 从[库存文件模板、风格指南和分类树指南](https://sellercentral.amazon.com/gp/help/external/G1641)页面导航至【选择文件模板】部分，然后下载**库存加载工具文件**。

- 仔细阅读库存加载工具文件中**数据定义**选项卡中的说明。

- 在**模板**选项卡中，填写所有必填字段（每行一个 SKU）

- 以制表符分隔文本格式（.xls 或 .tsv）保存文件。

- 依次点击【目录】 > 【批量上传商品】 > 【上传您的电子表格】以上传文件。

- **使用商品价格和数量文件：**

- 从[库存文件模板、风格指南和分类树指南](https://sellercentral.amazon.com/gp/help/external/G1641)页面导航至【选择文件模板】部分，然后下载**“商品价格和数量”文件**。

- 仔细阅读“商品价格和数量”文件的**数据定义**选项卡中的说明。

- 在**模板**选项卡中，填写所有必填字段（每行一个 SKU）。

- 以制表符分隔文本格式（.xls 或 .tsv）保存文件。

- 依次点击【目录】 > 【批量上传商品】 > 【上传您的电子表格】以上传文件。

- **使用商品信息加载工具：**

- 在[使用商品信息加载工具上传库存](https://sellercentral.amazon.com/gp/help/external/G201576570)页面，下载您的**商品信息加载工具文件**。

- 仔细阅读商品信息加载工具文件的**数据定义**选项卡中的说明。

- 在**模板**选项卡中，填写所有必填字段（每行一个 SKU）。

- 以制表符分隔文本格式（.xls 或 .tsv）保存文件。

- 依次点击【目录】 > 【批量上传商品】 > 【上传您的电子表格】以上传文件。

#### 3.此功能如何适用于 Prime 订单？

默认情况下，使用标准配送的 Prime 订单将在收到订单后的第二天发货。 您可以启用当日达备货时间为默认备货时间。启用后，您需要将所有配送方式的订单在当日发货。

**注意： **适用于卖家自配送 Prime 的所有配送模板都将配置当日达备货时间。

#### 4.当日达备货时间是否适用于“计划配送”？

不适用。目前，当日达备货时间不适用于“计划配送”。您可以为“安排配送”选项选择当日达备货时间。 有关安排配送的更多信息，请参阅[汽运零担 (LTL) 货件的货运配送模板](https://sellercentral.amazon.com/gp/help/external/G202188040)。

#### 5. 我是否需要将收到的每个订单都当日发货？

不需要。为避免延迟发货，**在订单截止时间之前**收到的所有订单都必须**在收到订单的当日**发货并确认发货。**在订单截止时间之后**收到的所有订单，则必须在不晚于收到订单的**第二天**发货并确认发货。

**注意： **默认截止时间是当地时间下午 2:00，您可以在您的[配送设置](https://sellercentral.amazon.com/sbr/ref=xx_shipset_dnav_xx)中对其进行编辑。

#### 6。当日达备货时间是否适用于我的所有商品？

这取决于您如何设置当日达备货时间。当您将当日达备货时间设置为默认账户备货时间，那么对于所有未单独配置备货时间的 ASIN 而言，都将适用当日达备货时间。如果您为某个 ASIN 配置了特定的备货时间，则其将覆盖默认备货时间。 如果您符合要求并在配送模板中设置了当日达备货时间，这将覆盖按 ASIN 设置的备货时间。
