# 卖家知识产权政策 - 商标

商标是一种[知识产权](https://sellercentral.amazon.com/gp/help/external/G201361070)，保护用于识别公司商品或服务的文字、符号和设计。

- **什么是商标？**

商标是指公司用于区别其商品或服务，并与其他公司的商品和服务进行区别的文字、符号或设计，或上述要素的组合（如品牌名称或徽标）。换句话说，商标表明了商品或服务的来源。一般来说，商标法旨在防止买家对商品或服务的来源产生混淆。

**示例：** “Amazon”是我们在许多商品和服务上使用的商标。其他的亚马逊商标包含图片和文字，如“Available at Amazon”商标。

![](https://d1n436oh1t0g4d.cloudfront.net/GY7X3DBUXLG4YQKP_Global_zh-CN.png)

- **商标所有者如何保护商标？**

商标所有人通常通过在特定国家/地区的商标局（如美国专利商标局）进行注册的方式来保护商标。在某些情况下，即使某标志从未在特定国家/地区的商标局注册，个人或公司也可能仅凭在商业应用中使用该标志的行为获得其商标权。这些权利称为“普通法”商标权利，可能受到更多限制。

- **商标法保护什么？**

一般来说，商标法保护商品和服务的卖家免于买家对特定商品或服务的提供商、认可方或从属方产生混淆。如果他人使用某种特定标志或易混淆的近似标志，可能导致买家对所售商品是否是商标所有者的商品产生混淆，那么商标所有者可以阻止他人使用该标志。

美国专利商标局提供了相关资源，可供您[了解有关商标的更多信息](https://www.uspto.gov/trademarks-getting-started/trademark-basics)。

- **商标显示在详情页面的什么位置？**

商标通常以商品详情页面上发布的商品和品牌名称的形式在亚马逊的商品详情页面、商品标题、“首行”、要点、商品描述、以及承运人或卖方处显示。例如，商标“Pinzon”会显示在品牌名称或如下所示的商品详情页面的“首行”部分。“Pinzon”商标也会出现在商品详情页面的商品名称部分（“Pinzon Flannel Sheet Set - King, Sage”）。在商品信息和品牌旗舰店中，可能还会显示公司的徽标。

![](https://d1n436oh1t0g4d.cloudfront.net/GQL56TBF8VFW25NV_Global_zh-CN.png)

- **我是否始终需要权利所有者的许可才能在创建商品详情页面时使用商标？**

使用他人商标时，必须慎之又慎。通常来讲，如果您在创建详情页面时未经授权使用商标，则当这一行为可能导致商品的来源、认可或从属关系发生混淆时，即构成侵权。但是，不是商标所有者不一定意味着您不能销售其他公司的商品。尽管如此，请务必清楚区分商品的来源（卖家和商标所有者）。

**示例：** 如果您正在销售正品 Pinzon 床单套装，且将商品作为 Pinzon 床单套装进行广告宣传，这可能不会让买家对商品的来源或从属关系（即，Pinzon）产生混淆，若确实如此，则并未对 Pinzon 商标造成侵权。

- **作为卖家，我可以在什么情况下使用他人的商标来创建商品详情页面？**

通常，卖家可以在以下情况下使用他人的商标：

- 如果销售正品，卖家可以使用商标名发布这些商品。例如，发布“Pinzon”正品的卖家不一定侵犯 Pinzon 商标的所有权，因为该卖家仅使用该商标来识别正品。

- 使用商标文字的普通字典含义时。

- 真实地陈述某商品与商标商品兼容时。例如，如果您提供与 Kindle 电子阅读器兼容的连接线，则可以在详情页面文本中使用品牌名称“Kindle”表示兼容性。您不应使用标志表示兼容性，只能使用品牌名称。您就兼容性做出的任何声明必须真实。

如果您想要在商品名称中表示您的商品与其他品牌的商品兼容，请使用以下格式创建商品名称，同时遵守[亚马逊品牌名称政策](https://sellercentral.amazon.com/gp/help/external/G2N3GKE5SGSHWYRZ)。如果您的商品名称不采用下述格式，您的商品信息可能会因涉嫌侵犯商标而被移除。

**品牌兼容商品的商品名称格式**

[您商品的品牌名称] + [商品名称] +“适用于”/“兼容”/“适合”/“可用于”+ [主要商品的品牌] + [主要商品名称] +（其他商品名称要素（如适用））

示例：

- Xandu USB 充电线，与 AmazonBasics 扬声器兼容

- 可用于 Kindle Fire 的 TonTon Sleeve

**无品牌兼容商品的商品名称格式**

“无品牌”+ [商品名称] +“适用于”/“兼容”/“适合”/“可用于”+ [主要商品的品牌] + [主要商品名称] +（其他商品名称要素，如适用）

示例：

适用于 AmazonBasics Waterfilter A3 的通用替换过滤器

**注意： ** 如果真实地宣称商品与商标商品兼容，请在要点和商品描述中使用上述表明兼容性的任一词语。

- 使用卖家自己的设备销售可供买家定制的正品（即按需打印）时。例如，卖家在正品“Callaway”高尔夫球上打印定制个性化消息或图片。

您有责任不配送侵犯商标所有者权利的订单。即使买家在其定制订单中向您提供了侵权内容，您也不得配送该订单。例如，如果买家请求在定制的 T 恤上添加亚马逊标志，则您不应同意配送此订单。

如果您想销售定制商品，请遵循以下指南：

- 按照以下步骤创建商品名称： 

品牌可定制商品的商品名称格式

“定制”/“个性化”[商品名称] +“创建自”/“个性化自”/“制作自”+ [主要商品品牌] + [主要商品名称] +（其他商品名称要素，如适用）

示例：

- 使用 Zippo Lighter 制作的定制打火机

- 使用 Yeti Tumbler 创建的个性化 Xandu Tumbler

- 如果您销售的是定制商品，请勿在商品图片中包含原始包装。

- 请勿在商品描述的品牌下发布您正在定制的商品的品牌。

- 在对两种商品进行比较时，可以从多方面加以比较，包括但不限于原材料、成分、性能、功效、口味和价格。您有责任确保您针对相应声明的贴标和宣传符合所有适用法律。

如果您想对两种商品进行比较性声明，请遵循以下指南：

- 所有声明必须真实无误。

- 所有声明必须在合理的基础上得到证实。所需证实的级别和类型取决于声明和商品类型。

- 如果针对不同分类的商品（例如化妆品与药物） 进行比较，则比较性声明必须明确指出两种商品之间的差异。

- 若比较性声明使用的是其他品牌的商标商品，则该声明所用语言必须阐明正在进行比较（例如使用“相较于”等字眼）以及比较依据（例如从效率方面加以比较）。

- 声明可以使用文字标记，但应避免使用徽标，且对比商品的展示效果不得比待售商品更突出。

- **如何确保在亚马逊上销售商品时不违反商标法？**

如果您决定在亚马逊商城销售商品，请先考虑以下问题：

- 销售的商品是否来自知名的分销商？

- 这些商品是如何获得的？如需验货，能否证明它们为正品？

- 描述这些商品的方式是否会让买家感到困惑？ 例如，商品详情页面对无品牌床单套装的某些描述是否会使买家认为他们购买的是 Pinzon 床单套装？

- 是否以不会造成混淆且真实的方式（通常允许）而非相似的方式（不允许）使用品牌名称或商标来描述兼容性？

- **什么是假冒？**

假冒是一种特殊的商标侵权行为。假冒是指在销售非商标持有人的商品时，非法全部仿制或部分仿制注册商标或与注册商标极其相似的商标的行为。

假冒的前提条件是在商品或包装上使用注册商标。注册商标可以保护所售商品的品牌名称、商品上的徽标或商品本身的形状或外观。如果商品在单独的商品详情页面上销售且未以不当方式使用注册商标，那么与注册商标商品形似或完全相同的商品便不属于假冒商品。但是，如果注册商标保护的是商品本身的形状或外观，那么相同的商品即使不带有品牌名称或徽标，也可能属于假冒商品。

**注意： **虽然不是假冒商品，但仍可能会侵犯他人的知识产权。您有责任确保自己不发布侵权商品。如果您对自己的知识产权或他人的知识产权有疑问，请咨询律师。

有关更多信息，请参阅[亚马逊防伪政策](https://sellercentral.amazon.com/gp/help/external/G201165970)。

#### 如何解决知识产权政策问题？

要解决侵犯知识产权的行为，请前往账户状况控制面板 (AHD) 的[账户状况](https://sellercentral.amazon.com/performance/dashboard)页面，然后选择侵权行为旁边的【提交申诉】以提供所需文件或信息。

#### 提交申诉时需要哪些文件和信息？

每种侵权行为都具有独特的体验，这些体验将显示在[账户状况](https://sellercentral.amazon.com/performance/dashboard)页面上。在申诉和争议过程中，您可以参阅[账户状况](https://sellercentral.amazon.com/performance/dashboard)页面，了解相关指导。

#### 商品与品牌如何关联？

亚马逊将品牌视为代表一款商品或一组商品的名称。同一品牌的商品在商品或包装上标有统一的名称、徽标或其他识别标记，用来将这些商品与不属于该品牌的相似商品区分开。要了解更多信息，请参阅[亚马逊品牌名称政策](https://sellercentral.amazon.com/gp/help/external/G2N3GKE5SGSHWYRZ)。

#### 什么是品牌注册？

品牌注册是亚马逊的权威服务，用于管理和保护品牌。亚马逊品牌注册是一项全球性服务，包含： (A) 品牌名称，(B) 品牌资料数据（例如，商标、徽标）以及 (C) 具有该品牌角色（例如，权利所有者、品牌代表）的账户。

#### 验证权利需要哪些文件？

在就强制措施提出申诉时，您通常需要提供发票或授权书 (LOA)，以证明他们有权销售相关商品。亚马逊将审核这些文件，以验证商品真伪或销售授权。如果商品经确认为正品，亚马逊将从您的卖家账户中移除强制声明。每种类型的侵权行为都具有独特的申诉步骤和要求。在申诉过程中，[账户状况](https://sellercentral.amazon.com/performance/dashboard)页面将针对其独特情况提供具体指导。

#### 有哪些商品发布规则和政策?

查看[商品详情页面规则](https://sellercentral.amazon.com/gp/help/external/G200390640)，了解亚马逊在编写商品信息以及添加和编辑商品详情页面方面的规则和政策。如果您是权利所有者或者想要了解有关不同类型的知识产权的更多信息，请参阅[权利所有者的知识产权](https://sellercentral.amazon.com/gp/help/external/GU5SQCEKADDAQRLZ)。

#### 什么是电子商务中的知识产权 (IP) 侵权行为？您如何确保它们符合要求？

如果未经授权使用受保护的知识产权，则会出现电子商务中的知识产权 (IP) 侵权行为。这包括未经授权使用版权材料、商标、专利或公开权。示例包括销售假冒商品和未经许可使用版权图片等。为避免侵权行为，您应获得适当的许可证、验证商品真伪、使用原始内容并提供准确的描述。任何未经授权的使用都可能导致法律和商城后果。如果您是权利所有者或者想要了解有关不同类型的知识产权的更多信息，请参阅[权利所有者的知识产权](https://sellercentral.amazon.com/gp/help/external/GU5SQCEKADDAQRLZ)。
