# Error 100429

## Error message

This contribution is not allowed to be submitted under Marketplace ID '${marketplace_id}' and Product Type '${product_type}'. As a result, this contribution was suppressed.

## Reason for error 100429

This error occurs for the following reasons:

- The product type selected doesn't allow specific types of contributions in that marketplace.

- You have tried to submit content that is restricted or not supported for the chosen product category.

- Marketplace and product type combination is invalid or not configured for contributions.

- Your account does not have the required permissions for this marketplace-product type combination.

## Resolve error 100429

To resolve the error, follow these steps:

- Review the feed processing summary report for the highlighted marketplace and product type.

- Verify the marketplace ID and ensure you are submitting to the correct regional marketplace for your product.

- Choose an appropriate product type that is supported in your target marketplace.
