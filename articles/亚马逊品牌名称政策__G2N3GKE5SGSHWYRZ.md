# 亚马逊品牌名称政策

亚马逊品牌名称政策要求卖家准确展示商品的品牌名称。该政策阐明了品牌商品和无品牌商品之间的区别。

## 亚马逊商城中的品牌如何定义？

亚马逊将品牌视为代表一款商品或一组商品的名称。同一品牌的商品在商品或包装上标有统一的名称、徽标或其他识别标记，用来将这些商品与不属于该品牌的相似商品区分开。

例如，Amazon Essentials 品牌下有多种商品，其中包括衬衫、太阳镜和钟表。所有 Amazon Essentials 商品都必须将“Amazon Essentials”作为品牌名称，无论其 ASIN 商品名称或卖家如何。

品牌名称（也称为品牌值）是商品信息页面中的一个字段。添加新商品时需输入此值。此品牌值应与商品品牌的名称保持一致，且不应为商品类型或商品描述。请务必提供准确的信息，以确保良好的买家体验。

品牌名称不能是 ASIN 的 SKU、对 ASIN 的描述或未体现在品牌商品或包装上的任何其他名称。商品和包装上的品牌标识必须为永久标识，即无法轻易移除。如果您已为自己的品牌注册商标或正在申请商标，则可以加入[品牌注册](https://brandservices.amazon.com/)计划。加入品牌注册计划后，可使用您的品牌名称作为品牌值来发布 ASIN。

禁止对 ASIN 品牌进行虚假展示。例如，如果您要尝试添加 Amazon Essentials 商品，则不能使用“Amaz0nEssent!al$”作为 ASIN 的品牌值。

## ASIN 品牌名称更正

您可以进行一些细微更正，例如修正拼写错误、大小写和法定缩写问题。要进行细微更正，请联系[销售伙伴支持](https://sellercentral.amazon.com/hz/contact-us)，选择【品牌 - 更新】作为问题类型，然后填写并提交表单。

## 无品牌商品

无品牌商品是指不属于任何可识别品牌的非品牌商品。非品牌商品没有独特的名称或徽标。例如，不属于某个品牌的智能手机壳就没有品牌标识。因此，此类 ASIN 的正确品牌名称值应为“generic”。

- 在无品牌商品的商品信息中使用其他品牌的知识产权，或者将品牌商品作为无品牌商品发布，均违反我们的商品发布政策。

- 如果您要新建无唯一标识（例如 UPC 或 GTIN）的无品牌商品，则必须先在所需商城和商品分类中申请 GTIN 豁免。要进行申请，请参阅[发布没有商品编码（UPC、EAN、JAN 或 ISBN）的商品](https://sellercentral.amazon.com/help/hub/reference/G200426310)。如果您想要新建没有任何商品编码的无品牌商品，请在要创建此商品的每个商品分类和商城中申请此项批准。

有关更多信息，请参阅[亚马逊无品牌商品政策](https://sellercentral.amazon.com/help/hub/reference/G84H3T69ZX762NWT)。

## 尝试创建或更新 ASIN 时的错误代码

如果您看到错误代码 5664、5665 或 5668，则是因为您所尝试创建的 ASIN 的品牌名称尚未获得亚马逊批准。要解决此类商品信息问题，您需要提交申请并随附特定文件。有关更多信息，请参阅[品牌名称批准要求和问题解决方案](https://sellercentral.amazon.com/help/hub/reference/G4LKBB2T7Q78CJRU)。

如果您看到错误代码 5461，则是因为您未获准为该品牌创建新的 ASIN。要解决此错误，您需要提交申请并随附特定文件。

有关更多信息，请参阅[错误代码 5461 和批准要求](https://sellercentral.amazon.com/gp/help/external/G8DUAKHVJGGRZ4CH)。

如果您看到错误代码 5885、5886 或 5887，则是因为您正在尝试添加报价或编辑无品牌 ASIN。

有关更多信息，请参阅[与亚马逊无品牌商品政策相关的错误消息](https://sellercentral.amazon.com/gp/help/external/G5VG3YWGGXF4Y5WB)。

如果您看到错误代码 5995，则是因为您正在尝试更新品牌名称，但未获得批准。

有关更多信息，请参阅[错误 5995](https://sellercentral.amazon.com/help/hub/reference/GPTQ2W7MDYJMPB97)。

**注意： **属于图书、音乐、影视和 DVD 分类或数字分类的商品不需要品牌值，无论是品牌商品还是非品牌商品。创建 ASIN 时，品牌名称可以留空。有关更多信息，请参阅[“BMVD”是什么意思？](https://sellercentral.amazon.com/help/hub/reference/G200384340) 有关包含多个品牌商品的捆绑商品的信息，请参阅[商品捆绑销售政策](https://sellercentral.amazon.com/help/hub/reference/G200442350)。 要了解更多信息，请参阅[商品详情页面规则](https://sellercentral.amazon.com/help/hub/reference/G200390640)和[亚马逊品牌注册](https://sellercentral.amazon.com/help/hub/reference/G202130410)，并观看[商品发布简介](https://sellercentral.amazon.com/learn/courses?ref_=SUTestClient&moduleId=4e1a71e7-388e-49ad-9752-866786639586&courseId=ae366239-3501-4608-b209-e7090ffbe1ab)。

#### 如何解决知识产权政策相关问题？

要解决侵犯知识产权的问题，请前往账户状况控制面板 (AHD) 的[账户状况](https://sellercentral.amazon.com/performance/dashboard)页面，然后选择侵权行为旁边的【提交申诉】并提供所需文件或信息。

#### 提交申诉时必须提供哪些文件和信息？

每种侵权行为都有各自的特点。这些特点将显示在[账户状况](https://sellercentral.amazon.com/performance/dashboard)页面上。在申诉和争议过程中，您可以参阅[账户状况](https://sellercentral.amazon.com/performance/dashboard)页面，获取相关指导。

#### 商品与品牌如何关联？

亚马逊将品牌视为代表一款商品或一组商品的名称。同一品牌的商品在商品或包装上标有统一的名称、徽标或其他识别标记，用来将这些商品与不属于该品牌的相似商品区分开。要了解更多信息，请参阅[亚马逊品牌名称政策](https://sellercentral.amazon.com/gp/help/external/G2N3GKE5SGSHWYRZ)。

#### 什么是品牌注册？

品牌注册是亚马逊的一项权威服务，用于管理和保护品牌。亚马逊品牌注册是一项全球性服务，其中包含： (A) 品牌名称，(B) 品牌资料数据（例如，商标、徽标）以及 (C) 具有该品牌角色（例如，权利所有者、品牌代表）的账户。

#### 验证权利需要哪些文件？

在对强制措施提出申诉时，您通常需要提供发票或授权书 (LOA)，以证明其有权销售相关商品。亚马逊将审核这些文件，以验证商品真伪或销售授权。如果商品经确认为正品，亚马逊将从您的卖家账户中移除强制措施声明。每种类型的侵权行为都具有各自的申诉步骤和要求。在申诉过程中，[账户状况](https://sellercentral.amazon.com/performance/dashboard)页面将针对不同情况提供具体指导。

#### 商品发布规则和政策有哪些？

请查看[商品详情页面规则](https://sellercentral.amazon.com/gp/help/external/G200390640)，了解亚马逊关于编写商品信息以及添加和编辑商品详情页面的规则和政策。如果您是权利所有者，或者想要了解有关不同类型的知识产权的更多信息，请参阅[权利所有者的知识产权](https://sellercentral.amazon.com/gp/help/external/GU5SQCEKADDAQRLZ)。

#### 在电子商务活动中，哪些行为构成知识产权 (IP) 侵权？如何确保这些行为合规？

如果未经授权使用受保护的知识产权，则会构成电子商务活动中的知识产权侵权。这包括未经授权使用受版权保护的材料、商标、专利或公开权。示例包括：销售假冒商品、未经许可使用受版权保护的图片等。为避免侵权行为，您应获得适当的许可，验证商品真伪，使用原始内容并提供准确的描述。任何未经授权的使用都可能导致法律诉讼和商城处罚。如果您是权利所有者，或者想要了解有关不同类型的知识产权的更多信息，请参阅[权利所有者的知识产权](https://sellercentral.amazon.com/gp/help/external/GU5SQCEKADDAQRLZ)。
