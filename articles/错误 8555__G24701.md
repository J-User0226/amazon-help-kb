# 错误 8555

Catalog data does not exist for this product. For more details, see http://sellercentral.amazon.com/gp/help/external/24701
如果您引用的 SKU 在亚马逊目录中不存在，就会出现此错误。可能是以下四种情况之一：
1. 您尚未将此 SKU 添加到亚马逊目录。
2. 库存文件或商品上传数据中之前存在的错误导致无法将此 SKU 添加至亚马逊目录。
3. 您引用的 SKU 不正确。
4. SKU 之前被从亚马逊目录中删除。

在您更正 SKU 或将 SKU 成功添加至亚马逊目录后，此错误便会消失。
