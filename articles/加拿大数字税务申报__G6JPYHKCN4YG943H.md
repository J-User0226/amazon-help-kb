# 加拿大数字税务申报

加拿大政府根据《所得税法》（加拿大）第 XX 部分出台了针对数字网站运营商的申报规则。这些规则要求为主要地址位于加拿大或某些合作辖区的卖家提供销售便利的在线平台或商城收集并核实卖家的信息和财务数据，然后向加拿大税务局申报。

为了遵守这些规则，我们必须做到以下几点：

- 收集并验证受影响卖家的具体信息，如纳税人识别号、公司注册号和地址。

- 向加拿大税务局申报这些经过核实的信息以及有关所得收入（未扣除亚马逊费用和销售税之前的总销售额）、缴纳的费用和收款信息的详情。

## 谁会受到影响

如果您满足以下所有条件，则需要申报相关信息：

- 您在亚马逊商城销售了商品

- 您的年销售额等于或超过 2,800 加元，或者您在当前或后续自然年内在亚马逊商城售出 30 件或 30 件以上商品。

- 以下其中一项： 

- 您居住在加拿大，在任一亚马逊商城开店，或

- 您居住在合作伙伴管辖区（见下文）并在 Amazon.ca 上销售商品。

## 合作伙伴管辖区

**这对您意味着什么？**

如果您的主要营业地址位于合作伙伴管辖区内，且您在 Amazon.ca 上销售商品：

- 根据这些规则，亚马逊需要收集并验证您的信息

- 我们会将您的信息上报至加拿大税务局

- 加拿大税务局可能会将您的信息告知您居住国家/地区的税务机构

如果您仅在加拿大境外的亚马逊商城销售商品，则加拿大的上报规则通常不适用于您。

## 如何遵守

为了履行您的数字税务申报义务，您可能需要根据要求向我们提供信息或证明文件，以便我们可以根据加拿大税务局的要求收集并核实应申报的信息。

必须提供的信息随您是以实体还是以个人身份开展业务变化。

| 信息 | 实体 | 个人 |
| --- | --- | --- |
| 姓名 | 否 | 是 |
| 公司法定名称 | 是 | 否 |
| 主要地址 | 是 | 是 |
| 纳税人识别号* | 是 | 是 |
| 商业登记证或许可证编号 | 是 | 否 |
| 出生日期 | 否 | 是 |

**注意： **“实体”是指法人或法定机构，如公司、业务关系、信托或基金会。“个人”是指不属于实体的卖家。

*纳税人识别号是一组用于识别实体或个人的唯一编号。对于加拿大卖家，纳税人识别号是您在加拿大税务局登记的社会保险号（个人）、商业号码（公司或商业关系）或信托号码（信托）。纳税标识号并非由亚马逊颁发，而是由加拿大税务局颁发。如果您对获取纳税人识别号有疑问，请直接咨询独立的税务顾问或加拿大税务局。

## 如何提供或更新您的加拿大税务信息

要提供或更新您的加拿大税务信息，请按照以下步骤操作：

- 在卖家平台的设置中，选择【账户信息】。

- 从左侧的菜单中，选择【税务信息】。

- 选择【增值税或商品及服务税登记号】，然后按照该页面上的步骤执行操作。

如果您未提供所需信息，或者我们不能对其进行验证，我们可能要向加拿大税务局报告此情况。如果您未在要求时提供纳税人识别号，那么加拿大税务局可能还会针对您的每一次此类信息不符处罚 500 加元。

## 常见问题

#### 这是新税种吗？

不是。加拿大的数字税务申报规则是基于经济合作与发展组织制定的示范规则而形成的透明规则。它们适用于所有数字网站运营商（如亚马逊）。

#### 此类申报义务是一次性的还是持续性的？

这是一项每年都需要履行的申报义务。此外，您有责任每 36 个月或每次更改上表中列出的数据时审查并更新可以向加拿大税务局申报的信息。

#### 我的主要地址在加拿大，但是我只在加拿大境外销售商品。我会受到影响吗？

会。数字税务申报规则适用于主要地址在加拿大或加拿大税务局确定的合作管辖区的卖家，不论您在哪个商城销售。例如，主要地址在加拿大但仅在美国商城销售商品的卖家将会受到影响。

#### 我的主要地址在加拿大，并在加拿大、美国和墨西哥商城中销售。所需信息必须添加多少次？

您必须分别在加拿大、美国和墨西哥的卖家平台账户中添加所需信息。

#### 我的主要地址位于合作伙伴管辖区（而非加拿大）。我会受到影响吗？

如果您在 Amazon.ca 上销售商品，可能会受到影响。如果您的主要地址位于合作伙伴管辖区（例如英国、爱尔兰或上述任何国家/地区），且您在 Amazon.ca 上销售商品，则根据加拿大的申报规则，亚马逊可能需要收集并验证您的信息。我们可能会将您的信息上报至加拿大税务局。

如果您仅在非加拿大亚马逊商城（如 Amazon.com 或 Amazon.co.uk）上销售商品，通常无需遵守加拿大的数字税务申报规则。但是，您可能需要遵守类似申报规则。

#### 如果我不能按时提供所需信息，会怎么样？

如果您不能按时提供所需的信息，我们可能会将这个情况向加拿大税务局报告。加拿大税务局可能还会根据具体情况要求您或亚马逊提供更详细的信息。

#### 如果我不提供纳税人识别号，我是否必须停止在亚马逊加拿大商城销售商品？

不会，就加拿大数字税务申报而言，即使您不提供纳税人识别号，也不影响您在亚马逊加拿大商城销售商品。但是，亚马逊可能需要向加拿大税务局上报该未提供纳税人识别号的情况，并且您每少提供一次纳税人识别号，加拿大税务局都有可能对您处以 500 加元的罚款。

其他国家/地区以及司法辖区（加拿大除外）的数字税务申报制度可能存在不同要求，如果您不提供纳税人识别号，亚马逊可能需要按照相应辖区的规定暂停您的销售权限。我们建议您仔细查看您收到的所有纳税人识别号请求以及针对各商城的具体要求。

#### 什么是可申报自然年？

可申报自然年为 1 月至 12 月。

#### 向亚马逊提供所有信息后会发生什么？

您在卖家平台中确认并提交信息后，我们将审核并验证这些信息。如果缺少数据，或者不能验证数据，我们可能会联系您，请您提供更多信息。
