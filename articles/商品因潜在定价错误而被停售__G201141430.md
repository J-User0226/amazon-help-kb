# 商品因潜在定价错误而被停售

当亚马逊检测到您的商品存在潜在定价错误时，我们会通知您，而且可能会停售受影响的商品，以避免可能产生负面买家体验。

您可以使用以下视图确定被停售的商品：
- 从【定价】下拉菜单中选择【修复价格警告】。
- 使用“【管理库存】”中的【非在售】筛选条件。

**您可以将最低价格设置为：[商品成本 + 亚马逊所收费用 + 期望的最低利润]。**
