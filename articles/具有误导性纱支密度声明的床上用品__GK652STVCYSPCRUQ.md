# 具有误导性纱支密度声明的床上用品

如果您要在亚马逊商城发布商品，则必须遵守与这些商品和商品信息相关的所有适用法律、法规、标准以及亚马逊政策。

## 亚马逊关于具有误导性纱支数声明的床上用品的政策

纱支密度是指每平方英寸面料中织入的纱线数量，其中包括横向和纵向纱线。亚马逊禁止在床上用品商品信息中提供误导性的纱支密度声明。本政策适用于在亚马逊商城销售且包含纱支密度声明的所有纯棉和棉混纺床上用品。

## 适用法律、法规和标准

亚马逊要求所有床上用品均应经过检测并符合下列法规和标准：

| 商品 | 法律、法规和标准 |
| --- | --- |
| 床上用品 | 以下所有项： 美国联邦贸易委员会 (FTC) 第 5 章诚信广告指南 ASTM D629（纺织品及纤维混纺成分定量分析） ASTM D3775:2023（机织物经纱/纬纱支数标准检测方法） |

## 亚马逊政策规定的可售商品的亚马逊合规性要求

您必须满足下列合规性要求：

| 要求 | 商品详情页面 | 合规性信息 |
| --- | --- | --- |
| 商品信息属性 | 必需 | |
| 声明 | 必须符合的要求 | |
| 文件 | | 必需 |

**商品详情页面**

商品详情页面必须满足以下所有条件：

【商品属性】

- 确切的纱支密度数值

- 面料成分百分比

- 编织类型，例如缎纹或平纹

- 商品尺寸和颜色

**声明**

所有商品信息内容均须准确且可核实，包括但不限于商品名称、要点、描述、图片、视频、包装和营销材料。

商品信息内容必须：

- 有经 ISO-17025 认可的实验室出具的有效检测报告作为证明

- 在商品名称、要点、描述、图片、视频和 A+ 商品描述中保持一致

- 商品包装和标签上的信息一致

商品信息内容不得：

- 包含夸大纱支密度的表述，包括但不限于“相当于”或“手感如同”

如果亚马逊发现某项声明违反此政策，您必须将其从所有商品信息内容中移除。移除此声明后，请截取移除前后的屏幕截图来证明已更新。然后，提交申诉以请求审核您的商品信息。

**合规性信息**

您必须直接向亚马逊提交以下信息：

**文件**

- 由经 ISO 17025 认可的实验室在过去 12 个月内出具的检测报告，证明商品符合以下所有要求：

- 对于纱支密度： ASTM D3775:2023

- 对于纤维成分： AATCC 20A 或 ASTM D629

- 与商品详情页面相符的纱支密度

- 与在亚马逊商城发布的商品一致的商品详情，例如 ASIN、颜色、尺寸和变体

- 商品收到时的照片，包括外包装和内包装

- 护理标签正面和背面的照片

**注意： **向亚马逊提供的所有检测文件必须显示“通过”或“不适用”的结果。若结果显示为“失败”“不合规”“不符合”或空白，将不予接受。

**提交文件和图片时，请确保：**

- 文件并非来自[暂时停用的验证实验室](https://sellercentral.amazon.com/gp/help/external/GQG5MW4Q93L59T5K)

- 提供的所有文件和图片必须真实，采用未经修改的原始格式，且并非电脑或人工智能生成

- 商品说明书、手册、安全信息、标签和警告均要采用目标销售国家/地区的语言

- 图片能够证明该商品与受检商品以及商品详情页面上发布的商品相同

- 图片必须展示商品或其包装的所有面

- 如果商品为套装或捆绑商品，请分别为套装或捆绑商品中包含的每件商品提供文档和图片

**注意： **请提供清晰易读的文档和图片，这样有助于降低批准流程出现延迟的可能性。

客户安全是我们的首要任务。我们保留随时要求您提供更多信息以验证商品安全性和合规性的权利。

**直接向亚马逊提交合规信息或申诉**

如果您的商品信息已停用，并且您需要提交合规文档，或者您认为您的商品无需满足此政策中的要求，请使用此部分。

要提交合规信息，或者对此要求提出申诉，请参阅[提交合规信息或申诉](https://sellercentral.amazon.com/gp/help/external/GC35Z63FGCUCUWXX)。

## 违反政策

对于不符合此政策的商品，亚马逊将采取相应措施。我们保留根据《亚马逊服务商业解决方案协议》采取任何进一步措施的权利，包括但不限于移除相关商品信息。
