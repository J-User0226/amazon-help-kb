# 亚马逊企业购托盘配送

**现在，亚马逊企业购买家所下的卖家自配送批量订单可以使用托盘进行配送。**

借助托盘配送功能，您可以将大型订单整合到一个托盘货件中，从而提高批量订单的成本效益，并改善亚马逊企业购买家的配送体验。

## 要向买家启用托盘配送选项，请按照以下步骤操作
1. 从卖家平台的设置菜单中，选择[【配送设置】](https://sellercentral.amazon.com/sbr/ref=xx_shipset_dnav_xx?ld=EM#shipping_templates)。
2. 点击【创建新配送模板】，然后创建配送模板或选择现有的货运配送模板或包裹模板。点击【确定】。
3. 在模板编辑器中，选中【托盘配送】旁边的复选框，以启用此配送选项。为此选项添加地区、运输时间和运费。

**注意： **
由货运承运人配送的托盘订单不受有效追踪率 (VTR) 约束。您还可以为托盘订单单独设置备货时间和运输时间，以保护您的准时送达率 (OTDR)，这些设置将反映在预计送达日期中。要添加托盘的备货时间，请前往[配送设置](https://sellercentral.amazon.com/sbr/ref=xx_shipset_dnav_xx?ld=EM#shipping_templates)中的【备货时间】。

托盘配送需要货运承运人。有关货运货件的详细信息，请参阅[汽运零担 (LTL) 货件的货运配送模板](https://sellercentral.amazon.com/help/hub/reference/G202188040)。我们建议您使用合作承运人来维持良好的有效追踪率，并确保买家可以在整个配送过程中追踪其包裹。您可以在【发货确认】页面查看合作承运人列表。

## 托盘配送如何运作
**托盘配送要求**： 订单商品数量必须大于 1，且重量必须接近或超过 500 磅，或体积足够大，需使用托盘运输。配送目的地必须是商业地址。

如果订单符合托盘配送要求，买家在结账时会同时看到此选项以及其他配送选项。您可以借助托盘配送选项让您的商品脱颖而出，因为这为企业买家提供了更多购买选择。

**买家下单后**： 您可通过以下途径得知买家选择了托盘配送选项：订单 API 中 getOrderItems 操作中的 【ShippingConstraints】 字段、“配送订单报告”中的【需要托盘】字段，以及卖家平台“管理订单”页面上的【配送服务】字段。

我们将为您提供买家的直接联系电话，以便您安排托盘配送。系统将告知买家，承运人将联系他们安排具体的送达日期和时间。

**退货**： 根据亚马逊退货政策，买家可以退回托盘订单中已残损或不想要的商品。

## 订单超过一个托盘
当您承诺进行托盘配送后，即使订单数量超过单个托盘的容量，您也应以托盘的形式配送整个订单。例如，如果订单商品需要 1.1 个托盘才能完成装载，那么您应根据需要将订单拆分为两个或多个托盘，并将整个订单以托盘的形式发货。

**重要： **您不能在发出一个托盘后，将其余商品作为包裹货件发出。遵循本指南，可确保买家以预期托盘装运的形式收到整个订单中的商品，同时保持托盘配送计划的一致性和效率。

## 要通过订单 API 获取托盘配送订单，请按照以下步骤操作
1. 使用以下端点对每个订单调用 getOrderItems 操作：
  - **HTTP 动词：** GET
  - **端点：**https://sellingpartnerapi-na.amazon.com/orders/v0/orders/{orderId}/orderItems
  - **路径参数：**orderId（必填）– 亚马逊定义的订单编号，格式为 3-7-7
  - **查询参数：** NextToken（可选）– 响应您之前的请求时返回的字符串标记

2. 当买家为订单选择托盘配送时，响应中将包含 ShippingConstraints 对象（具有以下字段）：
3. 名称 架构 描述
4. PalletDelivery（可选） enum (ConstraintType) 订单商品必须使用托盘配送。
5. **ConstraintType 值：**
6. 值 描述
7. MANDATORY 商品必须遵循限制
8. 如果买家表示订单需要使用托盘配送，请更新您的下游流程并安排托盘配送。

## 要通过订单报告获取托盘配送订单，请按照以下步骤操作
1. 在【配送限制】下启用【托盘配送】，以便您的订单报告在以后下载的报告中获取有关此字段的详细信息。
2. 下载订单报告时，请在【配送限制】下勾选【托盘配送】：
3. 字段值 含义
4. MANDATORY 这是托盘订单。订单商品必须使用托盘配送。
5. 如果【托盘配送】字段显示【必需 (Mandatory)】，请更新您的下游流程并安排托盘配送。

## 在卖家平台中查看托盘配送订单
对于托盘配送，您将在【管理订单】页面的【订单类型】下以及在【订单详情】页面的【配送服务】下看到托盘订单被自动标记为【托盘配送】。在您收到托盘订单时，系统将默认显示此信息。
