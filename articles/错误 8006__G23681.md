# 错误 8006

无法删除 SKU [%s]，因为它具有可售库存。要帮助将库存设置为零，请参阅 http://sellercentral.amazon.com/gp/help/23681



当您试图删除 Amazon.com 上仍旧在售的商品时，便会发生此错误。删除商品之前，您必须先将可售库存量设为零。这会造成无法在商品位于买家购物车时删除商品。



请注意，删除商品并不会将其从 Amazon.com 目录中删除。通常而言，最好将可售库存设为零，而不是删除该商品。



要使用制表符分隔的库存文件解决这一问题，您应：



- 在库存文件中将商品的数量更改为“0”（零）。


- 将更新-删除值设为“删除”。


- 重新提交库存文件。



要使用 XML 上传数据解决此错误，您应：



- 发布库存输入数据，并将此商品的数量设为“0”（零）。


- 发布此商品的商品输入数据，并在 XML 信封中将“操作类型”值设为“删除”。
