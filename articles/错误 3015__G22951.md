# 错误 3015

此商品现在与一个限制商品相匹配。您的报价将从 Amazon 中删除。

如果商品不再符合纳入到 Amazon 目录的相关要求，便会发生此错误。因法律和其他因素导致无法在 Amazon 上发布所有类型的商品。如果您认为此错误没有依据，请查看您的参与协议中的条款。
