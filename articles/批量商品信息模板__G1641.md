# 批量商品信息模板

批量商品信息模板是一种电子表格，您可以将其用于在亚马逊上批量创建和更新您的商品和报价，其中包含用于描述您商品的多个数据列。无需逐个添加商品，您可以在模板中填写多个商品的数据，然后一次性上传全部内容。

您可以将已完成的模板以 Excel 文件 (.xlsx) 格式提交。您无需将其保存或转换为制表符分隔格式。

**注意： **批量商品信息模板仅适用于专业销售计划。[详细了解销售计划](https://sellercentral.amazon.com/help/hub/reference/G64491)。

## 转换为最新模板

为优化您的商品发布体验并帮助买家做出更明智的购买决定，我们正在更新和改进我们的模板。

借助新增的转换功能，您可以将用于发布商品、管理库存及更新报价的模板无缝转换为最新版本。具体运作机制如下：

- 您在上传旧版模板时会收到一条通知，告知您该模板已停用。

- 点击【下载转换后的模板】。您的文件将转换为新版本，并显示在【模板下载历史记录】中。

- 下载并仔细查看转换后的模板，添加缺少的信息，然后提交。

转换过程会保留您的现有数据，因此您不必从头开始。新模板可能需要您提供更多商品详情，以确保商品信息质量上乘且具有竞争力。

**注意： **如果您先前使用的是特定分类模板或图书加载工具模板，则必须改用商品电子表格。如果您提交的是旧模板，可能会在处理报告中收到错误消息。

## 模板类型

有三种类型的模板。请选择适合您任务的一种：

| 模板 | 适用情况 | 您需提供 |
| --- | --- | --- |
| 商品电子表格 | 您要创建当前尚未收录在亚马逊目录中的新商品 | 完整的商品详情（商品名称、描述、图片、价格等）。每个文件最多支持 20 种商品类型。 |
| 商品信息加载工具 | 您要为亚马逊目录中已有的商品添加报价 | 商品编码 + 报价详情（价格、数量、状况）。无需商品详情，或仅需提供少量商品详情。 |
| 商品价格和数量 | 您要更新现有报价的价格和数量 | SKU + 新价格和/或数量。无需商品详情。 |

**商品如何匹配到目录**

上传模板时，亚马逊会使用您提供的商品编码（UPC、EAN、ISBN 或 ASIN）将您的商品信息匹配到目录中的现有商品页面。如果不存在匹配项，且您使用的是商品电子表格，则会创建新的商品页面。

如果为某个商品编码找到多个匹配项，商品信息加载工具可以比商品电子表格更轻松地帮助您解决匹配问题。

## 开始使用

| 如果您使用 | 转至 |
| --- | --- |
| 商品电子表格（新商品） | 使用商品电子表格添加和管理新商品，获取有关生成模板、填写商品详情和上传的分步说明 |
| 商品信息加载工具（现有商品的报价） | 使用商品信息加载工具模板添加和管理新报价，获取有关搜索商品、填写报价详情和上传的分步说明 |
| 商品价格和数量（更新现有报价） | 使用商品价格和数量模板更新报价，获取有关生成商品价格和数量模板以及更新商品信息的分步说明 |

## 上传前

在上传前，请确认您的文件符合以下要求：

- **文件格式：** 您可以将文件以 Excel 工作簿 (.xlsx) 或制表符分隔的文本文件（.txt 或 .tsv）格式上传。在上传前，您无需再将电子表格转换为制表符分隔格式。

**商品信息首选项**

商品信息首选项可让您保存默认属性值（例如“需要电池： 否”），并在下载或上传商品电子表格模板时自动应用这些值。这可以减少重复输入商品信息数据。

- **下载模板时：** 如果您为所选商品类型保存了首选项，则模板的第一行可以预填充您保存的值。

- 要保存或管理您的首选项，请前往[商品信息首选项](https://sellercentral.amazon.com/listing-preferences)。

**注意： **商品信息首选项仅适用于商品电子表格，不适用于商品信息加载工具模板或“商品价格和数量”模板。

**上传您的文件**

要上传文件，请按照以下步骤操作：

- 前往[添加商品](https://sellercentral.amazon.com/product-search/bulk)，然后选择【电子表格】选项卡。

- 在【上传您的文件】部分，选择您的库存文件。

- 选择【上传】。

**上传预览（最多包含 1,000 个 SKU 的文件）**

如果您的文件最多包含 1,000 个 SKU，并且使用商品电子表格，您可能会看到【验证您的文件】选项，而无法立即提交文件。这将打开在线电子表格视图，您可以在其中：

- 在提交前查看文件内容

- 查看电子表格中高亮显示的实时验证错误

- 直接于在线视图中修复错误

- 准备好后提交您更正后的文件

**注意： **只有新的商品信息（商品信息操作设置为“创建”或“替换”）才会在此体验中进行验证。上传预览不适用于商品信息加载工具模板或“商品价格和数量”模板。

**AI 优化（可选）**

对于最多包含 1,000 个 SKU 的商品电子表格模板文件，您还可能会看到使用 AI 优化商品信息的选项。这是可选的，如果您选择不优化，您的文件将进行验证或直接提交。

**注意： **AI 优化仅适用于商品电子表格。

**检查上传状态**

提交文件后，您可以追踪文件进度：

- 前往[添加商品](https://sellercentral.amazon.com/product-search/bulk)，然后选择【电子表格】选项卡。

- 点击【检查上传状态】。

状态部分显示：

| 列 | 描述 |
| --- | --- |
| 日期/时间 | 文件上传时间 |
| 批次编号 | 上传的唯一标识 |
| 状态 | 当前处理状态： 【处理中】或【完成】 |
| 结果 | 提交的 SKU 数量和成功数量 |
| 操作 | 查看处理报告或返回上传的链接 |

处理进行中时，结果会显示成功 SKU 数量为零。点击【刷新】可查看最新结果。上传历史记录显示最近 3 个月或最多 100 次提交。

处理时间取决于模板类型和文件中 SKU 数量。对于较大的文件，处理时间最长可能需要 8 小时。

## 下载处理报告

文件处理完成后，“结果”列将更新为最终数量。要下载此报告，请按照以下步骤操作：

- 在【检查上传状态】下查找您的提交内容。

- 点击【操作】列中的【下载处理报告】。

- 打开报告文件。处理报告是可重新提交的 Excel 文件，您可以在 Microsoft Excel 等电子表格程序中打开。

**解读处理报告**

处理报告包含两个部分：顶部的汇总和下方的详细错误信息。

**处理汇总**

报告顶部显示您提交内容的汇总指标：

| 指标 | 描述 |
| --- | --- |
| 已处理的 SKU 数量 | 此提交中已处理的 SKU 总数 |
| 成功的 SKU 数量 | 您的更改已应用于这些 SKU，无任何错误。前往“管理所有库存”查看当前状态。 |
| 成功但存在其他错误的 SKU 数量 | 您的更改已应用于这些 SKU，但其他字段存在错误。对于此文件中不存在的字段错误，请使用商品电子表格或前往“管理所有库存”进行修复。 |
| 因错误未成功的 SKU 数量 | 由于存在错误，您的更改无法应用于这些 SKU。对于此文件中不存在的字段错误，请使用商品电子表格或前往“管理所有库存”进行修复。 |
| 存在警告的 SKU 数量 | 此提交中存在警告的 SKU 数量。 |

**注意： **“成功”“成功但存在其他错误”和“因错误未成功”的总和等于已处理的 SKU 总数。

**SKU 级别的提交状态**

报告中的每一行都将**提交状态**列作为第一个字段：

| 状态 | 含义 |
| --- | --- |
| SUCCESS | 您的更改已应用，无任何错误 |
| SUCCESS (OTHER ERROR) | 您的更改已应用，但商品信息包含其他错误 |
| 错误 | 由于存在错误，您的更改无法应用 |

**错误详情**

每个错误行包含：

| 列 | 描述 |
| --- | --- |
| original-record-number | 发生错误的记录编号。 重要： 库存文件的前两行（标题）不计入记录。处理报告中的记录 1 对应库存文件中的第 3 行。 |
| error-code | 错误的编号。有关更多信息，请参阅模板文件中的“数据定义”选项卡，或查看错误代码说明。 |
| error-type | 警告： 数据已处理，但可能不会按预期显示。错误： 数据无法处理；记录未成功提交。 |
| error-message | 关于问题的简要说明，有时包括更正步骤。 |

**查看错误的提示**

- **按 error-type 筛选：** 对 error-type 列进行排序或筛选，以将错误消息（会阻止创建商品信息）与警告（仅供参考）区分开。

- **使用 SKU 列：** 报告中包含每个错误对应的 SKU，因此您可以准确确定受影响的商品。

**修复错误并重新提交**

- 打开您的原始库存文件。

- 对于处理报告中的每个错误，使用 original-record-number（实际的电子表格行需加 2）和 SKU 来找到对应的行。

- 根据 error-message 指导更正值。有关详细的错误说明，请参阅[错误代码说明](https://sellercentral.amazon.com/help/hub/reference/17781)。

- 保存您的文件。

- 前往[添加商品](https://sellercentral.amazon.com/product-search/bulk)并上传您更正后的文件。

您无需重新上传整个文件。您可以创建一个仅包含已更正行的新文件。
