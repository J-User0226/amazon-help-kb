# 错误 8335

## 错误消息

属性 ${attribute_name} 包含无效的商城 ${invalid_marketplace}。变体商城必须属于处理商城。要进行修复，请编辑上述属性以移除无效商城，或将商城替换为正确的值。请联系销售伙伴支持以获取更多帮助。

**注意： **亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。

## 导致错误 8335 的原因

出现此错误的原因如下：

- 您尝试创建或更新商品变体商品信息时，属性中指定的变体商城与提交商品信息的处理商城不匹配或者不属于提交商品信息的处理商城。例如，您试图在 Amazon.com 商城中创建变体关系，但属性引用了 Amazon.co.uk 或 Amazon.de 作为变体商城，或者您提交的上传数据包含对目标商城无效的商城编码。

- 您提交的商品数据在变体属性中包含商城代码，但这些代码无法作为当前操作的有效处理商城。

- 您使用批量上传上传数据或 API 集成跨多个商城创建变体商品信息，系统检测到您的属性中指定的变体商城与处理商城上下文冲突。

- 您提交的变体属性包含商城编码，但这些编码不属于您的卖家账户或特定商品分类允许的处理商城。

## 解决错误 8335

要解决此错误，请按照以下步骤操作：

- 识别无效的商城引用：查看错误消息以确定哪个 ${attribute_name} 存在问题以及哪个 ${invalid_store} 值导致了错误，然后检查您提交的商品数据，找到此商城编码在您的变体属性中的位置。

- 验证有效商城代码的方式：导航至【设置】并点击【账户信息】，确认您有权在哪些商城销售商品。请查阅亚马逊的商城编码文档，以确保您使用的是正确的商城代码。

- 编辑属性以移除或更正无效商城的方式：通过【库存】访问您的商品信息，然后选择【管理所有库存】。搜索 ASIN，然后点击受影响 SKU 上的【编辑】。找到错误消息中提到的变体属性，然后完全移除无效商城引用，或者将其替换为与您的处理商城匹配的正确商城代码。

- 在更正商城引用后重新提交您的商品信息或上传数据：将更改保存到商品信息编辑器中或重新上传更正后的库存文件，以便系统处理您提交的内容并验证商城引用是否正确。
