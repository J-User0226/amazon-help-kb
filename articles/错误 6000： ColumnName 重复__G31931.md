# 错误 6000： ColumnName 重复

列 *ColumnName* 出现多次。要更正此错误，删除所有重复的列并重新提交上传数据。

当您的文件中有多个列使用相同名称时，就会出现此错误。常见原因可能如下：
- 您修改了一个或多个列名称。
- 在创建文件时，多次导出了数据库中的同一列。

要解决该错误，您应该：
1. 将您的文件与卖家平台中的模板进行比较。
2. 确保文件中的列名称与模板中的列名称完全一致。
3. 确保每个列名称在文件中仅出现一次。
4. 保存所做的更改。
5. 重新提交文件。
