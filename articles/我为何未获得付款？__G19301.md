# 我为何未获得付款？

**旧版卖家平台**

您的付款可能正在处理中！ 亚马逊向您的银行账户发起存款后，此款项最多需要 5 个工作日才会到账。您可以在[付款控制面板](https://sellercentral.amazon.com/gp/payments-account/settlement-summary.html/)【付款控制面板】中查看任何结算周期的付款日期。

**新版卖家平台**

您的付款可能正在处理中！ 亚马逊向您的银行账户发起存款后，此款项最多需要 5 个工作日才会到账。您可以在[管理付款](https://sellercentral.amazon.com/manage/finance/payouts)中查看任何结算周期的付款日期。

请使用以下工具找出您未收到付款的原因。

**旧版卖家平台**

有关您最近 10 笔款项的问题：

- 请点击【结算一览】选项卡，然后从【结算周期】下拉列表中选择结算周期。

- 如果相关款项的结算周期仍未结束，即显示为【至今（打开）】，请等到结算周期结束。您可以在页面底部查看系统下次付款的日期。

- 如果您要找的付款属于一个较早的结算周期，请前往【所有结算】或【付款】选项卡。在这里，您可以在自定义日期范围内搜索，或通过滚动鼠标和点击翻页按钮手动浏览您的各项结算信息。

- 如果【付款状态】为【完成】的一笔成功付款未显示在您的银行账户中，请联系您的银行并提供追踪编码。您可以在【付款】选项卡中找到付款的追踪编码。

**新版卖家平台**

您可以在[付款摘要](https://sellercentral.amazon.com/amazonsell/payments?ref=homepage_redirect_ngs)（在表格底部）中查看最近的两笔付款。要查看过去的付款或其他付款详情，请访问[管理付款](https://www.sellercentral.amazon.dev/manage/finance/payouts)。付款周期为 14 天。您可以查看付款状态。付款状态：

- **即将开始**： 在**操作**下点击**请求付款**或查看余额（如适用）。偿还余额选项用于解决负余额问题。

- **已完成**： 查看追踪编码、付款周期和付款日期。

- **付款失败**： 您的付款可能因处理问题或存款方式问题而失败。您的资金将在下一笔计划付款中提供。点击操作卡片可查看失败的交易日期。

- **无付款**： 当结算周期无付款或余额为零时。

| 状态 | 描述 |
| --- | --- |
| 即将开始 | 付款已安排；请求立即付款、查看余额或偿还负余额。 |
| 运输中 | 付款已批准并正在转入您的账户；资金将在 1~3 个工作日内到账。 |
| 已完成 | 付款已成功到账；查看追踪编码、付款周期和付款日期。 |
| 已取消 | 付款因您的请求、付款方式问题或系统错误而取消；更新详情并请求新付款。 |
| 失败 | 因存款方式问题无法处理付款；资金将包含在下一笔计划付款中。 |
| 无付款 | 本期无付款；余额为零或无待结算交易。 |

保持您的卖家账户为最新状态且信用良好是确保您及时收到付款的最佳方式。以下是常见的付款延迟原因：

- [银行账户](https://sellercentral.amazon.com/sw/AccountInfo/DepositMethodView/step/DepositMethodView?ref_=macs_aidepvw_cont_acinfohm&)或[信用卡信息](https://sellercentral.amazon.com/sw/AccountInfo/ChargeMethod/step/View?ref_=macs_aichrgvw_cont_acinfohm)缺失或无效。您需要同时提供银行账户和信用卡信息，亚马逊才能将付款存入您的账户，因此，请务必在您的账户设置中提供最新信息。

**注意： **每当您添加或更新银行账户信息时，都必须等待 3 天的安全保留期，之后我们才能发起转账。因此，我们建议您不要在付款日期前的 3 天内更新银行账户信息。

- 付款时账户[负余额或零余额](https://sellercentral.amazon.com/gp/help/external/G16261)。出现这种情况可能是因为支付销售费用或为商品退款。在这种情况下，我们可能会从您的信用卡中扣除销售费用的金额。

- 根据[资金扣留政策](https://sellercentral.amazon.com/gp/help/external/G9RA9LYBJ3QP27M6)【资金扣留政策】，您的部分或全部资金可能会被扣留。

- 某个订单尚未确认发货。[有关更多信息，请参阅如何确认发货。](https://sellercentral.amazon.com/gp/help/external/200197960)

- 如需了解快捷支付付款以及款项尚未到账的常见原因，请前往[快捷支付常见问题](https://sellercentral.amazon.com/help/hub/reference/GA24UN79VBPKXZXX)【快捷支付常见问题】。

造成付款延迟的不常见原因包括我们为解决绩效问题而采取的措施或与您卖家账户相关的可疑活动。在这种情况下，您可以在[绩效通知](https://sellercentral.amazon.com/gp/customer-experience/perf-notifications.html)【绩效通知】中找到亚马逊发送的更多详情消息。
