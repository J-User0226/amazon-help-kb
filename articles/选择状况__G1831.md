# 选择状况

使用状况有助于您在一定状况范围下进行商品报价。对许多商品品类而言，卖家在多种状况下的报价有助于扩大买家可选择的购买范围。

买家查看商品页面时，他们会看到通用商品描述以及一系列购买选择。商品页面上的链接指向 

［
处于“二手”和“新品”
］
状况的商品。每种商品的商品信息会显示在该商品的所有卖家报价页上，并将按一定规律分组，以便买家可以根据商品状况或商品价格对商品进行排序和选择。

卖家也可以发布具有不同状况的商品。在【管理库存】页面上，点击下拉菜单中的 

［
“编辑”，
］
然后选择 

［
“添加其他状况”。
］
如此一来，卖家便可以创建具有其他状况的相同商品信息。

您可以为给定商品指定状况，但不同分类可用的状况不同。此外，某些分类只允许发布新品。有关各个分类可用状况的列表，请参见[状况指南](https://sellercentral.amazon.com/gp/help/external/200339950)。

您可以使用“添加新商品”工具、文本文件或 XML 上传数据提交商品并为商品指定相应的状况及添加状况说明。使用[添加新商品](https://sellercentral.amazon.com/gp/ezdpc-gui/start.html)工具时，您可从下拉列表选择商品状况。用于商品匹配的文本文件也要求包含商品状况。可以使用模板中的宏命令来选择状况数字代码。使用特定分类的库存文件时，对于提交时没有明确指定状况的所有商品，其商品状况均将设置为 

［
“新品”。
］
如在选择适合自己需求的商品发布工具时需要帮助，请参阅[比较并选择商品发布方法](https://sellercentral.amazon.com/gp/help/external/201576400)。

对于[媒介类商品（图书、音乐、影视）](https://sellercentral.amazon.com/gp/help/external/200384340)，强烈建议您指定状况。此外，收藏品书籍目录中批准上架的卖家可以使用特殊的商品信息属性，以在所有卖家报价页上增强特定状况详细信息的可见性。更多信息请参见下面的帮助页面：

- [收藏类图书的商品信息属性](https://sellercentral.amazon.com/gp/help/external/200386320)

- [收藏类图书的商品发布工具](https://sellercentral.amazon.com/gp/help/external/200406580)

- [商品信息中的照片](https://sellercentral.amazon.com/gp/help/external/201270290)
