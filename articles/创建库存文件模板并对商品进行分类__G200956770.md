# 创建库存文件模板并对商品进行分类

商品分类可以帮助买家在亚马逊商城搜索时找到您的商品。亚马逊会根据卖家提供的值来确定商品在亚马逊目录中的显示位置。如果此类信息缺失或不正确，买家将很难找到、比较和购买您的商品。

**重要： **库存文件模板仅供专业卖家使用。但是，[商品分类工具](https://sellercentral.amazon.com/productclassify)可供所有卖家使用。如果您之前已使用[分类树指南](https://sellercentral.amazon.com/gp/help/external/G1641)，则仍可使用这些文件。但我们建议您转用商品分类工具，因为该工具包含最新、最准确的亚马逊网站结构信息。有关更多信息，请参阅[使用分类树指南对商品进行分类](https://sellercentral.amazon.com/gp/help/external/G1661)。

要为您的商品确定相应的分类，专业卖家可以使用搜索工具和商品分类工具，如下所示：

- 前往【库存】选项卡，并选择[批量上传商品](https://sellercentral.amazon.com/listing/download)。【下载库存文件】选项卡会作为默认选项打开。

- 在【第 1 步： 选择您想要销售的商品类型】下，使用以下两个选项之一浏览您的商品所属的相应分类：

- 搜索工具： 

- 在搜索框中键入商品名称或商品描述关键词，然后点击【搜索】。

- 选择您要发布的商品的类型。点击【清除搜索】，进行下一项搜索。

**注意： **如果您要销售不同分类的商品，则可以进行多个选择。

- 商品分类工具：

- 选择商品所属的分类。

- 继续展开下级分类选项，直至出现【选择】按钮。

- 点击【选择】，将该分类添加到您的列表中。

- 重复上述步骤，为您的所有商品选择分类。

**注意： **如果某个商品旁边有锁定标志，则表示您需要获得批准才能在亚马逊商城销售此商品。有关更多信息，请参阅[需要批准的分类和商品](https://sellercentral.amazon.com/gp/help/external/G200333160)。如果无法找到您商品的类型，请在同一选项卡下方的【库存文件】部分下查找特定分类模板。仅当您无法使用上述工具找到您商品的类型时才可使用这些模板。

- 检查您选择的商品。您可以编辑您的商品列表，从中移除您不想在模板中包含的特定商品。

- 在【第 2 步： 选择模板类型】中，为您要生成的模板类型选择一种模式： 

- 高级： 包含与所选商品相关的所有属性（必填属性、首选属性和可选属性）。

- 自定义： 您可以选择与您要添加到模板中的上述所选商品相关的属性组。此外，它还包括必填属性。

- 点击【生成模板】。

**注意： **生成的模板将下载到您的浏览器中，可以将其保存到本地硬盘上。现在，可以为库存文件模板或 XML 上传数据填写与您的 SKU 相匹配的分类和其他商品数据。使用 XML 上传数据的卖家可以使用 [XML 上传](https://sellercentral.amazon.com/gp/help/external/G200374090)功能。

## 在库存文件中填写分类字段

要将您选定的分类添加至库存文件模板文件，请执行以下操作：

- 打开库存文件，然后选择【模板】选项卡。

- 对于模板的每一行（代表一个 SKU），首先从该行第一列中的有效值下拉菜单中选择【商品类型】。

- 然后从同一行的有效值下拉菜单中选择【商品类型关键词】。

**注意： **如果您想要发布具有不同【商品类型】的商品，可能需要生成包含该商品类型的新模板，以确保文件中存在所有必填属性。
