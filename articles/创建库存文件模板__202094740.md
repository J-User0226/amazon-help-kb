# 创建库存文件模板

**注意： **目前，此功能仅适用于专业卖家。

借助库存文件模板，您可以批量添加或编辑商品信息。库存文件模板是一种 Microsoft Excel 电子表格，包含使用不同属性或信息字段来描述商品的多个数据列。您可以根据自己的具体要求创建模板，并使用一个模板在多个分类下发布不同类型的商品。此模板将包含正确的分类节点，您无需再从分类树指南中查找它们。

**重要： ** 【转换为最新模板】
我们正在升级模板，以便优化您的商品发布体验并帮助买家做出更明智的购买决定。多个旧版模板即将弃用，并被经过改进的全新模板所取代。这包括用于发布商品、管理库存和更新报价的模板。为了实现无缝转换，我们创建了转换功能，可将现有模板升级为新版本。具体运作机制如下：
1. 您在上传旧版模板时，会看到一条关于弃用的通知。
2. 点击【下载转换后的模板】，我们会将您的文件转换为新版本。
3. 转换后的模板将显示在【模板下载历史记录】中，您可以从中下载模板。
4. 仔细查看转换后的模板，添加缺少的信息，然后提交您的模板。

转换过程会保留现有数据中的相关字段和值，因此您不必从头开始。但是，新模板可能需要您提供更多商品详情，确保您的商品信息质量上乘且具有竞争力。如果您想要改为下载空白模板，可在以下部分中找到相应步骤。

如果您先前使用的是特定分类的模板和图书加载工具模板，则现在需要使用商品模板。如果您提交的是旧模板，可能会在**处理报告**中收到一条错误消息。您可以前往[添加商品 > 电子表格 > 检查上传状态](https://www.sellercentral.amazon.com/product-search/bulk/generate/status)，点击上传状态旁边的**下载处理一览**，在新版本中下载您先前提交的数据。

**创建库存文件模板：**
1. 前往[添加商品 > 电子表格 > 下载空白模板](https://sellercentral.amazon.com/product-search/bulk/generate)。
2. 选择最符合您预期模板用途的卡片，包括但不限于发布新商品、更新商品价格和数量以及更新商品详情。
3. 如果要发布当前不在亚马逊目录中的商品，请前往[添加商品 > 电子表格 > 下载空白模板 > 发布当前不在亚马逊目录中的商品](https://sellercentral.amazon.com/product-search/bulk/generate/add-product)。
4. 使用以下任一方法选择您要销售的商品的类型：
  1. 【搜索工具】：
    1. 在搜索框中使用关键词或商品名称（例如“女士线帽”、“巴塔哥尼亚旅行海报帆布墙画”）描述您的商品，然后点击【搜索】。更详细的描述可以精简搜索结果。
    2. 系统会根据您的输入预先选择相关商品类型关键词，您可以在选择商品类型之前或之后编辑此列表。

  2. 如果您未找到想要销售的商品类型，可浏览**商品分类**：
    1. 选择商品所属的分类。
    2. 继续展开下级分类选项，直至出现【选择】。
    3. 点击【选择】，将分类添加到您的列表中。
    4. 重复上述步骤，为您的所有商品选择分类。

5. 检查您选择的商品。您可以对商品列表进行编辑，移除不想再包含在模板中的特定商品。
6. 选择您打算创建或编辑商品信息的商城；其他商城可取消选中。

## 填写模板
您必须使用商品模板来添加目前未列在亚马逊目录中的商品。此模板会显示必填、有条件必填和建议的属性。根据您在必填属性中输入的信息，有条件必填属性可能会变为必填属性。可选属性在每个属性组中处于折叠状态。要展开可选属性，请点击列顶部的“+/-”符号。或者，您也可以选择工作表左上角的“1”或“2”来展开或折叠所有可选属性。选择“1”将显示默认视图，选择“2”将显示包含所有属性的高级视图。在默认视图中，组中的第一个属性不会隐藏，以便于您找到特定的属性组。有关更多信息，请下载并阅读模板中的说明。
