# 错误 20007

One or more ImageType values are invalid.

For a list of valid values, see http://sellercentral.amazon.com/gp/help/25581

您在商品图片上传数据中提供的多个“图片类型”值中，有一个值无效。有效值为：

- MAIN

- SWATCH

- PT1 至 PT8

PT1 至 PT8 用于显示主商品图片的备选视图。有关可在商品图片上传数据中指定不同类型商品图片的更多信息，请访问[图片上传数据概览](https://sellercentral.amazon.com/gp/help/external/1171)
