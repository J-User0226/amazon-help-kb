# 使用库存文件添加商品

**Individual sellers：** 此功能适用于参与[专业销售计划](https://sellercentral.amazon.com/gp/help/external/64491)的卖家。

您可以使用库存文件模板同时添加多个商品信息。这些模板是用制表符分隔的文本文件 (.txt)，其中包含您在亚马逊商城发布商品所需的全部信息。

我们建议您在尝试使用库存文件模板之前对数据文件有一个基本的了解。

有关更多信息，请观看[卖家大学](https://sellercentral.amazon.com/learn/ref=xx_su_dnav_xx)中的【批量匹配或创建商品信息和变体】视频教程：

- 在电脑上安装电子表格程序（如果尚未安装），例如 Microsoft Excel。

- 确定您的商品所属的商品分类，并在[批量上传商品](https://sellercentral.amazon.com/listing)中下载相应的模板。

- 请求批准（如有必要）销售特定商品分类下的商品。要了解更多信息，请参阅[需要批准的商品](https://sellercentral.amazon.com/gp/help/external/G200333160)。

- 使用预填写模板在我们的目录中[搜索您的商品](https://sellercentral.amazon.com/help/hub/reference/G1641)，或使用商品编码[将您的商品匹配](https://sellercentral.amazon.com/gp/help/external/G1471)到我们目录中的商品。我们将按照以下顺序，根据您在文件中提供的信息为您的商品创建商品信息：

- **使用商品编码搜索商品： **使用 ISBN、UPC、EAN 或 ASIN 查找已存在于我们目录中的商品。转至[使用商品信息加载工具上传库存](https://sellercentral.amazon.com/help/hub/reference/G200231860)，下载预先填写的模板。

- **匹配 ISBN、UPC 或 EAN：** 如果您未使用预先填写的模板，但您的文件中包含某商品的商品编码（ISBN、UPC 或 EAN），且亚马逊中存在与之匹配的编码，我们将尝试为您的商品查找匹配项。

- **匹配制造商或书目信息：** 如果您的文件不包含特定商品的 ISBN、UPC 或 EAN 编码，我们将尝试根据您在文件中提交的制造商或书目信息进行匹配。创建商品信息要求达到精确匹配。

- **创建新的商品信息：** 如果我们无法使用商品编码、制造商信息或个人信息从现有目录中找出匹配项，但您在上传文件中提供了充分的数据，我们将为这些商品信息创建新的商品页面。

这些页面将显示您的库存，以创建可供买家购买的商品。如果没有充分信息与现有页面匹配或用来创建新页面，上传之后，您将在处理报告中收到一条错误消息。使用此报告可诊断和纠正上传文件中的错误。如您需要上传已编辑文件，请点击【返回上传页面】并重新上传您的文件。
