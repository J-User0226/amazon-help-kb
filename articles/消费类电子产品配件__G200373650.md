# 消费类电子产品配件

# 无媒体名称





品牌 + 系列 + 型号 + 容量 + 速度格式（每盒/轴数量）




**示例**：Memorex 8.5GB 8X 双层 DVD+R（50pk 轴）

# 音频视频线缆名称





品牌 + 系列 + 型号 + 声道 + 外形（长度（米）、颜色）




**示例**：Cables To Go Velocity 40315 HDMI 数字视频线（2 米，蓝色)
