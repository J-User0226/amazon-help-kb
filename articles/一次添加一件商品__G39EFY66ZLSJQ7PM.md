# 一次添加一件商品

[添加商品](https://sellercentral.amazon.com/product-search)工具是一个基于网页的交互式界面，用于一次发布一件商品。您可以通过以下方式开始发布商品：

- **添加报价：** 验证您的商品是否已在亚马逊目录中，并添加您的报价。
- **使用预填充工具发布商品：** 使用我们的 AI 预填充功能创建商品信息，以加快商品发布流程并节省时间。
- **从头开始发布商品：** 如果上述选项不起作用，请从头开始创建新商品信息

**注意： **如果您的同一商品有多个商品信息，请确保包含建议零售价的商品详情在所有这些商品信息中保持一致。

## 添加报价： 验证商品是否存在于目录中并添加您的报价
您可以通过两种方式添加报价： 搜索和商品编码。

- **使用搜索发布商品：**
  1. 前往[添加商品](https://sellercentral.amazon.com/product-search)。
  2. 在“发布商品”页面上，点击【搜索】。输入与您的商品相关的商品名称、描述和关键词，然后点击**【搜索】**。
  3. 在右侧面板中，我们将显示与您的关键词最匹配的商品。如果您确定了要发布的商品，请点击该商品，从“状况”下拉菜单中选择状况（“新品”“二手”“收藏品”或“翻新”），然后点击【销售此商品】。
  4. 在此页面上输入您的报价详情，然后点击【保存并完成】。

- **使用商品编码发布商品：**
  1. 前往[添加商品](https://sellercentral.amazon.com/product-search)。
  2. 在“发布商品”页面上，点击【商品编码】。输入您的商品编码（UPC、EAN、ISBN 或 ASIN），然后点击【提交】。 **注意： **您一次最多可搜索和发布 1,000 件商品。

  3. 您将转至交互式表单。输入您的报价详情，然后点击【保存并完成】。

## 使用预填充工具发布商品： 使用我们的预填充功能创建商品信息
您可以通过四种方式创建新商品信息：商品图片、Web URL、复制商品信息和商品信息首选项。

- **使用商品图片发布商品：**
  1. 前往[添加商品](https://sellercentral.amazon.com/product-search)。
  2. 在“发布商品”页面上，点击【商品图片】。点击【上传图片】以从您的设备上传商品图片，或者拖放图片，然后点击【提交】。
  3. 在【生成商品信息内容】部分，描述您的商品或点击【生成内容】。如果您对推荐的商品类型满意，请点击【确认】，或点击【选择其他】并找到与您的商品匹配的商品类型，然后点击【选择】。
  4. 我们将根据您上传的描述或图片，使用生成 AI 自动填写您的大部分商品详情，如商品名称、商品描述和要点等。您也可以点击【生成商品信息内容】框中的【编辑】，为图片和描述提供新的信息。
  5. 确认商品类型后，系统根据您提供的信息加载此表单。AI 生成的数据都将以黄色高亮显示。查看这些字段，添加必要的详细信息并修改 AI 生成的内容（如果需要）。
  6. 查看所有部分后，请执行以下操作之一：
    - 如果您希望稍后再完成商品信息，请点击【保存为草稿】。
    - 如果您的商品信息已准备就绪，可以发布，请点击【提交】。

- **使用网页 URL 发布商品：**
  1. 前往[添加商品](https://sellercentral.amazon.com/product-search)。
  2. 在“发布商品”页面上，点击 【Web URL】。输入您的品牌网站 URL，查看下方的法律免责声明，然后点击【提交】。
    - 如果 URL 无效，页面将提示存在问题。您可以修复该问题，然后重试。
    - 如果此 URL 有效，您将进入【补全您的草稿】页面，其中会显示成功提交消息。 **注意： **从网页 URL 导入商品数据最长可能需要 15 分钟。要检查是否有更新，请刷新页面。

  3. 如果我们发现您提交的 URL 属于已在亚马逊发布的商品，系统会自动将您转至商品信息表单，您可以在此表单填写报价详情，然后点击【保存并完成】。
  4. 如果尚未发现任何现有商品，亚马逊将根据您上传的 URL 使用生成 AI 自动填写您的某些商品详情，如商品名称、商品描述和要点等。点击【检查并提交】，查看商品信息草稿。
  5. AI 生成的数据都将以黄色高亮显示。查看这些字段，添加必要的详细信息并修改 AI 生成的内容（如果需要）。
  6. 查看所有部分后，请执行以下操作之一：
    - 如果您希望稍后再完成商品信息，请点击【保存为草稿】。
    - 如果您的商品信息已准备就绪，可以发布，请点击【提交】。

- **使用复制商品信息发布商品：**
- 您可以通过两种方式复制商品信息，即使用库存中的现有 ASIN 或使用亚马逊目录中的 ASIN。

  - **使用库存中的 ASIN 发布商品：**
    - **通过“管理所有库存”：**
      1. 前往[管理所有库存](https://sellercentral.amazon.com/myinventory/inventory)。
      2. 确定您要从中复制信息的商品。从商品右上角的下拉选项中，选择【复制商品信息】。
      3. 商品信息表单将包含您选择的 ASIN 的信息（包括商品和报价详情）。
      4. 按要求编辑您的商品信息，然后点击【提交】。

    - **从商品信息表单中：**
      1. 选择发布方式后，您将使用商品信息表单填写商品信息。
      2. 在商品信息表单的左侧面板上，点击【从现有商品复制】，在搜索栏中输入您的商品详情，然后点击【搜索】。
      3. 亚马逊将显示与您的搜索词最匹配的结果。找到您的商品并点击【选择】。
      4. 商品信息表单将包含您选择的 ASIN 的信息（包括商品和报价详情）。
      5. 按要求编辑您的商品信息，然后点击【提交】。

  - **使用亚马逊目录中的 ASIN 发布商品：**
    1. 前往[添加商品](https://sellercentral.amazon.com/product-search)。
    2. 在“发布商品”页面上，点击【搜索】。输入与您的商品相关的商品名称、描述和关键词，然后点击【搜索】。
    3. 在右侧面板中，亚马逊将返回与您的关键词最匹配的商品。点击您要发布的商品，然后选择【复制商品信息】。
    4. 商品信息表单将包含您选择的 ASIN 的信息（包括商品和报价详情）。
    5. 按要求编辑您的商品信息，然后点击【提交】。

- **使用商品信息首选项发布商品：**
  1. 选择一种发布方式并填写您的商品数据后，请选中“提交”按钮上方的【保存商品详情以备将来发布】部分中的复选框。
  2. 点击【商品属性】，然后选中您要保存以供将来使用的商品信息，然后点击【保存】。
  3. 当您日后使用同一商品类型创建商品信息时，请选择保存的【商品信息首选项】，以自动填写您的商品详情。 **注意： **可随时访问[商品信息首选项控制面板](https://sellercentral.amazon.com/listing-preferences)，查看和管理（更新或删除）您的商品信息首选项。

## 从头开始发布商品： 从头开始新建商品
如果上述选项不起作用，您可以按照以下步骤新建商品。

**使用空白表单发布商品：**

1. 前往[添加商品](https://sellercentral.amazon.com/product-search)。
2. 在“发布商品”页面上，点击【空白表单】，然后点击【开始】。
3. 在【商品名称】框中，为您的商品输入最合适的商品名称。亚马逊将根据您输入的商品名称建议合适的商品类型。
  - 如果您同意该商品类型，请点击【确认】，系统会将您重定向至商品信息表单。
  - 如果我们未提供商品类型建议，或者您对此建议不满意，请点击【选择其他】，找到与您的商品匹配的商品类型，然后点击【选择】。

4. 在【商品识别】、【描述】、【商品详情】、【报价】以及【安全与合规】选项卡中输入必填信息。 **提示： ** 使用页面左侧的属性筛选条件来查看所有属性或只查看必填属性。

5. **提示： ** 让 AI 帮助您编写商品属性或优化现有属性。点击“立即试用”，输入您的商品详情，然后点击“生成内容”。AI 建议显示为黄色，供您查看。

6. 输入所有必填商品信息后，请执行以下操作之一：
  - 如果您希望稍后再完成商品信息，请点击【保存为草稿】。
  - 如果您的商品信息已准备就绪，可以发布，请点击【提交】。

**注意： **当您使用**添加商品**工具上传主图片时，亚马逊会自动检查您的图片是否存在可能导致商品信息被禁止显示的合规性问题。如果检测到问题，在缺陷解决之前，您将无法提交商品信息。有关更多信息，请参阅[修复图片合规性问题](https://sellercentral.amazon.com/help/hub/reference/GBN4H9DXMKJK7MLY)。

**使用变体发布商品：**

1. 在[添加商品](https://sellercentral.amazon.com/product-search)工具中，确认商品类型后，您将看到发布变体的选项。选择【此商品具有变体】切换开关。这会将“变体”选项卡添加到左侧的追踪器中。
2. 在“变体”选项卡上，您可以选择商品的适用变体主题和选项。
3. 在【管理变体】部分，为您的每个子变体添加商品信息，如商品名称、图片和 SKU。您可以为每个变体添加自定义详情。您也可以使用【需要操作/已完成/未添加】等*状态*下拉选项筛选您的子 ASIN。
  - **注意： **处于“未添加”状态的任何变体 SKU 都不会保存为草稿，也不会提交。

  - **提示： **使用【批量编辑】选项，您可以一次性编辑所有子 SKU 的商品信息。为此，请点击“批量编辑”，选择要跨变体（SKU/商品编码/商品名称/图片）更新的属性，添加详情，然后点击**保存并继续下一步**。

4. 在【报价】选项卡中，您还可以【批量编辑】报价信息（商品价格/数量/状况/配送）。要执行此操作，请点击“批量编辑”，选择要跨变体更新的属性，添加详情，然后点击【保存并继续下一步】。

## 在多个商城发布
无论您是匹配现有的商品信息还是创建新的商品信息，均可在发布过程中使用以下步骤让您的商品同时在多个亚马逊商城上架。

1. 在“报价”选项卡中，选择【在其他亚马逊商城销售】切换开关。
2. 在【来源商城报价】部分，点击【编辑】并填写您的详情，例如 SKU、状况、数量、商品价格详情等，然后点击【确认】，之后再向其他商城添加报价。 **注意： **亚马逊将使用来源商城中的最终定价，预先填写您之前使用的商品价格和商城。对于新商城，请点击**销售**并按照后续步骤操作。如果您商城的详情页面尚不存在，我们将尝试使用相同的 SKU 和状况自动翻译您的本地内容。您可以稍后修改此内容。

3. 如果您想修改其他商城中的商品价格，请点击该商城的【编辑】按钮，然后点击【调整建立国际商品信息商品价格】以更新您的详情，然后点击【保存】。商品价格准备就绪后，点击【提交报价】。
4. 您也可以使用【定价规则】自动设置其他商城的定价。要执行此操作，请在您的来源商城中点击【编辑】。在【定价规则】部分，点击【添加定价规则】，设置定价操作，然后点击【保存】。有关定价规则的更多信息，请参阅[创建定价规则](https://sellercentral.amazon.com/help/hub/reference/G201995750)。 **注意： **
  - 定价规则会使用您在来源商城中设置的报价自动计算其他目标商城中商品的价格。
  - 您在来源商城进行的所有商品价格更改将会在目标商城中自动更新。
  - 定价规则会将您的报价自动换算为目标商城的货币（例如： 英镑到欧元）。
  - 如果您手动更新目标商城的报价，则会暂停对该特定 SKU 进行自动重新定价，且会保留您的手动选择，直至您恢复定价规则。

5. 商品信息准备就绪后：
  - 如果您希望稍后再完成商品信息，请点击【保存为草稿】。
  - 如果您的商品信息已准备就绪，可以发布，请点击【提交】。
