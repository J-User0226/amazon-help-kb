# 管理 Shopify 订单

使用多渠道配送 (MCF)，可以通过 Shopify 管理账户或您的亚马逊卖家平台账户管理 Shopify 商城的订单。您可以在一个位置查看和追踪所有 MCF 订单。

## 在您的 Shopify 管理账户中查看多 MCF 订单
1. 打开您的 Shopify 管理账户。
2. 在侧面菜单上，选择【订单】。
3. 在“订单”页面的右上角导航栏上，选择相关的亚马逊配送地址作为筛选条件。
4. 要进一步筛选订单，可以选择【所有订单】、【未配送订单】、【未付款订单】、【未完成订单】或【已完成订单】。

## 在卖家平台中查看 MCF 订单
**注意： **您可以在卖家平台中查找特定的 MCF 订单，也可以筛选所有 MCF 订单。

1. 登录与 Shopify 商城关联的亚马逊卖家平台账户。
2. 从左上角的菜单中选择【订单】，然后再选择【管理订单】。
3. 要查看所有 MCF 订单，请先筛选“销售渠道”，然后选择【非亚马逊】。

## 查找特定的 MCF 订单
1. 在卖家平台左上角的菜单中，选择【订单】，然后再选择【订单报告】。
2. 生成相关日期范围的报告并在 Excel 中打开。
3. **注意： **Shopify MCF 订单遵循以下格式： **Shopify #1234-123456789**。第一个数字序列（# 之后的部分）是 Shopify 订单编号，第二个数字序列则是唯一的 MCF 订单编号。

4. 在 Excel 报告文件中，搜索相关的 Shopify 订单编号，例如 **Shopify #1234**。此编号可在 Shopify 管理账户中的“订单”页面找到。
5. 从 Excel 文件中复制您想查找的配送订单的完整字符串，例如 **Shopify #1234-123456789**。
6. 从左上角的菜单中选择【订单】，然后再选择【管理订单】。
7. 在卖家平台中的【管理订单】页面上，选择【查看 FBA 订单】。
8. 将整个字符串（例如 **Shopify #1234-123456789**）粘贴到右上角的搜索栏中，即可查找订单。

## 对订单进行筛选和排序
1. 打开您的 Shopify 管理账户。
2. 在侧面菜单上，选择【订单】。
3. 在页面右侧，点击排序或筛选条件按钮。
4. 输入筛选参数或排序参数，然后点击【筛选】或【排序】。

您可以按状态筛选退货：

- 已退货
- 正在处理退货
- 已申请退货
- 退货失败
