# 新鲜农产品

如果您要在亚马逊商城发布商品，则必须遵守与这些商品和商品信息相关的所有适用法律、法规、标准以及亚马逊政策。

## 亚马逊的新鲜农产品政策

在美国，美国食品药品监督管理局 (FDA) 根据《联邦食品、药品和化妆品法》（FD&C 法案）及其后续修订的法规（包括《食品安全现代化法案》(FSMA) 中的《产品安全规则》和《人类食品的预防性控制》）的有关规定，对新鲜农产品（包括幼芽）的质量、安全性和贴标要求进行监管。卖家必须注册为食品经营者，持有所有适用的许可证，并按照当地法律法规的要求遵守特定指南。向美国市场供应新鲜农产品的所有卖家必须遵守美国联邦法规第 21 卷第 110、112 和 117 部分的规定，恪守良好的农业作业和生产规范。

**注意： **亚马逊物流 (FBA) 不配送新鲜农产品、冷藏食品或冷冻食品。

**合规信息**

您必须直接向亚马逊提交以下信息：

**文件**

- 有效的、未过期的第三方食品安全审查证书，内容应涵盖以下方面：种植、收获、冷却、储存、包装和加工。您必须每年或在新生长季开始时更新合规文件。可接受的审查方案包括：

- 《全球食品安全倡议》(GFSI)，包括等效方案

- 良好生产规范 (GMP)

- 良好农业作业 (GAP)

- 此外，对于附录 A 中定义且附录 B 中列出的高风险的未加工农产品： 仅限《全球食品安全倡议》认可的审查方案，包括等效方案。亚马逊不接受高风险商品联合认证或多站点认证。

- 此外，对于附录 C 中列出的其余所有未加工农产品和不宜生食农产品：《全球食品安全倡议》认可的审核方案，包括等效方案、Primus 标准审查（良好生产规范或良好农业作业）和美国农业部统一审查（良好生产规范或良好农业作业）。如有要求，我们也可能接受其他审查方案。

**注意： **如果您的第三方食品安全认证被暂停或取消，您必须在 24 小时内通过 [nbfs-team@amazon.com](mailto:nbfs-team@amazon.com) 通知亚马逊食品安全团队。

**附录 A：** 高风险新鲜农产品定义

高风险新鲜农产品是指未经加工或仅经过最低限度加工、可直接生食且本身具有食品安全风险的商品。这些商品在种植、收获、清洗、分拣、包装和运输过程中都会面临微生物危害。近几年来，此类风险引发了多起食品安全事故和商品召回事件。因此，亚马逊主动采取措施，严格管控生产和包装作业，在从农场到餐桌的过程中提高新鲜农产品的安全性。
