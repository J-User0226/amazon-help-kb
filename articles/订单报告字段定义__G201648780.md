# 订单报告字段定义

【订单】报告包含下列字段。

此列表并不详尽。订单报告可能还包含其他字段。

| 列名 | 定义 |
| --- | --- |
| 订单编号 order-id | 亚马逊为订单设置的唯一识别号码。用于发货确认和下单后的处理。示例： 058-3563777-5518068 |
| 订单商品编号 order-item-id | 亚马逊为订单中的商品设置的唯一识别号码。用于发货确认和下单后的处理。 |
| 购买日期 purchase-date | 下单日期，采用“yyyy-mm-dd”的格式。 注意： 如果不另行指定配送交期，则表示您同意在此日期后的 2 个工作日内配送订单。 |
| 付款日期 payments-date | 买家使用信用卡付款且订单处理完毕的日期，采用“yyyy-mm-dd”格式。 |
| 买家电子邮件 buyer-email | 买家的电子邮件地址示例：johndoe@somecompany.com |
| 买家的全名 buyer-name | 买家的全名示例： John Doe |
| SKU sku | 库存单位。卖家为商品定义的唯一标识。示例： AA786936215595 |
| 商品名称 product-name | 商品详情页面和浏览器标题栏中显示的简短商品名称。示例： 滑雪板 |
| 购买数量 quantity-purchased | 购买数量。 |
| 货币 currency | 币种 示例： 美元 |
| 商品价格 item-price | 买家为商品支付的价格。所有金额均为相应数量商品的费用总和，而非单价。示例： 商品价格 = $10 数量 = 2 显示的商品价格 = $20 |
| 礼品包装价格 gift-wrap-price | 买家为礼品包装支付的价格。所有金额均为相应数量商品的费用总和，而非单价。 |
| 运费 shipping-price | 买家支付的配送费用。所有金额均为相应数量商品的费用总和，而非单价。 |
| 商品税 item-tax | 买家为商品支付的相关税费。所有金额均为相应数量商品的费用总和，而非单价。 |
| 礼品包装税 gift-wrap-tax | 买家为礼品包装支付的相关税费。所有金额均为相应数量商品的费用总和，而非单价。 |
| 配送服务 ship-service-level | 买家在订购商品时选择的配送类型；例如：标准、加急。 |
| 收件人姓名 recipient-name | “配送”地址的姓名字段。 |
| 收件人姓名 + 采购订单编号 | 当企业买家为卖家自配送订单提供采购订单编号时，可将此采购订单编号附加到订单详情、订单报告以及销售伙伴 API 中的【收件人姓名】字段。如果货件标签和装箱单上已包含采购订单编号，或者出于其他原因而不想包含采购订单编号，请禁用此功能。有关更多信息，请参阅我需要了解哪些有关装箱单和采购订单编号的信息？ |
| 配送地址（3 列） ship-address-1 | “配送”地址的第一行。 |
| ship-address-2 | “配送”地址的第二行。 |
| ship-address-3 | “配送”地址的第三行。 |
| 配送城市 ship-city | “配送”地址所在的城市。 |
| 配送省/州 ship-state | “配送”地址所在的州、省或地区。随原产国/原产地变化。 注意： 缩写可能因买家的输入方式而异。 |
| 配送邮政编码 ship-postal-code | “配送”地址的邮政编码。值的格式取决于目的国家/地区。 |
| 配送国家/地区 ship-country | 国际标准组织双字母国家/地区代码（符合 ISO 3166-2 标准）。示例： US |
| 礼品包装类型 gift-wrap-type | 买家选择的礼品包装类型。示例： 生日气球。 |
| 礼品赠言文本 gift-message-text | 买家的礼品赠言。 |
| 礼品包装价格 gift-wrap-price | 买家选择的礼品包装价格。 |
| 礼品包装税 gift-wrap-tax | 礼品包装支付的税费。 |
| 商品促销折扣 item-promotion-discount | 对符合满减或折扣促销条件的订单减免的金额。 |
| 商品促销编号 item-promotion-id | 与满减或折扣促销相关的促销编号。 |
| 配送促销折扣 shipping-promotion-discount | 对符合免费配送条件的订单减免的金额。 |
| 配送促销编号 shipping-promotion-id | 与免费配送促销相关的促销编号。 |
| 配送说明 delivery-instructions | 其他配送说明。 |
| 订单渠道 order-channel | 关于下单方式的信息。 |
| 订单渠道实例 order-channel-instance | 关于下单方式的信息。 |
| 是否为企业订单？ is-business-order | 表示订单是否来自亚马逊企业购买家。示例：是、否 |
| 采购订单编号 purchase-order-number | 买家的采购订单编号（适用于来自亚马逊企业购买家的订单）。买家包裹装箱单或包裹货件标签上必须包含此类采购订单编号。有关装箱单和采购订单编号的更多信息，请点击此处。 |
| 价格标示 price-designation | 表示买家所使用的企业商品价格类型。了解有关企业商品价格的更多信息。（仅适用于亚马逊企业购卖家计划。） |
| 买家公司名称 buyer-company-name | 创建订单的亚马逊企业购买家的注册公司名称。这是一个自由形式文本字段，可以输入字母数字字符。（仅适用于亚马逊企业购卖家计划。）示例： Acme Business Supplies, Inc. |
| 被许可方姓名 licensee-name | 买家提供的专业许可证上的个人姓名。 示例： Jane Doe 12345 |
| 许可证号 license-number | 买家提供的专业许可证号。 示例： 12345 |
| 许可证状态 license-state | 专业许可证号有效的状态。 示例： TX |
| 许可证有效期 license-expiration-date | 买家提供的专业许可证的有效期。 示例： 2016-08-20 |
| 地址类型 Address-Type | 表明买家的配送地址是办公地址还是住宅地址。 |
| 商品数量 Number-of-items | 表示 ASIN 中包含的商品总数。 |
| 是否已加入 Transparency 计划？ | 示例：是、否；表示 ASIN 是否已加入 Transparency 计划。了解更多信息。 |
| 全球快递 is-global-express | 表示订单是否来自全球快递计划示例：是、否 |
| default-ship-from-address-name | 卖家平台账户配送设置或模板中使用的库房或公司名称 |
| 默认发货地址（3 列）default-ship-from-address-field-1 | “默认发货”地址的第一行 |
| default-ship-from-address-field-2 | “默认发货”地址的第二行 |
| default-ship-from-address-city | “默认发货”地址所在的城市 |
| default-ship-from-address-state | “默认发货”地址所在的州 |
| default-ship-from-address-country | “默认发货”地址所在的国家/地区 |
| default-ship-from-address-postal-code | “默认发货”地址的邮政编码，值的格式取决于目的国家/地区。 |
| actual-ship-from-address-name | 在确认订单时选择的库房或公司名称 |
| 实际发货地址（3 列）actual-ship-from-address-1 | “实际发货”地址的第一行 |
| actual-ship-from-address-field-2 | “实际发货”地址的第二行 |
| actual-ship-from-address-field-3 | “实际发货”地址的第三行 |
| actual-ship-from-address-city | “实际发货”地址所在的城市 |
| actual-ship-from-address-state | “实际发货”地址所在的州 |
| actual-ship-from-address-country | “实际发货”地址所在的国家/地区 |
| actual-ship-from-address-postal-code | “实际发货”地址的邮政编码，值的格式取决于目的国家/地区 |
| TCM | 征税模式，征税责任方 |
| 配送计划（仅适用于拥有多位置库存的卖家） | 按位置和订单商品列出的建议配送数量。 注意： 如果卖家或 ASIN 未注册多位置库存计划，则此字段将留空。 要了解更多信息，请参阅适用于您业务的库存解决方案。 示例：[{"supply-source-id":"dccb797a-e611-4399-a03e-e412636c8d5","item-quantity":3"}, {"supply-source-id":"af5980ec-a34a-41b6-8fa7-bc9b0514e3f4","item-quantity":3}] |
| 一站式进口申报系统编号 | 商城的一站式进口申报系统编号。如果亚马逊已代收销售增值税，那么将商品从非欧盟地区配送至欧盟地区的卖家必须向承运人提供此一站式进口申报系统编号。该编号由 12 个字母数字字符组成，格式为 IMXXXYYYYYYZ |
| 配送设置自动化 | 识别订单是否与已分配给配送模板的 SKU 相对应。如果对应，亚马逊将（使用您的地点、买家地点以及您首选承运人的最新运输时间）自动代您计算运输时间。支持配送设置自动化功能的商城会显示列值。 |
| 买家请求的取消 | 应打开“买家请求的取消”的切换按钮，以获取订单报告中“买家请求的取消”的请求状态 |
| 备货时间设置 | 与卖家自配送订单备货时间计算方法相关的信息。所含要素如下： 备货时间为订单所涉 SKU 设置的备货时间，以自然日为单位。 备货时间来源包括以下值： “AUTOMATED”“SELLER_OVERRIDE”“SELLER_SET”“AMAZON_OVERRIDE”以及“UNKNOWN”。 有效备货时间用于计算订单送达日期的实际备货时间。实际备货时间可能会不同于设定的备货时间，因为需要考虑其他因素。这些因素包括：因在订单截止时间之后、在订单处理容量达到极限后或者在假日季或非营业日期间收到订单而导致延长的情况。 要了解更多信息，请参阅修改备货时间。 |
| 运输时间设置 | 与卖家自配送订单运输时间计算方法相关的信息。所含要素见下文。 运输时间显示将订单交给承运人后预计送达的自然日数。 运输时间来源 显示运输时间的预计方式。如果显示为“SELLER_SET”，则表示运输时间将根据您在配送模板中依据配送地区选择的值计算得出。“AUTOMATED”指亚马逊根据您的库房地点和买家地点以及您首选承运人提供的最新运输时间计算运输时间。 发货地址（国家/地区，州/省，市） 用于计算运输时间的发货地址。当运输时间来源为“SELLER_SET”时，此字段将留空。 要了解更多信息，请参阅修改运输时间。 |
| 亚马逊购买配送服务使用购买配送服务 | 表明货件标签是否是通过亚马逊购买配送服务购买的。支持亚马逊购买配送服务的商城会显示列值，对于未发货订单，此值为空。 要了解“亚马逊购买配送服务”的运作方式，请参阅购买配送服务如何运作？ |
| 首选送达时间 delivery-preferred-time | 买家希望包裹送达的首选时间。此字段为空表示企业在该期间不营业。 示例： {"BusinessHours": [ {"DayOfWeek": "TUE", "OpenIntervals": [{ "StartTime": {"Hour": 8, "Minute": 0}, "EndTime": {"Hour": 16, "Minute": 0}}]}, {"DayOfWeek": "WED", "OpenIntervals": [{ "StartTime": {"Hour": 9, "Minute": 30}, "EndTime": {"Hour": 15, "Minute": 30}}]}, {"DayOfWeek": "THU", "OpenIntervals": [{ "StartTime": {"Hour": 7, "Minute": 0}, "EndTime": {"Hour": 15, "Minute": 0}}]}, {"DayOfWeek": "FRI", "OpenIntervals": [{ "StartTime": {"Hour": 9, "Minute": 0}, "EndTime": {"Hour": 17, "Minute": 0}}]}], "ExceptionDates": [ {"ExceptionDate": "2024-02-14", "IsOpen": true, "OpenIntervals": [{ "StartTime": {"Hour": 9, "Minute": 0}, "EndTime": {"Hour": 17, "Minute": 0}}]}, {"ExceptionDate": "2024-03-09", "IsOpen": false}, {"ExceptionDate": "2024-08-31", "IsOpen": false}]} |
| 投件地点 drop-off-location | 买家希望将包裹投递到的首选地点。 示例： FRONTDOOR 表示配送至前门 REAR_DOOR 表示配送至后门 FRONTDESK 表示配送至前台 LOADING_DOCK_STAFF 表示配送至装卸垛口 PROPERTYSTAFF_MAILROOM 表示配送至邮件收发室 BUILDINGRECPTIONIST_CARETAKER 指将商品交给前台 |
| 托拍配送 pallet-delivery | 订单的配送限制，例如是否需要使用托拍配送订单。 示例： MANDATORY |

## 订单报告中的其他字段

**Notes：** 

- 【purchase-order-number】 是默认添加的选项，面向所有亚马逊企业购买家，可使用订单报告列选择器开启或关闭该字段。买家包裹装箱单或包裹货件标签上必须包含 purchase-order-number。有关更多信息，请点击[此处](https://sellercentral.amazon.com/gp/help/external/QBDHEYGMALGGASA)。亚马逊企业购买家可以同时选择或取消选择【企业购买家】和【企业商品价格】，也可以单独选择或取消选择【公司名称】 。

- 如果您使用销售伙伴 API 检索采用 XML 上传数据的报告，则订单报告还包含其他字段。请访问[“定制信息”和“买家订单信息”字段](https://sellercentral.amazon.com/gp/help/external/200747980)。
