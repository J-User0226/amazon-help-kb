# 与亚马逊无品牌商品政策相关的错误消息

## 错误代码 5882

您不能创建品牌值为“无品牌”且侵犯某个品牌的[知识产权 (IP)](https://sellercentral.amazon.com/gp/help/external/G201361070) 的商品信息。在您的无品牌商品信息中使用其他品牌的知识产权，或者将有品牌商品发布为无品牌商品，均违反我们的商品发布政策。有关更多信息，请参阅[亚马逊品牌名称政策](https://sellercentral.amazon.com/gp/help/external/G2N3GKE5SGSHWYRZ)和[亚马逊知识产权政策](https://sellercentral.amazon.com/gp/help/external/G201361070)。如果您认为自己没有违反我们的[政策](https://sellercentral.amazon.com/gp/help/external/G84H3T69ZX762NWT)，请联系[销售伙伴支持](https://sellercentral.amazon.com/hz/contact-us)并提供错误代码 5882。

亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。

## 错误代码 5885

您不能更改商品详情页面，也不能为其他卖家的无品牌商品添加报价或将商品详情页面复制到另一个商城。如果您想要销售无品牌商品，请按照[添加商品](https://sellercentral.amazon.com/productsearch)中列出的流程创建新商品。有关更多信息，请参阅[亚马逊无品牌商品政策](https://sellercentral.amazon.com/gp/help/external/G84H3T69ZX762NWT)。如果您认为自己符合我们的政策，请联系[销售伙伴支持](https://sellercentral.amazon.com/hz/contact-us)并提供错误代码 5885 或使用亚马逊的卖家助手。

联系销售伙伴支持时，您必须提供以下信息：

- 商品名称

- SKU

- ASIN

- 如果您使用库存文件模板上传数据，请提供处理报告的批次编号。

- 商品或包装的真实图片，可清晰显示该商品为无品牌商品。

## 错误代码 5886

您不能更改商品详情页面，也不能为其他卖家的无品牌商品添加报价或将商品详情页面复制到另一个商城。如果您想要销售无品牌商品，请按照[添加商品](https://sellercentral.amazon.com/productsearch)中列出的流程创建新商品。有关更多信息，请参阅[亚马逊无品牌商品政策](https://sellercentral.amazon.com/gp/help/external/G84H3T69ZX762NWT)。

## 错误代码 5887

不得更改此商品详情页面。如果您想要销售无品牌商品，请按照[添加商品](https://sellercentral.amazon.com/productsearch)中列出的流程创建新商品。有关更多信息，请参阅[亚马逊无品牌商品政策](https://sellercentral.amazon.com/gp/help/external/G84H3T69ZX762NWT)。

## 我何时可以使用“generic”作为商品的品牌字符串？

如果您的商品不属于任何可识别的品牌，可使用品牌字符串“generic”。例如，不属于任一品牌的手机壳没有任何品牌标识，因此在创建新的商品信息时，您必须在品牌名称字段使用字符串“generic”。如果商品包含品牌名称或徽标，则不应使用品牌字符串“generic”。例如，如果商品包装显示品牌为“Amazon Basics”，则不应使用品牌字符串“generic”创建该商品。而应在品牌字符串中使用“Amazon Basics”。

| 商品图片和商品名称 | 商品的品牌字符串 | 备注 |
| --- | --- | --- |
| | Generic | 此品牌字符串正确。 品牌字符串为“Generic”，因为此商品不属于任何可识别的品牌。 |
| | Generic | 此品牌字符串不正确。品牌字符串为“Generic”，但商品属于可识别的品牌。由于商品来自 Kellogg's，并且该商品上有这一品牌，因此正确的品牌字符串为 Kellogg's。 |

## 如果我的商品与某个品牌商品兼容，我应该使用哪个品牌字符串？

品牌字符串应与商品一致。例如，如果某个无品牌的适配器充电器与某个品牌兼容，则应在品牌名称字段中使用品牌字符串“generic”。要了解有关兼容性条款的更多信息，请参阅[卖家知识产权政策](https://sellercentral.amazon.com/gp/help/external/G201361070)。

| 商品图片和商品名称 | 商品的品牌字符串 | 备注 |
| --- | --- | --- |
| | Generic | 此品牌字符串正确。商品名称表明兼容性，但并未暗示这是亚马逊商品。此品牌字符串为无品牌，因为该商品为没有品牌名称的非品牌商品。 |

## 我是否可以将商品的品牌字符串从“generic”改为某一品牌，或者从某一品牌改为“generic”？

根据[商品详情页面规则](https://sellercentral.amazon.com/gp/help/external/G200390640)，如果您使用品牌字符串“无品牌”或其本地翻译版本创建新商品，则以后将无法更改该品牌字符串。为保护商品的信誉，不允许将品牌字符串从“generic”改为某一品牌，或者从某一品牌改为“generic”。如果您选择更改商品的品牌，您必须创建新商品，而不是更新现有商品。即使商品为无品牌商品，并且在品牌字符串更改后没有实质性的变化，也应如此操作。其中包括为之前没有品牌的商品添加品牌。
