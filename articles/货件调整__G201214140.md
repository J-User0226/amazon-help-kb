# 货件调整

确定并解决入库计划中所列货件与运营中心所收货件之间差异的问题。

**注意： **要查询货件差异，请前往[货件](https://sellercentral.amazon.com/gp/fba/inbound-queue/index.html/ref=ag_xx_cont_fbashipq)并执行以下步骤：

- 找到您的货件，然后点击**追踪货件**。

- 在“货件一览”中，点击**物品信息**选项卡。

- 查看不一致问题并请求调查。

- 上传文件。

- 提供更多信息。

- 预览并提交申请。

对已发货库存进行货件差异查询通常需要 2 至 30 天。在某些情况下，最长需要 60 天。 您可以在“货件处理进度”中追踪货件的状态，状态会依次显示为【运输中】、【已送达】、【已登记】、【正在接收】和【已完成】。要了解更多信息，请参阅[亚马逊如何接收和储存您的库存](https://sellercentral.amazon.com/gp/help/external/G201081250)。

要了解如何为亚马逊物流货件提交货件差异查询请求，请观看此卖家大学视频。

**为常见货件问题查找解决方案**

**您的货件是否符合调查要求？**

只有状态为【已完成】的货件才符合货件差异查询的要求。货件差异查询工具中显示的资格日期是指您的货件准备就绪可供调查的预计日期。如果您的货件不符合货件差异查询要求，则可能是由于以下原因之一：

- 运营中心仍在处理货件。

- 货件尚未送达运营中心。

- 货件接收阶段正在等待确认最终商品数量。

- 发现您的货件中可能有其他商品，需要更多时间进行处理。

- 货件内商品已经全部接收，或者已完成货件差异查询。

**在哪里查看找到的商品？**

“差值”列显示了预计商品数量与已找到商品数量之间的差值，您可在【预计商品数量/已找到商品数量】列下找到这组值。将鼠标悬停在找到的商品数量上，您会看到有关已接收和已完成货件差异查询的商品的更多信息。

| “找到的商品数量”消息 | 描述 |
| --- | --- |
| 已接收 | 这些商品是通过标准接收流程统计数量的。已接收的商品数量显示在【物品信息】选项卡中。 |
| 已完成货件差异查询 | 我们会尽可能自动调查商品差异，并向您的货件增加或从中移除要完成货件差异查询的商品。 |
| 已赔偿 | 如果亚马逊应对丢失或残损商品负责，则会将其计为需赔偿的商品。赔偿金额列于【付款】报告的【交易一览】选项卡中。 |
| 找到的商品数量 | 找到的商品数量是指亚马逊已接收的商品数量和在货件差异查询期间更新的商品数量。所有找到的商品均可出售。 |
| 商品漏发 | 未发出的商品数量。 |
| 确认漏发商品 | 卖家确认其发出的商品数量少于其创建货件时最初输入的商品数量。 |
| 确认多发商品 | 卖家确认其发出的商品数量多于其创建货件时最初输入的商品数量。 |
| 不符合赔偿要求 | 被视为不符合赔偿要求的商品数量。 |
| 由于接收错误而调整的库存 | 在所有权转移盘点（而非接收）中转移回卖家的库存。 |
| 接收于货件 FBAXXXXXX | 从同一卖家的其他货件中重新分配的商品。 |
| 于货件 FBAXXXXXX 中按 FNSku BXXXXXXXX 接收的其他商品 | 从同一货件中收到的其他多余商品。 或 从相同或不同货件中收到的具有不同 SKU 的同款多余商品 或 与此货件中的不足量商品对应的其他货件（即商品置换）。 |

**有哪些不同的货件状态？**

状态列用于显示在您运往亚马逊的货件中每件商品的状态。

| 状态消息 | 描述 |
| --- | --- |
| 正在接收 | 商品正在接收。 |
| 需操作 | 商品存在差异，符合调查要求。必须先从下拉菜单中为处于此状态的每件商品选择一个选项，然后才能预览和提交调查申请。 |
| 已找到商品。无需操作 | 商品没有差异，因为已全部接收或已自动完成货件差异查询。无需执行任何操作。 |
| 等待接受危险品审核 | 为确保运营中心的库存对于买家和在运输途中的安全性，可能需要审核您的商品以确认符合我们的危险品要求。如果这些商品正在审核中，便无法被运营中心接收。了解有关亚马逊物流危险品审核流程的更多信息。 |
| 已完成调查 - 已清点并确认货件内商品 | 亚马逊已对送达的箱子或托拍及相关商品进行调查。如果看到您的商品被标记为【已完成调查】，即表示亚马逊在接收商品时进行了实物清点。在这些情况下，当运营中心开始接收商品时，亚马逊会先将接收的所有箱子与您入库计划中的预计箱数进行比较。然后，亚马逊再对入库的所有商品进行实物清点。当所有箱子情况已完成比较且实物清点完成后，我们会在卖家平台中将商品标记为【已完成调查 - 已清点并确认货件内商品】。 这些商品不再符合调查要求。 如果您可以提供信息来帮助找到任何缺少的商品，请联系销售伙伴支持。如果我们找到缺少的商品，会将其添加到您的库存中。否则，我们会将这些商品视为漏发，因此无法发放赔偿。 注意： 亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。 |
| 已提交问题单 | 已通过【物品信息】选项卡对商品提交调查申请，因此无需采取进一步操作。 |
| 索赔期限已过 | 根据亚马逊物流库存赔偿政策，货件的索赔期限已过。 |
| 2024 年 2 月 1 日之后创建的所有货件已于 45 天（国内货件）或 75 天（国际货件）后自动关闭。 | 货件已自动关闭。有关更多信息，请参阅追踪货件： 货件处理进度和货件一览。 |

**为什么我看到我的商品被作为卖家 SKU“Amazon.Found.Bxxxxxxxxx”接收？**

如果您的商品未正确贴标，它会作为同一 ASIN 的非已贴标库存被接收，其卖家 SKU 为 Amazon.Found.Bxxxxxxxxx；或者，如果您运送的商品与我们预期接收的商品不同，并且 ASIN 也不同，则收到的商品会作为卖家 SKU (Amazon.Found.Bxxxxxxxxx) 分配给您。我们创建这些卖家 SKU 的目的是可以将您的商品分配回您的账户。由于都是您的商品，所以可以通过为 Amazon.Found.Bxxxxxxxxx 卖家 SKU 创建商品信息来向买家销售这些商品。如果您没有为 Amazon.Found.Bxxxxxxxxx 创建在售商品信息，这些商品将显示在无在售信息的亚马逊库存报告中。如果您为 Amazon.Found.Bxxxxxxxxx 卖家 SKU 创建商品信息，则您在这一卖家 SKU 下的库存将需要接受虚拟追踪。您的其他已贴标库存不受影响。

**如何申请调查我的货件？**

对于货件中符合进一步调查要求的商品，您可以从【状态】列中选择“需操作”选项。必须先为处于“需操作”状态的每件商品从下拉菜单中选择一个选项，然后才能预览和提交调查申请。

| 需操作选项 | 描述 |
| --- | --- |
| 商品漏发 | 您确认您或您的供应商并未运送这些商品，或错发了其他商品。 |
| 调查缺少的商品 | 您确认货件中包含这些商品，需要亚马逊进一步调查。 |
| 运送了多余商品 | 您确认您或您的供应商运送了多余商品，或者与货件原记录不符的其他商品。 |
| 调查多余商品 | 您确认货件中未包含这些商品，需要亚马逊进一步调查。 |

**注意： **在提交调查申请之前，请进行货件差异查询，确认是否漏发或多发了商品。在提交调查申请之后，亚马逊将确认收到的商品数量，并尽力对漏发与多发的商品进行货件差异查询。进行此类货件差异查询不会影响您的可用库存。

**申请调查您的货件需要提供哪些文件？**

点击【选择文件】选择所有相关文件，然后点击【上传】，将文件附加到调查申请中。亚马逊会要求您提供一些文件来调查货件差异；上传这些文件可帮助亚马逊处理调查申请。

亚马逊要求在调查申请中同时提交库存所有权证明和交货证明：

- 库存所有权证明：此证明有助于找出任何可能存在的差异。可接受的库存所有权证明文件包括供应商提供的发票、其他卖家提供的收据或制造商签字的装箱单。

- 如果您使用发票作为库存所有权证明，则必须提供以下信息：

- 采购日期

- 与缺少的商品一致的商品名称

- 采购数量

- 如果您是制造商，则可以发送已签名的装箱单副本作为所有权证明。装箱单必须包含以下信息：

- 装箱单日期

- 货件编号或采购订单编号

- 缺少商品的商品名称

- 已发货数量

- 制造商签名或印戳

- 交货证明： 对于汽运零担或整车运输货件，请提供显示承运人取件时货件箱数和总重量的交货证明。您的承运人应有该文件的副本。这些信息有助于确认承运人是否按预期对整个货件进行了取件和运输。

**提示： **

如果您提供了收据或发票作为库存所有权证明，则不必展示您在采购这些商品时支付的价格。您可以隐藏或遮挡此价格。

我们不接受形式发票或类似的合同作为所有权证明，因为此类文件不能证明已完成采购。

发票和装箱单必须采用不可编辑的格式。发票必须明确由供应商或制造商开具。请注意，我们不接受 Excel、Word 或其他可编辑格式的文件。因此，我们要求您向我们提供原始发票的扫描件或图片，格式为 PDF、JPG、JPEG、PNG 或 TIFF。

**向销售伙伴支持团队提供说明时应包含哪些内容？**

对于其他任何差异，您都可以要求销售伙伴支持进行调查。请在提供的表单中说明存在的差异。此信息可以帮助亚马逊尽快完成调查并解决问题。

| 信息类型示例 | 描述 |
| --- | --- |
| 任何已知的差异 | 您或您的供应商实际运送的商品是否多于或少于之前计划的数量？ 是否运送了错误的商品？ |
| 发货箱描述 | 亚马逊会在运营中心进行实地调查，因此发货箱的颜色、尺寸或特殊标记等信息可以帮助我们更快地找到您的箱子。 |
| 商品编码 | 请核对您商品的 UPC、EAN 或 JAN。该编码是否与卖家平台上显示的商品编码相同？ |
| 任何遗漏的预处理工作 | 如果商品在发货前未进行正确的预处理，可能会导致接收过程出现延迟，因为我们必须为您的商品进行预处理。 |

**提交申请后，我需要做什么？**

对货件中余下的差异进行分类后，点击【预览申请】，查看其中的信息，如果准确无误，则点击【提交申请】。提交之后，系统将对需要调查的商品创建问题单并发送给销售伙伴支持。

提交申请后，您会得到一个问题单编号。此编号还会在您下次访问页面时显示在【物品信息】选项卡中。您可以点击问题单编号，或直接前往您的[问题日志](https://sellercentral.amazon.com/cu/case-lobby?ref=xx_caselog_count_home)，查看状态更新和沟通信息。
