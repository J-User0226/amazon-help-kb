# 超龄库存附加费报告

该报告为您提供近期的超龄库存附加费明细，让您能够确认您在亚马逊运营中心内有哪些商品支付了超龄库存附加费，并查看已经支付的费用金额。

该报告列出了已支付超龄库存附加费的各个 SKU 的商品详情、商品数量、每件商品的体积和支付的总金额。请参阅[超龄库存附加费报告](https://sellercentral.amazon.com/gp/ssof/reports/search.html/?recordType=LONGTERM_STORAGE_FEE_CHARGES)。

对于在亚马逊运营中心存放超过 180 天的商品，我们会按总体积（以立方英尺为单位）收取超龄库存附加费。我们将使用报告中的以下列计算每个 SKU 的金额：(amount-charged) = (rate-surcharge) x (qty-charged)。【rate-surcharge】 列是每件商品的费率，其计算方式为 (per-unit-volume) x（附加费率）。附加费率因 【surcharge-age-tier】 而异，具体取决于[超龄库存附加费](https://sellercentral.amazon.com/gp/help/external/GJQNPA23YWVA4SBD)中显示的费率。要计算所有库存的超龄库存附加费总额，请下载该报告并计算 【amount-charged】 列中费用的总和。
