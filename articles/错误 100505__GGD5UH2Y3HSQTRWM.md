# 错误 100505

## 错误消息

您的融资报价的卖家价格与制造商建议零售价相比不正确。请更新您的卖家价格以激活报价。

## 导致错误 100505 的原因

出现此错误的原因如下：

- 您试图发布的车辆的融资报价超出亚马逊可接受的定价范围（与制造商建议零售价相比）。

- 您的汽车用品商品信息中包含的融资报价价格违反了亚马逊针对车辆融资报价的定价验证规则，该规则要求价格与制造商建议零售价保持合理的关系。

- 您提交的融资报价触发了亚马逊的自动定价验证系统，该系统检测到价格与制造商建议零售价的比率异常，表明可能存在数据输入错误或违反政策的情况。例如，如果您意外为车辆的融资价格输入 3500 美元，而不是 35000 美元，或者当您在制造商建议零售价字段而非卖家价格中包含经销商费用或融资费用时，会导致计算不匹配。

- 您创建或更新了车辆商品信息，与公开的制造商建议零售价相比，融资价格与车辆状况、型号年份或市场定位不符。

- 您提交的批量上传上传数据或 API 包含的融资报价定价数据未通过根据为汽车用品商品信息设置的制造商建议零售价阈值进行的验证。

## 解决错误 100505

要解决此错误，请按照以下步骤操作：

- 查看您的当前融资报价价格和制造商建议零售价：导航至【库存】，然后选择【管理所有库存】。找到受影响的车辆商品信息，然后点击【编辑】。检查【融资报价价格】字段和【总制造商建议零售价】字段，以确定定价差异，并确定您的融资报价价格与制造商建议零售价相比是过高还是过低。

- 通过查看车辆制造商网站或官方经销商文档，从官方来源验证正确的制造商建议零售价。确认特定车辆的准确总制造商建议零售价，包括所有工厂安装选项和目的地费用，在调整融资报价之前确保您的制造商建议零售价数据正确无误。

- 计算适当的融资报价价格：确定能够反映市场状况、车辆状况、需求因素、融资条款和典型定价实践的真实融资报价价格，同时保持在制造商建议零售价的合理差异范围之内。

- 通过在相应字段中输入更正后的融资报价价格，更新融资报价价格，使其符合制造商建议零售价指南。在保存更改之前，确保价格的格式为不含货币符号或逗号的数值，并验证您的价格代表合格融资报价，而不是占位符或促销预告片。

- 重新提交并监控商品信息激活情况，让系统处理您的定价更新并验证融资价格目前在制造商建议零售价的可接受范围内。检查您的库存控制面板，确认商品信息状态更改为“在售”。
