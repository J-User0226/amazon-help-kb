# 错误 90004200

## 错误消息

“${attribute_name}”的值不含百分比（例如，此值仅为“棉”，而不是“100% 棉”）。有关更多信息，请将以下网址复制并粘贴到您的 Web 浏览器中：https://a.co/6YdsLVW

## 导致错误 90004200 的原因

出现此错误的原因如下：

- 列出的材质成分未提供要求的百分比值。

- 属性格式不符合正确的模式，例如，仅使用了“棉”，而不是“100% 棉”。

- 面料内含物信息不完整或格式不正确，或者列出了多种材质，而未提供其相应的百分比。

## 解决错误 90004200

要解决此错误，请按照以下步骤操作：

- 查看您的上传数据处理汇总报告。系统会突出显示存在错误的属性。

- 查看您商品的材质成分标签或制造商文件，了解所用每种材质的确切百分比。

- 更新材质信息，为每个组成成分提供具体的百分比。例如，“100% 棉”或“80% 涤纶，20% 棉”。

- 使用正确的格式列出多个材质成分，并验证所有材质加起来是否为 100%

- 更新属性值后，重新提交商品信息。
