# 浏览并搜索服装与配饰

买家来到 Amazon.com 购买商品。他们通过以下两种方式找到您的商品：浏览或搜索。通常，买家会浏览和搜索并用。请确保买家使用任一方式均能找到您的商品。您可以通过设置搜索项和商品类型关键词增加流量（适用于浏览）。





## 浏览





Amazon.com 上有数千位卖家销售着数以百万计的商品。为了帮助买家轻松找到商品，亚马逊开发了一套详尽的商品架构或浏览树状结构。买家通过类别和子类别链接不断精简搜索，直至找到最准确的商品类型。




亚马逊通过“商品类型关键词”在正确的流量节点中分类商品。为了确保您的商品在买家不断精简类别选项的同时始终出现，商品必须归类到最深的级别。这意味着 POLO 衫应归类到


*POLO 衫* 而不是 

*衬衫* 或者 

*服装*。





### 选择和使用浏览关键词





先分类商品，并参考库存文件模板中的
[“服装和配饰分类树指南”](https://sellercentral.amazon.com/gp/help/external/1661)(BTG) 
[和“有效值”表格](https://sellercentral.amazon.com/gp/help/external/1641)选择合适且相关的关键词。分类树指南是能够提供商品具体关键词的特定类型文件。




例如，您可以通过以下步骤分类女士小码牛仔裤紧身版：





- 请参见“服装和配饰分类树指南”，在指南中定位牛仔裤部分。




- 确定“商品_类型_关键词”（此案例中为“牛仔裤”）。




- 从“库存文件模板”（“紧身”）的 

*“有效值”选项卡中* 选择相应的合身类型。




- 从“库存文件模板”（“紧身”）的 

*“有效值”选项卡中* 选择相应的尺寸修改量。





**注意：** 



- “商品类型关键词”的拼写和格式必须与分类树指南中一致。




- 请确保以最具体的有效子类别选择关键词。





## 搜索





搜索项能够帮助买家找到您的商品。商品名称和公司名称本来就是可搜索的，因此请考虑商品描述的其他词语。




您可以站在亚马逊买家的角度考虑，使用他们在选择您的商品时，会在搜索栏中输入的词语，包括同义词。





### 选择和使用搜索项





- 每件商品可设置最多五个搜索项字段，每个字段长度限制为 50 个字符。




- 当买家搜索我们的网站时，我们的搜索引擎从您选择的词语中提取搜索项。




- 搜索项中已自动包括商品名称、卖家名称和品牌名称。您在手动添加搜索项时，无需重复提交上述词条。




- 商品名称字词和搜索项的任意组合均可搜索。





如果您使用库存文件模板上传您的商品数据，则搜索项字段将显示 

*搜索项 1、搜索项 2 *等。如需有关如何创建有效搜索项的更多信息，请参阅
[使用搜索和浏览](https://sellercentral.amazon.com/gp/help/external/10471)。




如果您使用 XML 上传您的商品信息，请了解
[如何使用 XML 分类您的商品](https://sellercentral.amazon.com/gp/help/external/1461)。
