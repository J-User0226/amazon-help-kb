# Amazon Handmade： 销售佣金

Amazon Handmade 卖家需要为售出的每件商品支付销售佣金。销售佣金可能是按统一百分比计算的费用，也可能是按商品计算的最低费用，以较高者为准，不会同时收取。这是在其他常规费用（如亚马逊物流费用或运费）的基础上加收的费用。因此，总费用可能高于下面列出的百分比。

按统一百分比计算的费用基于买家支付的总金额，含商品价格以及所有运费或礼品包装费，但不含通过亚马逊税务计算服务收取的任何税费。

| 销售佣金¹ | | |
| --- | --- | --- |
| Amazon Handmade 分类 | 亚马逊将扣除基于适用百分比计算得出的销售佣金或适用的每件商品最低销售佣金（以二者中金额较高者为准）。 | |
| 销售佣金百分比 | 适用的最低销售佣金（除非另有规定，否则按件收费） | |
| Amazon Handmade： 服装与配饰 | 15 % | $0.30 |
| Amazon Handmade： 服装 | 15 % | $0.30 |
| Amazon Handmade： 母婴 | 15 % | $0.30 |
| Amazon Handmade： 美妆和个护健康 | 15 % | $0.30 |
| Amazon Handmade： 家居 | 15 % | $0.30 |
| Amazon Handmade： 珠宝首饰 | 15 % | $0.30 |
| Amazon Handmade： 宠物用品 | 15 % | $0.30 |
| Amazon Handmade： 鞋靴 | 15 % | $0.30 |
| Amazon Handmade： 运动 | 15 % | $0.30 |
| Amazon Handmade： 玩具和游戏 | 15 % | $0.30 |

¹卖家需要为售出的每件商品支付销售佣金。

这些销售佣金仅适用于加入专业销售计划的获得批准的 Amazon Handmade 卖家。如果您是获得批准的 Amazon Handmade 卖家，但尚未升级到专业销售计划，则需支付亚马逊的标准销售佣金。

**注意： **
获得在 Amazon Handmade 店铺销售商品的许可并加入专业销售计划后，只要您拥有在 Amazon Handmade 店铺销售商品的许可且有符合要求的商品出售，那么您就无需支付专业销售计划费用。 有关 Amazon Handmade 权益的更多信息，请参阅 [Amazon Handmade](https://sellercentral.amazon.com/gp/help/external/G201817090)。
