# 错误 6000： URL 格式不正确

*URL* 格式不正确。

如果您提交的图片 URL 不符合一个或多个标准要求，则会发生此错误。有效的图片 URL 应符合下列要求：
- 以有效的文件扩展名结尾。
- 以“http://”开头。

有效的文件类型（及其扩展名）包括：
- JPEG (.jpg)
- GIF (.gif)
- TIFF (.tif)
- PNG (.png)
