# 合规性参考

合规性参考是专门用于培训和合规性评估的工具，旨在预览商品的最新合规性要求以及可帮助您满足这些要求的服务提供商。

**注意： **目前，并非所有商品类型都可在合规性参考中搜索到。如果您的商品未显示在搜索结果中，请转至[商品合规性](https://sellercentral.amazon.com/gp/help/external/GXMGGPL6LC4CVXHT)。

**搜索商品的合规性要求**

- 转至[合规性参考](https://sellercentral.amazon.com/ckp)，或转至[在亚马逊目录中查找您的商品](https://sellercentral.amazon.com/product-search?ref=xx_addlisting_dnav_xx)，然后点击[合规性自我评估](https://sellercentral.amazon.com/ckp)。

- 点击【确认】以遵守免责声明。

- 在【您想在哪里销售商品】下的下拉菜单中，选择相应的国家/地区。

- 在【搜索合规性】下方，按以下方法之一搜索商品：

- 点击【商品类型】选项卡，然后选择列出的商品类型。

- 点击 【ASIN】 选项卡，然后输入有效的 ASIN，并点击【搜索】。然后点击【查看合规性要求】按钮。

- 从下拉菜单中选择商品类型并输入商品关键词，然后点击【搜索】。

**注意： **如果您收到“未找到相关商品类型”的错误消息，那么目前合规性参考可能不支持您的商品。

- 要查看相关要求，请点击【查看帮助内容】按钮。

- 【商品合规性】选项卡列出了商品合规性要求。

- 要查看危险品合规性要求，请点击【危险品】合规性选项卡。选择适用于您商品的属性，然后点击【搜索】。

- 要查看出口贸易要求，请点击【出口贸易合规性】选项卡。从下拉菜单中选择商品的发货国家/地区。

- 要查看进口贸易要求，请点击【进口贸易合规性】选项卡。从下拉菜单中选择商品的发货国家/地区。

**注意： **如果此商品禁止在亚马逊商城销售，那么【查看帮助内容】按钮会禁用。

- 要选择服务提供商来帮助您满足要求，请从下拉菜单中选择【提供商位置】或【支持的语言】。

- 要下载 PDF 报告，请点击右上角的【下载要求】。

## 与您的商品相关的其他合规性要求

要查看适用于商品的欧洲法规要求，请完成以下步骤：

- 转至[合规性参考](https://sellercentral.amazon.com/ckp)，或转至[在亚马逊目录中查找您的商品](https://sellercentral.amazon.com/product-search?ref=xx_addlisting_dnav_xx)，然后点击[合规性自我评估](https://sellercentral.amazon.com/ckp)。

- 点击【确认】以遵守免责声明。

- 在【您想在哪里销售商品】下的下拉菜单中，选择相应的欧洲国家/地区。

- 转至【欧盟法规】选项卡。

- 点击【查看要求】。

- 在【查看要求】页面上，从选项卡中选择适用的法规，以查看相应的合规性要求。

- 要联系服务提供商来帮助您满足要求，请从下拉菜单中选择【提供商位置】或【支持的语言】。

- 点击右上角的【下载要求】下载 PDF 报告。
