# 举报违规行为

卖家在发布商品时有责任遵守所有法律、法规和亚马逊政策。亚马逊鼓励卖家举报商品信息滥用行为，以及违反亚马逊政策或适用法律的卖家行为。

我们的团队将对所有举报进行彻底调查。

出于保护隐私的原因，我们不能公开调查结果，但会采取我们认为适当的处罚措施。

违反政策是指卖家违反[销售政策和行为准则](https://sellercentral.amazon.com/gp/help/external/G1801)页面上所列活动的情况。

1. 前往[举报滥用行为](https://sellercentral.amazon.com/abuse-submission/index.html)。
2. 选择违规类型。
3. 提供相关的订单编号或 ASIN/ISBN（如适用）。
4. 务必在【描述您的问题】字段中填写以下信息（如适用）：
  - 被举报卖家的店铺或公司名称。
  - 商品详情页面中的 ASIN 或 ISBN 以及商品名称。
  - 发生违规行为的店铺。
  - 根据政策对违规行为进行简要说明。
  - 证明文件（例如：订单编号、相关消息或收据）。

5. 点击【提交】。

## 举报买家违规行为
对于与买家反馈相关的问题，请前往[反馈管理器](https://sellercentral.amazon.com/feedback-manager/index.html#/)，然后从【操作】列下的下拉菜单中选择适当的操作。

要举报买家发送的侮辱性消息，请使用[买家消息](https://sellercentral.amazon.com/messaging/inbox-v2?ct=&fi=RESPONSE_NEEDED&bt=&nt=&pn=1&pd=NONE&sd=&ed=&si=)。

**注意： **亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。
