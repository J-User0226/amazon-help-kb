# 卖家自配送 API 服务条款

本服务条款（以下简称“服务条款”）用于规范我们向您提供的一系列 API 的使用。这些 API 使您的系统能够与卖家可以使用的某些特性和功能进行交互（以下简称“卖家自配送 API”）。本服务条款是《亚马逊开店服务 API 开发者协议》（以下简称“协议”）的一部分，但是仅涉及和适用于您通过使用卖家自配送 API 或可通过卖家自配送 API 访问的服务（以下简称“服务”）而参与亚马逊开店服务 API（包括商城网络服务 API）的活动，除非另有明确规定。本服务条款中未定义的所有大写术语均具有协议阐明的相应含义。

如果您使用或获取卖家自配送 API 或服务的目的是将您的应用程序用于商业用途，那么您的应用程序必须符合亚马逊开店服务 API 规范规定的适用于卖家自配送 API 的所有技术和运营规范，并且不应限制（或允许任何人以您的名义限制）最终用户对卖家自配送 API 或服务的特性或功能的访问。您的应用程序必须突出显示卖家自配送 API 或服务的特性和功能，并且不应模糊处理这些特性和功能的访问权限。

通过您的应用程序，用户必须全年 365 天每天 24 小时随时可以访问卖家自配送 API 或服务的所有特性和功能。自您首次将应用程序用于商业用途之日起，每个月至少有 99.9% 的时间，从您通过卖家自配送 API 或服务收到信息到您通过应用程序显示或提供该信息的时间间隔将小于或等于 5 秒钟。

对于访问或使用卖家自配送 API 或服务，或者对于与卖家自配送 API 或服务相关的任何信息、功能或服务，您不应向任何卖家或其他最终用户收取任何类型的额外费用。

您不应通过卖家自配送 API 或服务禁用、隐去、替换、修改或添加亚马逊提供的费率，也不应显示或推广与亚马逊通过卖家自配送 API 或服务提供的费率不同的亚马逊费率。

您应向最终用户显示或以其他方式提供所有属性、版权信息、条款和条件或亚马逊可能提供给您的与卖家自配送 API 或服务相关的其他通知，不应移除、修改或隐去。

您只能代表请求使用服务的特定卖家或其他最终用户访问卖家自配送 API 或服务。

我们发出请求后，您应向我们提供应用程序访问权限，以用于测试和验证应用程序的特性和功能。您同意亚马逊监控您的应用程序，以确保质量、优化亚马逊商品和服务，并确认您遵守本服务条款和协议。
