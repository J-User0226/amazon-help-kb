# Amazon Handmade 个护健康用品指南

作为手艺人，您手工制作的个护健康用品类商品必须符合以下指南：

- 所有商品都必须符合[亚马逊一般政策和协议](https://sellercentral.amazon.com/gp/help/external/G521)的要求。

- 所有商品都必须遵守[分类、商品和发布限制](https://sellercentral.amazon.com/gp/help/external/G200301050)。

- 所有商品必须满足通用 [Amazon Handmade： 分类商品政策和要求](https://sellercentral.amazon.com/gp/help/external/GNGMMFQ5FPLJFBJP)。

- 禁止销售含有大麻的商品。查看[药物和药物用具](https://sellercentral.amazon.com/gp/help/external/G200164490)政策。

- 成人用品必须符合[成人用品政策和指南](https://sellercentral.amazon.com/gp/help/external/G200339940)的要求，且必须标记为“成人用品”。

- 商品必须符合亚马逊[化妆品和护肤/护发用品](https://sellercentral.amazon.com/gp/help/external/G200164470)政策的要求。
