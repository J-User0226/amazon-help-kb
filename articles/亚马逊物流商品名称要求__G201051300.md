# 亚马逊物流商品名称要求

商品名称要求适用于亚马逊全球所有商城的所有非媒介类商品，无论您是使用亚马逊物流还是卖家自配送方式都不例外。有关商品名称的主要要求以及优化商品名称的提示，请参阅[商品名称要求](https://sellercentral.amazon.com/gp/help/external/GYTR6SYGFA5E3EQC)主页面。 **重要： **要发送库存至亚马逊，您的商品必须包含税务属性，请参阅“亚马逊物流货件创建要求”了解如何进行更新。
