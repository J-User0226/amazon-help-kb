# 逐个管理您的商品

【管理库存】页面为您提供搜索、查看和更新商品及库存商品信息的工具。

有关更多信息，请参阅[管理库存](https://sellercentral.amazon.com/inventory)。

要了解有关查看、复制、删除或停售商品的更多信息，请参阅以下页面：
- 参阅[查看您的库存](https://sellercentral.amazon.com/gp/help/external/8GKMW7345AV3LCY)，了解按“状态”“SKU”“商品名称”等查看库存并进行排序。
- 参阅[编辑商品信息](https://sellercentral.amazon.com/gp/help/external/SGKAPSNT53G5B2P)，了解如何快速轻松地更改您的商品信息。
- 参阅[复制商品信息](https://sellercentral.amazon.com/gp/help/external/JAQ5MM8LB7MMZB7)，了解如何通过“复制商品信息”功能创建新的详情页面。
- 参阅[删除商品](https://sellercentral.amazon.com/gp/help/external/DMU6WZNPLTKM9J3)，了解如何从您的卖家账户中删除商品信息。
- 参阅[停售商品](https://sellercentral.amazon.com/gp/help/external/DJZDBNYUAS8C7QB)，了解如何停售商品。

有关重新发布商品、管理定价、查看销售历史记录和设置页面首选项的更多信息，请参阅以下页面：

- 参阅[重新发布处于非在售状态（已停售）的商品 - 非在售商品](https://sellercentral.amazon.com/gp/help/external/F5ES9LFB2RNU6R8)，了解如何重新发布商品。
- 参阅[商品被屏蔽的原因](https://sellercentral.amazon.com/gp/help/external/GGKKCTPTVTF95E5)，了解如何查找商品被屏蔽的原因。
- 参阅[添加商品图片和视频](https://sellercentral.amazon.com/gp/help/external/200216080)，了解如何为您的商品添加图片和视频。
- 参阅[更改商品分类](https://sellercentral.amazon.com/gp/help/external/201950630)，了解如何更改商品分类。
- 参阅[管理定价](https://sellercentral.amazon.com/gp/help/external/PTFQ566449VXXCP)，了解如何管理商品定价。
- 参阅[销售历史记录](https://sellercentral.amazon.com/gp/help/external/S3S7TP5FM7D5MEQ)，了解如何查看您的销售历史记录。
- 参阅[设置“管理库存”页面的首选项](https://sellercentral.amazon.com/gp/help/external/E7UVMSSJREL55WA)，了解如何自定义页面首选项。

## 处理商品信息中的建议
通过执行以下操作处理更多建议：
- [确保您的商品信息可见](https://sellercentral.amazon.com/gp/help/external/G2KNH9H3CXZN6ULZ) - 确保买家在搜索结果中可以看到您的商品信息。
- [改进商品信息](https://sellercentral.amazon.com/gp/help/external/G88AQCL62ED7WDGA)。
