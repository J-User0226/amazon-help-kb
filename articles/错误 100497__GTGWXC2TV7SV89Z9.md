# 错误 100497

## 错误消息

制造商建议零售价元素（例如，基础制造商建议零售价、原始设备制造商安装选项和目的地费用）不等于总制造商建议零售价。请更新制造商建议零售价数据以激活报价。

## 导致错误 100497 的原因

出现此错误的原因如下：

- 您提交了车辆商品信息数据，其中制造商建议零售价要素（如基础制造商建议零售价）、原始设备制造商安装选项、目的地费用和其他定价元素）在数学上不等于您提供的总制造商建议零售价。

- 您提交的商品上传数据或商品信息包含的制造商建议零售价定价数据存在计算错误、缺失要素或错误的值，导致系统无法根据单个定价元素的总和验证总制造商建议零售价。

- 您试图使用批量上传模板或 API 集成来创建或更新车辆商品信息，其中制造商建议零售价字段的填充不一致或存在格式错误，导致计算不匹配。

- 您提交的制造商建议零售价数据包含未正确计入【总制造商建议零售价】字段中的可选定价要素，或者总制造商建议零售价包含未细分到单个元素字段的要素。

## 解决错误 100497

要解决此错误，请按照以下步骤操作：

- 导航至【库存】，然后选择【管理所有库存】，查看您的制造商建议零售价要素值。找到受影响的车辆商品信息，点击【编辑】，并检查所有与制造商建议零售价相关的字段，包括基础制造商建议零售价、原始设备制造商安装选项、目的地费用和其他任何定价要素，以确定哪些值不正确或缺失。

- 计算正确的总制造商建议零售价。使用计算器或电子表格手动添加所有单个制造商建议零售价要素（如基础制造商建议零售价、原始设备制造商安装选项、目的地费用和其他适用费用），以确保准确求和，从而验证您的计算结果与来自官方来源（如车辆制造商网站或车窗标签）的制造商发布的制造商建议零售价数据相符。

- 更新制造商建议零售价字段：为每个要素字段输入准确的金额，确保所有值的格式均为不含货币符号或逗号的数字数据。

- 在重新提交验证计算结果：仔细检查基础制造商建议零售价、原始设备制造商安装选项、目的地费用和其他费用是否等于总制造商建议零售价。确认没有缺失或重复的要素，并确保所有值都代表制造商建议的定价，而不是经销商加价、折扣或买家协商的价格。

- 重新提交您的商品信息并监控激活情况：保存更正后的制造商建议零售价数据并允许系统处理您的更新。检查您的库存控制面板，确认商品信息状态更改为“在售”。
