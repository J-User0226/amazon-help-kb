# 默认运输时间

亚马逊在新[配送模板](https://sellercentral.amazon.com/gp/help/external/201834090)中设置了默认运输时间，如下表所示。默认运输时间设置将在您创建新模板时自动填充。如果您当前的承运人不能满足规定的最大默认运输时间，就必须在配送模板中重新设置时间。

## 国内卖家的默认运输时间

美国大陆所有州（美国本土的所有州，不包括夏威夷、阿拉斯加和美国保护国/地区）的建议运输时间为 2~4 个工作日。

| 地区 | 发货国家/地区 | 目的地 | 默认运输时间 | 可用的运输时间选项 |
| --- | --- | --- | --- | --- |
| 1 | 美国 | 美国大陆（美国本土的所有州，不包括夏威夷、阿拉斯加和美国保护国/地区） | 2~4 天 | 2~3 天 2~4 天 5~8 天* |
| 2 | 美国 | 夏威夷、阿拉斯加 | 5~8 天 | 2~3 天 2~4 天 5~8 天 7~14 天 |
| 3 | 美国 | 美国保护国 陆军邮箱地址或舰队邮箱地址 | 14~28 天 | 5~10 天 7~14 天 14~28 天 |

*标准配送： 对于媒介类商品（如图书、杂志和 DVD）以外的所有 SKU，标准配送运输时间将按 5 天计算（如果设置的是 5~8 天）。这仅适用于美国大陆（美国本土的所有州，不包括夏威夷、阿拉斯加和美国保护国/地区）。免费经济型： 对于所有 SKU（包括媒介类商品），免费经济型配送运输时间最长可以设为 8 天。此设置适用于所有美国目的地。

## 国际卖家的默认运输时间

对于从主商城以外的国家/地区发货的卖家，亚马逊为他们设置了默认的运输时间。

下表按配送区域列出了将商品送达美国的默认运输时间：

| 发货地址 | 默认配送时间 |
| --- | --- |
| 加拿大 | 7~14 天 |
| 日本 | 10~20 天 |
| 韩国 | 10~20 天 |
| 英国 | 10~20 天 |
| 中国 | 10~20 天 |
| 亚洲其他地区 | 14~28 天 |
| 欧洲其他地区 | 14~28 天 |
| 中东 | 14~28 天 |
| 非洲 | 14~28 天 |
| 南美洲 | 14~28 天 |

国际配送的可用运输时间随国家/地区变化，可以在[配送模板](https://sellercentral.amazon.com/gp/help/external/201834090)中查看。

有关更多信息，请参阅[国际卖家可设置更短的运输时间](https://sellercentral.amazon.com/gp/help/external/202182640)。
