# 错误 8119

## 错误 8119

## 错误消息

该 SKU (${uniqueID}) 无效。SKU 只能包含有效的 ISO 拉丁字符。请选取一个仅含有效 ISO 拉丁字符的新 SKU，然后重新提交。

## 导致错误 8119 的原因

出现此错误的原因如下：

- 您在 SKU 中使用了不属于 ISO 拉丁字符的特殊字符、表情符号或其他符号。

- 您在 SKU 中包含了非英文字符，例如中文、日文、阿拉伯文或西里尔字母。

- 您在 SKU 格式中使用了空格、斜杠或其他未经授权的标点符号。

- 您从其他系统复制的 SKU 包含隐藏或无效字符。

## 解决错误 8119

要解决此错误，请按照以下步骤操作：

- 将所有无效字符替换为可接受的 ISO 拉丁字符。例如，将

［
Product#123
］
更改为

［
Product123
］
。

- SKU 中仅能使用字母数字字符（A~Z、0~9 以及特殊字符 _ 或 -），并移除其中的所有空格、特殊字符或符号。

- 更新 SKU 值后，重新提交您的商品信息文件。
