# 亚马逊物流已残损库存所有权条款和条件

这些条款和条件是对[《亚马逊服务商业解决方案协议》](https://sellercentral.amazon.com/gp/help/external/G1791)的补充，对您参与亚马逊物流已残损库存所有权计划（以下简称“计划”）有规范约束作用。
1. **商品注册**： 在您同意参与该计划后，亚马逊将只注册符合[计划帮助页面](https://sellercentral.amazon.com/gp/help/external/G9MAM9ELJTSSNYS5)的商品资格部分所述资格要求的商品（已注册且符合要求的商品，以下简称“计划商品”）。亚马逊可能因任何原因随时更改本计划的资格标准。您可以随时退出和取消注册该计划。
2. **计划描述**： 亚马逊物流已残损库存所有权计划让您可以选择退出亚马逊的残损责任归属评估流程。您注册了该计划的商品不会进行残损责任归属评估，它们将被标记为“卖家导致的残损”且归您所有。已注册此计划的商品将不符合[残损赔偿](https://sellercentral.amazon.com/help/hub/reference/G200213130)要求，并将根据您的[不可售商品自动设置](https://sellercentral.amazon.com/recoveryui/removal-setting/automated-unfulfillable)进行移除。
3. **残损责任归属**： “残损”指导致商品不可售的问题，即商品不符合以新品状况出售的要求。标记为“卖家导致的残损”的残损包括买家导致的残损，以及库存属性：“存在瑕疵”、“已过期”或“分销商导致的残损”。标记为“亚马逊导致的残损”的残损是运输或搬运问题导致的残损，包括库存属性：“承运人导致的残损”和完成货件差异查询后标记的“库房导致的残损”。
4. **库存追踪和赔偿**： 对于每件计划商品，亚马逊通过将库存属性设为“存在瑕疵”，标记残损为“卖家导致的残损”，并可能因任何原因随时将此库存属性更改为其他库存属性。“卖家导致的残损”的标注不会更改。相关不可售商品将添加至您的亚马逊物流库存，您可通过可用的移除渠道将其移除。已注册计划的商品不符合残损赔偿的要求。
5. **违反条款和条件**： 如果您未能遵守这些条款和条件以及《亚马逊服务商业解决方案协议》，那么我们可能会将您从计划中移除。
