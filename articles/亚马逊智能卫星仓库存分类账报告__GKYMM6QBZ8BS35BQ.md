# 亚马逊智能卫星仓库存分类账报告

[亚马逊仓储和分拨库存分类账报告](https://sellercentral.amazon.com/reportcentral/AWD_INVENTORY_LEDGER_REPORT/1)可让您深入了解影响 AWD 分拨中心库存水平的事件。它可用于分析和查看历史流转情况，包括过去 18 个月内的库存盘点情况。

报告有两种版本，即详细视图和一览视图。

## 详细视图

[亚马逊仓储和分拨库存分类账报告](https://sellercentral.amazon.com/reportcentral/AWD_INVENTORY_LEDGER_REPORT/1)的详细视图显示分拨中心库存事件的详细信息。该报告旨在显示指定时间段内发生的、影响您亚马逊仓储和分拨库存水平的事件。

**详细视图参数**

您可以使用以下参数生成分类账报告的详细视图：

| 参数 | 描述 | 是否需要生成报告 |
| --- | --- | --- |
| 卖家 SKU (MSKU) | 您分配给商品的唯一标识。 | 不需要 |
| 配送网络 SKU (FNSKU) | 亚马逊为储存在亚马逊运营中心并从亚马逊运营中心配送的商品分配的唯一标识。 | 不需要 |
| ASIN | 由 10 个字母或数字组成，用于标识商品的唯一序列。ASIN 由亚马逊分配，可在商品详情页面上找到。 | 不需要 |
| 事件类型 | 导致库存更改的事件类型。其中包括已接收、已发出、已丢失、已找到和已残损。 | 不需要 |
| 日期范围 | 报告的开始日期和结束日期。 | 必需 |

**注意： **要为特定商品生成报告，请输入 ASIN、MSKU 或 FNSKU。将这些字段留空将生成所有商品的报告。

**详细视图报告中的字段**

| 字段 | 描述 |
| --- | --- |
| 日期 | 事件日期。 |
| MSKU | 您分配给商品的唯一标识。 |
| FNSKU | 亚马逊为储存在亚马逊运营中心并从亚马逊运营中心配送的商品分配的唯一标识。 |
| ASIN | 由 10 个字母或数字组成，用于标识商品的唯一序列。ASIN 由亚马逊分配。您可以在商品详情页面找到商品的 ASIN。 |
| 采购订单编号 | 为您运送至亚马逊智能卫星仓的货件所生成的货件追踪编号。 |
| 包装数量 | 每个箱子的商品数量。 |
| 事件类型 | 导致库存更改的事件类型。其中包括已接收、已发出、已丢失、已找到和已残损。 |
| 商品名称 | 商品的名称。 |
| 箱子数量 | 此分类账条目对应的箱子总数。 |
| 商品数量 | 此分类账条目对应的商品总数。 |
| 分拨中心编号 | 分拨中心编号。 |
| 参考编号 | 对应已接收 (STAR-XXXXXXXXXX) 和已发出 (FBAXXXXX) 事件的货件编号，或对应丢失或已找到的箱子的盘点编号。提交索赔时可以用到它。 |

**下载库存分类账报告的详细视图**

按照以下步骤下载库存分类账报告的详细视图：

- 在库存分类账报告中，点击【下载】。

- 选择“详细视图”，然后在【日期范围】下拉菜单中选择日期范围。

- 如果您想进一步筛选结果，请添加卖家 SKU、FNSKU、ASIN、事件类型或这些编码的任意组合。

- 点击【请求下载】。

- 一旦报告状态从【进行中】变为【下载】，请点击【下载】按钮。

- 保存文件并在电子表格或数据库程序（如 Microsoft Excel 或 Microsoft Access）中打开报告。

## 一览视图

[亚马逊仓储和分拨库存分类账报告](https://sellercentral.amazon.com/reportcentral/AWD_INVENTORY_LEDGER_REPORT/1)的一览视图可帮助您在 SKU/采购订单/包装数量级别跟踪货件的生命周期。对于指定的日期范围和合计时间段，您可以查看商品在运营中心的期初余量和期末余量，以及在选定时间段内，这些余量是如何调整的。

**注意： **为了简化计算，该报告将增加库存余额的事件（已接收和已找到）显示为正数，将减少库存余额的事件（已发出和已丢失）显示为负数。“其他”和“未知”列中的值可以是正数，也可以是负数，以对应延迟或未知库存事件，具体取决于这些事件是增加还是减少运营中心库存余额。请参阅下面的“一览视图报告字段”表，了解有关“其他”和“未知”列的更多信息。

**一览视图中的参数**

| 参数 | 描述 | 是否需要生成报告 |
| --- | --- | --- |
| 卖家 SKU (MSKU) | 您分配给商品的唯一标识。 | 不需要 |
| 配送网络 SKU (FNSKU) | 亚马逊为储存在亚马逊运营中心并从亚马逊运营中心配送的商品分配的唯一标识。 | 不需要 |
| ASIN | 由 10 个字母或数字组成，用于标识商品的唯一序列。ASIN 由亚马逊分配，可在商品详情页面上找到。 | 不需要 |
| 按地点汇总报告 | 选择【国家/地区】按国家/地区显示库存地点，或选择【分拨中心】按分拨中心显示库存位置。 | 必需 |
| 按时间段汇总报告 | 为报告选择所需汇总时间段，例如【每月】、【每周】或【每日】。 | 必需 |
| 日期范围 | 报告的开始日期和结束日期。 | 必需 |

**注意： **要为特定商品生成报告，请输入 ASIN、MSKU 或 FNSKU。将这些字段留空将生成所有商品的报告。

**汇总视图报告中的字段**

| 字段 | 描述 |
| --- | --- |
| 日期 | 请求报告的日期。 |
| MSKU | 您分配给商品的唯一标识。 |
| FNSKU | 亚马逊为储存在亚马逊运营中心并从亚马逊运营中心配送的商品分配的唯一标识。 |
| ASIN | 由 10 个字母或数字组成，用于标识商品的唯一序列。ASIN 由亚马逊分配。您可以在商品详情页面找到商品的 ASIN。 |
| 包装数量 | 每个箱子的商品数量。 |
| 采购订单编号 | 为您运送至亚马逊智能卫星仓的货件所生成的货件追踪编号。 |
| 商品名称 | 商品的名称。 |
| 期初运营中心余额 | 期初，此商品在分拨中心的可用箱子数量。 |
| 已收到 | 运送至亚马逊分拨中心的货件中收到的箱子数量。 |
| 已发出 | 作为补货货件的一部分从分拨中心运至运营中心的箱子数量。 |

**下载库存分类账报告的一览视图**

- 在库存分类账报告中，点击【下载】。

- 选择【报告类型】下的【一览视图】。

- 在【按时间段汇总报告】下拉菜单下，选择【每日】、【每周】或【每月】，然后在【日期范围】下拉菜单中选择日期范围。

- 如果您想进一步筛选结果，请添加卖家 SKU、FNSKU、ASIN 或这些编码的任意组合。

- 如果您想按库存存储的分拨中心查看库存汇总信息，请选择【按位置汇总报告】下的【分拨中心】。选择【国家/地区】将汇总该国家/地区所有分拨中心的所有库存。

- 点击【请求下载】。

- 一旦报告状态从【进行中】变为【下载】，请点击【下载】按钮。

- 保存文件并在电子表格或数据库程序（如 Microsoft Excel 或 Microsoft Access）中打开报告。

**报告数据时间表**

亚马逊仓储和分拨库存分类账报告一览视图中的数据取决于所选时间段。对于【每日】，最新的数据通常会在 48 小时内提供。对于【每周】，上一周的数据将在下一周的周二结束前提供。对于【每月】，上个月的数据将在次月的第二天结束前提供。

亚马逊仓储和分拨库存分类账报告的详细视图和一览视图中的数据通常会在 48 小时内提供。但是，有时可能需要更长时间。如果一览视图或详细视图中的数据缺失超过三天，请尝试扩大搜索的时间范围，或通过联系[销售伙伴支持](https://sellercentral.amazon.com/gp/help/external/G541)提交问题单。

**注意： **亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。

**次级用户的访问权限**

默认情况下，主用户可访问该报告。要向次级用户授予亚马逊仓储和分拨库存报告的访问权限，请参阅： [亚马逊智能卫星仓 (AWD)](https://sellercentral.amazon.com/gp/help/external/GF6ZC8VEBM7HCEGV)。
