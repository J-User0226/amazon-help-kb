# 卖家自配送 Prime 的承运人周末营业情况

加入卖家自配送 Prime 的卖家一周必须至少营业 6 天（接收、包装和配送订单），包括星期一至星期五以及星期六和/或星期日。卖家还必须使用配送服务每周至少 6 天（包括星期一至星期五以及星期六和/或星期日）为买家提供运输服务。

要提高您的配送速度绩效，除了这些最低营业要求外，您还必须考虑每周营业 7 天来配送 Prime 订单，并使用可一周提供 7 天运输的配送服务。

有关配送速度的更多信息，请参阅[卖家自配送 Prime 绩效要求](https://sellercentral.amazon.com/gp/help/external/G202072550)。

#### 提供星期六取件的配送服务

UPS 和 FedEx 的空运和速运服务均提供星期六取件和投件业务。对于 UPS 的陆运和 FedEx 的陆运或送货上门，星期六取件不属于其常规服务，但如果制定专项营业计划和签署承运人特别协议，也可以在星期六提供。有关更多信息，请联系相关承运人。

USPS 也提供星期六取件和投件服务

#### 提供星期日取件的配送服务

FedEx 和 UPS 在星期日一般不提供取件服务，但如果制定专项营业计划和签署承运人特别协议，也可以在星期日提供。有关更多信息，请联系相关承运人。

USPS 在星期日只提供有限的取件服务，在有预约的情况下可接受通过长途运输向大型处理场所投件。

以下是提供周末取件选项的承运人和配送服务一览：

| 承运人 | 服务 | 星期六取件 | 星期六投件 | 星期日取件 | 星期日投件 |
| --- | --- | --- | --- | --- | --- |
| UPS | 陆运 | 有限 | 否 | 有限 | 否 |
| 空运 | 是 | 是 | 否 | 否 | |
| FedEx | 陆运 | 有限 | 否 | 有限 | 否 |
| 送货上门 | 有限 | 否 | 有限 | 否 | |
| 速运 | 是 | 是 | 否 | 否 | |
| USPS | 全部 | 是 | 是 | 有限 | 有限 |

#### 提供星期六配送的配送服务

UPS 和 FedEx 的空运和速运服务均提供星期六配送，但需支付额外费用。如果运输时间为 3 天或更短时间，目的地为居住地址，且目的地符合星期六配送要求，则 UPS 和 FedEx 也为其提供星期六陆运或送货上门配送服务。

USPS 也提供星期六配送服务。

#### 提供星期日配送的配送服务

星期日配送由 FedEx 通过其送货上门服务提供。对于 FedEx 星期日送货上门，地址必须是居住地址，配送目的地必须符合星期日配送的要求，并且运输时间不能超过 3 天。

以下是提供周末配送选项的承运人和配送服务一览：

| 承运人 | 服务 | 星期六配送 | 星期日配送 |
| --- | --- | --- | --- |
| UPS | 陆运 | 是 | 否 |
| 空运 | 是 | 否 | |
| FedEx | 陆运 | 否 | 否 |
| 送货上门 | 是 | 是 | |
| 速运 | 是 | 否 | |
| USPS | 全部 | 是 | 否 |
