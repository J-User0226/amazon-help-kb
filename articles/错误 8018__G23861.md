# 错误 8018

无法删除 SKU [%s] 不存在的关系。 有关全部详情，请参阅 http://sellercentral.amazon.com/gp/help/external/23861

当您使用关系输入数据删除并不存在的商品关系时，便会发生此错误。要解决此错误，您应采取以下措施：

1. 检查商品关系输入数据中的父项 SKU 和 SKU 值，以确保您输入了正确的 SKU。
2. 否则，请编辑错误的 SKU 并再次发布您的商品关系输入数据。
3. 如果 SKU 正确，则无需采取进一步的行动。父项商品和子项商品当前不存在任何关系。
