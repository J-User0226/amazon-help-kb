# 交易一览

## 新版卖家平台中的“管理交易”

您可以点击**余额一览卡片**中的链接，访问**管理交易**。点击[此处](https://www.sellercentral.amazon.dev/manage/finance/transactions?~accountType=PAYABLE&~transactionDate%3Adr=preset%2CLAST_1_DAY%2C1%2Cday)可直接访问此页面。此页面显示您的所有交易，并配有不同颜色的状态指示器，让您一目了然地了解资金可用情况。每笔交易都会显示交易日期、状态、预计或实际放款日期以及交易总金额。不同颜色的标识系统可帮助您快速识别资金状态。您可以使用此页面追踪现金流、规划即将到账的资金，并了解某笔交易是否存在资金扣留的情况。

可使用筛选条件选项查看详情：

- 订单编号和结算编号

- 账户类型： 订单和发票

- 按所需时间范围

此表格包含以下列，便于访问和查看：

- **交易日期**： 特定货件交易的处理日期。

- **交易状态**： 可使用筛选条件查看三种状态：延期、已释放和账户级预留。

- **实际释放日期**： 资金释放用于结算的日期。

- **结算编号**： 这有助于您向金融机构追踪资金及其实际状态。

- **交易编号**： 对应交易的订单编号详情。

- **交易详情**： 对应交易商品的描述。

- **总金额**： 对应交易的总金额。

- **操作**： 点击【查看详情】，可查看包含费用的更详细交易明细。

## 旧版卖家平台中的“交易一览”

【交易一览】页面可显示某一结算周期内的账户交易情况（截至前一天交易结束时）。交易可以是订单、退款或亚马逊收取的费用或支付的款项。

您可以搜索特定订单，或使用日期和筛选条件选项根据您的需要自定义报告。设置您的筛选条件后，点击【更新】。仅可查看过去 24 个月的交易情况。

报告更新后，点击任意订单的【总计】链接，可查看更多交易详情。

## 调整报告设置

#### 筛选视图的方式： 使用此选项选择要显示的交易类型。

- 【所有交易类型】： 默认设置，显示所有交易

- 【订单付款】： 买家付款和卖家费用

- 【退款】： 订单退款

- 【信用卡拒付退款】： 买家通过其信用卡公司发起的退款

- 【亚马逊商城交易保障退款】： 请参阅[亚马逊商城交易保障](https://sellercentral.amazon.com/gp/help/external/27951)

- 【服务费用】： 各种服务（例如亚马逊物流仓储）的费用

- 【通过亚马逊购买的配送服务】： [配送服务](https://sellercentral.amazon.com/gp/help/external/200202220)购买、退款和承运人调整

- 【付款至亚马逊】： 您因某结算周期内的销售额低于相应费用而[向亚马逊支付的款项](https://sellercentral.amazon.com/gp/help/external/201058620)

- 【其他】： 服务相关费用以及其他由亚马逊收取的费用或支付的款项

- 【上一结算周期的未转账金额】： 上个结算周期末预留的总资金

#### 时间期限： 使用此选项选择要显示的交易日期范围。

- 【结算周期】： 这是默认设置。其中包括结算周期内的所有交易。

- 【过去天数】： 从预设天数中进行选择。

- 【自定义日期范围】： 选择您自己的日期范围。

#### 查找某项交易

- 在【交易一览】页面右上角的搜索框中输入订单编号，查找特定交易。

#### 下载

- 您也可以点击【下载】按钮，获取指定日期的所有订单和付款详情。下载的报告中所包含的信息要比【交易一览】中的信息更加详细，并且可以按照各订单更加清楚地显示【结算一览】中列出的费用和退款。

## 常见杂费盘点

您在查看交易报告时可能会遇到杂费余额盘点。常见的余额盘点包括：

| 杂费盘点类型 | 定义 |
| --- | --- |
| 亚马逊物流入库运输费 | 使用亚马逊的合作承运人运送库存所产生的运费。 |
| 亚马逊物流仓储费 | 对于存放在亚马逊运营中心的所有商品，按照日历月和平均每日占用体积（单位：立方英尺）所收取的费用。 |
| 退款补偿 | 由亚马逊承担责任的已退款亚马逊物流订单的款项。 |
| 预留金 | 通常由于待处理的亚马逊商城交易保障索赔或信用卡拒付而在各结算周期之间顺延的金额。 |
| 以前的预留金额结余 | 从上一结算周期顺延并重新计入当前结算周期的金额。 |
| 订阅 | 亚马逊对您的销售计划收取的月度费用以及对中期新增的其他订阅按比例收取的费用。 |
| 失败的收费 | 因上一结算周期中的负余额而向您的信用卡收费失败的金额。 |
| 订单反向收费 | |
| 反向收费退款 | 如果买家在我们实行反向收费后退回了商品，我们将从您的账户中扣除反向收费金额，因为这笔交易不再被视为销售交易，而是已完成的退货交易。 |
