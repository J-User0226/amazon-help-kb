# 错误 19003

## 错误消息

匹配无法完成，因为供应商代码“${vendorCode}”和供应商 SKU“${vendorSku}”与 ASIN ${vxpAsin} 匹配，而外部编码与其他 ASIN ${externalIdAsins} 匹配。

## 导致错误 19003 的原因

出现此错误的原因如下：

- 您尝试创建或更新商品信息，其中供应商代码和供应商 SKU 组合指向亚马逊系统中的一个 ASIN，但是您提供的外部商品编码（如 UPC、EAN、ISBN 或制造商部件编号）与目录中的其他 ASIN 匹配。

- 您提交的商品编码在亚马逊目录系统中创建了相互冲突的匹配项，其中供应商特定编码指向一个商品，而唯一商品编码指向另一个商品。

- 您正在使用的批量上传上传数据或 API 集成同时包含供应商特定编码和外部商品编码，并且这两个不同的编码类型在匹配过程中会解析为不同的 ASIN。

- 由于目录合并、重复的 ASIN 清理或重复使用商品编码，您的商品数据包含的外部编码与亚马逊目录中的多个 ASIN 相关联。

## 解决错误 19003

要解决此错误，请按照以下步骤操作：

- 验证您的商品编码：检查您的商品包装、制造商文档或供应商发票。确认您提交的供应商代码、供应商 SKU 和外部编码（UPC、EAN、ISBN）准确无误，且所有信息都与同一实际商品对应，确保您提交的信息中不存在数据输入错误或编码不匹配。

- 搜索错误中提到的两个 ASIN：导航至亚马逊零售网站，然后在搜索栏中输入 ${vxpAsin} 和 ${externalIdAsins} 中的 ASIN 以查看商品详情页面，比较商品以确定哪个 ASIN 正确地代表您正在尝试发布的商品，以及这两个 ASIN 是代表相同的商品还是不同的商品。

- 更正相互冲突的编码：编辑您的商品信息或提交的上传数据来移除或更新导致不匹配的编码。为此，请更正外部编码（UPC 和 EAN）以匹配与您的供应商代码和供应商 SKU 关联的 ASIN；如果供应商 SKU 在之前提交时被错误地分配到了错误的 ASIN，请更新供应商 SKU。

- 耐心等待目录更正，并在解决编码冲突（通过更新目录映射或遵循提供的有关正确编码的指导）后重新提交。所有目录更改需要 24~48 小时才能反映在亚马逊的系统中，然后使用更正后的商品编码重新提交您的商品信息或上传数据。
