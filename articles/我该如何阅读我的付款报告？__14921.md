# 我该如何阅读我的付款报告？

您从卖家平台下载的付款（结算）报告是制表符分隔的文本文件。阅读付款报告最简单的方法是将其保存到您的电脑上，然后在您最常用的电子表格或数据库应用程序中将其打开。然后，您可以按照自己希望的方式轻松汇总、处理数据或重新设置数据格式。

有些 Web 浏览器会使用电脑的默认文本编辑器自动打开报告。为了避免这种情况，请将报告副本保存到您的电脑上，然后在其他应用程序中将其打开。

有关付款报告中每列含义的更多信息，请参阅[下载付款报告](https://sellercentral.amazon.com/gp/help/external/791)。
