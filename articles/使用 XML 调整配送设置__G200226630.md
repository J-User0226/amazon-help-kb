# 使用 XML 调整配送设置

**注意： **此帮助页面不适用于已迁移到[新配送设置](https://sellercentral.amazon.com/gp/help/external/202062600)的卖家，因为在新配送设置中，配送调整已被配送模板取代。了解如何[迁移到新配送设置](https://sellercentral.amazon.com/gp/help/external/201834130)。

有时，您可能想为您出售的商品调整或修改默认配送设置。

例如，如果您销售电子产品，可能不希望向加拿大配送重量超过 50 磅的电视。

调整上传数据旨在处理异常情况。如果您发现自己正在使用调整上传数据更改超过 10% 的商品，请在【配送管理器】中修改默认设置，以便更好地支持您的运费结构。

要调整少数商品的配送设置，您可以使用[文本文件上传数据](https://sellercentral.amazon.com/gp/help/external/201576530)或 XML 上传数据。

[下载调整上传数据 XSD 文件 (.xsd)](https://sellercentral.amazon.com/gp/help/external/1611)

有关更多信息，请参阅 [XML 和数据交换](https://sellercentral.amazon.com/gp/help/external/221)。

作为您与亚马逊的 XML 交互的一部分，您需要向其提供商品上传数据，以在亚马逊目录中定义您的商品清单，并提供调整上传数据，以确定标准设置的异常情况。您选择的每个调整仅具有一个调整上传数据。调整条件改变时，您需提交其他调整上传数据。这与配置上传数据相似，即您提交一次数据，然后根据需要更新数据。

FULFILLMENTSERVICELEVEL 选项包括： 标准配送、加急配送、次日达、隔日达和当日达。此时，次日配送和隔日配送仅对“美国大陆”地区可用。

**注意： **您不能为固定价格为 0 美元的免费经济型配送提交价格调整。但是，您仍可通过提交调整上传数据，来调整单个 ASIN 是否可以使用免费经济型配送。

## 调整
现有两种类型的配送调整模板：

- 【专用：】 创建全新运费
- 【附加：】 在当前运费的基础上增加额外费用

## 专用调整
专用调整会根据您的整体运费，将默认运费替换为一件商品的固定运费。

例如，假设您销售图书并使用基于商品的配送方式。如果您使用加急配送将商品运送至欧洲，则运费包括每次配送 10.50 美元和每件商品 1.80 美元的费用。一位买家购买了一本图书，SKU# 1237，重量为 7 磅，通过加急配送将其运送至欧洲的运费为 35.00 美元。如果买家仅购买了这本图书，那么您将仅收取 12.30 美元（10.50 美元 + 1.80 美元）的运费。但是，如果您创建了专用调整，则可收取 35.00 美元的固定费用。

您的 XML 上传数据类似于如下示例：

<MESSAGE Type>调整</MESSAGE Type> <MESSAGE> <MESSAGEID>1</MESSAGEID> <OPERATIONTYPE>更新</OPERATIONTYPE> <OVERRIDE> <SKU>1237 </SKU> <SHIPPINGOVERRIDE> <FULFILLMENTSERVICELEVEL>加急配送</FULFILLMENTSERVICELEVEL> <LOCALE>InternationalEurope</LOCALE> <TYPE>专用</TYPE> <SHIPAMOUNT currency="USD">20.00</SHIPAMOUNT> </SHIPPINGOVERRIDE> </OVERRIDE> </MESSAGE>

## 附加调整
附加调整会向默认运费中添加商品的固定附加费。例如，假设您使用价格段配送方式，售出一件皮夹克（SKU 号为 1235），该夹克属于最高价格段 - 150 美元及以上。正常情况下，对于以加急配送方式发往欧洲且总额在 150 美元及以上的订单收取 14.00 美元费用，但是您需要向这件皮夹克额外收取 10 美元，作为保护皮制品的附加费用。您可以向这件皮夹克增收附加费，因此在欧洲境内的买家不是要支付 14.00 美元运费，而是要支付 24.00 美元（14.00 美元 + 10.00 美元）运费。

<MESSAGE Type>调整</MESSAGE Type> <MESSAGE> <MESSAGEID>1</MESSAGEID> <OPERATIONTYPE>更新</OPERATIONTYPE> <OVERRIDE> <SKU>1235 </SKU> <SHIPPINGOVERRIDE> <FULFILLMENTSERVICELEVEL>加急配送</FULFILLMENTSERVICELEVEL> <LOCALE>InternationalEurope</LOCALE> <TYPE>额外</TYPE> <SHIPAMOUNT currency="USD">10.00</SHIPAMOUNT> </SHIPPINGOVERRIDE> </OVERRIDE> </MESSAGE>
