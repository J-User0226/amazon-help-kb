# 错误 18030

“订单 ID”或“亚马逊订单 ID”无效。有关如何解决此问题的详细步骤，请参阅 http://sellercentral.amazon.com/gp/help/25441



对于提交制表符分隔配送文件或盘点文件的卖家而言，会在订单 ID 值无效时发生此错误。此值应为在您的订单报告中提供的商品编码值。此值可能无效的常见原因包含：



- 您在原订单 ID 值中省略了两个连字符。


- 您错误输入所购商品的错误商品编码值。


- 当您在配送确认或盘点模板中输入商品编码值时，Microsoft Excel 会更改它的格式。



要防止 Microsoft Excel 更改您的订单 ID 值：



- 在模板中选择“订单 ID”列。


- 点击**“格式”**菜单。


- 选择**“单元格...”。**


- 在**“格式化单元格”**框中，点击**“数字”**选项卡。


- 在**“类别”**列表中，选择**“文本”**。


- 点击**确定**。


- 在适宜的单元格中输入订单 ID。



对于发布 XML 上传数据的卖家，当您的订单确认输入数据、订单盘点输入数据或其他配送输入数据中的“亚马逊订单 ID”值无效时会发生此错误。此值应为在您的订单报告中提供的“亚马逊订单 ID”值。此值可能无效的常见原因包含：



- 您在原“亚马逊订单 ID”值中省略了两个连字符。


- 您错误输入了所购商品的错误“亚马逊订单 ID”值。


- 您错误填入内部“卖家订单 ID”值，而不是“亚马逊订单 ID”值。



要解决此错误，请使用格式正确的有效“亚马逊订单 ID”或“订单 ID”值重新提交数据。
