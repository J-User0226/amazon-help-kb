# 库存报告

在本页面，您可以查看有关亚马逊物流库存报告的信息，包括详细动作、盘点、合规性等。

有关商品信息报告的信息，包括在售商品和非在售商品的报告，请参阅[下载库存报告](https://sellercentral.amazon.com/gp/help/external/G561)。

| 库存调整 | 特定时间段（最多 18 个月）内的净库存详情，可帮助您调整库存 | 查看报告 |
| --- | --- | --- |
| 建议移除 | 在下一次库存清点时，在运营中心可能需要支付长期仓储费的库存 | 查看报告 |
| 亚马逊配送的库存 | 您的库存在生成报告时在运营中心接近实时的概况 | 查看报告 |
| 每日库存 | 您的库存在运营中心的每日概况，包括数量、位置和库存属性 | 查看报告 |
| 每月库存 | 您的库存在运营中心的每月概况，包括数量、位置和库存属性 | 查看报告 |
| 已接收库存 | 在运营中心已完成接收流程的库存 | 查看报告 |
| 库存动作详情 | 按照 SKU 和运营中心显示的库存动作（如接收、配送和盘点）历史记录 | 查看报告 |
| 盘库 | 针对残损、丢失、接收差额、库存转运等问题对您的库存进行的纠正和更新 | 查看报告 |
| 管理亚马逊物流库存 | 有助于执行日常库存管理任务的商品信息、状况、库存属性和数量信息，不包括已存档的商品信息 | 查看报告 |
| 管理亚马逊物流库存报告 — 已存档 | 有助于执行日常库存管理任务的商品信息、状况、库存属性和数量信息，包括已存档的商品信息 | 查看报告 |
| 入库绩效 | 关于您发送至运营中心的库存信息 | 查看报告 |
| 管理库存状况 | 可全面了解库存指标信息，以帮助您确定积压库存并采取相应措施，包括销量（7 天、30 天、60 天和 90 天）、预计月度仓储费和长期仓储费、超龄库存和冗余库存、商品价格和可销售周数 | 查看报告 |
