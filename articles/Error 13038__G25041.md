# Error 13038

Invalid StartDate. For help, see http://sellercentral.amazon.com/gp/help/25041



This error occurs when the start date for your sale is outside of
the currently accepted range. Dates must fall on or between January 1,
1970 (1970-01-01) and January 18, 2038 (2038-01-18). To correct this
error, please resubmit your inventory file or pricing feed (XML) with a
properly formatted date that falls within the valid date range.
