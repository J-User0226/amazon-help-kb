# 亚马逊 Easy Ship 商品限制

## 亚马逊 Easy Ship 商品限制

本页面将说明哪些商品是受限商品，不能使用亚马逊 Easy Ship 进行配送。

亚马逊保留更改、修改、修正或变更从 Easy Ship 中排除的商品列表的权利。

请阅读以下内容，了解哪些商品不能使用亚马逊 Easy Ship 配送：

- 卖家不能使用亚马逊 Easy Ship 销售受限商品。在亚马逊商城销售的商品必须遵守所有适用法律、法规和亚马逊政策的规定。我们严禁销售非法、不安全商品或其他受限商品（包括只能凭处方购买的商品）。要了解有关受限商品的更多信息，请参阅[受限商品政策](https://sellercentral.amazon.com/help/hub/reference/G200164330)页面。

- 以下商品不能使用 Easy Ship 配送：

- 重量超过 50 磅的商品

- 尺寸达到或超过以下限制的商品：

- 长度（最长边）： 59 英寸

- 宽度： 35 英寸

- 高度： 35 英寸

- 总围长（围长 = 长 + 2 [宽 + 高]）超过 130 英寸的商品

- 使用 Easy Ship 配送的商品不能归类为危险品。有关更多信息，请参阅[危险品政策](https://sellercentral.amazon.com/help/hub/reference/GN4SW35Y4KXHX8BT)。

- 卖家不能对符合以下任一条件的商品使用亚马逊 Easy Ship：

- 未经相关品牌或商标所有者同意即进行市售

- 卖家不是（商品制造商或分销商指定的）

［
授权转销商
］
或未向买家提供制造商标准保修服务

- 不能合法运往美国或在美国境内销售（受各州法规管辖）

- 经亚马逊酌情决定不支持在 Amazon.com 商城销售的任何其他类型的商品

- 易融化（例如，巧克力或石蜡）。有温度要求的商品必须能够在商品有效期/保质期内承受最低 10°C、最高 30°C 的温度，且不会对商品质量产生负面影响。除非指明 10°C 至 30°C 的温度范围要求，否则包装箱标记不能包含储藏温度要求

- 属于受《危险货物国际道路运输欧洲公约》(ADR)、《国际海运危险货物规则》(IMDG-Code)、国际航空运输协会的《危险品法规》(IATA DGR) 或任何其他相关机关或机构根据适用法律作为危险品或危险物质进行管制的商品。这包括可能具有爆炸性、易燃性、腐蚀性、毒性、放射性和磁性的压缩气体和化学品，可以是气态、液态或固态（包括粉末）形式。托运锂电池商品必须附加必要的标记，并且必须遵守《危险货物国际道路运输欧洲公约》和《国际航空运输协会危险品条例》中规定的适用条款和测试要求，这样亚马逊才会接收商品。
