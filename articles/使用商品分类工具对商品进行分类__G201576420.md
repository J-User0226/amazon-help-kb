# 使用商品分类工具对商品进行分类

亚马逊根据卖家提供的值确定商品在亚马逊目录中的显示位置。如果此类信息缺失或不正确，买家将很难找到、比较和购买您的商品。

使用[商品分类工具](https://sellercentral.amazon.com/hz/inventory/classify)执行以下操作：

- 选择您的商品分类，然后下载相应的库存文件，该文件包含了对商品进行分类所需的值。

- 使用商品分类工具文件中的值和其他商品数据填写您的库存文件模板或 XML 上传数据。

**注意： **如果您之前已使用分类树指南，则仍可使用这些文件。但我们建议您转用商品分类工具，因为该工具提供了最有针对性、最准确的亚马逊网站结构信息。查看[分类树指南](https://sellercentral.amazon.com/gp/help/external/1661)。

## 第 1 步： 选择您的商品分类

转至[商品分类工具](https://sellercentral.amazon.com/hz/inventory/classify)，然后使用【浏览】或【搜索】方法为您的商品找到正确的分类。

**浏览**

- 选择您商品的所属店铺。

- 继续展开下级分类选项，直至出现【选择】按钮。

- 点击【选择】，将该分类添加到您的列表中。

- 重复该步骤，对您的所有商品进行归类。

- 点击【下载列表】，然后保存文件。

**搜索**

- 在【搜索】框中输入关键词。

- 点击分类名称左侧的“【+】”符号（加号），为您的商品选择分类。

- 重复该步骤，对您的所有商品进行归类。

- 点击【下载列表】，然后保存文件。

## 第 2 步： 下载库存文件模板

确定正确的库存文件模板：

- 打开商品分类工具文件，然后查看【库存模板名称】列中给出的建议，为您的商品确定库存文件模板。

- 转至【库存文件模板】，下载并保存一个或多个库存文件。您可以使用多个库存文件。

**注意： **若卖家使用 XML 上传数据，可以使用 XML 上传文件。

## 第 3 步： 填写分类字段和细分字段

按下述步骤将所选分类和细分添加至库存文件模板：

**分类**

- 打开商品分类工具文件，然后滚动至【分类必填字段】列： 【分类字段】和【有效值】。

- 为您要发布的某一件商品确定【分类字段】。

- 在库存文件模板中确定这些相同的字段。

**注意： **
商品分类工具文件中的 【item_type_keyword】 对应于库存文件模板中的 【item_type】 和 XML 文件中的 【ItemType】 属性。

- 请针对您要发布的商品，将商品分类工具文件中的有效值复制到库存文件模板的对应单元格中。

- 对要发布的所有商品重复这一流程。

**细分**：

- 打开商品分类工具文件，然后滚动至**细分**列： 【细分名称】、【细分字段】、【有效值】和【修饰符】。

- 为您要发布的某一件商品确定【细分字段】。

- 在库存文件模板中确定这些相同的字段。

- 请针对您要发布的商品，将商品分类工具文件中的有效值复制到库存文件模板的对应单元格中。

- 对要发布的所有商品重复这一流程。
