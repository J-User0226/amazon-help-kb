# 亚马逊物流库存

**重要： **如果您有北美联合账户且在 Amazon.com、Amazon.ca 或 Amazon.com.mx 商城发布了商品，则必须将在这些商城发布的待售商品发送到各自国家/地区的运营中心。要为不同的北美商城创建货件，请先从卖家平台右上角的下拉菜单中选择相应商城，然后再创建货件。有关跨北美边界销售商品的信息，请转至[国际卖家重要须知](https://sellercentral.amazon.com/gp/help/external/200404870)。

使用卖家账户中的工具发布商品、创建入库计划、发送货件、追踪和监控货件，以及移除存放在亚马逊运营中心的库存。

## 发送库存至亚马逊

**注意： **
您的库存被运营中心或收货中心接收后即可供出售。 您可以在“货件处理进度”中追踪货件的状态。货件状态将随配送进度依次显示为**运输中**、**已完成配送**、**已登记**、**正在接收**和**已完成**。要了解更多信息，请参阅[亚马逊如何接收和储存您的库存](https://sellercentral.amazon.com/gp/help/external/G201081250)。

用于创建货件的选项包括：

- [Send to Amazon](https://sellercentral.amazon.com/gp/help/external/G6925SDD66GDLXJW)： 简化的标准化货件创建流程，采用简化步骤，可节省补货时间。可通过从 [Send to Amazon](https://sellercentral.amazon.com/fba/sendtoamazon/confirm_content_step) 页面添加商品或通过使用 Excel 电子表格上传商品列表来创建货件。

- [向亚马逊发/补货](https://sellercentral.amazon.com/gp/help/external/201021820)： 此标准化货件创建流程将替换为 Send to Amazon。自 2022 年 10 月 17 日起，必须在 Send to Amazon 中或者使用亚马逊商城网络服务或销售伙伴 API 创建所有新的亚马逊物流货件。要了解更多信息，请参阅[亚马逊物流货件创建变更为 Send to Amazon](https://sellercentral.amazon.com/gp/help/external/GF3FZUPP7UZ34AZY)。

- [销售伙伴 API](https://developer.amazonservices.com/gp/mws/docs.html/)： 针对中等到大型货件。您可以使用亚马逊 API 整合自己的库存系统。

要快速了解货件创建流程，请观看卖家大学系列视频，建议先从[亚马逊物流的运作方式](https://sellercentral.amazon.com/learn/courses?courseId=8&moduleId=38)开始看起。

**注意： **
默认情况下，在您创建工作流程后，您的库存可能会被拆分为多个货件，每个货件运往不同的运营中心。 我们将根据您要运送的商品和您的发货地来选择亚马逊运营中心。将您的库存分布到全国的多个亚马逊运营中心之后，相比库存较远的情况，购买您商品的买家可以更快收到您的商品。
