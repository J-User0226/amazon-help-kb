# 错误 300060

我们无法通过 URL ! {imageUrl} 访问该媒体。请确保此 URL 正确且该媒体可公开访问。

发生此错误的原因包括：

- 该媒体无法访问。

我们的系统多次尝试从指定的 URL 检索该媒体，但在某些情况下，所有尝试均告失败。要修复此错误，请尝试以下方法：

- 确保媒体服务器采用 HTTP 协议并返回正确的响应代码。

- 确保可通过与媒体服务器位于不同网络的计算机上的浏览器访问该文件。
