# 关于企业商品定价规则的常见问题

企业商品自动定价有三种不同的规则：

- 标准商品价格折扣规则。

- 企业目录规则。

- 企业有竞争力的推荐报价规则。

## 标准商品价格折扣规则

#### 我在“自动定价”中将数量折扣设置为折扣规则。为什么折扣在“管理库存/管理定价”中显示为固定价格折扣？

这种差异是由用于设置数量折扣的价格引起的。

通过[管理库存](https://sellercentral.amazon.com/inventory/ref=ag_invmgr_dnav_xx_)和[管理定价](https://sellercentral.amazon.com/inventory/ref=ag_primng_dnav_xx_?_encoding=UTF8&viewId=PRICING)查看和更新的数量折扣是基于单件商品的企业商品价格。但是，[自动定价](https://sellercentral.amazon.com/automatepricing/home/ref=ag_mars_dnav_xx_)会将您的企业商品价格和数量折扣与您的标准商品价格保持同步。

如果 SKU 通过自动定价中的企业商品定价规则进行管理，则每次标准商品价格更新时，企业商品定价规则中输入的百分比折扣都将应用于更新的标准商品价格，进而重新计算显示在【管理库存】和【管理定价】中的固定价格折扣。

## 企业目录规则

#### 企业目录规则与标准商品价格折扣规则有何不同？

借助企业目录规则，您可以设置一个标准商品价格折扣规则，然后对整个在售目录（包括新添加的 SKU）应用此规则进行自动重新定价。与标准商品价格折扣规则不同，使用企业目录规则时，您无需在“管理 SKU”或“批量上传”中选择 SKU。除此之外，企业目录规则设置与标准商品价格折扣规则设置类似（包括设置最低价格）。

## 企业有竞争力的推荐报价规则

#### 同时使用有竞争力的推荐报价和企业有竞争力的推荐报价规则时，自动定价如何为我的标准商品价格、企业商品价格和数量折扣重新定价？

有竞争力的推荐报价和企业有竞争力的推荐报价规则可独立发挥作用，提高您的报价在亚马逊商城和亚马逊企业购成为推荐报价的可能性。因此，有竞争力的推荐报价规则仅尝试匹配亚马逊商城的推荐报价，如果亚马逊企业购上有更具竞争力的企业商品价格和/或数量折扣，那么企业有竞争力的推荐报价规则会尝试匹配亚马逊企业购上的推荐报价。企业有竞争力的推荐报价规则为您创造了一个向企业买家提供更有竞争力的价格的机会。

#### 为什么我设置了五个数量分段，却只看到四个数量分段报价？

随着数量分段段位的提高，折扣力度也要加大，如此您的报价才能生效。如果较高数量分段的折扣力度反而较小，买家便无法看到此数量分段。例如，如果您为 2 件商品设置第一个数量分段，折扣为 10%，为 5 件商品设置第二个数量分段，折扣为 5%，那么系统将拒绝第二个数量分段，因为您为更大的数量设置了更高的价格。

#### 我的商品具有企业商品价格和数量折扣，并且已经是推荐报价。那么当我开始使用企业有竞争力的推荐报价规则时，该规则如何运作？

当您开始使用企业有竞争力的推荐报价规则时，您的商品可能始终以企业商品价格作为推荐报价，但是，由于您的商品已经是推荐报价，系统将移除您的数量折扣。因此，如果您确信自己的报价将始终成为推荐报价，那么我们建议您使用折扣规则来代替企业有竞争力的推荐报价规则。

#### 如果在亚马逊商城和亚马逊企业购中的推荐报价相同，企业有竞争力的推荐报价规则如何设置企业商品价格？

企业有竞争力的推荐报价规则将根据亚马逊企业购商品价格（与亚马逊商城的商品价格相同）重新定价。您可以创建企业有竞争力的推荐报价规则，将商品价格设定为低于、等于或高于亚马逊企业购推荐报价的获胜价格。如果企业商品价格低于您的标准商品价格，并且系统推荐了您的商品，当企业买家找到您的商品时，看到的便是企业商品价格。

#### 不同事件会对企业商品价格产生什么样的影响呢？

商品价格自动在您设置的最低和最高价格之间变动。为帮助您理解自动定价中企业商品定价规则的运作原理，下表说明了您的规则或价格在特定情况下会发生什么变化。

| 事件 | 结果 |
| --- | --- |
| 您的标准商品价格含促销或优惠券。 | 促销价格不会影响自动定价管理的企业商品价格和数量折扣。自动定价将继续根据提交的最新标准商品价格为选定的 SKU 重新定价。例如，如果某个 SKU 依据企业具有竞争力的推荐报价规则设定了价格，而您对同一 SKU 运行了促销，则系统将继续根据企业推荐报价对该 SKU 进行重新定价，且不会考虑相关促销。 注意： 在“管理库存”中，系统从标准商品价格字段中获取用于重新定价的标准商品价格。有促销价格的 SKU 在页面上标示标准商品价格外加绿框；将光标悬停在标准商品价格字段上方，可显示促销价格。 |
| 您使用折扣规则对一个 SKU 进行促销。 | 促销价格会影响自动定价管理的企业商品价格和数量折扣。在促销时段内，将在促销价格的基础上应用折扣，而不是以标准商品价格为基础。促销结束后，将在标准商品价格的基础上应用折扣。 |
| 在自动定价中对相同的 SKU 制定了标准商品价格规则。 | 对于相同的 SKU，您在自动定价中最多可制定一个标准商品价格规则和一个企业商品价格规则。对于标准商品价格的任何重新定价措施都将自动更新企业商品价格和/或数量折扣，设置范围为最低与最高价格限额之间。 |
| 将标准商品价格更新为低于“自动定价”中设置的最低价格限额。 | 适用于该 SKU 的定价规则将暂停，您的价格将保持在定价规则暂停前的最后价格。要重新启用该规则，请前往“自动定价”，选择该规则，然后选择【恢复】针对该 SKU 重新启用该规则。 注意： 相同的最低和最高限额将应用于您的标准商品价格和企业商品价格，但不会应用于数量折扣。因此，提交低于最低限额的标准商品价格将导致您的商品被禁止显示。有关更多信息，请参阅“我的商品在使用‘自动定价’工具后被禁止显示”。 |
| 将无现有企业商品价格或数量折扣的 SKU 添加到企业商品定价规则中。 | 如果 SKU 无企业商品定价，“自动定价”将在您点击【开始重新定价】后立即创建企业商品价格和数量折扣。初始价格集将取决于相关的规则参数和该 SKU 的当前标准商品价格。您可以在“自动定价”、“管理库存”或“管理定价”中查看创建的企业商品价格和数量折扣。 |
| 您将业务规则从“企业有竞争力的推荐报价规则”更改为“折扣规则”。 | 您的企业商品价格将按照标准商品价格的特定百分比折扣进行重新定价。如果您的商品价格没有竞争力，您的商品可能不会被推荐。 |
| 您使用现已推出的“企业有竞争力的推荐报价规则”为一个 SKU 添加数量折扣。 | 自动定价将停止为该 SKU 重新定价，保留最新的企业商品价格，并为该 SKU 添加数量折扣。 |
| 取消某个 SKU 与企业目录规则的关联，之后该 SKU 将变为非在售状态，然后重新变为在售状态。 | 该 SKU 将重新与企业目录规则关联。如果 SKU 先是变为“非在售”状态，然后又变回“在售”状态，目录规则会将该 SKU 视为新添加的 SKU，并会自动将此 SKU 分配给企业目录规则，即使该 SKU 在这一轮状态变化（“在售”变为“非在售”）之前已取消了与企业目录规则的关联。您可以前往“管理 SKU”页面，选择“停止重新定价”再次取消该 SKU 与企业目录规则的关联，这与使用其他定价规则的操作类似。 |
| 您取消了某个 SKU 与企业目录规则的关联，并选择暂停企业目录规则，稍后再恢复该规则。 | 该 SKU 将重新与企业目录规则关联。当您恢复暂停的企业目录规则时，该规则将再次应用于您的整个目录，而忽略之前所有 SKU 的取消关联操作。您可以前往“管理 SKU”页面，选择“停止重新定价”再次取消该 SKU 与企业目录规则的关联，这与使用其他定价规则的操作类似。 |
