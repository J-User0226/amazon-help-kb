# 错误 300429

“我们无法通过 URL 访问媒体。我们收到了 429 HTTP 状态代码。请确保服务器或防火墙配置未限制亚马逊服务器的速率，也未阻止亚马逊服务器访问该媒体。”

如果我们无法通过提供的图片 URL 访问该媒体，就会出现此错误。出现此错误的商品将在您的库存中作为禁止显示的商品。

要解决此错误，请执行以下操作之一：

- 在卖家平台中，前往【目录】 > 【补全您的草稿】，搜索出现此错误的 SKU，然后提交有效的图片 URL。

- 确保服务器或防火墙配置允许亚马逊服务器访问给定 URL 所指向的媒体，然后重新提交商品信息。
