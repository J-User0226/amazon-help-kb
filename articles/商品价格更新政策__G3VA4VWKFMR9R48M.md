# 商品价格更新政策

为了在所有亚马逊卖家之间保持公平性并确保亚马逊买家的线上购物体验，我们保留根据我们关于滥用亚马逊销售服务的政策在一天内处理有限数量的价格更新的权利。一旦达到每日商品价格更新次数配额，当天将不再处理其他更新，留待第二天处理。要查看我们的政策，请访问[禁止的卖家活动和行为](https://sellercentral.amazon.com/help/hub/reference/G200386250)页面。

如果您认为您的企业需要更高的每日配额，请联系[销售伙伴支持](https://sellercentral.amazon.com/cu/contact-us)。

亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。

## 什么操作可称为商品价格更新？

您可以通过多种机制更新您的商品价格，包括（但不限于）：

- 库存加载工具

- 商品信息加载工具

- 商品价格和数量文件

- 自定义库存文件

- “管理定价”页面

- “管理库存”页面

- 销售伙伴 API

## 可以在哪里查看您进行了几项商品价格更新？

我们无法追踪您每天进行的商品价格更新数量。您可以在[批量上传商品](https://sellercentral.amazon.com/listing/)页面上查看您提交的文件，并下载“监控上传状态”选项卡中的处理报告，以查看已成功得到处理的行数，从而预计您进行了几项商品价格更新。

## 避免达到商品价格更新次数限制的提示

建议您查看您的商品价格更新次数使用情况，以确保符合我们的政策。以下是一些提示和备用方法，可帮助您保持在限制范围内，同时为我们的买家提供最优惠的价格。

**库存文件模板**

如果您使用库存文件模板提交更新，并且只想更改商品的库存数量，请勿添加商品价格信息。包含有效的商品价格，即使它与当前的商品价格相同，也会计入您的每日商品价格更新次数配额。

**自动定价**

请考虑使用面向所有专业卖家开放的亚马逊自动定价工具。利用该工具，您可以自动调整目录中 SKU 的商品价格以达到赢得推荐报价等目的，而不必在每次想要更改商品价格时都重新操作 SKU。您可以通过定义规则参数、设置商品价格的上下限以及选择要自动定价的 SKU 来控制商品价格。“自动定价”工具定出的商品价格更改不计入每日商品价格更新次数配额。请参阅[自动定价](https://sellercentral.amazon.com/automatepricing/home/)了解更多信息。

## 常见问题

#### 商品价格更新次数限制是否适用于每个商城或卖家账户？

每日商品价格更新次数配额是为每个商城中的每个卖家账户设置的。

#### 怎么知道何时超出每日配额？

如果您试图在达到每日配额后进行任何更新，上传数据处理输出中将显示错误代码 8182。这条错误消息的内容将为“已达到商品价格更新次数限制，因此系统今天已无法处理任何其他更新”。

#### 如果已超过每日商品价格更新次数配额，在同一库存模板文件中提交的“商品价格”和其他列会怎么样？

对该 SKU 的所有更新都将被拒绝。要对该 SKU 进行除商品价格以外的任何更新，您可以提交包含所需更新的库存模板文件，并将“商品价格”列留空。
