# 修改库存文件

您可修改自己的库存文件，以：

- 在亚马逊商城更新现有商品和报价。
- 在亚马逊商城创建新商品和报价。
- 在亚马逊商城删除现有商品和报价。

如果您尚未创建库存文件，请参阅[创建库存文件](https://sellercentral.amazon.com/gp/help/external/201576650)。

## 更新现有商品
更新 SKU 关联的商品或报价数据与上传含有修改信息的库存文件一样简单。如果您使用商品文件或匹配文件，则还必须包括该 SKU 未更改的所有数据。“商品价格和数量”文件只有三列（SKU、商品价格和数量），是更新库存水平的最快方式，包含将缺货商品的数量设置为零 (0)。

编辑或修改商品信息，请遵循以下步骤：

1. 在“库存”选项卡上，选择“管理所有库存”。
2. 点击想要编辑的 SKU 的操作链接。
3. 从下拉列表选择编辑详情。
4. 完成编辑后点击“保存并完成”。

如果您遵循以下数据管理提示操作，则可以在主商品模板中更改该 SKU 的条目，将更改行粘贴至空白模板，并根据需要为其他 SKU 重复此流程，将新模板另存为制表符分隔的文本文件，然后上传。

【数据管理提示】
使用增量上传时，您可能无法掌握整个数据集的情况。以下几点建议可帮助您保持数据完整性：

- 针对您的每个售出商品分类，始终维护一个主商品模板，使其包含最新的商品数据。商品模板是用来生成库存文件的 Microsoft Excel 文件。
- 准备一份空白的商品模板。然后，当您更改主文件，并希望 Amazon.com 目录中能反映出这些更改时，可以从主模板中删除修改后的行并将它们粘贴至空白模板中。接下来，创建仅包含要更新的商品数据的新库存文件。
- 切勿更改商品“SKU”字段中的值。我们使用 SKU 将您的商品数据与目录中的相应条目进行匹配。

上传后，务必查看库存结果，确保上传成功。

## 增量上传
您无需在每次想要更新 SKU 的相关信息时上传一个包含所有商品信息的库存文件。上传该文件时，您可上传仅包含有关您想要创建、更新或删除的 SKU 信息的库存文件。

如果您上传了商品匹配文件，您的商品数据将保留在亚马逊商城中，直至您上传新的文件，以更改或删除与亚马逊目录中的页面匹配的特定 SKU。

如果您上传了商品信息加载工具文件或库存加载工具，您的商品数据将保留在亚马逊商城中，直至您上传新的文件，以更改或删除与亚马逊目录中的页面匹配的特定 SKU。

## 创建新的商品信息
在 Amazon.com 目录中创建新商品页面与为新商品上传包含商品数据的新库存文件一样简单。遵循上述数据管理建议，您可以在主商品模板中添加该 SKU 的条目，将新行复制粘贴到空白模板，并在需要时针对其他新 SKU 重复这一流程。然后，将新模板保存为制表符分隔的文本文件，并[上传您的库存文件](https://sellercentral.amazon.com/gp/help/external/201576670)。

完成任何上传后应始终[检查处理报告](https://sellercentral.amazon.com/gp/help/external/201576740)，以验证是否成功上传。

## 删除现有商品
删除商品的特定流程取决于您正在提交的商品类型。

**删除非媒介类商品**

要使用非媒介类商品分类的分类特定文件删除库存中的商品以及为商品提供的商品数据，请提交针对特定分类的库存文件，但不要为所选 SKU 的商品价格和数量数据提供任何数值。此外，请在所选 SKU 的“update-delete”字段中输入“delete”。

**删除媒介类商品（图书、音乐、影视）**

要使用媒介类商品（图书、音乐、影视）分类的分类特定文件删除库存中的商品以及为商品提供的商品数据，请提交分类特定文件，并将所选 SKU 的数量值设为零 (0)。此外，请在所选 SKU 的“add-delete”字段中输入“x”。

**从库存加载工具文件中删除所有商品（所有商品分类）**

要使用库存加载工具文件从库存中显式删除商品，并删除该商品的数据信息，请为所选 SKU 提交包含零 (0) 数量值的文件。此外，请在所选 SKU 的“add-delete”字段中输入“x”。有关更多信息，请参阅[使用库存加载工具删除 SKU](https://sellercentral.amazon.com/gp/help/external/201576560)。

如果您遵循上面的数据管理提示操作，则可以在主商品模板中剪切要删除的 SKU 条目，然后粘贴到空白模板中，并根据需要对其他 SKU 重复这些操作。下一步，删除所有与商品价格和数量相关的值。然后，按照上面的说明为您的文件类型中用于指明删除操作的字段输入相关代码值。最后，将该模板另存为制表符分隔的文本文件并上传。

## 特别注意事项
使用库存文件更新、修改或删除库存时，有几点需要特别注意。

1. 在为子商品分配新的 【parent-sku】 值之前，必须先删除其与原始父商品的关系。要删除此关系，删除父商品 SKU 或子商品 SKU 即可。
2. 删除父商品 SKU 时，会删除该父商品与其所有子商品的关系。但删除子商品时，只会删除该子商品与其父商品的关系。
3. 删除原有关系后，您可在子商品的 【parent-sku】 字段中输入新的父商品 SKU，将该子商品重新分配给新的父商品。
4. 对于部分商品，您的上传可能引发错误代码 8005。当您尝试更改当前在亚马逊商城拥有报价的商品的特定字段时，就会发生此错误。有关此错误的更多信息和要采取的纠正步骤，请参阅[错误 8005](https://sellercentral.amazon.com/gp/help/external/23191)。
