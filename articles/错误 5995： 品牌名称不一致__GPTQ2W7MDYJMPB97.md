# 错误 5995： 品牌名称不一致

您 SKU 中的品牌名称与亚马逊目录中此商品的值不一致。您需要先更新品牌，使其与亚马逊目录中的信息一致，然后才能对此 SKU 进行其他更新。

## 什么原因会导致出现此错误：
在您创建 SKU 后，品牌所有者或亚马逊对此商品的品牌名称进行了更正。根据[亚马逊 ASIN 创建政策](https://sellercentral.amazon.com/gp/help/external/G2N3GKE5SGSHWYRZ)，对商品品牌的更新仅限于细微语法更正，或者当我们发现商品不符合[亚马逊无品牌商品政策](https://sellercentral.amazon.com/gp/help/external/G84H3T69ZX762NWT)时进行更新。

## 如何修复此错误：
参与专业销售计划的卖家：
- 为受影响的 SKU 提交库存文件，并在文件中提供更正后的品牌属性。
  - 如果您从未提交过库存文件，请参阅[批量创建商品信息](https://sellercentral.amazon.com/gp/help/external/GZ4ZQ4HZQM2R4B2X)帮助页面。
  - 使用自动服务、库存管理服务的卖家也需要针对受影响 SKU 更新这些文件上的品牌信息。

参与个人销售计划的卖家：

您可以将账户升级至专业销售计划，以便通过库存文件更新品牌属性，也可以删除 SKU 并重新发布。
1. 要删除 SKU，请参阅： [删除商品](https://sellercentral.amazon.com/gp/help/external/GDMU6WZNPLTKM9J3)
2. 要使用更正后的品牌信息再次创建 SKU，请遵循： [一次创建一个商品信息](https://sellercentral.amazon.com/gp/help/external/G39EFY66ZLSJQ7PM)

## 仍有其他问题？
如果您有证据表明品牌未正确更新，请完成以下步骤，以便我们进一步调查。
1. 前往[获取帮助和资源](https://sellercentral.amazon.com/help/center?redirectSource=HelpHub)或使用卖家助手。
2. 选择“品牌 – 更新”
3. 输入 ASIN
4. 按照提示操作，请求进行目录审核

**注意： **亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。
