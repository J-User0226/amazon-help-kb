# 搜索优化

## 搜索优化
买家必须找到您的商品才能购买。本指南介绍了如何准确分类和发布商品，以便优化商品以便于搜索。

在亚马逊购物的买家会使用关键词或浏览细分来找到他们想要的商品。通过为您的商品提供相关且完整的信息，您可以提高商品的曝光度，从而提高销量，因此在【浏览】中准确分类您的商品非常重要。商品名称、品牌、商品描述和其他属性等商品信息必须准确且符合详情页面规则。在质量问题得到解决之前，任何不符合我们指南的商品都可能会被禁止在搜索结果中显示。

**注意： **亚马逊保留在买家购物搜索结果中检索商品时，不使用商品描述中提供的所有内容（包括要点）的权利。不使用所有关键词的原因包括但不限于：搜索运算效率、可能会操纵购物搜索结果、不相关的搜索词以及具有冒犯性的或非法的词语。但是，建议您根据风格指南更新这些详情。

## 搜索和浏览
买家可以通过浏览或搜索找到商品。大多数情况下，买家会同时使用浏览和搜索功能。

**浏览**

为了帮助买家轻松找到商品，亚马逊开发了一套详尽的商品架构或浏览树状结构。买家按分类和子分类链接细化搜索，直至找到最具体的商品类型。亚马逊使用商品类型关键词在正确的分类节点下对商品进行分类。

精确的商品分类可以优化商品曝光度，让亚马逊更轻松地帮助买家通过浏览和搜索找到他们想要的商品。商品分类如同在商店中将您的商品摆放在正确的通道中、陈列在正确的货架上。当买家在**所有部类**中搜索时，亚马逊可能会将购物搜索结果限制为与特定分类或商品描述符匹配的商品。

**选择和应用浏览关键词**

从要分类的商品开始，请参考[使用分类树指南对商品进行分类 - 分类树指南](https://sellercentral.amazon.com/gp/help/external/G1661)了解分类树指南。分类树指南是特定于分类的文件，为您的商品提供特定关键词。

**注意： **商品类型关键词的拼写和格式必须与分类树指南中列出的相同。确保在最具体的可用子分类中选择关键词。

**示例：** 如果您销售的是女式跑鞋：

- **太广泛：** “鞋靴”或“运动鞋”
- **正确： **“女士公路跑鞋”

**搜索和通用关键词**

为了让买家在亚马逊商城找到您的商品，请务必提供一些当买家搜索他们想要购买的商品时可能会使用的搜索词。搜索词是搜索引擎用于将 ASIN 与查询内容进行词汇匹配的关键词。例如，如果您发布的是不锈钢冰箱，则可包含如下术语：冰箱、冷冻室、冰柜、冷藏箱、节能型、无霜设计、可调节搁架、温度控制、不锈钢材质、厨房、家用电器、法式对开门、制冰机。

请务必提供商品的真实详情，包括电子产品兼容性或家电功能。

您可以为您的商品添加搜索词。这些搜索词应当仅包含可以提高商品曝光度的通用词语。例如，如果您销售的是头戴式耳机，您的搜索词可以包含“耳机”和“耳塞”等同义词。 这些信息不会显示在商品详情页面上，并且可以在商品信息的“通用关键词”字段中更新。

有关搜索的更多信息，请访问[有效使用搜索词](https://sellercentral.amazon.com/gp/help/external/G23501)。

**注意： ** 我们将通用关键属性的长度限制在 250 个字节以内。如果卖家提供品牌名称、ASIN 或冒犯性语言等禁止的搜索词作为通用关键词，则亚马逊可删除搜索词。

## 搜索词最佳实践
以下是优化商品信息以便于搜索的一些最佳实践：

- 不超过搜索词的文本长度限制
- 使用同义词，避免重复关键词
- 使用拼写变体，避免常见的拼写错误
- 包含缩写词
- 全部使用小写字母
- 用空格分隔单词，避免使用分号、冒号和破折号等标点符号
- 使用单数或复数词，请勿同时使用同一关键词的单数和复数形式
- 请勿使用品牌名称、ASIN、亵渎或攻击性词语
- 避免使用冠词、介词及其他短词，如“a”“and”“or”“the”或“with”
- 请勿使用临时表述，如“新品”或“立即促销”，或主观表述，如“最佳”或“最便宜”

**注意： **违反这些规则可能会导致您的 ASIN 被禁止显示，并可能会给您的销售账户状况带来风险。

## 了解搜索行为
**搜索查询自动更正**

某个 ASIN 有时可能由于自动更正搜索查询而无法搜索。更正搜索查询后，买家会在结果顶部看到“显示结果”消息以及更正后的查询。对于拼写更正的查询对买家无帮助，并且买家希望查看其原始查询的结果的情况，系统还会显示【“搜索”而不是 [原始查询]】 链接。

**ASIN 位置波动**

我们不保证搜索结果中某个 ASIN 的具体展示位置。ASIN 的位置会波动，因为我们一直努力向买家展示最相关的结果。

如果 ASIN 的位置发生变化，可能是因为其搜索位置以及登录的账户类型，或者它们是否在桌面或移动设备上。您可能不会在 Search Troubleshooter 工具报告的位置看到该 ASIN。这是我们有意为之。

**搜索结果限制**

亚马逊会限制搜索结果页面上显示的 ASIN 数量，且不会在特定页面数之后显示结果，具体取决于搜索类型和每页的结果数量。

如果 ASIN 未在设定的结果限制内显示，则无法使用搜索结果页面底部的页码或下一页链接通过搜索查询导航到该 ASIN。买家可以使用更具体的查询或使用筛选条件来细化搜索结果，从而在搜索中找到该 ASIN。

## 搜索故障排除工具
搜索故障排除的目的是帮助您了解商品的曝光度问题。如果手动搜索故障排除提示无法帮助诊断搜索问题，您可以使用名为【确定 ASIN 无法搜到的原因】的工具。

**注意： **在卖家平台帮助中心内搜索“ASIN 无法搜到”，可以访问此工具。输入搜索 URL 和 ASIN（子 ASIN 或非父 ASIN），该工具将诊断 ASIN 无法搜到的原因。
