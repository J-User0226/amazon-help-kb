# Amazon Handmade 服装、鞋靴和配饰指南

作为手艺人，您的手工服装、鞋靴和配饰类商品必须符合以下指南：

- 所有商品都必须符合[亚马逊一般政策和协议](https://sellercentral.amazon.com/gp/help/external/G521)。

- 所有商品都必须遵守[分类、商品和商品限制](https://sellercentral.amazon.com/gp/help/external/G200301050)。

- 所有商品必须满足通用 [Amazon Handmade： 分类商品政策和要求](https://sellercentral.amazon.com/gp/help/external/GNGMMFQ5FPLJFBJP)。

- 允许销售使用丝印、压印或热转印等生产方式设计和制造的服装。

- Amazon Handmade 店铺不允许转售商品；待售商品必须是新品或新制的商品。

- 允许对服装、配饰和全新/从未穿过的鞋靴进行翻新或装饰。

- 如果您在商品名称或描述中使用品牌名称，例如 Converse、Levi's 或 Nike，在经知识产权所有者书面许可后，允许销售经过装饰的品牌商品。

- 我们不允许在 Amazon Handmade 销售任何二手、[假冒](https://sellercentral.amazon.com/gp/help/external/201165970)、商标侵权、复制或仿制商品和/或图片。

- 如果您使用的是刺绣机器，则必须在您的家庭工作室或工作区完成商品。

- 商品的制造工作不可外包。例如，在服装商品上缝制和印刷艺术品的工作必须由您（即手艺人）或您的员工完成。

- 对于珐琅别针，如果模具和设计由您打造，则允许销售。

- 如果您在亚马逊商城销售商品，则必须遵守适用于这些商品和商品信息的所有联邦、州和地方法律以及亚马逊政策。对于[儿童商品](https://sellercentral.amazon.com/gp/help/external/G5SB2HLMUYFK4MXC)和[儿童学习用品](https://sellercentral.amazon.com/gp/help/external/GXT3EFQS54LRKYM3)，请查看这些政策以了解更多详情。

- 所有商品都必须符合商品销售所在的管辖区内的所有法律法规的要求。

- 成人用品必须符合[成人用品政策和指南](https://sellercentral.amazon.com/gp/help/external/200339940)，且必须标记为“成人用品”。

- 所有商品都必须符合北美商品安全标准，包括但不限于：

- [CPSIA 窒息危险警告和材质含量限制](https://sellercentral.amazon.com/gp/help/external/G200292910)

- [加利福尼亚州 65 号提案（简称“65 号提案”）](https://sellercentral.amazon.com/gp/help/external/G202141960)

- [纺织品成分标签法（简称“纺织品法案”）](https://www.ftc.gov/enforcement/rules/rulemaking-regulatory-reform-proceedings/textile-products-identification-act-text)

- [易燃性织物法案](https://www.cpsc.gov/regulations-laws--standards/statutes/flammable-fabrics-act)

- 由毛或皮制成的商品需要符合[毛制品标签法案](https://www.ftc.gov/node/119457)和[皮制品标签法案](https://www.ftc.gov/enforcement/rules/rulemaking-regulatory-reform-proceedings/rules-regulations-under-fur-products)的要求

- 有关为真皮和人造皮商品贴标的信息，请参阅[选择真皮和人造皮商品的 FTC 指南](https://www.ftc.gov/enforcement/rules/rulemaking-regulatory-reform-proceedings/leather-guides)。
