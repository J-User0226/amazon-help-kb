# 选择要发送的库存（步骤 1）并包装单个商品（步骤 1b）错误排除

## 选择要发送的库存（步骤 1）并包装单个商品（步骤 1b）错误排除

此页面用于排查“发送至亚马逊”货件创建工作流程中步骤 1 和 1b 的常见错误消息。

### 包装箱尺寸和重量错误

当包装箱尺寸或重量与亚马逊根据您的商品包装信息所预期的不符时，就会出现这些错误。

#### 箱子最小立方体积未达到预期的最小体积。

| 字段 | 内容 |
| --- | --- |
| 错误定义 | 根据您输入的商品包装尺寸，亚马逊认为您的包装箱尺寸不正确。 |
| 常见原因 | 输入的包装箱尺寸与亚马逊根据单个商品包装尺寸预期的值不符 |
| 问题解决 | 在库存的“编辑商品信息”部分仔细检查您的商品包装尺寸 验证在工作流程步骤 1 中创建的装箱模板中的包装箱尺寸 如果两者均正确，您可以忽略此错误。这将允许您继续执行下一步。 |

#### 包装箱重量未达到预期最小值。

| 字段 | 内容 |
| --- | --- |
| 错误定义 | 根据您输入的商品包装重量，亚马逊认为您的包装箱重量不正确。 |
| 常见原因 | 输入的包装箱重量与亚马逊根据单个商品包装重量预期的值不符 |
| 问题解决 | 在库存的“编辑商品信息”部分中仔细检查您的商品包装重量 验证在工作流程步骤 1 中创建的装箱模板中的包装箱重量 如果两者均正确，您可以忽略此错误。这将允许您继续执行下一步。 |

#### 重量超过 [重量限制] [重量单位] 的包装箱必须标记为“重型包裹”。

| 字段 | 内容 |
| --- | --- |
| 错误定义 | 当包装箱超过单人搬运重量限制时，会出现此警告。需要贴上“多人合搬”或“机械升降”标签。 |
| 常见原因 | 包装箱重量超过标准搬运限制 |
| 问题解决 | 无需进行任何故障排除。发货前，请贴上所需标签并完成包装。要查看包装箱标签要求的重量限制，请参阅运输和路线安排要求。 |

#### 超出 50 磅的标准重量限值的箱子只能包含单件重量超出 50 磅的大件商品/内含标准尺寸商品的箱子在任何一侧的长度均不能超过 25 英寸

| 字段 | 内容 |
| --- | --- |
| 错误定义 | 您的包装箱尺寸或重量超过含多件商品包装箱的标准限制。 |
| 常见原因 | 包装箱包含多件商品但重量超过 50 磅 包含标准尺寸商品的包装箱的任何一边尺寸超过 25 英寸 |
| 问题解决 | 请遵循入库货件运输和路线安排要求中的指南 |

### 商品预处理、重量和尺寸错误

当 SKU 缺少所需的预处理配置、尺寸或重量信息时，就会出现这些错误。

#### 缺少此 SKU 的预处理分类。

| 字段 | 内容 |
| --- | --- |
| 错误定义 | 此 SKU 的预处理分类未配置。选择适用于此 SKU 的预处理分类，并为每件可售商品完成所有必要的预处理和贴标。 |
| 常见原因 | 创建 SKU 时未在商品信息中配置预处理要求 新创建或最近修改的 SKU 未配置预处理设置 |
| 问题解决 | 打开“发送至亚马逊”工作流程并前往步骤 1 找到触发错误的 SKU 选择预处理信息 选择适当的预处理指导。如果无需预处理，请选择“无需预处理” 选择“条形码设置”，然后点击“保存” |

#### 此商品缺少必要信息；需在制造商的原始包装中提供的尺寸信息。

| 字段 | 内容 |
| --- | --- |
| 错误定义 | 此 SKU 缺少尺寸信息（长、宽和高）。亚马逊需要准确的尺寸来计算仓储费、确定货位位置并管理库存。 |
| 常见原因 | 创建商品时未输入尺寸 未记录制造商原始包装的尺寸 先前输入的尺寸被意外删除 |
| 问题解决 | 在“发送至亚马逊”工作流程的步骤 1 中识别该 SKU 前往卖家平台中的“管理商品” 找到 SKU，然后点击旁边的“编辑” 滚动至“商品包裹尺寸”部分 添加包装尺寸，然后点击“保存” 请等待 15 分钟让系统更新 |

#### 此商品缺少必要信息；需在制造商的原始包装中提供重量信息。

| 字段 | 内容 |
| --- | --- |
| 错误定义 | 此 SKU 缺少重量信息。亚马逊需要准确的重量（包括包装）来计算运费、仓储费并确定搬运要求。 |
| 常见原因 | 创建商品时未输入重量 未记录制造商原始包装的重量 先前输入的重量被意外删除 |
| 问题解决 | 在“发送至亚马逊”工作流程的步骤 1 中识别该 SKU 前往卖家平台中的“管理商品” 找到 SKU，然后点击旁边的“编辑” 滚动至“商品包裹尺寸”部分 添加包装重量，然后点击“保存” 请等待 15 分钟让系统更新 |

### 商品信息和 SKU 错误

当您的商品在卖家平台中的发布或配置存在问题时，就会出现这些错误。

#### 此 SKU 已用于其他商品。请使用新的 SKU 创建新商品，这样才能使用制造商条形码。

| 字段 | 内容 |
| --- | --- |
| 错误定义 | 另一个亚马逊物流 (FBA) 商品已使用相同的卖家 SKU (MSKU) 来对应 ASIN 或状况不同的其他商品。 |
| 常见原因 | 现有的 FNSKU 映射使用相同的卖家 SKU，但 ASIN 不同 现有的 FNSKU 映射使用相同的卖家 SKU，但商品状况不同 |
| 问题解决 | 将您的商品信息更改为与现有 SKU 的 ASIN 或状况相同，然后转换为亚马逊物流网络 或使用不同的 MSKU 创建新的商品信息 如果在转换期间看到此错误： 前往卖家平台，点击“转换为亚马逊物流网络/MFN”，然后检查错误是否仍然存在 如果在“发送至亚马逊”中看到此错误： 搜索该 MSKU 并检查错误是否仍然存在 |

有关更多信息，请参阅[使用制造商条形码进行亚马逊物流虚拟追踪](https://sellercentral.amazon.com/help/hub/reference/G200141480)。

#### 商品不能为无需贴标签的共享库存。/此商品未贴标的情况下无法运送至亚马逊。

| 字段 | 内容 |
| --- | --- |
| 错误定义 | 您为此商品创建的商品信息/SKU 已损坏或已过期，需要更换。 |
| 常见原因 | 此 SKU 的虚拟追踪配置不再有效 |
| 问题解决 | 将此商品从入库计划中移除 为 ASIN 创建新的商品信息（新商品信息将自动获取更新的 ASIN 信息） 将新商品信息添加到入库计划 |

有关更多信息，请参阅[亚马逊物流虚拟追踪常见问题](https://sellercentral.amazon.com/help/hub/reference/G200141480)。

#### 此商品尚未在目标商城发布。

| 字段 | 内容 |
| --- | --- |
| 错误定义 | 此商品目前在目标商城中没有目录条目，因此无法入库到该商城。 |
| 常见原因 | 该 ASIN 在目标市场目录中不存在 |
| 问题解决 | 使用“添加商品”页面、上传数据或其他方法，在目标商城中创建该 ASIN 完成后，将该商品从入库计划中移除，然后再重新添加进来 |

有关更多信息，请参阅[发布亚马逊物流商品](https://sellercentral.amazon.com/help/hub/reference/G200141220)。

#### 此商品的 SKU 未知或找不到。

| 字段 | 内容 |
| --- | --- |
| 错误定义 | 系统暂时无法找到此 SKU。此问题通常是暂时性的。 |
| 常见原因 | 系统识别此 SKU 时存在暂时性延迟 |
| 问题解决 | 等待 1 小时，然后再次查看“发送至亚马逊” 重新保存装箱模板，检查错误是否解决 |

有关更多信息，请参阅[发布亚马逊物流商品](https://sellercentral.amazon.com/help/hub/reference/G200141220)。

### 运营中心资格错误

当亚马逊无法将您的商品安排到符合条件的运营中心时，就会出现这些错误。

#### 此商品必须从货件中移除，因为目前目的地国家/地区没有能够接收此商品的运营中心。

| 字段 | 内容 |
| --- | --- |
| 错误定义 | 目前没有符合要求的运营中心可以接收此商品。 |
| 常见原因 | 没有运营中心支持此商品的预处理类型 没有运营中心支持此商品的全球配送 没有运营中心支持具有某些属性（尺寸、特殊处理和危险品）的 ASIN |
| 问题解决 | 重试工作流程（重试时错误通常会得到解决） 如果错误仍然存在，请将商品从工作流程中移除，稍后再尝试创建新货件 |

有关更多信息，请参阅：

- [预处理指导](https://sellercentral.amazon.com/help/hub/reference/G201021850)

- [亚马逊全球开店](https://sellercentral.amazon.com/help/hub/reference/G200421970)

- [危险品识别指南](https://sellercentral.amazon.com/help/hub/reference/G201003400)

#### 纸箱中的商品没有符合所有要求的亚马逊运营中心可以接收。

| 字段 | 内容 |
| --- | --- |
| 错误定义 | 您装箱组中的商品不再有一个共同的符合要求的运营中心。当步骤之间间隔时间过长时，就会发生这种情况。 |
| 常见原因 | 在点击“确认并继续”之前，您在步骤 1b 和步骤 2 之间停留时间过长 在此期间，您的装箱组中商品适用的运营中心发生了变化 |
| 问题解决 | 返回步骤 1 并重新触发步骤 1b（这会重新规划装箱组） 及时点击“确认并继续”，以便在资格再次变更之前创建货件 |

### 库存容量和限制

当您的库存水平或容量限制阻止您创建货件时，会发生这些错误。

#### 此 ASIN 在亚马逊运营中心库存的供货天数已经很长。必须将该商品从此货件中移除。

| 字段 | 内容 |
| --- | --- |
| 错误定义 | 供货天数是指根据预测需求，当前库存预计能够持续供货的天数。此错误表示，此 SKU 的供货天数过高。 |
| 常见原因 | 此 ASIN 当前的亚马逊物流库存超出了预测需求阈值 季节性商品可能未被标记为季节性商品，导致预测不准确 该商品可能因其他原因受到限制（无在售信息的亚马逊库存、危险品审核或超龄库存） |
| 问题解决 | 查看亚马逊物流库存页面，了解库存状况和总供货天数 如果您的库存水平较高： 考虑使用亚马逊智能卫星仓或第三方仓储 如果您有季节性商品： 确认该商品在亚马逊物流库存页面上已标记为“季节性商品” 如果您的库存水平不高： 该商品可能因其他原因受到限制 |

有关更多信息，请参阅[管理亚马逊物流商品级别货件限制](https://sellercentral.amazon.com/help/hub/reference/G200332450)。

#### 此商品超出了 [类型] 仓储的容量限制。

| 字段 | 内容 |
| --- | --- |
| 错误定义 | 您想发送的数量，加上您当前的亚马逊物流库存和入库库存，超出了特定仓储类型（标准尺寸、大件、超大件、服装或鞋靴）的容量限制。 |
| 常见原因 | 您当前的亚马逊物流库存、入库库存和工作流程库存超出了您的容量限制 您同时有多个“发送至亚马逊”工作流程，且每个流程中都有大量库存正在处理中 |
| 问题解决 | 删除您不打算使用的任何“发送至亚马逊”工作流程（前往“发送至亚马逊”工作流程，点击右上角的“有效工作流程”） 如果这无法解决问题，请针对相应的容量类型提出容量请求。有关更多信息，请参阅容量管理器。 考虑使用亚马逊智能卫星仓或第三方仓储 |

#### 目前，未启用单一 SKU 托拍模板

| 字段 | 内容 |
| --- | --- |
| 错误定义 | 跨境/SEND 货件或亚马逊全球物流货件不支持托拍模板。 |
| 常见原因 | 您正在从一个国家/地区向另一个国家/地区发送货件（例如，从中国发送到美国） 您正在使用亚马逊全球物流 |
| 问题解决 | 如果使用的是跨境物流或亚马逊全球物流，请改在步骤 4 输入托拍尺寸 要使用托拍模板，请勿使用跨境物流或亚马逊全球物流计划 |

有关更多信息，请参阅[发送至亚马逊： 选择要发送的库存](https://sellercentral.amazon.com/help/hub/reference/G8SXKYFWPG6DAW6T)。

### 危险品错误

当商品需要进行危险品分类或超出危险品数量限制时，会发生这些错误。

#### 目前，没有运营中心可以接收此货件中的全部危险品。

| 字段 | 内容 |
| --- | --- |
| 错误定义 | 亚马逊对运营中心内的危险品执行最大允许数量限制。您的货件超出了这些限制。 |
| 常见原因 | 此货件中的危险品数量超过了目的地运营中心的监管数量限制 |
| 问题解决 | 从货件中移除错误消息中显示的商品 尝试将危险品单独以较小数量入仓 |

有关更多信息，请参阅[危险品最大允许数量限制](https://sellercentral.amazon.com/help/hub/reference/G201003400)。

#### 此商品正在接受危险品审核。/需要更多信息。/需要更多关于电池的信息。/提交的文件不一致，与商品不符。/提交的文件不完整。

| 字段 | 内容 |
| --- | --- |
| 错误定义 | ASIN 已通过危险品审核，但由于信息缺失或不一致而无法分类。 |
| 常见原因 | 详情页面信息不足（缺少标题、要点或商品描述） 缺少足够的电池相关信息，无法对商品进行分类 上传的文件与商品不符或不完整 |
| 问题解决 | 如果商品信息不足： 使用描述性信息更新详情页面（标题、要点、图片和商品描述）。提供商品六个面的图片，并确保危险声明、图形符号和成分清晰可见。 如果需要电池信息： 从“管理危险品分类”中下载豁免表，并上传完整信息。 如果文件不一致/不完整： 提供安全数据表 (SDS)。SDS 必须是在 5 年内创建或更新的，包含 GHS/CLP 危险信息，与您的商品信息相符，并包含标准 SDS 的所有 16 个部分。 |

**注意： **上传后，亚马逊会在四个工作日内对该 ASIN 进行审核。

有关更多信息，请参阅[危险品审核流程](https://sellercentral.amazon.com/help/hub/reference/G201003400)。

### 发货确认错误

当您因缺少信息或配置问题而无法继续执行步骤 1 之后的操作时，就会出现这些错误。

#### 此货件中的一件或多件商品无法发送。在步骤 1 中再次确认货件数量，查看错误详情，以激活确认按钮。

| 字段 | 内容 |
| --- | --- |
| 错误定义 | 一件或多件商品未通过验证，您需要返回步骤 1 查看具体错误详情。 |
| 常见原因 | 您的货件中的某件商品存在阻止确认的问题 |
| 问题解决 | 返回步骤 1，然后点击“新建” 重新输入您的货件数量 查看每件被阻止商品显示的具体错误详情 |

有关更多信息，请参阅[发送至亚马逊： 选择要发送的库存](https://sellercentral.amazon.com/help/hub/reference/G8SXKYFWPG6DAW6T)。

#### 灰显的框或“确认并继续”按钮被禁用

| 字段 | 内容 |
| --- | --- |
| 错误定义 | 您尚未完成步骤 1 的所有必填部分。 |
| 常见原因 | 发货地址缺失或无效 未选择商城 SKU 详细信息不完整或在信息/操作列中存在警告 对于已输入数量的 SKU，尚未点击“准备包装”或“准备发货”按钮 |
| 问题解决 | 要启用“要发送的数量”框和“确认并继续”： 输入有效的发货地址 选择商城 填写所有 SKU 详细信息并解决所有警告 为每个 SKU，点击“准备包装”或“准备发货” |

有关更多信息，请参阅[发送至亚马逊： 选择要发送的库存](https://sellercentral.amazon.com/help/hub/reference/G8SXKYFWPG6DAW6T)。
