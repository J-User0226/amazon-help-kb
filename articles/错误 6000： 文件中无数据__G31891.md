# 错误 6000： 文件中无数据

此文件中无数据。

如果您提交的文件不包含任何数据，则会出现此错误。要纠正该错误，您应该：
1. 在文本编辑器（如记事本 [Windows] 或 TextEdit [Mac]）中打开您所提交的文件。
2. 检查此文件是否包含您的数据。
3. 如果此文件包含数据，请重新提交。
4. 如果此文件为空，应根据最初源文件重新创建它。
