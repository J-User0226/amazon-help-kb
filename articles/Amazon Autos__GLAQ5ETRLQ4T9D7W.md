# Amazon Autos

## Amazon Autos

Amazon Autos 为经销商和在亚马逊上选购新车的买家提供了一个纽带。买家可在线浏览和购买，然后到经销商处提车。经销商负责控制定价和库存，而亚马逊则负责提供买家所期待的便捷可靠的在线购车体验。借助 Amazon Autos，经销商可以触达更多买家、达成销售（而非仅获取潜在客户），并通过广告宣传来推进业务发展。
