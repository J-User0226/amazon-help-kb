# 错误 100543

## 错误消息
禁止在 Bazaar 上销售与此商品相关的商品类型。要修复此问题，请编辑商品信息，并移除您的 Bazaar 商品或者删除 SKU。您仍然可以选择在 core A.in 销售此商品。有关更多信息，请点击“了解更多信息”。

## 导致错误 100543 的原因
出现此错误的原因如下：
- 您试图在 Bazaar 上发布的商品分类或商品类型属于禁止或受限商品。
- 此商品类型属于特殊监管要求范畴，Bazaar 不支持此类要求。

## 解决错误 100543
要解决此错误，请执行以下步骤：
1. 验证您的商品类型是否包含在 Bazaar 卖家的获批分类清单中。要了解有关亚马逊 Bazaar 的更多信息，请前往[亚马逊 Bazaar](https://sellercentral.amazon.com/help/hub/reference/GDJZZGNRXFYB9AG4)。
2. 如果该商品分类未获准售许可，请删除该商品的 Bazaar 报价。
3. 您仍然可以在准售的地方继续销售该商品。
