# 查看处理报告

**注意： **个人卖家： 此功能仅适用于专业销售计划。[了解更多信息](https://sellercentral.amazon.com/gp/help/external/64491)。

处理报告是以制表符分隔的文本文件，您可以使用 Microsoft Excel 或记事本等程序打开并阅读此类文件。处理报告是可下载文件，供您查看库存文件上传的状态。

要下载和查看处理报告，请按以下步骤操作：
1. **前往[添加商品](https://sellercentral.amazon.com/product-search/bulk?ref=xx_catadd_dnav_xx)。**
2. 前往【电子表格】选项卡，然后点击[查看上传状态](https://sellercentral.amazon.com/product-search/bulk/status)。
3. 电子表格中包含数据的每一行称为一条“记录”。 处理报告的顶部是记录（商品信息）一览，其中包括已处理的记录总数和成功处理的记录总数。其差值就是未成功处理（或处理时出现错误）的记录总数。

4. （可选）对 【error-type】 列进行筛选或排序，以便仅查看错误消息（不查看信息或警告类消息）。
5. 对于每项错误，请参阅 【original-record-number】 和 【SKU】 列，以判断库存文件中的哪一项记录导致了错误。 **注意： **库存文件的头两行不是记录信息。因此，处理报告记录 1 中的错误对应的是库存文件的第 3 行。

在以下示例中，共处理了 1,045 条记录，其中成功处理的有 1,030 条记录，15 条记录因出现错误而未能成功处理：

Feed Processing Summary Number of records processed: 1045 Number of records successful: 1030
处理报告按以下格式显示错误。您可使用此报告对您的库存文件进行必要的更改，然后重新上传文件，以更正您的商品信息。有关更多信息，请参阅库存模板文件中的 【Data Definitions】 选项卡，或查看我们的[错误代码说明](https://sellercentral.amazon.com/gp/help/external/17781)。

元素 描述
original-record-number 发生错误的记录编号。
库存文件模板的头两行不是记录信息。因此，记录 1 中的错误对应的是库存文件的第 3 行。

error-code 错误消息的编号。请参照[错误代码说明](https://sellercentral.amazon.com/gp/help/external/17781)查找此编号。
error-type 以下两个值之一：
- **警告：** 数据已成功处理，但未按预期显示。
- **错误：** 数据不充分或存在瑕疵，导致无法成功处理记录。

error-message 关于错误的简要说明，可能包括更正措施。
