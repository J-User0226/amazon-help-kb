# 配件数据故障排除

对配件数据缺失进行故障排除，识别常见故障原因，并更正提交错误。

## ASIN 上未显示配件数据

如果您已提交配件数据，且已等待最多 1 周，但仍未在您的 ASIN 上看到这些数据：

- 在卖家平台中，导航至【联系我们】。

- 在**更新商品信息**下打开一个问题单。

- 输入标题： 

［
提交的配件数据未显示
］
。

- 在表格中包含以下信息：

- 您的亚马逊配件数据供应商账户名称

- 您为其提交配件数据的品牌名称

- 配件数据的提交日期

- 1~3 个示例 ASIN

- 此问题单将转给相应团队。

## 常见失败原因

| 问题 | 原因 | 解决方案 |
| --- | --- | --- |
| 未找到零件编号 | 商品编号与品牌组合在亚马逊商品目录中不存在 | 请验证您在卖家平台的 ASIN 上的零件编号与您在 ACES 文件中提交的零件编号完全匹配 |
| 品牌未注册 | 品牌代码未在汽车护理协会注册 | 前往 autocare.org 注册您的品牌并重新提交 |
| 品牌名称不一致 | 您的 ASIN 上的品牌名称与您的品牌代码关联的品牌名称不一致 | 更新您的 ASIN 的品牌名称，以正确的品牌代码重新提交，或提交支持问题单，请求亚马逊添加品牌别名 |
| 零件编号为空或无效 | 零件编号字段为空或缺失 | 检查您的上传数据中是否存在 <Part> 元素为空的记录 |
| VCdb 验证失败 | 车辆配置数据与 VCdb 不一致 | 查看 AFM 控制面板中的错误报告并更正车辆信息引用 |

## 更正错误的配件记录

请按照以下步骤更正您已提交数据中的错误零件编号：

- 为每条零件编号不正确的记录提交一项 action="D" 的 UPDATE 上传数据。

- 为每条具有更正后零件编号的记录提交一项 action="A" 的 UPDATE 上传数据。

- 这两个步骤可以包含在同一个 XML 文件中。请先放置删除记录，再放置添加记录。

**您必须先删除旧记录。仅提交更正后的记录会导致错误记录与新记录一起留在系统中。**

## 新手入门问题

如果您在新手入门流程中遇到问题，请在卖家平台中打开支持问题单，并请求将其分配给**汽车数据质量团队**。

**注意： **亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。
