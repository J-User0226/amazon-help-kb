# 开始使用多位置库存

多位置库存适用于具有单个或多个位置且通过 SP-API、上传数据 API、卖家平台的“管理所有库存”、卖家平台的模版上传功能或第三方合作商（多渠道合作商）提供库存的所有卖家自配送 (FBM) 卖家。您可以根据需要添加多个或仅添加几个 ASIN。要获得多位置库存的优势，我们建议您添加您的所有 ASIN。要使用多位置库存，必须在卖家平台中启用“配送设置自动化”。首先，请按照以下步骤进行操作：

- 创建和管理您的位置。

- 参考我们的多位置库存 API 集成说明来了解如何设置位置（也称为“供货来源”或“S2”）。您可以通过 API 集成或卖家平台创建位置。

- 查看集成说明

- 添加或更新您的位置级别库存。

- 使用以下选项管理和更新您的卖家自配送 SKU 的位置级别库存：

- 选项 1： 使用 SP-API

- 选项 2： 使用上传数据 API

- 选项 3： 在卖家平台中上传上传数据文件

- 选项 4： 使用卖家平台中的“管理所有库存”

- **注意： **（仅限首次使用时）您必须清空要为其共享位置级别库存的 SKU 的“默认”配送渠道库存。

- 在您的配送模板中启用配送设置自动化 (SSA)，并将使用多位置库存 (MLI) 同步的 ASIN 分配到此模板中。请按照以下步骤启用配送设置自动化 (SSA)： 

- 在卖家平台右上角的【设置】下拉菜单中，点击【配送设置】。

- 前往【配送模板】选项卡。

- 在【配送模板】选项卡上，您可以根据以下情况启用“配送设置自动化”：

- 点击【创建新配送模板】，然后选择新的【配送模板】。

- 选择【现有配送模板】，然后点击【编辑】。

- 启用【配送设置自动化】选项。

- 选择一个或多个【发货地址】，然后点击【下一步】。这些位置应与您的库存位置一致。

- 选择 Prime 或非 Prime 配送模板，然后点击【下一步】。

- 在【标准配送自动化首选项】页面上，按照以下步骤为标准配送启用自动运输时间： 

- 在【地区首选项】部分下，点击【编辑】，以管理您的标准配送地区。

- 在【承运人首选项】部分中，选择您目前使用的承运人和配送服务，然后点击【下一步】。

- 如果您从国内运营中心发货，则可以为优先配送地区自动化启用卖家自配送“次日达”和“隔日达”功能。在【优先配送自动化首选项】页面的【承运人首选项】部分中，选择您使用的承运人和配送服务，然后点击【下一步】。

- 查看您的配送设置自动化首选项，然后点击【确认】。

- 查看并编辑适用于您配送地区的【运费】。

- 点击【保存】以保存模板。

- 将您的多位置库存 SKU 分配到此配送模板中。

目前，配送模板仅限 10 个位置。您使用多位置库存同步的 ASIN 可以与未使用多位置库存同步的 ASIN 位于同一配送模板中。但是，此配送模板应启用配送设置自动化 (SSA)，并且必须包含您的所有库存位置。

您可以对卖家自配送 Prime 使用多位置库存，并根据需要将您的多位置库存放在任意数量的配送模板上。

如果在具有使用多位置库存同步的 ASIN 的配送模板上禁用了配送设置自动化，您的买家仍然可以下单。但是，您的配送承诺将以您的人工估算为准，您将无法享受到多位置库存和配送设置自动化的优势。
