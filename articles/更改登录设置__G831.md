# 更改登录设置

要更改您的账户电子邮件地址，请按以下步骤操作：

1. 在您的卖家账户中，转至【设置】，然后点击[登录设置](https://sellercentral.amazon.com/gp/seller/configuration/login-settings.html/)。
2. 点击【电子邮件地址】字段旁边的【编辑】以打开【更改电子邮件地址】表单。
3. 输入新的电子邮件地址，重新输入新的电子邮件地址，然后在指示的字段中输入密码。
4. 点击【保存更改】。

要更改您的账户密码，请按以下步骤操作：

1. 在您的卖家账户中，转至【设置】，然后点击[登录设置](https://sellercentral.amazon.com/gp/seller/configuration/login-settings.html/)。
2. 点击【密码】字段旁边的【编辑】以打开【更改密码】表单。
3. 输入当前密码，输入新密码，然后在指示的字段中重新输入新密码。
4. 点击【保存更改】。

如果您启用了两步验证，则可能需要输入安全代码才能更改“高级安全设置”。了解更多有关[两步验证](https://sellercentral.amazon.com/gp/help/external/202110760)的信息。
