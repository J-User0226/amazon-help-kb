# 亚马逊物流精选绩效衡量

## 入门：您的 90 天试用期

在您发出首个 FBA Select 货件后的前 90 天内，亚马逊会与您密切合作，帮助您熟悉该计划的工作流程。在试用期内，我们每周都会追踪您的绩效指标，并将其作为学习反馈提供给您。在此期间，我们不会采取基于绩效的强制措施。

在试用期内，您每周都会收到以下反馈：

- 【发货前绩效】： 您的数量调整与亚马逊建议的入库计划是否一致

- 【发货后绩效】： 您的准时送达率、足量交货以及货件质量指标

- 【指南】： 您的绩效与计划期望的对比情况，以及改进建议

此试用期旨在帮助您了解 FBA Select 计划的运作方式以及实际绩效期望，以及该计划是否符合您的业务运营需求。

【试用期结束后】： 如果您持续遇到绩效方面的挑战，亚马逊将通过专门的指导和运营支持与您合作，帮助您了解根本原因并帮助您满足计划要求。这种以指导为中心的方法体现了我们致力于优化所售商品，同时与卖家建立战略性长期合伙。我们将一起探索多种选项（包括其他指导、运营调整或配置更改），以确保该计划适用于您的业务。只有在结构限制导致长期无法进行计划调整，我们才会提前 30 天通知您终止参与该计划。

## 每月业务评论

亚马逊将分享您的关键月度业务绩效指标，以帮助您追踪进度，并充分利用您的 FBA Select 计划。这些评论涵盖：

- 【加入计划】： 符合要求的 ASIN 的注册范围。要继续参与该计划，您必须在 90 天的试用期过后让至少 80% 的高周转 ASIN（过去 8 周内周平均销量超过 100 件）继续注册在该计划中，并主动使用 FBA Select 计划

- 【配送速度和销售影响】： 已注册 ASIN 的配送速度绩效和一览视图转化率，包括次日达和当日达配送速度绩效

- 【库存状况】： 您对已确认入库计划中指定的库存水平的维护状况如何，包括已注册商品组合的可维持周数

- 【加入计划】： 符合要求的 ASIN 的注册范围以及卖家对计划工作流程的积极参与

- 【供应链成本节省】： 通过合并货件降低运输成本，降低费用，并提高 FTL/FCL 利用率

- 【入库计划的执行】： 您接受和执行亚马逊建议的入库计划（包括入库前计划的遵从性以及发货后的准时配送和足量配送绩效）的情况。

- 【预测调整】： 亚马逊和您自己的预测与实际需求相比的表现，以及供应限制是否影响了计划质量

- 【优化机会】： 通过调整配置、ASIN 精选或计划输入内容可改善效果的方面

- 【未解决的问题和挑战】： 您遇到的任何运营或计划方面的问题，亚马逊均可以帮助您解决

## 如何衡量绩效

我们会在两个广泛方面持续追踪绩效。所有指标都是在过去 4 周 (T4W) 的基础上计算的，并按每个 ASIN 的过去 4 周配送商品加权计算，这意味着相较于低周转 ASIN，您的高周转 ASIN（流通快且每周销量更高的商品）对您的整体分数影响更大。

【发货前绩效】用于衡量您使用亚马逊建议的入库计划的情况，特别是您确认的货件数量与亚马逊的建议是否一致。您可以修改计划数量以反映您的供货情况（例如供应商限制条件、需求变动或物流中断），我们会追踪您的整体计划接收率。要了解有关发货前绩效的更多信息，请参阅 [FBA Select 发货前绩效](https://sellercentral.amazon.com/help/hub/reference/G68PMCL58WK6S2EW)。

【发货后绩效】用于衡量您在创建货件后执行的效果 - 包括准时送达率、完整配送以及标准 FBA 运营要求（如正确贴标和有效追踪）。要了解有关发货后绩效的更多信息，请参阅 [FBA Select 发货后绩效](https://sellercentral.amazon.com/help/hub/reference/GTAPQUXDPJA5QTSA)。
