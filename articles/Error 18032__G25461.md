# Error 18032

促销编码未被识别。有关如何修复此错误的详细信息，请参阅 http://sellercentral.amazon.com/gp/help/25461

对于提交制表符分隔的盘点文件的卖家而言，会在商品促销 ID 或配送促销 ID 值未被识别时发生此错误。此值应与您在订单报告中提供的“商品促销编号”值或“配送促销编号”值相同。

对于发布 XML 上传数据的卖家而言，当您的订单盘点上传数据中的“卖家促销 ID”值不被识别时会发生此错误。此值应为在您的订单报告中提供的“卖家促销 ID”值。

如果您的订单报告未包含商品促销 ID、配送促销 ID 或“卖家促销 ID”的值，请勿在您的盘点文件或上传数据中包含“无”或“不适用”等数值。您应将此数值留空。

要解决此错误，请使用有效的“商品促销 ID”、“配送促销 ID”或“卖家促销 ID”值重新提交数据。
