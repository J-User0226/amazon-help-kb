# Amazon Handmade： 分类商品政策和要求

要在 Amazon Handmade 中发布商品，您的商品需要符合 [Amazon Handmade 商品资格](https://sellercentral.amazon.com/gp/help/external/G201817090)以及亚马逊针对 Amazon Handmade 商品的[名称](https://sellercentral.amazon.com/gp/help/external/GRLUNACJV3JB23G2)、[图片](https://sellercentral.amazon.com/gp/help/external/GNRP6DDJV79DUHRD)和[定制](https://sellercentral.amazon.com/gp/help/external/G201817850)标准中描述的资格要求。 所有 Amazon Handmade 商品必须遵守以下特定分类的商品政策和要求：

- [Amazon Handmade 艺术品指南](https://sellercentral.amazon.com/gp/help/external/GW5Y4K4TBPVLLNQX)

- [Amazon Handmade 母婴用品指南](https://sellercentral.amazon.com/gp/help/external/GDLH7JE6U8WXKCFH)

- [Amazon Handmade 美妆和美容用品指南](https://sellercentral.amazon.com/gp/help/external/G202102450)

- [Amazon Handmade 服装、鞋靴和配饰指南](https://sellercentral.amazon.com/gp/help/external/G202175100)

- [Amazon Handmade 电子产品配件指南](https://sellercentral.amazon.com/gp/help/external/GVQT5YS63MG8TJW4)

- [Amazon Handmade 个护健康用品指南](https://sellercentral.amazon.com/gp/help/external/GQEW7ZE8DX838YG4)

- [Amazon Handmade 珠宝首饰和钟表指南](https://sellercentral.amazon.com/gp/help/external/G201817790)

- [Amazon Handmade 宠物用品指南](https://sellercentral.amazon.com/gp/help/external/G202102470)

- [Amazon Handmade 家居及厨房用品指南](https://sellercentral.amazon.com/gp/help/external/GVA9JWUJ37GWA57B)

- [Amazon Handmade 运动户外用品指南](https://sellercentral.amazon.com/gp/help/external/GNBPK6NFHKZJ66U3)

- [Amazon Handmade 文具和派对用品指南](https://sellercentral.amazon.com/gp/help/external/GSEBFHFCAWN43DUH)

- [Amazon Handmade 玩具和游戏指南](https://sellercentral.amazon.com/gp/help/external/GZ9D44DRSKGCYAJ7)

除了这些特定分类的政策和要求外，在 Amazon Handmade 发布的所有商品还必须遵守亚马逊销售和发布政策，包括：

- [销售政策和卖家行为准则](https://sellercentral.amazon.com/gp/help/external/G1801)

- [商品详情页面规则](https://sellercentral.amazon.com/gp/help/external/G200390640)

- [状况指南](https://sellercentral.amazon.com/gp/help/external/G200339950)（升级改造或再利用的商品除外）

- [卖家知识产权政策](https://sellercentral.amazon.com/gp/help/external/G201361070)

- [成人用品政策和指南](https://sellercentral.amazon.com/gp/help/external/G200339940)

- [受限商品](https://sellercentral.amazon.com/gp/help/external/G200164330)

- [冒犯性和有争议的商品](https://sellercentral.amazon.com/gp/help/external/G200164670)

除了现有政策外，在 Amazon Handmade 中也不允许出现以下情况：

- 将商品生产外包

- 直接代发货的商品

- 由第三方转售商品

- 以下商品不允许在 Amazon Handmade 店铺中销售：

- 数字或可下载商品

- 食品或其他可食用的商品

- 电视/音响

- 活体植物 - 可能随附在手工制作的花盆/容器中的“气生植物”除外

- 不得在 Amazon Handmade 店铺中销售原材料和手工制作用品，但以下情况除外：

- DIY 套件中包含的手工制作用品

- 由您（即手艺人）制作的手工制作用品；例如，由手工制作的纱线或毡制品

- 经您（即手艺人）改造过的手工制作用品；例如，您染制的预购羊毛或纱线
