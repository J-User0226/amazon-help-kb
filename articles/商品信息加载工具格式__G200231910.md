# 商品信息加载工具格式

下表显示了商品信息加载工具格式的字段。可在下载的模板的【数据定义】选项卡中找到完整的属性和定义列表。

| 标签名称 | 定义和用途 | 是否必须提供？ |
| --- | --- | --- |
| Contribution SKU | 卖家为商品分配的唯一标识。发布的每件商品的 SKU 必须是独一无二的。为商品确定一个 SKU 后，在系统中删除相关商品之前请勿更改 SKU。 | 是 |
| Price | 卖家想要出售商品的价格（单位：美元）。 | 是 |
| Quantity | 输入您的待售商品的数量。这是您承诺的当前库存量。 | 是 |
| External Product Id | 用于唯一标识商品的标准字母数字字符串。可以是 UPC、EAN 或全球贸易项目代码。您也可使用条形码扫描仪直接输入此字段的值。您可以提供卖家建议的 ASIN 或外部商品编码。 | 是 |
| External Product Id Type | 在 product-id 字段中输入的唯一商品编码的类型。product-id-type 可以是以下选项之一： UPC、EAN 或全球贸易项目代码。 | 是 |
| Merchant Suggested ASIN | 如果您认为您的商品已存在 ASIN，请在此处提供。否则，请将此字段留空，系统将根据您提供的外部商品编码查找匹配项。 | 是 |
| Offering Condition Type | 指定商品状况，如“新品”、“二手，类似新品”、“二手，很好”等。从下拉菜单中选择一个选项。 | 是 |
| Offer Condition Note | 说明商品实际状况的描述性文本。如果 condition-type 不是“新品”，则此项选填。 | 可选 |
