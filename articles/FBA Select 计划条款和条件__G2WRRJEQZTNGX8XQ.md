# FBA Select 计划条款和条件

## FBA Select 计划条款和条件
如果您参与 FBA Select 计划（以下简称“【FBA Select】”或本“【计划】”），则要遵守本条款和条件（以下简称“【条款和条件】”）。本条款和条件是对[亚马逊服务商业解决方案协议](https://sellercentral.amazon.com/gp/help/external/G1791)（以下简称本“【协议】”）的补充。

- 本计划仅面向受邀卖家开放，并且卖家已通过电子邮件直接从亚马逊或者是通过其客户成功经理或客户经理收到了邀约。
- 只有符合亚马逊确定的特定客观资格标准的卖家和选品才可以参与该计划。资格可能会基于可衡量的运营因素、物流因素或经济因素来确定，包括但不限于：
  - 卖家配送基本情况
  - 库存特征
  - 供应链属性
  - 针对选品的绩效信号
  - 配置优化潜力
  - 网络效率指标

- 您将会获得“FBA Select 权益”帮助页面中描述的权益、服务或奖励（统称“计划权益”）。如果本计划包含货币奖励，金额将会以当地货币表示。计划权益只能用于邀约中指定的商城或商品。
- 要享受计划权益，您必须在指定的时间内完成邀约和/或计划页面中列出的注册步骤，同时还必须遵守邀约和/或计划页面中规定的所有要求，以确保您可以一直注册本计划。如果出现违规行为，可能会导致计划权益调整，若持续出现违规行为，可能会导致将您从本计划中移除。
- 如果邀约包含货币奖励或费用抵扣额度，则会在您注册时添加到您的卖家账户。任何未使用的奖励金额或抵扣额度都将在其存入您的卖家账户满一年后过期。
- 提供的计划权益不可转让，不可转售，也不可兑换现金。所有计划权益均由亚马逊依据特定条件自行决定提供，可随时修改或撤销，且不保证达成特定结果。
- 如果您违反本条款和条件或亚马逊服务商业协议，邀约将失效。亚马逊可能会取消所有未使用的计划权益，并且撤销加入本计划时发放到您账户的所有奖励。
- 亚马逊可随时终止或修改本条款和条件、更改或取消现有的计划权益，或取消您参与该计划的资格。
