# 亚马逊物流出口

**注意： **本页面上与亚马逊物流相关的所有信息均适用于在 Amazon.com 网站上进行国际销售的卖家。如果您想要在我们任何其他商城发布并销售您的商品，请转至[亚马逊全球开店](https://sellercentral.amazon.com/global-selling/dashboard/)。

亚马逊物流出口计划可帮助您将业务拓展至多个国家和地区，而无需支付任何额外费用。
- 来自 100 多个国家和地区的国际买家都可以访问您的本地店铺，并可购买符合亚马逊物流出口要求的商品。
- 亚马逊可帮助您确定符合亚马逊物流出口要求的商品，配送您的国际订单，处理进口关税和清关事宜，并将您的商品配送到国际买家的地址。
- 国际配送运费和关税由国际买家支付。配送亚马逊物流出口订单的卖家无需支付任何额外费用。配送亚马逊物流出口订单的卖家无需支付任何额外费用。
- 您可以从亚马逊物流出口计划中排除某些商品，也可以排除某些国家/地区。
- 亚马逊将根据退货政策来确定通过亚马逊物流出口配送的商品是否符合退货要求。
- 您可以使用卖家平台账户中的商品信息，向在 Amazon.com 购物的国际买家销售符合亚马逊物流出口要求的商品。除了多渠道配送订单外，卖家无需支付其他费用便可加入亚马逊物流出口计划。有关更多信息，请访问[亚马逊物流出口费用](https://sellercentral.amazon.com/gp/help/external/200804980)。

**注意： **要使用亚马逊物流出口计划，应确保所有符合亚马逊物流出口要求的商品可以在没有任何许可或其他授权的情况下合法出口，并且可以合法地进口至任何符合亚马逊物流出口要求的国家/地区，同时遵守当地所有适用的法律。

## 亚马逊物流出口注册
在默认情况下，大部分卖家会自动注册加入亚马逊物流出口计划。要查看您的亚马逊物流出口计划注册状态，请点击卖家平台【设置】下拉菜单中的【亚马逊物流】。您可以前往【出口设置】组，随时启用或禁用亚马逊物流出口排除国家/地区。

注册加入，即表示您授权亚马逊及其附属公司根据需要代表您从出口商品（包括签署商业发票）。此商业发票将详细列举并描述货件内容，并授权报关行和其他第三方签立出口商品所需的其他文件。

## 如何编辑您的亚马逊物流出口设置
亚马逊物流出口设置因商城而异。要编辑您的亚马逊物流出口设置，请在卖家平台中执行以下步骤：
1. 前往【设置】，选择【亚马逊物流】。
2. 向下滚动到【配送计划和出口设置】，然后点击【编辑】。

**结果：** 在同一页面上，您可以更改设置，随时停止出口您的亚马逊物流商品，或者从此计划中排除 ASIN。

## 将国家/地区或商品从亚马逊物流出口货件中排除
您可以通过排除国家/地区（不包括商品）或从某些国家/地区排除某些商品来更改亚马逊物流出口设置，以此满足您的业务需求。

排除国家/地区：

1. 前往【设置】下拉菜单，点击【亚马逊物流】。

2. 前往【出口设置】，然后点击【编辑】。

3. 在【配送限制】部分，点击【编辑】，选择您要排除的国家/地区，然后点击【保存】。

要从部分或所有国家/地区排除单件商品 , 请执行以下操作：

1. 在【设置】下拉菜单中，点击【亚马逊物流】。

2. 前往【出口设置】，然后点击【编辑】。

3. 点击【排除商品】。

4. 下载亚马逊物流出口排除文件，并按照文件中的说明从某个国家或地区排除个别商品。
5. 通过上传文件，您可以排除多达 100 万个非媒介类商品。

6. 您可以随时编辑、添加或移除亚马逊物流出口排除列表中的商品。

## 亚马逊物流适用商品
如需查看您的亚马逊物流库存中符合亚马逊物流出口条件的商品列表，请前往[可出口库存报告](https://sellercentral.amazon.com/reportcentral/EXPORTABLE_INVENTORY/1)。即使您禁用了亚马逊物流出口计划，也可以查看此列表。我们会定期更新此报告，因此，如果您目前没有可出口的商品，请稍后再查看。

**注意： **您可以将音乐、影视和 DVD 等商品配送至加拿大。您不能将图书类商品从美国配送至加拿大。

商品可能会因多种原因不符合亚马逊物流出口的要求，包括：

- **出口限制： **对于某些类别的商品，原产国/原产地的法律禁止这些商品进行国际配送。例如，为了国家安全，美国政府禁止出口军用商品。通常，以下类型的商品会被限制出口：
  - 武器和仿制武器
  - 植物、植物制品、种子和土壤
  - 动物和某些动物制品
  - 监控设备
  - 激光笔和相关商品

- **进口限制： **有时即使原产国/原产地可能允许出口某种商品，但目的地国家/地区可能对可进口的商品有自己的政策。政策因国家/地区而异。为了避免出现延迟、清关问题以及买家体验不佳的情况，亚马逊通常会限制对以下类型的商品（根据各个国家/地区进行评估）进行国际配送：
  - 酒类
  - 武器、武器组件和武器配件，包括防身喷雾；BB 枪、气枪、彩弹枪及其零部件；瞄准镜；枪套和便携包
  - 化学品，包括农药、肥料、杀虫剂、工业用化学品、汽车用化学品和某些清洁剂
  - 食品、药品和补充剂，包括宠物食品和宠物补充剂
  - 医疗器械，包括诊断工具、医疗警报设备和性别鉴定工具
  - 药物用具
  - 成人用品
  - 酿酒设备
  - 婴儿学步车、婴儿自主进食设备和儿童安全座椅
  - 加密电子设备
  - 赌博相关商品和用具
  - 仿制货币

- **运输和物流限制： **亚马逊会根据物流或运输限制而实施某些限制。例如，如果商品超过某一尺寸和重量，则无法加入出口计划。运输限制包括：
  - 重型或大件商品，如床垫或床
  - 危险品
  - 大型或独立的锂离子电池
  - 二手油，如食用油或机油

- **尚未处理的 ASIN： **指正在等待审核以确定是否符合亚马逊物流出口要求的商品。我们每个月会对新的 ASIN 进行一次资格审核。请为商品完善完整商品描述或五点描述，以便平台在下一轮审核周期完成处理。

有关更多信息，请参阅[危险品识别指南](https://sellercentral.amazon.com/gp/help/external/201003400)和[亚马逊物流商品限制](https://sellercentral.amazon.com/gp/help/external/G200140860)。

亚马逊可生成报告来帮助您确定符合亚马逊物流出口要求的商品，配送您的国际订单，处理进口关税和清关事宜（如适用），并将您的商品配送到国际买家的地址。

## 亚马逊物流出口和商品分销协议
如果您担心分销协议可能会限制您的商品在海外的销售范围，您可以退出亚马逊物流出口计划、限制发往某些国家/地区的货件、从该计划中排除特定商品或将某些国家/地区和目的地排除在出口范围之外。 您可以随时出于任何原因执行上述操作。

## 亚马逊物流出口国际订单销售报告
通过亚马逊物流出口计划，国际买家可以向您订购符合该计划要求的商品。要查看您的亚马逊物流出口计划销售报告，请前往【报告】选项卡，点击【配送】，然后在左侧面板中的【销量】下方，点击【亚马逊配送货件】。 在左侧面板中的【销量】下方，点击【亚马逊配送货件】。您可以按照“收货目的地国家/地区”进行筛选，来查看您的亚马逊物流出口国际订单。

对于 API 卖家，枚举值是“_GET_AMAZON_FULFILLED_SHIPMENTS_DATA_”。

## 国际多渠道配送订单
**重要： **只有以下媒介类商品才符合国际多渠道配送的要求：媒介类商品（图书、音乐、影视）。

即使非媒介类商品的 ASIN 符合亚马逊物流出口条件，但您仍无法为此类商品创建国际多渠道配送订单。

## 亚马逊物流出口的国际退货
通过亚马逊物流出口，亚马逊可为您的订单提供配送和客户服务，包括处理买家退货。亚马逊会根据亚马逊会根据[亚马逊退货政策](https://www.amazon.com/gp/help/customer/display.html/?nodeId=15015721)来确定商品是否符合退款要求。 来确定商品是否符合退货要求。但是，为了确保提供良好的买家体验，我们将会根据具体情况进行例外处理，接受可能已超出规定退货时间且通过亚马逊物流配送的商品的退货。

如果买家退回某一商品，亚马逊将按照标准亚马逊退货政策进行处理。如果在收到退回的商品时，该商品仍处于可售状况，亚马逊会将其退回至原卖家的库存。如果退回的商品处于不可售状态，亚马逊将确定责任方（亚马逊或买家），并根据[亚马逊物流丢失和已残损库存赔偿政策](https://sellercentral.amazon.com/gp/help/external/G200213130)进行赔偿。

如果商品没有缺陷，买家必须支付退货配送成本。如果商品存在缺陷，买家需要支付运费并将商品寄回亚马逊运营中心。亚马逊在收到包裹后会向买家补偿实际退货运费。

有关更多信息，请参阅[亚马逊物流买家退货政策](https://sellercentral.amazon.com/gp/help/external/G200379860)。
