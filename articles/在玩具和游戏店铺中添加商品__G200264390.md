# 在玩具和游戏店铺中添加商品

[/p
{""}) [/p/b
{""}) 下列条款仅适用于专业卖家。 (b] (p]

您可使用大部分现有卖家平台工具向玩具或母婴店铺中添加商品或库存。其中包括添加新商品、文本文件上传和 XML 上传数据。

如果您使用的是文本文件模板，您的下一步骤是：

- 下载最新的库存模板

- 填写您的库存文件

- 上传您的文件

要开始准备您的库存等待上传，请下载[/concept/conbody/p/a
{""}) 库存模板 (a]或 [/concept/conbody/p/a
{""}) XML 模板 (a]。

请务必包含每个商品的以下字段：

- [/concept/conbody/ul/li/strong
{""}) 商品类型： (strong]必须是 
[/concept/conbody/ul/li/em
{""}) 玩具和游戏 (em] 或者 
[/concept/conbody/ul/li/em
{""}) 母婴 (em]

- [/concept/conbody/ul/li/strong
{""}) 商品类型： (strong]必填

- 其他商品属性

- 主题内容

- 目标受众

- 用途

[/concept/conbody/p
{"attention"}) 注意：如果未包含关键字段，这会让您的商品无法在店铺的分类树中显示，或者会导致上传完全失败。 (p]
