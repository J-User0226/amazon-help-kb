# 签名确认建议

亚马逊使用机器学习技术，根据商品价值、商品类型和买家购物历史等几个标准来分析每个买家订单，以确定有可能会报告丢失的订单。 亚马逊将在各个卖家平台页面中使用专用 UI 消息和横幅来标记这些订单。

- 管理订单 - 【订单状态】下方将显示一条新消息：【建议进行签名确认】。

- 订单详情 - 页面顶部将显示一个新横幅，并在【更多信息】下显示一条消息。

**注意： **如果“签名确认”框可用，且您随货件购买了“签名确认”选项，请确保选中此选项。

此功能可减少您因订单商品丢失而支付的退款和索赔，据我们估计，为存在风险的订单添加签名确认可将丢失订单的报告率减少 35%。

如果您采纳该建议，请在“购买配送服务”页面上选择【签名确认】或【成人签名确认】作为确认方式。 签名确认的费用将计入您的运费。

如果买家报告已启用“签名确认”的订单商品【丢失】或【未收到】，亚马逊将在批准索赔或退款之前对该买家的账户执行额外检查。对于在您未参与的情况下批准的索赔，您都可以提出申诉。

**企业买家希望在营业时间内收到商品**，以尽可能减少多次尝试妥投以及包裹丢失或被盗的情况。【签名确认】可确保承运人在营业时间内将包裹配送给买家，从而帮助您获得更好的配送体验。有关营业时间配送的更多信息，请参阅[营业时间配送费率](https://sellercentral.amazon.com/help/hub/reference/GL6AWZ3XEHAQ66M8)。
