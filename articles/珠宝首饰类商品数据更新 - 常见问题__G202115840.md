# 珠宝首饰类商品数据更新 - 常见问题

#### 门类名称和商品类型关键字的“有效值”有哪些？
商品类型关键字的当前有效值已在分类树指南 (BTG) 中列出。针对珠宝首饰的分类树指南可在[特定分类模板](https://sellercentral.amazon.com/gp/help/external/G1641)页面上找到。
门类名称的有效值有：

- womens
- mens
- unisex-adult
- girls
- boys
- unisex-child

#### 材质类型、金属类型、宝石类型和珍珠类型的“有效值”有哪些？
这些属性的当前有效值已在珠宝首饰库存文件模板的“有效值”选项卡中列出。

#### 我无法访问库存文件上传工具，我该怎么做？
珠宝首饰分类政策规定，珠宝首饰卖家必须订阅专业销售计划，可按月支付服务费。只有参与专业销售计划的卖家才能使用库存文件上传工具更新 ASIN。如果您目前未参与专业销售计划，则可以立即切换到专业销售计划。有关更多信息，请阅读[切换到专业销售计划](https://sellercentral.amazon.com/gp/help/external/201747610)。

#### 我上传了新的 ASIN 数据，但新数据未反映在 ASIN 上，或在尝试进行更新时收到了错误。我该怎么做？
尝试针对该 ASIN 上传库存为 0 件商品的库存文件，然后添加您当前有货的实际商品进行重新上传。如果这没有解决问题，请下载一个新的分类商品报告，并检查您的 ASIN 数据。如果您提交的新数据仍未更新，那么原因有以下两个：
**原因 1：** 如果某个 ASIN 有多个卖家提供有效报价，则无法更新该 ASIN 的某些规格数据。

- 如果您创建了一个私有品牌 ASIN，而其他卖家有在售商品采用此 ASIN，那么这些卖家就违反了珠宝首饰分类政策。请按以下步骤操作：
  1. 在卖家平台中，[举报违规行为](https://sellercentral.amazon.com/gp/help/external/200444420)。请务必加入卖家姓名、卖家店铺 URL 和提供私有品牌 ASIN 的每位卖家的 ASIN 列表。
  2. 移除未经授权的商品后，我们会重新尝试上传您的库存文件模板。

- 如果您不是品牌的所有者、许可证持有人或授权卖家，请为您的商品创建一个新的 ASIN，并将品牌名称指定为“无品牌”或私有品牌。

**注意： **ASIN 的商品名称、要点和商品描述中提到的品牌必须与指定为品牌名称的品牌匹配。有关品牌名称和 ASIN 匹配政策的更多信息，请参阅[珠宝首饰分类政策和要求](https://sellercentral.amazon.com/gp/help/external/200332590)。

**原因 2：** 如果您不是 ASIN 品牌的品牌所有者，那么其他卖家可以是该 ASIN 的亚马逊 Brand Registry 品牌所有者，亚马逊零售部门也可以提供该 ASIN。

在这种情况下，零售部门或品牌所有者提交的数据将始终优先于您提交的数据；如果您希望将某个属性更新成与他们所提交值不同的值，请按以下步骤操作：

1. 在卖家平台中，点击[联系我们](https://sellercentral.amazon.com/gp/contact-us/)，然后依次点击“我要开店”“商品和库存”和“发布商品问题”。
2. 选择“提供批次编号”选项并予以输入，或者选择“我没有 ASIN 或 SKU 或批次编号”选项，然后点击“下一步”。
3. 在“我们能为您提供什么帮助？”下，点击“库存文件上传问题”，然后点击“下一步”。
4. 点击“电子邮件”选项卡。
5. 点击“添加附件”按钮，附上只包含未在 Amazon.com 详情页面上显示您所提交数据的那些 ASIN 的库存文件模板。
6. 输入以下信息，然后点击“发送”：
  - 联系原因： 我的库存文件模板不更新 ASIN 数据。
  - 请描述您的库存文件问题： 我需要更新所附文件中这些 ASIN 的数据。我已经上传了包含正确 ASIN 数据的库存文件模板。请检查 [品牌] 是否在亚马逊 Brand Registry 上进行了注册。如果是，请将此库存文件模板转发给品牌所有者，并要求他们将这些 ASIN 更新为正确的值。如果否，则请要求分类卖家经理更新这些 ASIN。
  - 批次编号：（输入您的批次编号）。
  - SKU： 请参阅附件。

**注意： **亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。

#### 我成功更新了 ASIN，但现在我的一些商品被取消了。为什么？
如果卖家希望销售由贵重金属、宝石或珍珠制成的珠宝首饰，则必须获得特殊许可。如果您没有此权限，请通过[珠宝首饰](https://sellercentral.amazon.com/gp/help/external/200332590)页面底部的链接重新申请加入“珠宝首饰”分类，并说明您有意销售采用优质材料制成的珠宝首饰。

#### 为什么我的有些 ASIN 被禁止显示？
珠宝首饰 ASIN 被禁止显示的原因有很多。【库存 > 管理库存】菜单下的“禁止显示”选项卡通常会显示每个 ASIN 被禁止显示的原因。有关可能的原因以及如何修复被禁止显示的商品信息的更多信息，请阅读[在搜索结果中禁止显示的商品和非在售商品](https://sellercentral.amazon.com/gp/help/external/200898440)。
