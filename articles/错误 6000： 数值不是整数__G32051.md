# 错误 6000： 数值不是整数

数值必须为非负整数（例如 0、5 或 20）。

如果您提供的整数小于零，则会发生此错误。

要更正此错误，您应该：

- 修改文件，使用大于或等于零且不包括小数或分数的数字。

- 保存所做的更改。

- 重新提交此文件。
