# 错误 6000： 列缺失

该文件缺少所需的列。请添加缺少的信息，并再次上传您的文件。

当您的文件缺少了必需的列时，就会出现此错误。常见原因可能如下：
- 从原始模板中删除了某个列。
- 创建文件时未能从数据库中导出所需的列。
- 修改了列的名称。

要解决该错误，您应该：
1. 参考文件中的数据定义。这些定义在 Excel 格式的文件模板中。
2. 记录文件中需要的所有列。
3. 添加缺少的必需列。
4. 按照数据定义中的描述，使用要求的数据填写这些列。
5. 保存所做的更改。
6. 重新提交文件。
