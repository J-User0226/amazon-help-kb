# 事件通知 Web 服务

【亚马逊事件通知网络服务】 (ENS) 允许您启用第三方软件应用程序，以可靠且安全的方式从您的账户中检索事件信息。

借助 ENS，您的软件应用程序可以检索您账户中与事件有关的通知。现在可通过该服务获得订单通知，声明和付款等其他类型的账户事件通知将于后期提供。
