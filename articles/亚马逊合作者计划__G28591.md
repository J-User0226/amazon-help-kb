# 亚马逊合作者计划

自 1996 年起，亚马逊“合作者”计划是第一个此类型的在线合作者计划。现在，它是最大并且最成功的在线合作者计划，在全球拥有 90 多万名合作者。如果您是网站所有人、亚马逊卖家或网络开放商，现在则可以通过我们的合作者计划开始赚取高达
10% 的销售佣金。





| “合作者”计划如何运行 |
| --- |
| “合作者”通过特殊格式的链接将网络流量送入 Amazon.com，使我们能够追踪销售和其他活动。 对于 Amazon.com 通过这些链接获得的所有符合条件的收益，“合作者”赚取高达 10% 的销售佣金。 我们每季度会将款项发送给“合作者”。 您加入该计划后，我们将授予您访问“合作者”平台的权限，我们的外联网为“合作者”专用。在此您将建立链接，查看流量和收益报告，阅读最新消息和该计划提供给您的机会。 |













| 参与十分简单并且免费 |
| --- |
| 完成 在线申请。 使用“合作者”平台中的“创建链接”工具创建链接，并将链接发布至 Amazon.com。 开始在线追踪您的流量和收益报告。报告每日更新。 |
