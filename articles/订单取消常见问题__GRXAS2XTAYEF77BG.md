# 订单取消常见问题

## 如果买家想要取消订单，我该怎么做？正式取消流程是什么？
要了解有关买家取消订单以及正式的订单取消流程的更多信息，请参阅[订单取消](https://sellercentral.amazon.com/gp/help/external/G201722390)。

## 如何编辑我的买家自动取消时限？
您可以点击[此处](https://sellercentral.amazon.com/fbm/buyerRequestCancellation)，编辑买家自动取消时限。您也可以从[一般配送设置](https://sellercentral.amazon.com/sbr/ref=xx_shipset_dnav_xx#settings)页面访问此设置。

## 在哪里可以找到买家通过正式流程请求取消的订单？
您可以通过以下方式查看买家通过正式流程请求取消的订单：

- 电子邮件通知
- 亚马逊卖家应用通知
- 卖家平台主页上的“买家取消请求”标记
- 卖家平台上的“管理订单”页面：
  1. 在【未发货】选项卡中，点击【显示筛选条件】，打开筛选窗格。
  2. 在【等待操作】部分，点击【买家请求取消】复选框，筛选买家请求取消订单的订单。

- 订单详情页面横幅
- 订单报告
- 订单 API 响应（销售伙伴 API）

## 要查看由买家请求取消的订单，是否需要下载订单报告？
不需要。如果您不使用订单报告，您将通过亚马逊卖家应用通知、电子邮件、卖家平台主页上的标记、卖家平台上的“管理订单”页面以及 API 收到有关买家发起的订单取消请求的通知。下载订单报告的优势在于，您能够在一份报告中查看所有由买家请求取消的订单。您需要切换相应选项才能启用【买家请求取消】字段。

## 哪种类型的取消会对取消率产生负面影响？
要详细了解取消订单的影响，请查阅[订单取消](https://sellercentral.amazon.com/gp/help/external/G201722390)页面的“哪种类型的取消会对您的取消率指标产生负面影响？”部分。

## 如何联系买家？
您可以通过[买家与卖家消息服务](https://sellercentral.amazon.com/gp/help/external/G200389080)联系买家。

## 如果我误取消了订单，该怎么做？
如果您误取消了订单，您的取消率将会受到影响。取消订单后，您将无法再看到买家信息。但是，如果买家与您取得联系并表示仍想要该商品，请让其重新下单。

## 如果订单状态显示为“等待中”，我可以取消该订单吗？
在亚马逊验证买家提供的付款方式时，订单将显示为**等待中**状态。等待中的订单不显示买家的配送地址或联系信息。即使买家直接与您联系，也不应配送这些等待中的订单。如果买家在其订单处于**等待中**状态时与您联系，请让买家联系[亚马逊客户服务](https://sellercentral.amazon.com/cu/contact-us)。

付款方式通过验证后，您便可以使用【管理订单】中，【确认发货】和【取消订单】按钮。此外，订单还将同时出现在“订单报告”和“未发货订单报告”中。此时应该配送订单（必要时也可取消）。

有关更多信息，请参阅[等待中订单](https://sellercentral.amazon.com/gp/help/external/40571)。

## 订单在被取消之前可能会在“等待中”状态停留多长时间？
在某些情况下，付款和订单详情验证流程可能会延长订单的处理时间，最多可达 21 天。

## 订单已取消，但我和买家都没有进行取消此订单的操作。订单是谁取消的？
如果自预计发货有效日期起已过去 7 天，而您尚未发货并确认发货，亚马逊将自动取消订单。

在您确认发货之前，我们不会向买家收费。

## 如何部分取消订单？
目前不支持取消部分订单。但是，您可以使用**订单退款**工具或[订单调整上传数据](https://sellercentral.amazon.com/gp/help/external/G1611)。

有关更多信息，请参阅[取消一件商品、一个订单或多个订单](https://sellercentral.amazon.com/gp/help/external/200198080)。

**注意： **要开始退款，必须确认订单已发货。

## 如果买家联系我要求更新订单中的地址，该怎么办？
如果您尚未配送此订单，而买家表示其无法通过最初提供的地址接收此订单，请让买家取消此订单。然后买家可返回亚马逊商城，使用正确的地址重新下单。根据亚马逊的政策，卖家只能向其卖家账户中显示的买家地址发货。如果买家没有回应，您可以发送[重要消息](https://sellercentral.amazon.com/gp/help/external/GRZ5Y5YEN9J84NAC)。如果您未收到买家的回复，请继续将订单配送至与此订单关联的地址，以免影响您的账户状况。

## 如果我因地址无法送达而无法配送订单，我该怎么做？
如果您尚未配送此订单，可以通过[买家与卖家消息服务](https://sellercentral.amazon.com/gp/help/external/G200389080)联系买家，让其取消此订单并使用正确的地址重新下单。如果买家没有回应，您可以发送[重要消息](https://sellercentral.amazon.com/gp/help/external/GRZ5Y5YEN9J84NAC)。

如果订单已发货，您可以联系承运人并要求其退回商品。在商品退回后，您可以扣除重新入库费，然后向买家退款。

## 如果我需要更多详细信息来配送此订单，但买家没有回应，我该怎么做？
如果您已配送相关订单，您可以联系相关承运人，让其退回商品，原因是买家没有回复。收到商品后，您可以从订单中扣除重新入库费，然后向买家退款。

## 如果我无法继续配送订单，该采取哪些后续步骤？
如果您因某些情况而无法配送订单，请勿联系买家取消这些订单。请参考以下示例场景：
- 库存不足或无库存
- 忘记启用“假期设置”，并在假日期间收到订单
- 定价错误
- 商品信息错误
- 可能遇到技术问题

请从下拉菜单中选择适当的原因并取消相关订单。取消这些订单将影响您的取消率。
