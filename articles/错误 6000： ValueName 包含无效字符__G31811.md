# 错误 6000： ValueName 包含无效字符

字段 *FieldName* 中的值 *ValueName*： xsd:normalizedString 包含无效字符...

如果您提供的值包含无效字符，则会发生此错误。出现该错误的常见原因包括：

- 从 Microsoft Word 中粘贴商品描述或要点数据。
- 输入了类型 1 高位 ASCII 字符，例如版权或商标符号。

要更正此错误，请删除所有无效字符，然后重新提交此数据。先将数据粘贴到记事本 (Windows) 或 TextEdit (MacOS) 等文本编辑器中，可能会有帮助。这样通常可去除任何不规范字符。
