# 比较并选择商品发布方法

亚马逊提供了两种发布商品的方法： 添加新商品和库存文件模板。

| | 添加新商品 | 库存文件模板 |
| --- | --- | --- |
| 库存文件模板是什么？ | 一种交互式发布工具，可指导您完成添加和维护库存的过程。 | 由制表符分隔的文本文件，包含发布商品所需的必要信息 |
| 优势 | 适合一次添加一件商品且发布少于 100 件商品 面向所有卖家提供 适合在“要求和限制”规定的商品分类中发布商品。 | 适合一次添加多件商品以及发布多于 100 件的商品 面向参加专业销售计划的卖家提供 可在 Excel 中轻松编辑 可用于发布和添加商品 针对每个商品分类的自定义模板 |
| 了解更多信息 | 请参阅 添加新商品工具 一次添加一件商品 如何发布您的第一件商品 | 请参阅 使用库存文件添加商品 上传您的库存文件 库存文件上传常见问题解答 错误代码说明 使用商品分类工具为商品分类 |

**注意： **如果您已发布商品，但对其在亚马逊目录中的显示方式存在疑虑，请参阅[更改商品分类](https://sellercentral.amazon.com/gp/help/external/G201950630)了解更多信息。
