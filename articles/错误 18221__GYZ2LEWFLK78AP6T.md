# 错误 18221

## 错误消息
不符合《电气和电子设备法案》的要求。

## 导致错误 18221 的原因
出现此错误的原因如下：
- 您试图在实施《电气和电子设备法案》的商城中发布电气或电子设备，但没有提供所需的合规性文件或注册信息。
- 您的商品信息中未包含商城电气设备法规要求的合规性属性或认证。
- 您的卖家账户未向您发布商品的商城的所需电气设备合规机构注册。
- 您试图为受管制分类的电气或电子设备提交商品数据，但您提交的信息中未包含所需的监管信息。
- 您尝试在遵守环境法规的商城中发布电气设备，但您的商品尚未完成必要的合规性验证。

## 解决错误 18221
要解决此错误，请按照以下步骤操作：
1. 确定您所在商城的具体合规性要求： 访问卖家平台帮助中心并搜索“电气和电子设备”或“电气和电子设备废料合规性”。 查看详细要求，包括注册义务、文件需求和商品分类定义。
2. 向相应的合规机构注册： 加入您所在商城的生产者责任组织或环境合规注册机构。
3. 为您的商品信息添加所需的合规属性： 前往【库存】，然后选择【管理所有库存】。点击受影响商品上的【编辑】，然后找到合规性或监管信息字段。
4. 重新提交您的商品信息并验证激活： 系统需要 24~48 小时来验证您的合规性文件和注册信息。检查您的库存控制面板，确认商品信息状态更改。
