# 错误 99019

## 错误消息

${attribute_name1} 或 ${attribute_name2} 字段需提供有效值。

## 导致错误 99019 的原因

导致此错误的原因如下：

- 必填属性字段留空或包含无效值。

- 系统要求至少填写两个特定属性中的一个，但两者都留空。

## 解决错误 99019

要解决此错误，请按照以下步骤操作：

- 查看上传数据处理汇总报告，检查哪些字段被标记为相互关联的字段（${attribute_name1} 或 ${attribute_name2}），然后在至少一个字段中提供有效值。

- 确保输入的值遵循正确格式和特定属性要求。
