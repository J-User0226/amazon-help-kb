# DHL 墨西哥条款和条件及配送说明

- [DHL 墨西哥： 条款和条件](http://www.dhl.com.mx/es/express/envios/sugerencias_de_envio/terms_conditions.htmlShipmentTermsAndConditions.html)

从 DHL 墨西哥购买货件标签，即表示您同意 DHL 墨西哥条款和条件。如有任何问题和索赔，请务必按照本条款和条件中的规定联系 DHL 墨西哥。

- [DHL 墨西哥： 查找 DHL 投件地点](http://www.dhl.com.mx/es/express/envios/encuentre_locales_dhl.html)

如果您购买了投放货件标签，则您需要将您的包裹投放在 DHL 门店。

- [DHL 墨西哥： 请求取件](http://www.dhl.com.mx/es/express/envios/solicite_una_recoleccion.html)

仅当您购买了包含取件的货件标签时，才能联系 DHL 请求包裹取件。

要安排取件，请拨打 DHL 热线 01-800-SOLO-DHL (7656-345) 或 55-5345-7040。我们建议您在购买标签后等待 15-20 分钟再致电 DHL。

如果您经常发货，您可能符合通过您的 DHL 代表设置每日或每周预定取件的要求。

- [DHL 墨西哥： 包装说明](http://www.dhl.com.mx/es/express/envios/sugerencias_de_envio/packaging_advice.html)

请务必妥善包装您的货件，以确保正确配送。

- [DHL 墨西哥： 危险品配送](http://www.dhl.com.mx/es/express/envios/sugerencias_de_envio/mercancias_peligrosas.html)

请务必遵守承运人有关危险品货件的规定。
