# 卖家自配送订单的预付费退货

我们将通过“购买配送服务”代表您为买家提供预付费退货货件标签。根据[我们的退货政策](https://www.amazon.com/gp/help/customer/display.html/?nodeId=15015721)，美国卖家会自动加入预付费退货计划。下表介绍了该计划所涉商品需遵循的指南。

| 预付费退货详情 | |
| --- | --- |
| 事项 | 政策或要求 |
| 账户要求 | 请确保及时更新您的账户信息。 设置默认退货地址。您需要为预付费退货标签计划提供一个美国国内地址。我们将对所有预付费退货使用此地址。要了解更多信息，请参阅退货地址设置。 注意： 您必须提供有效的退货配送地址。如果因为您提供的退货地址失效或不正确而导致退货无法送达，则相应退货商品将被视为您已丢弃，我们可能会酌情将其弃置并扣留相应收益。继续使用失效或不正确的地址可能会导致您无法继续在亚马逊商城销售商品。要了解更多信息，请参阅退货、退款、取消和索赔页面。 为您销售的商品提供准确的重量和尺寸信息并及时更新。我们会根据此信息计算退货运输成本。当买家发回商品后，我们将从您的卖家账户扣除退货运费。有关更多信息，请参阅卖家自配送退货的运费。 注意： 如果您选择免费退货或您销售的是时尚商品，便无法在买家符合免费退货政策要求的情况下扣留退货运输成本。要了解更多信息，请参阅卖家自配送订单免费退货和卖家自配送时尚类商品退货的免费退货。 |
| 退货流程 | 每当买家申请退货和收到预付费退货货件标签时，您都将收到电子邮件通知。管理卖家自配送退货页面会显示所有退货。有关更多信息，请参阅管理卖家自配送退货。 |
| 多个退货地址 | 您可以设置多个美国退货地址。有关详细信息，请参阅多个退货地址。 |
| 退款不退货解决方案 | 发放退款或提供换货，并让买家保留原商品，这就是退款不退货解决方案。如果买家请求退货且符合退款不退货解决方案的要求，买家提交退货请求后会收到全额退款或选择接收换货商品。您可以在管理卖家自配送退货中找到这些退货请求。退款不退货无需手动处理。要了解更多信息，请参阅不退货解决方案。 |
| 退货运输 | UPS 和 USPS 可通过购买配送服务为卖家自配送订单提供退货运输服务。有关详情，请参阅预付费退货配送服务。 重要： 买家也可以自行安排配送退货商品。仅当买家将包裹交给承运人时，我们才会从您的账户扣除退货标签费用。 |
| 退款和运费 | 要了解有关退款类型的更多信息，请参阅退款选项和退款退货运输成本。 要了解如何计算退货运输成本，请参阅卖家自配送退货的运费。有关时尚类商品退货运输的更多信息，请参阅时尚类商品卖家自配送订单的免费退货。 |
| 预付费退货报告 | 所有预付费退货都记录在“结算和付款”报告以及“退货”报告中。 “结算和付款”报告： 每项退货运费都将在您的“结算和付款”报告中显示为通过亚马逊购买的配送服务。这些费用将与订单费用分开。 退货报告： 每当买家申请退货和收到预付费退货货件标签时，您都将收到电子邮件通知。此外，您的退货报告还会显示您收到的所有退货请求，包括每个退货商品的状态。相关电子邮件和报告均包括订单编号、追踪编码、退货原因、标签费用、请求日期、退货商品授权编码和备注。 |
| 不符合要求的商品 | 并不是所有自动批准的退货都能分配到预付费退货货件标签。有关详细信息，请参阅不符合预付费退货要求的商品。 |
| 分类豁免 | 某些分类和子分类将自动豁免预付费退货标签。以下分类不需要提交豁免请求： Amazon Handmade 经过认证的二手钟表 商品为非实物商品（例如保修、数字软件和数字优惠券） 依法不可退货的商品和危险品 超大件或超重商品 |
| 退款申诉 | 如果我们代表您发放了您认为不应批准的退款，您可以提出申诉。 对于买家退回的已残损商品： 创建索赔时，请提供能够将退货商品与所购商品相关联的照片，例如残损商品的图片和未残损的原商品的图片。其他辅助文件可能还包括货件标签图片、追踪编码或交货证明。 注意： 根据我们的重新入库费政策，对于买家导致残损的商品，赔偿金额最高为商品订单价值的 50%。 有关详情，请参阅卖家自配送订单的赔偿。 |

## 已打印退货标签

买家可以联系亚马逊客户服务，支付少量费用，请亚马逊客户服务邮寄一张实物标签。

## 请向承运人提出索赔。

如果退回的商品在运输过程中丢失或残损，您应直接向承运人提出索赔。

- **UPS**： 要针对已丢失或已残损商品提出索赔，请拨打 1-800-711-5914致电 UPS Preferred Claims，并向代理人提供相关详细信息。请勿通过其他 UPS 电话号码或 UPS 网站提出遗失或残损索赔。

- **USPS**： 请通过 USPS 网站或通过邮件提出残损或丢失索赔。要了解更多信息，请参阅 [USPS 网站](https://www.usps.com/help/claims.htm)。
