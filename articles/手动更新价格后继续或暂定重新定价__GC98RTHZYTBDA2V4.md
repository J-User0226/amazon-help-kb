# 手动更新价格后继续或暂定重新定价

如果您使用上传数据、【管理定价】或【管理库存】在卖家平台的其他位置进行手动价格更新，您可以通过【自动定价】选择继续重新定价或暂停重新定价。

如果您选择继续重新定价，系统会使用您手动输入的价格，然后自动定价会继续根据您设定的规则（基于更新后的价格）重新定价。

如果您选择暂停重新定价，系统会暂停对 SKU 执行自动定价规则，而是使用手动更新的价格。在您对 SKU 恢复重新定价之前，系统不会进行任何自动价格更新。

要在手动更新价格之后自动继续重新定价，请执行以下操作：
1. 依次转至【定价】 > 【自动定价】。
2. 点击【编辑规则参数】。
3. 点击 【3 规则参数】的向下箭头。
4. 对于问题【如果您在卖家平台中的其他位置更新了您的价格，是否要继续重新定价？】，选择【是，我想要继续重新定价】。

如果您要暂停重新定价，请选择【否，我想要暂停重新定价】。规则中的所有 SKU 均将按照此操作进行处理。

要继续逐个重新定价，请执行以下操作：
1. 转至【自动定价】，并搜索已暂停的 SKU。
2. 点击【采取措施】按钮旁边的箭头。
3. 在【分配到规则】下，选择分配给 SKU 的规则。
4. 点击【开始重新定价】，自动开始对 SKU 重新定价。
