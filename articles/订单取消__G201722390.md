# 订单取消

**买家何时可以取消订单？**

在下订单后的 30 分钟内，买家可以在亚马逊商城点击【我的账户】 > 【我的订单】中的【取消商品】按钮，自行取消订单。

30 分钟后，买家无法再直接取消订单，他们只能提交取消请求以供卖家审核。买家请求取消订单时，您将收到一封电子邮件。

如果您更改了[买家自动取消时限](https://sellercentral.amazon.com/fbm/buyerRequestCancellation)，亚马逊将根据您的设置代表您自动取消订单，并且您将收到有关此类取消的电子邮件。

【如果买家想要取消订单，我该怎么做？】

根据订单处理阶段，以下选项可帮助您确定后续步骤：

【对于自配送订单：】

1. 【如果您尚未为此订单发货或确认发货】，可在[管理订单](https://sellercentral.amazon.com/orders-v3/ref=xx_myo_dnav_xx)中取消订单，或使用订单取消上传数据通过上传文件或 API 取消订单。要从“管理订单”取消订单，请按照【不会对您的取消率指标产生不利影响的订单取消正式流程】部分中的步骤进行操作。
2. 【如果您已发货但尚未确认发货】，则必须确认发货，然后通过[买家与卖家消息服务](https://sellercentral.amazon.com/gp/help/external/G200389080)联系买家，并建议他们拒收货件或发起退货。
3. **如果您尚未发货，但已确认发货**，则无法再取消订单。您必须发起退款流程，且不发货。

**注意： **
- 您取消订单后，亚马逊会自动更新买家亚马逊账户中的订单状态，并会向买家发送一封通知电子邮件。
- 有关取消订单的消息属于[重要消息](https://sellercentral.amazon.com/gp/help/external/GRZ5Y5YEN9J84NAC)，即使买家已选择不接收非重要消息，系统也会将其发送给买家。
- 如果您需要取消订单的原因不是买家请求取消订单，您必须自行取消此订单，而不是请求买家取消订单。
- 如果买家通过买家与卖家消息服务以非正式方式请求取消订单，而您据此取消了订单，那么您的取消率指标会受影响。此类消息被标记为【来自亚马逊买家的咨询】。
- 在您确认发货之前，我们不会向买家收费。

**不会对您的取消率指标产生不利影响的订单取消正式流程：**

买家请求取消订单的流程是：在其亚马逊账户中找到他们想要取消的订单 > 点击【我的账户】 > 【我的订单】 > 【请求取消】。

1. 如果买家在下单 30 分钟后请求取消，您将收到一封电子邮件，而且能够在【管理订单】页面的订单信息正上方看到取消请求，显示一条横幅，内容为“买家已请求取消此订单。取消此订单不会影响您的取消率指标。”
2. 在您取消订单之后，买家将收到一封电子邮件，确认订单已取消。

**注意： **如果您将订单的取消原因选择为【买家取消】，而买家并未发起订单取消，那么，取消该订单会对您的取消率指标产生不利影响。

## 要处理买家的订单取消请求，请按照以下步骤操作：

1. 从卖家平台、上的**订单**下拉菜单中，选择[管理订单](https://sellercentral.amazon.com/orders-v3/mfn/unshipped?)。在“未发货”选项卡中，点击“显示筛选条件”打开筛选窗格，然后在“等待操作”部分的下方勾选“买家请求取消”复选框，筛选出买家请求取消的订单。
2. 由买家发起取消的订单将显示一条横幅，内容为“买家已请求取消此订单。取消此订单不会影响您的取消率指标。”
3. 点击**操作**列下的**取消订单**。 **注意： **只有**未发货**订单才有对应的**取消订单**选项。

4. 点击**提交**。
5. 在您取消订单之后，买家将收到一封电子邮件，确认订单已取消。

第 4 步示例： “买家取消”已经被预先选择，因此无法编辑，因为我们知道这是买家请求取消的订单。

**注意： **如果您因无库存或库存不足、忘记打开“假期设置”并收到了订单、定价错误、商品信息错误、配送设置错误或技术问题而无法配送订单，请勿联系买家让其取消此类订单。请从下拉菜单中选择适当的原因并取消订单。取消这些订单将影响您的取消率。

## 将对您的指标产生不利影响的买家发起的非正式取消流程
如果买家未遵循正式取消流程，仅通过买家与卖家消息服务工具请求取消订单，则视为买家采取了不正确的方法来取消订单。 此类消息被标记为“来自亚马逊买家的咨询”。 因此，如果买家通过买家与卖家消息服务工具提出取消订单请求，而您应买家的请求取消了订单，那么这一取消将影响您的取消率指标。

为避免取消订单影响您的取消率指标，您可以回复买家的消息并请买家按照上述正式流程提交订单取消请求。

请在回复中使用以下说明： “您可以通过您的亚马逊账户中的**我的账户** > **我的订单** > **请求取消**来取消该订单。”

要查看您的取消率和政策要求，请参阅[取消率](https://sellercentral.amazon.com/gp/help/external/G200285210)。

## 部分取消
目前不支持部分取消订单。但是，您可以使用【订单退款】工具或[订单调整上传数据](https://sellercentral.amazon.com/gp/help/external/1611)，为订单中的每件商品发放全额和部分退款。

**注意： **要开始退款，此订单必须已确认发货。

有关更多信息，请参阅[取消一个或多个订单](https://sellercentral.amazon.com/gp/help/external/G200198080)。

## 自动取消
如果自预计发货有效日期起已过去 7 天，而您尚未发货和确认发货，亚马逊将自动取消订单。

## 用于买家发起订单取消的 API
## 销售伙伴 - API
与订单 API 类似，对于销售伙伴 API，当买家发起订单取消请求时：

1. 如果买家请求取消订单，则 **ordersV0GettOrderItemsList** 操作将在响应中为每个 OrderItem 添加一个 **isBuyerRequestedCancel** 标记和 **buyerCancelReason** 字符串。
2. 如果买家请求取消订单，则 **isBuyerRequestedCancel** 标记将设置为“True”。
3. **buyerCancelReason** 字段将显示买家指定的取消原因。

**销售伙伴 - 通知 API**

ORDER_CHANGE 通知 API 是 ORDER_STATUS_CHANGE 通知 API 的升级版本。卖家可以订阅，以便在出现重大变化（如订单状态更改和买家请求取消）时，可以主动收到通知。在卖家订阅后，如果买家发起订单取消请求：

1. 系统将会自动向卖家发送 ORDER_CHANGE 通知。
2. 如果买家请求取消订单，则 【isBuyerRequestedCancel】 标记将设置为“True”。

查看[销售伙伴用户指南](https://developer-docs.amazon.com/sp-api/docs/notifications-api-v1-use-case-guide#order_status_change)，了解如何订阅 ORDER_CHANGE 通知。
