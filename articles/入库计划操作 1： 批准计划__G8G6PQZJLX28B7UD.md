# 入库计划操作 1： 批准计划

## 使用时机

要返回上一主题，请参阅 [FBA Select 合作计划概览](https://sellercentral.amazon.com/gp/help/external/GAGYPRTP62VW2APL)。

当您查看了亚马逊提出的配送计划并准备按照建议继续创建货件时，请使用此操作。除非您的 ASIN 具有具体的商品信息要求（如有效期/保质期），否则您无需输入其他信息。

提交后，系统会为您创建货件，接着您将转至第 3 步 (Send to Amazon)，您需在此步中打印货件标签、预约承运人并安排接收预约货件。

## 运作方式

在新卖家平台中查看计划后，选择以下任一选项，然后点击“提交”：

- **选项 1 - 批准计划：** 如果计划适合您，选择此选项后，亚马逊将直接为您创建货件。无需提供其他信息。

- **选项 2 - 批准计划并添加其他货件创建详情：** 此选项仅在您的 ASIN 需要其他详细信息（如有效期/保质期）时可用。适用情况下将显示此选项，而非标准的“批准计划”选项。在入库计划 Excel 文件中，请在“货件详情”选项卡中高亮显示的单元格中填写所需信息。保存文件，在文件上传区域上传文件，然后点击提交。

## 接下来会怎么样？

提交批准后，亚马逊会在您的卖家平台账户中创建货件。货件准备就绪后，您将直接在卖家平台用户界面中收到通知。货件包含：

- 当前计划时段的货件编号，包括货件一览链接、入库接收日期、配送地址、箱数以及商品数量。

- 任何无法处理的 ASIN 的错误详情，包括工作流程编号、配送地址、ASIN、MSKU 以及错误原因。您可以点击工作流程编号链接直接进入工作流程，在这里，您可以移除受影响的 ASIN 并继续执行第 2 步，或者更正后再继续执行第 2 步。

- 为即将到来的计划时段提供输入链接。

收到货件编号后，请通过标准的“Send to Amazon”工作流程在卖家平台账户完成以下步骤：

- 打印货件标签。

- 选择您的承运人。

- 在指定的亚马逊越库垛口预约接收。

## 常见错误原因

如果某个 ASIN 无法创建货件，则错误通知中将说明原因。常见原因包括：

- 需要提供有效期/保质期但未提供

- ASIN 不再可售、无在售信息的亚马逊库存或尺寸缺失

如果您遇到无法解决的错误，请联系您的客户成功经理。

## 截止日期提醒

所有批准必须在当前计划周期的周六晚上 10 点（世界协调时）之前提交。如果在此截止日期之前未采取任何操作，则系统不会为此周期创建 FBA Select 货件。

## 文件参考指南

## 表 A： 货件编号通知格式

此表展示了您在批准计划后收到的格式。每行对应一个为当前计划时段创建的货件。

| 列 | 字段 | 描述 |
| --- | --- | --- |
| A | MCID | 卖家客户编号 |
| B | 货件编号 | 已创建货件的唯一编号（例如 FBA12346AD） |
| C | 货件一览链接 | 在卖家平台中查看货件详情的链接 |
| D | 工作流程链接 | 与此货件关联的工作流程链接 |
| E | 入库接收开始日期 | 配送时段开始日期（例如 2026/2/15） |
| F | 入库接收结束日期 | 配送时段结束日期（例如 2026/2/21） |
| G | 配送地址 | 接收货件的亚马逊节点（例如 MDW2） |
| H | 纸箱数量 | 此货件内的纸箱总数 |
| I | 商品数量 | 此货件内的商品总数 |

## 表 B： 错误通知格式

此表展示了当一个或多个 ASIN 无法处理时，通知中包含的错误详情格式。每行对应一个失败的 ASIN。

| 列 | 字段 | 描述 |
| --- | --- | --- |
| A | MCID | 卖家客户编号 |
| B | 工作流程编号 | 遇到错误的工作流程编号 |
| C | 工作流程链接 | 卖家平台工作流程链接 |
| D | 入库接收开始日期 | 预计配送时段开始日期 |
| E | 入库接收结束日期 | 预计配送时段结束日期 |
| F | 配送地址 | 接收货件的亚马逊节点 |
| G | ASIN | 失败 ASIN 的商品编码 |
| H | MSKU | 失败 ASIN 的卖家 SKU |
| I | 错误原因 | 无法创建货件的原因（例如，需要提供有效期/保质期） |

**注意： **入库接收开始日期和结束日期表明您的货件何时到达亚马逊接收节点（卡车抵达垛口）。这是用于衡量绩效的配送时间段。接收处理（登记和库存供应情况）是在交付后进行的，如果运营能力不足以及您的货件分多个包裹抵达，则可能需要更多时间。您的准时绩效是根据卡车到达亚马逊节点的时间而不是商品全部登记完毕并可上架销售的时间来衡量的。
