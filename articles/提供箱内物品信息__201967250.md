# 提供箱内物品信息

**注意： **数量差异缺陷不可再申诉 - 这包括纸箱内 ASIN 数量不准确、商品不在采购订单上、商品超量以及纸箱内出现意外 ASIN。您可以提交反馈以分享更多背景信息

**注意： **此缺陷不会产生任何经济后果或处罚

亚马逊要求发送至运营中心的各个货件均提供准确的箱内物品信息。此信息可让运营中心更快收到您的货件，并让您的库存尽早上架销售。如果您不提供箱内物品信息，亚马逊物流 (FBA) 团队将手动处理每个箱子内的物品并评估费用。 有关更多信息，请参阅[亚马逊物流人工处理费](https://sellercentral.amazon.com/gp/help/external/202061550)。

您可以在货件创建流程中通过卖家平台或销售伙伴 API 向亚马逊提供箱内物品信息。

## 货件类型
在货件创建工作流程的【预处理货件】步骤中，从【如何包装此货件？】下选择以下货件类型：

- 【所有商品装于一个箱子】：如果您的货件只有一个箱子，请选择【所有商品装于一个箱子】选项。通常，您需要输入箱子的重量和尺寸。如果箱内的任意商品具有有效期/保质期，也请输入这些信息。点击【确认】。
- 【每箱一个 SKU】： 如果您的货件包含多个箱子，但每个箱子只有一个 SKU，请选择【每箱一个 SKU】（或【多个箱子】，如果您的货件只有一个 SKU，系统将显示此选项）。您可以通过使用 Web 表单、上传文件或使用 2D 条形码提供箱内物品信息。请参阅下面的【如何提供箱内物品信息】。
- 【每箱不止一个 SKU（不超过 15 个包装箱）】： 如果您的货件包含多个箱子且每箱不止一个 SKU，一共不超过 15 个箱子且一共不超过 25 个 SKU，请选择【每箱不止一个 SKU（不超过 15 个包装箱）】选项。您可以通过使用 Web 表单、上传文件或使用 2D 条形码提供箱内物品信息。请参阅下面的【如何提供箱内物品信息】。 **注意： **如果您不确定您的货件是否超过 15 个箱子，请改用【每箱不止一个 SKU（超过 15 个包装箱）】选项。如果尝试使用“不超过 15 个箱子”和“超过 15 个箱子”选项，您将丢失输入的所有箱内物品信息。

- 【每箱不止一个 SKU（超过 15 个包装箱）】： 如果您的货件中每箱不止一个 SKU，且超过 15 个箱子或 25 个 SKU，请选择【每箱不止一个 SKU（超过 15 个包装箱）】选项。对于此类货件，您只能通过上传文件或使用 2D 条形码来提供箱内物品信息。请参阅下面的【如何提供箱内物品信息】。

## 如何提供箱内物品信息
提供箱内物品信息的可用方式取决于您的货件类型（如上一部分所述）。

【使用 Web 表单】（推荐）

选择此选项时，您最初将看到一个箱子配置。箱子配置包含商品数量、有效期/保质期（如果适用）、箱子重量和箱子尺寸。如果您有多个箱子具有相同配置，则只需输入一次箱子信息，然后指定有多少箱子与此配置匹配。

如果有箱子具有不同数量的商品、有效期/保质期、箱子重量或箱子尺寸，请添加其他箱子配置。对于每箱只有一个 SKU 的货件，请点击表单底部的【添加其他箱子配置】，以新建一行。对于每箱有多个 SKU 的货件，您可以根据需要向货件添加其他箱子，然后使用【添加其他箱子尺寸】选项指定不同的箱子尺寸。

如果您不确定货件中箱子的数量，则可以先输入两个箱子的箱内物品信息，然后逐个输入其他箱子的信息，直至完成货件的创建。

**注意： **每个箱子中的每个 SKU 只能有一个有效期/保质期。如果您的一个 SKU 具有多个有效期/保质期，则该货件必须使用不同的箱子分开包装，使每个箱子的每个 SKU 只有一个有效期/保质期。

确认提供的信息正确无误后，请点击【确认】，进入下一步。您也可以点击【保存以供日后使用】（如果您希望稍后返回以完成货件的创建）。

【上传文件（Excel 格式）】
1. 在【文件格式】下，从下拉列表中选择 【Excel (.xlsx) 模板】。
2. 输入货件中箱子的数量。
3. 点击【下载装箱单模板】以下载装箱单。使用 Excel 打开该文件。
4. 对于每个箱子，请输入每种商品的数量、有效期/保质期（如果适用）、箱子重量和箱子尺寸。确保信息正确无误后，保存该文件。
5. 装箱单完成后，您可以在【上传完成的装箱单】部分将其上传。 **注意： **如果使用 Excel 模板，请确保您的上传文件为 .xlsx 格式。文件上传验证可能需要几分钟的时间才能完成。检查以确保您的文件已正确上传。如果出现错误，请参阅处理报告以了解更多信息。

【上传文件（.tsv 格式）】
1. 在【文件格式】下，从下拉列表中选择【制表符分隔 (.tsv) 模板】。
2. 输入货件中箱子的数量。
3. 点击【下载装箱单模板】，并在任意电子表格程序中打开该文件（或将文本复制粘贴到电子表格中）。
4. 在箱子的 【[货件编号] U000001 – 商品数量】列中，输入您装在第一个箱子中的每种商品的数量（对于大包装发货的货件，列标题将显示【箱子数量】。这时，请输入装运箱的数量）。 例如，如果货件编号是 FBA2HCHGWK，1 号箱子附带有 U000001 (FBA2HCHGWK000001)，2 号箱子附带有 U000002 (FBA2HCHGWK000002)，且 3 号箱子附带有 U000003 (FBA2HCHGWK000003)。
5. 对于要求提供有效期/保质期的商品，在 【[货件编号][箱子编号] – 有效期/保质期】列中添加有效期/保质期。如果有效期/保质期不是必填项，您将在字段中看到“不需要”。
6. 将文件保存为制表符分隔格式（.tsv 或 .txt）。
7. 装箱单完成后，您可以在【上传完成的装箱单】部分将其上传。 **注意： **如果使用制表符分隔模板，请确保您上传的文件为 .tsv 或 .txt 格式。请勿修改任何列标题。文件上传验证可能需要几分钟的时间才能完成。检查以确保您的文件已正确上传。如果出现错误，请参阅处理报告以了解更多信息。

【使用 2D 条形码】

如果您使用 2D 条形码来提供箱内物品信息，则无需在卖家平台中输入箱内物品信息。有关更多信息，请参阅[使用 2D 条形码提供箱内物品信息](https://sellercentral.amazon.com/gp/help/external/202049090)。

【使用亚马逊销售伙伴 API (SP-API)】

有关配送入库 API 使用案例指南的信息，请参阅[提供箱内物品信息](https://developer-docs.amazon.com/sp-api/docs/fulfillment-inbound-api-v2024-03-20-use-case-guide#step-3-provide-box-content-information)。

【跳过提供箱内物品】

如果您的运输流程不支持提供箱内物品信息，您可以选择跳过此步骤，让亚马逊手动处理您的货件，但您需要为此支付相应的费用。
