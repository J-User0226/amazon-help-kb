# 阅读在售商品报告

【在售商品报告】是一个制表符分隔的文件，您可以在 Microsoft Access 或 Microsoft Excel 等任何电子表格或数据库程序中打开该文件。随后您可以在电子表格中修改商品数据和文件列，并使用【库存加载工具】或【商品信息加载工具】随时上传。有关更多信息，请参阅[使用报告更新库存](https://sellercentral.amazon.com/gp/help/external/200388940)。

如果您在 Microsoft Excel 中打开报告，Excel 会去除【商品编码】列中的 ISBN 的前导零。要避免这种情况，可以使用导入向导，以文本格式强制导入 【product-id】 列。有关此功能的更多信息，请参阅 Microsoft Excel 帮助。

下面是报告中显示的字段列表，以及这些字段的定义和示例。未使用的字段用于实现向后兼容性，让原本整合了使用这些字段的业务的卖家能够继续使用当前的软件程序。如果您不需要这些字段，可以从下载报告中删除这些列。
