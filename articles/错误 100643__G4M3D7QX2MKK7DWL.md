# 错误 100643

## 错误消息
亚马逊 Haul 中仅可销售品牌为“无品牌”的商品。请更正您的商品信息。

## 导致错误 100643 的原因
出现此错误的原因如下：
- 提交至亚马逊 Haul 的商品详情在品牌属性字段中包含“无品牌”以外的品牌名称。
- 商品信息包含与所需的“无品牌”值不完全匹配的品牌信息，包括大小写、空格或其他字符的变体。
- 多件商品通过库存文件或 API 集成上传，其中一件或多件商品包含不是“无品牌”的品牌值（例如，卖家上传的电子表格包含不同 SKU 的混合品牌值，并且某些条目包含制造商名称或商标品牌）。

## 解决错误 100643
要解决此错误，请按照以下步骤操作：
1. 查看上传数据处理汇总报告以了解突出显示的错误，并导航至上传数据模板中的品牌属性字段，然后将 brand_name 更新为“无品牌”
2. 您也可以导航至库存，然后选择管理所有库存，找到受影响的商品信息，点击编辑”，并使用正确的大小写将品牌字段更改为无品牌，然后保存更改并等待系统处理更新。
