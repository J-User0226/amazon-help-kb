# 错误 90178

## 错误消息
“${attribute_name}”的值未采用有效的限制属性格式。原因：“${reason}”。

## 导致错误 90178 的原因
出现此错误的原因如下：
- 您提交商品数据时，属性值不符合亚马逊目录系统中为该特定属性定义的所需限制格式。例如，您输入的日期格式为 MM/DD/YYYY，但系统要求日期为 YYY-MM-DD 格式。
- 您要更新的属性包含格式错误、无效字符或违反属性验证规则的数据结构。
- 您提交的商品信息包含与预期数据类型不匹配的属性值、长度限制或枚举值限制。例如，您输入的文本字符串超出了某个属性的最大字符限制，或者您提交的值不在允许的枚举列表中。
- 您使用批量上传上传数据或 API 集成来生成与亚马逊目录验证规则不兼容的属性值。
- 您提交的特定属性具有复杂的格式要求，例如结构化数据模式、特定分隔符或多部分值，而您提交的内容不符合要求的结构。

## 解决错误 90178
要解决此错误，请按照以下步骤操作：
- 确定出错的属性和原因：查看错误消息以确定是哪个 ${attribute_name} 导致了问题，以及系统提供的格式被拒原因 ${reason}。请参阅卖家平台中的商品类型定义或上传数据模板文档，了解该特定属性的正确格式要求。
- 更正属性值以匹配要求的格式：通过【库存】然后选择【管理所有库存】中编辑您的商品信息。点击受影响 SKU 上的【编辑】，找到错误中提到的属性字段，然后根据规定重新设置值的格式。
- 在重新提交之前验证更正后的数据：仔细检查重新设置格式后的属性值是否与要求的格式（包括字符大小写、空格、分隔符和数据结构）完全匹配。如果您使用批量上传，请在提交大批量之前，先用少量商品样品测试您的上传数据，以验证格式合规性。
- 通过保存更改或重新上传更正后的库存文件，重新提交您的商品信息并监控处理情况。等待系统处理您提交的内容并验证属性格式，然后检查您的处理报告或库存控制面板，以确认错误已解决。
