# 错误 90217

## 错误消息

“${attribute_name}”的值包含在 URL 中无效的图片格式。支持的图片格式为“${supported_formats}”。

## 导致错误 90217 的原因

出现此错误的原因如下：

- 若您提交的商品图片 URL 未使用支持的文件格式，而是使用了不受支持的文件格式（如使用 .bmp、.tiff、.svg 或 .webp），就会出现此错误。

- 系统检测到图片 URL 的后缀文件扩展名与亚马逊支持的图片格式不匹配。

- 若图片文件的实际格式与 URL 中的文件扩展名不匹配，或者图片文件损坏且亚马逊验证系统无法正确识别，就会出现此错误。例如，如果您将 .png 文件重命名为 .jpg，但保留其原始格式结构。

- 若提供的 URL 实际上不包含有效的图片文件，也不指向网页、文件或其他非图片内容，就会出现此错误。

## 解决错误 90217

要解决此错误，请按照以下步骤操作：

- 查看上传数据处理汇总报告，并查看亚马逊的图片要求，确认接受的格式（通常包括 .jpg、.jpeg、.png 以及 .gif）。

- 使用图片编辑软件或在线转换工具将您的图片转换为任一受支持的格式。确保转换后的图片仍符合质量标准，最长边不应低于 1000 像素才能实现最佳的缩放功能。

- 修改您的商品信息，将更正后的图片 URL（该 URL 具有与实际图片格式相匹配的正确文件扩展名）加入其中。

- 在将所有图片 URL 修正为支持的格式后，重新提交您的商品信息。
