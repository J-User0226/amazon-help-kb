# 货位检查请求常见问题

## 何时提交货位检查请求
如果您使用亚马逊物流，且认为自己因亚马逊物流团队在处理商品时出错而收到违反政策通知，您可以提出货位检查以对违规行为提出异议。

有关更多信息，请参阅[开始使用亚马逊物流](https://sellercentral.amazon.com/gp/help/external/G53921)

## 如何提交货位检查请求
请按照以下步骤提交货位检查请求。
1. 登录您的卖家平台账户。
2. 前往[获取帮助](https://sellercentral.amazon.com/help/center)页面
3. 在【选择要解决的问题】下，选择【我的问题未列出】。
4. 在【描述问题以便转至正确的支持团队】文本框中输入详细信息，然后点击【继续】。 **注意： **您可以从[政策违规申诉](https://sellercentral.amazon.com/performance/dashboard)页面或[绩效通知](https://sellercentral.amazon.com/performance/notifications)获取相关 ASIN 和 SKU 详情

5. 系统将要求您选择一种【联系方式】： “电子邮件”“在线聊天”或“电话”，以提交请求。选择适合您的选项，然后提供所需详细信息。
6. 提交所需信息后，您将收到一封包含相关问题单编号和详情的电子邮件通知。您也可以在“获取帮助”页面选择“前往问题日志”选项，查看此信息。

**注意： **只有当您认为自己错误地收到违反政策通知，并且想要就此提出申诉时，才可将就同一问题的已解决的问题单编号作为证据提交。您可以从[商品政策合规性](https://sellercentral.amazon.com/performance/account/health/product-policies)处提出申诉
