# 错误 6039

## 错误消息
您需要获得批准，才能在此受限子分类中销售商品。审批流程可能包括与商品相关的文件请求和绩效检查。

## 导致错误 6039 的原因
出现此错误的原因如下：

- 您试图在亚马逊指定为受限的子分类下创建商品信息，卖家需要获得明确的批准，才能在该分类下发布商品。
- 对于您尝试发布商品的特定子分类，您的卖家账户没有必要的分类批准或销售权限，即使您获得了更广泛的父分类批准。
- 您通过“添加商品”工作流程、批量上传数据或 API 集成提交商品信息，其中包括属于受限子分类的商品类型或分类节点分配，这会导致亚马逊的自动限制销售系统屏蔽商品，直到您完成批准流程。
- 您正在发布的商品包含亚马逊目录系统根据商品编码、品牌名称或商品描述确定属于受限子分类的属性、关键词或分类（例如，当您的商品名称或描述包含“处方”、“仅限专业用途”、“经 FDA 批准”等词语或其他自动标记商品以进行受限子分类审核的管制术语时，或者当您提供的 UPC 或 EAN 与属于需要卖家批准的受限分类的商品相关联时）。
- 您正在尝试在最近添加到亚马逊受限分类的子分类中发布商品。

## 解决错误 6039
要解决此错误，请按照以下步骤操作：

1. 导航至分类批准请求页面并请求批准（如果符合要求）
2. **方法 1： 对于新的商品信息**

  1. 前往**目录**，选择**添加商品**。
  2. 搜索您想要销售的商品。
  3. 选择所需的商品状况。
  4. 点击**申请销售**，然后点击**请求批准**开始申请流程。

3. **方法 2： 对于现有商品信息**

  1. 前往**库存**，然后选择**管理所有库存**。
  2. 对于需要进一步操作的非在售商品，选择**解决商品信息问题**。文件要求可能因您的商品分类和商城位置而异。
  3. 点击**请求批准**开始申请流程。

4. 请阅读详细要求页面，了解您需要提供哪些文件、证书、绩效标准或业务信息，以查看针对您的受限子分类的具体批准要求。

**注意：**即使卖家已提交全部所需文件，某些商品仍存在销售限制。这些限制由系统自动执行，销售伙伴支持团队无法对其进行修改。虽然商品限制可能会定期更新，但我们的支持团队无法提供更多详情，也无法调整这些限制。
