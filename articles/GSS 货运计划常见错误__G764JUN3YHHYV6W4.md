# GSS 货运计划常见错误

在卖家平台填写预约信息时，请确保：

- 需要填写数字的字段不能包含字母或符号

- 所有数字都必须为正数

- 包装箱数量不能超过货件中的商品数量

要在标准化货件创建流程中确定您货件中的商品数量，请导航至页面顶部并查看【货件内容】标题。您将看到与您的货件关联的 MSKU 和商品的数量。

**对于海运整箱装载 (FCL) 货件：**

确认包装箱数量未超过货件中的商品数量。容器尺寸和货物重量不得超过以下所示的最大限制。

| 容器类型 | 最大体积（立方米） | 典型最大货物重量（千克） |
| --- | --- | --- |
| 20 英尺 | 28 | 17,025 |
| 40 英尺 | 55 | 19,958 |
| 40 英尺高 | 68 | 19,958 |
| 拼箱货件 | 40 | 12,500 |

**对于空运货件：**

确认包装箱尺寸和货件重量未超过以下所示的最大限制。

| 类型 | 最大值 |
| --- | --- |
| 包装箱长度 | 316 厘米 |
| 包装箱宽度 | 242 厘米 |
| 包装箱高度 | 180 厘米 |
| 货件重量 | 140 公吨 |
