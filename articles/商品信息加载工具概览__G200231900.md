# 商品信息加载工具概览

商品信息加载工具是一个模板，用于在亚马逊商城为亚马逊目录中已经存在的商品上传库存。它让您可以只提供商品信息属性，无需提供商品属性，而这些商品属性在使用商品上传数据时是必填的。

对于亚马逊目录中没有的商品，您需要先将这些商品添加到目录中，然后才能使用商品信息加载工具。要了解如何向目录中添加商品，请参阅[商品详情页面和商品信息](https://sellercentral.amazon.com/gp/help/external/G51)下的【将商品添加到亚马逊目录】。要创建新的商品详情页面或者更新现有商品详情页面（商品名称、描述等信息），您需要继续使用[库存文件模板](https://sellercentral.amazon.com/gp/help/external/G1641)。 **注意： **您必须注册有版本包 1.7、1.9 或 4.1，才能使用商品信息加载工具。请参阅[库存文件模板和分类树指南](https://sellercentral.amazon.com/gp/help/external/G1641)以确认您具有哪个版本包以及您可以使用哪些模板。

## 功能
商品信息加载工具提供了以下功能：
- 使用一个模板，即可匹配您符合销售要求的所有分类中的商品。
- 仅根据标准商品编码进行匹配，减少在亚马逊商城发布商品所需的数据。
- 从 Excel 直接上传，节省您的时间。

**注意： **商品信息加载工具不会为卖家提供用于输入媒介类商品（图书、音乐、影视）配送选项的字段。建议您使用[库存加载工具](https://sellercentral.amazon.com/gp/help/external/G202154120)来发布媒介类商品（图书、音乐、影视）。

## 使用商品信息加载工具
**注意： **如果您没有用于使用商品信息加载工具的商品编码，您可以使用亚马逊标准商品编码 (ASIN)。同样，对于不要求提供 UPC、EAN 或 JAN 等商品编码的分类，您可在模板的“product-id”字段中输入 ASIN，并将“product-id type”设为“ASIN”，以便创建或更新您的商品信息。有关详细说明，请参阅[使用商品信息加载工具](https://sellercentral.amazon.com/gp/help/external/G201584910)。

## 符合要求的分类
您可以使用商品信息加载工具在下列受支持的分类中创建或更新您的商品信息。您可能无法销售某些分类的商品。*
- 服装*
- 汽车用品
- 母婴
- 美妆
- 电视/音响
- 食品
- 个护健康*
- 家居与园艺
- 工业用品
- 厨房用品*
- 其他
- 乐器
- 办公用品
- 户外生活*
- 电脑硬件
- 宠物用品
- 软件
- 运动户外*
- 工具
- 玩具和游戏
- 视频游戏
- 钟表
- 无线配件

**重要： **对于支持变体的分类，请勿将 ASIN 用作商品编码。

**注意： **要与所有商品分类实现基本匹配，可使用商品信息加载工具或库存加载工具。利用商品信息加载工具，卖家可以为具有 sale-start-date 和 is-gift-wrap-available 等可选字段的非媒介类商品（图书、音乐、影视）输入信息。商品信息加载工具不会为卖家提供输入媒介类商品（图书、音乐、影视）配送设置的字段。如果您的库存中包含媒介类商品（图书、音乐、影视），建议您使用库存加载工具。但是，如果某个商品具有多个匹配项，则商品信息加载工具可帮助您更加轻松地解决这一问题。

## 未找到商品
某些分类可能需要获得额外批准才能发布商品，您可以在提交商品信息加载工具后通过“管理库存”和[修复商品](https://sellercentral.amazon.com/fixyourproducts)请求批准。如果您在商品信息加载工具不支持的分类中发布商品，那么结合商品编码（UPC、EAN 或 JAN）使用商品查询时，您会在处理一览中看到错误。您必须使用“库存文件模板”或[添加新商品](https://sellercentral.amazon.com/product-search)等其他工具添加或更新您的商品信息。

此外，亚马逊目录中已经存在的商品也可能会没有关联的商品编码。在这种情况下，商品查询会将您的商品列入“未找到商品”表中。要为此类商品创建商品信息，您必须使用关联的 ASIN 作为 product-id，并将 product-id-type 设为“ASIN”。

但是，如果商品在亚马逊目录中不存在，则必须先创建该商品。

## 商品照片
在启用了“商品照片”的分类中，您可以使用商品信息加载工具为现有商品批量添加商品照片。使用商品信息加载工具上传商品照片时，只需在 【Offer XX】 字段中提供 SKU 和照片的 URL。所有其他字段均无需填写。
