# 图书、音乐、影视和 DVD 的文件格式

**Individual sellers：** 此功能适用于采用[专业销售计划](https://sellercentral.amazon.com/gp/help/external/64491)的卖家。

亚马逊会提供特定的文件模板，以便媒介类商品的卖家能够同时上传多件商品。此类模板将试图按照 ISBN（适用于图书）、UPC 或 EAN 将您的商品与亚马逊目录中的 ASIN 匹配。如果这些编码不可用，我们将交叉引用商品名称和其他商品信息以查找匹配项。如果您的某个特定商品没有可用的匹配项，但您提供了充足的商品详情，我们将为该商品创建一个新的详情页面。以下是为媒介类卖家提供的不同文件模板。
- 【图书加载工具】： 上传商品数据以使图书格式与现有图书信息匹配，或创建新的图书信息。
- 【UIEE 图书格式】： 如果图书卖家拥有通用信息交换环境 (UIEE) 格式的数据文件，则可使用此格式替代标准图书加载器文件。
- 【音乐加载工具】： 上传 CD、磁带和黑胶唱片等音乐格式的商品数据。
- 【视频加载工具】： 上传 VHS、DVD、HD DVD 和蓝光等视频格式的商品数据。

## 使用图书、音乐和影视模板
1. 前往[【批量上传商品】](https://sellercentral.amazon.com/product-search/bulk)，然后点击【下载模板】。
2. 【输入商品信息】： 在文件的模板选项卡中，输入想要发布的待售商品的 SKU、商品编码和商品信息数据。您可以逐个手动输入商品详情，也可以使用【导入文件】宏导入现有文件，前提是您已在 Excel 中启用宏。
3. 【验证商品信息】： 检查您输入的信息是否有错误。您可以使用 Excel 宏自动执行此过程。从【加载项】菜单中选择【验证】。该宏可检查数据的完整性，并且会大大减少由于输入错误而造成的上传失败。
4. 【向亚马逊上传商品信息】： 从【加载项】菜单中选择【上传文件】。输入您的销售账户的电子邮箱地址和密码。如果您未启用宏，请将文件另存为制表符分隔的文本 (.txt) 格式，然后前往【库存】菜单中的[上传商品和库存](https://sellercentral.amazon.com/gp/item-manager/ezdpc/uploadInventory.html/)上传文件。

## 上传 UIEE 图书文件
由于亚马逊不会提供宏来供您导入、验证或上传文件，因此您需要自行生成文件。请参阅[使用 UIEE 格式发布图书](https://sellercentral.amazon.com/gp/help/external/G200247530)。
