# 错误 6000： ValueName 格式不正确

字段 *FieldName* 中的值 *ValueName* 格式不正确。

如果您提供的图片 URL 的格式不符合该字段数据定义中的要求，则会发生此错误。出现该错误的常见原因包括：

- 图片 URL 未以 **http://** 开头。

- 列出的图片 URL 以 **https://**（表示安全服务器）。

- 图片 URL 未以 **.jpg** 或 **.gif** 之类的有效文件扩展名结尾。

要更正此错误，请修改您的图片 URL，使之符合数据定义中的准则，然后重新提交此数据。

如果您使用的是与 Yahoo! 店铺关联的图片，但图片未以 **.jpg** 或 **.gif** 结尾，可以尝试以下操作：

- 在 Windows 系统中使用 Microsoft Internet Explorer 导航至您的图片。

- 右键点击此图片。

- 从上下文菜单中选择“属性”。

- 记下图片的文件类型。通常为 JPEG 或 GIF。

- 如果图片的文件类型为 JPEG，请将 **.jpg** 添加至您的图片 URL。如果图片的文件类型为 GIF，请将 **.gif** 添加至您的图片 URL。

- 重新提交此图片 URL。

如果您无法提供有效的图片 URL，可使用卖家平台中的“管理库存”功能手动上传商品图片。有关更多信息，请参阅[管理我的库存](https://sellercentral.amazon.com/gp/help/external/551)帮助主题。
