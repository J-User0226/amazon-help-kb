# URL 格式无效（错误 15）

我们无法下载图片，因为图片 URL 不是有效格式。图片格式设置正确的 URL 的示例：http://www.domain.com/directory/image-file.jpg。

要更正此错误，请根据此示例提交标准格式的图片 URL：http://www.domain.com/directory/image-file.jpg。**注意**： 使用每个商城适用的域结构，例如 www.domain.com 或 www.domain.ca。

**注意： **

- 不强制要求图片文件采用 .gif 或 .jpg 后缀，但推荐采用这种格式。

- 您可以使用 http，但不可使用 https、ftp 或 file 协议。

- 避免使用空格和非字母数字字符，如 $、?、@、& 等。
