# 渠道配送设置

为您的各个销售渠道设置专属配送规则，包括配送速度要求、承运人首选项和包装选项等。配置完成后，这些规则会在您为该渠道创建多渠道配送 (MCF) 订单时自动应用。

## 如何设置和使用渠道配送设置
**第 1 步： 创建您的渠道设置**
1. 依次前往【新版卖家平台】 > > 【设置】 > > 【供应链设置】 > > 【多渠道配送】。
2. 在【亚马逊供应链服务控制台】中，依次前往【菜单】 > > 【分销与配送】 > > 【多渠道配送】 > > 【管理配送设置】。
3. 在【渠道配送设置】下，点击【添加渠道配送设置】。
4. 选择要配置的销售渠道，然后按照提示完成设置。

**注意： **对于 TikTok Shop 和 Walmart，多渠道配送会根据合规要求提供预配置设置。这些显示为 ［ 已设置。 ］ 您可以点击【编辑】，修改部分设置。修改后的值仅适用于进行更改后创建的订单。

**第 2 步： 将您的渠道设置应用于订单**

设置的应用方式取决于您创建订单的方式：
- **卖家平台或亚马逊供应链控制台**
- 在【多渠道配送创建订单】页面中，从【按渠道设置】下拉菜单中选择您的渠道。对于批量创建订单，请在模板的【销售渠道】字段中输入渠道名称。您也可以使用设置编码（格式： FS01-[13 个字符]，位于您渠道的设置页面上）。

- **已关联的渠道（直接集成）**
- 如果您通过新版卖家平台直接关联了 Walmart、Shopify 或 eBay 等商城，您的渠道设置会自动应用于从该商城接收的订单。创建订单时，请检查【多渠道配送创建订单页面】中所选的【渠道配送设置】。

- **第三方集成商**
- 您的集成商在向多渠道配送提交订单时可能会传递销售渠道名称。系统将根据其传递的渠道名称来应用渠道设置。要验证您的集成商如何识别渠道，请查看【卖家平台】 > > 【管理订单】 > > 【管理订单】 > > 【订单详情】中的【销售渠道】字段。如果未显示销售渠道，请联系您的集成商，确认其是否传递了渠道值。

- **销售伙伴 API (SP-API)**
- 如果您使用销售伙伴 API 创建多渠道配送订单，则传递销售渠道的方式取决于您使用的 API 版本：
  - **版本 2020-07-01：** 在 【featureConstraints】 数组中传递销售渠道，所用格式为“CHANNEL.[渠道名称]”（例如，CHANNEL.TIKTOK、CHANNEL.WALMART）。将 【featureFulfillmentPolicy】 设置为 【Required】。这是附加操作，请勿移除或替换 【featureConstraints】 数组中已有的其他条目（例如 BLANK_BOX 或 BLOCK_AMZL）。请将渠道条目与它们一起添加。
  - **版本 2026-07-04：** 在 [createOrderAPI](https://developer-docs.amazon/sp-api/reference/createorder) 请求的 【channel】 字段中传递销售渠道（例如，"channel": "TIKTOK"、"channel": "SHEIN"）。无需额外配置。

- **注意： **在上述两个版本中，渠道值必须与下面列出的受支持的渠道名称之一完全匹配，全部大写，无特殊字符。

**Shopify 订单**
- 直接关联 Shopify（通过卖家平台）： 为“SHOPIFY”创建的设置会自动应用。
- Shopify 多渠道配送应用程序： 系统将根据应用程序传递的源渠道值来应用设置。例如，如果传递的订单渠道为“TIKTOK”，则系统会应用您的 TikTok 设置。

**可应用设置的受支持渠道列表**

对于外部创建的订单（卖家平台或亚马逊供应链控制台之外），销售渠道值必须与以下名称之一完全匹配，全部大写，无特殊字符：
TIKTOK WALMART TEMU
EBAY SHEIN ETSY
MACYS LOWES NORDSTROM
BESTBUY BLOOMINGDALES NEWEGG
ALIEXPRESS WAYFAIR CHEWY
SHOPIFY

**第 3 步： 按渠道追踪绩效**

使用渠道配送设置后，可在【卖家平台】或【亚马逊供应链服务控制台】 > > 【定制分析】 > > 【精选控制面板】 > > 【多渠道配送】 > > 【销售渠道绩效报告】中查看绩效数据。

该报告提供了：

- 平均发货周转时间 (Click-to-Ship)
- 平均送达周转时间 (Click-to-Delivery)
- 达到速度目标的订单百分比：
  - 标准配送： 2 个工作日发货，3 个工作日送达
  - 加急配送： 1 个工作日发货，2 个工作日送达

**预配置渠道规则**

多渠道配送自动为具有特定配送和承运人要求的商城应用以下设置：
渠道 设置 预配置值 原因
**所有渠道** 无品牌包装 采用无亚马逊品牌标识的包装箱配送。 多渠道配送默认采用无品牌包装来配送多渠道订单。
**TikTok** 发货速度（承运人发货） 1~2 个工作日。对于预计送达时间超过 3 个工作日的标准速度配送，多渠道配送将加速发货（适用于非重型大件商品，配送目的地位于美国本土 48 个州）。 TikTok 要求 90% 以上的订单在 2 个工作日内发货，以避免账户状况相关处罚。
**TikTok** 允许使用 Amazon Logistics 使用 Amazon Logistics 作为承运人。 提供更多配送选项，加快发货和送达速度。
**Walmart** 禁止使用 Amazon Logistics 不使用 Amazon Logistics 作为承运人。 Amazon Logistics 不是此商城认可的承运人。

## 常见问题
#### 账户设置和渠道设置冲突时会发生什么？
渠道级设置优先于账户级设置。例如，如果在账户级别禁止使用 Amazon Logistics，但 TikTok 渠道设置允许使用，则 TikTok 订单将使用 Amazon Logistics。
如果您在创建订单时覆盖某项设置，则订单级别的值将最终优先于渠道设置和账户设置。

优先级顺序（从高到低）：
1. 订单级设置
2. 渠道级设置
3. 账户级设置

#### 能否修改 TikTok 或 Walmart 的预配置设置？
是。点击预配置渠道的“编辑”即可修改设置。但是，由于商城合规要求，某些字段无法更改。任何修改都仅适用于进行更改后创建的订单。现有订单不受影响。

#### 如果集成商未传递渠道名称怎么办？
如果您的订单未传递可识别的渠道名称，则系统会应用您的默认账户配送设置，而非渠道特定设置。请在【管理订单】 > > 【订单详情】中查看【销售渠道】字段进行核实。如果该字段为空，请联系集成商以确保其传递渠道值。

#### 渠道名称需要什么格式？
传递的渠道名称必须全部使用大写字母，且不能包含特殊字符（例如，TIKTOK，而不是“TIK-TOK”或“TTS”）。与支持的渠道列表不完全匹配的值不会触发渠道设置。

#### 如果我手动创建 TikTok 订单，这些订单是否符合 TikTok 促销活动的要求？
不是。手动创建的卖家平台订单不符合 TikTok Shop 折扣的适用要求。要获得此折扣，您的 TikTok Shop 订单必须通过参与活动的独立软件供应商支持的集成合作伙伴提交，并且此合作伙伴在提交订单时会标识 TikTok Shop 渠道。要查看受支持的集成路径，请查看[这篇文章](https://supplychain.amazon.com/learn/tiktok-shop-promotion?utm_medium=direct)。

#### 预配置的设置会随时间变化吗？
是。随着商城政策的变化，亚马逊可能会更新预配置值，或为其他商城添加预配置设置。您会在【渠道配送设置】页面中看到这些更新。

#### Shopify 订单如何适用渠道设置？
这取决于您关联 Shopify 的方式：
- **通过卖家平台直接关联 Shopify：** 您的“SHOPIFY”渠道设置适用于所有订单。如果您使用 Shopify 处理其他销售渠道的订单，并且需要更精细的渠道设置，请使用 [Shopify 多渠道配送应用程序](https://supplychain.amazon.com/integrations/shopify/userguide)。
- **Shopify 多渠道配送应用程序：** 系统将根据应用程序传递的源渠道来应用设置。例如，通过 Shopify 多渠道配送应用程序路由的 TikTok 订单，如果其渠道值为“TIKTOK”，则系统将使用您的 TikTok 设置，而不是您的 Shopify 设置。
- **没有匹配的渠道：** 如果应用程序传递的值与任何受支持的渠道都不匹配，则系统将适用账户配送设置。

#### 对于未配置渠道设置的渠道，我可以追踪其绩效吗？
如果您通过卖家平台或亚马逊供应链控制台的“创建多渠道配送订单”页面或批量创建订单功能创建订单，则对于您已创建并应用渠道配送设置的渠道，您可以在【销售渠道绩效报告】中查看绩效数据。如果您的集成商传递了销售渠道名称，则可以在【销售渠道绩效报告】中追踪这些渠道的绩效数据。
