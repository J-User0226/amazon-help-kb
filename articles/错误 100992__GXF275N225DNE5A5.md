# 错误 100992

如果提供的商品编码（ASIN、UPC、EAN、ISBN 或 JAN）与品牌或商品不匹配，并且您使用的条形码不属于该品牌，则会出现错误 100992。

此时将显示以下错误消息：

*“我们检测到您商品上的条形码 – {barcode} 不正确。如果您未提出申诉，我们将在 {date} 之前移除您的商品。如果您不使用“X00”贴签，您可能会丢失库存。如果您认为此消息有误，请在此处联系销售伙伴支持：https://sellercentral.amazon.com/hz/contact-us。如果您需要新的条形码，请直接从 GS1（非第三方卖家）获取它们。反复使用不正确的条形码创建 ASIN 可能会导致 ASIN 创建权限被取消。”*

要解决此错误，请确保商品编码与该品牌的条形码匹配。有关更多信息，请参阅 [ASIN 创建政策](https://sellercentral.amazon.com/help/hub/reference/G201844590)，并参考上述场景指南。

如果您使用的是正确的 JAN、ISBN、UPC 或 EAN，请联系[销售伙伴支持](https://sellercentral.amazon.com/help/center)，并提供以下信息以验证 GTIN：

- 品牌名称

- 当前 14 位条形码（EAN、UPC 或 GTIN）

- 如果需要使用新的 GTIN 替换当前的 GTIN，请提供新的 GTIN

- 禁止显示的 ASIN

- 禁止显示的 SKU

- 关于此错误的屏幕截图

- 清晰显示可见商品编码（UPC、EAN 或 ISBN）、品牌和商品详情的商品图片

- 禁止显示的 UPC、EAN 或 GTIN **或**需要添加到 ASIN 中的新 UPC、EAN 或 GTIN 的 GS1证书

- 品牌与 UPC、EAN 或 GTIN 所有者之间的授权书或关联关系证明（如果对于新的 GTIN，所有者和品牌是同一家公司，则无需提供此信息）

**向亚马逊提交授权书文件时的重要检查**

| 检查分类 | 可接受 |
| --- | --- |
| 格式检查 | PDF 文件 PDF 扫描图片 Word 文件（仅当您是品牌所有者时，才接受自我声明） 从受保护品牌的权属公司的域发出的电子邮件的屏幕截图 |
| 要素检查 | 信函应由品牌或父品牌使用带有其信笺抬头的纸张（最好附有徽标）出具 在 GS1 上明确标明品牌和 GTIN 所有者 明确提及关联关系 包含出具方的名称和联系信息（也可显示在信函的页脚中或在正文中注明） 具有品牌代表的签名或品牌印章 |

如果您的商品没有商品编码或 GTIN，您可能有资格申请 GTIN 豁免。有关更多信息，请参阅[亚马逊无品牌商品政策](https://sellercentral.amazon.com/help/hub/reference/G84H3T69ZX762NWT)。

**注意： **亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。

## GS1 政策

我们会通过查验 GS1 数据库来验证商品 UPC 的真实性。与 GS1 提供的信息不匹配的 UPC 将被视为无效。

我们建议您直接从 GS1（而非从销售 UPC 许可的第三方）获取您的 UPC，以确保在 GS1 数据库中体现相应的信息。请注意，如果您从 GS1 购买新发布的 GTIN 或 UPC，我们建议您至少等待 72 小时再发布商品。这是为了确保我们能够从 GS1 数据库验证 GTIN。

有关从 GS1 获取 UPC 许可的更多信息，请参阅 [GS1 标准网站](https://www.gs1us.org/)。
