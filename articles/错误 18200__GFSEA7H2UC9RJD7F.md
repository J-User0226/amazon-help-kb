# 错误 18200

收到的错误消息： 我们检测到属性“${attribute_name}”中存在不一致信息。请对比商品的“${unstructured_attribute_name}”，以验证您的值。

如果您未能提供亚马逊处理您的请求所需的全部必要数据，则会出现此错误。

如果您使用文本文件管理商品，请参阅模板中的数据定义，了解必填字段列表。

如果您提交 XML 上传数据来管理商品，请参考相关的 XSD（XML 模式定义）以确定哪些值为必填值。
