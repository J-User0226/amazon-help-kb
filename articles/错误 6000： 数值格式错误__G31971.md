# 错误 6000： 数值格式错误

*数值*格式必须为“true”、“false”、“1”或“0”。

如果为某个二进制字段提供的值无效，则会发生此错误。二进制字段会询问“是/否”问题。例如，字段 IsGiftMessageAvailable 会询问某商品是否有礼品信息。

要在二进制字段中回答“是”，请使用下列值之一：
- 1
- true

要在二进制字段中回答“否”，请使用下列值之一：
- 0
- false

要更正此错误，您应该：
1. 修改此文件，为每个二进制字段输入一个有效值。
2. 保存所做的更改。
3. 重新提交此文件。
