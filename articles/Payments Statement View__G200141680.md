### Excel Security
When you open the Settlement Summary Template in Microsoft Excel, you might encounter a Security Warning indicating that data connections have been disabled. In order to refresh the data, you will need to enable the data connection to the file you just downloaded. To enable the connection, click Options. On the Security Alert – Data Connection dialog box select "Enable this content" and click the "OK" button.

The pivot table is built from the settlement Flat File V2 report. The flat file report displays fee and sale amounts for each order on separate rows. The pivot table enables you to see a summary of all fees and sales for a specific order in one row. Follow these steps to take advantage of the pivot table in the Settlement Summary Template.

### Download the [Settlement Summary Template](https://images-na.ssl-images-amazon.com/images/G/01/rainier/templates/SettlementSummaryTemplate.xls).
1. Click the link above and save the file to your hard drive or open it with Microsoft Excel and save it. You can reuse the same template each time you download a Settlement Report Flat File V2 report or create a new copy each time.

### Download the Settlement Report Flat File V2
1. Go to **Reports** > **Payments** > **Past Settlements** and locate the latest [Settlement Report Flat File V2](javascript:null(0)).
2. Click the Download Flat File V2 button next to the settlement period you selected. If there is no Download button, click the Request Report button and return to the Past Settlements page in a few minutes.
3. Save the file to your hard drive.

### Refresh the Settlement Data tab
1. Open the Settlement Summary Template and go to the second tab, "Settlement Data."
2. Click anywhere within the range of cells that makes up the table
  - [PC Users](#showme): from the Data toolbar select "Refresh"
  - [Mac Users](#showme): from the Data pull-down menu select "Refresh Data"

3. A dialog box will ask you to locate the text file you would like to import. Select the Settlement Report Flat File V2 that you downloaded.
  - [PC Users](#showme): Click "Import."
  - [Mac Users](#showme): Click "Get Data."

The range of cells will populate with the data from the flat file text document.
### Refresh the Summary Report tab
1. Click the "Summary Report" tab
2. Click anywhere within the range of cells that makes up the pivot table
  - [PC Users](#showme): from the Data toolbar select "Refresh"
  - [Mac Users](#showme): from the Data pull-down menu select "Refresh Data"

3. The pivot table will load the data from the Settlement Data tab.
