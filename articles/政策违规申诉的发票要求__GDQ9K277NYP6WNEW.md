# 政策违规申诉的发票要求

观看[回复商品质量和真伪绩效通知](https://sellercentral.amazon.com/learn/courses?ref_=su_course_accordion&moduleId=5df5bcdd-328e-43f7-b400-8178d45dd550&courseId=b1a08bc8-bca0-47a1-8ce0-8e5615ab2f98&modLanguage=English&videoPlayer=youtube)，确定在申诉过程中需要提交发票的政策违规行为。

## 什么是发票？

发票是记录买家与供应商之间最终商品交易的文件。它由供应商直接开具，可显示已接收商品的明细清单以及已完成交易的销售条款。

![](https://m.media-amazon.com/images/G/01/generic/invoiceimg.png)

## 为什么亚马逊需要发票？

在解决很多违反亚马逊政策的行为时，您都必须提交供应商开具的发票的副本。亚马逊之所以要求提供发票，是为了验证卖家是从合法供应商处采购商品的，这样有助于维护商城的信誉。清晰的发票文件有助于避免商品被移除，并为账户状况提供证据，加快申诉解决速度。

## 发票应包含哪些内容？

发票必须包含以下内容：

| 供应商信息 | 供应商的联系信息，包括名称、电话号码、地址和网站。我们不会与零售团队或其他亚马逊卖家共享此信息。 注意： 有关采购供应商的信息，请参阅本页面底部的“如何获取经验证的供应商？” 常见问题。 |
| --- | --- |
| 交易详情 | 清晰显示的开具日期，必须在收到绩效通知前的 365 天内。 商品数量，此数量应足以涵盖绩效通知中列出的每个 ASIN 在过去 365 天内的销售量和有存货库存。 与政策违规相关的每个 ASIN 的销售记录。 注意： 如果您的发票显示多件商品，您可以突出显示与此次申诉相关的商品 |
| 商品信息 | 清晰的商品编码；包括商品名称、型号或通用商品编码（UPC、EAN 或 ISBN）。 对于商品变体，请提供与您的商品信息匹配的具体详情（版本、颜色或款式） 对于捆绑商品，请列出商品信息中包含的所有组成部分 |
| 文件标准 | 发票的格式必须为 PDF (.pdf) 或图片文件（.jpg、.png 或 .gif），且大小不得超过 10MB。 |

发票的其他重要注意事项：

- 发票必须记录已完成且已配送的交易

- 可能还有其他区域性要求（即，州/省税务信息），这些要求将通过我们的电子邮件提供给卖家。

- 您提供的文件必须真实且未经修改。

- 您可以从发票中移除定价信息，但所有其他信息务必清晰可见。

- 我们可能会联系供应商验证您的文件信息，并始终保持供应商信息的保密性。

## 不接受哪些文件？

以下文件**不**接受审核：

- 通过电子邮件或第三方共享发送的供应商发票；发票必须直接通过卖家平台提交。

- 销售报价、形式发票，或者在最终发票或交易完成之前发送的文件。

- 自行开具的发票，或者是供应商似乎与买家是同一企业实体的发票。

- 经过数字篡改的发票，或者可编辑格式（例如 .xlsx (Excel) 或 .docx (Word)）的发票

- 难以辨认、分辨率低、显示的信息不一致或缺少所需详情的发票。

**注意： **如果您的发票不符合我们的要求，或者是我们认定您的发票不真实或不准确，我们可能会拒绝接受。如果我们拒绝了包含发票的申诉，请参阅您的绩效通知，其中将说明我们不接受您提供的发票的原因。

## 如何在申诉中提交发票

要在申诉期间提交发票，请按照[账户状况](https://sellercentral.amazon.com/performance/dashboard)控制面板顶部横幅中的说明操作。

## 常见问题

**如何获取经验证的供应商？**

评估新供应商时，请考虑使用以下验证方法：

- 查看官方业务文件，例如营业执照。

- 验证实体企业身份，例如办公或库房位置。

- 通过业务监管部门评级、公司背景资料、媒体报道、行业声誉和在线形象检查商业信誉。

- 通过政府资源、品牌网站、商业目录和其他可信来源验证网络身份。

**发票是否必须使用英文（是否接受其他语言）？**

不需要，提交的发票不一定要用英文。

**媒介类商品（图书、CD 等）是否需要其他文件？**

媒介类商品与所有其他商品遵循的文件要求相同。
