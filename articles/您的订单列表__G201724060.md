# 您的订单列表

【管理订单】页面会以表格形式显示您的订单列表。您可从此列表访问配送订单所需的详细信息。如果您拥有专业销售账户，还可以下载订单报告。请参阅[订单报告](https://sellercentral.amazon.com/gp/help/external/651)，了解更多信息。

要查看您的订单列表，请点击【订单】，然后点击【管理订单】。要了解更多信息，请参阅[管理订单](https://sellercentral.amazon.com/gp/help/external/28141)。

**注意： **如果您在多个亚马逊北美销售渠道（例如 Amazon.ca、Amazon.com.mx 或 Amazon.com）上销售商品，则您在所有这些商城上的订单均会显示在订单列表中。

下表列出了【管理订单】页面中每一列的定义：

| 字段 | 描述 |
| --- | --- |
| 订单日期 | 提交订单的日期和时间。点击列标题，可按订单日期排序。 |
| 订单详情 | 订单编号： 链接到“订单详情”页面 用于指示下单买家类型的标签，其中会提供多种买家类型（Prime、企业买家等） 如果要将订单配送给企业买家，您必须提供装箱单和订货单编号（如果已提供）。了解更多信息。 商品名称 数量： 订购数量 ASIN SKU 联系买家： 链接到“联系买家”表单 销售渠道 配送方式 账单国家/地区（仅限美国） |
| 配送 | 配送类型： 请参阅设置运费 送达日期： 仅限卖家自配送订单 |
| 状态 | 请在 [日期] 之前确认发货，避免订单被取消： 此日期为避免订单被取消的最晚发货期限 状态： 对于卖家自配送订单（通过“购买配送服务”使用 Fedex、UPS、USPS、云途物流* 配送的订单除外），状态类型包括： 未发货 等待中 已发货 已取消 已申请退款 对于卖家自配送订单（通过“购买配送服务”使用 Fedex、UPS、USPS、云途物流* 配送的订单），状态类型包括： 未发货 等待中 等待取件/等待投件（购买标签时） 已取件/已投件（承运人扫描时） 正在派件（在末程物流配送时） 已配送给买家 买家已拒收 无法配送 退还卖家 运输中丢失 运输中残损 已取消 已申请退款 *承运人名单可能会不断更新 对于亚马逊物流 (FBA) 订单，状态类型包括： 等待中 付款完成 完成 已申请退款 对于多渠道配送订单，状态类型包括： 无法配送 正在规划 正在配送 完成 已申请退款 |
| 操作 | 此列显示您可对自己的订单采取的以下操作： 打印装箱单 确认发货 购买配送服务 取消订单 编辑配送信息 订单退款 |
