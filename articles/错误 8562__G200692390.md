# 错误 8562

SKU <SKU>, Missing Attributes <STANDARD_PRODUCT_ID>. A standard product id (UPC, ISBN, EAN, etc.) is required for <SKU>; MISSING_KEYSET cannot be used. Feed ID: <FEEDID>. For more details, see http://sellercentral.amazon.com/gp/help200692390
对于部分商品，亚马逊要求提供标准商品编码（UPC、EAN、ISBN 等），不会接受 MISSING_KEYSET 原因。请提供有效的标准商品编码。
