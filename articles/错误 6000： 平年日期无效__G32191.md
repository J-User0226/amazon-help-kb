# 错误 6000： 平年日期无效

*日期*无效，因为平年 *Year* 中的二月只有 28 天。

当指定的日期在日历上不存在时，就会出现此错误。例如，平年二月只有 28 天。闰年每四年出现一次。2004 年是闰年。其他闰年有 2008 年、2012 年、2016 年和 2020 年。

要解决该错误，您应该：

- 修改您的文件，输入有效的日历日期。

- 保存所做的更改。

- 重新提交文件。
