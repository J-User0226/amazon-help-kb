# 优先配送常见问题

#### 如何注册优先配送选项？

您需要根据 MFN 绩效满足优先配送资格：准时送达率 ≥ 93.5%、VTR ≥ 99%，且 CR ≤ 0.5%（过去 28 天）。

获得资格后，您可访问[“资格”页面](https://sellercentral.amazon.com/ah/eligibility)并点击“注册”来加入该计划。 确认计划要求后，即可开始向买家提供优先配送选项。

注册完成后，您需要设置包含次日达和隔日达选项的配送模板，选择承运人和配送方式，配置备货时间和配送速度，并启用配送设置自动化或手动设置运输时间，以开始作出配送承诺。

#### 我是否可以为优先配送选项设置备货时间？

不可以。无论是系统默认的备货时间（1 天），还是您在系统中输入的卖家设置的任何备货时间，优先配送商品的备货时间均为当日。

#### 如果买家在截止时间之前订购了具有优先配送选项的商品，但订单状态在截止时间之后才从“等待中”变为“未发货”，我是否仍要在当天将该商品发出？

您必须尽量满足买家对送达时间的预期。但是，对于在截止时间之后仍然处于“等待中”的订单，系统将会生成一个新的预计送达日期并将此日期告知买家。

#### 我目前没有资格提供优先配送，因为我不符合资格要求。我能否获得豁免？

我们不会对无法满足资格要求的卖家给予豁免。

#### 我的优先配送选项已被撤销。如何才有资格参与该计划？

您可以向 [op-pso-vtr-appeals@amazon.com](mailto:op-pso-vtr-appeals@amazon.com) 提交行动计划进行申诉，以恢复您的资格。有关更多信息，请参阅[优先配送计划政策](https://sellercentral.amazon.com/gp/help/external/G201503640)。如果您的行动计划未获得批准，或者您选择不提交行动计划，则必须重新获得该计划的资格。有关更多信息，请参阅[优先配送资格撤销](https://sellercentral.amazon.com/gp/help/external/G5C8BKMNBFSGU7GZ)。

#### 我的承运人无法提供追踪信息，或者不是亚马逊认可的承运人。我是否还可以提供优先配送选项？

我们仅支持可以验证追踪信息的指定承运人。有关更多信息，请参阅[优先配送计划政策](https://sellercentral.amazon.com/gp/help/external/201503640)。

#### 如果我的承运人在优先配送选项的截止时间之前取件，我能否更改截止时间？

您可以前往[位置](https://sellercentral.amazon.com/sbr#settings)，更改截止时间。在【配送能力】下，选择【配送】，然后点击【编辑】，以更新“订单截止时间”部分。订单截止时间必须为当地时间周一至周五下午 2:00 或之后。
