# 错误 18028

已收到的错误消息： 提交的数据不完整或无效。

如果您未能提供 Amazon.com 处理您的申请所需的全部必要数据，则会出现此错误。

如果您使用文本文件管理您的订单，请参阅模板中的数据定义，了解必填字段列表。

如果您提交 XML 上传数据管理您的订单，请参考相关的 XSD（XML 架构定义）以确定哪些值为必填值。
