# 管理图片

在[图片管理器](https://sellercentral.amazon.com/imaging/manage)中，您可以上传单张图片（包括特定国家/地区的图片）、删除图片、将媒体素材集复制到同系列商品，以及预览或检查您的图片是否已在商品详情页面上显示。

## 图片显示和合规性

- 您在**图片管理器**中为商品显示的图片顺序可能与商品详情页面上显示的不同。为打造最佳的购物体验，我们会从多个卖家提供的商品图片中进行选择和安排。为最大程度提高您的图片被显示的概率，请确保其符合我们在[商品图片指南](https://sellercentral.amazon.com/help/hub/reference/G1881)和[商品详情页面规则](https://sellercentral.amazon.com/gp/help/external/G200390640)中概述的商品图片要求。

- 当您上传图片文件时，我们会对其进行检查，确认其符合技术文件要求。不符合这些要求的文件不会上传到您的商品信息中。要查看图片的上传状态，请前往[提交状态](https://sellercentral.amazon.com/imaging/upload/status)并选择**图片上传状态**报告类型。

- 如果您的图片存在问题，我们会在图片管理器的图片缩略图中显示带有红色感叹号的图标。将鼠标悬停在图标上即可查看问题信息。您可以在**提交状态**页面中找到与您的账户相关的图片问题的完整列表，包括解决这些问题所需采取的措施。选择**内容合规问题**报告类型，在表格中查看问题或下载问题报告。

- 如果您的商品信息中的图片被发现不符合亚马逊政策，在您提供合规图片之前，该商品信息可能会从搜索中移除。要了解有关不合规问题的更多信息，请参阅[图片屏蔽](https://sellercentral.amazon.com/gp/help/external/hu/gp/help/GT8RSE9S9NK4LP6Z)。

- 如果您的图片被选中显示，则上传后最多需要 24 小时才会显示在商品详情页面上。

## 将媒体素材集复制到同系列商品

- 在**图片管理器**的左侧窗格中，使用 ASIN 或 SKU 搜索您的商品。

- 从搜索结果中选择您的商品。

- 点击**将媒体素材集复制到同系列商品**。

- 查看将接收媒体素材集的同系列商品列表。

- 点击 **复制。**

## 上传单张图片

- 在**图片管理器**的左侧窗格中，使用 ASIN 或 SKU 搜索您的商品。

- 从搜索结果中，选择要上传图片的商品。

- 在**您上传的图片**下，按商城筛选或在右侧面板中向下滚动，为所选商品上传图片到特定商城（仅适用于您在多个商城中为商品提供报价的情况）。

- 从下拉菜单中，选择您要上传的图片对应的变体代码（MAIN、FRNT、PT01、PT02 等），然后点击 **上传**。

- 有关图片变体代码列表，请前往[商品图片指南](https://sellercentral.amazon.com/help/hub/reference/G1881)帮助页面中的【图片变体】。

- 要了解有关为商品分配图片的更多信息，请前往[分配图片](https://sellercentral.amazon.com/gp/help/external/GSYPJKG5DFEGFHWD)

- 从计算机中选择图片，然后点击**打开**。此操作会将图片提交至此变体。

**注意： **

- 您上传的图片可以灵活地命名，例如 image1.jpg。

- 要替换主图片，请点击主缩略图下的相机图标，然后上传新的主图片。

- 要替换非主图片，请删除该图片并上传新图片。

## 删除图片

- 在**图片管理器**的左侧窗格中，使用 ASIN 或 SKU 搜索您的商品。

- 点击左侧面板上的商品后，即可在页面的右侧面板上查看您为该商品上传的特定国家/地区图片以及全球商城图片。

- 选择您想要移除的图片，然后点击图片右下角的删除图标。

- 在弹出窗口中确认删除图片。

**注意： **

- 由于所有 ASIN 都需要有一张主图片，因此您无法删除主图片。但您可以将主图片替换为一张新图片。要替换原来的主图片，请点击主缩略图下的相机图标，然后上传新的主图片。

- 必须从每个 ASIN 中分别删除子 ASIN 之间共享的图片。

## 图片状态和预览

**查看图片状态**

在**图片管理器**中：

- 使用 ASIN 或 SKU 搜索您的商品：

- 从搜索结果中选择您的商品。

- 每个图片模块都将在商品详情页面上显示图片状态（“上线”“未上线”或“状态未知”）。

- 如果您的图片没有显示，请将鼠标悬停在状态旁的信息图标上，以了解有关商品详情页面上显示的图片上传器的更多信息。

- 如果实时图片上传工具是您的合作伙伴账户下的卖家，我们会提供合作伙伴账户名称和卖家记号。

- 如果实时图片上传工具不在您的合作伙伴账户下，我们不会提供任何身份信息，并通知您实时图片是从其他销售伙伴中选择。

您也可以在[提交状态](https://sellercentral.amazon.com/imaging/upload/status)页面查看图片状态。

**在商品详情页面上实时预览当前图片：**

- 在**图片管理器**的左侧窗格中，使用 ASIN 或 SKU 搜索您的商品。

- 从搜索结果中选择您的商品。

- 点击所显示的国家/地区标题下的**实时图片**。此时将打开一个窗口，显示商品详情页面上显示的图片。此窗口底部显示图片的缩略图，其顺序与商品页面上的显示顺序相同（从左到右）。

**查看商品详情页面**

- 在**图片管理器**的左侧窗格中，使用 ASIN 或 SKU 搜索您的商品。

- 从搜索结果中选择您的商品。

- 点击所显示的国家/地区标题下的**查看商品详情页面**。

有关上传图片的详细步骤，请前往[上传图片](https://sellercentral.amazon.com/help/hub/reference/GUGPCYWV2P8KVFUT)。
