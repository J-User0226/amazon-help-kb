# 错误 5005

XML 有效负载中提供的 MerchantIdentifier 对您的凭证无效。

当您在 XML 标题中提供的 MerchantIdentifier 值对于您在 HTTP 标题中提供的凭证无效时，就会出现该错误。您的凭证与您访问卖家平台时使用的用户名和密码相同。MerchantIdentifier 值是您的卖家令牌，格式与 M_ACMEINC_012345 相似。这个值在您注册新卖家账户时由亚马逊生成。要纠正该错误，您必须更改 XML 标题中的 MerchantIdentifier 值，或者修改客户端设置，以便在 HTTP 标题中提供有效凭证。如果您不知道自己的卖家令牌，请联系我们。

**注意： **亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。
