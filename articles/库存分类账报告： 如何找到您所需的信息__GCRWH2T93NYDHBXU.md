# 库存分类账报告： 如何找到您所需的信息

在本页面，您将了解如何使用[库存分类账报告](https://sellercentral.amazon.com/reportcentral/LEDGER_REPORT/0)。该报告将替代以下类型的报告，这些报告将于 2023 年 1 月 31 日起停用：
- 每日库存历史记录
- 每月库存历史记录
- 库存动作详情
- 盘库
- 已接收库存
- 库存调整

**注意： **我们建议您现在开始使用库存分类账报告，以免上述这些报告被停用后，业务出现中断。有关更多信息，请参阅[库存分类账报告](https://sellercentral.amazon.com/gp/help/external/G4FKT5KQWFFJ7LDN)帮助页面。

下面提供了有关每个将被停用的报告的详细信息，以及如何使用库存分类账报告访问旧报告中所含信息的操作步骤。

这些说明通常适用于在线查看报告、下载报告或通过应用程序接口访问报告。如果相关说明因报告的访问方式而异，我们会在下面注明。

如果您通过应用程序接口下载报告，请参阅我们的[开发人员文件](https://developer-docs.amazon.com/sp-api/docs/report-type-values#inventory-reports)，了解有关设置请求筛选条件的更多信息。

## 每日库存历史记录报告
该报告提供了每日库存数量、位置和库存属性信息。要使用库存分类账报告获取该信息，请按照以下步骤操作：

1. 前往[库存分类账报告](https://sellercentral.amazon.com/reportcentral/LEDGER_REPORT/0)。

2. 选择【一览视图】。

3. 在【按位置汇总报告】下，选择【运营中心】或【国家/地区】。

4. 在【按时间段汇总报告】下拉菜单中，选择【每日】。

5. 点击【生成报告】。

在“每日库存历史记录”报告中，运营中心之间的在途商品数量显示在单独的行中，【*XFR】 显示在【库房编号】列中。在库存分类账报告的一览视图中，这些数量显示在名为【库房间转运量】的附加列中。按照运营中心或国家/地区将【库房间转运量】列中的数量相加，您的在途总数量等于【*XFR】。 **注意： **如果您在低价商品店铺中销售商品，则可以通过按 **Country = CN** 筛选结果，以便识别这些商品。

## 每月库存历史记录报告
该报告提供了每月库存数量、位置和库存属性信息。要使用库存分类账报告获取该信息，请按照以下步骤操作：

1. 前往[库存分类账报告](https://sellercentral.amazon.com/reportcentral/LEDGER_REPORT/0)。

2. 选择【一览视图】。

3. 在【按位置汇总报告】下，选择【运营中心】或【国家/地区】。

4. 在【按时间段汇总报告】下拉菜单中，选择【每月】。

5. 点击【生成报告】。

在“每月库存历史记录”报告中，运营中心之间的在途商品数量显示在单独的行中，【*XFR】 显示在【库房编号】列中。在库存分类账报告的一览视图中，这些数量显示在名为【库房间转运量】的附加列中。按照运营中心或国家/地区将【库房间转运量】列中的数量相加，您的在途总数量等于***XFR**。 **注意： **如果您在低价商品店铺中销售商品，则可以通过按 **Country = CN** 或 **FC = XCND** 汇总结果来识别这些商品。

## 库存动作详情报告
此报告包含您的所有库存动作，允许您按日期范围和动作类型进行筛选。要使用库存分类账报告获取该信息，请按照以下步骤操作：

1. 前往[库存分类账报告](https://sellercentral.amazon.com/reportcentral/LEDGER_REPORT/0)。

2. 选择【详细视图】。

3. 如果需要，请使用下拉菜单按【动作类型】进行筛选。按动作类型进行筛选将减少文件大小，以便更快地生成报告。

4. 从下拉菜单中选择日期范围或输入自定义日期范围。

5. 点击【生成报告】。

**注意： **该报告将包含所有交易（以前称为【动作】）以及发生交易的运营中心（以前称为【库房编号】）。

**注意： **如果您在低价商品店铺中销售商品，可以通过筛选 **FC = XCND** 来识别商品事件。

## 盘库报告
本报告提供了关于您存储在亚马逊运营中心内的库存的更正和更新信息。要使用库存分类账报告获取该信息，请按照以下步骤操作：

1. 前往[库存分类账报告](https://sellercentral.amazon.com/reportcentral/LEDGER_REPORT/0)。

2. 选择【详细视图】。

3. 在【动作类型】下拉菜单中，选择【盘点】。

4. 从下拉菜单中选择日期范围或输入自定义日期范围。

5. 点击【生成报告】。

**提示： **如果您正在查找某一特定盘点且正在使用在线视图，则可以在【内部编号】字段中筛选盘点（【内部编号】等同于【交易商品编号】）。按内部编号进行筛选仅可在在线视图中操作。通过下载方式或应用程序接口访问则无法进行，因为筛选条件将仅返回一条记录。

**注意： **如果您下载报告或通过应用程序接口访问报告，则报告将包含【已调整数量】和【未调整数量】列，类似于盘库报告。

**注意： **如果您在低价商品店铺中销售商品，可以使用筛选 **FC = XCND**，以便在报告中识别商品事件。

## 已接收库存报告
本报告显示的是已在运营中心完成接收流程的库存。要使用库存分类账报告获取该信息，请按照以下步骤操作：

1. 前往[库存分类账报告](https://sellercentral.amazon.com/reportcentral/LEDGER_REPORT/0)。

2. 选择【详细视图】。

3. 在【动作类型】下拉菜单中，选择【接收】。

4. 从下拉菜单中选择日期范围或输入自定义日期范围。

5. 点击【生成报告】。

**提示： ** 如果您正在查找某一特定货件，可以在【内部编号】字段中筛选该货件（【内部编号】等同于【亚马逊物流货件编号】）。按内部编号进行筛选仅可在在线视图中操作。通过下载方式或应用程序接口访问则无法进行，因为筛选条件将仅返回一条记录。

**注意： **如果您在低价商品店铺中销售商品，可以使用筛选 **FC = XCND**，以便在报告中识别商品事件。

## 库存调整报告
本报告显示了特定时间段内的净库存详情。使用本报告可以分析运营中心出入库流转情况，包括已售商品、退货商品、移除商品、弃置商品、已残损商品、丢失商品和找到的商品。要使用库存分类账报告获取该信息，请按照以下步骤操作：

1. 前往[库存分类账报告](https://sellercentral.amazon.com/reportcentral/LEDGER_REPORT/0)。

2. 选择【一览视图】。

3. 在【按位置汇总报告】下，选择【国家/地区】。

4. 在【按时间段汇总报告】下拉菜单中，选择【每月】。如果需要，您也可以按【卖家 SKU】 或 【FNSKU】 进行筛选。

5. 从下拉菜单中选择日期范围或输入自定义日期范围。

6. 点击【生成报告】。

**提示： **要在库存分类账报告的【一览视图】中从【退货】或【已接收】等字段中查看某一特定动作的详细信息，请点击数量链接。点击该链接，将打开报告的【详情视图】新选项卡，其中包含这些动作的详细信息。这一流程将取代之前的操作。在原先的操作流程中，点击库存调整报告中的链接将打开盘库或库存动作详情报告。

**注意： **如果您在低价商品店铺中销售商品，则可以通过按 **Country = CN** 或 **FC = XCND** 汇总结果来识别这些商品。

**注意： **要详细了解您的库存相关缺陷，包括其状态和赔偿决定，请前往[库存缺陷和赔偿门户](https://sellercentral.amazon.com/inventory-reimbursement/overview/)。

**运输途中的库存**

库存调整报告在计算【初始数量】和【期末数量】时会纳入【运输途中】的库存数量。默认情况下，库存分类账报告的【一览视图】不包含运输途中的库存数量。而是在报告中额外增加了一个名为【库房间转运量】的列。要获取与库存调整报告中显示的相同的初始或期末库存数量，请使用以下计算方式：
- 库存调整报告**初始数量** = 库存分类账报告【初始库房余量】 + 上个月或日期范围结束时的【库房间转运量】
- 库存调整报告【期末数量】 = 库存分类账报告【期末库房余量】 + 当前月份或日期范围内的【库房间转运量】
