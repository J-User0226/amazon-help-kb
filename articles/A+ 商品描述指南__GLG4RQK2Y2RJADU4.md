# A+ 商品描述指南

A+ 商品描述支持品牌所有者和授权转销商利用丰富的营销内容改进商品详情页面，其中包括图文版商品描述和品牌故事。

这一综合工具可帮助您展示商品特性、传达品牌价值，并提供详尽信息，帮助买家做出明智的购买决策。[A+ 商品描述管理器](https://sellercentral.amazon.com/enhanced-content/content-manager)提供了一种系统化方法，有助于在各类商品信息中创建、管理及发布图文版商品描述。

A+ 商品描述优势如下：

- 通过图文版详情页面提高商品的曝光度和转化率

- 主动提供详细的商品信息，减少买家的问题和负面评论

- 通过一致的信息传递和视觉叙事来提高品牌形象

- 优化商品内容在桌面和移动设备的显示效果，改善买家体验

**注意： **A+ 商品描述在基本和高级功能方面无需额外付费。对于卖家使用高级A+ 商品描述没有额外的资格条件。为避免发布遭拒和延迟，请在提交前根据我们的 A+ 商品描述指南审核所有内容。

## 对 AI 生成人物的披露

如果视频包含相片级逼真的 AI 生成人物，则某些司法管辖区可能要求进行相关披露。如果您的视频包含相片级逼真的 AI 生成人物，则在将其上传到亚马逊之前，必须使用适当的元数据标记该视频。

**如何添加所需的元数据**

使用与 IPTC 兼容的元数据编辑器，将关键字 contains-synthetic-performer 添加到视频文件的 dc:subject (XMP) 字段。

如果包含这些元数据，亚马逊将添加披露信息，以告知受众该视频包含 AI 生成的人物（如适用）。

有关更多信息，请参阅[如何标记包含 AI 生成人物的媒体](https://sellercentral.amazon.com/help/hub/reference/GFXHCHYZRGJRBZA5)。

当您将图片上传到 A+ 商品描述管理器中的创意资产时，您还可以选择勾选“AI 生成人物”以标记图片中的 AI 生成人物，我们将为您应用必要的元数据。

**何时提供此元数据**

如果您的视频包含完全由 AI 生成的人物（并非基于真人），请提供 contains-synthetic-performer 标签。

**何时不需要提供此元数据**

如果满足以下任一条件，请勿提供此元数据：

- 您的视频仅展示真人（即使已使用 AI 工具进行了修改）或

- 您的视频仅包含电影、视频游戏或其他表现形式作品（例如，电影海报或视频游戏封面）中的角色

- 您的视频中不包含任何人物

- 您视频中的人物不是照片级逼真的

## A+ 商品描述的类型

我们为商品详情页面提供三种不同类型的 A+ 商品描述：

**基本 A+ 商品描述**显示在商品描述部分，您可以通过富文本编辑器，访问自定义标题、图片、文本布局以及商品对比图等模块。

**高级 A+ 商品描述**通过交互式热点、多个视频、高级对比图、更大的图片以及问答模块等高级功能，优化商品描述部分。

显示在【来自品牌】部分的 **A+ 品牌故事内容**，支持一个以轮播格式呈现的模块，最多可包含 19 张预定义格式的卡片。它提供全屏背景、图文卡片以及指向商品和品牌旗舰店的链接。品牌故事可以与基本或高级 A+ 商品描述一同使用，但媒介类商品（图书、音乐、视频或 DVD）分类不支持这些功能。

| 基本与高级对比 | | | | | | | |
| --- | --- | --- | --- | --- | --- | --- | --- |
| A+ 商品描述类型 | 文本和图片 | 图片尺寸 | 对比图 | 详情页面支持的模块数量 | 模块选择 | 视频和热点 | 导航轮播 |
| 基本 A+ 商品描述 | 是 | 970 x 300 | 是 | 5 | 14 | 否 | 否 |

## 技术要求

| 系统要求 | | |
| --- | --- | --- |
| 要求 | 规格 | 说明 |
| 图片格式 | .jpg、.bmp、.png | 仅限 RGB 色彩空间（不支持 CYMK） |
| 图片尺寸 | 每个文件小于 2 MB | |
| 图片分辨率 | 低至 72 dpi | |
| 语言 | 匹配指定的商品描述语言 | 仅允许在品牌标识使用有限的其他语言 |

以下技术限制适用于您的商品描述：

- 无动画图片 (GIF)

- 无 HTML 标记

- 无 CMYK 色彩空间

- 无水印

- 无二维码

- 无超链接或外部重定向

**注意： **如果图片太大，系统会调整图片大小，使其不超出每个模板框旁列出的最大大小（但如果图片小于模板限制，则不会进行调整）。您还可以直接在此工具中裁剪和缩放图片。

## 商品描述创建流程

| 前提条件和品牌验证 | |
| --- | --- |
| 验证步骤 | 要求 |
| 账户角色 | 品牌代表与转销商 |
| ASIN | 必须注册到您的品牌 |
| 商品图片 | 必须符合技术规范，无动画图片或水印 |
| 品牌名称 | 必须完全匹配“Brand Registry”（区分大小写） |
| GTIN 和关键属性 | UPC、部件编号、型号、款式编号、目录编号 |

**创建 A+ 商品描述：**

请按照以下步骤创建基本 A+ 商品描述：

- 请前往供应商平台菜单中的【广告】，选择 [A+ 商品描述管理器](https://sellercentral.amazon.com/enhanced-content/content-manager)，然后点击【开始创建 A+ 商品描述】。

- 为您的商品描述项目命名，选择语言，然后选择商品描述模块。请务必时常保存进度。

- 要添加商品描述，请在文本字段中输入商品描述，然后将图片上传至【媒介类商品库】。请确保为每张图片添加 alt-text。使用桌面和移动视图预览内容。

- 要应用商品描述，请先搜索 ASIN 系列，然后选择目标 ASIN。

- 若 ASIN 超过 1000 个，您可以使用批量上传（每次上传的 ASIN 库存限制为 10000 个）。

- 提交后，审核期最长可能需要 7 个工作日。发布将在批准后的24小时内完成。图片描述只能在特定语言的页面上查看。我们建议您保留所有提交内容的副本，以供参考。

## 指南和最佳实践

为确保您的商品描述始终保持最高品质，我们建议您采取以下措施：

- 添加不与图片库内容重复的独特内容。

- 重点关注商品功能和优势，而不是促销语言。

- 确保所有内容既符合品牌的美学风格和调性，又保持专业水准。

对于图片，请确保上传高分辨率文件（最低 72 dpi），以 RGB 色彩空间（.jpg、.bmp 或 .png 格式）提交，且每个文件的大小均不超过 2 MB。

**发布最佳实践**

我们建议您在发布商品描述时采取以下操作：

- 对商品描述进行最终审核，并确保您审核应用的 ASIN，验证语言变体，并在预览模式下审核所有商品描述。

- 提交商品描述后，最多需要 7 个工作日才能获得批准。请务必监控批准状态并解决任何被拒原因。

- 商品描述发布后，请在 24 小时内完成以下操作： 

- 所有 ASIN 均处于在售状态且正确显示

- 确认语言变体

- 测试所有交互式元素

我们建议您使用以下文件和维护步骤：

- 记录所有应用的 ASIN。

- 记录任何自定义模块。

- 保存模板配置。

- 安排商品描述定期审核。

**注意： **一次最多提交 20 份待处理内容。经常将工作保存为草稿，以免进度丢失。

## 解决步骤

如果您的内容未显示，请执行以下步骤：

- 验证内容状态是否为【已批准】。

- 检查【已应用 ASIN】 下的 ASIN 状态。

- 确认语言选择正确无误。

- 确保您在获得批准后已等待 24 小时

- 如果仍未显示内容，请联系销售伙伴支持。

**注意： **亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。

如果您的商品描述遭拒，请执行以下步骤：

- 在 【A+ 商品描述管理器】中审核遭拒原因。

- 根据上述 A+ 商品描述指南进行检查。

- 进行必要的更正。

- 重新提交以供批准。

**注意： **媒介类商品（图书、音乐、视频或 DVD）(BMVD) 分类下通过卖家平台销售的商品尚不支持 A+ 商品描述功能。A+ 商品描述与亚马逊企业购图文版商品描述不同，后者是一个工具，可让您向详情页面上传单独的文件。
