# 回复或解决买家反馈

如果您收到负面反馈，请务必尽快找出问题的原因，然后想办法解决问题。请注意，以下指南仅适用于卖家反馈而非买家评论。但是，所有适用于买家商品评论的政策还适用于卖家反馈。有关评论的特定指南，请参阅[买家商品评论政策](https://sellercentral.amazon.com/help/hub/reference/external/GYRKB5RU3FS5TURN)。

## 解决买家反馈
如果买家发布了负面的卖家反馈，我们建议您单独联系买家解决问题。请记住，强迫或通过提供物质奖励的方式请求买家移除或修改负面反馈属于违规行为。

**问题解决后可接受的通知示例：** “感谢您为我们的业务提供反馈，我们希望您所遇到的所有问题都已得到圆满解决。”

**违反政策的消息示例：** “如果我们解决了您遇到的问题，您能否删除反馈？”

要联系买家处理负面反馈，请执行以下操作：
1. 前往[管理订单](https://sellercentral.amazon.com/orders-v3)。
2. 找到您要联系的买家所下的订单。
3. 在【订单详情】列中，点击买家名称。
4. 在【联系买家】页面执行以下操作：
  - 在【主题】下拉菜单中选择一个主题（例如：【反馈请求】）。
  - 在【消息】区键入消息内容。
  - 使用【添加附件】添加收据、证明文件等。

5. 点击【发送电子邮件】，将消息发送给买家。

**注意： **自最初发布反馈之日起，买家可以在 60 个日历日内随时删除针对卖家交易提供的反馈。

## 回复买家反馈
如果您主动联系买家解决问题，但买家拒绝删除负面反馈，您可以针对反馈发布回复。该回复将显示在亚马逊网站上。

**注意： **您的回复将向所有人公开。与买家沟通时，请不要采用这种方式。

您可以在回复中说明您采取了哪些补救措施。您的回复不会更改反馈评级，但其他买家在看到该买家的反馈时可以看到您的解释说明。

回复负面反馈时，请尽量让语言简短专业。即使买家在评论时语气不善，您也不要以同样的语气和买家争论，这样只会适得其反，给您的商业带来不良影响。

1. 前往[反馈管理器](https://sellercentral.amazon.com/feedback-manager/index.html#/)。
2. 点击要回复的反馈对应的【订单编号】。
3. 点击【回复反馈】。
4. 输入回复内容。
5. 点击【提交】。

提交回复后，您无法再次编辑，但可将其删除。删除回复后，您无法再次提交回复。此外，如果买家移除反馈，您的回复也将一并移除。

要移除回复，请执行以下操作：
1. 前往[反馈管理器](https://sellercentral.amazon.com/feedback-manager/index.html#/)。
2. 点击包含您回复的反馈对应的【订单编号】。
3. 找到要移除的评论，然后点击【请求移除】。
4. 再次点击【请求移除】进行确认，或点击【取消】以取消请求。

如果买家为卖家发布了中性/负面评论（即 1~3 星），我们建议您联系买家以了解其反馈的性质，并确定您是否可以采取一些措施来解决任何有待解决的问题。即使在解决了买家的问题后，您也不能要求买家修改或删除反馈。但是，您可以通过买家与卖家消息服务以中立的态度请求买家提供其他反馈（如果买家愿意）。

请注意，为了让买家留下正面反馈（即 4~5 星评论）或删除负面评论而给买家施压或者提供奖励措施属于违反我们政策的行为。有关更多信息，请参阅[买家评论](https://www.amazon.com/gp/help/customer/display.html?ref_=hp_left_v4_sib&nodeId=G3UA5WC5S5UUKB5G)。

**可接受的通知示例：** “我们希望我们已经解决了您的问题。根据您在使用我们服务时的体验，如果您有其他反馈，请告知我们。”

**违反政策的示例：** “如果我们为您提供一张可在下次购物时享受 25% 折扣的优惠券，您是否愿意删除反馈？”

## 解决买家反馈
您可以按照以下步骤操作，联系买家解决其负面反馈：

**使用反馈管理器**
1. 前往【绩效】选项卡下的[反馈](https://sellercentral.amazon.com/feedback-manager/index.html#/)。
2. 在【最新反馈】表中，选择指定订单编号旁边【操作】列下的【联系买家】。

**重要： **您只能使用买家与卖家消息服务就订单或客户服务问题联系买家。

**注意： **如果买家愿意，他们可在自最初发布反馈之日起 60 个日历日内随时删除针对卖家交易提供的反馈。

有关更多信息，请参阅[亚马逊是否可以删除买家反馈？](https://sellercentral.amazon.com/gp/help/external/G20231)。

要了解有关我们就买家反馈告知了买家哪些信息的更多信息，请参阅[删除第三方卖家反馈](https://www.amazon.com/gp/help/customer/display.html/ref=au_xx_cont_202126280?&nodeId=201125570)。

## 回复买家反馈
对于解决其问题后未删除负面反馈的买家，您可以在亚马逊网站上就提供的解决方案发布回复。

**使用反馈管理器：**
1. 前往【绩效】选项卡下的[反馈](https://sellercentral.amazon.com/feedback-manager/index.html#/)。
2. 在【最新反馈】表中，选择【发布公开回复】。

**注意： **您的回复将向所有人公开。请不要将此作为与买家沟通的方式。

您可以在回复中说明您采取了哪些补救措施。您的回复不会更改反馈评级，但其他买家在看到该买家的反馈时可以看到您的解释说明。

回复负面反馈时，请尽量让语言简短专业。即使买家在评论时语气不善，您也不要以同样的语气和买家争论，这样只会适得其反，给自己带来不良影响。

**要删除回复，请执行以下操作：**
1. 在卖家平台中，点击【绩效】标题下方的【反馈】。
2. 点击包含您回复的反馈对应的【订单编号】。
3. 找到要删除的评论，然后点击【请求删除】。
4. 再次点击【请求删除】进行确认，或点击【取消】以取消请求。

提交回复后，您无法再次编辑，但可将其删除。删除回复后，您无法再次提交回复。如果买家删除或修改了他们的反馈，您的回复也将一并删除，并且您可以提交新回复。
