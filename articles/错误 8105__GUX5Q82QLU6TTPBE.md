# 错误 8105

## 错误消息
您为某个属性提供的数据与有效值列表不匹配。请从“数据定义”中选择一个有效值，然后重新提交您的文件。

## 错误 8105 产生原因
错误 8105 是由以下原因导致的：

- 您为某个字段提供的值与亚马逊的有效值列表不匹配。
- 模板中提供了数据定义建议，您提供的值与建议的值不匹配。
- “Data Definitions”选项卡包含可接受的值格式，在填写“Template”选项卡时，该值格式可应用于各列。

## 如何解决错误 8105
要解决错误 8105 错误，请执行以下步骤：

1. 请参阅“**Valid Values**”选项卡，了解亚马逊建议的有效值。
2. 请下载上传的模板，并检查模板中受影响的属性。受影响的值以橙色高亮显示。对受影响的列进行必要的更改。重新提交文件，以确保成功提交。

**注意： **
- 确保您的商品编码已正确更新。请参阅“查找您的商品编码 (GTIN)”，详细了解商品编码的字符要求。
- 对于需要从下拉列表中选择一个值的属性，请勿在其中复制粘贴任何不属于该下拉列表的无效值。此操作将导致出现错误。请仅从下拉列表中选择适用的值。
- 评估并为从属属性选择有效值。例如，如果您在“Age Range Description”中选择“Adult”，则必须在“Shoe Size Age Group”字段中选择“Adult”值。
