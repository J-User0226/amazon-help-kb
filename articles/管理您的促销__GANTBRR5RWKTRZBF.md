# 管理您的促销

您可以在**管理您的促销**页面访问一个清单，其中包含所有您已创建的促销。要访问此页面，您可以登录卖家平台账户，并依次前往“广告”>“促销”>“管理您的促销”选项卡。

页面上列出的每个促销都有一个对应的状态，同时还有包括关键指标在内的其他信息，和用于查看或编辑现有促销的选项。这可让您监控促销的当前状态，并在必要时采取适当措施。下表介绍了完整的状态列表及其简要描述。

| 选项卡 | 促销状态 | 描述 |
| --- | --- | --- |
| 您的促销 | 活跃 | 目前在亚马逊购物网站上进行的促销活动，买家可以申请享受相关促销。 |
| 等待中 | 已成功创建并已排期等待上线（未来的日期/时间）的促销。 | |
| 已过期 | 已结束的促销。 | |
| 全部 | 列出上述状态的所有促销。 | |
| 验证提交内容 | 正在处理 | 最近创建的、目前系统正在处理的促销。一旦我们的系统验证通过了该促销，它将显示在您的促销选项卡中。 |
| 失败 | 最近创建的、系统未能成功处理的促销。要了解失败的原因，请选择一个促销，以导航至查看促销页面。您可以编辑促销，更正问题，然后重新提交。 | |

## 常见问题 (FAQ)

- 我不太熟悉**验证提交内容**选项卡。这与**您的促销**选项卡有何不同？

当您提交新创建的或编辑过的促销时，我们的系统需要一些时间来验证相应内容。在此期间，可在**验证提交内容**选项卡中查看相关促销。成功完成此验证流程后，您可在**您的促销**选项卡中查看相关促销。有关此过程需要多长时间的更多信息，请参阅常见问题 2。

- 我的促销现在显示在**验证提交内容**选项卡中。需要多长时间，相关促销才会显示在**您的促销**选项卡中？

如果您的促销显示在**验证提交内容**选项卡中，则表示我们的系统仍在处理您提交的内容。此过程通常需要最长一个小时，之后促销将显示在**您的促销**选项卡中。在某些情况下，这可能需要最长 3 天，在此期间，我们将会在后台积极进行处理，以加快这个流程。

- 为什么我无法编辑促销？

如果您的促销显示在**验证提交内容**选项卡中，并处于**处理中**状态，那么您将无法对其进行编辑。请耐心等待一段时间，以便我们的系统完成对您提交内容的处理（如常见问题 1 中所述），之后您就可以编辑相关促销了。

- 我已经编辑了促销，但促销仍停留在“处理中”状态。这是否意味着我的促销未激活？

当系统处理您编辑过的促销时，相关促销的先前版本/原始版本将处于激活状态。在系统成功处理编辑后的促销前，将一直如此。如果系统处理编辑后的促销失败，则您将可以在“查看促销”页面查看失败原因。您可以再次编辑相关促销，此时，请根据列出的失败原因采取纠正措施。
