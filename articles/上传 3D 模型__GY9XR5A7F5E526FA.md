# 上传 3D 模型

为商品添加 3D 内容可帮助买家通过互动方式使用商品功能，让他们了解您的商品，并激发他们对您品牌的兴趣。目前，只有特定的商品分类（如家居、家具、消费类电子产品、鞋靴和眼镜分类）支持 3D 内容。

**注意： **3D 资产不得包含任何人物图像。

开始之前，请确保您已经准备好要与 3D 模型一起提交的准确商品尺寸。有关文件要求的更多信息，请参阅 [3D 模型技术要求](https://sellercentral.amazon.com/help/hub/reference/G7RGSNQFZ2BAG7K3)。

要将 3D 模型上传至您的商品信息中，请按照以下步骤操作：

- 前往【目录】，然后选择【上传图片】。

- 在屏幕左上角选择【图片管理器】选项卡。

- 在左侧窗格中，使用 ASIN 或 SKU 搜索您的商品。

- 从搜索结果中，选择要上传 3D 模型的商品。

- 在右侧窗格中，查看是否有**已注册的品牌所有者**图标。您只能为分配了[品牌代表](https://sellercentral.amazon.com/gp/help/external/GJ84K745AL3R5N3Q)角色的商品上传 3D 内容。

- 在右侧窗格中，前往 【3D 模型】，然后选择【上传 3D 模型】。

- 按照页面上的说明上传您的参考资料和 3D 模型。

- 所有提交的内容在发布前都必须根据我们的质量标准进行评估，并且可能需要进行修正。要确定您提交的内容是否已成功发布或是否需要采取其他操作，请前往**提交状态**选项卡。对于大多数提交的内容，我们会在两周内进行审核。
