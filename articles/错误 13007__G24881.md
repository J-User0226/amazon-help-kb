# 错误 13007

最低宣传价格 (MAP) 必须为正数值。有关详情，请参阅 http://sellercentral.amazon.com/gp/help/24881



“最低宣传价格”也被称作“MAP”。如果库存文件或商品价格输入数据中的 MAP 值无效，则会发生此错误。



要确保数值有效，您的 MAP 值必须为正数值。例如，“3.00”是有效值，但“-3.00”是无效值。



要解决此错误，请使用大于零的 MAP 值并重新提交数据。
