# 墨水或墨粉

为了提供良好的买家体验，卖家必须确保 ASIN 商品名称、品牌名称、图片、特征要点和商品描述能够准确描述待发布的墨水或墨粉商品。如果未遵守亚马逊的商品发布指南，可能会导致商品信息从亚马逊商城被移除，或者卖家失去在亚马逊商城的销售权限。请参阅[销售墨水或墨粉盒](https://sellercentral.amazon.com/gp/help/external/200511820)，了解有关分类要求以及如何在亚马逊商城对墨水或墨粉商品进行分类的详细信息。

## 商品名称
好的商品名称应该具有足够的描述性，让买家只看到商品名称就会做出购买决定。避免使用营销内容（例如，免费、独家、红利、时尚、轻巧、耐用等）或使用商品名称字段列出硬件兼容性。请注意下文为再制造、再装填和兼容商品列出的商品名称格式，以确保正确使用品牌名称。

#### 同品牌墨水或墨粉盒（零售包装）
[OEM Brand] + [Series Name] + [Model Name] + [Product: Ink or Toner Cartridge] + ([Color(s)], [#-Pack], if app) + "in Retail Packaging"
示例
- HP + 02 + 墨水盒 +（黑色，5 支装）+ 零售包装 = HP 02 喷墨盒（黑色，5 支装）（零售包装）
- Brother + TN-350 + 墨粉盒 +（黑色）+ 零售包装 = Brother TN-350 墨粉盒（黑色）（零售包装）

#### 再装填的墨水或墨粉盒
[Third Party Brand] + "Refilled" + [Product: Ink or Toner Cartridge] + "Replacement for" + [OEM Brand] + [Series Name] + [Model Name] + ([Color(s)], [#-Pack], if app)
示例
- LD Products + 再装填 + 墨水盒 + 用于更换 + HP + 02 +（黑色，5 支装）= LD Products 再装填喷墨盒用于更换 HP 02（黑色，5 支装）
- Office 66 + 再装填 + 墨粉盒 + 用于更换 + Brother + TN-350 +（黑色）= Office 66 再装填墨粉盒用于更换 Brother TN-350（黑色）

#### 再制造和再装填的墨水或墨粉盒
[Third Party Brand] + "Remanufactured" + [Product: Ink or Toner Cartridge] + "Replacement for" + [OEM Brand] + [Series Name] + [Model Name] + ([Color(s)], [#-Pack], if app)
示例
- LD Products + 再制造 + 墨水盒 + 用于更换 + HP + 02 +（黑色，5 支装）= LD Products 再制造墨水盒用于更换 HP 02（黑色，5 支装）
- Office 66 + 再制造 + 墨粉盒 + 用于更换 + Brother + TN-350 +（黑色）= Office 66 再制造墨粉盒用于更换 Brother TN-350（黑色）

#### 兼容的墨水或墨粉盒
[Third Party Brand] + "Compatible" + [Product: Ink or Toner Cartridge] + "Replacement for" + [OEM Brand] + [Series Name] + [Model Name] + ([Color(s)], [#-Pack], if app)
示例
- LD Products + 兼容 + 墨水盒 + 用于更换 + HP + 02 +（黑色，5 支装）= LD Products 兼容墨水盒用于更换 HP 02（黑色，5 支装）
- Office 66 + 兼容 + 墨粉盒 + 用于更换 + Brother + TN-350 +（黑色）= Office 66 再制造墨粉盒用于更换 Brother TN-350（黑色）

## 品牌名称
使用的商品名称或品牌名称不能让买家对您商品的来源产生误解。再装填、再制造和兼容的商品应将再制造商或“无品牌”列为品牌名称。

例如，如果商品名称为： Sophia Global 再制造墨水盒用于更换 HP 61（2 个黑色），则品牌名称应采用以下两种之一：
- Sophia Global
- 无品牌

## 图片
通过卖家平台单独上传或批量上传。

主要图片应为 jpeg 或 tiff 文件，分辨率至少为 1000 x 1000 像素至 3000 x 3000 像素，以充分利用缩放功能。

品牌墨水或墨粉的图片应在包装前面显示实际商品，且均应为白色背景。对于非品牌墨水或墨粉，仅以白色背景显示实际商品即可。如果商品本身是白色，请使用阴影来凸显它。

最多可使用 8 张备用图片，而且我们建议您这样做。备用图片应突出使用中的商品以及重要特征的特写画面。

如果您在创建或上传符合上述规范的优质图片时遇到任何问题，请联系我们。

**注意： **亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。

## 特征要点
基本指南

要点 描述 示例
1 商品的总体概述 采用 Vivera 技术的双支装黑色墨水盒
2 包含颜色 包含： 2 支黑色 HP 02 喷墨盒
3 主要特征 防褪色、防脏污、防渗漏
4 次要特征 打印鲜明逼真的照片和激光品质的文本
5 预计打印页数 预计打印页数： 1,320 页（取决于打印机和使用情况）
以句子形式撰写要点，句尾无句号。每条要点最多 256 个字符（包括空格）。

## 商品描述
简洁、真实、浅显易懂。侧重于商品的独特属性。请勿提及竞争对手。提及商品的最佳使用场景。

如果您想列出与您的商品兼容的打印机或硬件，请使用【商品描述】部分。 **注意： **随着新型号的发布，如果您未能定期更新，您的信息可能会过时。

*另请注明其他商品限制（例如，买家在其打印机上使用所列墨盒时可能会遇到的潜在设置问题或常见错误消息）。*

示例： “当您的墨粉指示灯开始闪烁时，您一定想拥有这么一款黑色墨粉盒；仅需将黑色墨粉盒卡入到位，即可再次启动和运转打印机。TN-350 与 HL-2040 和 HL-2070N 型号 Brother 激光打印机兼容，预期寿命印量达到 2,500 页（以 5% 覆盖率计算）。

与 Brother 品牌耗材搭配使用性能最佳，其细微颗粒有助于产生丰富的黑色和巧妙的灰色色调，让您的页面看上去外观专业、清晰可辨。”
