# 重新打印货件标签

如果您需要对货件标签进行更改，请要求承运人退还标签款项，然后购买包含正确信息的新标签。有关承运人列表及其退款流程的更多信息，请访问[购买配送服务费用退款](https://sellercentral.amazon.com/gp/help/external/G200202270)。

有关所支持浏览器的信息，请参阅[通过卖家平台购买配送服务](https://sellercentral.amazon.com/gp/help/external/G200202280)。

如果您对缺少配送方式存在疑问，或在尝试购买配送服务时收到错误信息，请参阅[“购买配送服务”中缺少承运人或配送方式](https://sellercentral.amazon.com/gp/help/external/GTQMVHPB94LP2355)。 **注意： **您只能重新打印通过“购买配送服务”购买的标签。如果您尚未购买配送服务，请参阅[通过卖家平台购买配送服务](https://sellercentral.amazon.com/gp/help/external/200202280)，了解通过“购买配送服务”购买配送服务的步骤。

## 重新打印同一标签
要重新打印同一货件标签，请按照以下说明操作：

1. 在您的卖家账户中，访问【订单】 > 【管理订单】。

2. 点击“管理订单”下的【已发货】，导航至已发货订单列表。 **注意： **请确保您查看的是“卖家自配送”订单。如果您查看的是亚马逊物流订单，则下方工作流程不适用。

3. 点击一个现有订单，打开【订单详情】页面，找到相关货件。

4. 点击显示在货件上方的【重新打印标签】选项。

5. 在【已购买并确认的货件】页面，点击【打印标签】选项。

**注意： **对于某些承运人，或者对于发货地址在美国境外的情况，则会显示【下载标签 (PDF)】 按钮。点击此按钮并在下载完成后重新打印 PDF 标签。

## 重新打印新标签
如果您需要更改并重新打印某个标签，请按照以下说明操作：

1. 在您的卖家账户中，访问【订单】 > 【管理订单】。

2. 点击一个现有订单，打开【订单详情】页面，找到相关货件。

3. 点击【为已购买的货件标签退款】。

4. 点击【配送退款】。

5. 返回【管理订单】页面，打开【订单详情】页面，点击【编辑货件】，然后点击【购买配送服务】。

6. 点击【打印标签】。

**注意： **有些配送服务允许您更改货件标签的打印方向。要了解更多信息，请参阅 [Amazon Print Connect： 故障排除](https://sellercentral.amazon.com/gp/help/external/HHCDEF3QS9P5TW7)。在【购买配送服务】页面上，选择一个配送服务及其任一可选服务，然后点击【标签打印方向】（如有）。
