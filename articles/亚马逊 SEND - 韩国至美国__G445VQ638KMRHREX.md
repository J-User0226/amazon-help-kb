# 亚马逊 SEND - 韩国至美国

借助亚马逊 SEND 计划，您可以通过已加入该计划的承运人将您的亚马逊物流库存从韩国运往美国的亚马逊运营中心。您可以利用该计划以经济高效的方式将亚马逊物流货件运送到全球各地。亚马逊 SEND 支持空运和海运服务。在亚马逊 SEND 承运人取走您的货件后，他们将会处理从清关到送达亚马逊运营中心的端到端运输事宜。通过亚马逊 SEND，您可以让其承运人上门取件，也可以将货件投件至承运人网点。

## 通过亚马逊 SEND 运送您的货件

按照以下步骤，通过亚马逊 SEND 为亚马逊物流货件进行预约：

- 要创建亚马逊物流货件，请从卖家平台的【库存】下拉菜单中选择【货件】，然后导航至【货件】下拉菜单，选择 【Send to Amazon】。

- 会自动选中**我想使用亚马逊 SEND 运输货件**复选框。

- 在第 1 步中，选择您计划运往亚马逊物流的 ASIN 和数量。选择库存和数量后，输入包装详情。有关包装配置的更多信息，请参阅 [Send to Amazon： 选择要发送的库存](https://sellercentral.amazon.com/gp/help/external/G8SXKYFWPG6DAW6T)。

- 如果 ASIN 是单一 SKU 包装箱（例如大包装），则选择相应的【装箱模板】（如果您已创建了模板）。否则，请创建新的装箱模板。然后，选择【准备发货】。对于您计划发往亚马逊物流的所有 ASIN 按照此流程操作。然后，选择【确认并继续】。

- 如果是混合 SKU 包装箱，请选择【混装商品】。然后，选择【准备包装】。对于您计划发往亚马逊物流的所有 ASIN 按照此流程操作。然后，选择【包装混装商品】。此时将前往【第 1b 步】，您需要在此步骤中提供包装箱详情。提供包装箱详情后，选择【确认并继续】。

- 对于运送方式，选择【亚马逊运营中心】或【亚马逊仓储和分拨中心】。

**注意： **对于亚马逊仓储和分拨中心，亚马逊 SEND 仅支持海运。

- 选择【亚马逊 SEND】。

- 运输模式选择【空运】或【海运】。

- 选择入库配置选项： 根据您的需求选择亚马逊物流库存入库配置选项，以优化您的总物流费用。对于高级配置选项，卖家可以选择入库区域，例如东部、西部或中部。

**注意： **此处预计的入库配置服务费不包括承运人运费。承运人运费可能会因您选择的库存入库配置选项（如货件拆分数量和地区，如适用）而有所不同。有关更多信息，请参阅[亚马逊物流入库配置服务费](https://sellercentral.amazon.com/gp/help/external/GC3Q44PBK8BXQW3Z)。

- 为货件选择所需的发货日期和【取件或投件】选项。如果您打算进行投件，请在此页面的【亚马逊 SEND 运送要求】部分找到投件详情。

- 选择所需的亚马逊合 SEND 承运人，然后点击【继续选择发货方】。

- 点击【获取运费】，根据包装箱尺寸和重量生成预计承运人运费。此费用不包括美国海关收取的关税和其他附加费用。

- 在确认发货方后，输入适用于您货件的清关信息。

- **税号或增值税登记号：** 输入出口实体的税号或增值税登记号。

- **公司名称：** 输入出口实体的公司名称。

- **公司信息：** 添加或选择出口实体的公司地址。

- **起运地联系详情：** 输入起运地人员的详细联系信息，以方便亚马逊 SEND 协调取件事宜。

- **商品描述：** 对库存的完整描述以及预期用途说明。例如：非临床用体温计、洗发水、保湿洁面乳。请尽可能准确地描述，以免在清关时出现问题。

- 通过选中复选框来点击【接受费用】，即表示您接受费用并同意链接中包含的亚马逊 SEND 计划条款和条件。在货件送达后，我们将从您的卖家平台提现账户中扣除相应金额。

**注意： **最终费用将根据亚马逊 SEND 审计过程中核实的实际重量和尺寸以及运送期间产生的适用关税和附加费计算得出。有关更多信息，请参阅[亚马逊 SEND - 卖家条款和条件](https://sellercentral.amazon.com/gp/help/external/G27F6UHDSSHW6WXF)。

- 在您接受费用后，请下载亚马逊物流标签和承运人标签（如适用），并将标签粘贴到包装箱上。

- 确认发货后，请在 Send to Amazon 工作流程中下载和上传所需文件。

**注意： **对于您通过亚马逊 SEND 运送的首个 UPS 货件，您可能无法看到文件上传选项。承运人取件时，您需要向其提供纸质文件副本。对于后续货件，则可以在卖家平台中上传文件。

- 交接时，货件应附有必要的亚马逊物流标签、空运单或承运人标签（如适用）。

- 此外，亚马逊 SEND 可能会要求您提供此处未提及的其他文件，具体取决于您要运送的商品分类。

## 通过亚马逊 SEND 运送您的 AWD 货件

请按照以下步骤创建亚马逊物流 AWD 货件：

- 从【库存】下拉菜单中，选择【货件】。

- 在“货件处理进度”页面的“货件”下拉菜单中，选择【发送至亚马逊】。

- 在【发送至亚马逊】页面上，点击【创建 AWD 货件】。

您也可以从【库存】下拉菜单中选择【亚马逊智能卫星仓 (AWD】)，然后选择【发送至 AWD】 以创建货件。

或者，您也可以开始创建货件，前往[亚马逊智能卫星仓 (AWD)](https://sellercentral.amazon.com/asdn/about#learn-service)，导航至【管理服务】，然后点击【创建货件】。然后，您将转至【发往亚马逊智能卫星仓】工作流程。有关更多信息，请参阅[将货件运送至亚马逊智能卫星仓 (AWD)： 确认发货](https://sellercentral.amazon.com/gp/help/external/GQ6ZR5KNWKRBPT4M)。

## 亚马逊 SEND 运送要求

亚马逊 SEND 计划可提供多个承运人和多条运输路线，您可以通过该计划与承运人合作伙伴建立联系，以便将您的库存从您的场所运输至亚马逊运营中心。

选择以下亚马逊 SEND 承运人选项以查看相应指南和要求：

- [亚马逊 SEND - 韩国至美国： UPS 承运人（空运模式）](https://sellercentral.amazon.com/gp/help/external/GZT8YLZ4YGBML99H)

- [亚马逊 SEND - 韩国至美国： KW International 承运人（空运模式）](https://sellercentral.amazon.com/gp/help/external/GUG6LSFQSHTDF5C7)

- [亚马逊 SEND - 韩国至美国： KW International 承运人（海运模式）](https://sellercentral.amazon.com/gp/help/external/GDNXWN6CZZHF7N78)

## 亚马逊 SEND 付款和卖家费用

使用亚马逊 SEND 计划的卖家需要在货件送达后支付运费。运费将从卖家的提现账户中扣除。

请按照以下步骤查找您的亚马逊 SEND 承运人和海关费用详情：

- 要查看费用，请前往您的销售账户，选择【付款】下拉菜单，然后选择【交易一览】选项卡。

- 使用亚马逊物流或 AWD 货件编号查找您的交易。

## 亚马逊 SEND 商品运输资格

对于国际货件，不能通过亚马逊 SEND 计划运输危险品。

## 联系销售伙伴支持

如有任何疑问，请前往【帮助】下拉菜单，然后选择【获取帮助和资源】或使用卖家助手。选择 【AWD、运输和物流】选项，然后选择【亚马逊 SEND】。这将直接将您转到亚马逊 SEND 的支持服务。
