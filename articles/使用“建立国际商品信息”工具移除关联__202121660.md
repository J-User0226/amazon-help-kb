# 使用“建立国际商品信息”工具移除关联

您可以通过以下步骤移除来源商城与目标商城之间的关联：

1. 前往[建立国际商品信息](https://sellercentral.amazon.com/gp/global-selling/sync-offers)工具。
2. 从页面左侧的列表中，选择要断开关联的目标商城。
3. 点击【关联设置】小部件中的【移除关联】链接。
4. 在弹出窗口中，选择您要在移除关联之后保留还是删除目标商城中的商品。
  - 如果您选择保留目标商城中的商品，这些商品将保留在该目标商城中，但其商品价格将不再与来源商城中的商品同步。您需要手动维护这些商品。
  - 如果您选择删除目标商城中的商品，则只有与来源商城相关联的商品会被删除。其他所有商品均将保留下来。最长可能需要四小时的时间才能删除目标商城中的商品。您无法撤销此操作。

5. 点击【移除关联】确认您的选择并移除关联。

**注意： **出于以下一种或几种原因，亚马逊物流商品不会被删除，并且可能会保留“在售”状态，以防止亚马逊运营中心出现无在售信息的亚马逊库存：
- 商品在目标商城的亚马逊运营中心内有库存。
- 商品在过去 60 天内有销量，并且可能会被退回到目标商城的亚马逊运营中心。
- 商品库存正在运往目标商城的亚马逊运营中心的途中。
