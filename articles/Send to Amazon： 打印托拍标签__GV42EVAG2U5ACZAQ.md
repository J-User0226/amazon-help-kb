# Send to Amazon： 打印托拍标签

在 Send to Amazon 工作流程的第 4 步中确认托拍配置并接受运输的估算成本后，即可为您的托拍打印标签。

- 第 1 步：[选择要发送的库存](https://sellercentral.amazon.com/gp/help/external/G8SXKYFWPG6DAW6T)
- 第 1b 步：[包装单件商品](https://sellercentral.amazon.com/gp/help/external/GQ2HY393LHXF3GZN)
- 第 2 步：[确认发货](https://sellercentral.amazon.com/gp/help/external/GWC4BVUFCZ2FKHQW)
- 第 3 步：[打印箱子标签](https://sellercentral.amazon.com/gp/help/external/GCUH6KKZA6PRA4E7)
- 第 4 步：[确认承运人和托拍信息](https://sellercentral.amazon.com/gp/help/external/GBJBZ65P2LHZM2DG)（仅适用于托拍货件）
- **第 5 步：打印托拍标签**（仅适用于由亚马逊合作承运人配送的托拍货件）
- 最后一步：[追踪详情](https://sellercentral.amazon.com/gp/help/external/GWKTQ4PADXXT58JY)（适用于未使用亚马逊合作承运人的小包裹和托拍货件）

## 由亚马逊合作承运人配送的托拍货件
您通过[亚马逊合作承运人](https://sellercentral.amazon.com/gp/help/external/201119120)配送的每个托拍都必须贴有托拍标签，其中包含运营中心用以核实货件送达的信息。

系统将为您货件中的每个托拍生成一式四份标签。在托拍的四个侧面各贴上一份标签（贴于每个侧面的顶部中间位置，在拉伸膜外侧）。

**重要： **托拍货件的所有箱子还必须贴有亚马逊物流箱号标签。您可以在第 3 步[打印箱子标签](https://sellercentral.amazon.com/gp/help/external/GCUH6KKZA6PRA4E7)中打印这些标签。

要打印托拍标签，请按照以下步骤操作：

1. 在【打印托拍标签和文档】下选择托拍标签类型，然后点击【打印】。货件状态从【处理中】变为【准备发货】。
2. 将标签平直地（不要倾斜）贴在托拍的四面，以便叉车驾驶员能够看到标签。
3. 如果托拍只包含一种 ASIN 的商品，请为其贴上**单一 ASIN 托拍**标签。
4. 用一个托拍运输多个 SKU 时，请分隔不同的 SKU，以便运营中心在接收时能轻松分辨。

如果您使用亚马逊合作承运人，亚马逊将为您提供提货单。提货单将在取件日期当天上午生成。您必须向承运人提供有效的提货单，否则货件在送达时将被拒收。

**重要： **如果您使用亚马逊货运汽运零担配送计划发送货件，则需要额外粘贴亚马逊承运人托拍编号标签。每组一式四份亚马逊承运人托拍编号标签都是唯一的，必须与亚马逊物流托拍编号标签一起贴上。 有关更多信息，请参阅[亚马逊货运汽运零担配送服务](https://sellercentral.amazon.com/gp/help/external/GM9THX2S47XTGJTQ)。

**注意： **将托拍交给承运人后，您可以点击 Send to Amazon 页面底部的**追踪货件**链接，在“货件一览”页面上追踪库存的接收情况并查找货件差异查询信息。
