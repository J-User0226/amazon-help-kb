# 买家与卖家消息权限

如果您的公司有多人负责与买家沟通，您可以使用[买家与卖家消息](https://sellercentral.amazon.com/messaging/inbox)页面上的【消息权限】工具批准或禁止可用于与买家沟通的电子邮件地址。 **注意： **如果向买家发送消息的电子邮件地址不是买家与卖家消息中该账户的注册电子邮件地址或授权的电子邮件地址，那么系统将拒绝向买家发送消息。这些电子邮件消息需要在电子邮件地址获得授权后重新发送。

您可以在[消息权限](https://sellercentral.amazon.com/gp/communication-manager/address-authorization.html)页面批准或禁止发件人。

【消息权限】页面会显示以下内容：
- 在您的公司中已获得您的授权，可以通过买家与卖家消息服务向买家发送电子邮件的人员的电子邮件地址。
- 尚未获得批准或已禁止向买家发送消息的人员的电子邮件地址。

电子邮件地址可以是个人电子邮件别名，也可以是组织电子邮件地址别名（例如您公司的客户服务部门）。

要添加其他已授权的电子邮件地址或更改当前电子邮件地址的状态，请按照以下步骤操作：
1. 请访问[消息权限](https://sellercentral.amazon.com/gp/communication-manager/address-authorization.html)页面。
2. 点击“电子邮件”列底部的 【+ 添加电子邮件地址】。
3. 输入电子邮件地址，然后从“已批准”“已阻止”或“删除”选项中选择相应的状态。
4. 点击【保存】。

要更改之前输入的电子邮件地址的状态，请按照以下步骤操作：
1. 请访问[消息权限](https://sellercentral.amazon.com/gp/communication-manager/address-authorization.html)页面。
2. 点击【编辑】。
  1. 要将地址从“已阻止”更改为“已批准”，请在【已批准列】中点击单选按钮。
  2. 要将地址从“已批准”更改为“已阻止”，请在【已阻止列】中点击单选按钮。

3. 点击【保存】。

**注意： **您可以批准之前禁止的内部发件人，也可以禁止之前批准的内部发件人。但是，如果内部发件人的电子邮件地址已被批准或禁止，则不能将其删除。
