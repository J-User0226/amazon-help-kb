# 错误 18031

净盘点金额不是正数值，因此已被拒绝。

发生此错误的两个原因如下：

- 您提交的盘点金额超出了订单商品的余额。

- 您的盘点金额为零。

您可使用卖家平台的“管理订单”功能确定订单商品的未偿清余额。

要解决此错误，请提交一个大于零且未超过订单商品未偿清余额的盘点金额。有关更多信息，请参阅[订单盘点概览](https://sellercentral.amazon.com/gp/help/external/G200387280)了解 XML 上传数据，或请参阅[管理我的订单](https://sellercentral.amazon.com/orders-v3/ref=xx_myo_dnav_xx)页面。

**注意： **与商品数据不同，除非您想要进行多次盘点，否则您不应多次提交一个订单商品的盘点数据。如果不先移除已成功处理的数据就重新提交包含某些错误的整个盘点文件或上传数据，通常就会出现此错误。
