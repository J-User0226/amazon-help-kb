# 企业商品价格和数量折扣

**注意： **这些功能仅适用于参与专业销售计划的卖家。[了解更多信息](https://sellercentral.amazon.com/gp/help/external/201542150)。

作为亚马逊企业购卖家，您可以提供两种类型的折扣：

- **企业商品价格：** 仅为亚马逊企业购买家提供的折扣价，不限购买数量。
- **数量折扣：** 仅为亚马逊企业购买家的大批量采购提供的分段折扣。每个卖家可指定自己的数量定价分段。

提供企业商品价格和数量折扣可以帮助您吸引买家的注意，获得他们的信任，并最终促成交易。企业商品价格和数量折扣也有资格为企业订单减免费用。有关更多信息，请参阅[亚马逊企业购批量订单费用折扣](https://sellercentral.amazon.com/gp/help/external/GQBCQZZKZQ94LL55)和[亚马逊企业购亚马逊物流多件商品配送费用折扣](https://sellercentral.amazon.com/gp/help/external/GMZ5WFTZHCM4Q4C5)。

## 添加、编辑或删除企业商品价格和数量折扣
您可以使用[管理库存](https://sellercentral.amazon.com/inventory/ref=ag_invmgr_dnav_xx_)、上传数据或 XML 文件为商品添加、编辑和删除企业商品价格和数量折扣。要了解更多信息，请参阅以下页面：

- [使用上传数据添加企业商品价格和数量折扣](https://sellercentral.amazon.com/gp/help/external/201995470)
- [编辑企业商品价格和数量折扣](https://sellercentral.amazon.com/gp/help/external/201958240)
- [删除企业商品价格和数量折扣](https://sellercentral.amazon.com/gp/help/external/201958320)

您也可以使用[自动定价工具](https://sellercentral.amazon.com/automatepricing/home)，根据标准商品价格的变化设置和自动更新您的企业商品价格和数量折扣。有关更多信息，请参阅[创建企业商品定价规则](https://sellercentral.amazon.com/gp/help/external/GD29LN5JBS94EL4L)。

有关亚马逊企业购功能的更多信息，包括常见问题和故障排除信息的链接，请参阅[亚马逊企业购概览](https://sellercentral.amazon.com/gp/help/external/201542150)。有关企业商品定价的更多常见问题，请参阅[企业商品定价和数量折扣常见问题](https://sellercentral.amazon.com/gp/help/external/201824530)。
