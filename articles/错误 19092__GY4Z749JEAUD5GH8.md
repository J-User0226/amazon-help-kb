# 错误 19092

## 错误消息

${relationship_type} 具有无效的 child_id（不是 SKU）：${child_id}

## 导致错误 19092 的原因

出现此错误的原因如下：

- 提交的关系中包含的 child_id 与亚马逊目录系统中有效 SKU 编码的格式或结构不匹配，例如，child_id 字段包含 ASIN、商品编码、外部编码或其他非 SKU 值，而不是卖家的唯一 SKU（例如，提交了“B08N5WRWNW”作为 child_id，而该值应为卖家定义的 SKU，如“PROD-12345-RED-L”）。

- 提交的父子关系文件或 API 中的 child_id 字段为空或包含不符合 SKU 命名要求的无效字符，例如 SKU 中不允许使用的特殊字符、长度超过 40 个字符的限制或仅空格值。

- 卖家尝试使用未在其库存中创建为 SKU 的子商品编码创建变体关系，或 child_id 引用已删除的、从未在卖家账户中存在的或属于其他商城的 SKU。

- 由于在 SKU、ASIN、UPC、EAN 或其他商品编码之间存在混淆，导致提交的关系的 child_id 字段使用了错误的编码类型，而系统要求使用卖家的唯一 SKU，但收到了不同的编码类型。

- 批量关系文件包含格式错误，其中 child_id 列填充了错误来源字段的值或者包含系统生成的编码，而不是卖家分配的 SKU。

## 解决错误 19092

要解决此错误，请按照以下步骤操作：

- 验证您提交的关系中的每个 child_id 值是否为有效的 SKU：导航至库存并在卖家平台中选择管理所有库存，搜索每个子 SKU 以确认其存在于您的在售库存中，然后再将其包含到父子关系文件中。

- 更正关系提交文件中的 child_id 值：将任何 ASIN、UPC 或其他非 SKU 编码替换为实际的卖家 SKU 值，确保每个 child_id 与您库存中显示的 SKU 完全匹配，包括正确的大小写、空格和特殊字符。

- 检查您的上传数据文件模板，确保从包含 SKU 值的正确来源字段填充 child_id 列。

- 先在您的库存中创建任何缺失的子 SKU，再尝试建立父子关系：导航至目录并在卖家平台中选择添加商品，然后将每个子变体添加为具有各自唯一 SKU 的单独商品。

- 重新提交上传数据文件。
