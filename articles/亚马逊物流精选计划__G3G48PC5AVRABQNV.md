# 亚马逊物流精选计划

## 计划概览
FBA Select 是一项邀请制计划，专门面向在亚马逊商城销售买家需求量较高的商品的卖家开放。该计划将亚马逊的需求预测、网络优化功能与卖家的业务背景信息（例如促销活动、新品发布、季节性变动以及供货情况）相结合，助力卖家保持有货状态、降低成本，并实现更快的配送速度。

这种合作基于一个简单的见解：更好的输入才能带来更好的结果。亚马逊和卖家共同制定计划时，库存会离买家更近，从而提升配送速度，并降低供应链成本。卖家可以通过该计划了解未来 13 周的计划安排、提前预留的仓储容量以及提前预定的接收预约，即使是在旺季期间也可如此。此外，FBA Select 货件无需支付入库配置服务费，因为我们会与您共同规划发货量、发货频率和入库地点。对于已注册的 ASIN，如果在 90 天试用期后仍按照协作式计划保持合规发货，亚马逊将免除低库存水平费用。

## 为什么要加入 FBA Select？
FBA Select 可为您提供基础设施和计划工具，让您能够以更低的成本和更高的可预测性拓展您的亚马逊业务。

【更快的配送速度带来更高的销量】： 我们会将您的库存放在离买家更近的地方，从而实现次日达和当日达的配送承诺。如果商品的配送速度更快，买家发现商品的几率会更高，转化率也会更高。

【提前 13 周规划您的供应链】： 您会提前 13 周收到按照亚马逊的需求信号制定的前瞻性入库计划。借助该预见性，您无需猜测，即可同步采购、制造和物流等环节，从而消除淡季库存积压和旺季缺货的高成本循环。

【每周运送至 2~3 个区域】： 整合的入库计划会将每周的货件减少运送至 2~3 个区域，从而提高整车运输和整箱装载率。这样会减少每件商品的运输成本。您无需支付入库配置服务费，因为我们会与您共同规划发货量、发货频率和入库地点，并且您可以享受更低的库存仓储费，可直接降低您的商品成本。

【提前预留的容量】： 何时最需要 您会在第 4 季度和 Prime 会员日期间收到提前预留的仓储空间和提前预定的接收预约，确保您的供应链在容量最受限的旺季期间顺利运营

【直接向入库计划提供信息】： 您向亚马逊提供您的业务背景信息（即将推出的促销活动、新品发布和生命周期终结的 ASIN），我们会将这些信息整合到为您定制的入库计划中。这取代了标准的“一刀切”方式，转为采用可体现您实际业务日程的规划方式。

## 计划权益
- 更快的配送速度，助力提高转化率
- 即使在旺季，也可提前预留仓储容量和提前预定接收预约
- 通过将货件合并发往更少的亚马逊接收点，降低入库运输成本
- 无入库配置服务费；对于符合约定入库计划的已注册 ASIN，在 90 天试用期后免除低库存水平费用

要了解有关该计划权益的更多信息，请参阅 [FBA Select 权益](https://sellercentral.amazon.com/help/hub/reference/GD4P4VDPDZPLSCGC)。

## FBA Select 的运作方式
FBA Select 将入库计划分为三阶式流程：一次性注册以配置您的设置，制定定期协作式计划周期以检查并确认入库计划，以及开展月度业务审核以追踪绩效。
1. 【注册（一次性设置）】
2. 在卖家平台配置您的 FBA Select 设置。注册时，您将看到一份符合要求的 ASIN 预填充列表，这些 ASIN 均来自您的商品组合。默认情况下，包含您商品组合中的所有标准的非危险品 ASIN。您可以查看此列表，并在您认为合适的情况下添加或移除 ASIN。对已注册 ASIN 所做的任何更改都将在下一次入库计划中体现。

3. 【ASIN 注册要求】： 为最大限度地享受计划权益并保持符合资格条件，您必须在 90 天试用期后为您至少 80% 的高周转 ASIN（过去 8 周内每周销量超过 100 件的 ASIN）注册并主动使用 FBA Select。此阈值可确保亚马逊拥有足够的规模，从而能够优化库存定位，并显著提升配送速度。

4. 注册期间，默认包含所有符合要求的 ASIN。您可以移除特定 ASIN，但我们建议您注册完整的标准商品组合，以最大限度地享受权益。您可以随时通过配置设置来调整已注册的 ASIN

5. 您还可以随时通过配置设置来修改您的入库频率、库房地址、备货时间、每周最大发货容量以及运输模式首选项。

6. 要了解有关卖家注册和配置设置的更多信息，请参阅 [FBA Select 卖家配置设置](https://sellercentral.amazon.com/help/hub/reference/GL2SG9ZZJVKUBS8J)。

7. 【协作式计划（定期）】
8. 在每个计划周期中，亚马逊都会生成未来 13 周的入库计划，该计划经过优化，旨在将库存放在离买家更近的地方，从而支持次日达和当日达的配送承诺。该计划将货件合并发往仅 2~3 个区域，从而降低运输复杂性和成本。

9. **注意： **这一 13 周计划清晰显示了供应商协调与采购计划情况。您仅可在查看并确认未来 2~3 周（您当前和下一个计划周期）的货件。剩余周数仅供查看计划内容，并不构成任何承诺。

  1. 【查看您的计划】： 亚马逊为您提供下一周期的建议的入库计划，包括您的已注册 ASIN 的数量、目的地以及时间。
  2. 【分享您的输入内容】（可选但建议您这样做）： 提供您的需求预测和供应状况（促销、新上线或供应限制），帮助改进计划。
  3. 【确认并配送】： 在您确认后，系统会在您的卖家平台账户中自动创建货件，以便通过标准的 Send to Amazon 工作流程完成相关操作。

10. 要了解有关入库计划创建和协作式计划的更多信息，请参阅 [FBA Select 协作式计划概览](https://sellercentral.amazon.com/help/hub/reference/GAGYPRTP62VW2APL)。

11. 【进度追踪】
12. 亚马逊将分享月度业务审核指标来追踪配送速度的改进情况、节省的运输成本以及整体计划绩效。前 90 天为试用期，在此期间，亚马逊会与您密切合作，以深入了解您的供应链设置，并帮助您满足计划要求。在试用期结束后，卖家应持续符合该计划的绩效阈值要求。

13. 要了解有关绩效衡量和合规性的更多信息，请参阅 [FBA Select 绩效衡量](https://sellercentral.amazon.com/help/hub/reference/GRSM6BNT5KTWF2MX)。
