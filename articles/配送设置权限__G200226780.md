# 配送设置权限

【配送设置】页面位于【设置】下拉菜单中的[配送设置](https://sellercentral.amazon.com/sbr)下（导航栏右上角的齿轮图标），仅供有权修改账户设置的账户用户使用。如果您没有权限，则只有您账户的主账户持有人（而非亚马逊）才能为您授予该权限。主账户持有人是指最初在亚马逊商城注册开店的人。

主账户持有人可以通过[用户权限](https://sellercentral.amazon.com/gp/account-manager/home.html)页面为用户授予权限，具体步骤如下：

- 前往 【设置】 > 【用户权限】 。

- 在【用户权限】页面上，添加一个用户或选择一个现有用户，然后点击【管理权限】。

- 向下滚动到【设置】部分，然后找到【配送设置】。

- 从三个配送设置权限级别中选择一个：

| 无 | 此类用户没有访问配送设置的权限。 |
| --- | --- |
| 查看 | 此类用户仅可查看配送设置。 |
| 查看和编辑 | 此类用户可以创建和修改配送设置。 |

**警告： **主账户持有人应谨慎操作，切勿向无权创建或修改配送条款的用户授予**查看和编辑**权限。
