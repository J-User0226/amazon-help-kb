# “举报侵权”表： 批量输入 ASIN

在[举报侵权表单](https://www.amazon.com/report/infringement)，您可以通过输入包含最多 50 个 ASIN 的逗号分隔列表和/或关联的亚马逊商品详情页面 URL，发起针对多个商品的举报。在搜索字段中输入列表并点击【搜索】。搜索结果会包含您搜索的特定 ASIN，包括从 URL 中解析出的 ASIN。

要获得完整的搜索结果，请确保列表的格式正确。输入的每个 ASIN 或 URL 均应使用逗号分隔，如以下示例所示。

**ASIN：**

B01DFKC2SO, B01J24C0TI

**URL：**

https://www.amazon.com/Amazon-Echo-Show-Alexa-Enabled-Black/dp/B01J24C0TI, https://www.amazon.com/Amazon-Echo-Dot-Portable-Bluetooth-Speaker-with-Alexa-Black/dp/B01DFKC2SO/ref=sr_1_6?ie=UTF8&qid=1514490339&sr=8-6&keywords=Echo+show+plus

**ASIN 和 URL：**

B01DFKC2SO, B01J24C0TI, https://www.amazon.com/Amazon-Echo-Show-Alexa-Enabled-Black/dp/B01J24C0TI, https://www.amazon.com/Amazon-Echo-Dot-Portable-Bluetooth-Speaker-with-Alexa-Black/dp/B01DFKC2SO/ref=sr_1_6?ie=UTF8&qid=1514490339&sr=8-6&keywords=Echo+show+plus

批量输入工具将会针对您输入的有效 ASIN 或 URL 返回结果。

如果您的批量输入包含无效的 ASIN 或 URL，则会在有效结果上方的搜索栏中列出这些 ASIN 或 URL，并显示文本“我们无法处理该行上方包含的数据”。 您可以直接在搜索栏中对无效的 ASIN 或 URL 进行编辑，确保用逗号将其隔开，然后再次点击【搜索】以重新处理整个 ASIN 列表。

**注意： **同一商品在不同的亚马逊商城（如 amazon.co.uk 和 amazon.com）可能会具有不同的 ASIN。确保您输入的 ASIN 在您登录的商城中有效。

## 常见问题

**什么是 ASIN？**

亚马逊商品编码 (ASIN) 由 10 个字母或数字组成，是用于在亚马逊商城中标识商品的唯一编码。您可以在商品的商品详情页面上找到 ASIN。

**什么是亚马逊商品详情页面 URL？**

亚马逊商品详情页面 URL 是您在亚马逊商城上查看某一商品的详情页面时显示在浏览器地址栏中的 URL。有效的商品详情页面 URL 包含商品的 ASIN。

**最多可以输入多少个 ASIN 和/或 URL？**

您最多可以输入 50 个 ASIN 或商品的 URL。
