# Error 100339

## Error message

Remove any non-compliant mark-up from attribute ${attribute_name} to ensure your data meets with Amazon's guidelines: Don’t use HTML, JavaScript, or other types of code in your product detail pages.

## Reason for error 100339

This error occurs for the following reasons:

- Product descriptions, titles, bullet points other fields contain HTML tags such as <p>, <br>, or <strong>, markup language, or formatting code that isn't permitted.

- JavaScript or other programming code has been included in product detail fields, either intentionally or through copy-paste errors.

- Special characters, CSS styling, or webpage formatting elements appear in product attributes.

## Resolve error 100339

To resolve the error, follow these steps:

- Review your feed processing summary report for highlighted attribute and remove any HTML tags such as <b>, <i>, <p>, <br>, or any other code elements.

- Convert the content to plain text format, ensuring all styling and formatting is removed.

- Check your product titles, bullet points, descriptions, generic keywords and ensure no special formatting like bullet points created with HTML, JavaScript snippets, or website styling codes are used.

- Resubmit your file after updating the attribute value.

- For more information, refer to [Product title requirements and guidelines](https://sellercentral.amazon.com/help/hub/reference/GYTR6SYGFA5E3EQC) and [Product bullet points requirements](https://sellercentral.amazon.com/help/hub/reference/GX5L8BF8GLMML6CX).
