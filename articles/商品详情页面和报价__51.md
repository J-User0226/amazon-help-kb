# 商品详情页面和报价

买家可以在商品详情页面中看到亚马逊上销售的唯一商品。其中可以包含来自卖家或亚马逊的一个或多个报价。

该页面是一个共享的页面，可以显示一个商品的所有报价的共同属性，例如：
- 商品名称
- 图片
- 要点
- 描述
- 商品变体（如尺寸或颜色）
- 买家评论

某些分类具有额外的商品详情属性。以“电子产品”分类为例，相机的光学变焦和最大分辨率等属性是其他商品分类不需要提供的。

您和其他卖家可以在商品详情页面上发布报价。您可以针对某个商品创建并控制自己的报价，包括商品价格、配送选项、状况及其他属性。如果亚马逊商城上没有某款商品，您可以提交新商品信息的请求，然后亚马逊将创建一个新的商品详情页面。亚马逊根据制造商和卖家提供的数据来选择要在商品详情页面中包含哪些信息。有关更多信息，请参阅[了解商品详情页面](https://sellercentral.amazon.com/gp/help/external/G201911450)。 **注意： **对于新注册的卖家，注册之后可能需要等待 90 分钟或更长的时间，才能在亚马逊上发布商品进行销售。

## 演示商品详情页面
​了解商品详情页面，包括如何发布商品和创建变体。从【目录】下拉菜单中选择[添加商品](https://sellercentral.amazon.com/hz/productsearch)。在【添加商品】页面，请参阅“关于添加商品”部分。

请参阅以下链接，了解有关商品详情页面和向商品添加商品的更多信息：
- [如何发布没有 GTIN（UPC、EAN、JAN 或 ISBN）的商品](https://sellercentral.amazon.com/gp/help/external/G200426310)
- [ASIN 创建政策](https://sellercentral.amazon.com/gp/help/external/G201844590)
- [改善商品信息](https://sellercentral.amazon.com/gp/help/external/200403880?language=en_US&ref=ag_200403880_cont_G51)

## 使用卖家平台添加新商品报价
使用卖家平台中的“库存”工具搜索已有商品详情页面的商品，以添加您的报价。

如果您拥有专业销售计划，则可以下载库存文件模板来帮助您批量上传大量商品报价。从【目录】下拉菜单中选择[批量上传商品](https://sellercentral.amazon.com/hz/inventory/addproducts)，开始这一操作过程。

如果您提供少量商品，或者如果您没有专业销售计划，您可以使用下述方法每次添加一件商品。

1. 从【目录】下拉菜单中选择[添加商品](https://sellercentral.amazon.com/hz/productsearch)。

2. 在亚马逊搜索您想要出售的商品。 **注意： **如果搜索商品编码（如 UPC、EAN、JAN 或 ISBN），可获得更准确的搜索结果。

3. 对于您要发布的商品，请点击对应的【销售此商品】按钮。 **重要： **点击【销售此商品】后，查看亚马逊开店服务卖家平台页面上提供的任何限制。如果您发现自己未获准添加此商品，请点击【了解更多】链接。

4. 如果您获得添加商品的批准，系统将转至【“报价”】页面。

5. 添加报价详情，包括商品价格、数量、状况及配送选项。

6. 保存所做的更改。

## 将商品添加到亚马逊目录
如果您在亚马逊没有找到某一商品，您可以提交商品信息，以便亚马逊创建新的商品详情页面。详情页面由提供相同商品的所有卖家共享。

1. 从【目录】下拉菜单中选择[添加商品](https://sellercentral.amazon.com/hz/productsearch)。

2. 点击【我要添加未在亚马逊销售的新商品】。

3. 输入所需信息，该信息将在工作流程的选项卡之间以红色高亮显示。

4. 在提供的选项卡中输入必填信息后，您可以点击【提交】。
