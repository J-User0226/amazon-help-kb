# 亚马逊 SEND 计划

借助亚马逊 SEND 计划，您可以通过亚马逊 SEND 承运人将您的亚马逊物流 (FBA) 库存从一个国家/地区运往另一个国家/地区的亚马逊运营中心。您可以利用该计划以经济高效的方式将 FBA 货件和 AWD 货件运送到全球各地。亚马逊 SEND 支持空运、海运和陆运服务。

承运人取走您的货件后，会负责处理从清关到送达亚马逊运营中心和 AWD 库房的端到端运输事宜。您可以让承运人上门取件，也可以将货件投递至承运人网点。

**注意： **亚马逊 SEND 计划的起运地为：印度、越南、泰国、韩国、中国台湾、中国、墨西哥、英国、德国和土耳其，目的地为美国。

## 亚马逊 SEND 的主要优势

- **有竞争力的费率和顺畅的付款流程**

亚马逊会约定具有竞争力的运费，卖家将通过卖家平台直接付款。

- **上门取件和上门送货**

承运人从您的场所取件，并将其直接运送至运营中心或 AWD 库房。

- **在卖家平台中管理所有操作**

在一个位置集中创建货件、选择承运人、追踪包裹和管理付款。

- **海关服务支持**

承运人同时负责起运地和目的地的海关文件，但卖家仍然需要遵守所有适用的进出口法规。

- **端到端追踪**

在卖家平台中实时查看包裹的最新动向，监测货件状态。

- **及时支持**

通过【帮助】 > 【获取帮助和资源】 > 【AWD 运输和物流】 > 【亚马逊 SEND】 联系训练有素的员工，获取有关 SEND 问题的帮助。

**注意： **亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。

## 亚马逊 SEND 付款和卖家费用

使用亚马逊 SEND 计划的卖家需要在货件送达后支付运费。运费将从卖家的提现账户中扣除。

请按照以下步骤查找您的亚马逊 SEND 承运人和海关费用详情：

- 要查看费用，请前往您的销售账户，选择【付款】下拉菜单，然后选择【交易一览】选项卡。

- 使用亚马逊物流或 AWD 货件编号查找您的交易。

## 亚马逊 SEND 商品运输资格

对于国际货件，不能通过亚马逊 SEND 计划运输危险品。
