# 如果买家想移除反馈

买家可以删除卖家反馈，但是应以他们自己的意愿为准。当买家移除反馈时，您的平均评级将会更新。当反馈符合以下标准时，亚马逊会将其删除：
- 反馈包含脏话、淫秽内容或在公共论坛上通常被认为不恰当的语言。
- 反馈包含仇恨言论。
- 反馈中包含个人身份信息，包括电子邮件地址、全名或电话号码。
- 反馈涉及其他卖家销售的商品。
- 反馈涉及您作为品牌所有者或授权转销商的商品。
- 整条反馈评论是商品评论。例如：“Acme Super-Widget 没有 Acme Ultra Widget 那么清晰、快速。”

**注意： **仇恨言论是基于种族、族裔、国籍、性别、性别认同、性取向、宗教、年龄和残疾等特征表达对他人的仇恨的语言。

如果您想移除符合我们标准的错误反馈，可以按照以下步骤请求审核反馈：
1. 前往[反馈管理器](https://sellercentral.amazon.com/feedback-manager/index.html#/)。
2. 在**最新反馈**表中的特定**订单编号**旁边，选择**操作**列下的**请求审核**。
3. 在弹出窗口中，完成以下操作：
  - **选择原因：** 根据您的特定使用情形，从下拉菜单中选择一个符合我们移除政策的原因。
  - **备注：** 您可以在申诉中添加备注，以提供证据说明该反馈为何不符合我们的政策。

4. 选择**提交**。

提交后，您可以在“管理审核请求”选项卡中追踪您的请求。有关您的争议状态的详情，请参阅[关于反馈管理器](https://sellercentral.amazon.com/help/hub/reference/external/G761)。

有关更多信息，请参阅[亚马逊可以移除买家反馈吗？](https://sellercentral.amazon.com/gp/help/external/G20231)

要解决买家关于订单或客户服务的问题，您可以使用以下选项之一联系买家：

**使用反馈管理器**
1. 在【绩效】选项卡下选择[反馈](https://sellercentral.amazon.com/feedback-manager/index.html#/)。
2. 在【最新反馈】表中，前往【操作】列。点击【选择一个】下拉菜单，然后选择【联系买家】。

**使用[买家与卖家消息服务模板](https://sellercentral.amazon.com/messaging/templates)**

您只能使用“买家与卖家消息服务”模板就订单或客户服务问题联系买家。请勿要求买家删除负面反馈，也不要为正面反馈或反馈删除提供补偿或其他奖励。

有关更多信息，请参阅[买家与卖家消息服务的电子邮件模板](https://sellercentral.amazon.com/gp/help/external/G201109160)。

有关更多信息，请参阅[禁止的卖家活动和行为](https://sellercentral.amazon.com/gp/help/external/G200386250)。
