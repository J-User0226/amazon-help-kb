# 礼品包装扣款费用

如果买家支付了亚马逊物流 (FBA) 订单的礼品包装费，亚马逊将针对该货件中的每件商品收取礼品包装扣款费用。此费用可让亚马逊收回向买家收取的礼品包装费。

## 礼品包装扣款费用详情

| 详情 | 描述 |
| --- | --- |
| 费用金额 | 费用金额等于买家为该商品支付的礼品包装费（不含税） |
| 货币 | 美元 |
| 税务处理方式 | 不含税（费用金额中不包含税费） |
| 费用构成 | 的全额礼品包装费（不含税） |

**费用示例**

**示例 1：** 买家在 Amazon.com 下单并支付 3.99 美元的礼品包装费。亚马逊通过亚马逊物流配送此订单。

卖家需要支付 3.99 美元的礼品包装扣款费用，该费用等于买家为该商品支付的全额礼品包装费。

**示例 2：** 买家在 Amazon.ca 下单，该订单包含三个货件行项目，且合并成一个货件发货，并为其中两个行项目选择了礼品包装服务。礼品包装费如下所示：

- 行项目 1： 3.99 美元（礼品包装）

- 行项目 2： 4.49 美元（礼品包装）

- 行项目 3： 未选择礼品包装

亚马逊通过亚马逊物流配送此订单。卖家只需为买家支付了礼品包装费的行项目支付礼品包装扣款费用：

- 行项目 1： 3.99 美元

- 行项目 2： 4.49 美元

- 行项目 3： 不收费（未选择礼品包装）

- **礼品包装扣款费用总额： 8.48 美元**

礼品包装扣款费用按货件行项目级别收取，因此每个行项目的费用将分别基于买家支付的礼品包装费收取。无需礼品包装的行项目不予收费。

## 常见问题

#### 什么是礼品包装扣款费用？

礼品包装扣款费用是指在买家支付礼品包装费时对亚马逊物流 (FBA) 订单收取的费用。由于亚马逊负责配送事宜，因此此费用是亚马逊收回买家所支付礼品包装费的方式。

#### 如何计算礼品包装扣款费用？

该费用等于买家为相应货件行项目支付的全额礼品包装费（不含税）。它并非固定费用，而是根据每个订单的礼品包装费而变化。

#### 礼品包装扣款费用是否含税？

否。对于 Amazon.com（美国）商城，礼品包装扣款费用不含税，即，此费用金额中不包含税费。

#### 如果买家通过促销获得免费礼品包装，我是否仍需支付这笔费用？

否。如果买家符合免费礼品包装条件，则买家无需支付礼品包装费，卖家账户也不会收到礼品包装金额，因此不会产生礼品包装扣款费用。

#### 如果买家退回商品，会怎么样？ 扣款费用会退还吗？

是。如果买家退回商品且已处理退款，礼品包装扣款将按买家退款金额的比例退还。如果原礼品包装免费，则不会退还扣款。

#### 其他亚马逊商城是否有类似的扣款费用？

是的，全球所有的亚马逊商城均收取扣款费用。

#### 礼品包装扣款是否适用于 Seller Flex 订单？

不适用。如果您已加入 Seller Flex 计划，则您的订单不会被收取礼品包装扣款费用。由于您在自己的库房管理包装和礼品包装，亚马逊不会针对 Seller Flex 订单扣收礼品包装金额。

#### 在哪里可以查看我的礼品包装扣款费用？

您可以通过【付款报告】查看向您的账户收取的礼品包装扣款费用：

- 在卖家平台中，选择【报告】下的【付款】。

- 在付款控制面板上选择【交易一览】。

- 选择【交易类型】为【订单付款】。

- 选择日期范围，然后点击【更新】。

- 查找【商品详情】列为【礼品包装扣款】的交易。
