# 根本原因洞察定义

## 根本原因洞察定义

本页面提供了针对某些商品在“买家之声”页面上显示的根本原因，具体取决于买家评论的根本原因。

我们利用基于机器学习的摘要技术来获得驱动因素和根本原因。这些根本原因直接来自买家的问题，并归入相应的根本原因。

请注意，只有当我们的机器学习模型能够将买家反馈与这些洞察信息和定义相匹配时，才会提供这些洞察信息。在某些情况下，您不会发现您的商品存在这些并不显眼的根本原因。

| 根本原因 | 定义 |
| --- | --- |
| 外观问题 | 买家体验不佳是受到商品外观而非残损或瑕疵的影响。 |
| 真伪问题 | 买家对商品的真伪有疑虑。 |
| 图书真伪问题 | 买家对图书或相关商品的真伪有疑虑。 |
| 制造品质问题 | 买家担心商品质量不佳。这包括偷工减料、工艺不良和不稳定问题。 |
| 颜色问题 | 买家对商品颜色有疑问。这包括商品颜色、商品脏污或商品变色方面的问题。 |
| 商品描述相关问题 | 买家对商品描述、文字拼写和语法等有疑问。这些问题常见于图书类商品，但也可能在其他商品中出现。 |
| 原产国或原产地 | 有关外文商品描述或制造国家/地区的问题。 |
| 脏污问题 | 买家声称收到的商品脏污，有头发等。 |
| 不起作用 | 买家已收到商品，但商品没有反应，无法使用。 |
| 耐用性 | 买家对商品的耐用性有疑问，例如，商品使用时间不长就出了问题。 |
| 容易造成瑕疵 | 如果商品导致其他商品出现划痕、瑕疵或残损。 |
| 过期问题 | 如果买家收到过期商品。 |
| 适合性问题 | 如果商品不适合，或者商品不兼容。 |
| 难以使用 | 商品不适合使用、难以安装或难以使用。 |
| 说明问题 | 如果商品在没有解释或说明的情况下送达，或者如果说明不清楚。 |
| 商品状况问题 | 买家对商品状况有疑虑。例如，买家购买了新商品，但商品看上去并不像新品。 |
| 材料问题 | 买家对商品材质有疑虑。 |
| 细微商品瑕疵 | 商品送达时有刮伤、污渍和划痕等。与外观问题不同，表面瑕疵是指存在轻微的物理残损。 |
| 误导性商品信息 | 买家对虚假、不准确或误导性广告问题（主要是在商品详情页面上）存在疑虑。 |
| 缺少问题 | 如果买家表示商品缺少一部分或缺少整个商品。 |
| 非商品质量问题 | 买家担心的问题与商品质量不直接相关。 |
| 已开封状况 | 买家对已开封商品有疑虑。 |
| 印刷质量差 | 买家对图书或其他媒介类商品的质量有疑虑。 |
| 商品性能差 | 与商品功能相关的瑕疵。 |
| 商品编码问题 | 商品编码读取问题。 |
| 商品已残损 | 与商品相关的问题，例如送达时破损、弯曲、凹陷、开裂或破碎等。 |
| 商品包装问题 | 与商品包装相关的问题，例如送达时破损、弯曲、凹陷、开裂或破碎等。 |
| 商品变质 | 与商品变质相关的问题。此类问题包括消费类商品发霉、粘连等。 |
| 随机错误商品 | 买家声称收到随机错误商品。 |
| 相关错误商品 | 买家声称收到相关错误商品。这包括不同的版本或款式等。 |
| 安全问题 | 买家关注的是与商品相关的安全问题。 |
| 密封问题 | 买家因商品密封而产生了负面体验。这包括商品或包装缺少密封或密封损坏。 |
| 货件包装问题 | 买家对货件包装有疑虑，例如送达时破损、弯曲、凹陷、开裂或破碎等。 |
| 气味问题 | 买家对商品的气味有疑虑。 |
| 即将过期 | 买家收到的商品即将过期。 |
| 声音问题 | 买家对商品的声音或音质有疑虑。 |
| 口感问题 | 买家对商品的口感或风味有疑虑。 |
| 不具体的质量问题 | 买家对于一般质量问题的顾虑，没有具体的根本原因。 |
