# 错误 5008

操作不受支持。

有关更多详情，请参阅 http://sellercentral.amazon.com/gp/help/external/23111

如果您提交**库存文件**后收到此错误，则说明您在更新-删除列中提供了除“更新”或“删除”之外的值。请填入其中一个有效值并重新提交。

如果您发布**数据源**后收到此错误，则说明您在 XML 信封中提供了除“更新”或“删除”之外的“操作类型”值。请填入其中一个有效值并重新发布文档。

如果您提交 **XML 商品信息上传数据**后收到此错误，则说明您为某条消息提供了除“更新”、“部分更新、或“删除”之外的“操作类型”值。请确保您的所有“操作类型”根据操作的类型使用这些值中的一个，并重新提交上传数据。
