# 儿童安全保护带系统、儿童增高椅和旅行装置

如果您要在亚马逊商城发布商品，则必须遵守与这些商品和商品信息相关的所有适用法律、法规、标准以及亚马逊政策。

## 亚马逊儿童安全保护带系统、儿童增高椅和旅行装置政策

儿童安全保护带系统，也称为儿童安全座椅、增高座椅或婴儿安全座椅，是一种可拆卸装置，可以与汽车座椅一起使用，以便在车辆碰撞期间约束并保护儿童免受伤害或死亡。儿童安全保护带系统是一种具有刚性或半刚性框架的商品，含有垫子或泡沫材料，以便在发生碰撞时提供保护。

**前向式儿童安全保护带系统**

前向式儿童安全保护带系统是一种可拆卸装置，可以固定儿童，使其面向机动车行驶的方向。它配有安全带和系绳，可以在发生碰撞期间限制您的孩子向前移动。

**后向式儿童安全保护带系统**

后向式儿童安全保护带系统是一种可拆卸装置，可以固定儿童，使其面向与机动车行驶方向相反的方向。

**婴儿安全保护带系统**

婴儿安全保护带系统是一种可拆卸装置，可作为新生儿和婴幼儿提篮。婴儿提篮有一个向后倾的靠背（与水平方向呈 10° 以上的角）。本政策适用于旅行装置、婴儿提篮和婴儿安全座椅底座，包括无提篮的独立底座。旅行装置包括全尺寸独立婴儿手推车，配备可卡入婴儿手推车的兼容婴儿汽车安全座椅。

**机动车儿童增高椅**

机动车儿童增高椅是一种可拆卸装置，可以抬升和固定儿童，以便汽车的三点式安全带能够正确贴合儿童身体的强健部位：臀部和胸部。儿童增高椅并非像儿童安全座椅那样牢固地安装在车辆内。儿童增高椅依靠儿童自重和汽车的三点式安全带来固定。儿童增高椅是一种无靠背的儿童安全保护带系统或安全带固定座椅。

无靠背的儿童乘员用约束系统包含 (1) 一个不能向上拉伸来用软垫保护儿童背部或头部的座椅，以及 (2) 一个可在产生前冲力时防止儿童身体前移的结构组件。

安全带固定座椅可以 (i) 将儿童固定在车座上，让汽车安全带系统更加适合儿童，并且 (ii) 不具备可在汽车产生向前的冲击力时能够防止儿童身体向前移动的组件，如安全带系统或结构组件。

**织物儿童安全保护带系统**

织物儿童安全保护带系统，又称织物儿童安全座椅，是指由织物（例如尼龙或棉）制成的商品，带有带子、夹子和衬垫。它们用于在汽车内约束儿童。此类商品没有任何金属或硬塑料框架。可折叠而且轻巧。

## 适用的法律、法规和标准

亚马逊要求所有其他儿童安全保护带系统、儿童增高椅和旅行装置均符合适用的法律、法规和标准，包括：

| 商品 | 法律、法规和标准 |
| --- | --- |
| 前向式儿童乘员用约束系统 | 消费品安全改进法案第 101 条（铅） FMVSS 第 213 号（联邦机动车安全标准第 213 号 - 儿童安全保护带系统） |
| 后向式儿童安全保护带系统 | |
| 儿童增高椅（无靠背，安全带固定） | |
| 婴儿提篮 | 以下所有项： 消费品安全改进法案第 101 条（铅） FMVSS 第 213 号（联邦机动车安全标准第 213 号 - 儿童安全保护带系统） 美国材料实验协会 F2050-19（婴儿提篮安全标准） |
| 旅行装置（可折叠儿童安全保护带系统，包括带坐式婴儿车的装置） | 以下所有项： 消费品安全改进法案第 101 条（铅） FMVSS 213（联邦机动车安全标准第 213 号 - 儿童安全保护带系统） 美国材料实验协会 F833-19（卧式婴儿车和坐式婴儿车安全标准） 美国材料实验协会 F2050-19（婴儿提篮安全标准） |
