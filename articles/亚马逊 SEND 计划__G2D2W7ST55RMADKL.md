# 亚马逊 SEND 计划

借助亚马逊 SEND 计划，您可以通过亚马逊合作承运人将您的亚马逊物流（“FBA”）库存从**一个国家/地区**运送至另一国家/地区的亚马逊运营中心。您可以利用该计划以经济高效的方式将亚马逊物流货件运送到全球各地。目前，从中国至墨西哥的亚马逊 SEND 支持空运模式。

承运人会在取走您的货件后处理从清关到送达亚马逊运营中心的端到端运输事宜。您可以让承运人上门取件，也可以将货件投递至承运人网点。

**注意： **亚马逊 SEND 计划现已开通从中国启运地至墨西哥的货运服务。

**主要优势**

- **有竞争力的费率和顺畅的付款流程**

- 亚马逊会约定具有竞争力的运费，卖家将通过卖家平台直接付款。

- **上门取件和上门送货**

- 承运人会从您所在地点取件，并将其直接发往运营中心。

- **在卖家平台中管理所有操作**

- 创建货件、选择承运人、追踪包裹，均可一站式完成。

- **海关服务支持**

- 承运人同时负责起运地和目的地的海关文件，但卖家仍然需要遵守所有适用的进出口法规。

- **端到端追踪**

- 在卖家平台中实时查看包裹的最新动向，监测货件状态。

- **及时支持**

- 您可以通过亚马逊销售伙伴支持上报问题，亚马逊 SEND 团队可以帮助您联系亚马逊 SEND 承运人以解决您的问题。创建支持问题单时，请务必注明此货件为亚马逊 SEND 货件，并提供所有相关详情，例如货件编号、承运人名称和问题描述，以便我们更好地为您提供帮助。

**亚马逊 SEND： 支持的路线**

亚马逊 SEND 可以帮助您与经批准的承运人合作伙伴联系，将您的库存从您所在地点运输至亚马逊运营中心。许多配送路线都提供有多种承运人选项 — 在选择合作承运人时，请务必查看所有指南和要求。

- 亚马逊 SEND：中国至墨西哥

**付款和卖家费用**

使用亚马逊 SEND 计划的卖家需要在首次发货前与 360Lion 签订合同，并直接向承运人支付相应费用。

**危险品**

不得通过亚马逊 SEND 计划跨境运输危险品与危险物质。
