# 取消一件商品、一个订单或多个订单

您可以从[管理订单](https://sellercentral.amazon.com/gp/orders-v2/list/)页面取消任何未发货的商品或订单。在您取消商品或订单后，亚马逊将向买家发送取消电子邮件。

## 取消一个订单
1. 在【管理订单】页面上，找到您想要取消的订单。

2. 点击【操作】列中的【取消订单】。

3. 在【取消订单】页面上，选择【取消原因】。您还可以在**卖家备注**字段中输入您想要追踪的任何信息。

4. 点击【提交】。

## 取消多个订单
您还可以使用以下一种方法取消多个订单：

- 专业卖家还可以通过上传订单取消文件来取消多个订单。请参阅[取消多个订单](https://sellercentral.amazon.com/gp/help/external/50791)。

**注意： **我们希望卖家能够确保库存水平准确无误。如果未及时调整您的库存，可能会导致过多订单在配送前取消。有关我们如何将已取消订单计入您整体绩效的信息，请参阅[买家指标](https://sellercentral.amazon.com/gp/help/external/200205250)。

## 部分退款
有时，您可能需要取消一个包含多件商品的订单中的部分商品，并针对已取消的商品退款。如果您使用库存文件管理订单，则可以上传[订单调整上传数据](https://sellercentral.amazon.com/gp/help/external/1611)。

要取消一个多商品订单中的部分商品或为部分商品退款，请按照以下步骤操作：

1. 对您可以配送的所有商品发货并确认发货。

2. 使用[订单调整上传数据](https://sellercentral.amazon.com/gp/help/external/200387280)为您无法配送的订单商品提交退款。在上传数据中提供以下信息：
  - 已取消的商品数量： 无法配送的商品数量。
  - 盘点原因： 退款代码。选择 【NoInventory】 或 【CustomerCancel】。

有关更多信息，请参阅[退款订单 - 订单调整上传数据](https://sellercentral.amazon.com/gp/help/external/200387280)。
