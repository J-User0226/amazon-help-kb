# 各分类商品编码（全球贸易项目代码）要求

下表概述了亚马逊商城中每个商品分类的标准商品编码（UPC、ISBN、EAN、JAN 和其他全球贸易项目代码）要求。根据亚马逊的要求，卖家在大多数分类下发布商品时，都需要提供制造商的标准商品编码。表中注明了例外或豁免情况。

| 商品分类 | 是否需要商品编码 | 例外和豁免 | 操作 |
| --- | --- | --- | --- |
| 亚马逊 Kindle | 是 | 无 | |
| 汽车用品* | 是 | 主要品牌均需具有 UPC。 | 了解更多信息 |
| 母婴 | 是 | 主要品牌均需具有 UPC，但是可为私有品牌商品申请豁免。 | 了解更多信息 |
| 美妆 | 是 | 主要品牌均需具有 UPC，但是可为私有品牌商品申请豁免。 | 了解更多信息 |
| 图书 | 是 | 所有图书均需具有 ISBN、EAN 或 JAN。如果卖家想要发布没有 ISBN、EAN 或 JAN 的图书，则可以申请豁免。 | 了解更多信息 |
| 手机和配件（无线） | 是 | 卖家必须使用唯一的 UPC 为批量商品或采用通用/承运人包装的商品创建单独的页面。 | 了解更多信息 |
| 服装与配饰* | 是 | 主要品牌均需具有 UPC，但是可为私有品牌商品申请豁免。 | 了解更多信息 |
| 消费类电子产品 | 是 | 捆绑商品均需具有唯一的 UPC。 | 了解更多信息 |
| 影视 | 是 | 无 | |
| 娱乐收藏品* | 是 | 主要品牌均需具有 UPC，但是可为私有品牌商品申请豁免。 | |
| 食品 | 是 | 主要品牌均需具有 UPC，但是可为私有品牌、专门性商品、艺术类商品和精选礼品申请豁免。 | 了解更多信息 |
| 个护健康 | 是 | 主要品牌均需具有 UPC，但是可为私有品牌商品申请豁免。 | 了解更多信息 |
| 多件装商品需要提供商品包装数量。 | 了解更多信息 | | |
| 家居与园艺（包括宠物用品） | 是 | 主要品牌均需具有 UPC，但仅可为私有品牌商品和/或手工商品申请豁免。 | 了解更多信息 |
| 家居装修 | 是 | 主要品牌均需具有 UPC，但是可为私有品牌商品申请豁免。 | 了解更多信息 |
| 多件装商品需要提供商品包装数量。 | 了解更多信息 | | |
| 工业与科学用品 | 是 | 不得在此分类下发布没有 UPC 的商品以及属于其他分类的商品。如果某个品牌具有 UPC，则需要提供 UPC。 | |
| 珠宝首饰* | 是 | 主要品牌均需具有 UPC。 | 了解更多信息 |
| 箱包* | 是 | 主要品牌均需具有 UPC，但是可为私有品牌商品申请豁免。 | 了解更多信息 |
| 音乐 | 是 | 无 | |
| 乐器 | 是 | 无 | |
| 办公用品 | 是 | 捆绑商品均需具有唯一的 UPC。 | 了解更多信息 |
| 个人电脑 | 是 | 捆绑商品均需具有唯一的 UPC。 | 了解更多信息 |
| 成人用品 | 是 | 无 | |
| 鞋靴、手提包和太阳镜* | 是 | 无 | 了解更多信息 |
| 软件 | 是 | 无 | |
| 运动户外 | 是 | 主要品牌均需具有 UPC，但是可为私有品牌和专门性商品申请豁免。 | 了解更多信息 |
| 体育收藏品* | 否 | 仅主要集换式卡片品牌需要具有 UPC 或 EAN。 | |
| 玩具和游戏 | 是 | 主要品牌均需具有 UPC，但是制造商可为私有品牌商品申请豁免。 | 了解更多信息 |
| 视频游戏* | 是 | 捆绑商品均需具有唯一的 UPC。 | 了解更多信息 |
| 钟表* | 是 | 主要品牌均需具有 UPC，但是可为私有品牌、精品商品或专门性商品申请豁免。 | 了解更多信息 |
| 酒类 | 是 | 无 | |
| 所有其他分类** | 否 | 不得在此分类下发布没有 UPC 的商品以及属于其他分类的商品。 | |

*表示要求卖家在发布和销售商品之前获得批准的分类。有关更多信息，请参阅[分类批准流程](https://sellercentral.amazon.com/gp/help/external/200333160)。

**“所有其他”分类面向所有卖家开放，主要适用于收藏品（如硬币和邮票）以及明显不属于现有分类的其他商品。如果商品与现有商品页面匹配，或能恰到好处地归入需要批准的分类，请勿将它们发布在“所有其他”分类下。
