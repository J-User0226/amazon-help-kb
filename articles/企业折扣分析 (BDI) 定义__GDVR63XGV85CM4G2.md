# 企业折扣分析 (BDI) 定义

[企业折扣分析](https://sellercentral.amazon.com/business/insights?ref=xx_bdihp_xx)报告中提供了以下信息。有关更多信息，请参阅[企业折扣分析](https://sellercentral.amazon.com/help/hub/reference/G6ADCY95R5HWLD84)帮助页面。

| 列或字段 | 定义 |
| --- | --- |
| 建议类型 | 指示为某商品确定的具体定价优化分类。可能会出现以下差值： |
| - 企业商品价格 >= 标准商品价格 | 商品的企业商品价格高于标准零售价格，因此无法显示企业商品价格。我们建议您更新企业商品价格，使其低于标准商品价格，以获得潜在的提高曝光度优势。 |
| - 未设置企业商品价格 | 符合 B2B 销售条件但未针对 B2B 买家配置企业商品价格的商品。我们建议您为亚马逊企业购商城中的商品设置企业商品价格。 |
| - 未设置数量折扣 | 符合 B2B 销售条件但未针对批量购买配置数量折扣与批量定价分段的商品。我们建议您在设置有竞争力的企业商品价格后添加数量折扣，以鼓励批量购买。 |
| - 不符合企业节省蓝色标记价格资格 | 不符合企业节省蓝色标记 (BSBB) 价格要求的商品（企业商品单价至少 5% 的折扣或 3% 的第一分段数量折扣）。我们建议您争取达到企业节省蓝色标记价格要求，以增加获得企业节省蓝色标记的机会，从而进一步提高对 B2B 买家的曝光度。 |
| 商品 | 【发布商品】页面上的商品名称字段。 |
| ASIN | 即“亚马逊商品编码”，是亚马逊分配给商品的 10 位字母数字编码。它用于识别亚马逊目录中的商品，是商品详情页面的关键部分。 |
| SKU | 库存单位，即 SKU，是帮助电子商务卖家识别其库存商品的唯一代码。SKU 通常由 8 到 10 个字母和数字组成。借助 SKU，您可以在销售过程中更轻松地追踪库存。 |
| 配送类型 | 配送渠道 - 亚马逊物流/MFN/卖家自配送。在亚马逊物流 (FBA) 的帮助下，您可以将商品储存在亚马逊运营中心，我们将负责分拣、包装和配送，并为这些商品提供客户服务。卖家自配送网络是指在亚马逊商城中发布商品，但自行管理所有仓储和包装以及配送和客户服务的一种运营模式。 |
| 浏览量 | “浏览量”是指过去 30 天亚马逊企业购买家查看商品详情页面的次数。此指标可帮助您了解企业买家对您的商品的兴趣。 |
| 符合企业节省蓝色标记要求的商品价格 | 卖家的商品达到此参考价分界点后，即有资格向亚马逊企业购商城中的企业买家显示企业节省蓝色标记。企业节省蓝色标记为那些设置了较大商业折扣的商品提供了视觉提示，以吸引买家的注意，并帮助他们做出购买决策。注意： 仅符合定价标准并不能保证显示标记，因为在考量最终是否显示标记时，还会考虑商品评级和整体卖家绩效等其他因素。有关更多信息，请参阅企业节省蓝色标记帮助页面，了解如何获得资格。 |
| B2B 推荐报价 | 亚马逊企业购商城上的当前 B2B 推荐报价。此参考价可帮助您更具有战略性地为企业买家设置 B2B 商品价格。B2B 推荐报价是显示在亚马逊企业购商城商品详情页面顶部附近的报价，方便企业买家立即购买相应商品或将其添加到购物车，这与亚马逊零售商品详情页面上的推荐报价相似。有关更多信息，请参阅推荐报价资格，了解如何获得资格。注意： 即使定价具有竞争力，也不能保证投放推荐报价，因为这取决于多种绩效因素以及提供相同商品的其他合格卖家的竞争。 |
| 您的标准商品价格 | “商品价格”“零售商品价格”“正常商品价格”和您的“标准商品价格”是商品的零售 (B2C) 价格，面向不属于商业实体、购买商品供个人使用的所有亚马逊买家。如果您未设置企业商品价格，系统也会默认向亚马逊企业购 (B2B) 买家显示。 |
| 您的企业商品价格 | “企业商品价格”是打折后的企业商品单价，仅面向亚马逊企业购买家。企业商品价格不能高于标准商品价格。如果您提交的企业商品价格高于标准商品价格，则会向企业买家显示您的标准商品价格。 |
| 热门数量折扣分段（1 段 - 5 段） | 这是最受欢迎的多商品数量折扣分段建议，显示的是建议批量购买的商品数量。建议基于您的商品分类中已完成的批量购买模式。 |
| 热门数量折扣价格分段（1 段 - 5 段） | 这是多商品数量折扣价格建议，显示的是批量购买数量的建议价格，包括折扣类型（定额或百分比）和定价（以当地货币为单位）。建议基于您的商品分类中已完成的批量购买模式。 |
