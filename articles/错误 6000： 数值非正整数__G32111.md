# 错误 6000： 数值非正整数

数值必须为正整数（例如 1、5 或 20）。

如果您提供的整数小于或等于零，则会发生此错误。

要更正此错误，您应该：
1. 修改此文件，使用大于零且不包括小数或分数的数字。
2. 保存所做的更改。
3. 重新提交此文件。
