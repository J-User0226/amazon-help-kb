# 分配图片

在【分配图片】中，您可以为商品、特定国家或地区或全球商城以及特定图片变体分配单张或多张图片。您还可以从一个商品复制图片并分配给其同系列商品。

查看合规商品图片的要求： [商品图片指南](https://sellercentral.amazon.com/help/hub/reference/G1881)。

## 概述
- 使用**分配图片**可为商品分配以所需名称格式命名的图片（例如 image1.jpg）。
- 如果您以“商品编码 + 变体代码 + 文件扩展名”格式（例如 B000123456.MAIN.jpg）为文件命名，并在**上传图片**中为国家或地区和卖家代码分配图片，则您的图片将分配给您的商品，并可在**图片管理器**中找到这些图片。
- 图片会在**分配图片**中存储 30 天。此后，图片将被移除。
- 您可以选择单张或多张图片并将其分配给商品。
- 图片仅适用于您在登录账户所在国家或地区发布的商品信息。如果您想将图片上传到您有报价的其他国家或地区，则需要从相应账户进行上传图片。前往**选择账户**。
- 在**上传图片**中上传的图片若因问题而未能成功分配给商品，则会显示在**分配图片**中。您可以在**问题**列中查看问题原因和后续步骤。如要详细了解上传图片，请前往[上传图片](https://sellercentral.amazon.com/help/hub/GUGPCYWV2P8KVFUT)。
- 将图片分配给商品后，您可以使用**复制到同系列商品**功能，从一个商品复制图片并分配给其同系列 ASIN。
- 将图片分配给商品后，您可以在[图片管理器](https://sellercentral.amazon.com/imaging/manage)中管理图片。如要详细了解管理图片，请前往[管理图片](https://sellercentral.amazon.com/help/hub/G7F9QAFM53E8C3X3)。

## 分配图片
1. 前往[分配图片](https://sellercentral.amazon.com/media/assign)。
2. （可选）搜索任何文本（例如，文件名）。
3. （可选）按表格中的每列标题进行筛选和排序。
4. （可选）选择**所有筛选条件**以显示所有筛选选项，包括图片名称、供应商代码、ASIN/SKU/其他、变体、国家/地区、问题以及上传日期。
5. 点击某行内的**编辑**来编辑单张图片，或者选择多行并点击页面底部的**编辑**来编辑多张图片。
6. 选择特定**国家或地区**。
  - 未注册或缺少图片管理权限的国家和地区将被禁用。

7. 在**ASIN/SKU/其他**中输入商品编码。
  - 商品编码是条形码编号、ASIN、SKU、UPC、ISBN（10 或 13 位）、EAN、GTIN 或 JAN。

8. 为每张选定图片选择一个变体。请参阅[图片变体](https://sellercentral.amazon.com/help/hub/reference/G8HQAHPDXA9ANPH4)，了解更多详情。
9. （可选）**复制到以下同系列商品**（默认选择）。 **注意： **选择**国家或地区**和 **ASIN 或 SKU 或其他**后，同系列商品将发布在页面上。如果保持选择该选项，则无需为每个与所选商品具有相同颜色或样式的同系列 ASIN 提供图片。

10. 点击**保存**。
11. 然后，将您的图片分配给您的商品，即可在[图片管理器](https://sellercentral.amazon.com/imaging/manage)中进行管理。

## 删除图片
1. 点击**目录或商品**选项卡，然后选择**上传图片**。
2. 点击**分配图片**选项卡。
3. 点击某行内的**删除**来删除单张图片，或者选择多行并点击页面底部的**删除**来删除多张图片。
4. 点击**删除 [x] 张图片**以确认删除。
