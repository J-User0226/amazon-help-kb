# 电池供电加热服装和鞋垫

如果您要在亚马逊商城发布商品，则必须遵守与这些商品和商品信息相关的所有适用法律、法规、标准以及我们的政策。

## 本政策适用的电池供电加热服装和鞋垫

加热服装和鞋垫是设计用于在寒冷环境中提供温暖的可穿戴商品，其使用电池供电的加热元件，在户外活动或寒冷的工作场所中维持舒适感。这类商品具有多项关键功能，例如可调节热量设置、可充电电池、防水材料、柔性加热元件，且大多数商品可水洗。它们主要适用于滑雪、徒步旅行和露营等冬季户外活动，以及建筑工地和仓库等寒冷的工作环境。本政策明确不包括由非锂离子电池供电的加热服装、装有嵌入式电池的加热鞋垫和非电池供电（直接插拔式）加热服装。

电池供电加热服装和鞋垫商品的常见组件：

- 外层绝缘面料

- 含加热元件（碳纤维或金属线圈）的内层

- 可充电锂离子电池电源

- 热量设置控制装置

- 温度调节功能

- 防水材料（在大多数情况下）

- 可水洗结构（适用于大多数商品）

**由锂离子电池供电的加热服装：**

- 加热夹克 - 集成加热功能的外套服装

- 加热背心 - 含嵌入式加热元件的无袖服装

- 加热手套和连指手套 - 含内置加热元件的手套

- 加热袜子 - 含集成加热元件的鞋靴

- 加热帽子和无檐小便帽 - 含嵌入式加热元件的头罩

- 加热头带 - 含集成加热元件的头部配饰

**由锂离子电池供电的加热鞋垫：**

- 电池供电鞋垫 - 含加热元件的可拆卸鞋垫

亚马逊限制销售在承重部位装有锂离子电池的加热服装和鞋垫（例如在鞋垫底部装有锂离子电池），这是因为电池在持续压力和重量作用下可能存在安全风险。

## 我们的电池供电加热服装和鞋垫政策

**亚马逊政策规定的禁售商品**

我们必须确保买家在亚马逊商城找到的商品品类充足、安全可靠且符合相关法规要求。我们不允许发布或销售不合规的商品或禁售商品。

示例包括但不限于：

- 将锂离子电池集成到鞋垫底部的加热鞋垫

- 在承重部位装有锂离子电池的加热服装

- 任何在正常使用过程中电池会受到直接压力或重量作用的加热商品设计

有关禁售商品的更多信息，请参阅[商品安全性发布限制](https://sellercentral.amazon.com/help/hub/reference/external/GRLKLZ6WQ9R259LC)。

**亚马逊政策规定的可售商品**

亚马逊要求所有其他电池供电加热服装和鞋垫均经过检测并符合下列法规、标准和要求：

| 商品 | 法规、标准和要求 |
| --- | --- |
| 电池供电加热服装和鞋垫 | 以下任意一项（如适用商品级别）： IEC/UL/CSA 62368-1 或 UL 499 或 IEC/UL/CSA 60335-2-17 |
| 随附移动电源或电池组 | 以及以下三个选项中的任何一项（如果提供了电池组）： UL 2054、BTS 和 UN 38.3 或 IEC/UL/CSA 62133-2 BTS 和 UN 38.3 |
