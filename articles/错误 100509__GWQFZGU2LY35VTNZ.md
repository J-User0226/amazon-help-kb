# 错误 100509

## 错误消息
您的现金报价中的一项或多项经销商费用不正确。请查看费用并更新以激活报价。

## 错误 100509 原因
出现此错误的原因如下：
- 我们检测到现金报价中的一个或多个经销商费用超出了单笔费用的上限。
- 所有经销商费用的总额违反定价保护或商城政策。例如，文件费用、翻新费和经销商预处理费共同产生不合理的总金额，从而触发自动验证检查。
- 经销商费用适用于不允许销售或结构错误的车辆分类。
- 由于费用格式错误或缺少所需的费用信息，系统无法正确计算最终的现金报价。例如，如果费用金额包含无效字符（如字母或特殊符号而非数值），或者当填写可选费用时，必填费用字段留空。

## 解决错误 100509
要解决此错误，请按照以下步骤操作：
1. 查看您的报价中的所有经销商费用： 点击商品信息以查看完整的费用明细，并确定触发错误的特定费用。
2. 检查每笔经销商费用是否未超过上限。确保任何单笔费用（如文件费、翻新费或经销商预处理费）不超过阈值。
3. 确保费用分类正确，且仅适用于相应的车辆类型。从新车辆商品信息中移除翻新费，验证文件费用是否符合州法规，并确认所有费用描述均准确反映所提供的服务。
4. 调整费用金额和结构，然后保存更改并重新提交报价。
