# 统一全球账户

- 转至您的全球账户页面

- 在这里，您将看到您的全球账户。要将其他账户统一到一个全球账户中，请点击【添加账户】。您将转至新页面，以添加您的凭证。

- 为您要添加的账户添加用户名和密码。

- 登录第二个账户后，您将被重定向至全球账户页面，并会看到两个账户。

- 点击每个账户旁边的复选框，选择要统一的账户。

- 点击【统一】。

- 您的账户将统一到新的全球账户中。
