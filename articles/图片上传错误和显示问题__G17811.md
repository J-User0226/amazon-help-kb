# 图片上传错误和显示问题

如果您收到图片上传错误的提示，或者图片未显示在您的商品详情页面中，请查看以下最常见的原因和解决方法。

## 图片未显示的原因
如果您的图片已成功上传，但未显示在商品详情页面中，请按以下步骤排查：
1. **等待 24 小时。** 图片上传后可能需要最多 24 小时才能显示。
2. **检查合规性。** 查看[商品图片指南](https://sellercentral.amazon.com/help/hub/reference/G1881)，确保您的图片符合所有技术和内容要求。我们在初次上传扫描后检查图片是否符合规范。 **注意： **不符合我们所列商品图片要求的图片无法上传至我们的系统，或可能从搜索结果中移除。前往[图片屏蔽](https://sellercentral.amazon.com/gp/help/external/GT8RSE9S9NK4LP6Z)了解更多信息。

3. **检查您的提交状态。** 前往[提交状态](https://sellercentral.amazon.com/imaging/upload/status)查看您上传的图片的状态（全球/美国及国家/地区专属）。显示“图片上传已完成”的 ASIN 已成功处理。如果存在问题，请选择【内容合规问题】报告类型查看详细信息。
4. **检查重复项。** 如果您上传的图片组与之前提交的一组图片相同，我们可能会将其检测为重复项，您提供的信息内容将保持不变。更新图片时，请确保图片反映实际更改（例如，不同的分辨率或裁剪），以便系统识别新的提交。

**其他注意事项**
- 上传图片并不能保证图片会显示在商品详情页面。我们会从多位销售伙伴中筛选并排列图片，以确保每个商品都有足够的高质量图片供买家查看。为了最大限度地提高图片的显示几率，请确保其符合我们的商品图片要求。
- 我们可能会选择与您提供的不同的图片，包括与品牌中分配了[销售角色](https://sellercentral.amazon.com/gp/help/external/GJ84K745AL3R5N3Q)（品牌代表或经销商）的卖家提供的不同的图片。
- 如果您的商品有多种尺寸或颜色（变体系列），我们会自动从一个选项中选择图片，以显示在该颜色或款式的所有尺寸变体中。
- 如果商品信息缺少主图，它将不会在商城中显示。请确保您的上传包含主图（变体代码： MAIN）。

## 修复图片上传错误
如果您的图片在"上传图片"工具中上传失败，请在下方查找报错：
错误 报错原因 如何解决
[错误的 ASIN 或变体](https://sellercentral.amazon.com/help/hub/reference/GP8W3L6D7G2ZFVME) 您的文件无法与亚马逊商品编码 (ASIN) 或变体关联。 请验证您的文件名是否符合命名格式： 商品编码 + 变体 + 扩展名（例如 B000123456.MAIN.jpg）。请确认该 ASIN 存在，并且您有该 ASIN 的有效商品信息。
[不支持的文件扩展名](https://sellercentral.amazon.com/help/hub/reference/G2AHG9AAHGG2DPVH) 您上传的文件类型暂不支持。 请将您的文件转换为支持的格式： JPEG (.jpg/.jpeg)、TIFF (.tif/.tiff)、PNG (.png) 或非动画 GIF (.gif)。
[图像文件已损坏或格式异常](https://sellercentral.amazon.com/help/hub/reference/G7HVPM8H8YTKXTAW) 文件已损坏或格式不正确。 请确认您的文件没有损坏，最长边小于 10,000 像素，并保存为支持的格式（JPG、TIF、PNG、GIF），颜色模式为 RGB 或 CMYK。
图片尺寸太小 图片的最长边小于 500 像素。 请上传最长边至少为 500 像素的图片。如需使用缩放功能，请使用 1000 像素或更大的图片。要查看尺寸，请查看文件的属性。
权威图片已存在 此 ASIN 和变体已有首选图片。 系统不会接受您为此变体上传的图片。如果您认为当前图片不正确，请上传一张符合所有要求且与现有图片不同的替换图片。
重新提交此前已被接受或拒绝的图片 此完全相同的文件已为该商品提交过。 请勿多次上传同一文件。如果您的商品仍需要图片，则其之前很可能因技术要求而未通过。对图片进行修改（裁剪、调整分辨率或重新导出），使系统将其识别为新提交的内容，然后重新上传。
[未知内部错误]() 出现未知问题。 请稍后重试上传。如果问题仍然存在，请验证您的文件是否符合所有技术要求。
已提交具有相同亚马逊商品编码 (ASIN) 和变体的图片 在您的图片仍在处理期间，已为此 ASIN 和变体上传了较新的图片。 较新的图片优先。如果您需要更新图片，请进行可见更改（裁剪或提高分辨率），使系统将其视为新文件，然后重新上传。
[图片与标题不匹配（错误 100239）](https://sellercentral.amazon.com/help/hub/reference/GCNDJ7XFEQWDJ73E) 主图片与图片文件名不符。 请验证您上传了正确的图片，且文件名与预期的 ASIN 匹配。
[主图片与商品编码不匹配（错误 990003）](https://sellercentral.amazon.com/help/hub/reference/GJBM8ZUVXP7J2DVP) 提交的主图片显示的商品与当前该 ASIN 上的商品不同。 请上传一张主图片，显示该 ASIN 所代表的商品。如果商品发生了实质性变更，请改为创建新的商品信息。

## 使用库存文件对图片进行故障排除
库存文件可让您指定一个 URL，供亚马逊从中检索您的商品图片。文件中的错误可能会导致图片无法加载。 **注意： **您必须使用直接 URL。弹出窗口或重定向 URL 将不被接受，且上传流程无法处理。

症状 报错原因 如何解决
商品图片未显示在亚马逊商城中 该 URL 未指向实际的图像文件。 请验证图片 URL 是否为文件的直接链接，并重新提交您的商品图片上传数据。
亚马逊拒绝此图片 该 URL 处的图片格式不受支持。 请转换为 JPG、TIFF 或 GIF 格式，更新文件中的 URL，然后重新提交。

**如果您的库存文件有错误：**
1. 查看并更正错误：
  - 查看您的处理报告以了解错误。有关更多信息，请参阅[查看处理报告](https://sellercentral.amazon.com/help/hub/reference/G200194300)。
  - 更正报告中指出的错误。有关更多信息，请参阅[错误代码说明](https://sellercentral.amazon.com/help/hub/reference/17781)。
  - 有关具体的无效图片 URL 错误，请参阅[无效 URL 格式（错误 15）](https://sellercentral.amazon.com/help/hub/reference/G30601)。

2. 上传您更正后的库存文件。
3. 重复此操作，直到您的文件处理无误。
4. 图片最长需要 24 小时才会显示。

**解决 zip 文件上传错误**

错误 报错原因 如何解决
上传失败。请减少图片数量后重试，或者检查 zip 中是否存在隐藏文件/文件夹。 您的 zip 文件包含隐藏的系统文件。
1. 启用隐藏文件可见性：
  1. 在 Windows 中，打开文件资源管理器，然后在"查看"菜单下勾选"隐藏的项目"。
  2. 在 macOS 中，打开 Finder 并按 Shift + Command + 句点键以显示隐藏文件。
  3. 在 Linux 中，打开终端并使用 ls -la 命令查看隐藏文件。

2. 解压 zip 文件。
3. 删除隐藏文件（以"."开头的文件或"__MACOSX"文件夹）。
4. 重新压缩文件并再次上传。
5. **注意： **每个 zip 文件最多包含 1000 张图片，大小限制为 1GB。

**解决特定国家/地区的图片显示问题**

如果您的特定国家/地区图片未显示，而是显示了全球图片，则主图（变体代码： MAIN）未包含在特定国家/地区上传中。如无主图，则不会考虑显示任何特定国家/地区的图片。

重新上传特定国家/地区的图片组，并包含一张主图。
