# 如何通过亚马逊购买配送服务购买 FBM Ship+ 货件标签

## 什么是 FBM Ship+

FBM Ship+ 是针对卖家自配送货件的配送解决方案，可将您的送达日期升级为加急配送，而无需支付任何额外的加快配送费用。注册后，买家将看到准确且快速的送达日期，从而使您的商品更具吸引力，而且通常会提高您的销售额。FBM Ship+ 配送速度更快，并且提供较大的运费折扣。此外，您的准时送达率将免受延迟送达的影响；对于与配送相关的亚马逊商城交易保障索赔，您可获得退款。

要享受这些权益，您必须通过亚马逊购买配送服务从 FBM Ship+ 合作承运人处购买货件标签，并在 1 个工作日内发货。

FBM Ship+ 适用于从中国发往美国、英国、法国、德国、意大利、西班牙、澳大利亚和日本的卖家自配送货件，并作为面向美国国内货件的选定卖家的试点解决方案。

您可以从多个位置通过亚马逊购买配送服务为 FBM Ship+ 订单购买货件标签：

- 卖家平台中的[管理订单](https://sellercentral.amazon.com/gp/orders-v2)页面。

- 多渠道集成商/ERP 合作伙伴。

- 我们的配送 API。

## 使用卖家平台中的亚马逊购买配送服务购买 FBM Ship+ 货件标签

您可以从亚马逊购买配送服务上的合作承运人处购买 FBM Ship+ 标签。前往[管理订单](https://sellercentral.amazon.com/gp/orders-v2)，然后点击已注册 FBM Ship+ 的 SKU 订单旁的【购买配送】。

在“用于计算配送承诺的配送服务”部分，查找 FBM Ship+ 标记以识别 FBM Ship+ 订单。点击“购买配送”后，您必须输入包裹尺寸和大小，以查看您可以为配送此订单购买的配送服务。在这些服务中，我们的 FBM Ship+ 合作承运人（例如，对于从中国发货的销售伙伴，可以选择云途物流）提供的服务旁边会有一个标记。

购买货件标签后，您将转至下一步骤以打印货件标签。

**注意： **批量购买配送服务目前不可用于从中国发货的订单。要了解更多信息，请参阅[批量购买配送](https://sellercentral.amazon.com/help/hub/reference/G202168950)。

**注意： **中国承运人目前不支持通过[将您的承运人账户与卖家平台关联](https://sellercentral.amazon.com/carrier-preferences/main)来使用自有承运人运费。

## 使用亚马逊购买配送服务从合作的企业资源计划 (ERP) 或多渠道集成商购买 FBM Ship+ 货件标签

注册 FBM Ship+ 或调整偏好设置只能在卖家平台进行，但您可以在已启用亚马逊购买配送服务的 ERP 或多渠道集成商 (MCI) 中，从我们的合作承运人处购买 FBM Ship+ 标签。使用亚马逊购买配送服务购买标签的体验可能随 ERP/MCI 变化。通常，这需要 3 个步骤：

- 将您的亚马逊店铺与 ERP/多渠道集成商关联

- 将亚马逊购买配送服务与 ERP/MCI 关联

- 使用亚马逊购买配送服务（您可以从中访问主要承运人，包括 FBM Ship+ 合作承运人）购买标签

**注意： **中国承运人目前不支持通过[将您的承运人账户与卖家平台关联](https://sellercentral.amazon.com/carrier-preferences/main)来使用自有承运人运费。

## FBM Ship+ 首选合作伙伴

部分 ERP/MCI 被视为 FBM Ship+ 首选合作伙伴，因为他们提供简化的体验，方便您启用亚马逊购买配送服务、购买 FBM Ship+ 标签。

要通过我们的首选合作伙伴之一使用 FBM Ship+，请将您的亚马逊店铺与多渠道集成商或 ERP 关联。与我们的首选 ERP 合作伙伴关联后，系统将自动为您的订单启用亚马逊购买配送服务。接下来，前往 ERP/MCI 中的【管理订单】部分，找到带有 FBM Ship+ 标记的订单。要享受 FBM Ship+ 的权益，请在亚马逊购买配送服务上购买 FBM Ship+ 合作承运人（例如，对于从中国发货的销售伙伴，可以选择云途物流）的配送服务标签。首选合作伙伴标注使用 FBM Ship+ 标记来标注这些配送服务，。以下是我们的一些首选合作伙伴：

## 其他合作伙伴

如果您使用的 ERP/MCI 不是首选合作伙伴，但有权使用亚马逊购买配送服务，那么您仍然可以购买 FBM Ship+ 标签并获得 Ship+ 权益。

## 通过我们的配送 API 使用亚马逊购买配送服务购买 FBM Ship+ 货件标签

如果您有需要配送的 FBM Ship+ 订单，可以通过以下任一亚马逊购买配送服务 API 购买 FBM Ship+ 货件标签： [配送 V2 API](https://developer-docs.amazon.com/amazon-shipping/docs/shipping-api-v2-reference) 或[卖家自配送 API](https://developer-docs.amazon.com/sp-api/docs/merchant-fulfillment-api-v0-reference)。

如果您使用自有软件，则启用 FBM Ship+ 体验需要使用通知 API（可选，但建议使用）、订单 API 和购买配送服务 API。使用通知 API (ORDER_CHANGE)，您可以订阅通知，系统会在订单状态发生变化（订单更改或取消）时通知您。使用订单 API，您可以确定符合 FBM Ship+ 要求的订单。要使用购买配送服务 API 享受 FBM Ship+ 的权益，请购买 FBM Ship+ 合作伙伴承运人（例如，对于从中国发货的销售伙伴，可以选择云途物流）的配送服务标签。对于 FBM Ship+ 推荐的配送方式，购买配送服务 API 同样会传递“FBM_SHIP_PLUS”标记。有关更多详情，请参阅[教程： 将 FBM Ship+ 与 ERP 和多渠道集成商集成](https://developer-docs.amazon.com/amazon-shipping/docs/tutorial-integrate-fbm-ship-with-erps-and-multi-channel-integrators)。

**注意： **FBM Ship+ 服务和 API 正在开发中，因此详情可能变更。API/服务启动并可供使用后，我们将提供最终确定的 API 文档和教程。
