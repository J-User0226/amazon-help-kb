# PIN 验证

PIN 验证流程是我们账户验证系统的一部分。当您进入注册流程的“业务信息”步骤时，您可以选择通过 SMS 短信或电话接收PIN。

**注意： **如果您选择呼叫，接听电话的预计时间可能会有所不同。

选择其中一个选项后，我们将用您在验证过程中提供的电话号码与您联系，并要求您使用我们的自动系统输入 PIN。

**注意： **您可使用能够接收来电的任何电话线路，使用触摸按键或通过语音输入 PIN。如果您使用语音，而非触摸按键输入 PIN，请确保说话缓慢而清晰。此外，尝试使用手机按键输入 PIN。如果仍然无法输入您的 PIN，请[联系我们](https://sellercentral.amazon.com/cu/contact-us?_encoding=UTF8&ref_=pt_contactus_nmhb_59921)。

如果未收到电话呼叫，则说明您的电话可能占线。如果您正在使用拨号 Internet 连接，请确保您已断开与 Internet 的连接，并再次尝试注册过程中的 PIN 验证步骤。

如果您在通过电话呼叫接收 PIN 时仍然遇到问题，请返回注册流程，以验证是否输入了正确的电话号码。

**注意： **检查注册过程中输入的电话号码是否有误，确保电话号码无误并包含国家/地区代码且没有多余的 0。

如果您关闭了浏览器，可以点击电子邮件邀请函中的链接，重新登录注册流程。登录之后，您将能够在注册系统中从之前中断的地方继续操作。
