# 错误 8008

**什么原因会导致错误 8008？**

当您在商品关系上传数据中引用的子 SKU 未使用商品上传数据正确设置时，就会出现此错误。出现此错误的常见原因如下：

- 您使用的子 SKU 是错误的 SKU。

- 您使用了正确的 SKU，但未在商品上传数据中将该 SKU 指定为子商品。

- 您使用了正确的 SKU，但您的商品上传数据中的错误导致无法正确设置子商品 SKU。

**错误消息：**

我们无法识别您尝试与父 SKU [%s] 关联的子 SKU [%s]。

**如何解决和避免错误 8008？**

要使用 XML 上传数据解决此错误，请按照以下步骤操作：

- 检查您的上传数据，确保 SKU 值正确无误。

- 如果不正确，请更正该值，然后发布更新后的上传数据。这样就能解决此问题。

- 如果 SKU 值正确，则请找到包含该子 SKU 的最新商品上传数据。

- 确保子 SKU 的“父子关系”值为“子”，并且具有与变体系列一致的有效变体主题。

- 查看之前的错误报告，了解其中是否存在与子 SKU 相关的商品上传数据错误，并更正所有错误。

- 使用商品上传数据发布该子 SKU 更新后的商品数据。

- 发布您的上传数据。

有关如何正确创建父子关系的更多信息，请参阅[创建父子关系](https://sellercentral.amazon.com/gp/help/external/G8841)。
