# 美国税务信息采集常见问题

亚马逊要求所有卖家均完成美国纳税身份信息采集。

如需向亚马逊提供您的纳税人身份信息，您可以使用[自助税务信息采集](https://sellercentral.amazon.com/hz/account-info/tax-interview-redirect)，完成纳税人信息输入，最后验证您的 W-9 或 W-8 表格。为了尽可能高效地满足美国国家税务局的要求，请在信息采集过程中回答所有问题并输入要求填写的所有信息。请避免拼写错误或输入错误的纳税任识别号，否则您填写的税务表格将无效。

系统会根据您在税务信息采集提供的回答自动确定您适用哪个美国国家税务局表格（W-8 或 W-9）。 **注意： **本信息采集只有“我要开店”付款账户的主用户才可以访问。

#### 亚马逊能否帮助我填写纳税申报单或协助我完成税务信息采集？
尽管我们会帮助卖家了解这些税务规定的要求，但是我们不提供税务指导。请联系税务专业人员。

如需税务指导，请前往[服务提供商网络](https://sellercentral.amazon.com/tsba/searchpage/taxCategory?ref_=ag_agsSPN_cont_201062890&)，联系税务专业人员。

#### 我是一名美国纳税人。我需要向亚马逊提供什么信息？
通过完成卖家账户中的[自助税务信息采集](https://sellercentral.amazon.com/hz/account-info/tax-interview-redirect)，您可以用 W-9 或 W-8 表格向亚马逊提供相应的纳税身份信息。

对于美国纳税人，出于税法管理目的，美国国家税务局要求提供纳税人识别号。在大多数情况下，纳税人识别号可以是雇主识别号，也可以是社会保障号。

#### 我是一名海外卖家，不是美国纳税人。我需要向亚马逊提供信息吗？
是的，即使您不是美国纳税人，您仍需提供相关信息，系统将根据您在纳税信息采集问题中的回答为您生成相应的税务表格。

#### 在税务信息采集期间，我是否需要提供增值税号或商品及服务税号？
不需要，信息采集工作不采集增值税或商品及服务税信息。我们将在卖家平台的“账户信息”页面中继续采集您的增值税或商品及服务税信息。

#### 如何确定我的销售账户的受益所有人?
有关受益所有人的信息，请访问[美国国家税务局](https://www.irs.gov/individuals/international-taxpayers/beneficial-owners)网站。

#### 亚马逊会向我提供我的 W-8或 W-9表格的副本吗?
亚马逊不提供 W-8 或 W-9 表格的纸质副本，但您可以在税务信息采集结束时选择下载表格的电子副本。请保留您向亚马逊提供的所有税务信息的副本。

#### 在尝试完成税务信息采集时，我收到一条错误消息。我该怎么办？
在税务信息采集期间提供的信息必须与美国国家税务局记录相符。
- 如果您是以个人卖家身份完成美国纳税身份信息采集，请填写社保卡上显示的信息。
- 如果您是以企业身份填写信息，请填写美国国家税务局发给您的 CP575A 通知上的名称（位于地址的第一行中）。
- 姓名拼写错误、漏掉了中间名缩写或中间名，或者输入了错误的纳税人识别号，都可能会导致表格验证失败。

美国人士：

- **个人**： 请填写社保卡上显示的姓名。
- **企业**： 请填写实体的纳税申报单上显示的名称和纳税人识别号。
- 如果您选择了“个人/独资经营者”以外任何类型的联邦税分类，请根据所选的联邦税分类，使用如下选项：
  - C 类公司： 请参阅 CP575 通知以确认您的联邦税分类类型，或联系美国国家税务局。
  - S 类公司： 请参阅 CP575 通知以确认您的联邦税分类类型，或联系美国国家税务局。
  - 合作伙伴： 请填写合作伙伴协议中的名称。
  - 信托方： 请填写信托契约上的名称。
  - 有限责任公司： 请参阅 CP575 通知以确认您的联邦税分类类型，或联系美国国家税务局。
  - 其他：
    - 如果您是美国《国内税收法》第 501 (c) 或 501 (d) 节规定的非盈利组织，请选择“其他”作为您的联邦税分类，然后在下拉列表中的“其他类型”下选择第一个选项：“根据第 501 (a) 节的规定而免税的组织、任何个人退休账户或当账户满足第 401 (f) (2) 节的要求时，符合第 403 (b) (7) 节规定的保管账户”。
    - 请参阅法规第 501(a) 节中的声明：“第 (c) 或 (d) 小节中描述的组织应予以免税...” 因此，通过声明根据第 (a) 节的规定您可以获得免税，即表示您可以根据 (c) 或 (d) 小节的规定获得免税。

非美籍人士：
- **个人**和**企业**： 请填写您的所得税申报单上显示的姓名或名称。

#### 我收到一封电子邮件，指出我的纳税身份信息无效。我认为我提供的信息是正确的。能告诉我为什么无效吗？
我们不确定您的纳税身份信息无效的具体原因，但是可以为您提供几条建议：
- 对于个人，这通常意味着需要输入社会保障卡上显示的姓名和社会安全号码。
- 对于企业，这通常意味着需要输入您的雇主识别号以及随该号码收到的通知上显示的名称。
- 如果您是一人有限责任公司，则可以输入企业所有者的社会保障号码和姓名。另一个选择是输入雇主识别号和企业名称。请勿输入非独立实体的雇主识别号。
- 有关确保您提供的税务信息有效的更多详细信息，请参阅上述常见问题。

如果您提供的纳税身份信息无效，则必须提供正确的纳税身份信息，以便保留您的销售权限。 **重要： **本文件中包含的信息不构成税务、法律或其他专业建议，也不得作为此类用途使用。如有其他疑问，请联系您的税务、法律或其他专业顾问。
