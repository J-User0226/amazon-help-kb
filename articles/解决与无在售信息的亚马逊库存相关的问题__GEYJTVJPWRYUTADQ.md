# 解决与无在售信息的亚马逊库存相关的问题

亚马逊在[修复无在售信息的亚马逊库存](https://sellercentral.amazon.com/inventoryplanning/stranded-inventory)页面上提供**无在售信息的原因**列。 此列显示每件商品无在售信息的原因。**其他信息**列显示更多信息和说明。

请参阅下表，了解有关每个**无在售信息的原因**和**其他信息**列表，包括建议操作。

## 新版“修复无在售信息的亚马逊库存”页面上的主要功能
#### 信息更准确，时效性更强
有时，同一件商品，在【管理库存】上显示为【在售】，而在[修复无在售信息的亚马逊库存](https://sellercentral.amazon.com/inventoryplanning/stranded-inventory)上显示为【无在售信息】。请注意，**修复无在售信息的亚马逊库存**所包含的信息准确度最高，时效性最强。

#### “无在售信息的原因”列
此列为您提供了无在售信息的亚马逊库存的相关信息。您还可以查看更多详情以及应采取哪些措施。

#### 按“无在售信息的原因”和“建议”进行筛选
借助这些功能，您可以对商品无在售信息的原因以及每个问题的解决方法进行排序并更好地予以理解。

#### “无在售信息的事件日期”列
此列会显示您的库存在累积产生仓储费期间，其无在售信息状态已存在了多久。您还可以使用此列中显示的日期帮助找到与该商品相关的电子邮件和绩效通知。

#### 一键式操作
使用【一键重新发布】，只需一次点击即可重新发布商品，无需离开当前页面。如果您必须在激活商品之前编辑商品信息，请点击【编辑商品】或【重新发布】。
使用【一键转换为亚马逊物流】，只需一次点击即可更改配送渠道，无需离开当前页面。此选项仅适用于已提供危险品信息的商品。所有商品都需要提交危险品信息。如果您之前未提供此信息或必须更改之前提供的信息，请点击【转换为亚马逊物流】以更改配送渠道。

#### 批量操作和自动操作
使用【批量重新发布】，您可以一次选择最多 25 种商品进行重新发布。选择这些商品后，您可以使用【一键重新发布】一次性重新发布所有商品，这是我们建议的操作。 **注意： **批量重新发布商品时，您无法更改任何受影响商品的目录或商品信息。要在激活前编辑商品信息，请点击【编辑】或【重新发布】。

使用【批量一键转换为亚马逊物流】，您可以一次选择 25 种商品进行配送渠道变更。选择这些商品后，您可以使用【一键转换为亚马逊物流】一次性重新发布所有商品，这是我们建议的操作。 **注意： **使用【批量一键转换为亚马逊物流】时，您无法提供或更新危险品信息。要提供危险品信息，请使用【转换为亚马逊物流】。

【自动重新发布】将根据以下无在售信息的原因自动重新发布缺少在售信息达 7 天的库存：
- 商品已下架
- 商品已停售

您可以通过点击【编辑自动操作设置】来调整此设置。对于不希望自动重新发布的商品，请在商品右侧的下拉箭头中选择【禁用自动操作】。

【自动转换为亚马逊物流】会自动将无在售信息达 5 天且无在售信息原因为【卖家自配送】的库存的配送渠道更改为“亚马逊物流”。您可以通过点击【编辑自动操作设置】来调整此设置。对于不希望转换为亚马逊物流的商品，请在商品右侧的下拉箭头中选择【禁用自动操作】。

【自动重新发布】可设置为在最短两天内重新发布商品。如果您将其设置为 0 天，则【自动转换为亚马逊物流】可在一天之内更改配送渠道。

**重要： **如果您通过将库存变为无在售信息来管理终止时间，则可以设置【开始销售日期/报价开始日期】，将库存的无在售信息状态保持到未来的某个时间，从而避免自动重新启售。自动操作将不会对这些商品产生影响。

以下是有关使用自动操作的一些提示：

- 您可以使用批量上传模板或 API 避免意外将库存设置为无在售信息。将【自动转换为亚马逊物流】设置设为 0 或 1 天，以确保您的库存快速取消无在售信息状态并可供销售。
- 在假期、商品评估或宗教活动期间暂时下架商品。在【管理库存】中下架您的商品并设置自动重新发布，以便在指定天数后自动重新发布商品。
- 当您由于 ASIN 受限而必须下架将来还会重新启售的商品时，要防止销售损失。商品重新启售后，将作为已下架商品仍保持无在售信息状态。更改【自动重新发布】设置可以更快启售商品。
