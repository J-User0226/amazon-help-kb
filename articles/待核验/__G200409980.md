# 

为了帮助您在亚马逊销售音乐商品，我们提供了一款专用工具，可以让您一次性上传多个商品，它就是音乐加载工具。音乐加载工具会将您的商品数据与亚马逊目录中现有的商品页面进行匹配；如果目录中没有相应页面，该工具则会新建一个商品详情页面。
## **音乐加载工具功能**
如果 Amazon.fr 目录中已经存在您的商品的详情页面，音乐加载工具将使用您提供的商品编码（UPC 或 EAN）查找匹配项和创建商品详情。详细了解[商品匹配](https://sellercentral.amazon.com/gp/help/external/1471)。
如果音乐加载工具无法在目录中找到匹配项，但是您在上传文件中提供了充分的数据，亚马逊将自动创建一个新的商品页面。一旦创建了页面，您的库存将与页面“匹配”，从而为买家创建商品。
如果系统没有充分信息与现有页面匹配或创建新页面，上传之后您将在处理报告中收到一条错误消息。
音乐加载工具模板包含几个宏，它们可在您上传商品信息时显著简化和改善您的体验。有关宏的更多信息，请参阅[音乐加载工具说明](https://sellercentral.amazon.com/gp/help/external/200409990)。
