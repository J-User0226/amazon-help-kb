# 待核验文章 GJC65LYU5NZLSDFF

## 错误消息

请从属性 ${attribute_name} 中移除所有不合规的标记，确保您的数据符合亚马逊指南： 请勿在商品详情页面中使用 HTML、JavaScript 或其他任何类型的代码。

## 导致错误 100339 的原因

出现此错误的原因如下：

- 商品描述、商品名称、要点等字段含有不准使用的内容，例如 HTML 标签（如 <p>、<br> 或 <strong>）、标记语言或格式代码。

- 商品详情字段中包含 JavaScript 或其他编程代码（可能是故意添加，也可能是复制粘贴时的操作失误）。

- 商品属性中出现了特殊字符、CSS 样式或网页格式设置元素。

## 解决错误 100339

要解决此错误，请按照以下步骤操作：

- 查阅上传数据处理汇总报告，找到其中高亮显示的属性，并移除所有 HTML 标签（如 <b>、<i>、<p>、<br>）或其他任何代码元素。

- 将内容转换为纯文本格式，确保清除所有样式与格式。

- 检查商品名称、要点、描述和通用关键词，确保未使用任何特殊格式，例如通过 HTML、JavaScript 片段或网站样式代码创建的要点。

- 更新属性值后，重新提交文件。

- 有关更多信息，请参阅[商品名称要求和指南](https://sellercentral.amazon.com/help/hub/reference/GYTR6SYGFA5E3EQC)以及[商品要点要求](https://sellercentral.amazon.com/help/hub/reference/GX5L8BF8GLMML6CX)。
