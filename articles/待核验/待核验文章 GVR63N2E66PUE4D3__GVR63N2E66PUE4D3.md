# 待核验文章 GVR63N2E66PUE4D3

## 如何销售没有商品编码（全球贸易项目代码/条形码）的商品？

大多数分类均要求卖家使用商品编码（通用商品编码 (UPC)、欧洲商品编号 (EAN)、JAN 或 ISBN）创建新的商品页面和商品信息。

创建和匹配商品页面所需的特定商品编码因商品[分类](https://sellercentral.amazon.com/gp/help/external/200317520)而异，不过最常使用的是通用商品编码 (UPC)。

如果您是商品转售商或进口商，您可以通过[申请全球贸易项目代码豁免](https://sellercentral.amazon.com/gtinx/browser)来销售没有商品编码的商品。

如果您发现自己的商品确实需要全球贸易项目代码，我们建议您直接从 [GS1](https://www.gs1us.org/get-started/im-new-to-gs1-us) 处获取。
