# 错误 90004199

## 错误消息
“${attribute_name}”属性的值应按百分比降序排列（例如 10% 尼龙，90% 涤纶未按降序排列），但您提供了 ${value}。有关更多信息，请将以下链接复制并粘贴到您的 Web 浏览器中：https://a.co/6YdsLVW。

## 导致错误 90004199 的原因
导致此错误的原因如下：
- 商品信息中的材质成分百分比未按降序排列（从最高到最低百分比）。
- 材质成分的格式与亚马逊要求的材质百分比显示结构不符。
- 提供的材质百分比总和未达到 100% 或包含错误值。

## 解决错误 90004199
要解决此错误，请按照以下步骤操作：
1. 重新排列商品材质成分信息，按降序显示百分比，例如： 90% 棉，8% 涤纶，2% 氨纶。
2. 确认所有材质百分比准确无误，总和为 100%。
3. 对于每个成分，都请遵循亚马逊的标准格式：[百分比]% [材质名称]。如有多个材质，请使用逗号分隔。
4. 更新后，请重新提交文件。
