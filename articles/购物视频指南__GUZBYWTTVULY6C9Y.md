# 购物视频指南

借助购物视频，您可以演示商品的实际使用效果，描述商品特色，讲述独特的品牌故事。有效利用此类视频，可以提高转化率并提升销售额。您可以上传商品视频，视频会显示在商品图片旁边。

视频的主要优势如下：

- 通过商品演示让买家更放心

- 让买家更好地了解商品尺寸、特性和功能

- 让买家对商品形成更清晰的预期，从而减少商品退货

- 增加详情页面的吸引力

- 平均而言，在商品详情页面添加视频的卖家，相关销售额较未添加视频的 ASIN 增长了 *24%（*亚马逊内部历史数据，2026 年 1 月至 6 月）。

要了解更多信息，请观看[在商品信息中添加视频的好处](https://www.youtube.com/watch?v=ZhFHSYykfVY)。

## 对 AI 生成人物的披露

如果视频包含相片级逼真的 AI 生成人物，则某些司法管辖区可能要求进行相关披露。如果您的视频包含相片级逼真的 AI 生成人物，则在将其上传到亚马逊之前，必须使用适当的元数据标记该视频。

**如何添加所需的元数据**

使用与 IPTC 兼容的元数据编辑器，将关键字 contains-synthetic-performer 添加到视频文件的 dc:subject (XMP) 字段。

如果包含这些元数据，亚马逊将添加披露信息，以告知受众该视频包含 AI 生成的人物（如适用）。

有关更多信息，请参阅[如何标记包含 AI 生成人物的媒体](https://sellercentral.amazon.com/help/hub/reference/GFXHCHYZRGJRBZA5)。

**何时提供此元数据**

如果您的视频包含完全由 AI 生成的人物（并非基于真人），请提供 contains-synthetic-performer 标签。

**何时不需要提供此元数据**

如果满足以下任一条件，请勿提供此元数据：

- 您的视频仅展示真人（即使已使用 AI 工具进行了修改）或

- 您的视频仅包含电影、视频游戏或其他表现形式作品（例如，电影海报或视频游戏封面）中的角色

- 您的视频中不包含任何人物

- 您视频中的人物不是照片级逼真的

## 视频类型和用途

| 视频类型 | 目的 | 内容重点 |
| --- | --- | --- |
| 商品概览 | 展示完整的商品信息 | 商品功能和物理特征的综合概览 真实案例与实际场景演示 展示品牌专属特性或通用商品功能 商品尺寸和关键属性的可视化呈现 可适用于某一特定品牌，或展示许多商品共有的商品功能 |
| 拆箱 | 展示包装和初次接触商品体验 | 从运输包装中取出商品 商品尺寸和比例的可视化呈现 展示所有箱内物品及配件 |
| 商品操作与使用指南 | 演示商品用途 | 特定用途或功能说明 多种使用场景展示 功能的实际应用示例 |
| 设置 | 指导商品组装和安装 | 分步指南 组装流程演示 设置要求及所需工具 |

| 品牌简介 | 传达品牌形象 | 品牌愿景、使命和价值 公司历程和里程碑事件 商品系列概览 品牌差异化优势 |
| 其他 | 覆盖其他内容 | 不属于其他分类的特定内容 独特的商品特性 补充信息 |

**权利和侵权**

您的视频不能侵犯第三方的知识产权或其他产权。请仅发布属于您自己的内容或您有权使用的内容。除非您已获得所有相关第三方的许可，否则不能在您的视频中播放音乐，也不能包含图片、艺术作品或其他音像作品。

**技术限制**

- 元数据可在发布后进行编辑。

- 每个视频必须至少与一个 ASIN 关联。

- 美国和加拿大商城的共享商品信息会自动同步，但不支持其他商城的共享功能。请注意，我们不断尝试为买家和卖家提供最佳的体验。在此测试期间，某些视频可能会在试验过程中显示在共享的全球商品信息的详情页面上。

## 最佳实践

购物视频必须确保商品清晰可见，音质清晰、光线充足、画面呈现专业且商品信息准确无误。

| 允许 | 不允许 |

| ✓ 展示尺寸和比例 | ✗ 使用未经授权的音乐或艺术作品 |

| ✓ 解决常见的买家问题 | ✗ 作出误导性声明或提供错误信息 |
| ✓ 使用高质量视频（分辨率不超过 1,080p） | ✗ 上传模糊或低质内容 |
| ✓ 确保录音清晰 | ✗ 包含外部品牌标识 |
| ✓ 始终保持充足的照明 | ✗ 添加促销内容 |
| ✓ 创建具有吸引力的缩略图 | ✗ 使用质量较差的缩略图 |
| ✓ 使用专业的出镜人员（如适用） | |

## **上传视频**

在上传视频之前，请确保符合以下要求：

- 您的账户处于活跃状态的时间超过 3 个月（已注册品牌或未注册品牌）。

- 已创建和发布商品 ASIN。

- 视频文件为 MOV 或 MP4 格式，分辨率不超过 1,080p（文件最大 5GB）。请参阅上面的**视频文件要求**表，了解更多信息。

- 遵守我们的[社区准则](https://www.amazon.com/gp/help/customer/display.html?nodeId=GLHXEX85MENUE4XF)。

**方法 1： 通过“上传和管理视频”上传**

要使用此工具，请按照以下步骤操作：

- 前往[上传和管理视频](https://sellercentral.amazon.com/creatorhub/video/library/)。

- 点击【上传视频】。

- 在必填字段中填写相关内容： 

- 标题： 视频的显示名称

- ASIN： 选择相关商品

- 语言： 选择与您的视频相关的受支持的语言。

- 缩略图： 自动生成或上传自定义缩略图（JPG、PNG、GIF 或 BMP，小于 5MB）

- 点击**提交**。

**方法 2： 通过图片管理器上传**

要使用此工具，请按照以下步骤操作：

- 前往[图片管理器](https://sellercentral.amazon.com/imaging/manage)。

- 选择您的商品。

- 点击商品详情面板上的【视频】。

- 点击【上传视频】。

- 在必填字段中填写相关内容： 

- 标题

- 缩略图自动生成，您也可选择替换为 JPEG、PNG、GIF 或 BMP 格式的图像文件，大小需在 5MB 以下。建议使用 1,920 x 1,080 像素、比例为 16:9 的文件。

- 点击**提交**。

**重要： **支持一次批量上传最多 15 个视频。

**变体**

如果您想要将视频上传到选定的某组 ASIN，上传时请在 【ASIN】 字段中列出这些 ASIN。这样一来，系统会将此视频仅与指定的 ASIN 进行关联。请勿激活变体扩展功能。

要将视频扩展关联至上述 ASIN 的所有变体，请将【包含 ASIN 商品变体】切换至“开启”位置，激活变体扩展功能。

**语言支持**

您可以上传多种语言的视频。上传视频时，请在【视频语言】下选择您的视频中采用的语言。下拉列表中包含此商城支持的所有语言。

**缩略图**

系统将自动为视频生成缩略图。如果您决定替换此缩略图，请点击它，然后上传图片。请上传 JPEG 或 PNG 格式的高质量图片，图片大小不可超过 5MB。图片应具有高分辨率，画面清晰。

**处理时间**

视频上传和更新所需的处理时间如下：

- 初步审核： 1~7 个工作日

- 发布至详情页面：获得批准后的 3 天内

- ASIN 变体更新：作出变更后最多 3 天

**注意： **在假日购物季之前和期间，审核和发布可能需要更长时间。

## 故障排除

上传视频时，请确保：

- 视频格式符合要求

- 已提供标题和缩略图

- 已正确关联 ASIN

- 已确认语言选择

| --- | --- | --- | --- |

| 视频未显示 | 视频已上传，但未在商品详情页面上显示 | 前往【上传】，然后选择【管理视频】。 检查视频状态。 确认视频处于【已发布】状态至少已达 3 天。 确保视频关联的 ASIN 与视频中展示的 ASIN 一致。 | 对于软百货商品： 如果您的商品有六张或六张以上图片，则视频将在桌面视图中被禁止显示。 请删除多余的图片以显示视频。 |

## 视频指标控制面板

【趋势计算：】 趋势的计算方式根据指标类型会有所不同。我们采用平均值计算百分比指标（例如观看时长百分比），采用加总值计算数值指标（例如商品点击量）。所有对比均基于当前周期与上一同等周期进行。

【趋势图线：】 趋势将您当前选择的日期范围与上一同等周期进行比较。您可以通过控制面板顶部的下拉按钮更改日期范围。

- 绿色表示该指标呈正向趋势。

- 红色表示该指标呈负向趋势。

- 无色则表示该指标无变化。

就退货率而言，退货率下降时，趋势线显示为绿色，表示退货减少；退货率上升时，趋势线显示为红色，表示退货增加。

| 问题 | 表现/状态 | 故障排除 |
| --- | --- | --- |
| 视频指标为空 | 当数据不足时，视频的所有指标均显示为空 | 可能由以下两种主要原因导致： 视频可能尚未发布（仍在审核中，或视频被拒绝）。 尚未收集到足够的数据以计算有意义且准确的报告。 |
| 某些指标有数据，而其他指标仍为空白 | 对于同一视频，部分指标有数据，其他指标则为空白 | 为保护卖家隐私，某些指标可能不予显示。当针对您视频关联的 ASIN，拥有在售报价的卖家数量过少时，隐私保护便会激活。当针对您视频关联的 ASIN，拥有在售报价的卖家数量增加时，相关指标便会恢复显示。 |
| 对于曾上线但目前已停用的视频，其指标如何计算 | 控制面板顶部的卡片仅统计已发布、已处理或被拒绝的视频 | 要将视频数据计入所选时间范围内的累计指标数，请将您的 ASIN 所关联的视频设为上线状态。 |
