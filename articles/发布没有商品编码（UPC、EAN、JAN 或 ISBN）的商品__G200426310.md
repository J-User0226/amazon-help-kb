# 发布没有商品编码（UPC、EAN、JAN 或 ISBN）的商品

请观看以下视频，了解如何发布没有商品编码的商品。

在开始之前，请确保您满足以下基本要求：

- 商品不在亚马逊目录中
- 您的商品没有商品编码或 GS1 条形码
- 您已获得分类批准（如果需要）

**注意： **GTIN 对于提高您的业务效率至关重要。借助 GTIN，能够快速准确地识别商品，简化库存管理，并且通过条形码扫描来减少错误。GTIN 还可以提高定价准确度、库存水平追踪和整体运营效率。有关从 GS1 获得 UPC 许可的更多信息，请参阅 [GS1 标准网站](https://www.gs1us.org/?utm_source=partner&utm_medium=referral&utm_campaign=idgtm-amazon-sellercentral)。

**申请前检查现有的 GTIN 豁免**

如果您已经获得该商品类型的批准豁免，则无需申请新的 GTIN 豁免即可发布您的商品。在此情况下，【立即申请】选项不可用，因为无需提交新的申请。

请注意，GTIN 豁免按父商品类型级别获得批准，并自动涵盖所有子级商品类型。例如，“Party_Supplies”豁免会自动涵盖“Balloon”。

**资格指南**

如果您要销售以下商品，可以申请 GTIN 豁免：

- 自有品牌或手工艺品
- 您生产、拥有品牌或发布的无条形码商品
- 没有商品编码的零件： GTIN/EAN/UPC/ISBN GTIN（例如汽车零件、手机配件）
- 捆绑商品（例如，皮带和钱包套装）
- 通用、无品牌商品（请参阅[亚马逊无品牌商品政策](https://sellercentral.amazon.com/help/hub/reference/G84H3T69ZX762NWT)）

如果您的商品存在以下情况，您将无法申请 GTIN 豁免：

- 已有 GS1 批准的条形码
- 已有 GTIN/EAN/UPC/ISBN
- 来自需要强制性 UPC 的品牌（会导致“您的账户不符合条件”）
- 如果您的商品是图书，且您试图将出版商（品牌或制造商）列为“无品牌”
- 如果您的商品存在于亚马逊目录中

## 申请准备工作（图片要求、品牌格式）
**申请准备工作**

申请遭拒的主要原因：

- 对于图书： 没有图书的正面、背面和书脊图片，内封面缺少出版商名称，或图片中缺少出版商名称。
- 品牌名称不是永久性标识，或已被以数字方式更改。
- 未提供在真实环境里拍摄的图片（经过了数字化渲染）。
- 质量较差的图片。
- 所有图片中的品牌名称不一致。
- 已有 GS1 条形码。
- 没有六面（所有面）图片。

**图片要求**

请提供以下在真实环境里拍摄的图片：

- 商品和包装的所有面（前、后、左、右、上、下）
- 对于扁平物品：商品和包装的正面和背面图片
- 对于图书：封面、封底、印有出版商名称的内封面以及书脊
- 对于捆绑商品：单独的各个组件 + 组装后的捆绑商品

**图片质量标准**

- 最低分辨率：（例如，500 x 500 像素）
- 光线充足且清晰的图片
- 文件格式： JPEG 或 PNG
- 文件大小上限： *10 MB*

**注意： **错误代码 400 通常表示您上传的图片文件不符合图片要求。有关图片要求的详细信息，请参阅[商品图片指南](https://sellercentral.amazon.com/help/hub/reference/G1881)。

**品牌标志**

可接受的永久性品牌标志：

- 凸雕和凹雕徽标
- 印刷和丝网印刷的品牌名称
- 缝制标签
- 永久性贴纸和标签
- 金属和塑料铭牌

不可接受： 可移除的贴纸、临时标签或以数字方式粘贴。

**品牌名称格式**

正确的示例：

- “Brand Name”（标准）
- “BRAND NAME”（全部大写，前提是与商品一致）
- “Brand-Name”（带连字符）
- “Brand.Name”（带句点）
- “bRand”（首字母小写，例如 iPhone）

不正确的示例：

- “B rand Name”（有多余的空格）
- “BrandName™”（不应包含商标符号）
- “Brand_Name”（下划线）
- 大写情况与商品上的不同

## 申请流程（添加商品、时间线）
【申请流程和可能的情景】

表 1. 【场景 1. 品牌所有者或无品牌】
描述 步骤 说明
您是品牌所有者且没有商品编码，或者您销售的是无品牌商品
1. 前往[添加商品](https://sellercentral.amazon.com/product-search)工具，在搜索栏中输入您的商品名称，然后点击【搜索】。点击【创建新商品信息】。
2. 填写商品详细信息并选择合适的商品类型/分类。
3. 输入品牌名称（或者为无品牌商品选择“此商品没有品牌名称”）。
4. 勾选“我没有商品编码”，然后点击“下一步”。
5. 系统将自动批准您的 GTIN 豁免申请。

【时间线： 自动批准。】 获得批准后，请等待 30 分钟再发布商品，否则您可能会看到商品编码错误，因为我们的系统正在处理此项豁免信息。

仅适用于真正通用、无品牌的商品。不适用于印刷版图书。

表 2. 【场景 2. 亚马逊商城中的品牌（UPC 或 GTIN 不是必需）】
描述 步骤 说明
除了 GTINx，您还必须获得品牌名称批准 (BNA)
1. 前往[添加商品](https://sellercentral.amazon.com/product-search)工具，在搜索栏中输入您的商品名称，然后点击【搜索】。点击【创建新商品信息】。
2. 填写商品详细信息并选择合适的商品类型/分类
3. 为 BNA（品牌名称批准）输入品牌名称
4. 勾选“我没有商品编码”，然后点击【下一步】
5. 然后，您将被定向到一个新窗口进行申请，如果您没有看到申请的即时链接，请查看您的卖家申请控制面板中是否有待处理草稿，然后完成申请

**时间线： 48 小时内。** 检查[问题日志](https://sellercentral.amazon.com/cu/case-lobby?ref=xx_caselog_cont_home)中的申请状态

如果获得批准，您将同时获得 BNA 和 GTIN 豁免

1. 前往[添加商品](https://sellercentral.amazon.com/product-search)工具，在搜索栏中输入您的商品名称，然后点击【搜索】。点击【创建新商品信息】。
2. 填写商品详细信息并选择合适的商品类型/分类
3. 输入品牌名称
4. 勾选“我没有商品编码”，然后点击“下一步”
5. 然后，您将被定向到一个新窗口进行申请，如果您没有看到申请的即时链接，请查看您的卖家申请控制面板中是否有待处理草稿，然后完成申请。

【时间线： 48 小时内。检查】[问题日志](https://sellercentral.amazon.com/cu/case-lobby?ref=xx_caselog_cont_home)中的申请状态

如果获得批准，您将同时获得“仅匹配”和 GTIN 豁免

描述 步骤 说明
没有可用的豁免途径
1. 前往[添加商品](https://sellercentral.amazon.com/product-search)工具，在搜索栏中输入您的商品名称，然后点击【搜索】。点击【创建新商品信息】。
2. 在创建商品信息时输入品牌名称
3. 如果该品牌强制使用 GS1，您将看到一则通知，提示需要有 GTIN
4. 您不可以申请豁免或发布没有商品编码的商品
5. 要发布商品，您必须从品牌所有者处获取 GTIN 或 UPC，或者从 GS1 处购买

【时间线： 自动拒绝】

发布没有有效 GTIN 的商品将导致错误

**注意： **对于您想要在没有商品编码的情况下发布商品的每个商城和分类，您需要分别申请 GTIN 豁免。但是，一旦获得批准，您不需要为同一分类中的单个商品单独申请豁免。例如，如果您想要发布没有商品编码的衬衫和裤子，则只需对整个服装分类申请一次豁免即可。这种单次分类豁免将涵盖这两款商品以及您将来希望在没有商品编码的情况下发布的任何服装商品。请注意，如果您在多个商城销售商品，则需要分别在每个商城获得这一分类的豁免。有关更多信息，请参阅[亚马逊无品牌商品政策](https://sellercentral.amazon.com/gp/help/external/G84H3T69ZX762NWT)。

## 批准之后（发布方法）
- 获得 GTIN 豁免批准后，请等待 30 分钟再发布商品。如果没有等待 30 分钟，您可能会看到商品编码错误，因为系统正在处理此项豁免信息。
- 按照批准通知中的内容，输入确切的分类和品牌名称
- 对于图书： 在品牌和制造商字段中使用确切的出版商名称

【发布方法：】

**A. 添加商品（逐个）**

1. 前往[添加商品](https://sellercentral.amazon.com/product-search)工具并选择【空白表单】选项。
2. 输入详细信息，然后勾选“我没有商品编码”。
3. 填写所有必填字段并提交（请参阅上面的情景表了解更多信息）

**批量上传商品（批量上传）**

1. 前往[批量上传商品](https://sellercentral.amazon.com/product-search)工具。
2. 点击【下载空白模板】，然后前往【下载商品电子表格】。
3. 如果您在【选择您想要创建商品的商城】部分选择了多个商城，则可以使用旧模板下载电子表格。
  - 生成电子表格后，在填写电子表格时，将 **external_product_id_type** 和 **external_product_id** 输入列留空。

4. 如果您在【选择您想要创建商品的商城】部分选择了单个商城，则可以使用新模板下载电子表格。
  - 填写生成的电子表格，从下拉菜单中选择 【GTIN 豁免】作为【商品编码类型】。将【商品编码】列留空。

5. 上传填写完毕的电子表格。

## 【特殊情况（无品牌商品、捆绑商品、例外情况）】
【捆绑商品要求】

每个组件必须满足以下情况之一：

1. 目前没有 GTIN
2. 或者，属于已批准品牌的一部分
3. 必须遵循商品[捆绑销售政策](https://sellercentral.amazon.com/help/hub/reference/G200442350)
4. 所有组件必须单独拍照并在完全组装后拍照
5. 在描述中列出所有组件

**例外情况请求**

为确保提供可信赖的购物体验，亚马逊会定期识别已注册 GTIN 的品牌。亚马逊已经识别出拥有 [GS1 条形码](https://sellercentral.amazon.com/help/hub/reference/GLE2KYT2UVPMTYGS)的品牌不符合 GTIN 豁免资格，必须提供有效的商品编码。 此外，对于最初没有 GTIN 但此后已获得 GS1 条形码的品牌，亚马逊可能会终止之前的 GTIN 豁免。

如果您的某个品牌不符合豁免要求，并且需要商品编码，而您认为该品牌不应具有 GTIN，那么您可能符合例外情况的要求。以下是您可以为需要提供商品编码的品牌申请例外情况的一些场景：

- 您的品牌商品可能与某个需要提供商品编码的品牌同名。
- 您可以提供品牌或制造商出具的授权书 (LOA)。
- 您发布商品的国家/地区目前不能提供 GTIN。
- 您不能为您的商品购买新的 GTIN（例如，费用太高，或者商品销售总额较低）。
- 您的商品是替换零件，没有 UPC。

如果您的品牌不符合要求，但您认为应该被豁免：

1. 前往[获取帮助和资源](https://sellercentral.amazon.com/help/hub)页面，然后点击【添加新商品】。 **注意： **亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。

2. 点击【商品编码豁免】，然后点击【联系员工】。
3. 提供详细信息，包括品牌、商品类型、国家/地区，您收到的“UPC 豁免未批准”错误，及其为何有资格获得豁免的说明。
4. 选择【检查并提交】，然后选择【电子邮件】。
5. 提供符合申请 GTIN 豁免的图片指南要求的商品图片，以及“UPC 豁免未批准”错误消息的屏幕截图，然后点击【发送】。
