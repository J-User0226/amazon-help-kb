# 创建库存文件

本帮助页面介绍构建库存文件的完整流程。这包括生成模板、用您的商品和报价数据填写模板、随时间管理您的商品信息，以及更新或删除现有商品信息。每个文件最多可上传 10,000 行商品数据。

**注意： **此功能仅适用于专业销售计划。要了解更多信息，请参阅[销售计划对比](https://sellercentral.amazon.com/gp/help/external/64491)。

## 生成您的模板

在填写文件之前，请生成针对您的商品定制的模板。亚马逊会根据您选择的商品类型构建该模板，因此它仅包含与您的目录相关的属性。

**选择您的模板类型**

- 商品电子表格： 如需创建尚未在亚马逊目录中的新商品，请使用此模板。

- 商品信息加载工具： 如需为目录中已有商品添加报价，请使用此模板。

- 商品价格和数量： 如需更新现有报价的价格和数量，请使用此模板。

有关所有模板类型的概述，请参阅[批量商品信息模板](https://sellercentral.amazon.com/help/hub/reference/G1641)。

**生成商品电子表格模板**

使用商品电子表格模板为尚未在亚马逊目录中的商品创建商品和报价。需要填写商品详情。

- 前往[添加商品](https://sellercentral.amazon.com/product-search/bulk)，然后选择【电子表格】选项卡。

- 点击【下载空白模板】。

- 在【发布当前不在亚马逊目录中的商品】下，点击【下载商品电子表格】。

- 选择您要销售的商品类型。您可以使用任一方法： 

- 搜索： 输入关键词或商品名称（例如，“女式针织帽”或“帆布墙面装饰画”），然后点击【搜索】。系统会根据您的输入预先选择相关的商品类型。您可以在选择之前或之后编辑列表。

- 按分类浏览： 选择一个商品分类，并逐步缩小分类范围，直到您可以点击【选择】。

- 仔细核对您已选择的商品类型。您可以删除不再需要的内容。

- 选择您要创建或编辑商品信息的商城。

- 点击【生成电子表格】，下载您的模板。

**注意： **如果您为所选商品类型保存了[商品信息首选项](https://sellercentral.amazon.com/listing-preferences)，则会看到一个可将其包含在内的选项。如果选择此选项，您保存的属性值将预填充到模板的第一行。然后您可以根据需要将这些值复制到其他行。

## 了解模板结构

您下载的模板按列分类组织：

| 分类 | 包含 |
| --- | --- |
| 变体 | 父 SKU、父子关系级别、变体主题 |
| 商品编码和详情 | SKU、商品类型、商品编码、商品名称、品牌、描述和其他目录属性 |
| 图片 | 主图片 URL 和其他图片 URL |
| 报价 | 价格、数量、配送渠道、状况、亚马逊企业购 (B2B) 定价 |
| 配送 | 配送、备货时间、预处理说明 |
| 安全与合规性 | 电池、危险品及法规属性 |

**注意： **亚马逊企业购 (B2B) 定价属性包含在报价分类中。

属性标记为：

- 必填： 每个商品都必须填写

- 有条件必填： 根据您在其他字段中输入的值成为必填

- 选填： 提供额外的商品详情，但非必填

要查看选填属性，请点击列上方的 【+/-】 符号，或使用工作表左上角的 【1】（默认视图）或 【2】（高级视图）按钮。在默认视图中，每组中的第一个属性保持可见，以便您找到特定组。

有关每个属性的详细定义，请阅读模板文件中包含的说明。

## 填写您的模板

要填写库存模板，请按以下步骤操作：

- 在 Microsoft Excel 或兼容的电子表格程序中打开您下载的模板。

- 为每个商品输入数据，每个 SKU 一行。

- 先填写必填属性，然后填写有条件必填属性，最后根据需要填写选填属性。

- 为每行设置商品信息操作。

**注意： **如果您在生成模板时包含了商品信息首选项，则第一行会预填充您保存的默认值。将这些值复制到其他适用的行。

## 主要字段和最佳实践

**商品信息操作值**

【商品信息操作】列会告知亚马逊如何处理每一行：

| 值 | 作用 |
| --- | --- |
| 创建或替换（完全更新） | 创建新的商品信息，或将现有商品信息替换为您提供的值。如果留空，则此为默认选项。 |
| 编辑（部分更新） | 仅更新您为现有商品信息提供的属性。留空的属性不会被更改。 |
| 删除 | 从您的目录中移除 SKU。 |

**SKU**

SKU 是每个库存文件中的关键标识符。请遵循以下规则：

- 每个商品必须具有唯一的 SKU。

- 您上传的每个新 SKU 都会在亚马逊目录中创建一条新记录。

- 现有 SKU 无法更改。它会一直保留在目录中，直到您将其删除。

- 如果您为现有 SKU 上传数据，新数据将替换该 SKU 的先前数据。

**商品编码（UPC、EAN、JAN、ISBN）**

创建新商品信息时，请始终提供有效的标准商品编码。有关各分类要求，请参阅[商品编码 (GTIN) 要求](https://sellercentral.amazon.com/help/hub/reference/G200317470)。

**搜索词**

搜索词能够帮助买家找到您的商品。大多数商品类型最多支持 5 个搜索词字段。使用与买家搜索方式匹配的关键词。有关提示，请参阅[提高商品曝光度](https://sellercentral.amazon.com/help/hub/reference/G10471)

**价格**

- 确保价格字段为数字格式，尤其是在使用逗号作为小数分隔符时

- 要删除 SKU 上的报价，请使用下拉菜单将“您的价格”设置为“删除报价”

- 要删除卖家允许的最低价格，请使用下拉菜单将其设置为“删除卖家允许的最低价格”

- 要删除卖家允许的最高价格，请使用下拉菜单将其设置为“删除卖家允许的最高价格”

**图片**

所有商品都必须提供图片。在提供图片之前，该 SKU 将无法购买。

您可以通过两种方式提供图片：

- **模板中的图片 URL：** 在模板的主图片和附加图片列中输入图片 URL。

- **图片上传工具：** 先提交模板，然后使用[图片上传工具](https://sellercentral.amazon.com/imaging/upload)单独上传图片。

**注意： **如果您要为亚马逊目录中已有的商品添加报价，则无需提供图片；系统将使用现有商品页面图片。有关亚马逊的图片标准，请参阅模板中的"图片"选项卡。有关完整的商品图片要求，请参阅[商品图片要求](https://sellercentral.amazon.com/help/hub/reference/G1881)。

**创建变体（父子商品关系）**

某些分类支持变体关系，其中包含一个不可售的父商品和多个可售的子商品。

要设置变体，请按照以下步骤操作：

- 创建父商品行。输入父 SKU，并将【父子关系级别】设置为【父】。父商品不直接销售，而是将子商品组合在一起。

- 为每个变体创建一个子商品行。输入子 SKU，将【父子关系级别】设置为【子】，并在【父 SKU】 列中输入父 SKU。

- 为系列中的所有行设置【变体主题】，例如尺码、颜色、尺码颜色。

在商品名称中区分每个子商品。例如： “棉质 T 恤，红色，大号”和“棉质 T 恤，蓝色，中号。”

可用的变体主题因商品类型而异。

**注意： **如果您的商品存在适当的变体主题，您必须设置父子关系。

有关变体的更多信息，请参阅[商品变体概览](https://sellercentral.amazon.com/help/hub/reference/GH3RMVV3ZDYRRQ5S)。

**设置备货时间**

备货时间是指您将商品交付给运输承运人所花费的时间。买家的总配送时间为备货时间加上承运人运输时间。

请在“备货时间”字段中设置此值。此值必须是 0 至 30 之间的数字。

| 输入（天数） | 买家消息 |
| --- | --- |
| 空白 0~2 | 有货 |
| 3 | 通常会在 2~3 天内发货 |
| 4~14 | 通常在 [n-1] 到 [n] 天内发货 |
| 15~21 | 通常会在 2~3 周内发货 |
| 22~28 | 通常会在 3~4 周内发货 |
| 29~30 | 通常会在 4~5 周内发货 |

**注意： **如果您未指定备货时间，则默认为 1~2 天。更新库存时请务必包含备货时间，以防止其重置为默认值。

## 更新现有商品信息

您无需在每次要进行更改时都重新上传整个文件。您可以上传仅包含要更新的 SKU 的文件。

**增量更新的工作原理：**

- 您为某个 SKU 提交的数据将保留在目录中，直到您为同一 SKU 上传新数据。

- 当您为现有 SKU 上传新数据时，新值将替换以前的值。

- 上传文件中未包含的 SKU 不会受到影响。

要更新特定商品信息，您有两个选项：

**选项 1：** 通过您的分类商品报告进行编辑

- 前往[库存报告](https://sellercentral.amazon.com/listing/reports)，然后选择【分类商品报告】作为报告类型。

- 请求并下载此报告，获取包含您之前提交的 SKU 值的电子表格。

- 编辑您想要更改的值。

- 提交电子表格以更新您的目录。

有关更多信息，请参阅[下载分类商品报告](https://sellercentral.amazon.com/help/hub/reference/GFYSJC946YKTD68L)。

**选项 2：** 下载空白模板

- 前往[添加商品](https://sellercentral.amazon.com/product-search/bulk)，然后选择【电子表格】选项卡。

- 点击【下载空白模板】。

- 点击【下载商品电子表格】，然后选择正确商品类型。

- 提供 SKU，并将商品信息操作设置为【编辑】（部分更新）。

- 仅提供您想要更新的特定属性。

- 提交文件以更新您的目录。

## 删除商品

要删除商品信息，请执行以下操作：

- 前往[添加商品](https://sellercentral.amazon.com/product-search/bulk)，然后选择【电子表格】选项卡。

- 点击【下载空白模板】。

- 点击【下载商品电子表格】，然后选择任意商品类型。

- 输入 SKU，并将【商品信息操作】设置为【删除】。

- 上传文件。

**重要： **删除 SKU 会移除该商品的报价以及您为该商品提供的商品数据。如果您只是需要暂时将商品设为无货，请改为将数量设置为零。

**变体的特殊注意事项：**

- 删除父商品会移除该父商品与其所有子商品之间的关系（子商品将成为独立的商品信息）。

- 删除子商品仅会将该子商品从变体系列中移除。

- 要将子商品移至其他父商品，请先删除该子商品（或原始父商品），然后将其重新分配给新的父 SKU。

## 多商城商品信息模板

如果您在生成模板时选择了多个商城，则会出现更多列，用于特定商城的报价数据（包括价格）。

**要点：**

- 请为您想要发布商品的每个商城提供报价数据（至少提供价格）。

- 如果次要商城中不存在商品详情页面，亚马逊将尝试通过翻译您的商品数据来创建该页面。此过程最多需要 48 小时。

- 价格必须使用每个商城的当地货币（显示在列标题中）。

- 在整个模板中使用一致的小数分隔符。

**保存您的文件**

您可以保存文件并以 Excel 工作簿 (.xlsx) 格式上传。您无需将其转换为制表符分隔格式（.tsv 或 .txt）。

**提示：** 在上传之前，保存一份副本作为您的 Excel 工作文件（在文件名中包含日期以便进行版本追踪）。我们建议您在电脑上保留一份备份副本，以便日后用于更新。
