# 高压清洗机

如果您要在亚马逊商城发布商品，则必须遵守与这些商品和商品信息相关的所有适用法律、法规、标准以及亚马逊政策。

## 我们关于高压清洗机的政策

高压清洗机是一种功能强大的清洁设备，它利用泵将水以高压状态从喷嘴喷出，可清除壁板、舱面、车道和汽车等表面上的顽固污垢、油渍、霉菌和油漆。这类设备需连接电源（可选电池供电或汽油动力）及水源，随后通过电机对水进行加压，并通过喷枪将水喷出。本政策适用于家用和轻型商用高压清洗机，此类设备的运行压力通常在 5,000 PSI 范围内。PSI（磅/平方英寸）是衡量水压的单位，它反映了水流喷射到物体表面时剥离污垢和污渍的冲击力度。

**家用高压清洗机**

家用高压清洗机是专为家庭使用而设计的高压清洗设备。此类设备适用于清洁庭院家具、车辆以及小型户外表面等轻度清洁任务。

**轻型商用高压清洗机**

轻型商用高压清洗机是专为小型企业或专业用途而设计的高压清洗设备。此类设备适用于清洁建筑物外墙、停车区及各类设备等要求更高的清洁任务。

本政策不涵盖工业级高压清洗机、手动加压喷雾器，或者喷嘴、软管、喷枪等高压清洗机配件。

## 适用的法律、法规和标准

亚马逊要求所有高压清洗机均符合适用的法律、法规和标准，包括：

| 商品 | 法律、法规及标准 |
| --- | --- |
| 高压清洗机 | 以下两项之一： UL 1776（高压清洗机安全标准） UL 60335-1（家用电器和类似电器标准 - 安全性 - 第 1 部分： 一般要求）以及 UL 60335-2-79（家用电器和类似电器标准 - 安全性 - 第 2-79 部分： 高压清洗机和蒸汽清洗机的特殊要求） |
| 高压清洗机电池充电器 | 以下三项之一： UL 1012（非 2 类电源装置安全标准） UL 1310（2 类电源装置标准） UL 60335-2-29（家用电器和类似电器 - 安全性 - 第 2-29 部分： 电池充电器的特殊要求） |
| 高压清洗机电池 | 以下两项之一： UL 2054（家用电池和商用电池标准） UL 62133-2（含有碱性或其他非酸性电解质的蓄电池单元和电池标准 - 便携式密封蓄电池单元及电池组的便携应用安全要求 - 第 2 部分： 锂系统） 以及以下项： UN 38.3（锂离子电池的运输测试） |
