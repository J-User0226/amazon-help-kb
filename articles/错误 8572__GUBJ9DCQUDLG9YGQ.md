# 错误 8572

您使用的 UPC、EAN、ISBN、ASIN 或 JAN 码与您尝试发布的商品不匹配。亚马逊禁止使用不正确的编码，否则，可能会导致您的 ASIN 创建权限被暂停或永久取消。在发布商品时，请确保始终使用相应的编码。”

如果提供的商品编码（ASIN、UPC、EAN、ISBN 或 JAN）与品牌或商品不匹配，则会出现此错误。您使用的条形码不属于该品牌。请确保某个商品使用的商品编码与相应品牌的条形码相符。要解决此错误，请先查看相应情况的指南和参考信息，再[联系销售伙伴支持](https://sellercentral.amazon.com/hz/contact-us)。有关更多信息，请参阅 [ASIN 创建政策](https://sellercentral.amazon.com/gp/help/external/G201844590)。

**注意： **亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。

如果您使用的是相应的 JAN、ISBN、UPC、ASIN 或 EAN，请联系销售伙伴支持并提供以下信息，以验证您正在使用的 GTIN：

- 如果您使用的是“添加新商品”工具，请提供收到相关错误消息的商品的以下信息：
  - 错误的屏幕截图以及商品编码、品牌名称、制造商和时间戳
  - 商品名称
  - 制造商
  - 品牌名称
  - UPC、EAN、JAN 或 ISBN

- 如果您是使用库存文件模板来上传商品，请提供收到错误消息的商品的批次编号。
- 对于任一情况，还要提供一张真实的商品图片，要清晰显示永久性贴在商品上的条形码和品牌。您可以提供多张图片，以确保涵盖要求的所有信息。对于图书，请提供图书封面和封底的真实图片，其中要印有 ISBN 和出版商名称。
- 对于任一情况，还要提供 GS1 签发的证书，其中要显示您的法人实体和相关 GTIN 前缀，或者提供 GS1 网站的屏幕截图。我们不接受来自第三方的条形码。
- 对于任一情况，还要根据下述不同情况，提供有效的证据，证明您用于发布商品的全球贸易项目代码的真实性。
  1. 如果您是所销售商品的品牌所有者，请提供 GS1 证书上的法人实体与您的品牌相关的证明（例如显示您的商品或品牌并提及法人实体的版权、商标或网站）。
  2. 如果您不是品牌所有者，请提供相关制造商或品牌出具的信函或法律协议，确认您使用的全球贸易项目代码 (GTIN) 有效且归其所有，或者证明您有权使用自己的 GTIN 销售其品牌的特有商品。
  3. 如果您通过第三方许可公司（而非直接与品牌合作）获得某品牌的销售授权并获权使用自己的 GTIN，则需提供两份文件来证明从属关系链：‌品牌与许可公司之间的关系证明书或许可协议‌，以及‌您与许可公司之间的关系证明书或许可协议‌。
  4. **向亚马逊提交授权书文件时应进行的重要检查**

  5. **检查分类** **可接受**
  6. **格式检查**
    1. PDF 文件。
    2. 扫描的 PDF 图片。
    3. 文字（只有当您是品牌所有者时，才可接受自我声明）。
    4. 电子邮件的屏幕截图，发送域名应是持有受保护品牌权利的公司域名。

  7. **要素检查**
    1. 信函应由品牌或父品牌使用带有其信笺抬头的纸张（最好附有徽标）出具。
    2. 信函应明确列出 GS1 上所示的品牌和 GTIN 所有者。
    3. 信函应明确提及关联关系。
    4. 应包含出具方的名称和联系信息（也可显示在信函的页脚中或在正文中注明）。
    5. 应具有品牌代表的签名或品牌印章。

  8. 可供参考的信函模板（您提供的信函无需与以下模板完全相同，但请确保包含以下要素）

  9. 如果您的商品没有商品编码或全球贸易项目代码，那么您可能符合申请全球贸易项目代码豁免的要求。有关更多信息，请参阅[亚马逊无品牌商品政策](https://sellercentral.amazon.com/gp/help/external/G84H3T69ZX762NWT)。

## 我们的 GS1 政策
我们会通过查看 GS1 数据库来验证商品 UPC 的真实性。与 GS1 所提供信息不匹配的 UPC 将被视为无效 UPC。我们建议您直接从 GS1（而非其他出售 UPC 许可的第三方）获取您的 UPC，以确保在 GS1 数据库中体现相应的信息。请注意，如果您刚刚从 GS1 购买了新发布的 GTIN 或 UPC，我们建议您至少等待 72 小时再发布商品。这是为了确保我们能够从 GS1 数据库验证 GTIN。有关从 GS1 获得 UPC 许可的更多信息，请参阅 [GSI 标准网站](https://store.gs1us.org/barcode-identifiers?utm_source=partner&utm_medium=referral&utm_campaign=idgtm-sellercentral-gs1policy)。
