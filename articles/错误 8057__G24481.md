# 错误 8057

SKU [%s] 的“状况类型”具有可售库存，因此无法删除。 有关如何解决此问题的步骤，请参阅 http://sellercentral.amazon.com/gp/help/external/24481

当您为此 SKU 提交的“状况类型”值与 Amazon.com 目录中的现有“状况类型”值不同时，便会发生此错误。当商品在 Amazon.com 上保持在售状态时，您无法更改与商品关联的“状况类型”。要解决此错误，您必须先删除任何现有报价，然后才可更新“状况类型值”。

要使用制表符分隔的库存文件解决此问题，请采取以下操作：

1. 在您的库存文件中更改此 SKU 的“状况类型”，使其与您上次成功提交的数据匹配。
2. 在“数量”列中输入“0”（零）。
3. 提交修改后的库存文件，或者从 Amazon.com 上删除任何在售商品。
4. 在库存文件中将此 SKU 的“状况类型”更改为您的“状况类型”。
5. 在“数量”列中输入正确的数量。
6. 重新提交更新后的库存文件。

要使用 XML 上传数据解决此错误，应采取以下措施：

1. 发布库存输入数据，并将此 SKU 的数量设为“0”（零）。
2. 发布新的商品输入数据。
3. 当您的商品输入数据被成功处理时，请发布另一个库存输入数据并包含商品的有效数量。
