# 知识产权政策

本政策简要介绍了有关知识产权的信息以及在亚马逊商城销售商品时可能出现的一些常见知识产权问题。当您在亚马逊商城销售商品时：

- 您必须遵守适用于您的商品和商品信息的所有联邦、州和地方法律以及亚马逊政策

- 您不应侵犯品牌或其他权利所有者的知识产权

违反本政策可能会导致您丧失销售权限或产生其他法律后果。

**重要： **本政策不是法律建议。如果您对自己的知识产权或他人的知识产权有疑问，应咨询律师。

主要有三种类型的知识产权：

- 版权是对原创作品的法律保护

- 商标可对公司用来识别其商品或服务的文字、符号、设计或这些元素的组合提供法律保护

- 专利是针对发明的法律保护

要详细了解我们的知识产权政策，请观看此卖家大学视频。

## 亚马逊知识产权强制执行

- ** *回复知识产权侵权通知。* ** 如果您收到侵权通知或警告，但认为权利所有者或亚马逊的处理有误，您可以针对索赔提出申诉或争议。

| 通知或警告的类型 | 您可以采取的措施 |
| --- | --- |
| 对于您从未在亚马逊商城发布的商品 | 回复收到的通知，说明您从未发布过被举报的商品。我们将展开调查，以确定这其中是否出现差错。 |
| 如果您与权利所有者建立了关系 | 如果您持有的许可或其他协议允许您使用通知中指出的知识产权，请联系提交投诉的权利所有者，请求对方撤回。如果我们收到权利所有者的撤回请求，您的内容可能会被恢复。 |
| 商品或包装上的商标或假冒侵权行为 | 使用卖家账户中显示的账户状况控制面板提供可证明商品真伪的发票或订单编号。然后，我们将重新评估此通知，您的内容也可能会恢复。 |
| 商品详情页面上的商标或假冒侵权行为 | 修改商品详情页面，确保不存在商标侵权，然后前往账户状况页面提交申诉。 或者 如果您认为商品被错误下架，可前往账户状况页面提交申诉。请提供证明文件（例如授权书或许可协议）。然后，我们将重新评估此通知，也可能会恢复您的内容。 |
| 专利侵权 | 回复您收到的通知，并说明您认为处理有误的具体原因。您还可以提供法院命令，证明您的商品未侵权，或者声称的专利无效或无法执行。 |
| 版权侵权 | 您可以根据《数字千年版权法》提交反驳通知。反驳通知必须发送至版权警告中提供的电子邮件地址，其中必须包含： 您的手写签名或电子签名。您可通过电子方式签名，具体为键入您的姓名，并指示其用作签名：“/s/卖家名称”。 指明已被移除或禁止访问的材料，以及材料被移除或禁止访问之前出现的具体位置。ASIN 通常已足够。 提交一份声明，说明您确信材料是由于存在错误或判断有误而被移除或禁用，如所言不实，甘受伪证罪处罚。 提供您的姓名、地址和电话号码，并且提交声明，说明您同意接受卖家地址所在司法辖区的联邦地方法院管辖；或者，如果您位于美国境外，则声明您受美国华盛顿西区地方法院的管辖，并且您将接受举报涉嫌侵犯版权的个人或其代理人提供的流程服务。 |

- ***多项知识产权侵权警告。* ** 如果您收到多个知识产权侵权警告，且您认为自己销售的是非侵权商品，请通过卖家平台提交申诉，并提供以下信息：

涉嫌侵权的 ASIN 列表和以下至少一项（如适用）：

a.证明商品真伪的发票（您可以删除定价信息）；或

b.证明商品真伪的订单编号；或

c.权利所有者提供的授权书（不能是转发电子邮件）；或

d.认定您的商品未侵犯宣称的知识产权或宣称的知识产权无效或无法执行的法院命令。

- ***账户暂停。* **如果您的账户因收到针对您的商品或内容的知识产权侵权通知而被暂停，可向我们提交申诉。要了解更多信息，请参阅[恢复销售权限](https://sellercentral.amazon.com/gp/help/external/G201623610)。

通过[账户控制面板](https://sellercentral.amazon.com/performance/dashboard)发送申诉，或者回复收到的账户暂停通知。我们将评估您的申诉，并确定您的账户是否可以恢复。请注意，亚马逊在适当的情况下可终止反复侵权者的账户。

- ** *卖家应该遵守相关法律。* ** 亚马逊非常重视知识产权侵权问题。即使卖家在不知情的情况下侵犯了知识产权，我们仍然会采取措施，卖家账户可能会收到警告或暂令停售。您应该咨询律师寻求帮助，确保您有相应的程序来防止知识产权侵权。

#### 如何解决知识产权政策问题？

要解决侵犯知识产权的问题，请前往账户状况控制面板 (AHD) 的[账户状况](https://sellercentral.amazon.com/performance/dashboard)页面，然后选择侵权行为旁边的【提交申诉】并提供所需文件或信息。

#### 提交申诉时必须提供哪些文件和信息？

每种侵权行为都有各自的特点。这些特点将显示在[账户状况](https://sellercentral.amazon.com/performance/dashboard)页面上。在申诉和争议过程中，您可以参阅[账户状况](https://sellercentral.amazon.com/performance/dashboard)页面，获取相关指导。

#### 商品与品牌如何关联？

亚马逊将品牌视为代表一款商品或一组商品的名称。同一品牌的商品在商品或包装上标有统一的名称、徽标或其他识别标记，用来将这些商品与不属于该品牌的相似商品区分开。要了解更多信息，请参阅[亚马逊品牌名称政策](https://sellercentral.amazon.com/gp/help/external/G2N3GKE5SGSHWYRZ)。

#### 什么是品牌注册？

品牌注册是亚马逊的一项权威服务，用于管理和保护品牌。亚马逊品牌注册是一项全球性服务，其中包含： (A) 品牌名称，(B) 品牌资料数据（例如，商标、徽标）以及 (C) 具有该品牌角色（例如，权利所有者、品牌代表）的账户。

#### 验证权利需要哪些文件？

在对强制措施提出申诉时，您通常需要提供发票或授权书 (LOA)，以证明其有权销售相关商品。亚马逊将审核这些文件，以验证商品真伪或销售授权。如果商品经确认为正品，亚马逊将从您的卖家账户中移除强制措施声明。每种类型的侵权行为都具有各自的申诉步骤和要求。在申诉过程中，[账户状况](https://sellercentral.amazon.com/performance/dashboard)页面将针对不同情况提供具体指导。

#### 商品发布规则和政策有哪些？

请查看[商品详情页面规则](https://sellercentral.amazon.com/gp/help/external/G200390640)，了解亚马逊关于编写商品信息以及添加和编辑商品详情页面的规则和政策。如果您是权利所有者，或者想要了解有关不同类型的知识产权的更多信息，请参阅[权利所有者的知识产权](https://sellercentral.amazon.com/gp/help/external/GU5SQCEKADDAQRLZ)。

#### 在电子商务活动中，哪些行为构成知识产权 (IP) 侵权？如何确保这些行为合规？

如果未经授权使用受保护的知识产权，则会构成电子商务活动中的知识产权侵权。这包括未经授权使用受版权保护的材料、商标、专利或公开权。示例包括：销售假冒商品、未经许可使用受版权保护的图片等。为避免侵权行为，您应获得适当的许可，验证商品真伪，使用原始内容并提供准确的描述。任何未经授权的使用都可能导致法律诉讼和商城处罚。如果您是权利所有者，或者想要了解有关不同类型的知识产权的更多信息，请参阅[权利所有者的知识产权](https://sellercentral.amazon.com/gp/help/external/GU5SQCEKADDAQRLZ)。
