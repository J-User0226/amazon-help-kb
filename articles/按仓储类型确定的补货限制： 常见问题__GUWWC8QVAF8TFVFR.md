# 按仓储类型确定的补货限制： 常见问题

#### 什么是补货限制？

补货限制是根据您的历史销量和预测销量按仓储类型设置的，您可以在您的 ASIN 之间分配此限制。您可以展开页面底部的**补货限制监视器**，在“库存绩效”或“货件处理进度”中查看您的仓储类型级别的补货限制及库存限额使用量。

![](https://m.media-amazon.com/images/G/01/rainier/US_pik_for.png)

补货限制监视器显示以下内容：

- “最高库存水平”（或补货限制）。该值是根据您的历史销量和预测销量计算的，并根据配送能力进行调整。

- “库存限额使用量”。该值计入您的最高库存水平，并用于确定您可以发送的最大货件数量。库存限额使用量包括您在亚马逊的当前库存和所有入库货件，包括处于**处理中**、**运输中**和**正在接收**状态的货件。在计算库存限额使用量时，不包括等待移除的库存和所有预留库存。要按分类类型查看库存限额使用量，请转至您的补货限制监视器，并按仓储类型查看您的库存限额使用量。

- “最大货件数量”。该值表示您还可以向亚马逊运营中心运送的商品数量，计算方法是用允许的最高库存水平减去库存限额使用量。

#### 补货限制为何从 ASIN 级别变为仓储类型级别？

我们在不断改进各项政策，以提高亚马逊配送网络的效率并更好地接收您的商品。我们认为，补货限制可让您更灵活地分配仓储限制并管理您发往亚马逊的库存。

#### 如何计算补货限制？

生成补货限制时，系统会考虑多种因素，包括商品的季节性销售周期和销售旺季、ASIN 预测销量以及您所销售的新商品。预测销量由复杂的机器学习模型生成，可根据历史销量来预测商品的季节性销量。

#### 我怎样确定自己可以发送多少库存？

请转至补货限制监视器，查看您的按仓储类型确定的最大货件数量。您可以基于自己的选择将其用于您的 ASIN。

**重要： **运送的库存数量超过允许发送的最大货件数量将会违反亚马逊政策，可能导致不合规货件被取消。如果您创建货件时并未超出限制数量，但随后该限制数量下降且低于您的库存限额使用量，则该货件不会被取消。

#### 我的亚马逊物流补货限制会发生变化吗？

我们不断评估我们的网络容量，以寻找机会来提高您的补货限制并为您的业务提供最佳支持。您可以展开库存绩效控制面板底部的补货限制监视器，查看您最新的补货限制。我们将定期更新补货限制。销售伙伴支持团队没有更进一步的指导信息，请知悉。

#### 为什么我无法为某些仓储类型创建货件？

您无法为商品创建货件的原因可能有以下几方面：

- 入库计划中的商品超出您在该仓储类型的最大货件数量

- 您的分类类型库存限额使用量已超出补货监视器中所示的补货限制

- 您已超出该仓储类型的仓储容量限制

- 该 ASIN 有政策方面的限制，例如危险物品政策限制

#### 如何使用补货限制更好地管理我的库存？

- 降低库存限额使用量

您可以发送的最大货件数量等于最高库存水平减去库存限额使用量。因此，降低库存限额使用量有助于留出空间来创建新货件。

您可以通过以下方式降低库存限额使用量：(1) 取消您不打算发往亚马逊的商品所对应的正在处理的货件；(2) 减少您在运营中心的库存量。

- 您可以在[货件处理进度](https://sellercentral.amazon.com/gp/fba/inbound-queue/index.html)中查看和取消任何正在处理的货件。要取消或删除货件，请点击货件名称，或者点击**查看货件**或**追踪货件**。然后点击**取消货件**或**删除货件**。

- 有三种方法可以减少您在运营中心的库存：

- 销售更多库存。有关提高销量的建议，请访问[管理库存状况](https://sellercentral.amazon.com/inventoryplanning/manageinventoryhealth)。它可帮助您就冗余和超龄库存做出正确的决定。此外，您可以使用[多渠道配送](https://sellercentral.amazon.com/gp/help/external/G200332450)，通过其他销售渠道（例如您自己的网站）销售库存。

- 通过创建移除订单，请求退回库存。

- 通过创建移除订单，请求弃置库存。

有关更多信息，请参阅[移除库存（概览）](https://sellercentral.amazon.com/gp/help/external/200280650)。

**重要： **当您提交移除订单或进行类似更改时，库存仓储容量会在您的请求处理完毕后才能反映出相关更改，通常是在第二天。买家退货也会计入您的整体库存数量。

- 为畅销商品补货，提高销量并拓展业务

要查看这些 SKU 的**建议补货数量**并尽快补货，请转至[补充库存](https://sellercentral.amazon.com/restockinventory/recommendations)。我们对此工具进行了改进，能够根据各仓储类型的补货限制为您提出建议。

“补充库存”工具可帮助您规划要发往亚马逊运营中心的库存量以及发送时间。建议显示在这些列中： **建议补货数量**和**建议发货日期**。

#### 我的多渠道配送 (MCF) 订单对我的补货限制有何影响？

多渠道配送订单包括在您历史销量和预测销量数据中，用于计算您的补货限制。

#### 我的亚马逊物流商品也要遵守 ASIN 数量限制吗？

属于标准尺寸商品、大件商品、“服装”和“鞋靴”仓储类型的商品无需再受 ASIN 级别的数量限制。您可以根据相应仓储类型的补货限制，发送此类库存至亚马逊。

但是，亚马逊物流受限商品可能需要遵守不同的数量限制政策。有关更多信息，请参阅[受限商品](https://sellercentral.amazon.com/help/hub/reference/G200164330)。

#### 补货限制与仓储限制有何不同？

补货限制和仓储限制是两种不同的限制，前者用于管理库存的流入，后者用于管理运营中心的实际空间使用量。

补货限制是根据卖家和具体 ASIN 这两方面的历史销量和预测需求计算得出的。您可以发送的最大货件数量等于允许的最高库存水平减去库存限额使用量。

仓储限制与您的库存绩效指标 (IPI) 分数有关，该分数用于衡量您管理现有亚马逊物流库存的能力和效率。

**注意： ** 无论您的库存绩效指标分数如何，都需要遵守补货限制。

| | 补货限制 | 仓储容量限制 |
| --- | --- | --- |
| 定义 | 取决于历史销量和预测销量，决定了您可以发往亚马逊运营中心进行储存的最大商品数量。 | 基于体积，以立方英尺为单位，决定了可供您使用的运营中心容量。 |
| 管理哪个方面？ | 库存流入 | 物理存储体积 |
| 库存绩效指标分数相关性 | 不论库存绩效指标分数如何，均适用 | 如果您的库存绩效指标低于有关标准，则适用 |
| 更新频率 | 定期 | 每季度 |
| 限制格式 | 商品数量 | 立方英尺或立方米 |
| 使用量超出限制时适用的费用 | 不适用 | 超量费 |
| 使用量 | 包括亚马逊库存和运输途中的货件 | 包括亚马逊库存 |

仓储限制和补货限制可能同时适用于您的账户。如果达到任何分类的补货限制或仓储容量的上限，您将无法再向亚马逊运营中心发送相应分类（标准尺寸商品、大件商品、服装和鞋靴）的库存。您可以通过[库存绩效控制面板](https://sellercentral.amazon.com/inventory-performance/dashboard)查看这些限制。

在[库存绩效控制面板](https://sellercentral.amazon.com/inventory-performance/dashboard/)和[货件处理进度](https://sellercentral.amazon.com/gp/fba/inbound-queue/index.html)页面展开**仓储容量**，即可查看当前和潜在的仓储限制以及使用情况。

#### 亚马逊是否会做出其他变更？

我们将继续做出调整，为您的业务提供最佳支持，并确保您能一直了解最新的动态。

#### 我能否更改商品的仓储类型？

不可以。仓储类型是根据商品特征确定的。要查看您的商品归为哪种仓储类型，请参阅[亚马逊物流库龄](https://sellercentral.amazon.com/inventoryplanning/inventory-age)。

#### 我能否将一种仓储类型的补货限制与另一种仓储类型的补货限制进行交换？

不可以。不同仓储类型的补货限制不能交换。
