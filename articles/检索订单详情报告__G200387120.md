# 检索订单详情报告

## 描述
检索订单报告，该报告包含一个在先前的订单报告创建后收到的新订单列表。该报告包含了处理您的订单所需要的全部信息。当您打开账户后，亚马逊将与您一同确定生成报告的频率（如每天或每小时）。如果需要较高的频率，订单报告可以每 15 分钟生成一次。 **注意： **XML 不是订单报告的默认格式。如果想要生成的报告是 XML 格式，请点击大部分卖家平台页面底部的 ［ 联系销售伙伴支持 ］ 链接联系我们，并告知我们您想要为账户配置该选项。

**注意： **亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。

## 术语表
元素 描述
**亚马逊订单编号** 亚马逊为订单提供的唯一标识，用于识别整个订单，不论订单中各种商品的数量是多少。
**亚马逊会话编号** 亚马逊提供的将单个订单链接到同一购买会话的唯一标识（仅供亚马逊使用）。
**订单日期** 下订单的日期。
**订单发布日期** 买家使用信用卡付款和订单处理完成的日期。
**账单数据** 账单信息容器，包含以下要素：
- 买家电子邮件地址
- 买家姓名
- 买家电话号码

**配送数据** 订单配送信息的容器，包括以下要素：
- 配送方式
- 配送服务级别
- 地址容器
  - 名称
  - 地址字段一
  - 地址字段二
  - 城市
  - 州或地区
  - 邮政编码
  - 国家/地区代码

**亚马逊订单商品编码** 亚马逊为订单内的商品提供的唯一标识。
**SKU** 特定卖家为特定商品提供的唯一标识。
**商品名称** 对商品的简短描述。
**数量** 购买的数量（单个商品）。
**商品税务代码** 识别商品的税务属性。商品税务代码首先在商品上传数据中被识别，然后在买家订购商品后传输至订单报告。
**商品价格** 买家购买商品所支付的金额，按类型（要素）分类。全部金额指所购全部商品的总价格，而非商品单价。商品价格包含以下要素：
- 本金
- 配送
- 税费
- 运费税

**商品费用** 您需要付给亚马逊的商品金额。商品费用包含以下要素：
- 佣金

**税收辖区** 用于提供纳税辖区的容器。税收辖区包含以下要素：
- 纳税地点代码
- 城市
- 县
- 州

**应纳税金额** 应纳税金额，按辖区分类。根据商品纳税规则计算得出的应纳税金额（该金额与您的征税设置相对应）。应纳税金额包含以下要素：
- 区
- 城市
- 县
- 州

**非纳税金额** 非纳税金额，按辖区分类。根据商品纳税规则计算得出的非纳税金额（该金额与您的征税设置相对应）。非纳税金额包含以下要素：
- 区
- 城市
- 县
- 州

**零税率金额** 与税率为 0% 的地点相关联的金额，按辖区分类。零税率金额包含以下要素：
- 区
- 城市
- 县
- 州

**征税额** 征税总额，按辖区分类。征税额包含以下要素：
- 区
- 城市
- 县
- 州

**税率** 区、城市、县和州税率，按辖区分类。税率包含以下要素：
- 区
- 城市
- 县
- 州

**促销优惠码** 买家为了获得指定的促销优惠而在结账时输入的代码
**卖家促销编号** 卖家用于追踪指定促销的编号
**是否为企业订单** 表示订单是否为[亚马逊企业购买家](https://sellercentral.amazon.com/gp/help/external/201750810)所下。（仅适用于[亚马逊企业购卖家计划](https://sellercentral.amazon.com/hz/b2bregistration)。）
**采购订单编号** 买家的采购订单编号（仅适用于企业订单）。[了解有关买家提供的采购订单编号的更多信息](https://sellercentral.amazon.com/gp/help/external/GQBDHEYGMALGGASA)。[了解更多有关企业订单的信息](https://sellercentral.amazon.com/gp/help/external/201750810)。
**价格指定** 表示买家所使用的企业商品价格类型。[了解有关企业商品价格的更多信息](https://sellercentral.amazon.com/gp/help/external/201740300)。（仅适用于[亚马逊企业购卖家计划](https://sellercentral.amazon.com/hz/b2bregistration)。）
**配送设置自动化** 识别订单是否对应已分配给配送模板的 SKU。如果对应，亚马逊将使用您的地点、买家地点以及您首选承运人的最新运输时间自动代您计算运输时间。支持配送设置自动化功能的商城会显示列值。
**亚马逊计划** 包含与 Subscribe and Save、Amazon_Bazaar、Amazon_Haul、FBM Ship plus 等项目相关的计划列表。
**备货时间设置** 与卖家自配送订单备货时间计算方法相关的信息。所含要素见下文。计算方法请在“修改备货时间”中查看。
- 备货时间

为订单所涉 SKU 设置的备货时间，以自然日为单位

- 备货时间源

可能的值包括“Automated”“Seller-override”“Seller-set”“Amazon_override”以及“Unknown”

- 有效备货时间

用于计算订单送达日期的实际备货时间。这可能会长于设定的备货时间，因为需要考虑可能会延长备货时间的其他因素。这些因素包括：因在订单截止时间之后、在订单处理容量达到极限后或者在假日季或非营业日期间收到订单而导致延长的情况

**运输时间设置**
与卖家自配送订单运输时间计算方法相关的信息。所含要素见下文。在[修改运输时间](https://sellercentral.amazon.com/gp/help/external/G202169100)帮助页面中了解详情

- 运输时间

此字段显示将订单交付给承运人后预计送达所需的自然天数

- 运输时间源

显示确定运输时间的方式。如果显示为“Seller-set”，则运输时间将根据您在配送模板中依据配送区域选择的值计算得出。“Automated”指亚马逊根据您的库房地点和买家地点以及您首选承运人提供的最新运输时间计算运输时间

- 发货地址（国家/地区，州/省，市）

用于计算运输时间的发货地址。如果运输时间源为“Seller-set”，则此字段为空

**购买配送服务使用率** 表明货件标签是否是通过亚马逊购买配送服务购买的。支持亚马逊购买配送服务的商城会显示列值，对于未发货订单，此值为空。在[购买配送服务如何运作？](https://sellercentral.amazon.com/gp/help/external/GLXKP5E6P6QTSSU8)中了解亚马逊购买配送服务的运作方式
**注意： **如果您选择使用此链接中的 OrderReport.xsd，以便通过亚马逊销售伙伴 API 验证 XML 订单报告，请务必在您的验证逻辑中添加错误处理代码。亚马逊销售伙伴 API 客户端应用程序中包含的所有报告验证都应该能够妥善处理未被识别的新响应元素或响应元素值。有关更多信息，请参阅“销售伙伴 API 概览”。
