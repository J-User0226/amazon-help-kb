# 下载卖家自配送未发货订单报告

要下载您的未发货订单报告，请前往“订单报告”页面，选择“未发货订单”，然后按照以下步骤操作：

- 当【下载】按钮出现在您请求的报告的【下载】列中时，点击此按钮。此时将显示“另存为”对话框。

- 选择文件夹位置，然后点击**保存**。

在您下载卖家自配送未发货订单报告后，您可以在任何数据库或电子表格程序（例如 Microsoft Access 或 Microsoft Excel）中打开该报告。
订单报告上传数据中不包含买家的信用卡信息，仅包含买家的电子邮件、姓名、电话号码和收货地址。
收货地址由买家在下单时提供，亚马逊不会确认任何邮政编码或收货地址。
