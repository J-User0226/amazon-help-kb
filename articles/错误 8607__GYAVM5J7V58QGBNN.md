# 错误 8607

## 错误消息

每个捆绑商品只能引用一次 SKU ${component_sku}。请按照以下指示进行操作，然后重新提交上传数据： 1) 移除对组件 SKU 的一个引用之外的所有其他引用。2) 指定一个数量，以便多次包含该组件。

## 导致错误 8607 的原因

导致此错误的原因如下：

- 当同一 SKU 在库存上传数据中多次作为组件商品发布时，就会触发此错误。

- 使用库存模板文件或 XML 上传数据构建商品捆绑商品时，每个组件 SKU 在每个捆绑商品中必须仅显示一次。如果在同一捆绑商品父 SKU 下的两个或更多行或节点中输入了相同的 SKU，则系统会拒绝提交内容并出现此错误。

- 卖家试图通过重复 SKU 而非使用数量字段来指示同一组件的多件商品。

- 在更新或编辑上传数据时将重复的组件 SKU 放入现有捆绑商品中。

## 解决错误 8607

要解决此错误，请按照以下步骤操作：

- 查看您的上传数据处理汇总报告，并确定受影响捆绑商品中出现的所有 ${component_sku}。

- 移除组件 SKU 的所有重复条目，仅保留一个引用。

- 如果捆绑商品旨在包含同一组件商品的多件商品，请勿重复该 SKU。而是保留单个 SKU 条目，并更新数量属性或列，以反映正确的商品数量。例如，如果捆绑商品包含三件 ${component_sku}，请在该 SKU 的单个剩余条目中将 【Quantity】 字段设置为“3”。

- 进行必要的更改后，检查上传数据中的整个捆绑商品定义，以确认其他组件 SKU 均未重复，并重新提交更新后的上传数据文件。
