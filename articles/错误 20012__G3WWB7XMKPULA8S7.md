# 错误 20012

## 错误消息
图片超出最大尺寸限制（当前：${actualWidth}x${actualHeight}，最大长度：${maxLength}）。要进行修复，请将图片大小调整为低于最大尺寸，然后重新提交符合要求的图片尺寸。

## 导致错误 20012 的原因
出现此错误的可能原因如下：
- 上传图片的尺寸（宽或高）超出商城允许的最大尺寸（最长边的最小值为 500 像素，最大值为 10,000 像素）。
- 图片分辨率过高，导致尺寸大于允许的尺寸。
- 图片的纵横比不正确且尺寸过大。

## 解决错误 20012
1. 调整图片大小以满足商城要求（最长边的最大值为 10,000 像素）。
2. 保持图片质量，同时减小尺寸。
3. 以可接受的格式（.JPEG [.jpg 或 .jpeg]、TIFF [.tif 或 .tiff]、PNG [.png]）保存已调整大小的图片。
4. 上传符合亚马逊[商品图片指南](https://sellercentral.amazon.com/gp/help/external/G1881)的新合规图片。

有关更多信息，请参阅[在图片管理器中上传图片](https://sellercentral.amazon.com/gp/help/external/GUGPCYWV2P8KVFUT)。
