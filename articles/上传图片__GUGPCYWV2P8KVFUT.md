# 上传图片

本页面介绍了如何将商品图片单独或批量上传到您的商品信息中（包括国家/地区专供图片），以及上传后的预期效果。

亚马逊商城的每件商品必须至少有一张图片。商品详情页面上的第一张图片是“主”图片，会在搜索结果中展示给买家。

单独或批量上传图片：

- 使用[上传图片](https://sellercentral.amazon.com/media/upload)工具可以批量或单独上传商品图片。每个 zip 文件最多可以上传 1000 张图片和 1 GB 的数据。您还可以同时上传多个单独文件和多个 zip 文件。

- 要为特定商品上传单张图片，请使用[图片管理器](https://sellercentral.amazon.com/imaging/manage)。按 ASIN 或 SKU 搜索您的商品，选择变体代码，然后直接上传图片。要详细了解图片管理器，请前往[管理图片](https://sellercentral.amazon.com/help/hub/reference/G7F9QAFM53E8C3X3)。

您可以随时向商品信息中上传更多图片。

## 上传前

- 以 JPEG（.jpg 或 .jpeg）、TIFF (.tif 或 .tiff)、PNG (.png) 或非动画 GIF (.gif) 格式提供文件。

- 查看[商品图片指南](https://sellercentral.amazon.com/help/hub/reference/G1881)，确保您的图片符合所有技术和内容要求。

- 如果您的图片不符合要求或违反[销售政策和卖家行为准则](https://sellercentral.amazon.com/help/hub/reference/G1801)，我们可能会将其移除。

**注意： **上传图片并不能保证图片会显示在商品详情页面。我们会从多位销售伙伴中筛选并排列图片，以确保每个商品都有足够的高质量图片供买家查看。为了最大限度地提高图片的显示几率，请确保其符合我们的商品图片要求。

## 全球或美国商城上传与国家/地区专供上传对比

如果您在多个国家/地区销售商品，可以在所有国家/地区使用相同的图片，也可以为每个国家/地区上传专供图片。

使用[上传图片](https://sellercentral.amazon.com/media/upload)工具，您可以将图片上传到全球商城或特定国家/地区的商城。

**决策指南 **

| 您的情况 | 操作 |
| --- | --- |
| 仅在美国销售 | 以全球方式上传 |
| 您在多个国家/地区销售，并且希望所有地方使用相同的图片 | 以全球方式上传 |
| 您在多个国家/地区销售，并且每个国家/地区需要不同的图片（例如，图片上带有特定语言的文字） | 先以全球方式上传，然后为每个国家/地区上传专供图片 |

**国家/地区专供上传的重要信息：**

- 要为美国商城上传图片，请使用“全球”选项。国家/地区专供上传不支持特定于美国的图片。

- 如果您的图片包含文字，则必须使用该国官方语言或英语。

- 上传国家/地区专供图片时，必须将主图片（变体代码： **MAIN**）包含在图片集中。如果缺少主图片，您提交的所有图片都不会在该国家/地区显示。

- 例如，如果您向德国商城上传德国专供变体图片但未包含主图片，则您提交的图片都不会被用于显示。如果您之前已为同一商品上传过全球图片，系统将为德国商城默认使用全球图片。

- 后续上传的全球图片不会覆盖您的特定国家/地区图片。

- 例如，如果您上传了德国专供图片，之后又提供了一组更新的全球图片，您的全球图片不会影响德国专供图片集。

- 图片仅适用于您在登录账户所在国家或地区发布的商品信息。

- 要向其他国家或地区上传图片，请登录相应的账户。

- 我们可能需要您提供一些图片变体，证明您遵守了与这些商品和商品信息相关的适用法律、法规和标准以及我们的政策。如果遇到这种情况，您会收到一封包含相关说明的电子邮件。

## 向您的商品上传图片

**注意： **开始之前，请先查看本页面上的【上传之前】部分，了解图片要求和政策。

上传图片时，您可以通过两种方式命名文件：

- **旧版文件命名：** 将文件命名为 商品编码 + 变体代码 + 扩展名（例如 B000123456.MAIN.jpg）。系统将根据文件名自动为商品分配图片。此选项最适合有自动化工作流程或商品目录规模较大的资深卖家。如需查看图片变体代码列表，请前往【图片变体】，该内容位于[商品图片指南](https://sellercentral.amazon.com/help/hub/reference/G1881)帮助页面。 

**注意： **注意： 文件名中包含商品编码但无变体代码的图片将被视为主图片。例如，B000123456.jpg 将被上传为主图片。

- **灵活的文件命名：** 按您喜欢的方式命名文件（例如 image1.jpg），上传后再将其分配给商品。此选项最适合新卖家、一次性上传，或当您尚未准备好商品编码时。

**注意： **为每种颜色或款式变体上传一组图片。您之后可以在[分配图片](https://sellercentral.amazon.com/media/assign)中将媒体集复制到同类商品。这样，您就无需为商品的每款同类商品都重命名并重新上传图片。

**批量上传您的图片**

- 前往[上传图片](https://sellercentral.amazon.com/media/upload)工具。

- 从您的电脑中选择或拖放文件。

- 如果您使用旧版文件命名，请确保您的文件遵循以下格式： 商品编码 + 变体代码 + 扩展名（例如 B000123456.MAIN.jpg）。

- 如果您使用灵活的文件命名，可以按您喜欢的方式命名文件。

- 您可以上传多个单独的文件或 zip 文件。每个 zip 文件最多 1000 张图片，大小不超过 1 GB。

- （可选）将图片分配到全球商城或特定的国家或地区。（您也可以稍后在[分配图片](https://sellercentral.amazon.com/media/assign)中进行这些分配。） 

- 选择您要分配的图片。

- 选择【全球】或特定的国家或地区。

- 选择【卖家编码】。

- 如果您使用灵活的文件命名，请输入商品识别码，可以是 ASIN、SKU 或其他（条形码编号、ASIN、SKU、UPC、ISBN 10 或 13、EAN、GTIN 或 JAN）。变体在分配图片中进行分配。

- 点击【上传】。

## 上传之后

- 上传完成后，亚马逊会立即检查文件格式、权限和报价状态。查看**上传结果**提示：

- 系统会为每次上传提交提供一个批次 ID。使用此 ID 在分配图片中筛选您的图片。

- 查看**结果细分**，其中会显示已分配图片、未分配图片以及失败的情况。

- 如果存在失败情况，请下载**失败报告**，确定哪些文件失败、失败原因以及建议的后续步骤。

- 接下来，我们会进行额外的技术合规性和商品图片要求检查。处理时间最长可能需要 24 小时。

**注意： **您可能需要提供某些图片的变体，以证明您符合适用的法律、法规、标准和亚马逊政策。如果这适用于您的商品，您将收到包含指导说明的电子邮件。

- 如果上传图片时遇到技术错误，例如文件格式、文件大小或命名问题，请前往[图片上传错误和显示问题。](https://sellercentral.amazon.com/help/hub/reference/G17811)

- 如果您的图片被选中用于显示，它将出现在商品详情页面。

**查看您的图片状态**

如需查看图片是否上传成功，请前往[提交状态](https://sellercentral.amazon.com/imaging/upload/status)。显示“图片上传已完成”的 ASIN 已成功处理。如果图片存在问题，图片缩略图会出现红色感叹号图标。选择【内容合规性问题】报告类型以查看详细信息。

**管理您的图片**

前往[图片管理器](https://sellercentral.amazon.com/imaging/manage)，在商品详情页面预览您的图片显示效果，将媒体集复制到同类商品，上传单独的图片，或删除图片。前往[管理图片](https://sellercentral.amazon.com/help/hub/reference/G7F9QAFM53E8C3X3)帮助页面了解更多信息。 。

**完成您的分配**

如果您在上传图片时未将图片分配到国家或地区，请从[分配图片](https://sellercentral.amazon.com/media/assign)中进行分配。如果您使用灵活的文件命名，请前往**分配图片**，为图片分配变体，并对分配不完整的图片进行进一步调整。前往[分配图片](https://sellercentral.amazon.com/gp/help/external/GSYPJKG5DFEGFHWD)帮助页面了解更多信息。
