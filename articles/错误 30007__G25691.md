# 错误 30007

未找到卖家促销 ID





您似乎正在延长或取消促销。但是，您的促销输入数据中的“卖家促销 ID”值与您创建的任何促销都不匹配。如果您不知道现有促销的“商品促销 ID”，可参照卖家平台中的“广告促销”链接。
