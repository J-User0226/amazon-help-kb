# 优惠券资格标准

要想提供优惠券，您必须是专业卖家，且[卖家反馈评级](https://sellercentral.amazon.com/gp/seller-rating/pages/feedback-manager.html/ref=xx_feedback_dnav_help)至少为 3.5。 尚未收到任何反馈评级的卖家也符合提供优惠券的要求。

此外，商品资格需满足以下条件：
- 尚未收到评论的新品符合要求。
- 如果商品已有评论，则必须满足以下条件：
  - 有 1~4 条评论的商品，平均评分必须至少为 2.5 星。
  - 有 5 条以上评论的商品，平均评分必须至少为 3 星。

- 商品可以由卖家自配送，也可以通过亚马逊物流配送。
- 商品必须处于新品状况。
- 商品折扣必须比历史售价或市场价至少低 5%

以下商品不符合提供优惠券的要求：
- 二手商品、收藏品或经认证的翻新商品。
- 成人用品
- 以下类型的商品：
  - 性健康
  - 狩猎和垂钓
  - 枪支和枪支配件
  - 图书、音乐、影视和 DVD

- 商品详情页面上包含令人反感、尴尬或不适宜内容的商品。

**重要： **卖家不应明示或暗示将优惠券作为买家发表评论的奖励。此外，买家使用优惠券购买商品后发表的评论不一定能获得【亚马逊已确认购买】标记。要了解更多信息，请参阅[关于“亚马逊已确认购买”评论](https://www.amazon.com/gp/help/customer/display.html?nodeId=G75XTB7MBMBTXP6W)页面。
