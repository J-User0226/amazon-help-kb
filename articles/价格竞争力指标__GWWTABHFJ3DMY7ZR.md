# 价格竞争力指标

有竞争力的价格是在亚马逊商城外的其他知名和相关零售商处找到此商品的最低价格。这不包括亚马逊商城中其他卖家提供的价格。我们会定期进行审核，确定针对每个国家/地区及商品类别提供类似选品的零售商。

价格竞争力指标的优秀基准为 95%。指标的计算方法如下：

针对 ASIN 的价格竞争力 % = 亚马逊价格有竞争力的页面的总浏览量/价格有竞争力和价格无竞争力的页面的总浏览量

以下示例展示了如何针对给定品牌计算该指标的示例数据。此卖家的一个价格竞争力 % 低于基准。

| ASIN | 页面浏览量 （有竞争力的价格） | 页面浏览量 （总数） | 价格 竞争力 % |
| --- | --- | --- | --- |
| B00EPP5ZZZ | 1,603 | 1,831 | 87.55% |
| B00SLL5ZZZ | 17,405 | 19,567 | 88.95% |
| B0123D5ZZZ | 28,190 | 31,050 | 90.79% |
| 品牌合计 | 47,198 | 52,448 | 89.99% |

针对 ASIN 的价格竞争力 % = 亚马逊价格有竞争力的页面的总浏览量/价格有竞争力和价格无竞争力的页面的总浏览量： **1,603 / 1,831 = 87.55%**

品牌合计价格竞争力 % = 品牌所有 ASIN（亚马逊价格有竞争力）的页面总浏览量之和/品牌所有 ASIN（价格有竞争力和价格无竞争力）的页面总浏览量之和： **47,198 / 52,448 = 89.99%**

相比页面浏览量较少的商品，浏览量最多的商品对您的买家体验绩效的影响更大。缺货商品或非在售商品不会计入此指标。如果我们在其他主要零售商中找不到您商品的价格，有竞争力和无竞争力页面的浏览量可能为零。

**注意： **数据更新有两天的延迟。[参考价](https://sellercentral.amazon.com/gp/help/external/G202170370)实时更新。

为确保基准维持在 95% 以上，建议您执行以下步骤：

- **自动定价： **您可以利用自动定价功能自动调整目录中 SKU 的价格以应对“推荐报价”（购买按钮）价格变动等事件，而不必在每次想要更改价格时都重新操作 SKU。您可以通过定义规则参数、设置最低价格和最高价格限制以及选择要自动定价的 SKU 来控制价格。您可以随时启用和停止自动定价规则。要了解更多信息，请参阅[自动定价](https://sellercentral.amazon.com/gp/help/external/G201994820)帮助页面。

- **利用 API 调整价格**： 商品定价销售伙伴 API（简称商品定价 API）可以在亚马逊商城中检索商品的价格和促销信息，帮助您根据市场状况快速高效地更新价格。该 API 支持各种应用代表您自动更新和管理价格，大幅减少人工操作和时间成本，帮助您保持价格竞争力。

商品定价 API 还支持重新定价工具开发。重新定价工具是第三方自动定价工具，可持续监控价格点位、竞品价格等相关因素，并实时调整您的商品价格。通过 API 和通知提供的数据与分析，重新定价工具能帮助您确保商品定价始终对买家具有吸引力。要了解更多信息，请前往[亚马逊开发者网站](https://developer-docs.amazon.com/sp-api/reference/product-pricing-v2022-05-01)。

- **手动调整价格**： 您可以在价格更新窗口中手动调整单个商品的价格。要到达价格更新窗口，请执行以下步骤：

- 从卖家平台的下拉菜单中，选择【绩效】，然后选择【买家体验指标】。

- 在表中，向下滚动到要调整的 ASIN。

- 在**操作**列的下拉菜单中，选择**手动更新价格**。

如果想验证参考价，请[使用亚马逊卖家助手](https://sellercentral.amazon.com/help/center?redirectSource=HelpHub)或前往【获取帮助和资源】，点击未列出我的问题，然后输入问题详情。按照界面提示验证参考价。如果问题仍未解决，请选择联系客服专员协助解决。客户专员会在问题单中看到您提供的所有信息。

**注意： **亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。
