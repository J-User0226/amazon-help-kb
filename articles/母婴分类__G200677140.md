# 母婴分类

我们很高兴宣布，亚马逊母婴分类下的母婴商品新增了 80 个属性。现在，您可以为与家具、汽车座椅、手推车、监视器、游戏围栏、母乳喂养及喂食相关的母婴商品提供额外信息了。

母婴分类库存文件已更新，其中添加了新属性。请尽可能多地提供商品的新信息。提供所售商品的丰富数据不仅有助于亚马逊在搜索和浏览结果中显示您的商品，还能给买家提供更多有用的详细商品规格。买家有时候是根据详情页面上他们得到的有关商品的信息量来做出购买决定的。

| 库存文件模板母婴版块 | 重点介绍新属性 |
| --- | --- |
| 通用商品属性 | 高度推荐、材料信息、护理说明、原产国、特性、以及电动功能 |
| 基本母婴属性 | 商品不含不良材料 |
| 母婴旅行系统（汽车座椅和手推车） | 汽车座椅、手推车信息（底座规格、汽车座椅系带、座位数、内部座位、前向及后向信息、肩带、以及各种长、宽、高和重量信息）。注意：要提供长、宽、高和重量信息，必须注明计量单位。示例：如果填写 ［ 把手高度 ］ ，则必须注明“把手高度计量单位”。 |
| 家具属性 | 垫子数量、高度、五金件可见度、便携性、家具表面处理、以及轨道类型 |
| 监视系统 | 警示特性、监视器信息、传感器技术、控制信息、以及范围规格 |
| 喂食商品属性 | 奶瓶类型、吸奶器规格、能否放入洗碗机、以及其他喂养规格属性 |
| 单品价格 | 没有 UPC/EAN 编码的包装内的商品数量、单独包装的商品数量、以及重量、体积、长度和单位计数信息。 注意： 要提供重量、体积和单位计数信息，必须注明计量单位。示例：如果填写“显示重量”，则必须注明“显示重量计量单位”。 |
| 电池信息 | 电池类型、平均寿命、以及其他电池规格信息 |
