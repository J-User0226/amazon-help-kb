# Send to Amazon： 用于提供箱内物品信息的二维码

您可以使用二维码为货件中的每个箱子提供商品数量。

**注意： **[Send to Amazon](https://sellercentral.amazon.com/gp/help/external/G6925SDD66GDLXJW) 工作流程现已提供此选项。如果您在之前的第 1 步中将库存添加为单件商品，便可在工作流程的第 1b 步中使用二维码选项。

如果您使用二维码，则无需通过卖家平台提供箱内物品信息。您可以在标准化货件创建流程中选择【使用二维码】，然后为每个箱子贴上二维码。这样一来，我们只需扫描您的条形码便可确定特定箱子内的物品。

**重要： **如果您未提供准确的箱内物品信息，我们可能会禁止您今后运送货件，并将收取人工处理费。

提供箱内物品信息有助于缩短从商品到达运营中心到商品可供销售所需的时间。对于由供应商直送的库存，二维码的作用尤为重要。您的供应商可以提供箱内物品信息，而无需获取您的亚马逊物流货件的详细信息。如果您要管理大量操作，二维码可更轻松地扩展到更大批量的货件。

**注意： **即使您选择不在卖家平台提供箱内物品信息，也需要为所有货件提供准确的包装箱重量和尺寸。有关更多信息，请参阅[运输和路线安排要求](https://sellercentral.amazon.com/gp/help/external/G200141510)。

请注意，您将需要使用第三方应用程序或网站来生成二维码。二维码不会取代亚马逊货件标签。仍然需要亚马逊货件标签。

**重要： **使用二维码可能会导致货件接收出现延迟。与提供了箱内物品信息的货件相比，使用二维码的货件所需的处理时间更长。

## 二维码要求
亚马逊接受满足以下标准的所有二维码：

PDF417（推荐）
模块宽度 最小： 0.020 英寸（0.508 毫米）
行高 最小： 3 个模块
错误校正 最小： 6 级
数据矩阵
支持的版本 14x14、16x16、18x18、20x20 或 22x22
模块宽度和高度 最小： 0.040 英寸（1.016 毫米）
二维码
模块宽度和高度 最小： 0.040 英寸（1.016 毫米）
错误校正 最小： 高级

应该采用白底黑墨方式打印条形码标签，并且分辨率至少要达到 600 dpi。

**注意： **强烈建议您使用热敏或激光打印机打印二维码标签。请勿使用喷墨打印机。要防止 PDF 文件打印区域缩放，请确保将打印机的缩放设置设为**无**或 **100%**。我们还建议您定期扫描条形码进行测试。

条形码必须按所列顺序包含以下信息：

1. 以字符 **AMZN** 开头

2. 亚马逊物流货件编号，也称为亚马逊订货单编号（代码： **PO**）

3. 商品编码（代码： **ASIN、UPC、EAN、ISBN 或 FNSKU**） **注意： **商品编码应与预期商品一致。例如，如果货件中商品的编码为 FNSKU，那么在提供商品编码时也应采用 FNSKU。

4. 数量（代码： **QTY**）

用冒号分隔代码及其值，用逗号分隔每一段码值，例如：

UPC:847603044631,QTY:24

其他指南：

- 仅使用大写字母。
- 请勿在数据中输入空格。
- 为每个字段输入一个值。空值或零值无效。
- 请勿列出数量为 0 的 ASIN。数据中不要包含这样的 ASIN。
- 一个箱子中不同 ASIN 的数量不能超过 100 个。
- 按照每个箱子中的 ASIN 只有一个有效期/保质期的原则来装箱。

## 示例条形码
**注意： **图片不能缩放。实际尺寸取决于多种因素，包括条形码类型以及货件中的 ASIN 数量。

装有 UPC 商品的箱子
货件编号 (PO) = FBA23JFC2G

UPC = 847603044631

数量 = 24

此条形码显示为： AMZN,PO:FBA23JFC2G,UPC:847603044631,QTY:24
装有 ASIN 和 UPC 商品的箱子
货件编号 (PO) = FBA23JFC2G

ASIN = B00H1BPQ1Y

数量 = 12

货件编号 (PO) = FBA23JFC2G

UPC = 847603044631

数量 = 24

此条形码显示为： AMZN,PO:FBA23JFC2G,ASIN:B00H1BPQ1Y,QTY:12, UPC:847603044631,QTY:24
装有两个 UPC 商品的箱子
货件编号 (PO) = FBA23JFC2G

UPC = 776403045720

数量 = 10

货件编号 (PO) = FBA23JFC2G

UPC = 847603044631

数量 = 24

此条形码显示为： AMZN,PO:FBA23JFC2G,UPC:776403045720,QTY:10, UPC:847603044631,QTY:24
