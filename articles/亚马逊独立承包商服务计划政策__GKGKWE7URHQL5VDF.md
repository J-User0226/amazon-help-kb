# 亚马逊独立承包商服务计划政策

为确保为买家提供安全、理想的体验，并保护亚马逊的声誉，任何提供服务的服务提供商（以下简称“您”）必须遵守亚马逊独立承包商服务计划政策（以下简称“政策”）以及针对提供服务的相关条款，其中包括亚马逊服务提供商协议（以下简称“协议”）和特定于提供商的条款等。如果您不遵守本政策，我们可能会向您发出警告、暂停或取消服务订单和/或覆盖区域，减少路线或终止您提供服务的权限，包括终止本协议。本政策中未定义的所有大写术语均具有协议中规定的相应含义。

## 工艺水平

您应至少要根据适用的制造商保修和保证以及法律（包括商业和专业许可要求、建筑与规划规范、行业标准安全要求，以及特定州的“挖掘前先打电话”或关于地下公用工程管线等的类似要求）及时、熟练、专业地成功完成所有服务。

根据[满意度保障](https://www.amazon.in/gp/help/customer/display.html?nodeId=202132790)，您为买家提供的每项服务（每项“任务”）的工艺水平均由亚马逊提供担保。如果买家针对您的任务提出满意度保障索赔或任何其他索赔，您必须与买家和亚马逊合作（包括遵守满意度保障政策和卖家平台上的帮助内容），以解决该问题，费用由您承担，亚马逊有权决定，解决方案中可能会包括重新完成相关任务。因此，您应在以下期限内（以其中时间最长的期限为准），向亚马逊提供每项任务的工艺水平的保证和保修：

- 自成功完成任务之日起一年内；或

- 亚马逊可能要根据法律规定向买家提供任务工艺的保证和保修的期限。

## 技术应用

亚马逊将提供一个应用（“技术应用”），以帮助成功完成提供给买家的任务，您的员工应使用这个应用。借助技术应用，您的员工可以执行以下各项操作，例如：

- 查看、管理任务并将其标记为完成。

- 与买家沟通以核对任务详情并发送预计到达时间通知。

- 导航至买家场所。

- 查看任务追踪步骤，协助准确完成任务。

- 拍摄现场照片和自拍照片作为验收证明。

随着亚马逊独立承包商服务计划（以下简称“计划”）不断发展以满足买家需求，亚马逊可能会自行决定定期更新技术应用。如果您要使用您自己的等效于技术应用的其他应用（替代亚马逊的技术应用），那么必须获得亚马逊的书面批准，是否批准由亚马逊自行决定。如果获得批准，此类等效工具必须使用应用程序编程接口连接到亚马逊的系统。在本政策中，此类等效工具称为“API”。某些功能可能仅在技术应用中提供。

如果您未达到服务级别标准指标，请查看[帮助内容](https://sellercentral.amazon.com/gp/help)，了解最佳实践。如果您有失去某一服务地区的风险，亚马逊会通知您，然后您需要提交一份解决相关问题的行动计划。如果您无法达到绩效标准，亚马逊可能会选择将已安排的任务和已分配的服务地区重新分配给其他提供商，终止您提供服务的权限或终止本协议。

## 一般标准

提供服务时，您必须确保为买家提供安全专业的体验，并维护亚马逊的声誉，包括达到上述服务级别标准和满足下文所述的其他期望：

**配备充足的人员以满足需求**

您需要提供充足的人员，以确保每个买家在适用商品的预计送达时间后的四天内获得首次可用服务预约（预计送达时间可在卖家平台的“管理订单”页面的【订单详情】列下找到）。您必须每周至少一次，使用服务能力文件（“FBC”）模板（可在卖家平台中找到）提交可用人员数量，以满足亚马逊在所有服务地区提供的每日预测需求，完成特定于提供商的条款中商定的全部工作（以小时计算）。每周提交的服务能力文件都必须至少包含未来 4 周的人员数量配置，即分配来完成服务的员工。例如，在第 3 周，您必须根据亚马逊对第 4~7 周的每日预测需求提供第 4~7 周的服务能力文件。如果您未能每周提供至少一个服务能力文件，可能会导致亚马逊向您发出警告，在亚马逊确定的一个时间段内暂停和/或（向其他提供商）重新分配您的任务，或者终止您提供服务的权限。但是，如果您还根据与亚马逊签订的单独协议将相关商品配送给买家，则本节不适用。

**在提供服务时，保护买家、买家的预期和亚马逊的声誉**

为了在提供服务时保护买家、买家的期望和亚马逊的声誉，并成功完成任务，您必须确保员工：

- 接受服务级别标准方面的全面培训，了解如何保持最低的服务级别标准，并可靠地完成任务。

- 无论是在完成任务的过程中，还是在与买家及公众沟通时，都应保持礼貌和专业的态度。

- 充分了解授权他们提供的每项服务的工作范围。

- 在到达时段开始前提前 30 至 60 分钟通过技术应用或 API 发送预计到达时间。

- 您必须遵守买家的首选到达时段。亚马逊要求您在买家首选到达时段抵达买家处所提供服务。可以在卖家平台“管理订单”页面的【订单详情】列中的链接中查看买家首选到达时段。

- 如果未成年人独自在家，无人陪伴，绝对不可提供上门服务。您要确保儿童始终有父母或监护人陪伴。

- 在技术应用或 API 中选择【开始任务】，表明已开始执行预约任务。

- 在开始任务之前，请与买家一起查看任务范围，并检查环境是否存在可能导致安装不安全或设置不当的因素。

- 遵循技术应用或 API 中的服务说明，若没有服务说明，则遵循亚马逊提供的标准操作程序。请勿提供任何不符合安全标准或法律规定的服务。

- 采取适当且合理的预防措施，以保护买家及其财产免受损害和/或损坏。

- 在开始任务之前或发现需要更改订单时，及时与买家讨论并明确沟通更改订单（定义见下文）事宜。

- 针对每一项任务，妥善地完成全部工作。

- 当面确认买家对已完成的任务是否满意，如果不满意，则进行更正或改进。在买家确认满意后，请在离开买家处所之前，在技术应用或 API 中将任务标记为“完成”。所有已完成的任务都必须在技术应用或 API 中标记为“完成”（如适用），或根据亚马逊的其他指示进行标记。

- 当系统提示提交自拍时，使用技术应用或 API 拍摄并提交自拍照。

- 仅使用自己的亚马逊账户（“登录账户”），不可使用任何其他人的登录账户，或向其他人透露自己的登录账户信息。

在买家处所完成现场工作的所有人员必须：

- 年满 18 周岁，并且拥有操作适用的机动车所需类型的有效驾驶执照；

- 根据亚马逊的[全球员工资格要求](https://aws.amazon.com/legal/global-personnel-suitability-requirements/)和亚马逊提供的任何其他相关标准（包括卖家平台的新人入职步骤）通过犯罪背景调查；

- 按照亚马逊的[全球员工资格要求](https://aws.amazon.com/legal/global-personnel-suitability-requirements/)中的规定，在法律允许的情况下，通过标准五项药物测试（包括大麻、阿片类药物、苯环利定、可卡因和安非他明），测试由无关的第三方（至少必须是有执照的医疗审核官）管理；

- 签订同意书，允许您公司向亚马逊提供药物检测和背景检查结果、绩效管理/纪律处分，以及亚马逊在行使其审计权时可能会要求提供的任何其他信息；

- 签订保密与不披露协议，以保护买家和亚马逊的机密信息；

- 在安排的预约时段到达，并携带完成每项任务所需的全部适当工具、材料和设备；

- 不索要小费；以及

- 完成任务过程中，应遵守法律。

您公司需要保留相应的记录，并在入职过程中确认您的每个员工均已进行并通过了五项药物测试（在法律允许的情况下）。

**强制性安全报告**

如果发生可能影响买家对您或亚马逊的信任的安全事件或任何其他敏感事件，包括任何违法行为，涉及任何死亡、伤害、身体或语言威胁、骚扰、犬伤、跟踪或尾随、不良互动或财产损失的事件，您应立即通知亚马逊（在第一时间将事件报告给应急响应人员后，例如，警察或消防部门，如果有必要）。

**执照和许可**

您和您的员工必须持有和保持提供此服务时所需的所有执照（包括营业执照和机动车驾驶执照）、许可、授权、注册和批准（以下简称“执照”），并满足与执照相关的要求。一旦得知任何执照已过期、丢失、终止或暂停，或者如果任何管理机构发现您违反了任何与提供服务相关的法律，您必须立即通知亚马逊。

**零容忍**

亚马逊将对买家报告的严重事件进行调查，并可能在调查期间立即暂停您的服务权限，是否认定事件为严重事件以及是否暂停您的服务权限由亚马逊自主决定。

**更改订单**

如果您发现需要进行约定工作内容以外的额外工作，才能完成任务令买家满意，则可以在原服务价格的基础上适度合理地增加更改费用，但前提是必须获得买家的事先同意（“更改订单”）。买家批准更改和付款必须通过技术应用或 API 进行。

当您的员工到达时，相关商品应位于适合完成任务的正确位置。如果您必须将商品搬运至买家选择的正确房间，则针对将商品搬运至正确位置的工作，您最多可以增加 $20 的更改费用，前提是买家接受这笔增加的费用。如果您还根据与亚马逊签订的单独协议向买家配送相关商品，则此费用不适用。

如果未遵守本政策，可能会导致亚马逊向您发出警告，在亚马逊确定的一个时间段内暂停您的任务，或者终止您提供服务的权限。如果我们确定您或您的员工未遵守或者规避了这一政策，则我们可能会扣留支付给您的款项，直到我们完成所有相关调查为止，也可能会使用本协议中规定的任何方法来收回应该归属于买家或亚马逊的款项。

**买家沟通**

您与买家就服务事宜进行的所有沟通都必须使用亚马逊通信渠道（例如，技术应用或买家与卖家消息服务）进行。您不可出于营销或促销目的或出于与提供所需服务无关的原因使用买家个人数据或亚马逊通信渠道联系买家。

**禁止招揽**

在买家处所，您不可进行任何类型的招揽活动，包括分发任何印刷品或材料；穿着专门用于招揽的衣服（不包括您的标准制服）；销售商品或服务；获得捐款、会员资格、订购或签名；分发广告或其他商业材料。

**付款**

发票和付款条款在双方签订的“特定于提供商的条款”中说明。亚马逊将从应付给您的款项中扣除您应当承担的所有满意度保障索赔款或其他索赔款。

**取消**

通过向您发送书面通知，亚马逊有权在任何时候，因任何原因，自行决定取消任何任务。

**遵守法律**
