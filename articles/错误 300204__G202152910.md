# 错误 300204

## 错误消息

无法访问 URL ${imageUrl}（204 状态代码）上的媒体文件。要解决此问题，请执行以下操作： (1) 验证服务器配置是否正确；(2) 确保文件可公开访问；(3) 测试不同网络环境中的 URL 访问；(4) 使用可访问的 URL 重新提交。

## 导致错误 300204 的原因

由于以下原因导致出现此错误：

- 系统正尝试从返回 204 无内容 HTTP 状态代码的 URL 访问媒体内容。

- 媒体文件已被移动、删除或暂时不可用。

- 此 URL 需要验证身份，或访问权限受限。

## 解决错误 300204

要解决此错误，请按照以下步骤操作：

- 验证媒体服务器是否采用 HTTP 协议并返回正确的响应代码。

- 检查媒体 URL 中没有拼写错误。

- 确保请求的文件 

- 未被重命名

- 未被移至其他位置或被删除

- 未因维护、升级或其他未知原因而暂时不可用

- 更新图片 URL 并重新提交媒体文件。
