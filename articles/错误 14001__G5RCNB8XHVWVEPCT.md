# 错误 14001

## 错误消息

卖家 customer_id: '${customer_id}' 未在 marketplace_id: '${marketplace_id}' 中注册。请耐心等待 72 小时，以便系统传播商城注册变更，然后重新尝试提交。如果您尚未在此商城中注册，请进行注册。如需更多帮助，请联系销售伙伴支持。

**注意： **亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。

## 错误 14001 的原因

出现此错误的原因如下：

- 您的卖家账户尚未完成特定商城的整个注册流程。

- 您的账户注册仍在等待中或正在激活中。

## 解决错误 14001

要解决此错误，请执行以下步骤：

- 确认您已完成相关商城的注册流程。如果没有，请登录卖家平台并完成所需商城的注册。

- 如果您最近已在此商城注册，请耐心等待至少 72 小时，以便亚马逊的系统能够完全处理您的注册信息。

**注意： **请保持您的卖家平台账户信息最新，因为过时的信息（例如：过期的信用卡信息）可能会导致出现注册问题。
