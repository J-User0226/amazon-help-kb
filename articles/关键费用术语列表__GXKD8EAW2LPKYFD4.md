# 关键费用术语列表

了解关键术语，理解费用计算方式。

| 费用术语 | 描述 |
| --- | --- |
| 体积重量 | 使用包裹的长、宽、高计算出该包裹的体积重量。 |
| 商品尺寸分段 | 基于包装后的商品重量、商品尺寸和体积重量确定测量分类。 |
| 商品尺寸和体积 | 按照亚马逊物流政策和要求包装完毕且准备发货时，测量商品的尺寸。 |
| 发货重量 | 商品重量加上用于将订单配送给买家的亚马逊包装或填充物的重量。发货重量的计算依据是商品重量或体积重量加上包装重量。 |
| 商品重量 | 测量商品包装时的重量。 |
| 费用分类 | 对于某些费用类型，费用分类决定了适用于特定商品的费率。您商品的费用分类可能与其在亚马逊自营网站上显示的分类不同。 |
