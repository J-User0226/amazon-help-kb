# 事件通知网络服务的安全性

为了识别和验证，根据 WS-Security 安全标准，“事件通知网络服务 (ENS)”的调用必须使用亚马逊网络服务 (AWS) X.509 证书进行签名。由于 X.509 证书与您的账户信息相关，您的公钥将用来识别，而签名用来验证请求的真实性。此外，所有网络服务请求使用安全套接层 (SSL) 加密算法来加密，以确保您的账户数据在传输中不被篡改和捕获。

在您使用 ENS 之前，您需要一个已向亚马逊网络服务注册的 X.509 证书和私钥。

**注意： **注意：任何时候您只能有一个与您账户相关联的 X.509 证书。上传或创建一个新证书将取代您拥有的所有较旧的证书。

如果您已经创建了一个 X.509 证书，请参考工具包文档以了解如何将您的公钥导出为经过 Base64 编码的 .PEM 证书文件。将显示如下：

然后按照以下步骤使用 AWS 注册证书。

- 前往 [http://aws.amazon.com](http://aws.amazon.com/)

- 在页面右侧，将鼠标悬停在 【您的网络服务账户】 按钮上，直到出现菜单。点击 【查看访问密钥标识符】 链接。
您需要登录到您的账户。

- 使用主账户的电子邮件地址和密码登录。 
如果您从未使用过的亚马逊网络服务，可能需要创建一个账户。

- 向下滚动 【AWS 访问标识符】 页面，直到看到 【X.509 证书】 部分。

- 如果您已经拥有 AWS 证书，请点击 【上传】 按钮。

- 如果您尚未在 AWS 创建证书，请点击 【创建新的】。

- 在下一页，您将收到警告，上传证书将替换您已经与账户关联的任何旧证书。如果可以，请点击 【是】 继续。

- 如果您要上传现有证书，请点击【浏览】按钮打开文件选择对话框，在其中找到您导出的 .pem 证书。找到证书后，请点击【上传】将其上传到 AWS。

- 如果您正在创建新证书，您将看到一个包含两个下载按钮的页面，一个标记为 【下载私钥文件】，另一个标记为 【下载 X.509 证书】。单击“下载私钥文件”下载私钥，然后保存到您的电脑并转移到安全位置。单击“下载 X.509 证书”，然后保存文件到您的电脑。

**注意： **虽然您可以随时下载 X.509 证书（公钥），但请务必在仍位于此页面时下载私钥——离开此页面后，您将无法再次下载私钥。AWS 不存储私钥，并且不能提供再次生成相同密钥值的任何方式。如果您再次生成新的密钥值，您现有的密钥将无效。

一旦您使用亚马逊网络服务注册了 X.509 证书，您可以使用 WS-Security 对“事件通知网络服务”请求进行签名。详情请见您所选编程语言和网络服务工具包的文档，或亚马逊开店服务提供的 SDK。更多示例可在亚马逊网络服务门户 [http://aws.amazon.com](https://aws.amazon.com/) 上找到。
