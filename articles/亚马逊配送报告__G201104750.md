# 亚马逊配送报告

可使用亚马逊配送报告来监控和管理您的亚马逊物流 (FBA) 库存。这些报告可帮助您追踪货件、做出明智的补货决策并核对库存余额。要访问和自定义您的报告，请前往[报告平台](https://sellercentral.amazon.com/reportcentral/WelcomePage)。

## 下载报告

请从左侧菜单中选择要查看的报告。调出报告后，您可以选择下载为逗号分隔值 (.csv) 或文本 (.txt) 格式。

使用 .csv 格式可让您以电子表格的形式打开报告，但 MSKU、ASIN 和 FNSKU 中的前导零将被删除。如果您不希望删除前导零，可以下载 .txt 格式的文件。有关如何导入 .txt 文件的更多信息，请查看您正在使用的电子表格应用程序的帮助内容。

## 补货

库存建议的主要目的是通过保持良好的库存水平，让您的库存分布在配送网络中，使您的商品离买家更近，从而提高配送速度。只要我们拥有生成这些建议所需的输入信息，我们就会针对所有商品提供这些建议。新添加的 SKU、在较长时间段内没有销量的 SKU 和无在售信息的亚马逊库存可能会被暂时排除在外，原因是我们可能无法预测这些商品的销量。

最低库存水平工具会根据您的需求预测、波动性和交期等信息，对每个 ASIN 的现有配送水平进行分类：

- 良好： 您的现有可售库存处于最佳水平，既没有低于最低库存水平，同时也没有冗余商品。

- 低库存： 您的现有可售库存已降至最低库存水平以下，我们建议您考虑补货建议并规划您的库存，以提供最佳的买家体验。

**注意： **低库存并不一定产生低库存水平费用。仅当相对于过去的销量，商品库存水平持续较低时，我们才会收取低库存水平费用。

- 缺货： 您的现有可售库存为零。

- 冗余： 您有机会通过减少现有冗余库存来提高售出率或降低不必要的仓储成本。

有关更多信息，请参阅[最低库存水平](https://sellercentral.amazon.com/gp/help/external/G9BYNYF4FAXXBPJZ)和[亚马逊物流库存](https://sellercentral.amazon.com/inventoryplanning/manageinventoryhealth)

#### 用于管理您的亚马逊物流库存并查看库存水平的建议（如补货）报告：

[库存状况报告](https://sellercentral.amazon.com/gp/ssof/reports/search.html/?ie=UTF8&recordType=INVENTORY_HEALTH)、[管理亚马逊物流库存](https://sellercentral.amazon.com/gp/ssof/reports/search.html/?ie=UTF8&recordType=FBA_MYI_UNSUPPRESSED_INVENTORY)和[亚马逊配送货件报告](https://sellercentral.amazon.com/gp/ssof/reports/search.html/?ie=UTF8&recordType=AFNShipmentReport)。

#### 最佳实践：

- 我们建议您在现有可售库存低于建议的最低库存水平之前，确保下一个货件到达亚马逊运营中心。此外，您还可以使用亚马逊的补货建议，这些建议为下一批货件提供具体的发货日期和补货数量，以确保相关库存在未来保持在建议的最低库存水平之上。

**注意： **在某些情况下，如卖家的库存交期较长或商品预测变化较大，那么可能需要将库存维持在 28 天以上。

- 对于没有建议的商品，请根据您的预估销售预测进行规划，保持至少可维持 28 天销售的存货量，修复所有无在售信息的亚马逊库存，并更新单个 SKU 的设置。有关更多信息，请参阅[无在售信息的亚马逊库存概览](https://sellercentral.amazon.com/gp/help/external/G201436600)和[自定义 SKU 设置](https://sellercentral.amazon.com/gp/help/external/G455QMHQTVD5XW6P)

## 核对库存

使用[库存分类账报告](https://sellercentral.amazon.com/reportcentral/LEDGER_REPORT/0)【一览视图】可查看已核对的库存，以及在运营中心和国家/地区级别汇总的每日/每周/每月 FNSKU 的期初和期末余额。您的期末库存余量的计算方式如下：

【期初库存余额】 + 【已接收库存】 - 【买家订单量】 + 【买家退货量】 +/- 【盘点量】 - 【移除量】 = 【期末库存余额】

#### 确定您的期初库存余量：

使用[库存分类账报告](https://sellercentral.amazon.com/reportcentral/LEDGER_REPORT/0)【一览视图】可查看根据前一天/上一周/上一月的期末库存余额确定的期初库存余额。

#### 已接收库存：

使用[库存分类账报告](https://sellercentral.amazon.com/reportcentral/LEDGER_REPORT/0)，可确定要添加至期初库存余额的库存接收量。

#### 买家订单量：

买家订单通常会进行发货，从而降低您的整体库存余量。使用[已完成订单销售](https://sellercentral.amazon.com/gp/ssof/reports/search.html/?ie=UTF8&recordType=SHIPMENT_SALES)报告，可确定给定时间段内某 SKU 或某组 SKU 的已发货数量。

#### 买家退货量：

买家退货会使商品重新添加到您的库存池中。使用[亚马逊物流买家退货](https://sellercentral.amazon.com/gp/ssof/reports/search.html/?ie=UTF8&recordType=CUSTOMER_RETURNS)报告，可了解给定时间段内某 SKU 或某组 SKU 已退回并计入库存余额的商品数量。

#### 盘点量：

我们偶尔会因运营中心或买家的意外问题而对您的库存余量进行盘点。使用[库存分类账报告](https://sellercentral.amazon.com/reportcentral/LEDGER_REPORT/0)【详细视图】可追踪这些盘点情况。

#### 赔偿：

有时，我们会在盘点后对您进行赔偿。使用[赔偿](https://sellercentral.amazon.com/gp/ssof/reports/search.html/?ie=UTF8&recordType=REIMBURSEMENTS)报告，可查看您已获得赔偿的商品。

#### 移除量：

提交从运营中心移除库存的订单会减少您的库存余量。要查看已移除数量的详情，请使用[移除货件详情](https://sellercentral.amazon.com/reportcentral/REMOVAL_SHIPMENT_DETAIL/1)报告。

**Tips：** 

- 核对库存的最佳方式是在每个报告中按照 FNSKU 字段内容进行核对。

- 您可以追踪最近 18 个月的库存交易详情。

- 总库存水平将始终保持不变。

- 要了解有关赔偿的更多信息，请参阅[亚马逊物流库存赔偿政策](https://sellercentral.amazon.com/gp/help/external/200213130)或[库存缺陷和赔偿 (IDR) 帮助页面](https://sellercentral.amazon.com/help/hub/reference/G66ZLS453YSE2Y4R)。

- 对于配送报告中未能解决的问题，请联系[销售伙伴支持](https://sellercentral.amazon.com/gp/contact-us/contact-amazon-form.html)。

**注意： **亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。
