# 错误 90114

## 错误消息
值“${attribute_value}”低于允许的最小值：${min_allowed}。

## 导致错误 90114 的原因
出现此错误的原因如下：
- 提交的数值低于系统允许的最小值。
- 定价或数量字段中的值低于可接受的限值。例如，如果最低库存水平为 1，则输入 0 将导致此错误。

## 解决错误 90114
要解决此错误，请按照以下步骤操作：
1. 查看您的上传数据处理汇总报告，以发现此错误。系统会突出显示存在错误的属性。
2. 查看您的指定属性允许的最小值，确保您的输入内容超出此值。
3. 更新数值以符合或超过最低阈值，然后使用符合店铺要求的修正值重新提交上传数据。
