# 视频加载工具

为了帮助您在 Amazon 商城销售视频和 DVD，我们提供了视频加载工具，这是一款专用工具，可以让您一次性地上传多个商品。视频加载工具可用于上传视频 (VHS)、DVD、HD DVD、蓝光光盘和其他视频格式的商品数据。

视频加载工具会将您的商品数据与亚马逊目录中现有的商品页面进行匹配。如果目录中没有对应页面，则该工具会创建一个新的商品详情页面。

## 视频加载工具的功能
如果您的商品详情页面已存在于亚马逊目录中，则视频加载工具将使用您提供的商品编码（UPC 或 EAN）来查找匹配的页面并创建您的商品信息。了解有关[商品匹配](https://sellercentral.amazon.com/gp/help/external/1471)的更多信息。

如果视频加载工具无法在目录中找到匹配页面，但是您在上传文件中提供了充分的数据，亚马逊将自动创建一个新的商品页面。一旦创建了页面，系统会将您的库存“匹配”到该页面，并创建报价以供买家购买。

如果系统没有充分信息与现有页面实现匹配或创建新页面，那么，上传之后您将在处理报告中收到一条错误消息。

亚马逊的视频加载工具模板的选项卡中提供了帮助您创建文件的信息和说明。此模板中还包含宏，可显著简化您上传商品数据的流程并提升您的体验。

有关使用视频加载工具模板的信息，请参阅[视频加载工具说明](https://sellercentral.amazon.com/gp/help/external/200482410)。
