# 高级和时尚时尚珠宝首饰分类

在亚马逊上发布销售的珠宝首饰可根据其材质分为 ［ 高级 ］ 或 ［ 时尚 ］ 珠宝首饰。请按照以下指南，确定您的商品是被认定为 ［ 高级 ］ 还是 ［ 时尚 ］ 。不正确的商品信息和/或将时尚珠宝首饰材质误认为高级珠宝首饰或将高级珠宝首饰材质误认为时尚珠宝首饰，可能会导致您的销售权限被中止或移除。

如果您的珠宝首饰商品包含任何高级首饰材质 - 即如果它包括 1.2 或 1.3 部分列出的培植或天然珍珠、钻石或高级宝石；或者金属含有 1.1 部分列出的高级金属成分 - 那么，该商品可称为高级珠宝首饰。

亚马逊使用多种标准来确定网站上商品的展示位置，为买家提供更好的浏览体验。有关商品展示位置的更多信息，请参阅[珠宝首饰帮助页面](https://sellercentral.amazon.com/gp/help/external/200332590)。

## 1.0 高级珠宝首饰
高级珠宝首饰采用贵金属制作而成，或搭配有珍贵或类珍贵宝石及培植或天然珍珠：

1.1 高级珠宝首饰采用黄金和白金系列贵金属。如果一种商品含有这些贵金属中的一种或多种成分，或者一种贵金属镀上了另外一种贵金属（包括银镀金），那么亚马逊将把该商品分类为 ［ 高级珠宝首饰 ］ 。更具体地说，高级珠宝首饰的金属成分包括白黄金、银镀金和白金系列金属。高级珠宝首饰还包括由贵金属制成（添加有白银）并镀有贵金属的珠宝首饰。
