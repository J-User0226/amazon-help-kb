# Amazon Print Connect

借助 Amazon Print Connect (APC) ，使用您的热敏和激光打印机直接打印购买配送标签。借助 APC，您可以：

- 选择首选打印机来打印您的所有购买配送标签。

- 用您的首选打印机直接打印标签。

- 用 Zebra 热敏打印机以本地 ZPL 标签格式打印标签。

**注意： **Amazon Print Connect (APC) 不支持一键批量购买配送。安装并使用 [QZ Tray](https://sellercentral.amazon.com/gp/help/external/GKULTMACW6HHP7AD) 可一键批量购买配送。安装和使用 QZ Tray 无需卸载 Print Connect。

## 系统要求

目前，只有 Windows 操作系统支持此应用程序。

**支持的 Windows 操作系统：**

- Windows 7

- Windows Vista

- Windows 8

- Windows 10

**支持的浏览器：**

- Mozilla Firefox： 24 ESR（扩展支持版本）和最新版本

- Internet Explorer： 版本 8 及更新版本

- Google Chrome：最新版本

**不受支持的打印机：**

以下打印机不受支持：

- EPL 打印机 LP-2844。

下载以下任意应用程序的安装程序文件，即表示您同意[软件许可协议](https://sellercentral.amazon.com/gp/help/external/GLJU3HEJGJBT8WVE)的条款和条件。我们有权自行决定通过在亚马逊网站上发布修订后的条款来修改本协议的任何条款。如果您在本协议的修订条款生效日期后继续使用 Amazon Print Direct，即表示您接受这些条款。

安装

- 在此处下载应用程序： [APC 1.0（32 位）](https://m.media-amazon.com/images/S/direct-print-artifacts-prod/x86/AmazonPrintConnect.msi)、[APC 1.0（64 位）](https://m.media-amazon.com/images/S/direct-print-artifacts-prod/x64/AmazonPrintConnect.msi)。

- 【保存】并【运行】下载的应用程序。

- 查看《Amazon Print Connect 软件许可协议》。如果您同意其中的条款，请接受该协议，然后点击【下一步】。

- 安装应用程序。

**提示： **请选中“在启动计算机时启动该应用程序”复选框，以确保 Amazon Print Connect 在您每次启动计算机时都处于启用状态。

- 点击【完成】即可启动 Amazon Print Connect。

**账户设置**

您可在此页面找到您独有的访问密钥和密钥： [获取访问密钥和秘密密钥](https://sellercentral.amazon.com/buy-shipping/amazon-print-connect)。在应用程序中输入访问密钥及密钥进行验证。

**打印机设置**

从您的已安装打印机列表中选择一个打印机，将其设置为打印您的购买配送标签的默认打印机。
