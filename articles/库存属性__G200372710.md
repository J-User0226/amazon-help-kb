# 库存属性

当商品出现残损、存在瑕疵或其他不适合销售或配送的情况时，该商品即被视为无法配送/不可售。如果商品在我们的控制范围内出现残损（因亚马逊合作承运人导致残损、在亚马逊运营中心残损或在配送给买家的过程中残损），我们将为此负责，并根据《亚马逊物流丢失和已残损库存赔偿政策》就此商品对您做出赔偿。如果残损并非发生在我们的控制范围内，或者如果商品本身存在瑕疵，您可以创建移除订单，以便我们将该商品退还给您或在亚马逊运营中心弃置该商品。

## 状况代码

| 库存属性 | 描述 | 您的操作 |
| --- | --- | --- |
| 可售 | 商品已返回库存并且可供购买 | 无 |
| 在库房出现残损 | 亚马逊对残损负责。商品的所有权转移给亚马逊。亚马逊根据亚马逊物流丢失和已残损库存赔偿政策对您进行赔偿。 | 我们会自动移除残损商品并就此商品对您进行赔偿，此操作将在残损之日起 10 天内完成。 |
| 因承运人导致的残损 | 亚马逊确定承运人损坏了商品，并对残损负责。商品的所有权转移给亚马逊。亚马逊根据亚马逊物流丢失和已残损库存赔偿政策对您进行赔偿。 | 无 |
| 买家导致残损 | 亚马逊确定，商品在退回至亚马逊运营中心时已被买家损坏。该商品被视为不可售。 | 您可以请求将商品退还给您。 |
| 存在瑕疵 | 亚马逊确定商品存在瑕疵并将其设为不可售。 | 您可以请求将商品退还给您。 |
| 因分销商导致的残损 | 亚马逊确定商品从卖家（在本例中为分销商）处收到时即已处于残损状况。该商品被视为不可售。 | 您可以请求将商品退还给您。 |

以下列表列出了导致商品不可售的商品库存属性以及对每种属性的描述。您可以查看[盘库](https://sellercentral.amazon.com/gp/ssof/reports/search.html/ref=ag_fbafulrpts_cont_help?recordType=Inventory_Adjustment)报告，找到您的不可售商品适用的库存属性。

| 商品库存属性 | 在线报告 | 可下载报告 |
| --- | --- | --- |
| 由于存在瑕疵（外观无残损但无法正常使用）而从可售库存中减去的库存，可能是召回的商品。 | 商品缺陷造成的残损 | K |
| 由于被买家损坏而从可售库存中减去的库存。 | 已残损 – 买家退货 | H |
| 由于被卖家损坏而从可售库存中减去的库存。 | 卖家造成的残损 | U |
| 由于在亚马逊运营中心残损而从可售库存中减去的库存。 | 在亚马逊运营中心残损 | E |
| 在发送给买家或运往亚马逊运营中心时由承运人损坏而从可售库存中减去的库存。 | 由入库承运人造成残损 | 6 |
| 由非上述残损原因造成残损而从可售库存中减去的库存。 | 残损 – 其他 | Q |
| 当亚马逊为残损负责并向残损商品发放赔偿时而从可售库存中减去的库存。此时，残损库存归亚马逊所有。 | 转移给另一位所有者 | O |
| 表明不可售商品已被加至不可售库存数量中。这是一个正值，与 K、H、U、E、6 或 Q 原因代码所表示的负值相对应。 | 不可售库存 | P |
