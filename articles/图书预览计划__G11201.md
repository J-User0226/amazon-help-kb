# 图书预览计划

借助图书预览计划，图书出版商可以为买家提供图书预览，帮助他们做出明智的购买决定。买家可以浏览样本页面，并在图书中进行额外搜索，以确认该图书是否正是他们想要的。

此外，当买家在亚马逊商城查找图书时，我们会使用图书的实际字词，而不仅仅是作者姓名、书名和关键词，来提供最佳的图书选择。借助这个强大的全新搜索功能，买家可以找到之前搜索结果中从未出现的图书。

**注意： **

这些指南是一个理想的案例。我们将接受和处理更多种类的文件，同时，我们也鼓励卖家提供可提交测试文件。如果您无法为图书预览计划准备文件，请联系[销售伙伴支持](https://sellercentral.amazon.com/help/center)。

亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。

要注册图书预览计划，您必须登录您的卖家账户。

- 填写[图书预览计划注册表](https://sellercentral.amazon.com/sitb/sign-up)。

- 您将在 24 小时内获得为图书预览计划上传文件的权限。要上传，请参阅[图书预览文件上传](https://sellercentral.amazon.com/sitb/pdf-upload-v2)。

**注意： **

使用此流程一次只能上传一个文件。要使用文件传输协议批量上传文件，请联系[销售伙伴支持](https://sellercentral.amazon.com/help/center)。

亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。

在提交图书预览文件之前，您必须先将商品名称添加到亚马逊目录中。如果您的商品名称尚未处于可售状态，您仍可将商品名称添加到亚马逊目录中，也就是说，您可以在出版日期或销售日期之前提交文件。有关向亚马逊目录中添加商品名称的信息，请参阅[商品名称要求](https://sellercentral.amazon.com/gp/help/external/GYTR6SYGFA5E3EQC)。

我们希望在图书的生命周期内，尽早将书内图片链接至详情页面，因此图书预览功能在图书进行推广时可用。

将商品名称添加到亚马逊目录后，您就可以排版并上传商品标题的 PDF 文件和图片。

请按照以下指南准备您的文件：

#### 要求格式：

- PDF 文件不受密码保护，允许进行编辑和打印文件。

- PDF 文件包含输出所需的所有页面（除非按照上述要求单独提供封面），而且只有这些页面是输出所必需的。

- PDF 文件中的页面顺序必须与纸质图书完全对应。

- PDF 文件必须与 Acrobat 4.0或更高版本 （即 PDF 1.3或更高版本） 兼容。

#### 推荐格式：

- 所有嵌入的字体均为 PostScript Type 1或 TrueType 。

**注意： **MM 和 Type 3 字体不允许使用。

- 所有文件名称必须符合亚马逊的命名标准。

- 所有图片，包括封面图片或书皮图片（如果单独提供），则必须以尽可能高的分辨率提交。我们倾向于使用 600 dpi 或更高分辨率的嵌入式图片。嵌入式图像的高 DPI 设置可提高我们对嵌入式图像中的文本进行搜索的能力。不过，我们也接受 dpi 设置较低的文件。

- PDF 页面不得包含注册标志和其他无关的非打印文本、标记或元素。

对 PDF 文件和图片进行排版后，即可开始上传文件。

文件名必须采用以下格式：[PublisherName] - YYYYMMDD-HHMM.zip。

- PublisherName 是出版商名称的任何简短版本，不含空格。

- YYYYMMDD 是 8 位数字日期代码。2005 年 1 月 3 日 = 20050103。

- HHMM 是 4 位数字的时间戳。下午 8:05 = 2005。

ZIP 文件应包含一个或多个商品名称的文件，如下所述。理想情况下，所有数据，包括封面、封底、前折页、后折页、书脊和书籍内容，都必须包含在一个带书签的 PDF 文件中。但是，我们了解到，许多卖家不会保留折页或书脊文件，并且这些文件可能是单独的 JPG，而不是 PDF 的一部分。因此，我们接受两个捆绑商品选项中的文件。

**选项 1： 单个 PDF 文件（推荐）**

包含所有已打印的书页和封面。根据所列规范，封底、前折页、后折页和书脊可以包含在一个 PDF 文件中（如果有）：

0123456789.pdf [ISBN.pdf]

**选项 2： Zip 文件**

0123456789.zip [ISBN.zip]文件，其中包含：

0123456789.pdf [ISBN.pdf]

0123456789-frontcover.jpg

0123456789-backcover.jpg（如果有）

0123456789-frontflap.jpg（如果有）

0123456789-backflap.jpg（如果有）

0123456789-spine.jpg（如果有）

或者，您也可以提交名称为 0123456789-dustjacket.jpg 或 0123456789-dustjacket.pdf 的文件，而不必分别提交封面、封底、前折页、后折页和书脊。

此外，我们认可许多卖家将每章另存为单独的 PDF 格式。在很多情况下，只要它们使用一致和明显的命名规则进行保存，我们就能够接受和处理这些文件。

如果您的文件不符合上述“要求格式”指南，您将收到一条错误消息，指出问题的性质，并要求您重新提交文件。如果不符合其他指南，您收到的电子邮件可能包含警告和建议解决方案。

**注意： **亚马逊希望尽可能减少卖家在提供数字文件时面临的工作。要实现这一目标，我们可以在其中部分指南上保持灵活性。例如，我们通常可以接受带有裁切标记的 PDF 文件，但该文件可能需要稍长的时间才能处理并显示在亚马逊商城。如果没有嵌入字体，且纠正这一问题需要大量人力，我们可以接受该文件，前提是卖家了解亚马逊商城显示的图书在排版方面可能与印刷图书不完全匹配。
