# 问题排查指南

## 虚拟身份验证： 问题排查指南
本指南针对您在虚拟身份验证过程中可能遇到的常见问题提供了解决方案。

## 开始视频通话前
请确保您使用兼容的浏览器：
- Windows 用户： Google Chrome（推荐）、Firefox
- iOS/Apple 用户： Safari
- Android 用户： Google Chrome

## 常见问题与解决方法
**音频问题**

如果您听不到对方讲话，或者对方听不到您讲话：
- 检查您的麦克风是否已静音
- 调高您的设备音量
- 在浏览器中允许麦克风访问
- 尝试使用耳机
- 确保您已在设置中将耳机选为“播放设备”
- 关闭其他正在使用音频的应用程序

**视频问题**

如果您的摄像头无法正常工作：
- 检查是否有其他应用程序正在使用摄像头
- 在浏览器中允许摄像头访问
- 刷新浏览器页面
- 尝试关闭并重新打开您的浏览器

**摄像头/麦克风权限问题**

对于 Chrome 用户：
1. 点击地址栏中的摄像头图标
2. 将摄像头和麦克风的权限均设为“允许”
3. 刷新页面

对于 Safari 用户：
1. 当系统提示请求摄像头/麦克风访问权限时，点击“允许”
2. 检查“设置”>“Safari”>“摄像头/麦克风权限”

**连接问题**

如果看到“出错了”：
- 刷新页面
- 检查网络连接
- 在 WiFi 与移动数据之间切换
- 若正在使用 VPN，请暂时禁用

**屏幕/图像问题**

若屏幕卡住或显示错误信息：
- 刷新浏览器页面
- 清除浏览器缓存
- 尝试更换其他浏览器
- 重启您的设备

**文件上传问题**

如果无法上传文件：
- 确保文件格式为系统支持的类型（仅限 DOCX、JPEG、JPG、PDF、PNG）
- 检查文件大小（单个文件须小于 4MB）
- 尝试每次只上传一个文件
- 若上传进程停滞，请刷新页面

**快速提示**
- 务必使用稳定的网络连接（最低要求 1.5 Mbps）
- 建议在约定通话时间前测试音频与视频设备
- 关闭不必要的浏览器标签页和应用程序
- 浏览器务必更新到最新版本
- 如条件允许，建议准备一台备用设备
- 在安静、光线充足的环境下加入视频通话

**常见错误信息及解决方法**

“音频/视频设备出现问题”：
- 关闭正在使用摄像头/麦克风的其他应用程序
- 刷新页面
- 检查设备的权限设置

“出错了”：
- 刷新页面
- 尝试更换其他浏览器
- 检查网络连接
- 若正在使用 VPN，请暂时禁用
