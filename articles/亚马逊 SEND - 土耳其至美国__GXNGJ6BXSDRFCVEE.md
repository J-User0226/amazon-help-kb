# 亚马逊 SEND - 土耳其至美国

借助亚马逊 SEND 计划，您可以通过亚马逊 SEND 承运人将您的亚马逊物流库存 (FBA) 从土耳其运往美国的亚马逊运营中心。您可以利用该计划以经济高效的方式将亚马逊物流货件运送到全球各地。亚马逊 SEND 支持空运服务。在亚马逊 SEND 承运人取走您的货件后，他们将负责处理从清关到送达亚马逊运营中心的全程运输事宜。通过亚马逊 SEND，您可以让其承运人上门取件，也可以将货件投件至承运人网点。

## 通过亚马逊 SEND 运送您的货件
按照以下步骤，通过亚马逊 SEND 为亚马逊物流货件进行预约：
1. 要创建亚马逊物流货件，请从卖家平台的【库存】下拉菜单中选择【货件】，然后导航至【货件】下拉菜单，选择 【Send to Amazon】。

2. 会自动选中**我想使用亚马逊 SEND 运输货件**复选框。

3. 在第 1 步中，选择您计划运往亚马逊物流的 ASIN 和数量。选择库存和数量后，输入包装详情。有关包装配置的更多信息，请参阅 [Send to Amazon： 选择要发送的库存](https://sellercentral.amazon.com/gp/help/external/G8SXKYFWPG6DAW6T)。
  1. 如果 ASIN 是单一 SKU 包装箱（例如大包装），则选择相应的【装箱模板】（如果您已创建了模板）。否则，请创建新的装箱模板。然后，选择【准备发货】。对于您计划发往亚马逊物流的所有 ASIN 按照此流程操作。然后，选择【确认并继续】。
  2. 如果是混合 SKU 包装箱，请选择【混装商品】。然后，选择【准备包装】。对于您计划发往亚马逊物流的所有 ASIN 按照此流程操作。然后，选择【包装混装商品】。此时将前往【第 1b 步】，您需要在此步骤中提供包装箱详情。在提供包装箱详情后，选择【确认并继续】。

4. 选择运输模式【空运】。

5. 选择入库配置选项： 根据您的需求选择亚马逊物流库存入库配置选项，以优化您的总物流费用。对于高级配置选项，卖家可以选择入库区域，例如东部、西部或中部。

6. 为货件选择所需的发货日期和【取件或投件】选项。如果您打算进行投件，请在此页面的【亚马逊 SEND 运送要求】部分找到投件详情。

7. 选择适用的 IOR 选项。

8. 点击【获取运费】，根据包装箱尺寸和重量生成预计承运人运费。此费用不包括美国海关收取的关税和其他附加费用。

9. 确认运输方后，输入适用于您货件的清关信息。
  1. **出口类型**：
    - 销售额： 这是最实用的出口模式，您可以开具直接销售发票（电子存档或电子发票），无需额外报关。
    - 微出口： 这是经过简化的出口模式，适用于 €30,000 和 600 千克以下的货件，可提供快速、低成本的选项，并使用电子存档发票。

  2. **公司名称（土耳其语）**： 输入出口实体的公司名称。
  3. **公司信息**： 添加或选择出口实体的公司地址。
  4. **起运地联系详情**： 输入起运地人员的详细联系信息，以便亚马逊 SEND 协调取件事宜。
  5. **备案进口商 (IOR)**： 用于选择使用您自己的 IOR。
  6. **发票编号和日期**：（适用于微出口）： 这是您的电子存档发票在系统中的唯一参考编号，也是将货件与 ETGB（微出口）申报中的信息以及您电子存档发票的开具日期进行匹配所必需的信息。
  7. **商品描述**： 对您的库存以及预期用途的完整描述。例如：非临床用体温计、洗发水、保湿洁面乳。请尽可能准确地描述，以免在清关时出现问题。

10. 通过选中复选框来点击【接受费用】，即表示您接受费用并同意链接中包含的亚马逊 SEND 计划条款和条件。 **注意： **最终费用将根据亚马逊 SEND 审计过程中核实的实际重量和尺寸以及运送期间产生的适用关税和附加费计算得出。

11. 在您接受费用后，请下载亚马逊物流标签和承运人标签（如适用），并将标签粘贴到包装箱上。

12. 确认发货后，请在 Send to Amazon 工作流程中下载和上传所需文件。

13. 交接时，货件应附有必要的 FBA 标签、空运单或承运人标签（如适用）。

14. 此外，亚马逊 SEND 可能会要求您提供此处未提及的其他文件，具体取决于您要运送的商品分类。

## 亚马逊 SEND 承运人运送要求
亚马逊 SEND 可将您与承运人合作伙伴建立联系，以便将您的库存从您所在位置运输至亚马逊运营中心。

请选择以下亚马逊 SEND 承运人选项以查看相关指南和要求：
- [亚马逊 SEND 土耳其至美国： Navlungo（空运模式）](https://sellercentral.amazon.com/gp/help/external/GQXFLJAF5DEX9UUR)

## 亚马逊 SEND 付款和卖家费用
使用亚马逊 SEND 计划的卖家需要在货件送达后支付运费。运费将从卖家的提现账户中扣除。

请按照以下步骤查找您的亚马逊 SEND 承运人和海关费用详情：
1. 要查看费用，请前往您的销售账户，选择【付款】下拉菜单，然后选择【交易一览】选项卡。
2. 使用 FBA 货件编号查找您的交易。

## 亚马逊 SEND 商品运输资格
危险品不可以使用 SEND 计划进行全球运送。为确保安全运输，危险品必须遵守所有适用法规，并且还需遵守其他条款。有关更多信息，请参阅[亚马逊物流危险品计划](https://sellercentral.amazon.com/gp/help/external/GZLZBQ7W6QZRKWWK)。

## 联系销售伙伴支持
如有任何疑问，请前往【帮助】下拉菜单，然后选择【获取帮助和资源】或使用卖家助手。选择 【AWD、运输和物流】选项，然后选择【亚马逊 SEND】。这将直接将您转到亚马逊 SEND 的支持服务。
