# 卖家自配送出口

## 卖家自配送出口的配送工作

作为卖家，您可以选择通过我们的某个全球计划来发布商品，供全球买家购买。以下是部分可用于商品国际配送的计划：

- 【卖家自配送（国际配送模板）】： 借助配送模板，您可以同时管理多个商品的配送设置（例如，服务级别、配送地区、运输时间和运费）。您可以在配送模板中启用国际配送设置，并选择要配送的商品以及目的地。有关更多信息，请参阅[创建、编辑或删除配送模板](https://sellercentral.amazon.com/gp/help/external/G201834090)。

- 借助【亚马逊物流出口】计划，您只需在亚马逊商城发布亚马逊物流商品，我们便会为您处理订单出口事宜，将您的商品配送给世界各地的买家。有关更多信息，请参阅[亚马逊物流出口](https://sellercentral.amazon.com/gp/help/external/G200149570)。

- 借助【亚马逊全球开店】，您能够在遍布全球的多个亚马逊商城中发布和销售商品。您只需将库存运输至您发布商品所在国家/地区的亚马逊运营中心，然后我们会为您将商品配送给买家。有关更多信息，请参阅[亚马逊全球开店](https://sellercentral.amazon.com/gp/help/external/G201062890)。

- 借助【亚马逊物流远程配送】，您可以向位于加拿大和墨西哥的买家销售商品，而无需将库存发送到这些国家/地区。有关更多信息，请参阅[亚马逊物流远程配送](https://sellercentral.amazon.com/gp/help/external/G5P3CDUHZWSZLXLB)。

## 注册加入卖家自配送出口计划

如果您通过卖家自配送计划来配送货件，则可以在配送模板中启用国际配送，并从包含 200 多个目的地的清单中选择您的配送目的地。在创建模板之前，请务必了解[创建配送模板的最低要求](https://sellercentral.amazon.com/gp/help/external/202115770)，并确认您的默认发货地址准确无误。

## 符合要求的商品

当您决定通过我们的某个全球计划在全球销售商品时，您作为卖家，有责任了解自己的商品是否适合从发货国家/地区向买家居住的目的地国家/地区进行销售。并非所有商品都符合通过我们的全球计划进行销售的要求。请务必确保您遵守每个目的地的所有适用法律。

例如，您必须确认以下信息：

- 适用的进出口法律允许向每位潜在买家配送相关商品。

- 商品满足目的地适用的消费者保护要求、商品合规性要求以及环保法规要求。

- 商品符合适用法规，包括但不限于当地的年龄限制、可用性要求（例如，所需的商品文件），以及商品安全要求和认证（例如，遵守所有危险品限制，包括商品所需的贴标）。

- 向目的地销售和配送您的商品不会侵犯他人（例如商品制造商）的知识产权。

**注意： **此清单并不详尽，可能存在其他限制。您有责任遵守所有适用法律。

如果您销售的商品违反了相关法律或任何亚马逊政策，我们将视情况采取纠正措施，包括但不限于立刻停售商品、终止销售权限、销毁运营中心内的相关库存且不提供赔偿、退还库存、终止业务关系，以及永久扣留销售款项。销售非法或不安全的商品还可能引发法律诉讼，包括受到民事和刑事处罚。

商品可能会因多种原因不符合出口要求。最常见的原因包括但不限于：

#### 出口限制

对于某些分类的商品，来源国家/地区的法律禁止将商品配送至海外。例如，为了国家安全，美国政府禁止出口军用商品。通常，以下类型的商品会被限制出口：

- 武器和仿制武器

- 植物、植物制品、种子和土壤

- 动物和某些动物制品

- 监控设备

- 激光指示器和相关商品

#### 进口限制

有时即使出口国家/地区可能允许出口某种商品，美国以外的目的地也可能对可进口的商品有自己的政策。相关政策因目的地而异。为了避免出现延迟、清关问题以及买家体验不佳的情况，进口法律限制将以下类型的商品向所有或部分目的地进行国际配送：

- 酒类

- 武器、武器组件和武器配件，包括防身喷雾；BB 枪、气枪、彩弹枪及其零部件；瞄准镜；枪套和便携包

- 化学品，包括农药、肥料、杀虫剂、工业用化学品、汽车用化学品和某些清洁剂

- 药物，包括宠物药物、宠物食品和宠物补充剂

- 医疗器械，包括诊断工具、医疗警报设备和性别鉴定工具

- 药物用具

- 酿酒设备

- 加密电子设备

- 赌博相关商品和用具

- 仿制货币

其他限制根据具体目的地而定。

#### 其他限制

除了上述进出口限制外，您在亚马逊商城销售的商品还必须遵守您的卖家协议，包括所有其他适用法律法规和亚马逊政策。发布商品之前，请确保您了解自己作为卖家的所有责任。对于我们认为违反亚马逊内部政策的商品，可能会被归于“其他限制”分类并受到限制，并且配送地址在美国境外的国际买家将无法再购买这些商品。例如，如果商品被确定为假冒或非法复制的商品，即为违反亚马逊的内部政策，从而会被限制进行国际销售（也可能会被移除，无法向国内买家销售）。在发布商品时，请确保您熟悉亚马逊的计划政策。

有关更多信息，请参阅[亚马逊计划政策](https://sellercentral.amazon.com/gp/help/external/G521)。

#### 等待处理

如果报告中您的 ASIN 或报价显示为【等待处理】，则意味着我们尚未确定您商品的出口资格。可能导致其出口资格尚未确定的原因包括：您的商品没有在售商品信息，或者是您的商品缺货。

#### 无

如果报告显示该 ASIN 或报价的限制类型为【无】，则表示目前您的商品没有受到限制。

## 符合出口要求的库存报告

有关您库存中符合卖家自配送出口要求的商品列表，请前往[库存报告](https://sellercentral.amazon.com/listing/reports/ref=xx_invreport_dnav_xx)，选择【符合卖家自配送出口要求的库存报告】。即使没有启用国际配送模板，您也可以查看该报告。假设您日后会启用国际配送，该报告会显示您的哪些商品可以出口。

商品可能因为多种原因而无法进行国际配送。确定哪些商品可以出口并进行国际配送后，您可以在[配送设置](https://sellercentral.amazon.com/sbr/ref=xx_shipset_dnav_xx)页面将这些商品添加到国际配送设置模板，或移除受限商品。即使未采取任何操作，配送地址位于受限目的地的买家也无法购买受限商品。

您的报告将显示如下： 

| 1 | SKU | 库存单位。卖家为商品定义的唯一标识。示例： AA786936215595 |
| --- | --- | --- |
| 2 | ASIN | 亚马逊商品编码。ASIN 是详情页面的标识符。 |
| 3 | 商品名称 | 商品详情页面和浏览器标题栏中显示的简短商品名称。 |
| 4 | 来源 | 销售商品的地点。 |
| 5 | 限制类型 | 使商品不能进行国际配送的相应限制的类型。限制类型为“【进口限制】”“【出口限制】”“【其他限制】”“【等待处理】”和“【无】”。 请在上面【符合要求的商品】部分中查看各限制类型的定义。 |
| 6 | 符合出口要求的目的地 | 商品可配送到的目的地。 |
| 7 | 受限目的地 | 商品无法配送到的目的地。 |

要更好地了解属于受限分类的商品类型，请参阅上面的【符合要求的商品】部分。

我们会持续监控可能影响商品资格的因素，以确保商品可以安全地进口并销售给买家。如果商品被限制进行国际配送，很有可能是因为其违反了亚马逊政策、贸易合规性法规或目的地的适用法律。在某些情况下，商品可以使用其他配送方式进行国际配送（例如卖家自配送），但无法使用亚马逊物流远程配送进行国际配送。原因包括运输限制、高监管风险或其他潜在风险。

## 销售伙伴 API 卖家的符合卖家自配送出口要求的库存报告

如果您使用销售伙伴 API 来管理您的亚马逊业务，并拥有符合销售伙伴 API 要求的卖家账户，则可以使用以下 API 操作来下载最新的符合卖家自配送出口要求的库存报告：

报告编号： 11000

报告类型： GET_SELLER_FULFILLED_EXPORTS_ELIGIBILITY_REPORT

**重要： **为了向美国境外的买家销售符合国际配送要求的商品，请务必在配送模板中启用国际配送设置。启用后，网站才会将这些商品向居住在美国境外的买家显示。如果商品在您的报告中显示为符合出口要求，但并未分配到已启用国际配送的配送模板，则美国境外的买家将无法购买这些商品。

此外，请务必确保您面向美国境外发布的商品具有高质量的商品信息，且所有相关字段（例如“商品描述”和“要点”）均已填写完毕。 高质量的商品信息不仅能让买家更轻松地找到、评估和购买您的商品，从而改善买家体验，详细的商品信息还有助于亚马逊了解您的商品，从而对其进行正确分类，以便进行国际销售。有关更多信息，请参阅[商品信息质量](https://sellercentral.amazon.com/gp/help/external/G200786710)。

为了保护买家的利益，我们不断锐意创新，并与监管部门、第三方专家、供应商和卖家共同努力改进我们的检测和预防手段，避免非法商品和不安全商品流入亚马逊商城并销售给全球买家。亚马逊鼓励您及时[联系我们](https://sellercentral.amazon.com/cu/contact-us)，举报违反亚马逊政策或适用法律的商品。我们将对每宗举报展开彻查并采取适当的措施。
