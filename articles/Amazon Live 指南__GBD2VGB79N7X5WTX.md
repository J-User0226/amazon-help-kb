# Amazon Live 指南

Amazon Live 通过在您的品牌旗舰店直接开展互动式可购物直播，将您的品牌生动呈现，从而在亚马逊上实现社交电商功能。使用 Amazon Live Creator 应用进行直播，展示商品，通过实时聊天与买家互动，并促成实时购买。无论您是要放大现有广告活动，还是举办专门的直播购物活动，Amazon Live 都能帮助您讲述品牌故事并触达更多买家。

## 资格
Amazon Live 目前面向符合以下要求的专业亚马逊卖家和供应商开放：已在亚马逊品牌注册中注册为品牌代表或品牌权利所有者角色，拥有已获批准并已发布的品牌旗舰店，并且在 Amazon.com 上销售商品。

## 如何设置 Amazon Live Creator 应用
Amazon Live Creator 应用是一种移动应用，用于创建直播购物视频，并在亚马逊上与买家实时互动。您还可以使用该应用通过内置分析功能跟踪效果。首次设置 Amazon Live Creator 时，请按照以下步骤操作：
1. 从 Apple 应用商店 (iOS) 或 Google Play 商店 (Android) 在手机上下载 Amazon Live Creator 应用。
2. 打开应用，在主屏幕上选择您的账户类型——卖家 。
3. 使用您的 卖家平台凭证（卖家） 登录。具有 Brand_Representative 或 BRAND_RIGHTS_OWNER 角色的用户可以为您的品牌创建渠道并登录。
4. 选择希望直播播放并与之关联的品牌旗舰店所属品牌。
5. 查看应用中显示的 Amazon Live [社区指南](https://www.amazon.com/b?node=88213481011)。必须合规才能保留直播访问权限。
6. 渠道现已激活。您已准备好创建您的首场 Amazon Live 直播。

## 如何将 Amazon Live 模块添加到您的品牌旗舰店
直播购物模块是一种增强型视频播放器，有助于在买家的购物旅程中向积极参与互动的买家讲述您的品牌故事。此可自定义模块让您可以控制页面位置和视频的预定展示时长。通过将直播购物模块放置在品牌旗舰店页面（买家在此自然浏览您的品牌，不受竞争干扰），您可以通过动态故事讲述和教育建立更深层的联系。这种形式展示精选商品，并通过沉浸式购物体验帮助提升整体品牌价值。

要将直播购物模块添加到您的品牌旗舰店页面，请按照以下步骤操作：
1. 前往亚马逊广告平台，并在品牌旗舰店生成器中打开您的品牌旗舰店。
2. 点击“添加新分区”，然后选择“直播购物”作为模块类型。
3. 配置模块设置：选择可见持续时间（最多60天）以及店铺内的页面位置。建议将直播放在流量最多的页面上。
4. 确保已启用“直播聊天”。
5. 选择“播放所有直播”，按时间顺序优先播放最近的直播，或选择“播放单个直播”以突出展示特定内容。选择“选择直播”以选择您要展示的直播。保存并发布您的品牌旗舰店。

## 技术设置和要求
Amazon Live 支持两种主要直播设置：通过 Creator 应用实现的简单手机摄像头设置，以及用于更高制作质量的专业编码器设置。只要搭配适当的灯光和音频，两种方法都能产生出色的效果。

## 设备建议
为获得最佳效果，特别是在专业或有品牌宣传的制作中，请考虑以下设备：
- **摄像机**： 使用专用相机或高质量智能手机。
- **灯光**： 合适的灯光至关重要。使用环形灯、柔光箱或主光补光设置。避免强烈的阴影和逆光设置。
- **音频**： 为主持人使用领夹式（夹扣式）麦克风，为产品演示使用定向麦克风。尽量减少背景噪音。
- **编码软件**： 对于多机位设置，请使用编码软件，例如 OBS Studio（免费）。确保输出设置符合亚马逊的规格要求。要设置 OBS Studio，[请前往“如何使用 OBS 进行直播。”](https://www.amazon.com/gp/browse.html?node=116240251011)
- **备用连接**： 始终准备备用互联网连接（例如，移动热点），以防主连接中断。
- **录制备份**： 同时进行本地录制，作为直播中断时的安全备份。

## 如何使用 Amazon Live Creator 应用进行直播
1. **添加新的直播**： 点击屏幕底部的"+"。
2. **添加缩略图**： 缩略图会在播放前显示在直播中。建议添加直播标题、相关产品和达人形象图片。尺寸： 1920 x 1080.
3. **添加您的直播标题以及开始日期和时间**： 如果这是您在拍摄当天要进行的直播，也请保持练习模式为禁用状态。
4. **设置视频**： 点击“视频来源。”
5. **选择您的摄像头**： 选择使用手机还是外接摄像头进行直播，以及视频方向。
6. **前往添加商品**：[点击“添加”将商品添加到轮播](https://www.amazon.com/b?node=210709471011#product-carousel)。
7. **搜索并添加商品**： 按标题或 ASIN 编码搜索商品。我们建议按 ASIN 编码搜索，以确保找到正确的商品。点击“添加到直播。”
8. **调整商品顺序**： 点击左上角的返回箭头返回主屏幕。点击“Edit”以重新排列商品顺序。
9. **开启“练习模式”：** 启用练习模式，即可在没有任何公开观众的情况下测试直播。
10. **点击“获取练习模式链接”：** 在测试环境中查看您的练习直播。
11. **结束练习直播**： 点击右上角的“结束练习”。
12. **点击“预览”：** 等待红色的“开始直播”按钮亮起。当它变成鲜红色时，表示您的直播数据已正确传输到应用。
13. **点击“开始直播”：** 您将看到 3 秒倒计时，然后您将在亚马逊上开始直播。
14. **直播时，点击精选商品即可突出显示：** 当商品被突出显示时，它将跳到视频播放器列表的最前面。
15. **结束直播**： 点击右上角的“结束直播”。

## 如何为直播吸引观众
要最大化直播的影响力，重要的是不要只考虑自然社交传播。虽然在您的社交渠道上发帖是一个很好的起点，但自然触达往往有限。在社交媒体和数字渠道上采用付费媒体策略，将有助于您的直播在合适的时间触达合适的受众。

**最佳实践：**

- **使用经过验证的媒体组合**： 从历史上对您的品牌表现良好的格式和渠道开始，然后在扩大规模时扩展并测试新的选择。
- **保持内容新鲜多样**： 在静态和视频格式之间取得平衡，以保持内容吸引力
- **策略性应用广告格式**：
  - 亚马逊广告： 静态和视频创意各占 50% 的混合比例往往能取得最佳效果，既能提升品牌认知度，又能实现更深入的互动。

  - Instagram： 优先使用静态格式，将视频留给用户生成内容（UGC）风格的执行，这通常对受众来说感觉更真实、更亲切。

- **遵循创意最佳实践：**
  - **让广告可点击**： 确保每个素材都包含清晰的行动号召，引导客户回到您直播中展示的品牌旗舰店页面。
  - **保持内容新鲜多样**： 在静态和视频格式之间取得平衡，以保持内容吸引力： 带有最小或微妙徽标的广告通常比带有过大或过于强势品牌的广告表现更好。
  - **利用人才和产品演示**： 客户希望看到产品实际使用效果。与产品互动的真实人物始终比静态产品图片能带来更高的互动率。

## 绩效指标
**如何查找您的指标**

在 Amazon Live Creator 应用中查看您的指标。分析部分提供您直播表现的完整视图，追踪完整的客户旅程，并衡量互动质量和业务影响。指标涵盖三个关键领域：您触及了多少客户、他们与您的内容互动效果如何，以及您产生的收入。每个指标都包含趋势指示器，显示随时间变化的表现情况，可通过“查看详情”链接获取详细细分数据。

**何时回顾表现**

您的内容在直播结束后仍会持续产生效果。直播后您内容的流量会扩展覆盖范围并最大化您的投资。

- **数据可用性**： 指标在您的直播结束后 72 小时开始填充。所有过往直播数据均可无限期访问，而所有过往渠道数据可访问过去 180 天的内容。
- **建议时机**： 在进行深入表现分析之前，至少等待两周。这两周的时间窗口涵盖了直播期间和直播后的互动，以及任何由更大规模营销活动带来的互动，让您全面了解内容的有效性。

**了解归因类型**

Amazon Live 追踪三种类型的指标，以展示您直播的完整影响：

- 直接： 直接归因于您在直播中展示和推广的产品所产生的收入。
- 光环： 来自品牌内产品的收入，这些产品未在您的直播中直接推广，但由观看您直播的客户购买。这捕捉了您的内容激发的更广泛购物行为。
- 总计： 直接销售和光环销售的合并收入（直接 + 光环）。

**了解您的指标**

**指标组** **指标名称** **描述**
认知 曝光量 直播在所有平台（移动端和桌面端）上显示的总独立次数。

## 问题解决
请使用下表诊断并解决在您的 Amazon Live 直播前、直播期间和直播后遇到的常见问题。

**问题** **症状** **解决步骤** **其他检查**
**无法登录 Creator 应用** 登录屏幕显示错误；凭证被拒绝
- 确认是否选择了正确的店铺（例如，美国对应 Amazon.com）
- 确认凭证与品牌注册所有者账户匹配
- 清除应用缓存后重试；如果问题仍然存在，则重新安装应用

确保品牌注册处于有效状态且未过期
**“开始直播”按钮未变红** 点击“预览”后按钮保持灰色或非活动状态
- 重启编码软件并重新启动 Creator 应用
- 检查网络连接速度和稳定性
- 验证直播输出设置是否符合亚马逊的规格（比特率、分辨率、关键帧间隔）

如果主连接不稳定，则切换到备用网络（移动热点）
**直播结束后在亚马逊上不可见** 卖家或供应商在 Amazon.com/live 上通过互联网搜索查找直播时，直播未显示
- 直播结束后，处理时间最长可能需要 2 小时
- 验证轮播中的商品是否与您的品牌相关联且有库存
- 确认直播未违反社区准则

检查 Creator 应用通知，查看是否存在任何政策或内容违规
**直播购物模块未在品牌旗舰店中显示** 模块添加至品牌旗舰店后缺失
- 发布后，该模块最多可能需要 48 小时才会显示
- 验证是否已配置正确的 ASIN 和预定直播时间
- 在添加该模块之前，确认已至少登录过一次 Creator 应用

每个品牌旗舰店页面仅支持一个“直播购物”模块；添加新的模块会替换现有模块
**轮播中 ASIN 缺少价格** 直播期间购物轮播中商品未显示价格
- 选择其他子 ASIN 变体（例如不同尺寸或颜色）
- 验证该 ASIN 在卖家平台/供应商平台中是否未被禁止或处于非活跃状态

检查商品定价规则，确保至少有一个活跃变体具有有效价格
**直播期间观看人数较少** 尽管已开始直播，但并发观众人数很少
- 至少在直播前 3~7 天在社交媒体上推广您即将进行的直播

将 Amazon Live 整合到全漏斗付费媒体策略中，以实现最大触达
**直播期间 Creator 应用出错** 应用在直播期间崩溃、卡顿或显示错误
- 检查直播输出设置；确保比特率不超过 4 Mbps
- 强制关闭并重新打开应用；确认手机有足够的存储空间和电量
- 将 Creator 应用更新到可用的最新版本

在直播前务必进行一次完整的练习，以提前发现技术问题
