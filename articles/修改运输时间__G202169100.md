# 修改运输时间

运输时间（以前称为配送时间）是从卖家将订单商品交付给承运人到订单送达至买家地址这一过程所用的时间。运输时间将计入显示在商品信息页和结算页中的[配送时间](https://sellercentral.amazon.com/gp/help/external/202167920)：

总配送时间 = [备货时间](https://sellercentral.amazon.com/gp/help/external/200955560) + 运输时间（+ 所有节假日天数）

**注意： **亚马逊按工作日计算备货时间和运输时间。

如果您使用“配送设置自动化”，亚马逊便会根据您的发货地址和承运人首选项管理您的运输时间。如果您已选择手动定义运输时间，请按照以下步骤进行修改：

- 转至[配送设置](https://sellercentral.amazon.com/sbr)。

- 在【配送模板】选项卡中，选择您要编辑的配送模板。

- 点击页面右侧的【编辑模板】。

- 选择要设置的【配送选项、地区和运费】选项。

- 选择【运输时间（不含备货时间）】列中的下拉菜单，修改运输时间。

- 根据需要对任意数量的【配送选项和地区】重复上述操作。 

**注意： **标准配送要求您能够向美国大陆的所有地区配送商品。[了解更多信息](https://sellercentral.amazon.com/gp/help/external/202115770)。

- 点击【保存】。

## 运输时间要求

要查看默认的运输时间，请参阅[默认的运输时间](https://sellercentral.amazon.com/gp/help/external/202169120)。
