# 状况指南： 贴身内衣

在亚马逊商城发布销售的所有贴身内衣商品必须处于【新品】状况。

本政策涵盖所有贴身内衣商品。贴身内衣示例包括：内衣裤、女士内衣、文胸、无钢圈文胸、塑身衣、丝袜、内衣式睡衣和泳衣。

要被视为【新品】，贴身内衣商品必须采用原包装，所有卫生衬板、标签和密封应完好无损，并且必须妥善包装和贴标，以确保在运输和搬运过程中保持清洁和安全。

要被视为**新品**，除符合上述要求外，贴身内衣商品还应满足以下条件：
1. 之前不可以被穿过；
2. 不可以被试穿过；
3. 不可以被洗过；
4. 不可以有磨损、使用或残损痕迹；或
5. 不可以采用会破坏卫生的方式处理过。

为清楚起见，任何具有或可能具有以上所列任何特征的商品均不可被视为【新品】状况。

亚马逊不允许销售除【新品】状况以外的任何状况的贴身内衣商品，无论其类型如何。这是为了保护买家安全，同时在平台上保持高标准的卫生状况。
