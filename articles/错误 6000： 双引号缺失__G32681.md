# 错误 6000： 双引号缺失

用来定义字段开始或结束位置的双引号缺失。请添加缺失的双引号并重新上传此条记录。

如果文件中应有的双引号缺失，则会出现此错误。在制表符分隔的文本文件中，包含一个或多个特殊字符的数据需要用引号括起来。如果某一字段中的数据包含双引号（例如表示英寸），则该字段的开头和结尾也必须添加双引号。

如果您使用 Microsoft Excel 模板创建制表符分隔文本文件，则 Excel 会自动添加正确数量的双引号。
