# B2B 选品推荐（销售机会）

您可以在 [B2B 选品推荐](https://sellercentral.amazon.com/business/opportunities/)页面上找到适用于您的商业的 B2B 选品推荐。我们使用需求信号，例如购买趋势、B2B 相关商城可能出售但亚马逊商城尚未上架的商品以及您的销售历史记录，为您的企业创建产品推荐。目前，我们提供以下两个企业购销售机会报告：

#### 发布亚马逊商城尚未上架的商品

包括亚马逊企业购买家请求的商品以及 B2B 相关商城可能出售但亚马逊商城尚未上架的商品。

有关更多信息，请参阅[发布亚马逊商城尚未上架的商品](https://sellercentral.amazon.com/gp/help/external/GPNBU9M8RSY7ZQKP)。

#### 向现有 ASIN 添加报价

包括您目前所售商品的所属分类或品牌中需求量较大的商品。

有关更多信息，请参阅[向现有 ASIN 添加报价](https://sellercentral.amazon.com/gp/help/external/GURRDDL9EK8KH6BL)。

**注意： **现在，API 可用于自动处理您的企业购销售机会报告。借助 API，您可以选择未个性化的报告以发现新的分类和品牌，查看最多 10,000 条商品推荐，并借助自动化来节省时间。

有关如何为企业购销售机会构建自己的 API 集成文件，请参阅[销售机会报告类型值](https://developer-docs.amazon.com/sp-api/docs/report-type-values-b2b-product-opportunities)，并查看 [GitHub](https://github.com/amzn/selling-partner-api-models/tree/main/schemas/reports) 中提供的 API 架构。

报告类型： GET_B2B_PRODUCT_OPPORTUNITIES_RECOMMENDED_FOR_YOU

报告类型： GET_B2B_PRODUCT_OPPORTUNITIES_NOT_YET_ON_AMAZON。
