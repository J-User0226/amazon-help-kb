# 卖家自配送商品的有效期

发布具有有效期的库存之前，请确保您遵守以下政策和要求。*不遵守相关要求可能会导致您的商品被移除或亚马逊销售账户被停用。*

## 具有有效期的商品定义

即使商品包装上未注明有效期，亚马逊也会将任何具有保质期或随时间而失去有效期的商品视为有效期。

存在有效期的商品包括但不限于：

- 在商品或其包装上印有有效期的任何商品。

- 消费类商品，如薯片、茶叶和营养补充剂，无论是供人类食用还是动物食用。

- 外用商品，如护肤霜、肥皂、洗发水、发胶和专供人类或动物使用的化妆品。

- 清洁商品，如消毒湿巾、清洁喷雾和溶液，以及清洁剂。

- 包含可能过期组件的商品，如与咖啡捆绑销售的咖啡机。

- 带有开封后（PAO）标志的任何商品（下图）。

![](https://m.media-amazon.com/images/G/01/fba-help/icons/12M_PAO_Symbol.png)

## 具有有效期的商品的保质期要求

供定期服用或使用并具有有效期的商品，或者以散装/捆绑商品包装形式出售的商品必须由买家接收，并留出充足的时间供其使用。例如，一瓶每天为 240 份的补充剂必须在有效期前超过 240 天才收到该商品。此要求适用于批量销售或作为捆绑商品一部分的所有单件商品。此外，食品和饮料类商品以及配送时包含食品或饮料的商品，必须采用分批控制方法，并在接收时备有足够的时间供买家使用。

下表列出了亚马逊认为可能存在有效期的商品以及各自的保质期指南。

**注意： **此列表并不详尽，仅作为指南。

| 商品 | 保质期 |
| --- | --- |
| 薯片和其他零食 | 90–180 天 |
| 干果 | 180–270 天 |
| 婴儿配方奶粉 | 180–365 天 |
| 谷物棒和格兰诺拉燕麦棒 | 180–365 天 |
| 宠物食品和零食 | 180–540 天 |
| 饮料，如咖啡、茶、苏打水和果汁 | 270–540 天 |
| 色拉酱和油 | 270 天 |
| 面粉、香料和烘焙用品 | 270–365 天 |
| 花生酱、果酱和果酱 | 365 天 |
| 意大利面 | 365 天 |
| 调味品,包括盐、胡椒和糖 | 365–730 天 |
| 糖果 | 540 天 |
| 罐装食品 | 540 天 |
| 草药或矿物补充剂 | 730 天 |
| 清洁用品 | 900–1,825 天 |
| 个护和美妆商品（洗发水、肥皂、乳液、化妆品、香水） | 900–1,825 天 |

## 具有有效期的商品的贴标

具有有效期的商品必须遵循以下贴标要求。

- 所有可食用商品（包括动物用品）必须明确标注有效期或制造日期。仅提供批号是不够的。

- 所有婴儿食品和婴儿配方奶粉商品必须明确标注有效期。

- 商品上的任何有效期都必须明确标注有效期。亚马逊认为“最佳使用日期”或“销售截止日期”等同于有效期。

- 商品上的任何制造日期都必须清晰标注为制造日期。制造日期等同于生产日期。

- 所有医疗器械必须有有效期。必须使用YYYY-MM-DD格式清晰贴标。

- 对于医疗器械之外的商品，可接受的日期格式为：

- MM-DD-YYYY

- MM-YYYY

- 最好使用数字日期格式。但是, 也可以采用字母缩写的月份日期 (例如，DD-JAN-YYYY)。

- 所有装运箱、内装多件商品的包装和展示箱以及其中的单件商品或捆绑商品上都必须标注有效期。

- 请勿遮挡商品包装上的原始有效期或其他信息（如成分、药物标识、净含量或经销商信息）。

## 对具有有效期的商品进行预处理

必须使用适合运输的包装材料完整包装和密封具有有效期的商品。对于需要进行额外预处理（需要使用塑料袋或气泡膜包装）的具有有效期的商品，必须在经过预处理的商品或商品包装外部粘贴具有有效期的标签。
