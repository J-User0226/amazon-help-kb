# 取消您的亚马逊手工艺品市场账户

**注意： **即使在移除 Amazon Handmade 账户后，您也必须配送或取消所有待处理的手工艺品订单。

如果您选择退出 Amazon Handmade，该操作将立即生效，并且您的账户将发生以下变化：

- 【我们将于下一账单周期开始向您收取专业销售计划费用】： $39.99 的月度专业销售计划费用豁免将会过期，且您每月均需支付该费用，除非您[切换到个人销售计划](https://sellercentral.amazon.com/gp/help/external/G201710030)或[关闭您的卖家账户](https://sellercentral.amazon.com/gp/help/external/G200399470)。

- 【您在 Amazon Handmade 发布和销售商品的权限将被撤消】： 您将无法再在亚马逊手工艺品市场发布商品，或提供定制手工艺品进行销售。亚马逊将移除您的艺术家资料页面。

- 【您将无法再访问您的商品评论或销售历史记录】： 如果您选择在 Amazon Handmade 之外重新发布商品，则您对您的商品评论或销售历史记录的访问权限将被撤销。

要退出 Amazon Handmade，请执行以下操作：

- 前往[我的服务](https://sellercentral.amazon.com/gp/express-boarding/mys-wizard-mode/components/manage-your-services.html?)。

- 在 【Amazon Handmade】 部分，点击【想要取消您的 Amazon Handmade 账户？】。

- 选择从专业销售计划中移除 Amazon Handmade 的原因。

- 点击【移除 Amazon Handmade】。

**注意： **一旦我们收到您的请求，就会向您发送确认信息。如果您改变了主意，想要再次开始在 Amazon Handmade 销售商品，请联系销售伙伴支持。

**注意： **亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。
