# 禁用退货评估的条款和条件

这些条款和条件是对[亚马逊服务商业解决方案协议](https://sellercentral.amazon.com/gp/help/external/G1791)的补充，对您禁用【退货商品评估】设置的决定进行管理，该设置可让您退出亚马逊退货评估流程。

退出亚马逊退货评估流程，即表示您接受并同意这些条款和条件以及任何适用的相关亚马逊政策。我们保留随时更改【退货商品评估】设置、相关亚马逊政策以及这些条款和条件的权利。

在这些术语中，“您”指您个人或您代表的企业。
1. **禁用“退货商品评估”设置。** 对于已禁用退货评估的 ASIN，您同意亚马逊不再评估买家退货商品。
2. **残损索赔。** 亚马逊不再评估您的退货商品以确定谁应该对商品残损负责。对于由亚马逊、承运人和买家造成的残损，您不再对亚马逊、承运人和买家提出索赔。
3. **商品注册。** 只能对符合要求的商品禁用退货评估。有关更多信息，请参阅[帮助页面](https://sellercentral.amazon.com/help/hub/reference/GHLB73JHHFHZCW2Y)。
4. **卖家参与。** 只有信誉良好的卖家才能禁用【退货商品评估】设置。
5. **违反条款和条件。** 不遵守这些条款和条件或亚马逊服务商业解决方案协议可能会导致【退货商品评估】设置被删除。
