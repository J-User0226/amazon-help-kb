# 关于商品文件

您可以在卖家平台中为任意商品上传商品文件，如用户手册或故障排除指南。商品文件旨在向买家提供购前信息和购后支持内容，让您遵守适用于您的商品的法律、法规和亚马逊政策。您有责任确保上传的所有文件始终准确无误。

## 允许的商品文件

下表说明了您可以在卖家平台上传哪些类型的文件。未显示在商品详情页面上的文件会离线存储。

| | 文件类型 | 描述 | 是否显示在商品详情页面上？ |
| --- | --- | --- | --- |
| 1 | 分析证书 | 由质量保证或检验机构签发的文件，确认某款受管制商品符合商品规范。 | 是 |
| 2 | 合规证书 | 经主管部门、制造商或制造商代表认证的文件，说明提供的商品或服务符合要求的规范。它也称为符合性证书、符合性声明或合格证书。 | 是 |
| 3 | 紧急使用授权 (EUA) | 对于每种获得紧急使用授权的新冠感染疫苗，美国食品药品监督管理局 (FDA) 要求向免疫接种者或其看护人员提供某些特定于疫苗的紧急使用授权信息，以帮助他们就疫苗接种做出知情决定。 | 是 |
| 4 | 紧急使用授权修正条款 | 紧急使用授权管理机构使美国食品药品监督管理局能够通过促进公共卫生紧急情况下提供和使用所需医疗应对措施，从而加强国家针对化学、生物、辐射和核威胁（包括传染性疾病）的公共卫生保护。 | 是 |
| 5 | 情况说明书（患者） | 包含有关商品、物质、服务或其他主题的基本信息的单页文件。 | 是 |
| 6 | 情况说明书（提供商） | 包含有关商品、物质、服务或其他主题的基本信息的单页文件。 | 是 |
| 7 | 安装手册 | 说明如何安装商品的文件。 | 是 |
| 8 | 使用说明书 | 一份说明商品的预期用途、如何正确使用商品以及任何注意事项的文件。 | 是 |
| 9 | 用户指南 | 说明如何使用商品的文件。 | 是 |
| 10 | 用户手册 | 一份包含有关商品操作、遵循标准和具备功能的详细信息的文件，让买家轻松了解如何使用相关商品。 | 是 |
| 11 | 安全信息 | 包含商品警告和安全信息的文件。 | 是 |
| 12 | 质保 | 说明商品保修条款和期限的文件。 | 是 |
| 13 | 故障排除指南 | 针对买家在使用商品时可能遇到的常见问题提供解决方案的文件。 | 是 |
| 14 | 安全数据表 | 包含关于商品中使用的化学品、化合物和化学混合物及其潜在危害信息的文件，有时还包括安全使用说明。 | 否 |
| 15 | 规格表 | 包含商品相关技术规格的文件。 | 否 |
| 16 | 兼容性指南 | 说明商品兼容性和使用方法的文件。 | 否 |
| 17 | 应用指南 | 提供有关商品操作和维护的详细技术信息的文件。 | 否 |

## 上传商品文件

您可以使用文件模板、“管理库存”页面或 API 上传商品文件。必须针对每个商城分别执行此操作。

**库存文件模板**

要使用单一商城模板完成批量提交，请按照以下步骤操作：

- 前往[添加商品](https://sellercentral.amazon.com/product-search)。

- 从【下载电子表格】选项卡中，选择“发布当前不在亚马逊目录中的商品”模板。

**注意： **如果您使用其他模板，这些步骤将不会起作用。

- 要上传商品文件，您必须使用商城的官方语言（例如，在德国商城，官方语言为德语）为单个商品类型和单个商城生成一个电子表格。您可能需要使用 ASIN 或 SKU 搜索商品。如果系统显示了【选择您想要创建报价的商城】步骤，请取消选择所有商城（显示为灰色的商城除外）。

**注意： **【生成电子表格】按钮上方可能会显示一条消息，提示您下载商品信息模板的测试版。选择加入，系统将生成一个包含必填属性的模板，并允许您继续执行第 4 步。如果此消息未显示，则表示所选商品类型和商城的必填属性尚不可用，但会稍后提供。要上传该商品类型和商城的商品文件，请按照下方“管理库存”部分下的步骤操作。

- 在第一行中，点击【下载】。

- 点击【生成电子表格】。

- 打开 Excel 文件。在 Excel 中，您可能需要点击【启用编辑】。

- 前往【模板】工作表。

- 在每行中，填写 A 列、B 列和 C 列。在 B 列中，您必须选择“部分更新”。

- 找到工作表的【安全与合规性】或【合规性】部分，该部分以紫色高亮显示。

- 滚动至“安全与合规性”部分并

- 在相关文件类型的列中（有 17 列，每种文件类型各一列）输入商品文件链接（您的商品文件所在的 URL）。这必须是直接下载链接（例如 https://s3.amazonaws.com/my-store-public-files/installational_manual.pdf），而不是在浏览器中打开 PDF 的共享链接（例如 https://s3.amazonaws.com/file/d/1RG3CAPiwiFlFATUlIIwhk0RrbEU4PgVP/view?usp=sharing）。

根据您选择的模板类型，这些行和列可能默认是隐藏的。 点击 Excel 标题中的 + 符号（公式栏下方）以取消隐藏这些列。

- 如果您想为其他 SKU 添加文件，请在新行中重复第 8~10 步。

- 将模板保存到您的本地驱动器并将其关闭。

- 前往[添加商品](https://sellercentral.amazon.com/product-search)，并在【发布商品】页面上选择【电子表格】选项。

- 打开【上传电子表格】选项卡，然后将文件拖放到上传框中，或者点击【浏览文件】，在您的电脑上找到该文件。

- 文件上传后，系统将开始自动验证流程。如果系统显示【验证失败】消息，请按照建议的步骤更正任何错误。然后，点击【替换】并上传更新后的文件。

- 系统显示【验证完成】消息后，点击【提交商品】。

- 点击【电子表格上传状态】选项卡。如果状态为【需操作】，请按照建议的步骤更正任何错误并替换文件。当状态更改为【完成】时，文件将发送给我们的审核团队进行进一步验证。

**注意： **如果您收到带有警告的一览模板，则说明您已成功提交数据，但我们建议您按照说明更新文件。

- 为任何其他商城重复第 1 步至第 19 步。

## 管理库存

要为现有单个 SKU 上传文件，请按照以下步骤操作：

- 前往[管理所有库存](https://sellercentral.amazon.com/myinventory/inventory)。

- 针对您要添加商品文件的 SKU，选中其所在行的复选框。然后点击该行末尾的三个点图标，并点击【编辑商品信息】，系统将在 Web 浏览器中打开一个新页面。

- 选择页面左侧的【所有属性】（可能已被选中）。如果在页面右上角可以看到【商品信息建议更改】，请点击该提示。

- 点击【安全与合规性】选项卡。

- 确保所有必填字段均已填写。

- 向下滚动至【合规性媒介】部分，填写以下属性： 

- **合规性媒介语言**： 从下拉菜单中选择语言代码。这是商城官方语言的代码，您的文件必须采用该语言印刷（例如，法国为 fr_FR，比利时为 fr_BE）。如果您要上传多语言文件，请仅选择商城的官方语言。

- **合规性媒介内容类型**： 从下拉菜单中选择文件类型。有关每种文件类型的描述，请参阅此帮助页面的“允许的商品文件”部分。

- **合规性媒介来源位置**： 输入商品文件链接（存储商品文件的 URL）。这必须是直接下载链接（例如 https://s3.amazonaws.com/my-store-public-files/installational_manual.pdf），而不是在浏览器中打开 PDF 的共享链接（例如 https://s3.amazonaws.com/file/d/1RG3CAPiwiFlFATUlIIwhk0RrbEU4PgVP/view?usp=sharing）。

- 点击【添加更多】，为同一 SKU 添加其他文件。

- 点击【保存并完成】。

创建新商品信息时，请遵循[一次添加一件商品](https://sellercentral.amazon.com/gp/help/external/200220550)中列出的标准步骤，然后执行上述第 3~7 步。

## API

您可以使用 API 上传您的商品文件（如果文件大于 10MB，则可能需要使用这种方式）。了解有关[商品信息 API](https://sellercentral.amazon.com/gp/help/external/GD76M4FUWL4NEU32) 的更多信息。

## 验证

您的商品文件可能需要七个工作日才能通过审核，以确保符合亚马逊商品文件指南。不符合这些指南的文件将被拒绝。

**注意： **上传文件并不能保证相关文件会显示，即使文件已获得批准。如果亚马逊收到多个卖家提交的文件，则将选择最符合风格指南和标准的文件，从而为买家提供最佳体验。我们会离线存储所有获得批准的文件，以便日后根据需要使用这些文件。

## 更正被拒的文件

如果文件被拒绝，亚马逊将通过电子邮件通知您。

您可以在[绩效通知](https://sellercentral.amazon.com/messaging/inbox?fi=responseNeeded)中查看该电子邮件。

**查看并提交商品的合规性文件**

- 前往[账户状况](https://sellercentral.amazon.com/performance/dashboard)。

- 在【政策合规性】下，点击【监管合规性】，以查看您的所有有效请求和拒绝原因。

- 在搜索字段中输入相应 ASIN。

- 点击“后续步骤”列中的“提交”，查看未满足的文件指南要求的更多详情。

- 点击【提交】以查看拒绝原因。

- 对文件进行必要的更改。

- 点击在同一文件类型下【添加新文件】，以替换该文件。

- 点击【保存】，发送您提交的内容以供审核。

**注意： **要对被拒绝的文件提出申诉，请点击[获取帮助](https://sellercentral.amazon.com/help/center)或使用卖家助手。

**如何修复文件中的错误**

| 小部件的拒绝原因 | 建议修复 |
| --- | --- |
| 提交的文件为空。 | 添加相关内容和图片。 |
| 文件缺少实质内容、内容未提供有用信息，或者未包含充分的商品相关信息。 | 添加详细信息以全面描述商品并满足内容要求，然后上传新版本文件。您的文件可能缺少有关商品功能、规格和优势的基本信息。 |
| 文件包含亚马逊标题、徽标、图片或与亚马逊相关的其他设计。 | 从您的文件中移除亚马逊标题、徽标、图片或其他与亚马逊相关的徽标。 |
| 文件提到了亚马逊或如何在亚马逊商城购买商品。 | 从文件的文本或图片中移除“亚马逊”一词，除非该词与特定的 Amazon Basics 和亚马逊品牌商品相关。 您还必须移除对亚马逊功能的任何引用（用来引导买家购买商品）。例如，“立即购买”“加入购物车”“立即获取您的商品”或“在我们这里购物”。 |
| 文件包含与配送、送达或物流相关的参考信息或详细信息。 | 移除文件中提及的任何配送详情，如免费配送优惠、配送时间表和配送方式，或任何其他物流相关详情。 |
| 文件中包含具有有效期的消息、内容或促销，或者涉及具有时效性的优惠。 | 移除具有有效期的商品消息或促销，或具有时效性的优惠。具有时效性的信息示例包括“正在促销”“限时优惠”“优惠即将结束”等词语，或提及有截止日期的具体活动或促销。 |
| 文件包含水印。 | 从文件中删除所有水印。 水印是覆盖或叠加在文件上的可见标志或徽标，通常用于表示所有权或真实性。 |
| 提交的文件与上传时自行选择的文件类型（例如用户手册和规格表）不符。 | 请使用正确的文件类型上传文件。 例如，如果您上传的是安全数据表，但选择了“用户手册”，则会被视为不一致。请参阅上方的“允许的商品文件”查看说明。 |
| 文件内容（例如商品规格、功能或描述）与实际销售的商品不符。 | 上传与该 ASIN 匹配的文件。 |
| 文件包含违反亚马逊风格指南政策的露骨或不适宜的材料。 | 请移除任何露骨或不适宜的内容，包括裸体内容、色情内容、攻击性语言或暴力内容。 |
| 文件包含与退款或退货相关的参考信息或详细信息。 | 删除任何提及退货和退款的内容。避免包含此类说明或信息，如“退还给卖家”“退款费用”或任何退货流程参考信息。 |
| 文件语言不包含该商城的主要语言。 | 上传使用商城主要语言的文件。这可以是单一语言文件，也可以是多语言文件。 |

## 替换您的商品文件

您可以替换上传的商品文件，方法是在[管理库存](https://sellercentral.amazon.com/hz/inventory)中编辑单个商品信息。 请确保您选择相同的“合规性媒介内容类型。” 如果有其他用户为同一 ASIN 提供了报价并上传了文件，那么您不能替换这些文件，这些文件可能会保留在商品详情页面上。编辑后提交的文件将再次进入审核流程。

**注意： **商品文件可以替换，但无法删除。

## 文件指南

请遵循我们的指南，为买家编写清晰有用的文件。您必须对您所上传文件中的图片和文本拥有所有必要的权利：

- 支持的文件类型： PDF（存储在直接下载 URL 中）

- 最大文件大小： 10 MB

- 仅允许使用有助于买家浏览文本的合理或有益的品牌图标或徽标。

- 文件不可包含以下术语或徽标： FCKW、CE-certified、WEEE、RoHS、CE-approved、CE-marked。

- 不应使用个人、买家或其他非公众人物的言论或署名。最多可使用 4 条来自出版物、公众人物、名人和品牌代言人的言论或背书。

- 不允许提及竞争对手的商品或与之进行比较，无论以何种方式提及竞争对手都不允许（如使用具体名称，表述为“另外的”或“其他”，或者采用其他方式）。此内容旨在打造品牌知名度并提供更多商品详情，而不是讨论竞争对手。

- 如果商标和版权符号大小合理，并且已包含在商品包装中或始终显示为徽标的一部分，则可以使用。

- 注明获得奖项和背书的日期，并确保来自经过核实且公开认可的来源（如证明、许可证编号或权威机构）。请勿提及获奖时间已超过 2 年的奖项。

- 不应使用任何形式的浮夸宣传，如“排名第一”“顶级”和“最畅销”。

- 所有营销声明、有关受管制商品（如药物、化妆品、医疗器械、饮料、食品和保健品 [包括天然保健品、维生素和补充剂]）的所有声明以及任何一般性健康声明均需经过证实。

- 文件中的语言必须与买家使用的语言一致。例如，在荷兰可以使用荷兰语和英语。

- 禁止提交空白文件。文件必须包含相关内容和图片。

- 文件必须提供全面且相关的内容，包括商品功能、规格和优势，以及其他任何相关详情，以帮助买家了解商品。

- 文件不可包含亚马逊标题、徽标或其他与亚马逊相关的徽标。

- 文件不可在内容文本或图片中提及“亚马逊”，除非文件与特定的 Amazon Basics 商品和亚马逊品牌商品相关。与亚马逊自有品牌无关的品牌不可模仿或引用亚马逊功能，引导买家购买。例如，“立即购买”“加入购物车”“立即获取您的商品”或“在我们这里购物”。

- 文件不可提及配送详情，如免费配送或配送时间表。

- 文件不可包含具有有效期或具有时效性的商品消息或促销。具有时效性的信息示例包括“正在促销”“限时优惠”“优惠即将结束”等词语，或提及有截止日期的具体活动或促销。

- 文件不可带有水印。水印是显示在数字内容上的可识别图片或图案，通常用于表示所有权或真实性。针对商品文件，水印指叠加到文件图片或文本上的任何可见标记或徽标。

- 文件的类型必须与上传时自行选择的文件类型一致。例如，如果您上传的是安全数据表，但选择了用户手册，则会被视为不一致。请参阅上方的“允许的商品文件”查看说明。

- 商品文件中提供的信息必须与描述的实际商品完全一致。例如，文件描述的是电视，但商品实际上是电话，这将被视为不一致。

- 文件不可包含色情成人内容的图片或文本。成人内容是指包含不适合所有受众的露骨或不适宜内容的图片或文本。这包括但不限于裸体、色情或冒犯性语言、暴力或其他成人主题。亚马逊指南禁止在商品文件中包含成人内容，从而为所有买家营造一个适合家庭的安全环境。

- 文件不可提及退货和退款。例如，“退还商品到发货地址”“退货并提供采购订单编号”“退还给卖家”“包含退货费用”。

**注意： **亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。
