# 错误 6000： 第一行不可读

文件中用于说明模板类型和版本的第一行经过修改后无法读取。请下载该模板的新版本，然后使用此版本上传您的数据，切勿修改第一行。

如果库存文件的第一行与已知模板类型或版本号不匹配，则会出现此错误。为了使亚马逊能够成功处理库存文件，您必须指定模板类型（如“服装”或“宠物用品”）以及版本号。库存文件的相关信息已记录在模板的第一行。

要纠正该错误，您应该：
1. 将您库存文件的第一行与相关库存文件模板的第一行进行比较。
2. 修改库存文件的第一行，使其与模板的第一行保持一致。
3. 如果在 Excel 中编辑库存文件，则 A1 单元格应包含模板类型，A2 单元格应包含版本号。
4. 如果在文本编辑器中编辑库存文件，第一行中应使用一个制表符来分隔模板类型和版本号。
5. 保存所做的修改。
6. 重新提交此库存文件。
