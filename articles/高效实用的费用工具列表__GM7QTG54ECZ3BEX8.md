# 高效实用的费用工具列表

## 费用估算工具

了解亚马逊提供的各种工具来估算和查看您的费用。

| | |
| --- | --- |
| 亚马逊物流收入计算器 | 根据配送渠道估算费用和利润。前往亚马逊物流收入计算器。 |
| 费用预览报告 | 该报告可显示您当前商品预计的“我要开店”费用和配送费用。要下载该报告，请前往亚马逊配送报告。 |
| 每件售出商品的预计费用 | 预览售出特定 SKU 的一件商品时需要支付的“我要开店”和亚马逊物流的主要费用。要查看预计费用，请前往管理库存。 |
| 销售佣金预览报告 | 该报告可提供基于您当前所发布商品价格的预计销售佣金。要下载该报告，请前往库存报告。 |
| GetMyFeesEstimate API | GetMyFeesEstimate API 可获取商品列表，以及这些商品的“我要开店”费用和配送费用。 |

## 查看已支付费用的工具

| | |
| --- | --- |
| SKU 成本卡 | 查看 SKU 在一段时间内的成本。要查看 SKU 成本卡，请前往管理库存，点击相应 SKU。 |
| SKU 成本报告 | SKU 成本报告提供汇总历史数据，以帮助您了解在选定的亚马逊商城和时间段内，商品在父 ASIN、子 ASIN、MSKU 或 FNSKU 级别随时间变化的成本。这包括销售数据、费用数据、广告数据、每商品成本数据和净收入数据。 |
| 付款一览 | 本页面提供付款一览信息，包括已支付的费用。链接的报告提供了针对特定交易和事件已支付的费用明细。要了解更多信息，请前往付款控制面板。 |
| 费用说明 | 借助费用说明，您可以查看有关特定交易的销售费用计算方式的详情。查看特定交易详情时，请前往交易视图。 |
| 月度仓储费报告 | 该报告可显示储存在亚马逊运营中心的各个 ASIN 的预计月度仓储费。要下载该报告，请前往亚马逊配送报告。 |
| 长期仓储费报告 | 该报告可提供储存在亚马逊运营中心的库存的长期仓储费明细。要下载该报告，请前往亚马逊配送报告。 |
| 费用分类指南 | 这是各个费用分类中商品的详细列表，可供搜索，您可以快速找到特定商品的费用分类。有关更多信息，请参阅了解费用分类。 |
