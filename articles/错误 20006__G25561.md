# 错误 20006

我们无法处理您的图片。

造成此错误的原因可能有很多。它们包括：

- URL 中显示的图片文件名没有有效的扩展名。

- 文件格式与各个有效的图片文件格式都不匹配。

- URL 包含了一个参数，不是指向图片的直接路径。例如：URL 中有问号 [?]。

有效的图片文件格式和扩展名为：

- GIF (*.gif)

- JPEG (*.jpg)

- TIFF (*.tif)

- PNG (*.png)

即使 URL 以这三种有效扩展名之一结尾，您仍应检查图片文件的格式是否有效。尝试以下操作：

- 在 Windows 系统使用 Internet Explorer 访问该 URL。

- 点击“查看”菜单并查询“来源”选项。

- 如果您可以选择“来源”，则您的文件是 HTML 文档。查看文件的来源，并使用此处显示的 URL。

- 如果您无法选择“来源”选项，则您的文件是图片文件。右键点击图片并选择“属性”。 将出现一个信息框，指明图片类型。

- 确保您的图片类型与有效的扩展名列表匹配。如果不匹配，请更改扩展名以匹配图片类型。

更改图片文件的扩展名并不会更改底层图片格式。例如，若您仅仅将扩展名更改为 .jpg 格式，您无法将位图 (*.bmp) 或 Adobe Photoshop (*.psd) 图片转化为 JPEG 图片。如要在 Windows 系统中使用 Internet Explorer 查询图片文件格式，其快捷方法是右键点击该图片，并从上下文菜单中选择“属性”。随即信息框会显示图片文件的格式。

有些基于 Unix 和 Mac 的操作系统会使用四个字符的文件扩展名，如 *.jpeg 和 *.tiff。在这种情况下，只需将扩展名更改为上述三字符版本即可。
