# 虚拟捆绑商品

借助虚拟捆绑商品工具，品牌代表和授权转销商可以创建由两个到五个互补的 ASIN 组成的“虚拟”捆绑商品，以使买家能够从单个商品详情页面购买这些商品。虚拟捆绑商品会向买家显示为单个商品信息，但会分别处理和配送其中的组成商品。这样，您在提供这些捆绑商品时就无需将商品打包在一起或更改您的入库库存了。

**注意： **虚拟捆绑商品工具在 Firefox 或 Chrome 浏览器上可呈现最佳效果。

## 卖家资格

此功能仅适用于在品牌注册中至少有一个品牌获得品牌代表或授权转销商角色分配的卖家。如果您无法使用此功能，说明您尚未被认定为品牌代表或授权转销商。请访问[品牌权益资格](https://sellercentral.amazon.com/brands/brand-relationships?ref=brnd_bndl_bssi_help)页面，确定已成为品牌代表或授权转销商，并且获得“虚拟捆绑商品”的访问权限和其他品牌专属权益。

## 要求

要向虚拟捆绑商品添加商品，必须满足以下资格要求：

- ASIN 必须属于您拥有的品牌，并且已经在[品牌注册](https://brandservices.amazon.com/)中注册。

- ASIN 必须有处于“新品”状况的在售亚马逊物流库存。

- 单个捆绑商品中的所有组成 ASIN 必须采用相同的配送方式。您不能混用不同配送渠道的库存，例如一个商品来自亚马逊物流库存，另一个来自卖家自配送库存。

- 可在以下亚马逊商城创建虚拟捆绑商品： 澳大利亚、巴西、法国、德国、印度、意大利、日本、墨西哥、西班牙、英国以及美国。

以下商品不能包含在虚拟捆绑商品中：

- 礼品卡

- 电子配送商品（如数字音乐、影视和图书）

- 翻新或二手 ASIN

- 手工艺品

## ASIN 数量

虚拟捆绑商品必须包含 2 ~ 5 个 ASIN。每个组成 ASIN 都必须可单独购买。这意味着，不能使用此工具创建[多件装](https://sellercentral.amazon.com/gp/help/external/94GSFMC79RSLDBY)商品和“多箱装”商品（即，用多个包装箱分批配送的单个 ASIN）。

符合要求和不符合要求的虚拟捆绑商品示例包括：

- 红色钢笔 (2) - 不能成为捆绑商品，因为只有 1 个 ASIN。

- 红色钢笔 (1) + 蓝色钢笔 (1) - 可以成为捆绑商品，因为有 2 个唯一的 ASIN。

- 红色钢笔 (4) + 蓝色钢笔 (7) - 可以成为捆绑商品，因为有 2 个唯一的 ASIN。

要在虚拟捆绑商品中包含属于某个 ASIN 的多件装商品，请将该 ASIN 添加到此捆绑商品中。然后，点击【捆绑商品中的数量】旁边的数字，调整该组成商品的可售有存货库存数量。

## 定价

虚拟捆绑商品根据各组成商品的价格总和定价。创建捆绑商品时，您设置的折扣百分比将按比例应用于所有组成商品。捆绑商品节省金额根据捆绑商品创建工具中显示的组成商品价格计算。

**重要： **

单个组成商品的有效促销活动、优惠或优惠券不计入捆绑商品价格计算。

如果您更改某个组成商品的价格，捆绑商品价格将根据新的组成商品价格及您作为卖家自定的捆绑商品折扣百分比更新。

如果捆绑商品价格高于组成商品当前价格的总和（包括组成商品的所有有效优惠或促销活动），该捆绑商品将失去推荐报价资格。为避免商品被屏蔽，请设置折扣百分比，以确保将任何有效的组成商品级促销活动考虑在内后，购买捆绑商品仍比单独购买各组成商品更便宜。

**注意： **

组成商品的优惠结束后，捆绑商品的折扣百分比保持不变。捆绑商品价格不会随促销活动的开始或结束自动调整。由您负责监控组成商品的促销活动并根据需要调整捆绑商品折扣。

如果您的捆绑商品显示的价格不正确，请前往[管理所有库存](https://sellercentral.amazon.com/myinventory/inventory?ref_=xx_invmgr_dnav_xx)，然后点击捆绑商品 ASIN 上的【编辑】。在不进行任何更改的情况下重新保存捆绑商品。这会在我们的系统中刷新捆绑商品。如果问题仍然存在，请删除并重新创建捆绑商品。

## 虚拟捆绑商品中的主要组成商品

您可以选择虚拟捆绑商品中的任何 ASIN 作为其主要组成商品。主要组成商品可帮助确定捆绑商品的搜索和浏览分类。捆绑商品 ASIN 会继承其主要组成 ASIN 的搜索关键词。

创建虚拟捆绑商品后，您无法再更改主要组成商品。如果您必须进行更改，请删除此捆绑商品，然后重新创建它。请使用其他 SKU，或者务必等待 24 小时后再重新使用同一 SKU。

## 曝光度

您的虚拟捆绑商品可能会在亚马逊商城的多个位置显示，以帮助买家发现它。

捆绑商品主要组成商品的详情页面可能会显示【包含此商品的捆绑商品】小部件，该小部件会显示共享同一主要组成 ASIN 的捆绑商品。

您的捆绑商品也可能会显示在商城中的搜索结果和其他详情页面展示位置。

要让捆绑商品显示在【包含此商品的捆绑商品】小部件中，须满足以下条件：

- 该捆绑商品的价格必须比单独购买各组成商品至少优惠 1%。

- 该捆绑商品必须可在其详情页面上购买。

- 该捆绑商品必须在其详情页面上显示为优胜报价。

- 新创建的捆绑商品最长可能需要 4 小时才会显示。

- 如果该捆绑商品的价格与各组成商品的总价相同，或优惠幅度小于 1%，则该捆绑商品虽然有优胜报价，但不会显示在“包含此商品的捆绑商品”小部件中。

**注意： **

禁止创建与现有捆绑商品具有完全相同的组成商品但指定的主要组成商品不同的捆绑商品。

## 编辑捆绑商品

保存捆绑商品后，可编辑虚拟捆绑商品 ASIN 的以下属性：

- 商品名称

- 描述

- 要点

- 商品亮点

- 折扣百分比

- 图片

但是，组成此捆绑商品的商品、主要组成商品、配送类型及此捆绑商品的 SKU 一旦保存便无法编辑。如果这些属性错误，请删除此捆绑商品，等待 24 小时后再重新创建它。如果您要重新创建，请使用其他 SKU，或者务必等待 24 小时后再重新使用同一 SKU。

编辑捆绑商品时，每个组成商品旁边都会显示一个【配送方式】标识，用于说明该捆绑商品的配送方式是亚马逊物流还是卖家自配送。

在[管理所有库存](https://sellercentral.amazon.com/myinventory/inventory)中，您的捆绑商品会显示为空白信息。虚拟捆绑商品 ASIN 在“管理所有库存”页面上显示的信息有限，此为故意之举，以防相关信息在捆绑商品工具之外被更改。要查看或编辑您的捆绑商品，请在“管理所有库存”页面上点击该捆绑商品 ASIN 的【编辑】。

## API 集成或上传数据

只能在卖家平台上创建和编辑虚拟捆绑商品。无法使用 API 或上传数据集成。请勿尝试使用上传数据或捆绑商品工具以外的任何其他方式编辑捆绑商品。

否则，您的虚拟捆绑商品将无法再购买。要解决此问题，请先从您的 API 集成或第三方工具中移除捆绑商品 ASIN。然后，编辑并重新提交此捆绑商品。

## 变体

目前，虚拟捆绑商品不能为变体系列的一部分。

## 促销、优惠券和 A+ 商品描述

虚拟捆绑商品必须符合[所有标准条件](https://sellercentral.amazon.com/gp/help/external/202111490)，才符合参与促销的要求。

**注意： **

添加捆绑商品折扣不会影响其组成 ASIN 的价格历史记录或其参与促销的资格。

虚拟捆绑商品可以使用[优惠券](https://sellercentral.amazon.com/gp/help/external/GJHCPEFJ5JJQD52D)和 [A+ 商品描述](https://sellercentral.amazon.com/gp/help/external/G202102960)。

## 广告

虚拟捆绑商品可以参与[品牌推广](https://advertising.amazon.com/solutions/products/sponsored-brands)和[商品推广](https://advertising.amazon.com/solutions/products/sponsored-products)广告。

## 评论和评级

虚拟捆绑商品 ASIN 的评论和评级与其各个组成 ASIN 的评论和评级相互独立。

## 订单和退货

虚拟捆绑商品中的商品会分别配送，就像单独购买的一样。买家可以根据每件商品的标准退货政策，退回捆绑商品中的单个组成商品。

## 费用

虚拟捆绑商品中的商品收取的卖家费用与单独购买时相同。创建或销售虚拟捆绑商品不收取额外费用。

如需了解更多信息，请参阅[虚拟捆绑商品的故障排除常见问题](https://sellercentral.amazon.com/gp/help/external/G2BTQWUUDS3RV7WB)。
