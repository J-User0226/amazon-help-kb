# 撤销优先配送资格

您需要一直保持优先配送计划参与资格，并且必须始终满足所有计划要求。

亚马逊每周都会评估您的绩效指标，如果您的绩效低于[优先配送要求](https://sellercentral.amazon.com/gp/help/external/G5M27FJWX76NAWRL)中规定的最低阈值，或者如果您违反了[计划政策](https://sellercentral.amazon.com/gp/help/external/G201503640)，您的资格都可能会被撤销。如果被撤销，您将无法为您的商品提供次日达和隔日达配送选项，并且您在[优先配送资格控制面板](https://sellercentral.amazon.com/performance/eligibilities)中的计划状态将从“符合要求”变为“不符合要求”

## 重新获得优先配送资格

如果您的资格被撤销，那么只要您满足所有绩效要求，就可以在等待 4 周后自动重新注册该计划。

以下示例展示了为何您的资格可能被撤销，并提供了有关如何避免未来再发生此类问题的建议。

| 您未达到以下要求： | 建议的操作 |
| --- | --- |
| 准时送达率 | 与承运人合作，确保他们在发出订单商品当天对您的拖车进行卸货、扫描和分拣。 确定哪些配送服务具有最佳准时送达绩效，并增加通过这些服务配送的量。 请确保已配置您的订单处理容量，以防订单数量超出每天的配送能力。 |
| 取消率 | 查看您的库存管理和库存控制流程。如果您发现已发布的商品经常缺货，您可以每天监控库存，以确保不会发布无法立即发货的商品。 |
| 有效追踪率 | 在确认发货之前，请确保您手动或自动上传追踪编码的流程可有效提供准确的编码。 考虑使用亚马逊购买配送服务，该服务可代表您上传追踪编码并确认订单发货，从而确保有效追踪。 |
