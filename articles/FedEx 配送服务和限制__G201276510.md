# FedEx 配送服务和限制

请前往 FedEx 的[配送方式](https://www.fedex.com/en-us/shipping/services.html)页面，了解有关以下国内配送服务的更多信息：

- FedEx Ground - 商业地址配送，星期一至星期五

- FedEx Ground Economy - 原 FedEx SmartPost

- FedEx Home Delivery - 住宅地址配送，星期二至星期六

- FedEx Standard Overnight

- FedEx Priority Overnight

- FedEx One Rate - 统一费率定价 

- FedEx 2Day

- FedEx 2Day A.M.

- FedEx Priority Overnight

- FedEx Express Saver

- FedEx Standard Overnight

**通过亚马逊购买配送服务使用 FedEx**

通过亚马逊购买配送服务购买 FedEx 配送服务时，承运人的配送及相关服务费用将从您的卖家平台账户中收取。如果您有直接与 FedEx 关联的托运人账户，则还可以将您的 FedEx 账户与您的卖家平台账户关联起来，以便在使用亚马逊购买配送服务时使用 FedEx 协议费率。在这种情况下，FedEx 的费用由您直接支付给 FedEx。

如果您在通过亚马逊购买配送服务购买 FedEx 货件标签时遇到任何问题，请确保您的发货地址格式正确，并且所表示的街道地址有效。地址行必须在 30 个字符以内且包含 2 个字符的州/省代码，并且不能为邮政信箱。

通过亚马逊购买配送服务购买标签，即表示您同意[亚马逊购买配送服务 - 条款和条件](https://sellercentral.amazon.com/gp/help/external/G200672320)。

**使用协议价格或关联您自己的 FedEx 费率**

[亚马逊购买配送服务](https://sellercentral.amazon.com/gc/sell-online/amazon-buy-shipping)使您能够通过亚马逊从可信承运人处购买标签，同时获得与配送问题相关的账户状况保护。我们通常会代表您与承运人协商更优惠的费率。您可以通过[卖家平台](https://www.youtube.com/watch?v=gHN4V2K38ZA&t=226s)或[配送 API V2](https://developer-docs.amazon.com/amazon-shipping/docs/shipping-api-v2-reference) 使用购买配送服务，也可以选择[多渠道配送合作商](https://sellercentral.amazon.com/gp/help/external/GZZPMC9QLNBX48RP)。此外，如果您想要使用自己的费率，可以直接在卖家平台上[关联您的 FedEx 费率](https://sellercentral.amazon.com/carrier-preferences/main)，并在您的首选渠道上使用。

无论您是关联自己的费率还是使用我们的协议费率，您都可以获得亚马逊购买配送服务提供的账户状况保护：

- **针对配送索赔的保护：** 准时配送您的订单，并获得亚马逊商城交易保障索赔保护*和 SAFE-T 索赔退款。

- **准时送达率：** 使用能可靠准时送达的配送方式，将延迟送达的可能性降低 34%**。

- **更快地配送订单：** 获取所有订单的自动发货确认和有效追踪信息。

*注意：*

**要获得亚马逊商城交易保障索赔保护资格，您必须： 1) 通过亚马逊购买配送服务购买货件标签；2) 准时发货（根据承运人首次扫描时间而非确认发货时间判定）；3) 在 48 小时内通过买家与卖家消息服务回复买家问询。*

***与在购买配送服务之外购买货件标签的亚马逊卖家相比。*

**运费**

您通过卖家平台账户从 FedEx 购买配送或相关服务，即表示您同意支付与这些服务相关的费用，包括基于重量的费率或基于尺寸的费率（以两者较高者为准），以及承运人根据其政策收取的任何附加费。费率可能随时变更，恕不另行通知。有关更多信息，请参阅[购买配送服务 - 条款和条件](https://sellercentral.amazon.com/gp/help/external/G200672320)。

**FedEx 尺寸和重量限制**

FedEx 有权在其设施内对您的货件进行称重和测量后调整运费。要对运费提出异议，请联系 FedEx。

对于因尺寸和重量限制而需要进行额外处理的货件，FedEx 可能会收取相应附加费。可访问 FedEx 官方[网站](https://www.fedex.com/en-us/shipping/rate-changes/additional-shipping-fees.html)查看完整列表。要减少调整运费的情况，请务必准确报告货件的重量和尺寸，并查看 FedEx [体积重量规则](https://www.fedex.com/en-us/small-business/peer-insights/packaging-tips/what-is-dimensional-weight.html)。

## 非邮政信箱配送

FedEx 配送选项不适用于使用邮政信箱配送地址的订单。FedEx 仅配送到街道地址。

## 打印标签

在亚马逊购买的 FedEx 标签有 4x6 PNG、4x6 ZPL 和 8.5x11 PDF 三种形式。

## 关联您的 FedEx 账户

要关联您的 FedEx 账户，请参阅[管理您的承运人账户](https://sellercentral.amazon.com/gp/help/external/200785170)。

## FedEx 配送方式限制

- FedEx Ground Economy 服务对于包裹处理有特定要求。为确保正确追踪并避免产生额外的邮费，所有包裹都必须直接交付或投递到 FedEx 网点。此外，使用此服务进行配送时，请务必遵循以下包裹规格： 

- 包裹货件的重量为 1~70 磅，长度不超过 130 英寸。

- 亚马逊购买配送服务不支持 Bound Printed Matter (BPM) 和媒介类商品邮寄选项。

- FedEx Ground Economy 目前仅支持亚马逊预先商定的费率。

- 如果您的包裹残损或丢失，请参阅 [Ground Economy - 特定索赔](https://www.fedex.com/en-us/shipping/ground/economy/rate-zones-documents.html)资源，或者前往[针对丢失或残损货件的可选保险项目](https://sellercentral.amazon.com/gp/help/external/G200204080)了解更多信息。

- 前往链接资源中的 [Ground Economy 费用](https://www.fedex.com/en-us/shipping/ground/economy/rate-zones-documents.html)和其他配送信息文件，了解有关大件和不可加工限制的更多详情。

**以下限制适用于 FedEx One Rate：**

选择 FedEx One Rate 配送方式时，您可以通过两种方法查看 FedEx One Rate 报价并配送商品。

- 您可以使用 FedEx 统一费率信封、扁盒、厚箱或长箱。请参阅 [FedEx One Rate 网站](https://www.fedex.com/en-us/shipping/one-rate.html)订购这些包装箱盒。当输入的包裹尺寸（长宽高）与下表所列的其中一个 FedEx One Rate 标准尺寸完全一致时，FedEx One Rate 将显示为一项可用服务。

## 联系 FedEx

要查找离您最近的 FedEx 投件地点或追踪包裹，请访问 [FedEx.com](https://www.fedex.com/en-us/home.html)。如有特殊需求，例如安排取件、咨询周末服务事宜以及[遗失或残损索赔](https://sellercentral.amazon.com/gp/help/external/G200204080)，请直接致电 FedEx（电话：1-800-463-3339）。

## 费率免责声明

FedEx 配送报价仅为预估值。最终费用可能因实际包裹特征和 FedEx 条款而异。

## 购买配送服务 API

要使用 FedEx Ground Economy，卖家、集成商和开发人员可能需要添加配送方式名称和编号，它们可通过以下属性来表示：

| API | 属性 | 价值 |
| --- | --- | --- |
| 卖家自配送 API | ShippingServiceId | FEDEX_PTP_SMARTPOST |
| | ShippingServiceName | FedEx Ground Economy |
| 配送 API v2 | ServiceId | FEDEX_PTP_SMARTPOST |
| | ShippingServiceName | FedEx Ground Economy |

要了解有关亚马逊购买配送服务 API 的更多信息，请参阅[卖家自配送 API](https://developer-docs.amazon.com/sp-api/docs/merchant-fulfillment-api-v0-reference#geteligibleshipmentservices) 和[配送 API v2](https://developer-docs.amazon.com/amazon-shipping/docs/shipping-api-v2-reference#getrates)。
