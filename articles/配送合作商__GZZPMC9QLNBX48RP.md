# 配送合作商

如果您是参与专业销售计划的卖家，则可以使用[卖家配送 API](G201950090) 通过[亚马逊商城网络服务](https://developer.amazonservices.com/)访问[亚马逊购买配送](G200202220)。开发人员可以借助亚马逊商城网络服务开发让卖家在卖家平台以外使用亚马逊购买配送服务的应用程序。

您也可以通过采用亚马逊卖家自配送 API 的符合要求的第三方配送合作商来购买货件标签。对于许多合作商来说，这个过程简单到只需点击一次即可完成。亚马逊卖家平台合作伙伴网络是一个目录，列出了代表亚马逊卖家进行创新且经批准的第三方软件和服务合作伙伴。转至[亚马逊卖家平台合作伙伴网络](https://sellercentral.amazon.com/partnernetwork)，查找配送解决方案。

如果您当前使用的配送合作商不在列表内，请联系您的合作商以了解他们是否已采用 API 或他们采用 API 的时间计划。
