# FSA/HSA accounts and product eligibility

灵活支出账户和健康储蓄账户（FSA、HSA）是具有税收优势的金融账户，人们可以留出部分收入来支付符合要求的医疗费用。买家可以在我们的网上商城中注册其 FSA 或 HSA 卡，然后像使用借记卡一样购买符合 FSA 或 HSA 要求的商品。

要符合 FSA 或 HSA 要求，商品必须符合美国国家税务局规定的指南（税务法 508C 第 213(d) 款），并由解释这些指南的库存标准特殊兴趣小组 ([SIGIS](https://www.sig-is.org/)) 确定。

为了确定符合要求的商品，亚马逊获取了 SIGIS 提供的通用商品编码 (UPC) 列表，并将其与目录中已有的相应商品进行匹配。

亚马逊的“符合 FSA 或 HSA 要求”标记是健康福利资格的原始依据。请避免在您的商品详情页面中包含“符合 FSA 或 HSA 要求”等字眼。符合要求的字眼包括：

- 符合 FSA 或 HSA 要求

- 符合 FSA 要求

- 符合 HSA 要求

## Add or remove a product from being FSA/HSA eligible

如果您想要添加或移除符合 FSA 或 HSA 要求的商品，我们将代表您将请求提交至 SIGIS。

要提交商品并将其添加至 SIGIS 的符合要求的商品列表，或从该列表中移除，请完成以下操作：

- 确认您已查看 [SIGIS 符合要求的商品列表标准](https://www.sig-is.org/eligible-product-list/eligible-product-list-criteria)，且认为商品符合指定的指南要求。

- 确认您确定的商品在我们的网上商城中的目录数据（尤其是 UPC）正确无误。如果目录数据不准确或已过时，我们的系统可能无法正确识别已列入 SIGIS 列表的商品。

- 填写[商品申请表](https://m.media-amazon.com/images/G/02/Vendor_SOP/US_ASIN_FSA_Eligibility_Request.xlsx)，列出您想要添加或移除的符合 FSA 或 HSA 要求的商品和目录信息。

- 要在[卖家平台](https://sellercentral.amazon.com/help/hub/reference/GK3V2JYCN2P28BFX)中提交查询，请点击【联系我们】，并将商品申请表附加到您的查询中。

**注意： **亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。

如果商品被添加至 FSA 或 HSA 资格列表，或从该列表中移除，则同样使用 SIGIS 的所有国内零售商都将知晓这一变更。

## FSA/HSA eligible product has not become FSA/HSA eligible in our online store yet

如果您确认商品已获得 SIGIS 批准，属于符合 FSA 或 HSA 要求的商品，但其在我们的网上商城中尚未成为符合 FSA 或 HSA 要求的商品，请完成以下步骤。这有助于我们对这一问题进行审核，并验证商品是否为已注册的品牌，是否具有正确的 UPC，以及所确定的商品是否位于 SIGIS 符合要求的商品列表中。

- 确认您已查看 [SIGIS 符合要求的商品列表标准](https://www.sig-is.org/eligible-product-list/eligible-product-list-criteria)，且认为商品符合指定的指南要求。

- 确认您确定的商品尚未在我们的网上商城中被列为符合 FSA 或 HSA 要求的商品。

- 确认您确定的商品在我们的网上商城中的目录数据（尤其是 UPC）正确无误。如果目录数据不准确或已过时，我们的系统可能无法正确识别已列入 SIGIS 列表的商品。

- 填写[商品申请表](https://m.media-amazon.com/images/G/02/Vendor_SOP/US_ASIN_FSA_Eligibility_Request.xlsx)，列出您想要添加或移除的符合 FSA 或 HSA 要求的商品和目录信息。

- 要在[卖家平台](https://sellercentral.amazon.com/help/hub/reference/GK3V2JYCN2P28BFX)中提交查询，请点击【联系我们】，并将商品申请表附加到您的查询中。

**注意： **亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。

**注意： **如果商品未被 SIGIS 认定为符合 FSA 或 HSA 要求，则亚马逊无法将其发布为符合 FSA 或 HSA 要求的商品。如果您不确定您的商品是否符合 FSA 或 HSA 要求，请参阅 [SIG-IS 的 FSA 或 HSA 资格商品列表标准](https://www.sig-is.org/eligible-product-list/eligible-product-list-criteria)。
