# 错误 8106/8108/8602

StandardProductID 值无效。

有关详情，请参阅 http://sellercentral.amazon.com/gp/help/24741。

如果您提供的 StandardProductID 值不符合您指定的 ProductIDType 的要求，就会出现此错误。有效的 ProductIDType 值包括：

- UPC

- EAN

如果您输入“UPC”作为 ProductIDType，则必须提供一个有效的 12 位 UPC 作为您的 StandardProductID 值。如果您输入“EAN”作为 ProductIDType，则必须提供一个有效的 13 位 EAN 作为您的 StandardProductID 值。

您的值可能无效的常见原因包括：

- 您遗漏了校验位，因此位数不符合要求。校验位是字符串中的最后一位，是根据字符串中的其他数位计算得出的。您可以使用万维网上提供的众多 UPC 或 EAN 验证器之一验证或计算您的校验位。

- 您未提供要求的位数，因为您的 StandardProductID 以 0 开头，当您将其输入库存文件模板后，Excel 将这个 0 删除了。如果是这种情况，请在输入 StandardProductID 值之前将 StandardProductID 列的格式更改为文本（“格式”>“单元格”）。

- 您指定了错误的 ProductIDType。如果是这种情况，请输入正确的 ProductIDType。

计算 UPC 和 EAN 编码的校验位的实用在线工具由 EAN International 维护。[https://www.gs1us.org/](https://www.gs1us.org/)
