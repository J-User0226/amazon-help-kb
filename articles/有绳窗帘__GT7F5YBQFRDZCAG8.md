# 有绳窗帘

如果您要在亚马逊商城发布商品，则必须遵守与这些商品和商品信息相关的所有适用法律、法规、标准以及亚马逊政策。

## 亚马逊针对有绳窗帘的政策

有绳窗帘是一种室内用的窗帘，可通过一根吊绳控制升降。此类商品包括但不限于风琴帘、水平百叶帘、百褶帘、卷式百叶帘、卷帘、透光帘、罗马帘、帘杆（包括使用帘杆的商品，如带帘杆的窗帘和布帘）、面板轨道和垂直百叶帘。

## 适用的法律、法规和标准

亚马逊要求所有带绳窗帘均须符合适用的法律、法规和标准，包括：

| 商品 | 法律、法规和标准 |
| --- | --- |
| 有绳窗帘 | 以下所有法规： ANSI/WCMA A100.1-2022（美国窗帘商品安全国家标准） |

## 针对亚马逊政策规定的可售商品的亚马逊合规性要求

您必须满足下列合规性要求：

| 要求 | 商品详情页面 | 合规性信息 |
| --- | --- | --- |
| 商品信息属性 | 必需 | |
| 文件 | | 必须符合的要求 |
| 图片 | | 必需 |

**商品详情页面**：

商品详情页面必须满足以下所有条件：

**商品信息属性**

- 型号、部件编号或商品编号

- 制造商或品牌名称

**合规性信息**

您必须直接向亚马逊提交以下信息：

**文件**

- 由 ISO 17025 认可的实验室出具的检测报告，证明该商品符合 ANSI/WCMA A100.1-2022 标准

**注意： **向亚马逊提供的所有检测文件必须显示“通过”或“不适用”的结果。若结果显示为“失败”“不合规”“不符合”或空白，将不予接受。

**图片**

- 型号、部件编号或商品编号

- 制造商、进口商或私有品牌商、分销商或授权代表的名称和地址

- 商品说明书和手册（英语和西班牙语）

- 商品标签

- 危险警告应永久附着在商品及其包装上（英语和西班牙语），表明该商品符合 ANSI/WCMA A100.1-2022 第 5.1 节和第 5.2 节

- 示例包括但不限于： “警告： 勒颈危险 — 儿童可能会被拉绳和珠链套环勒住。请将拉绳和珠链放在儿童接触不到的地方。”

**提交文件和图片时，请确保：**

- 文件并非来自[暂时停用的验证实验室](https://sellercentral.amazon.com/gp/help/external/GQG5MW4Q93L59T5K)

- 提供的所有文件和图片必须真实，采用未经修改的原始格式，且并非电脑或人工智能生成

- 商品说明书、手册、安全信息、标签和警告均要采用目标销售国家/地区的语言

- 图片能够证明该商品与受检商品以及商品详情页面上发布的商品相同

- 图片必须展示商品或其包装的所有面

- 如果商品为套装或捆绑商品，请分别为套装或捆绑商品中包含的每件商品提供文档和图片

**注意： **请提供清晰易读的文档和图片，这样有助于降低批准流程出现延迟的可能性。

客户安全是我们的首要任务。我们保留随时要求您提供更多信息以验证商品安全性和合规性的权利。

**直接向亚马逊提交合规信息或申诉**

要提交合规信息，或者对此要求提出申诉，请参阅[提交合规信息或申诉](https://sellercentral.amazon.com/gp/help/external/GC35Z63FGCUCUWXX)。
