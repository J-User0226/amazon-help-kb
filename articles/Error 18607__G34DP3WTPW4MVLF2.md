# Error 18607

## Error message

${variant} image contains inappropriate content not permitted for this product type. To fix this: (1) remove any suggestive or inappropriate content; (2) ensure image meets Product Image Requirements; (3) resubmit compliant image. For more details, search for error code or error message in the help section of your account.

## Reason for error 18607

This error occurs for the following reasons:

- Product images contain suggestive, offensive, or adult-oriented content that violates marketplace standards.

- Images include unauthorized text overlays, watermarks, or promotional content not permitted for the product type.

- Images display graphic content, violence, or other restricted visual elements that breach policy.

## Resolve error 18607

To resolve the error, follow these steps:

- Review your image carefully against the detailed [Amazon's product image requirements](https://sellercentral.amazon.com/help/hub/reference/G1881).

- Remove or edit any elements in the image that could be considered inappropriate, suggestive, or violating the guidelines.

- Resubmit the compliant image that accurately represents your product without any restricted content.
