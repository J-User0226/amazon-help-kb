# 使用“发送至亚马逊”创建货件

[Send to Amazon](https://sellercentral.amazon.com/fba/sendtoamazon/)是一个简化的标准化货件创建流程，只需几步，就可以补充亚马逊物流库存。

通过 Send to Amazon，您可以做到以下几点：

- 通过简化流程步骤，**缩短创建货件所需的时间**。

- **按照最适合您的操作步骤**，在创建货件之前或[之后](https://sellercentral.amazon.com/gp/help/external/GWS4LCESEXQKDB5S)打包包装箱。

- **[创建可重复使用的大包装模板](https://sellercentral.amazon.com/gp/help/external/G8SXKYFWPG6DAW6T)**，为单一 SKU 包装箱中的货件提供箱内物品信息、包装箱重量和尺寸，以及预处理和贴标详情。如果您想要为某个 SKU 使用相同的包装箱配置，模板是理想之选，因为您不必在每次补货时都重新输入详细信息。

- **在创建货件之前或[之后](https://sellercentral.amazon.com/gp/help/external/GWS4LCESEXQKDB5S)打包单一 SKU 和混合 SKU 包装箱**，并在包装时更新数量，然后再确认货件的运送目的地。

- **选择最佳选项来运送库存**，可以是单个包装箱（[小包裹快递](https://sellercentral.amazon.com/gp/help/external/G200280260)），也可以是托拍（[汽运零担](https://sellercentral.amazon.com/gp/help/external/G200280270)）。

- **比较预计的承运人费用**，以便在单个包装箱（[小包裹快递](https://sellercentral.amazon.com/gp/help/external/G200280260)）或托拍（[汽运零担](https://sellercentral.amazon.com/gp/help/external/200280270)）两种库存运送方式之间做出最佳选择。

## 开始使用“发送至亚马逊”

要开始使用此工作流程，请前往[货件处理进度](https://sellercentral.amazon.com/gp/fba/inbound-queue/index.html)，然后在此页面顶部附近的“货件”下拉菜单中点击【发送至亚马逊】，以显示您的亚马逊物流 SKU 列表。

接下来，要创建货件，请按照以下步骤操作：

通过“发送至亚马逊”工作流程，只需以下 3 步，就可以创建运往亚马逊运营中心的货件：

- 第 1 步： [选择要运送的库存](https://sellercentral.amazon.com/gp/help/external/G8SXKYFWPG6DAW6T)

- 第 1b 步： [包装混装商品](https://sellercentral.amazon.com/gp/help/external/GQ2HY393LHXF3GZN)

- 第 2 步： [确认发货](https://sellercentral.amazon.com/gp/help/external/GWC4BVUFCZ2FKHQW)

- 第 3 步： [打印箱子标签](https://sellercentral.amazon.com/gp/help/external/GCUH6KKZA6PRA4E7)

- 第 4 步： [确认承运人和托拍信息](https://sellercentral.amazon.com/gp/help/external/GBJBZ65P2LHZM2DG)（仅针对托拍货件）

- 第 5 步： [打印托拍标签](https://sellercentral.amazon.com/gp/help/external/GV42EVAG2U5ACZAQ)（仅适用于由亚马逊合作承运人运送的托拍货件）

- 第 6 步： [追踪详情](https://sellercentral.amazon.com/gp/help/external/GWKTQ4PADXXT58JY)（适用于未使用亚马逊合作承运人的小包裹和托拍货件）

要了解更多信息，请前往[站点导航培训](http://sellerassistant.compassites.net/sta_dashboard)控制面板。

要了解如何更改或取消货件，请参阅[发送至亚马逊： 更改或取消货件](https://sellercentral.amazon.com/gp/help/external/GP29SYECJZGJ9XMR)。

## 切换工作流程

您最多可以在三十个有效工作流程之间进行切换。 一旦某个工作流程中所有货件都处于已发货状态，即您为小包裹快递和合作承运人货件打印了承运人标签，为货运合作承运人货件打印了提货单，或为所有非合作承运人货件输入了送达时段，该工作流程即视为已完成，将不再算作有效工作流程。

要切换到其他有效工作流程，请按照以下步骤操作：

- 点击【有效工作流程】。

- 找到所需的工作流程，然后点击【切换到此工作流程】。

**注意： **您还可以点击[货件处理进度](https://sellercentral.amazon.com/gp/fba/inbound-queue/index.html)中的货件名称，访问之前创建货件的工作流程详情。

## 常见问题

#### 我是否可以使用 Send to Amazon 将 SKU 转换为亚马逊物流？

不可以。货件工作流程第 1 步[选择要发送的库存](https://sellercentral.amazon.com/gp/help/external/G8SXKYFWPG6DAW6T)中仅显示已转换为亚马逊物流的 SKU。 要了解如何将 SKU 转换为亚马逊物流，请参阅[开始使用亚马逊物流](https://sellercentral.amazon.com/gp/help/external/53921)。

#### 如何查看我的入库计划（Send to Amazon 工作流程）？

点击[货件处理进度](https://sellercentral.amazon.com/gp/fba/inbound-queue/index.html)中的货件名称，就可以查看您的 Send to Amazon 工作流程。要了解如何在有效工作流程之间切换，请参阅上面的【切换工作流程】部分。

#### 如何访问之前创建的货件的工作流程详情？

您可以从[货件处理进度](https://sellercentral.amazon.com/gp/fba/inbound-queue/index.html/ref=ag_xx_cont_fbashipq)中获取有关所有已确认货件的信息，并使用货件编号搜索这些货件。在“货件处理进度”中点击一个货件，就可以前往“货件一览”页面。您可以在该页面追踪货件、查看货件内的商品并对库存进行货件差异查询。要查看 Send to Amazon 中的货件，请点击【创建自】旁边的链接。

#### 可以为我的 Send to Amazon 工作流程重新命名吗？

可以。您可以点击**重命名工作流程**，为 Send to Amazon 工作流程重命名。

#### 销售伙伴 API 是否支持 Send to Amazon？

支持。我们有[亚马逊物流入库 v2024 API](https://developer-docs.amazon.com/sp-api/docs/fulfillment-inbound-api-v2024-03-20-reference)，支持构建入库工作流程，以创建和管理货件并将其运送至亚马逊配送网络。此 API 与 Send to Amazon 用户界面具有互操作性。

#### 我能否在 Send to Amazon 工作流程中安排亚马逊运营中心的预约？

不可以。亚马逊不允许通过一般公共运输方式送货。只有专业承运人才能通过承运人平台在运营中心进行送货预约。有关更多信息，请参阅[有关汽运零担和整车运输货件的承运人要求](https://sellercentral.amazon.com/gp/help/external/200978420)。
