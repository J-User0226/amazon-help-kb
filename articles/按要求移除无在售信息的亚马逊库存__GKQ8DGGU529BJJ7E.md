# 按要求移除无在售信息的亚马逊库存

根据[亚马逊服务商业解决方案协议](https://sellercentral.amazon.com/gp/help/external/G1791)，您需要从亚马逊运营中心移除所有“不当商品”。

具有有效报价但无在售信息的亚马逊库存商品不会被自动移除。有关更多信息，请参阅[解决无在售信息的亚马逊库存问题](https://sellercentral.amazon.com/gp/help/external/GEYJTVJPWRYUTADQ)。

如果由于以下原因出现无在售信息的亚马逊库存，则暂时**不**需要按要求移除：

- 未到商品销售日期

- 正在接受危险品审核

## 无在售信息的亚马逊库存移除设置

所有卖家都应更新无在售信息的亚马逊库存的自动移除设置，以便自动移除此类库存。请注意，如果您在多个国家/地区拥有账户，您必须在每个国家/地区配置自动移除设置，否则这些设置将仅为一个国家/地区保存。

商品可能由于账户问题或商品问题而没有在售信息。自动移除设置允许卖家在库存自动移除之前选择首选的自动移除选项以及无在售信息的亚马逊库存的留存时间。这适用于账户级别和商品级别的库存。

## 安排自动移除

无在售信息的亚马逊库存的自动移除设置页面会显示【亚马逊建议的天数】以及允许安排自动移除此类库存的【最长天数】。建议的天数和最长天数将根据导致无在售信息的亚马逊库存的原因而有所不同。

- 系统将根据您的设置和商品无在售信息的时间计算自动移除日期。

- 如果您尚未配置无在售信息的库存移除设置，您的库存将在[修复无在售信息的亚马逊库存](https://sellercentral.amazon.com/inventoryplanning/stranded-inventory)页面上显示的无在售信息原因代码所允许的最多天数后被弃置。

- 当您的库存变为无在售信息的亚马逊库存时，您将收到一封电子邮件通知，系统将通知您，您在亚马逊运营中心有无在售信息的亚马逊库存，这些库存计划自动移除，并且亚马逊将根据您在 [修复无在售信息的亚马逊库存](https://sellercentral.amazon.com/inventoryplanning/stranded-inventory) 页面上选择的设置退还或弃置这些库存。

对于每个导致无在售信息的亚马逊库存的原因，允许的最长天数如下所示：

| 无在售信息的亚马逊库存的类型 | 导致无在售信息的亚马逊库存的原因 | 最长天数 |
| --- | --- | --- |
| 商品的无在售信息的亚马逊库存 | 违反政策和限制 | 60 天 |
| 严重违反政策和严格限制 | 30 天 | |
| 已停售商品或卖家自配送商品 | 180 天 | |
| 商品已删除 | 30 天 | |
| 账户的无在售信息的亚马逊库存 | 账户问题 | 60 天 |

如果您已让我们加速自动移除无在售信息的亚马逊库存商品，这些商品的移除速度可能会更快。一旦您的库存变为无在售信息的亚马逊库存，您就会收到关于此事件的通知，因此，您可以在自动移除日期之前在“修复无在售信息的亚马逊库存”页面上自定义您的设置。

您可以在【自动移除前天数】字段中指定一个小于允许的最长天数的值，从而选择加速自动移除无在售信息的亚马逊库存商品。您可以选择【亚马逊建议的】天数，也可以提供自己选择的天数。为了简化您的设置配置流程，我们已将所有无在售信息的亚马逊库存原因代码汇总到账户问题和无在售信息的亚马逊库存问题中。

要自定义自动移除设置，请前往[修复无在售信息的亚马逊库存](https://sellercentral.amazon.com/inventoryplanning/stranded-inventory)，然后点击【编辑自动操作设置】。

下表显示了您是否会在自动移除之前收到通知，还指出您在自动移除设置中选择【亚马逊建议的天数】后可能会收到通知的时间。

| 无在售信息的亚马逊库存的类型 | 导致无在售信息的亚马逊库存的原因 | 建议天数 | 首次通知： 当库存变为无在售信息的库存时 | 弃置通知： 弃置日 |
| --- | --- | --- | --- | --- |
| 商品的无在售信息的亚马逊库存 | 违反政策和限制 | 30 天 | 是 | 是 |
| 严重违反政策和严格限制 | 7 天 | 是 | 是 | |
| 已停售商品或卖家自配送商品 | 90 天 | 是 | 是 | |
| 商品已删除 | 14 天 | 是 | 是 | |
| 账户的无在售信息的亚马逊库存 | 账户问题 | 45 天 | 是 | 是 |

要查看计划移除商品的时间，您可以监控[修复无在售信息的亚马逊库存](https://sellercentral.amazon.com/inventoryplanning/stranded-inventory)页面。

**注意： **查看[修复无在售信息的亚马逊库存](https://sellercentral.amazon.com/inventoryplanning/stranded-inventory)页面时，【无在售信息的亚马逊库存事件日期】列会显示库存是何时进入无在售信息状态的。无在售信息的天数从该日期开始计算。【自动移除日期】列会显示计划移除库存的时间。

您可以在计划自动移除之前创建移除订单，以弃置库存，或者将其退还给您。亚马逊将收取标准的亚马逊物流移除订单费用。

## 用于移除无在售信息的亚马逊库存的退还地址

如果您选择的移除方式是【退还商品】，请确保在【无在售信息的亚马逊库存的自动移除设置】中更新您的退货地址。

更新可售和不可售商品设置中的地址后，无在售信息的亚马逊库存的自动移除设置中的地址并不会自动更新。无在售信息的亚马逊库存自动移除设置和不可售商品设置中的地址必须单独更新。

要更新您的地址，请前往[修复无在售信息的亚马逊库存](https://sellercentral.amazon.com/inventoryplanning/stranded-inventory)，然后点击【编辑自动操作设置】。

- 点击【查看或编辑自动移除设置】。

- 点击自动移除设置中的【编辑地址】，然后更新无在售信息的亚马逊库存自动移除地址中的退货地址。

## 延迟自动移除

如果您需要更多时间来解决无在售信息的亚马逊库存问题，请前往[修复无在售信息的亚马逊库存](https://sellercentral.amazon.com/inventoryplanning/stranded-inventory)页面，然后从商品右侧的下拉菜单中选择【将移除延迟 30 天】。

**注意： **对于**每个无在售信息的亚马逊库存事件，您只能延迟移除一次**。
