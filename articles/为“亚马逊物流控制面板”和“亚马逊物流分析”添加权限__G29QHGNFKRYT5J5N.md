# 为“亚马逊物流控制面板”和“亚马逊物流分析”添加权限

可从卖家平台主页中的【库存】下拉菜单访问“亚马逊物流控制面板”和“亚马逊物流分析”。它们仅对有权使用该工具的账户用户可见。

如果您没有权限，则您账户的主账户持有人可以通过[用户权限](https://sellercentral.amazon.com/gp/account-manager/home.html?)页面向您授予权限。亚马逊无法向您授予权限。

要向账户用户授予权限，请按照以下步骤操作：

- 从【设置】的下拉菜单，选择【用户权限】。

- 添加新用户或选择现有用户。

- 点击【添加至全球账户】或【管理全球权限】，以添加或修改用户的权限。

- 向下滚动至【库存】部分，找到【“亚马逊物流控制面板”和“亚马逊物流分析”】。从以下三个权限级别中选择一个：

| 选项 | 描述 |
| --- | --- |
| 无 | 这类用户无权访问库存信息。 |
| 查看和编辑 | 这类用户可以对库存采取措施。 |
| 仅查看 | 这类用户只能查看库存信息。 |

**重要： **请注意，只能向有权对亚马逊物流库存执行操作或更改库存设置的用户授予【查看和编辑】权限。
