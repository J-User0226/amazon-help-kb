# 如何设置有效预算？

有效预算应涵盖您的促销在设置的期限内生成的买家需求成本。例如，如果某种商品在没有促销的情况下每天平均售出 20 个订单，而您想要为该商品设置 $5 折扣的促销，为期 10 天，则您能设置的最低预算为：（促销价值 X 日均订单数 X 天数）。在本示例中，您的最低预算为 (5 x 20 x 10) = $1000。在高流量事件中或您的促销与其他促销（例如秒杀）结合使用时，或者当您为提高折扣设置了不切实际的低预算时，最有可能出现预算超支。

要充分利用促销生效时间，请考虑使用促销带来的潜在销售提升，并在您的计算中考虑这一因素。在本示例中，如果商品在没有促销的情况每天平均售出 20 个订单，并且您估计有 10% 的销售提升，则应考虑 (10 x 22 x 5) = $1100 的预算。

避免创建不切实际的低预算。为高折扣创建低预算可能会造成您的预算仅在几个小时后便迅速到期，从而导致只有少数买家能够看到并获取您的促销，并且您可能会预算超支。 **重要： **促销预算仅用于计划目的，您应该要预计到会出现各种超出预算的情况。亚马逊不对任何预算超支负责。

要了解更多信息，请参阅[为什么我的促销支出高于预算？](https://sellercentral.amazon.com/gp/help/external/GRDZA5UAECYY9VRU)
