# 液体商品

如果包装受损，液体可能会泄漏。粘性商品（如凝胶、乳膏和乳霜）在运输和备货过程中也存在泄漏风险。如果容器在运输和备货过程中发生泄漏，则需要进行额外的预处理以防出现残损。

## 液体商品示例

液体商品包括但不限于以下商品：

- 饮料

- 罐装或瓶装食品

- 液体清洁用品

- 洗衣液

- 乳液

- 睫毛膏

- 指甲油

- 香水

- 油（如食用油或机油）

- 油漆

- 滚珠除臭剂

- 调味酱

- 洗发水

- 剃须膏

- 防晒霜

- 牙膏

## 了解您的液体商品是否需要预处理

液体商品的容器及盖子类型决定其是否需要额外的预处理。[加盖密封](https://sellercentral.amazon.com/gp/help/external/GM6RPXLLRCECY5UB)、[包装袋](https://sellercentral.amazon.com/gp/help/external/G201685210)以及[气泡膜包装](https://sellercentral.amazon.com/gp/help/external/G201685300)是最常用于液体商品的预处理类型。

## 危险液体

所有属于受管制危险品的液体商品都必须[装袋](https://sellercentral.amazon.com/gp/help/external/G201685210)，以防止在运输过程中发生泄漏或外溢，无论商品是否密封。

要确定您的商品是否为危险品，请参阅[危险品识别指南（危险物质）](https://sellercentral.amazon.com/gp/help/external/201003400)。

## 非危险品液体

非危险品液体商品的预处理要求因其体积和现有包装而异。

**体积**： 如果液体商品不超过 4.2 盎司（125 毫升），则无需额外的预处理，除非商品在运输或备货过程中反复出现残损。

**现有包装**：

- 金属罐或锡罐、睫毛膏、滚珠以及带螺旋盖的非易碎瓶子无需额外的预处理。

- 玻璃或陶瓷等易碎容器需要采用[气泡膜包装](https://sellercentral.amazon.com/gp/help/external/G201685300)，而在气泡膜包装不能防止泄漏时，则还需进行[加盖密封](https://sellercentral.amazon.com/gp/help/external/GM6RPXLLRCECY5UB)。

- 双重密封，也称二次密封，可防止泄漏，减少额外的预处理需求。如果没有采用双重密封，则可能需要[加盖密封](https://sellercentral.amazon.com/gp/help/external/GM6RPXLLRCECY5UB)或[聚乙烯塑料袋](https://sellercentral.amazon.com/gp/help/external/G201685210)。有关更多信息，请参阅下面的“双重密封”定义。

- 锁定机制可防止容器喷出液体，从而减少额外的预处理需求。

## “双重密封”的定义

[双重密封](https://sellercentral.amazon.com/gp/help/external/GM6RPXLLRCECY5UB)的定义是具有无法轻易打开的拧紧外盖***和***以下任何一种密封：

| 双重密封类型 | 示例 |
| --- | --- |
| 感应式密封： 通过感应式加热密封到容器开口的热塑材料。 | |
| 安全环： 将商品的盖子密封到容器上的塑料环。 | |
| 夹子： 将盖子密封到罐子上的金属夹。适用于罐装且不属于受管制危险品的液体、乳膏、凝胶和乳霜商品。至少需要两个夹子。 | |
| 塑料包装带： 商品开口周围的严密塑料膜。 | |
| 防儿童误开盖： 需要额外操作（如推动和转动）才能打开的盖子。 | |
| 热收缩包装： 商品周围进行热密封的收缩包装。可作为套筒，顶部和底部空间最小。仅适用于非危险品。 | |
| 包装箱： 用密封六面瓦楞纸或纸板箱包装出售商品，防止溢漏和残损。 | |

**注意： **
**如果商品在送达亚马逊时采用的包装或条形码不当或不符合要求，我们可能会拒收、退还或重新包装该商品，相应费用由您自行承担**。我们还可能会因残损和与残损相关的退货而对商品增加额外的预处理要求。

## 测试您的包装

3 英尺跌落测试可以确定商品的现有包装或新增包装是否适用。为防止出现不必要的残损，亚马逊不会执行此测试。但是，您可以使用此测试来检查包装的完整性。

## 3 英尺跌落测试

3 英尺跌落测试包括多次连续跌落。要测试您的商品，您应从 3 英尺的高度连续**五次**让商品跌落到混凝土表面。一个测试物品必须通过一次测试（五次跌落）。如果容器的残损不会造成泄漏或致使商品完整性发生任何重大变化，则可以接受。

需要进行跌落测试的商品侧：

- 顶部

- 底部

- 最大面

- 底角

- 最长底边
