# 编辑目标商城设置

您可以按照以下步骤，更改目标商城的设置选项：

1. 前往[建立国际商品信息](https://sellercentral.amazon.com/gp/global-selling/sync-offers/)工具。
2. 如果您已设置第二个来源商城，则需要使用页面顶部的商城切换器选择要为其添加目标商城的来源商城，然后才能继续操作。
3. 点击来源商城右侧的【编辑】按钮。
4. 按照[使用“建立国际商品信息”工具创建关联](https://sellercentral.amazon.com/gp/help/external/202121580)的工作流程为选定的来源商城编辑目标商城设置。

处理和创建商品可能需要最长 4 小时的时间才能完成。目标商城关联更新完毕后，系统会生成一份状态报告，您可在【“建立国际商品信息”下的“管理关联”】页面找到该报告。系统会向您发送一封电子邮件，告知流程已完成，并在邮件中提供结果一览。[了解更多信息](https://sellercentral.amazon.com/gp/help/external/202121620)

对于亚马逊物流商品，您需要将库存运送到目标商城的运营中心，之后才能激活这些商品。要管理您的库存，请前往[管理亚马逊物流库存](https://sellercentral.amazon.com/amazonsell/fba-inventory?)。

**注意： **如果您使用的是卖家自配送方式，建议查看在每个商城中的[配送设置](https://sellercentral.amazon.com/sbr#shipping_templates)，确保所设置的费率能够满足要求。要调整配送设置，请使用商城切换器更改商城。您可以从卖家平台的【设置】菜单访问配送设置。
