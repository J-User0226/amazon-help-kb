# 错误 8080

## 错误消息

属性 ${attribute_name} 中的内容不符合详情页面要求，因为其中包含 HTML 或其他类型的文本标记或代码。在销售伙伴帮助页面中搜索“详情页面规则”，以获取有关要求的更多信息。要更正错误，请删除所有不符合要求的内容，然后重新提交您的商品信息。

## 导致错误 8080 的原因

由于以下原因导致出现此错误：

- 商品描述、商品名称、要点等字段包含 HTML 标签（如 <p>、<br>、<strong>）、标记语言或不允许使用的格式代码。

- 商品详情字段中包含 JavaScript 或其他编程代码，无论是故意还是在复制粘贴时出错。

- 商品属性中显示有特殊字符、CSS 样式或网页格式元素。

## 解决错误 8080

要解决此错误，请按照以下步骤操作：

- 查看您的上传数据处理汇总报告，了解突出显示的属性，并删除任何 HTML 标签（如 <b>、<i>、<p>、<br>）或任何其他代码元素。

- 将内容转换为纯文本格式，并删除所有样式和格式。

- 确认您的商品名称、要点、描述、通用关键词未包含特殊格式，如使用 HTML、JavaScript 片段或网站样式代码创建的要点。有关更多信息，请参阅[商品名称要求](https://sellercentral.amazon.com/help/hub/reference/GYTR6SYGFA5E3EQC)、[商品要点要求](https://sellercentral.amazon.com/help/hub/reference/GX5L8BF8GLMML6CX)和[商品页面风格指南](https://sellercentral.amazon.com/help/hub/reference/G200270100)。
