# 错误 19056

## 错误消息
我们认为主图片中的商品采用了不允许此商品类型使用的包装或品牌/吊牌。请提交合规图片以解除禁止显示。另请参阅商品图片要求。

## 导致错误 19056 的原因
导致此错误的原因如下：
- 主商品图片显示的是采用零售包装、箱子或塑料袋包装的商品。
- 商品图片包含可见的价格标签、品牌标签或吊牌。

## 解决错误 19056
要解决此错误，请按照以下步骤操作：
1. 在拍摄前将商品完全从包装中取出，并去除所有吊牌、贴纸和标签。确保商品以自然状态呈现。
2. 要解决此问题，请参阅[商品图片要求](help/hub/reference/G1881)。

## 更新图片
要更新图片，请按照以下步骤操作：
- **选项 1**
  1. 依次前往【库存】 > > 【管理所有库存】。
  2. 找到您的商品信息，然后点击【编辑商品信息】。
  3. 前往【图片】选项卡并更新您的图片。
  4. 使用更新后的图片 URL 重新提交模板文件。

- **选项 2**
  1. 前往[图片管理器](https://www.sellercentral.amazon.dev/imaging/manage)。
  2. 点击【目录】，然后点击【上传图片】，将其转至图片管理器工具。
  3. 使用搜索栏，查找您的商品信息并上传图片。
  4. 使用更新后的图片 URL 重新提交模板文件。

- **选项 3**
  1. 在卖家平台搜索栏下，找到您的商品信息，然后点击【上传图片】。
  2. 上传您的图片，然后使用更新后的图片 URL 重新提交模板文件。
