# 设置或更改默认配送模板

您可以在“配送设置”页面将任何现有配送模板设置为默认配送模板。当您创建新的 SKU 时，除非您为其分配其他配送模板，否则默认配送模板将自动应用于该 SKU。

您也可以更改默认配送模板。但是，您不能删除默认配送模板。如果您想要将其删除，需要先更改默认配送模板。

要设置或更改默认配送模板，请按照以下步骤操作：
1. 前往[配送设置](https://sellercentral.amazon.com/gp/shipping/dispatch.html)，然后点击【配送模板】选项卡。
2. 从页面左侧的配送模板列表中选择所需的模板。
3. 点击【编辑模板】右侧的下拉菜单，然后点击【设为默认模板】。
4. 点击【确定】。

**注意： **更改默认模板时，已被指定旧默认模板的所有 SKU 仍将使用旧模板。未指定模板的新 SKU 将使用新的默认模板。
