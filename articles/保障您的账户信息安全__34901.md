# 保障您的账户信息安全

您的账户安全对我们而言非常重要，因为它对您的业务至关重要。我们建议您遵循最佳实践来增强您亚马逊账户的安全性：

## 卖家平台 - 安全性最佳实践
1. 为您的所有亚马逊账户设置[两步验证](https://sellercentral.amazon.com/gp/help/external/202110760)。您可以通过这种方式强化您的密码安全，因为您需要在登录账户时额外输入您手机收到的验证码。这将会显著降低密码泄露时的未授权访问风险。

2. 为您的每个账户设置各不相同的强密码，并定期[更改密码](https://sellercentral.amazon.com/gp/help/external/831)。
  - 为您的所有在线账户选择相同的密码，就如同可用同一把钥匙打开您家、汽车和办公室的门锁一样，一旦有犯罪分子破解了其中一个，则所有密码都会泄露。
  - 使用由数字、字母和符号组成的长密码。
  - 避免在密码中使用公开信息（例如：您的电话号码）。

3. 确保您用于登录账户的电子邮件地址或手机号码是最新的。有关如何更改电子邮件地址或密码的更多信息，请参阅[更改登录设置](https://sellercentral.amazon.com/gp/help/external/831)。

4. 如果您的公司有[多个用户](https://sellercentral.amazon.com/gp/help/external/901)，请让每个用户设置自己的账户，然后与您的账户关联。 确保定期审查有权访问您账户的子用户，并撤销不再需要访问的用户的访问权限。

5. 检查您的通知设置，确保您已完成必要的设置，可接收有关对您账户执行的重要操作的通知。当心网络钓鱼。亚马逊不会通过电子邮件要求您验证敏感信息。只有当您在我们的网站上完成订单、在亚马逊商城注册开店或在卖家平台中更新账户信息时才需要提交此类信息。
6. 如果您对某电子邮件的真实性存有疑问，请通过在浏览器地址栏中输入地址来直接访问我们的网站，而不要点击任何链接。

7. 要详细了解亚马逊为打击欺诈性电子邮件而采取的措施，请参阅[识别虚假（欺骗性）电子邮件](https://sellercentral.amazon.com/gp/help/external/G32261)帮助页面。

## 如果您的账户遭到了入侵。
如果您认为您的亚马逊账户遭到了入侵，请按照以下步骤操作：
1. 更改您的卖家平台登录密码。如果您无法登录您的账户，请联系销售伙伴支持。 **注意： **亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。

2. 检查您账户中的以下信息，以确定是否有任何更改：
  1. 电子邮件地址首选项
  2. 付款信息
  3. 用户权限
  4. 亚马逊店铺详情
  5. 商品和状况说明

3. 您的电子邮件账户也可能遭到了入侵。请考虑更改与您账户关联的电子邮件地址，并对您的电子邮件账户使用不同的密码。
4. 如果您怀疑自己收到的电子邮件或链接存在网络钓鱼攻击的风险，请将其举报给 [stop-spoofing@amazon.com](mailto:stop-spoofing@amazon.com)。有关更多信息，请参阅此[帮助页面](https://sellercentral.amazon.com/gp/help/external/G32261)。
5. 请联系销售伙伴支持，举报您的账户遭到了入侵。 **注意： **亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。
