# 赔偿报告（概览）

[赔偿](https://sellercentral.amazon.com/gp/ssof/reports/search.html#recordType=REIMBURSEMENTS)报告提供所有赔偿的明细，包括由您申请的赔偿和自动生成的赔偿。

赔偿获批后，相关款项将在 4~5 个工作日内显示在您的账户中。

**提示： **有关亚马逊物流买家退款的信息，请参阅[亚马逊物流买家退货](https://sellercentral.amazon.com/gp/help/external/200453320)。

赔偿也会显示在【付款】报告中。要查找某项赔偿，请执行以下操作：

1. 在 [【付款】 控制面板](https://sellercentral.amazon.com/payments/dashboard/index.html)中，点击 【交易视图】。
2. 在【视图筛选条件】下，选择【其他】。
3. 在【商品详情】列中，搜索【余额盘点】或【亚马逊物流库存赔偿】。

对于由您申请的赔偿，点击报告中的问题单编号以查看详情。对于与买家退款相关的赔偿，请使用报告中的亚马逊问题编号查看详情。

赔偿得到批准后，最长可能需要五天才会出现在报告中。如果我们在同一天内处理了针对同一问题的多项赔偿，则可能将其合并成一个单项交易。

## 字段定义
在线报告标题 可下载报告标题 描述
日期 批准日期 赔偿获得批准的日期。
赔偿编号 赔偿编号 此赔偿的唯一编号。每个赔偿可以包括多项商品。
问题编号 问题编号 在您申请赔偿时分配给相应问题的唯一编号。
亚马逊订单编号 亚马逊订单编号 分配给买家订单的唯一编号。如果赔偿与订单无关，则此字段为空。
原因 原因 赔偿的原因（如“在库期间 残损”）。
卖家 SKU SKU 卖家 SKU（库存单位）是您为您的商品分配的唯一编码。
FNSKU FNSKU 配送网络 SKU（库存单位）是亚马逊物流为您的商品分配的唯一编码。
ASIN ASIN ASIN（亚马逊商品编码）是亚马逊为亚马逊商品目录中的商品分配的唯一编码。可在商品详情页面上找到 ASIN。
商品名称 商品名称 商品的名称。
状况 状况 商品的状况（如“新品”)。
数量 数量 此项赔偿涉及的商品总数。
[在线版本中不显示] currency-unit 适用商城的货币。
每件商品的金额 每件商品的金额 此项赔偿的按件赔偿金额。
赔偿数量 [现金] 现金赔偿数量 以现金形式赔偿的商品总数。
总金额 总金额 此项赔偿的现金赔偿总额。
赔偿数量 [库存] 库存赔偿数量 以库存形式赔偿的商品数。
赔偿数量 [总计] 赔偿总数 以现金或库存形式赔偿的商品总数（赔偿数量 [现金] + 赔偿数量 [库存]）。
原始赔偿编号 original-reimbursement-id 要调整的原始赔偿请求的唯一标识（如果有）
原始赔偿类型 original-reimbursement-type 要调整的原始赔偿请求的交易类型（如果有）

**注意： **亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。
