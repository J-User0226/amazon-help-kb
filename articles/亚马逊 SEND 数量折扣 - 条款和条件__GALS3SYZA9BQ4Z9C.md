# 亚马逊 SEND 数量折扣 - 条款和条件

亚马逊 SEND 是卖家平台中内置的一项配送计划，可帮助卖家使用合作承运人跨境配送商品。它提供货件预约、承运人标签生成和货件追踪。您可以将商品运送至我们指定的运营中心或其他亚马逊指定设施，费用由您自行承担。如果您在卖家平台上预约从符合条件的起运国家/地区的发货地址发往符合条件的目的地国家/地区的货件，并选择亚马逊 SEND 承运人（与亚马逊合作的第三方承运人）来执行该货件运输，则您受以下条款和条件约束。有关亚马逊 SEND 计划的更多信息，请参阅[亚马逊 Send 计划](https://sellercentral.amazon.com/gp/help/external/GZELJ3VF77L5H4QH)帮助页面。

此补充条款是亚马逊 SEND 计划[条款](https://sellercentral.amazon.com/gp/help/external/G27F6UHDSSHW6WXF) 的一部分。除非下文另有定义，否则本页面上使用的术语与亚马逊 SEND 计划条款中的含义相同。
1. **折扣和分段**： 亚马逊 SEND 承运人可能会针对亚马逊 SEND 配送费提供按数量收费的折扣。这些折扣由各个亚马逊 SEND 承运人提供，而非由亚马逊提供。卖家平台中的亚马逊 SEND 承运人报价将提供任何可用的按数量收费的折扣和资格条件，并且可能会随时更新或终止。
2. **资格要求**： 折扣和分段由您在每个日历月（“资格期”）内通过各亚马逊 SEND 承运人预约的合格货件总数决定。“合格货件”是指已交给亚马逊 SEND 承运人、已支付配送费用，且未取消、拒收或退还给发件人的货件。
3. **临时折扣**： 如果您收到的折扣基于预测或已预约的未来货件量，则该折扣为临时折扣，直到我们确认您的实际符合要求的货件量达到了该资格期适用的分段门槛。如果您在某个资格期内实际符合要求的货件量低于所适用折扣分段阈值，我们将向您收取您获得的临时折扣与您有资格享受的折扣（如有）之间的差额。我们将为此金额开具发票，或将其从未来应付给您的款项中抵扣。
4. **不可合并**： 符合要求的货件数量不得在亚马逊 SEND 承运人之间叠加，并且数量折扣不得与其他促销抵扣额度或折扣叠加，除非我们另有书面说明。
5. **变更和终止**： 我们可能会在提前 30 天通知的情况下修改或终止本补充条款。在终止时已应用的任何临时折扣，仍会根据上述第 3 点的要求被追回。
