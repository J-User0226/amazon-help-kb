# 汽车配件入门

了解汽车配件数据以及为您的商品信息提交这些数据的要求。

## 概述
亚马逊的零件查找器依赖 ACES 配件数据来帮助买家找到适合其车辆的零件，并对特定车辆的零件执行“检查是否适配”。您通过 XML 上传数据以 ACES 格式提交车辆配件数据。该数据经过多个系统，最后一个系统会将配件数据与我们目录中的商品数据相匹配。
- 您可以使用两种工具提交配件数据，这两种工具均可通过卖家平台访问：
  - **汽车配件管理器 (AFM)**： 用于批量 XML 提交。
  - **配件工具**： 允许通过 Web 界面编辑单个记录。

- 配件数据一旦进入我们的系统，我们便不会对其进行编辑。我们只能删除配件记录。
- 我们接受美国、加拿大和墨西哥的配件数据。每个区域都有一个 ID： 1 = 美国，2 = 加拿大，3 = 墨西哥。如果您指定区域，则配件数据仅适用于该区域的零件查找器。如果您未指定区域（不限区域的数据），则该数据仅适用于记录值有效的区域。例如，指定仅在美国和加拿大存在的车辆编号的不限定区域记录将仅适用于美国和加拿大。删除特定于区域的数据只会影响该区域。删除不限区域的数据会影响所有适用区域。
- 我们接受来自多个提供商的配件数据。您提交的数据可能不会被选为商品显示的配件数据。

如对配件数据有疑问，或希望为您的商品请求优先处理特定数据源，请通过 automotive-dataprovider@amazon.com 联系汽车配件团队。

## 先决条件
在提交汽车配件数据之前，请确保您已完成以下操作：

** 1. 您必须拥有有效的卖家平台账户。 **

- 无论您是提交自己配件数据的卖家，还是代表他人提交配件数据的第三方数据提供商，此规定均适用。

- 代表现有亚马逊卖家（或根据与亚马逊签订的合同协议）提交一个或多个汽车品牌配件数据的第三方数据提供商，必须设置一个专门用于提交配件数据的新账户。

**2. 向汽车护理协会注册您的品牌代码**

每个 ACES 文件都必须在其标头中引用有效的品牌代码。您必须向汽车护理协会的车辆信息门户 (VIP) 注册您的品牌。

1. 在 [autocare.org](https://www.autocare.org/) 上创建一个账户，以便访问 [autocarevip.com](https://www.autocarevip.com) 上的车辆信息门户 (VIP)。
2. 请注意，虽然 VIP 访问是免费的，但创建和接收 ACES XML 文件需要有效的付费订阅 VCdb 套餐，其中包括访问 VCdb、Qdb 和 PCdb。有关订阅和账单问题，请联系 techbilling@autocare.org。
3. 搜索现有品牌，检查您的品牌是否已注册。避免创建重复项。
4. 如果您的品牌未列出，请提交新的品牌请求。您需要提供品牌名称和公司名称。系统会分配一个唯一的 4 个字符的品牌代码。
5. 创建新的品牌代码后，大约需要 1 个工作日，该代码才能在 Auto Care 的系统中可用于 ACES 提交。
6. 有关汽车护理注册相关的问题，包括为您的品牌名称分配品牌代码，请发送电子邮件至 technology@autocare.org。

**品牌代码匹配**
- 您的品牌代码很重要。这是我们用于将您的配件记录与您的商品关联的主要标识符。品牌代码必须包含在 ACES 文件标头的 <BrandAAIAID> 元素中。
- 与您的品牌代码关联的品牌名称必须与您在卖家平台中的 ASIN 上使用的品牌名称相匹配。 如果不匹配，则表明您的配件记录将与您的商品不匹配。

**维护您的品牌代码**
- 支付所有必需的年度维护费用，以使品牌代码保持活动状态。非活动品牌代码会导致之前提交的配件数据被禁止显示。当 Auto Care 将某个非活动品牌归档后，该品牌将在我们的系统中变为无效，且与该品牌代码关联的所有配件记录都将被隐藏。

**3. 申请并获批成为配件数据提供商**

我们首选接收由制造商或品牌所有者直接提供的配件数据，或者由制造商/品牌所有者批准的第三方数据提供商提供的配件数据。并非所有请求成为直接配件数据提供商的销售伙伴都会获得批准。此决定由我们的汽车零件查找器团队全权决定。

1. 在卖家平台中，前往【库存】，然后选择【管理汽车配件数据】。
2. 系统将提示您提供以下信息：
  - 包含 5~10 条申请记录的 ACES 文件示例
  - 您将为其提供数据的品牌

3. 我们将审核您的请求，并可能会要求您修改示例 ACES 文件。
4. 如果获得批准，您将收到确认信息，并可以访问[汽车配件管理器 (AFM)](https://sellercentral.amazon.com/automotive-mfm/) 控制面板。
  - 只有账户上的主用户才能申请 AFM 访问权限。

5. 要请求对[配件工具](https://sellercentral.amazon.com/automotive/fitment/)的访问权限，请联系销售伙伴支持，并请求启用“汽车配件工具。” 在此之后，我们的团队会将您的卖家编号添加到许可名单中，您会在 1 小时内获得访问权限。
  - 您必须在美国商城拥有有效的销售账户。
  - 您必须以主账户所有者身份登录，因为不支持子账户。（如果您已获得启用，但无法看到该工具，请确认您已使用主账户凭证登录。）
  - 您必须在某个 ASIN 上拥有在售报价，才能为其提交配件数据。

获得批准后，您即可提交配件数据。请参阅[向亚马逊提交配件数据](https://sellercentral.amazon.com/help/hub/reference/GRB9TXB3SNPTVCKW)。 。

如果您在此新手入门流程中遇到问题，请通过卖家平台提交支持问题单。 请求将其分配给**汽车数据质量**。

## 我们如何使用汽车配件数据
无论商品由谁销售，我们都会为亚马逊上的所有特定于车辆的汽车商品使用配件数据。了解我们如何将配件数据与商品匹配，可帮助您避免常见的提交错误。

我们目录中的每件商品都有一个名为亚马逊标准商品编码 (ASIN) 的唯一标识。我们的匹配流程基于两个主要属性将 ACES 记录与 ASIN 关联：品牌名称和零件编号。

创建 ACES 数据文件时，请确认以下事项：
- **品牌名称完全匹配。** 您在标头中声明的品牌代码的品牌标签必须与 ASIN 商品详情页面上的品牌名称完全匹配。
- **零件编号完全匹配。** 您在每个申请记录中申报的零件编号必须与 ASIN 上的零件编号完全匹配。 您卖家平台目录中的零件编号必须与您 ACES 文件中的零件编号完全匹配。
- **零件类型编号正确无误。** 每个申请记录中的零件类型编号必须正确标识零件的类型。我们使用零件类型编号来区分品牌中具有相同零件编号的不同商品。

如果“品牌名称”或“零件编号”任一项不匹配，您的配件记录将无法关联到您的商品。

请参阅[创建您的 ACES 配件文件](https://sellercentral.amazon.com/help/hub/reference/GTVEB7S6YY5WVPMR)了解更多详情。

**注意： **亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。
