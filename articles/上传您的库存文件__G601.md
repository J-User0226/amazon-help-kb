# 上传您的库存文件

## 亚马逊物流
如果要上传亚马逊物流库存，请按照[批量发布亚马逊物流商品](https://sellercentral.amazon.com/gp/help/external/200327780)中提供的附加说明进行操作。

在[创建](https://sellercentral.amazon.com/gp/help/external/581)或[修改](https://sellercentral.amazon.com/gp/help/external/G201576660)库存文件后，请将文件保存为制表符分隔的文本 (.txt) 或 excel (.xls) 格式。

要上传文件，请按照以下步骤操作：

1. 在卖家平台的【目录】下，前往【批量上传商品】。 **注意： ** 如果您拥有[北美联合账户](https://sellercentral.amazon.com/gp/help/external/201394090)，请检查所选网站或切换商城以选择首选商城，并确保将库存文件上传到正确的网站。您还要检查文件，确保使用全球 SKU 的商品的数量值大于 0（零）。如果您在一个商城中将该数量更改为 0，则会从所有北美的亚马逊商城中移除该商品。

2. 点击【上传您的电子表格】选项卡。在【上传文件】框中，拖放库存文件（您也可以点击【浏览文件】）。在选择文件后，状态条将从 0 加载到 100%，对文件进行验证。 **注意： **验证完成状态不代表已完成上传流程。

3. 在完成文件验证后，在大多数情况下系统会自动检测到【文件类型】，但库存加载工具和非亚马逊文件除外。如果未自动选择【文件类型】，请使用下拉菜单选择您的文件类型。

4. 如果要使用商品文件在亚马逊目录中创建新页面，通常您将为“非媒介类商品的库存文件”选择第一个选项。

5. **注意： **对于媒介类商品（图书、音乐、影视）文件和库存加载工具文件，“上传”框将包含针对配送设置的额外选项。有关如何使用这些选项的更多信息，请参阅[配送媒介类商品（图书、音乐、影视）](https://sellercentral.amazon.com/gp/help/external/200384330)。

6. 如有需要，请查看下方关于“清除并替换”选项的信息。
7. 确认页面上的所有信息后，点击页面底部的【上传文件】。

上传库存文件并不能确保上传成功。在上传库存文件后，请点击相关链接查看上传结果。有关更多信息，请参阅[审查库存文件](https://sellercentral.amazon.com/gp/help/external/611)。

## 清除并替换您的库存
如果您要移除全部库存，并仅使用您上传的文件中的内容替换它，请点击【上传文件】框右上角的【清除并替换您的库存】。

**注意： **库存文件中未包含的所有商品都将被删除。

我们建议您在使用“清除和替换”选项前，运行[在售商品报告](https://sellercentral.amazon.com/gp/help/external/200385890)。 此报告提供有关您卖家账户中所有商品的信息，包括可售数量为零 (0) 的 SKU。“在售商品报告”为审核您现有的库存记录提供良好的基础，也可以用作备份文件，以防在执行清除和替换时发送的文件出现错误。

通常，您可以提交库存文件，并为要添加或更改的 SKU 选择【添加】选项，以此来添加或修改商品信息。这也是默认选项，因此如果您未指定其他选项，系统会认为您要添加库存数据或修改已记录的库存数据。（“添加”选项和“清除并替换”操作不适用于“商品价格和数量”文件，后者只能进行修改。）

如果要移除缺货商品，请在库存文件中将其数量设置为零 (0)，或使用“商品价格和数量”文件进行快速更新，而不是使用“清除并替换”选项。使用“清除并替换”操作后，SKU 及关联的商品数据信息将被永久删除。如果想再次销售该商品，您必须使用针对特定分类的库存文件重新提交该商品的所有数据。。有关更多信息，请参阅[修改库存文件](https://sellercentral.amazon.com/gp/help/external/G201576660)。

如果要对商品信息进行非常重大的更改，涉及很多添加和删除的操作，则可以仅提交您要添加或修改的商品信息，并选择“清除并替换”选项。但是，由于这会删除库存文件中未包含的所有商品信息，因此如果您在选择“清除并替换”选项时所用的文件未包含所有的现有库存，则可能需要提交另一个文件并选择【添加】选项，以重新加载仍想在亚马逊商城销售的所有商品信息。有关更多信息，请参阅[使用“清除和替换”选项](https://sellercentral.amazon.com/gp/help/external/G201576690)。

此外，移除所有商品并将其重新发布可能会十分方便，特别是当您无法追踪自己在亚马逊商城已发布的库存时。但请注意，选择“清除并替换”会降低库存文件的整体处理速度。

发送文件时，使用【移除现有商品】选项将不会移除您使用“添加新商品”工具专门创建和管理的所有商品。您不能使用“清除和替换”选项移除这些商品。如有必要，您必须通过【管理库存】页面手动删除这些商品。或者，您也可以使用库存加载工具文件的“x”选项来移除这些商品。要执行这一操作，您需要使用“在售商品报告”并将其转换为库存加载工具文件。请参阅[使用报告更新库存](https://sellercentral.amazon.com/gp/help/external/200388940)。

**注意： **使用【清除并替换】选项时，如果您有北美联合账户并使用全球 SKU 共享库存，则当您从一个亚马逊网站中删除商品时，该商品也会从其他亚马逊网站中移除。

**注意： **亚马逊的卖家助手可以通过此主题提供帮助。对于大多数语言设置，卖家助手还可以直接将您转接至销售伙伴支持。
