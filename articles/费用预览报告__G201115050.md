# 费用预览报告

此报告显示了针对您当前的亚马逊物流库存估算的亚马逊销售和配送费用，以及即将针对您的卖家自配送商品和亚马逊物流商品推出的费用变更（如果有）。

针对卖家自配送商品预估的亚马逊物流费用仅供您参考，不会从您的账户中扣除。此报告中数据的更新时间不超过 72 小时。

有关更多信息，请参阅[亚马逊物流功能、服务与费用](https://sellercentral.amazon.com/gp/help/external/201074400)。

## 字段定义

| 字段名 | 描述 | 示例 |
| --- | --- | --- |
| sku | 库存单位 (SKU) 由一组字母或数字组成，是用于标识您商品的唯一编码。SKU 由卖家分配。 | AB-8675309 |
| fnsku | 亚马逊为亚马逊运营中心储存并配送的商品分配的唯一标识 | X00000E5TX |
| asin | 亚马逊商品编码 (ASIN) 由 10 个字母或数字组成，是用于标识商品的唯一编码。ASIN 由亚马逊分配。您可以在商品详情页面找到商品的 ASIN。 | B003ZYF3LOv |
| product-name | 商品的名称 | Toysmith 不粘锅或烤盘套装 |
| product-group | 亚马逊部类或分类 | 厨房用品 |
| brand | 商品的品牌 | Casio |
| fulfilled-by | 配送商品的实体 | 卖家自配送或亚马逊物流网络 |
| your-price | 您当前的销售价格 | 10.25 |
| sales-price | 您当前的促销价格 | 4.00 |
| longest-side | 商品最长边的测量值（含包装） | 20 |
| median-side | 商品次长边的测量值（含包装） | 10 |
| shortest-side | 商品最短边的测量值（含包装） | 4 |
| length-and-girth | 商品最长边的长度（含包装）加上围长（一种商品测量值，计算方法为 2 x [次长边 + 最短边]） | 48 |
| unit-of -dimension | 测量时所使用的尺寸单位 | 英寸 |
| item-weight | 商品的重量 | 10 |
| unit-of-weight | 测量重量时所使用的重量单位 | 磅 |
| product-size-tier | 亚马逊物流根据商品的尺寸和重量为商品分配的尺寸分段 | 大号大件 |
| currency | 计算费用时所使用的货币 | 美元 |
| estimated-fee-total | 预计的配送和“我要开店”费用 | 25 |
| estimated-referral-fee-per-unit | 预计的“我要开店”销售佣金 | 2 |
| estimated-variable-closing-fee | 商品的预计可变交易手续费 | 5 |
| estimated-order-handling-fee-per-order | 每笔订单的预计订单处理费 | 6 |
| estimated-fba-fulfillment-fee-per-unit | 每件商品的预计亚马逊物流配送费用 | 2 |
| estimated-weight-handling-fee-per-unit | 基于出库发货重量的商品预计配送费 | 1 |
| estimated-future-referral-fee-per-unit | 根据按未来费用类别生效日期将收取的未来费用类别预计的每件商品的销售佣金 | 3.54 |
| current-fee-category | 您的商品所对应的当前费用分类 | 图书 |
| future-fee-category | 按未来费用分类生效日期与您的商品匹配的费用分类 | DVD |
| future-fee-category-effective-date | 未来费用分类生效的日期 | 2022/3/15 |
